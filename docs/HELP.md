# Drawer 로컬 도움말

## welcome | 시작 안내 | 도움말 처음 시작 로컬 오프라인

Drawer는 인터넷 연결과 계정 없이 로컬 문서와 설정을 사용하는 그림 작업공간입니다.
New canvas로 그림을 만들고 Open으로 자체 문서를 엽니다. 캔버스에 마우스로 그리거나 지우고 획을 실행 취소할 수 있습니다. 독립 Test painting 창에서도 도구를 시험합니다. 펜 입력도 지원하며 실장치 검증은 대기 상태입니다.
검색란에 한국어 용어, 영어 메뉴 이름 또는 현재 지정한 단축키를 입력합니다. 검색 결과가 없으면 검색어를 지우거나 시작 안내로 돌아갑니다.

## files | 문서·저장·가져오기 | 파일 저장 열기 PNG JPEG TIFF 클립보드 취소

New canvas는 독립 미저장 문서를 만듭니다. px/mm/inch, DPI, 비율 잠금과 로컬 크기 프리셋을 선택합니다.
Save는 편집 가능한 .drawer 형식으로 저장합니다. Save as는 새 위치로 저장하고 이후 저장 대상을 그 위치로 바꿉니다. PNG export는 합성된 그림을 내보내며 자체 문서와 보기 상태를 바꾸지 않습니다.
Image as new document는 PNG/JPEG/TIFF/BMP를 미리 본 뒤 독립 그림으로 가져옵니다. New from clipboard는 이미지 클립보드로 새 그림을 만들고 Paste image layer는 이동 가능한 새 레이어를 미리 본 뒤 한 번에 확정합니다. 취소는 기존 그림을 유지합니다.
Recent files는 최근 성공한 경로를 보존합니다. 원본 이미지에 덮어쓰지 않습니다. 마지막 보기를 닫거나 종료할 때 미저장 그림의 저장·버리기·취소를 선택합니다.
Local file actions의 저장본 되돌리기는 변경을 버린다는 확인 뒤 실행합니다. 자체 파일 연결은 Windows 기본 앱 설정에서 직접 선택합니다.

## size | 크기·해상도·DPI | 캔버스 물리 크기 밀리미터 인치 비율 회전 자르기

Sizing에서 이미지 재샘플링, DPI만 변경, 캔버스 크기/각 변 여백 변경, 자르기, 좌우·상하 반전, 90도 회전을 선택합니다.
크기 창의 보간은 보기 보간과 별개입니다. 픽셀 유지 DPI 변경은 픽셀을 바꾸지 않습니다. 물리 크기 유지는 DPI에 맞게 픽셀을 재샘플링합니다.
미리보기에서 적용하거나 취소합니다. 내용 제거는 확인을 거치고 확정된 변경은 Undo 한 번으로 복원합니다. 캔버스 밖 레이어 픽셀도 자체 파일에 보존됩니다.

## view | 보기·내비게이터·모니터 | 확대 축소 줌 이동 배율 회전 반전 선택 화면 모니터

휠은 커서 위치를 유지하며 확대합니다. 가운데 버튼 또는 Space와 드래그는 보기를 이동합니다. Zoom region은 드래그 영역을 화면에 맞춥니다.
100%, 0°, Center, Reset view는 각각 배율·회전·위치·전체 보기를 복원합니다. 보기 반전은 저장 픽셀을 반전하지 않습니다.
Duplicate view는 같은 그림의 다른 배율/각도 탭을 만듭니다. Ctrl+PageUp/Down은 보기 순서를 이동하며 Alt+1부터 Alt+9는 현재 순서의 탭을 선택합니다. 없는 번호는 아무 작업도 하지 않습니다.
Navigator의 녹색 경계는 보이는 영역, 파란 채움과 점선은 선택입니다. 클릭은 보기 중심을 옮기며 그림을 편집하지 않습니다.
Display view는 선택 모니터의 별도 캔버스 창입니다. 보기 동기화를 끄면 독립 배율과 중심을 유지합니다. F11은 전체화면, Esc는 창 모드입니다. 화면이 사라지면 사용 가능한 화면으로 회수합니다.

## aids | 눈금·격자·가이드 | 길이 인쇄 물리 크기 눈금 격자 가이드 보정

Canvas aids에서 단위와 눈금, 격자, 가이드 표시를 선택합니다. 격자 간격/원점과 가이드 추가는 문서 편집이며 Undo로 복원합니다. 표시 켜기/끄기는 설정입니다.
인쇄 크기를 보려면 기준선의 실제 밀리미터 길이를 입력해 화면을 보정합니다. 모니터를 바꾸면 다시 보정합니다.

## tools | 도구·시험 칠하기 | 브러시 붓 연필 지우개 워시 필압 펜 마우스 커서 색

Brushes는 Pen, Pencil, Eraser, Airbrush 팁과 현재 크기·타원 비율·팁 회전을 표시합니다. 커서는 보기 회전/반전/화면 배율을 반영한 외곽과 도구 아이콘입니다.
Test painting은 문서와 분리된 시험 영역입니다. 현재 도구·크기·색으로 드래그해 칠하고 Eraser로 지웁니다. 내용과 표시 상태는 로컬 저장되며 문서 Undo에 포함되지 않습니다.
펜 하드웨어 검증은 별도이며 마우스로 시험할 수 있습니다.
Tool input behavior에서 임시 도구 유지 시간과 실제 화면 픽셀의 드래그 거리를 선택합니다. 짧은 도구 키는 선택 유지, 기본 300ms 이상 누른 키는 놓으면 이전 도구로 돌아옵니다. 포커스/문서 변경은 유지 입력을 끝냅니다.

## reference | 참고 이미지·색 선택 | 참고 서브뷰 색 스포이트 투명도 색환

References에 로컬 이미지 또는 이미지 클립보드를 추가합니다. 목록과 Previous/Next로 전환하고 휠/가운데 버튼/Space 드래그로 보기를 조절합니다.
Pick color 클릭 또는 Auto pick으로 원본 색과 알파를 읽습니다. Color ring은 커서 옆에 선택 색을 보여줍니다. Open as new drawing은 독립 새 문서를 만듭니다.
참고 복사본과 설정은 로컬 저장합니다. 참고 제거는 원본을 지우지 않습니다. Save set/Load set은 복사본을 포함하는 로컬 묶음이며 참고 설정에 별도 취소와 이전본 복원을 제공합니다.

## workspace | 작업공간·패널 | 배치 도킹 분리 레이어 타임라인 설정 백업 초기화

Panels는 브러시/색/레이어/타임라인 표시, 썸네일과 도구 아이콘/이름/획 미리보기, 속성/명령막대 표시를 선택합니다. 대상 선택과 그림 데이터는 그대로 유지합니다.
Workspaces 또는 패널 Dock 메뉴에서 좌/우 도킹 또는 Floating 분리 창을 선택합니다. 이름 있는 배치를 저장하고 전환·갱신·삭제·재적용할 수 있습니다.
로컬 가져오기/재적용은 설정군을 따로 골라 확정합니다. 미선택 설정은 유지합니다. 적용 전 자동 백업과 미저장 배치의 별도 이름 저장은 따로 선택합니다. 취소는 현재 설정을 유지합니다.
Interface size는 모니터 배율에 더하는 50–200% 크기입니다. 그림의 픽셀과 보기 중심은 유지합니다.

## shortcuts | 실제 단축키·명령 배정 | 키보드 shortcut 빠른 접근 원형 메뉴 순환 장치

아래 실제 목록은 현재 설정의 키 배정입니다. 기본 키를 바꿨다면 바꾼 배정을 보여줍니다.
Input and commands에서 키와 명령을 배정합니다. 중복/예약 키는 즉시 알리고 기존 배정을 덮지 않습니다. 변경은 임시본에서 확정하며 취소는 기존 배정을 유지합니다.
도구 순환 목록은 이름·순서·역순·복제·삭제와 다음/이전 입력을 지원합니다. 삭제된 도구는 건너뛰고 빈 목록은 이유를 표시합니다.
빠른 접근/명령막대는 명령·도구·고정색·구분자, 검색과 타일/목록/팝업을 지원합니다. 일반 드래그 또는 선택한 Ctrl 필요 드래그로 재배열합니다. 등록한 고정색은 현재 색 변경에 영향받지 않습니다.
원형 메뉴의 4/8방향 슬롯은 마우스와 1–8 키, 방향키로 같은 명령을 선택합니다. 중앙/Esc/영역 밖은 취소입니다. 공통 명령 선택은 기존 배정을 선택해 열고 Confirm으로만 임시본을 바꿉니다.
장치 어댑터가 제공하는 이름 있는 동작 또는 포인터 추가 버튼을 같은 명령에 배정합니다. 사용할 수 없는 동작은 이유를 표시하고 키보드 대체를 사용합니다.

## movie | 로컬 영상 가져오기 | 애니메이션 영상 동영상 프레임 셀 오디오 FFmpeg

Movie 메뉴는 로컬 영상으로 새 애니메이션을 만들거나 현재 애니메이션에 별도 트랙으로 삽입합니다. 로컬 FFmpeg/FFprobe 7.1이 필요합니다. Choose local FFmpeg로 직접 지정하며 앱은 코덱을 내려받지 않습니다.
시간 범위·FPS·크기·보간·오디오를 선택하고 Decode range and preview에서 확인한 뒤 확정합니다. 대응표는 목표 FPS의 전체 프레임 위치를 표시합니다.
오디오는 채널 수를 유지한 48kHz PCM입니다. 취소는 현재 그림을 유지하며 삽입은 Undo 한 번으로 제거합니다. Frame 슬라이더는 확인 프레임을 바꾸며 그림을 편집하지 않습니다.
지원 범위는 MOV/MP4 H.264, MKV FFV1, AVI rawvideo, WebM VP9의 검사된 8bit SDR 변형입니다. 자세한 제약은 설치 폴더의 MOVIE-IMPORT.md를 읽습니다.

## behavior | 패널·커서·가장자리·절전 | 자동 숨김 스크롤바 커서 화면 가장자리 절전 전원

Panels, cursor and power에서 브러시/색/레이어/타임라인 패널의 유휴 자동 숨김, 스크롤바와 브러시 커서 표시를 선택합니다. 숨긴 패널은 제목/내용 표시 버튼에 마우스를 가져가거나 키보드로 접근해 다시 펼칩니다. 분리 창은 원래 전체 크기를 유지한 채 접고 펼칩니다.
화면 가장자리 이동을 켜면 캔버스의 primary 버튼을 누르는 동안 가장자리 방향으로 보기가 이동합니다. 여백과 속도는 화면의 실제 픽셀 기준입니다. 버튼 해제·포커스 상실은 이동을 끝냅니다. 보기는 저장 픽셀을 바꾸지 않습니다.
자동 유휴 절전 억제는 기본 꺼짐입니다. 켜면 칠하기·영상/이미지/크기 처리와 저장/PNG 출력 중에만 요청하며 완료·실패·취소·종료에서는 해제합니다. 화면 켜짐 유지도 따로 고를 수 있습니다. 사용자가 직접 요청한 절전은 Windows 정책을 따릅니다.
설정은 임시본에서 확정하고 취소는 현재 값을 유지합니다. 적용 전 백업·초기값·이전본을 제공합니다.

## cursors | 원시·보정·예측 커서 | 커서 안정화 보정 예측 최소 크기 방향 반전 기울기

Cursor styles에서 각 도구의 외곽/십자/아이콘/시스템 커서와 작은 외곽의 최소 화면 픽셀 크기를 선택합니다. 팁 회전과 보기 회전/반전을 함께 반영합니다.
Raw는 현재 수신 좌표를 흰색으로 표시하고 Corrected는 실제 획 계산에 쓰는 필터 좌표를 청록색으로 표시합니다. Both는 원시 십자와 보정 외곽을 구분합니다. 예측은 주황색 열린 표시이며 확정 픽셀에 사용하지 않습니다. 시스템 커서는 원시 마우스 위치입니다.
안정화 강도는 Tool input behavior의 도구별 설정입니다. 커서 표시 선택은 안정화나 결과 픽셀을 바꾸지 않습니다. 시험 칠하기는 같은 필터를 사용하며 입력 이탈·포커스 상실·버튼 해제는 오래된 표시를 끝냅니다.

## information | 좌표·길이·색 정보와 테마 | 정보 좌표 거리 측정 단위 RGB HSV HSL CMYK 테마

Information은 포인터 또는 측정점의 문서 좌표, 두 점의 가로/세로 차이와 직선 거리를 보여줍니다. Pick start/Pick end를 누른 뒤 캔버스를 클릭하거나 선택한 점의 숫자를 조절합니다. 측정선과 위치는 세션 상태이며 그림을 편집하지 않습니다.
표시 단위는 Document(현재 눈금 단위), px, mm, cm, inch, point입니다. 실제 길이는 문서 DPI를 사용하며 보기 확대/회전/반전에 영향받지 않습니다.

## modifier-tools | Modifier tools | Ctrl Shift Alt temporary hold conflicts 수정키 임시 도구 충돌

Open Tool input behavior to assign Ctrl, Shift or Alt to a temporary tool. Modifier tools always return to the previous tool when released, even before the short-key threshold. Letter tool keys still follow the configured hold threshold. Overlapping modifiers restore in press order.

Shared shortcuts appear in the editor. Key chords, input fields, menus and dialogs take priority and suspend modifier tools until the modifier is released. Release and press again after closing a popup. Window focus loss cancels pending tool input. These assignments are local workspace preferences and do not add drawing history.

## screen-mode | Simple and full screens | F12 panels screen mode 간단 전체 도구 화면

The screen button switches between all panels and a simple drawing screen. F12 is the default shortcut on a new profile; assign Simple/full screen in Input and commands for an existing profile. Simple mode keeps document tabs, tools and canvas controls, and provides All tools and commands for the remaining controls. Floating tool panels and the navigator return to their previous layout when switching back.

Screen mode is session-only. It preserves document contents, selections, tool choices, view values and pending previews. The screen button remains available while a preview disables drawing commands. Independently opened information, reference and test-painting windows remain usable.

크기는 0.1~4096 문서 픽셀, 불투명도·경도는 0~100%, 간격은 브러시의 짧은 축 지름의 0.01~10배입니다. 경도 0은 부드러운 가장자리, 100%는 단단한 가장자리입니다. 불투명도는 한 획 전체에 적용하므로 같은 획의 팁이 겹쳐도 지정 농도를 넘지 않으며 0은 픽셀·이력 불변입니다. 크기 단위 px/mm/in은 활성 문서 DPI로 변환하며 실제 크기는 픽셀로 저장합니다. 슬라이더 옆 숫자를 클릭해 직접 입력하고 Enter/포커스 이동으로 확정합니다. 숫자 위/아래, 슬라이더 왼쪽/오른쪽 키는 같은 단위 증분을 사용하며 Ctrl은 1/10입니다. 잘못된 문자·NaN·무한대·범위 밖 값은 마지막 정상값을 유지하고 오류를 표시하며 적용/복사/저장을 막습니다. 빠른 이동은 받은 점 사이를 문서 좌표의 팁 간격으로 연결합니다. 회전한 납작한 타원도 짧은 축 기준으로 보간합니다. 큰 간격을 지정한 점 브러시의 의도된 여백은 유지합니다. 짧은 획은 실제 끝점에서 마무리하고, 자원 한도를 넘으면 부분 확정 없이 획을 취소합니다.

## brush-material | 혼색·번짐·수채 | 혼합색 유지 주색 공급 수분 희석 농도 유지 알파 잠금 무색 번짐

## pointer-input | 마우스·펜 입력 구분 | 장치 종류 ID 안정화 펜 터치

Mouse and pen input에서 마우스와 펜의 그리기 허용·안정화 덮어쓰기를 각각 설정합니다. 덮어쓰기를 끄면 현재 도구의 안정화를 사용합니다. Apply는 적용 전 백업과 함께 로컬 저장하고 Cancel은 이전 값을 유지합니다. 마지막 그리기 종류·세션 장치/접촉 ID와 Windows 펜 연결 상태를 표시합니다.

Pen input backend의 기본값은 Windows Pointer입니다. Wintab은 컴퓨터에 설치된 드라이버가 필요하며 초기화 실패 시 Pointer, 이후 마우스로 복귀합니다. Mouse는 펜 전용 경로를 끕니다. 요청한 방식과 실제 활성 방식·실패 이유를 표시하며 Retry current backend로 다시 연결할 수 있습니다. 전환/재연결은 현재 획을 한 번 종료하고 이전 입력을 비웁니다. 전환하거나 포커스가 돌아온 뒤 펜을 한 번 들어 올려 주세요. 드라이버를 내려받거나 설치하지 않습니다. 실제 장치의 필압·기울기·좌표 검증은 별도로 남아 있습니다.

처음 누른 장치가 놓거나 취소할 때까지 획을 소유합니다. 소유 중 다른 장치의 입력은 해당 획에 넣지 않으며 종료 후 새로 눌러야 그립니다. 마우스 ID 0은 창 라이브러리가 제공하는 통합 입력입니다. 종류 정보가 없는 터치는 압력 유무로 펜으로 추정하지 않으며 그리지 않습니다. 펜 ID는 세션 동안만 유효합니다. 연결 성공은 실제 펜 시험 완료를 의미하지 않습니다.

Pen click, coordinates and buttons에서 문서 그리기에 적용할 클릭 필압(기본 꺼짐), Absolute/Relative 좌표, 상대 이동 속도를 설정합니다. 켠 임계값 이상이면 획을 시작하고 아래로 내려가면 종료합니다. 필압이 없으면 1을 사용하며 기본 꺼짐에서는 장치의 0압력을 그대로 유지합니다. 상대 좌표는 처음 캔버스 중심에서 시작하고 접촉 중 좌표 차이에 속도를 곱합니다. 들어 올렸다 다시 누르면 마지막 그리기 위치를 이어 쓰며 포커스 상실·설정/백엔드 변경에서는 초기화됩니다. 앱의 그리기 커서만 이동하고 운영체제 커서는 바꾸지 않습니다.

보고된 논리 버튼 1–32에 기본값 유지·현재 브러시·지우개·그리기 무시를 배정할 수 있습니다. 번호는 백엔드/드라이버에 따라 다를 수 있습니다. Pointer의 배럴 버튼은 1번이며 Wintab은 식별된 펜촉 버튼을 번호 비트에서 제외합니다. 번호를 지원하지 않으면 기존 동작을 유지하고 마지막 보고 비트를 표시합니다. 동시 버튼은 무시→지우개→현재 브러시 순으로 우선하며 시작한 획의 동작은 끝날 때까지 고정합니다. 그리기 무시로 시작한 접촉은 버튼을 놓아도 펜을 들기 전까지 획을 만들지 않습니다. 실제 장치 검증은 별도입니다.

Tablet area, target and touch offset에서 장치가 보고한 전체 태블릿 영역의 0–1 비율 중 사용할 사각형을 지정하고 Active canvas 또는 모니터에 매핑합니다. 왼쪽<오른쪽, 위<아래여야 합니다. 창/보기/배율이 바뀌면 기존 획을 끝내고 펜을 다시 눌러야 합니다. 상대 좌표와 속도는 영역 매핑 뒤에 적용됩니다. 모니터는 물리 위치·크기로 보존하며 분리하거나 배치를 바꾸면 다시 선택해야 합니다. 장치가 영역 좌표를 제공하지 않으면 그리기를 취소하고 이유를 표시합니다. 화면 위치로 장치 좌표를 추정하지 않습니다.

미리보기 사각형 위에서 마우스를 움직이면 가상 태블릿 좌표의 변환 결과를 확인할 수 있습니다. 이 시험은 문서를 바꾸거나 실제 펜으로 기록하지 않습니다. Virtual input replay의 Tablet area sample도 독립 시험 문서에서 실행할 수 있습니다. Touch X/Y offset은 물리 픽셀 기준이며 터치에만 적용되고 손가락 그리기를 켜지는 않습니다. 실제 태블릿 영역·화면 매핑/터치 드라이버 검증은 대기 상태입니다.

## pressure | 브러시 필압 연결 | 필압 크기 불투명도 독립 펜 마우스 프리셋

Brush pressure에서 펜·연필·지우개·워시 각각의 Pressure controls size와 Pressure controls opacity를 독립 선택합니다. 기본값은 크기 켬/불투명도 끔입니다. 연결된 축은 정규화 필압 0–1을 곱하고 연결하지 않은 축은 유지합니다. 크기 연결에서 0압력은 자국을 남기지 않으며 불투명도 연결만 켠 경우 굵기는 변하지 않습니다. 마우스와 필압 정보가 없는 장치는 1로 동작합니다.

획 도중 설정을 바꾸어도 시작값으로 끝냅니다. 불투명도 연결은 겹친 팁의 최대 기여도를 사용하여 같은 획이 왕복해도 압력보다 진해지지 않습니다. 지우개는 같은 비율로 알파를 제거합니다. 새 획은 기존 픽셀 위에 새로 합성합니다. 위치 보정과는 별도 계산입니다.

Apply/Cancel과 적용 전 백업을 제공하고 도구별 필압 연결을 로컬 JSON 프리셋으로 저장/불러옵니다. 기존 파일을 바꾸려면 Replace an existing preset을 명시적으로 선택합니다. 잘못된 버전·손상·64KiB 초과 프리셋은 임시 설정을 유지합니다. 실제 펜/드라이버의 압력 값 정확도 검증은 별도 대기입니다.

필압 입력 범위 Minimum/Maximum은 그리기 장치가 보고한 값 중 사용할 구간입니다. 최소값 아래는 0, 최대값 위는 1로 제한한 뒤 곡선을 적용합니다. 범위 안의 25%/50%/75%에서 출력 값을 편집하며 양끝은 0과 1로 고정합니다. 수평 구간은 허용하지만 감소하는 곡선·최소=최대·역전 범위는 이유를 표시하고 Apply/프리셋 저장을 막습니다. 그래프는 원시 입력 필압에 대한 최종 출력을 보여줍니다. 변경한 범위/곡선은 이후 시작하는 획에만 적용하고 기존 픽셀과 그림 이력은 바꾸지 않습니다.

마우스·펜 입력 설정에서 지원되는 기울기를 팁 각도에 연결하고, 펜 지우개 또는 보고된 버튼을 누른 채 시작한 획을 지우개로 그리도록 선택할 수 있습니다. 기울기는 보기 회전·반전을 반영한 문서 방향으로 변환합니다. 속성이 없으면 기본 각도와 선택 도구를 사용하고, 비유한 기울기는 무시하며 축별 ±90° 범위로 제한합니다. 펜 지우개/버튼 동작은 현재 브러시 모양·필압 설정을 유지하고 알파를 지웁니다. 획 도중 펜 방향/버튼 상태가 바뀌어도 지우개 여부는 누를 때의 값으로 끝냅니다.

버튼 옵션은 기본 꺼짐입니다. 입력 제공자가 펜 촉 자체를 버튼으로 포함할 수 있으므로 개별 버튼 번호를 임의로 가정하지 않고 보고된 버튼 중 하나가 눌린 상태에 적용합니다. 입력 설정에서 마지막으로 보고된 속성을 확인할 수 있으며 None은 해당 속성 미제공입니다. 버튼별 세부 배정은 별도 기능에 있습니다. 실제 펜 기울기·지우개·버튼 시험은 대기입니다.

Windows에서 펜 제공자가 연결되어 있으면 OS가 펜에서 만든 것으로 표시한 호환 마우스 입력은 문서 획에 다시 넣지 않습니다. 메뉴/버튼에는 기존 입력을 유지합니다. 실제 마우스는 펜과 같은 위치에 곧바로 눌러도 시간·거리로 제거하지 않습니다. 펜 제공자가 연결되지 않으면 호환 마우스를 기본 마우스 입력으로 사용할 수 있습니다. 입력 누락/큐 초과는 미완성 획을 버리고 새로 누를 때 다시 시작합니다. 장치가 출처를 표시하지 않은 이벤트를 임의로 추정해 제거하지 않습니다.

필압이 없는 마우스/펜은 압력 1로 그립니다. 기울기가 없으면 추가 회전 0을 사용합니다. 장치가 실제로 0압력을 보고한 경우와 속성이 없는 경우는 구분하며, 실제 0은 선택한 필압 연결 규칙대로 처리합니다. 속도나 이벤트 간격을 압력 누락의 대체값으로 추정하지 않습니다. 마우스 가상 필압/속도 반응은 별도 기능의 명시적 설정이며 기본 입력은 일정합니다.

## input-replay | 가상 입력 자동 검증 | 필압 시간 재생 기록 시험 로컬 JSON

Virtual input replay는 사용자 문서와 분리된 시험 그림에서 같은 입력·브러시·이력 경로를 실행합니다. 기본 기록은 압력0→최대 급변→반압력→해제를 포함합니다. Missing end는 미완성 획 취소를, Reverse time은 시간 역전 거부를 시험합니다. Use current brush settings in record로 현재 도구·색·모양·안정화·필압/장치 설정을 기록에 복사할 수 있습니다.

Run virtual record는 백그라운드에서 수행하고 Cancel replay 또는 창 닫기로 취소합니다. 결과에는 획 수·RGBA 지문·종료 누락 취소·Undo/Redo 검증과 그림 미리보기를 표시합니다. PASS는 예상 획 수·기록에 선택적으로 지정한 픽셀 지문·실행 취소/재실행이 일치한다는 뜻입니다. 예상 픽셀 지문이 없으면 화면에 그 사실을 표시합니다. 실제 펜/드라이버 검증 완료라는 뜻이 아닙니다.

기록/결과는 지정한 로컬 JSON 경로로 저장하며 기존 파일 교체는 명시적으로 선택합니다. 결과는 .result.json 사본에 입력 전체를 포함하므로 다시 Load input record로 읽고 재생할 수 있습니다. 원래 저장된 PASS 값은 새 시험 결과로 믿지 않습니다. 기록은 문서 좌표와 마이크로초 시간, 장치 종류/ID·접촉·압력·속성·출처를 보존합니다. 시간 역전·손상·범위 밖·과도한 기록은 실행 전에 거부합니다. 시험 범위는 1–256px 그림/팁·4096개 이벤트·512개 시간값·100번 시작·2MiB이며 가상 시간은 실제 대기 시간이 아닙니다. 기존 그림·설정·클립보드를 바꾸지 않습니다.

## acquisition | 로컬 스캐너·카메라 | 스캔 촬영 장치 WIA 카메라 가져오기 원본 취소

Scanner / camera에서 Refresh local devices를 눌러 Windows가 제공하는 로컬 WIA 스캐너/카메라와 영상 카메라 목록을 조회합니다. 장치를 고르고 Acquire one image를 누르면 한 이미지를 취득합니다. WIA는 Windows/드라이버의 스캔 창을 표시할 수 있습니다. 카메라는 선택한 영상 장치만 사용하고 마이크는 사용하지 않습니다. 장치 없음·분리·사용 중·Windows 접근 차단은 이유를 표시합니다. 장치를 자동 선택해 촬영하거나 드라이버를 내려받지 않습니다.

미리보기를 확인한 뒤 Use as new document로 독립 그림을 만들거나 Place as layer로 배치 미리보기를 열어 레이어를 확정합니다. 확정한 레이어는 Undo 한 번으로 되돌립니다. ## touch | 터치·제스처·손바닥 방지 | 두 손가락 이동 확대 회전 손가락 그리기 펜 우선

Mouse and pen input의 Touch and palm policy에서 두 손가락 이동·확대·회전과 손가락 그리기, OS 손바닥 표식 무시를 설정합니다. 기본값은 두 손가락 제스처 켬, 한 손가락 그리기 끔, 손바닥 표식 무시 켬입니다. 장치가 명시적으로 제공한 터치만 사용하고 압력이나 마우스 위치로 종류를 추정하지 않습니다.

같은 장치의 두 손가락을 캔버스에서 시작하면 중점을 따라 이동하고 간격으로 확대하며 방향으로 회전합니다. 제스처는 보기만 바꾸며 그림 픽셀·변경 표시·Undo 이력은 바꾸지 않습니다. 세 손가락 이상이면 잠시 멈추고 두 손가락으로 돌아올 때 기준을 다시 잡습니다. 다른 패널·입력 창에서 시작한 접촉을 캔버스 제스처에 섞지 않습니다.

한 손가락 그리기를 켜면 현재 브러시로 그립니다. 두 번째 손가락이 닿으면 아직 확정하지 않은 획을 취소하고 제스처로 바꿉니다. 다시 한 손가락이 되어도 누른 채 자동으로 그리지 않으며 모두 들고 새로 눌러야 합니다. 펜이 닿아 있으면 터치를 막고 진행 중인 손가락 획도 취소합니다. 손바닥으로 표시된 접촉은 기본적으로 무시합니다. 포커스 상실은 미확정 획과 접촉 상태를 취소하며 보기/설정이 바뀌어도 들어 올린 뒤 새로 시작합니다. 취소되지 않은 손가락 획은 한 번의 Undo로 되돌립니다.

Windows 직접 터치 메시지를 읽는 어댑터와 가상 다중 접촉 검사를 제공하며 실제 터치/펜 장치 검증은 대기 상태입니다. 지원 여부를 보고하지 않는 입력을 손가락으로 바꾸지 않습니다. 터치의 원래 UI 클릭은 계속 전달하며 문서용 호환 마우스 중복만 제외합니다.

Add default dial bindings는 회전에 브러시 크기 증감, 클릭에 다음 도구를 배정합니다. 각 명령을 확대/축소·실행 취소·도구 전환 등으로 바꿀 수 있습니다. OS 다이얼 메뉴에서 Drawer를 선택해야 앱이 회전/클릭을 받으며 길게 누르기는 OS 메뉴를 엽니다. 민감도는 명령당 1~180도, 기본 15도입니다. 설정 적용/취소·초기화·백업·로컬 가져오기/내보내기를 지원합니다.

Windows가 노출하는 다이얼만 이 어댑터로 처리합니다. 전용 컨트롤러가 키보드나 추가 마우스 버튼을 보내면 기존 단축키/Extra1·Extra2 배정을 사용합니다. 같은 명령을 키보드에 배정해 장치 없이 검증할 수 있습니다. 초기화 상태와 오류는 명령 설정 창에 표시하며 Retry Windows dial adapter로 다시 연결합니다. 지원하지 않는 원시 제스처는 추정하지 않습니다. 실제 컨트롤러/드라이버 시험은 대기 상태입니다.


## precision | 키보드 이동·직선·도구값 | 방향키 Shift 1픽셀 10픽셀 직선 크기 농도 스포이트 잠금

브러시 패널의 Keyboard editing에서 방향키 대상을 Selection boundary(선택 테두리), Selected pixels(선택 픽셀), Raster layer(현재 래스터 층) 중 고릅니다. 상태줄에 현재 대상과 도구가 표시됩니다. 방향키는 문서 좌표 1픽셀, Shift+방향키는 10픽셀 이동합니다. 누른 동안의 반복 입력은 실행 취소 한 번으로 묶으며 놓기·대상/명령 변경·포커스 상실에서 끝냅니다. 선택 픽셀 이동은 선택도 함께 옮기며 캔버스 밖 내용도 보존합니다. 빈 선택·잠금 층·메모리/크기 한도는 이유를 표시하고 이동하지 않습니다. 층 속성의 Lock raster layer는 그림 파일에도 저장합니다.

L을 누른 뒤 캔버스를 클릭하면 같은 문서·층·브러시의 마지막 확정 획 끝점부터 직선을 잇습니다. 이전 획이 없으면 시작 획을 먼저 그리도록 안내합니다. 직선 하나는 실행 취소 한 번이고 Escape는 대기를 취소합니다. 끝점은 문서를 닫으면 지워지는 세션 정보입니다.

기본 단축키 [ / ]는 크기 감소/증가(현재 크기의 10%, 최소 0.1픽셀), Shift+[ / Shift+]는 농도 10%p 감소/증가, 1~9는 농도 10~90%, 0은 100%입니다. Keyboard editing의 Brush opacity에서도 조절합니다. 크기와 농도는 활성 브러시별로 보존하며 그림 이력에 들어가지 않습니다. Ctrl을 누른 숫자/슬라이더 드래그는 1/10 속도로 조절하고 슬라이더 방향키 증분도 줄어듭니다.

M은 방향키 이동 도구, I는 합성 그림 색을 고르는 스포이트입니다. 이 도구는 크기·농도·직선 명령을 지원하지 않으며 이유를 표시합니다. B/N/E/W 또는 브러시 선택으로 그리기로 돌아옵니다. 입력란·IME·메뉴·대화상자에는 그림 단축키가 적용되지 않습니다. 기존에 저장한 단축키는 유지하며 Input and commands에서 새 명령을 배정하거나 기본값 초안을 불러올 수 있습니다.


## mouse-pressure | 마우스 가상 필압과 획 확정 | 시작 끝 필압 곡선 거리 속도 seed 시드 혼색 번짐 분사 수채 예측 재계산

Tool input behavior → Mouse virtual pressure에서 브러시별로 시작/끝 길이와 곡선을 설정합니다. 길이는 안정화된 문서 경로의 픽셀 단위이며 겹친 시작/끝 구간은 두 곡선을 곱합니다. 길이 0인 점은 필압 1을 사용합니다. 가상 필압이 꺼지면 거리 필압은 1이고, 속도 반응을 별도로 켜면 빠른 움직임의 계수를 곱합니다. 측정 시간이 없거나 증가하지 않으면 속도 계수는 1입니다. 크기/농도 중 실제 바뀌는 대상은 기존 Pressure mapping 설정을 따릅니다.

Pattern seed와 동작 선택은 거리 필압과 독립적이며 0은 기본 패턴입니다.

그리는 동안 결과는 임시 미리보기입니다. 놓으면 전체 길이의 끝부분 필압을 확정해 원래 그림에서 다시 계산합니다. 미리보기에 덧칠하지 않고 수채 확산도 한 번만 처리합니다. 실제 놓기 시각 뒤의 임시 분사 시간은 확정에서 제외합니다. 픽셀과 설정·시드는 실행 취소 한 번으로 함께 복원됩니다. 예측 표시는 확정 입력에 포함되지 않습니다. Escape, 포커스/장치 손실, 계산 취소나 자원 한도 실패는 미확정 결과를 모두 버립니다.

가상 입력 검증 창의 Mouse start/end pressure 샘플은 시간·설정·시드를 포함한 로컬 JSON 기록을 재생합니다. 기록과 결과는 로컬 파일로 저장하며 실제 장치 시험을 뜻하지 않습니다. 시간 기반 분사는 누르고 있는 획이 필요하므로 직선 잇기 명령 대신 드래그합니다. 설정은 적용/취소·초기화·백업·작업공간 저장을 지원합니다.

## brush-dynamics | 팁 방향과 크기 동역학 | 필압 기울기 속도 곡선 방향 회전 간격 무작위 크기

도구 입력 → Tip direction, size dynamics and spacing에서 브러시별로 설정한다. Fixed는 팁 기본 각도+고정 오프셋, Stroke direction은 문서 경로 진행 방향, Pen direction은 문서 좌표로 변환된 펜 방향이다. 길이0/기울기 없음은 저장된 기본 각도를 사용한다. Scatter overall direction은 산포 전체 방향, Toward scatter center는 각 입자가 중심을 향하는 방향이다. 팁 기본 각도는 추가 오프셋이다. 산포 타원의 회전은 별도로 지정한다.

필압0~1·수직에서 기울어진 각도0~90°·문서 속도px/s마다 입력 최솟값/최댓값,5개 곡선 점, 출력 배율 범위, 입력 누락 배율을 편집한다. 내림/올림 곡선도 가능하다. 활성 배율들을 곱한 뒤 시드 기반 무작위 크기 배율을 곱하고 최소/최대px 범위로 제한한다. 기존 필압/최소 출력도 먼저 적용되며 시작끝 기하는 마지막에 적용하므로 크기 하한이 있어도 획 끝은0이 될 수 있다. 범위가 잘못되면 적용을 막고 정상 설정을 유지한다.

설정/로컬 프리셋과 획의 고정 스타일/결과를 저장한다. 획 도중 설정을 바꿔도 시작 설정을 유지하고 취소는 원본을 보존한다. 물리 펜 검증은 별도로 대기한다.

## brush-variation | 색상 변동과 두 팁 합성 | HSV 색상 채도 명도 시드 dual 이중 브러시 마스크

설정은 누르기 때 고정하고 시드/프리셋/문서의 획 스타일과 결과를 보존한다. 취소는 원본 유지, 정상 놓기는 한 번의 실행 취소다. 색 변동은 주색 안료 공급에 적용하며 무색 번짐은 기존 안료만 운반한다. 전용 Pixel pen에 부드러운 두 번째 마스크를 명시적으로 결합하면 중간 알파를 사용할 수 있다.

## clone-stamp | 복제 도장과 원점 | clone stamp source origin 복사 복제 원본 오프셋

## local-materials | 로컬 이미지 팁·질감 등록 | 소재 PNG JPEG TIFF 알파 농담 브러시 라이브러리

도구 입력 → Local image materials에서 파일·이름·팁/질감을 골라 Register image locally를 누른다. PNG/JPEG/단일 페이지 TIFF를 지원하며 저장된 방향과 ICC를 반영한 sRGB 이미지에서 마스크를 만든다. 크기는 각 변1~512px, 등록32개/마스크 합계2MiB, 목록 파일8MiB와 읽기 작업 메모리32MiB로 제한한다. 손상·크기 초과·완전 투명·빈 팁·같은 이름은 설명하고 기존 소재를 보존한다.

Use on [도구]는 현재 입력 임시본에 팁/질감을 선택한다. 여러 팁 목록과 Brush texture에서도 등록 소재를 고를 수 있다. 등록/삭제는 즉시 로컬 목록에 저장되고, 그리기 설정 선택은 적용/취소를 따른다. 폴더/레이어의 종이 효과는 기존 내장 질감을 사용한다. 등록 자체는 열린 그림·변경 표시·실행 취소 이력을 바꾸지 않는다.

획과 가상 재생은 시작 때 소재 목록을 고정한다. 삭제된 팁은 현재 도구 팁, 삭제된 질감은 무효과로 대체하며 저장된 번호는 보존한다. 기존 문서의 그려진 픽셀은 자체 문서에 남는다. 향후 그리기/프리셋의 소재 참조는 사용자 데이터 materials/library.json이 필요하며 원래 가져온 이미지 파일은 다시 읽지 않는다. 목록이 손상되거나 외부에서 바뀌면 덮어쓰지 않고 다시 읽기를 요구한다. 클라우드/계정/다운로드를 사용하지 않는다.

## brush-composite | 브러시 합성과 폴더 통과 | 지우기 뒤쪽 알파 대체 농도 비교 확률 혼색 필압

도구 입력 → 안료 설정에서 Normal, Erase, Dissolve, Background, Replace alpha, Black burn, White burn, Compare density, Erase (compare)를 선택한다. Erase는 알파 감소, Background는 기존 픽셀 뒤 칠하기, Replace alpha는 기존 RGB를 유지한 알파 대체다. Compare density는 최종 잉크 밀도가 기존 알파보다 클 때만 교체하고 Erase(compare)는 같거나 클 때 지운다. Black/White burn은 색을 어둡게/밝게 강조하는 별도 규칙이다. 원본 앱과 같은 수식을 사용한다는 뜻은 아니다.

특수 합성은 한 획에서 coverage 최대값을 쓰고 필압 농도·전체 농도·선택·질감을 한 번 반영한다. Dissolve는 최종 농도를 픽셀 점유 확률로 사용하며 저장한 시드/좌표로 결과를 고정한다. 특수 합성의 수채/시간 효과 후처리 확산은 생략한다. 알파 잠금은 원래 알파를 유지한다. 복제 도장과 기존 지우개의 역할은 기존 규칙을 따른다.

Rendering quality의 High는 기하 경계를 픽셀 내 네 위치에서 평균한다. 기존 중심 계산인 Normal과 선택할 수 있고 Running color의 혼색 품질과 별도로 저장된다. 픽셀 펜은 두 품질 모두 정확한 픽셀 격자를 유지한다.

Pressure controls pigment pickup에서 필압 혼색을 켜고5점 곡선을 정하면 보정된 압력이 안료 pickup 혼색량에 곱해진다. 끄면 기존 혼색량을 그대로 사용한다. 크기/농도와 분리되며 기존 품질·혼색 공간·도구별 선/필압 보정도 함께 각 브러시에 저장된다. 프리셋을 바꾸어도 다른 브러시 설정은 바뀌지 않는다.

Layer and folder paper에서 레이어/격리 폴더의 합성 모드를 고를 수 있다. Through는 자식을 외부 아래층에 직접 합성하며, 끈 격리 폴더는 자식을 먼저 투명 바탕에서 합친다. Through를 켜면 현재 임시본의 폴더 자체 효과를 초기화하며 Apply/Cancel과 문서 실행 취소를 따른다. 외부 바탕 의존 합성이 있는 부분트리 굽기와 PSD Rendered layers는 거절하고, 자체 문서 보존 또는 PSD Rendered image를 사용하도록 안내한다.

## tool-slots

농담·섬유 팁은 Local image materials에서 등록한다. 회색값/알파 밀도와 기존 어두운색 밀도를 선택하고, Owned fibre tip editor에서 위치·굵기·길이·방향·밀도를 편집할 수 있다.

다른 PC에는 Export portable tools + materials로 만든 새 Drawer-tool-bundle 폴더 전체를 옮긴다. Import portable tool bundle은 모든 파일을 검증하고 새 ID로 등록한다. 소재는 즉시 저장되고 슬롯은 Apply로 확정한다. 슬롯 삭제/Cancel은 등록 소재를 지우지 않는다. 기존 폴더에는 내보낼 수 없으므로 다른 빈 부모 위치를 고른다.


## brush-behavior

Tool input → Scatter, ribbon and repeating decorations에서 도구별 화면 픽셀 크기·최소1문서픽셀·간격 농도 보정·연속 분사·고정 산포점을 선택한다. 기본값은 모두끔이다. 화면 크기는 획 시작 배율에서 환산하며 이미 그린 획은 바꾸지 않는다.

연속 분사는 버튼을 누른 동안 정지한 커서에도1–200회/초로 그린다. 놓으면 정지하고 한 번의 그림 Undo로 취소할 수 있다. Esc는 진행 중 세션을 취소한다. 포커스 상실도 기본적으로 취소하며, 수채 경계가 켜진 유효 수채 획은 경계 후처리와 함께 완료한다. 기존 Mouse spray와 함께 선택하면 Mouse spray의 입자 제어를 사용한다. 팝업 시험 영역에서도 시간 분사를 확인할 수 있다.

고정 산포점은 같은 시드·팁·입자 위치를 유지한다. 간격 농도 보정은 기준0.15에 맞춰 누적 농도를 보정하며 팁 경계나 넓은 간격의 빈 공간까지 같게 만들지는 않는다.


## brush-color

안료 설정에서 문서 RGB·CIELAB D65·Oklab 혼색을 선택하고 Lightness correction으로 입력색의 밝기에 맞추는 강도를 조절한다. 기본 강도0은 기존 결과를 유지한다.

색 변화/보조 팁 설정의 Combine secondary RGB and alpha를 켜면 별도 보조 RGBA를 사용한다. 끄면 주 잉크와 보조 마스크로 그린다. 14개 합성 모드와 기존 Difference를 선택할 수 있다. Height는 두 높이의 선형 평균, Apply RGB value는 보조색의 휘도를 밀도에 반영한다.

Link secondary size를 끄면 주 브러시 크기를 바꿔도 보조 지름을 문서 픽셀 단위로 유지한다. 지우개·복제·픽셀 덮어쓰기는 자신의 쓰기 규칙과 보조 coverage를 사용한다. 모든 설정은 프리셋/사용자 도구에 저장되고 한 획의 두 팁·색 변화는 함께 실행 취소된다.


## tip-texture

Tool input의 각 팁 슬롯에서 좌우/상하 반전과 Override inherited brush texture를 설정한다. 여러 팁이 꺼져 있을 때는 슬롯1이 현재 팁에 적용된다. 보조 브러시에도 별도 반전·질감 설정이 있다. 팁을 이동하면 질감 설정도 함께 이동한다.

질감의 배율·각도·반전·밝기·대비와 문서/팁 좌표,10개 밀도 합성 모드를 선택할 수 있다. Outline은 질감 경계, Height는 밀도와 질감 높이의 평균을 사용한다. 질감 재정의에서 No texture를 고르면 상속된 질감을 끈다. 새 재정의를 사용하면 팁마다 질감을 적용한 뒤 팁들을 합친다.

Watercolor의 Darken the finished watercolor edge는 획을 놓을 때 가장자리를 한 번 어둡게 하고 알파를 유지한다. 이 옵션이 켜진 유효 수채 획은 포커스를 잃어도 같은 후처리로 완료한다. Esc는 전체 획을 취소한다. 후처리까지 한 번의 그림 Undo에 포함된다. 이 제어는 Normal 합성의 수채에 적용된다.


## line-references | 참조 선·벡터층·여러 층 지우기 | 경계 채색 자석 교차점 벡터 erase magnet

Keyboard editing의 Line references and vector layers에서 벡터층과 경로를 만들고 Boundary/magnet, Intersections, Erase 대상을 따로 고른다. Apply는 설정/벡터 초안을 저장하고 Cancel/Esc는 버린다. 잠긴 참조는 읽을 수 있고 숨긴 참조는 무시한다.

Restrict brush coloring은 획 시작점이 속한 닫힌 참조 영역 안으로 채색을 제한한다. Apply and pick fill point 또는 X,Y 직접 실행으로 선택한 래스터층을 전경색으로 채운다. 경계가 열려 있거나 시작점이 선 위면 적용하지 않는다. 자석 거리는 화면 배율과 독립인 문서px다.

Erase는 표시되고 잠기지 않은 선택 대상에만 적용한다. 래스터는 원형 반경, 벡터는 선택한 교차점 참조 사이의 경로 구간을 지운다. 대상 오류는 사전 목록에 표시하고 전체 명령을 취소한다. 벡터 지우기는 래스터 선택을 먼저 해제한다. 모든 영향층은 한 Undo로 복원된다. 위치 선택은 주 탭 캔버스 클릭, Esc/초점 상실 취소다. 설정과 편집 벡터는 .drawer에 저장한다.


## tonal-locks | 닷지·번과 도구 설정 잠금 | 밝기 톤 그림자 중간톤 하이라이트 프리셋 잠금 복원

로컬 프리셋/사용자 도구 편집기에서도 저장값을 잠글 수 있다. 잠긴 원본 덮어쓰기/초기화는 거부한다. 설정 잠금은 그림 실행 취소와 별개다.


## color-selector | 색상환·색상값과 색 이력 | RGB HSV HEX 색상환 스포이트 알파 색 이력

## color-modes | 주색·보조색·투명색 | 주색 보조색 투명색 지우기 색 교환 X C

## RGB/HSV/HSL and editable swatches

Choose RGB, HSV or HSL without changing the selected RGBA. Enable Preserve HSL hue/saturation to adjust only lightness; one drag retains the source color through black and white. Local swatches support size, automatic/fixed columns, scrolling, naming/replacing/deleting, drag before another swatch, and Ctrl-drag to copy. Use the panel’s Undo/Redo color table edit commands separately from drawing Undo. Escape, dropping outside, or releasing Ctrl during a copy cancels it. All values and layout are saved locally.

## Canvas references and screen color

Sampler and used colors offers composite reference/excluded layers and separate page/vector/animation switches. Exclusions win; current-layer RGB/RGBA still reads the raw layer. Canvas averages use alpha-weighted RGBA. Screen sampling reads displayed RGB only after an explicit click, keeps drawing alpha, and uses an arithmetic average. Select Hide app window to sample underneath it. Escape/right-click cancels; original window placement and focus are restored. If Windows declines focus restoration, an error keeps the prior color. No screenshots are saved or transmitted. Settings and recent colors stay local; drawing Undo is unchanged.

## View ICC and tone preview

Color proof and tone preview edits each canvas view or the separate display view independently. Preview draft changes display only; Save view preview settings keeps local values; Cancel/Escape restores the saved preview. Choose a local RGB/Gray/CMYK ICC with usable transforms in both directions. Preview/Save reloads the file. Missing or unsupported ICC displays an error and preserves document pixels.

Apply tone/levels to selected raster is a separate drawing command: it bakes only the curve/levels into the active selected layer and selection, preserves alpha and sRGB, and creates one drawing Undo. Activate the view being edited first. Its tone preview then resets to avoid applying the adjustment twice. ICC simulation stays view-only. The preview uses an 8-bit ICC gamut round trip; it does not promise calibrated monitor or print matching.

## Rectangle, lasso and page selections

Choose Rectangle select or Lasso select in Precision tools or Commands. Drag and release on the canvas; Escape/focus loss cancels the preview. Deselect removes restrictions, Invert complements the current page mask, and Reselect restores this page’s previous selection. Edges use 4×4 coverage. Selections use drawing Undo and never change raster/cell pixels by themselves.

Page selections saves/replaces named masks (16 per page), loads/removes them, and duplicates a page as a separate document with independent selection identity. Cells and frames share their page’s selection. Saved/previous masks reopen with the document. Out-of-range or oversized shapes are rejected with the previous selection preserved.

## Painting through selections

Raster drawing and erasing use the page selection’s coverage, including soft edges. Empty selections produce no pixel edit or drawing Undo. PixelPen RGBA overwrite first determines replacement RGBA from brush controls, then blends it with the original using selection strength; soft selections preserve the underlying RGBA instead of only lowering new alpha. Undo/Redo and document reopening retain pixels and the mask. Independent test/mixing buffers keep their own selection state.
