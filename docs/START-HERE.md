# Drawer 실행·설치·제거

Windows 64비트에서 `Drawer.exe`를 실행한다. 기본 도구와 글꼴을 실행 파일에 포함해 별도 소재 다운로드가 필요하지 않다.

사용자 계정에 설치하려면 배포 폴더에서 PowerShell로 `./Install.ps1`을 실행한다. 기본 설치 위치는 사용자 LocalAppData의 `Programs/Drawer`이며 관리자 권한을 요구하지 않는다.

설정은 사용자 LocalAppData의 `Drawer/settings`, 사용자 소재는 `Drawer/materials`에 보관한다. 문서는 사용자가 선택한 위치에 보관한다.

`New canvas`로 새 그림을 만들고 `Open…`으로 로컬 `.drawer`를 여러 개 연다. `Image as new document…`는 PNG/JPEG/TIFF를 미리 보고 독립 새 그림으로 가져온다. TIFF는 페이지를 먼저 선택하고 방향 메타데이터 적용을 선택한다. 미리보기와 생성한 그림의 방향·색이 같다. ICC는 sRGB로 변환하며 비트 깊이는 RGBA8로 변환한다. 지원 범위와 한도는 [이미지 가져오기](process/image-import.md)에 있다.

`New from clipboard`는 이미지 클립보드의 크기·투명도로 독립 새 그림을 만든다. 빈 클립보드나 읽기 실패는 기존 그림을 유지한다. 위쪽 탭으로 전환하며 같은 이름의 파일은 탭에 마우스를 올려 경로를 확인한다. `Save`는 편집 가능한 `.drawer`로 저장한다. `Save as…`는 새 경로에 저장하고 이후 저장 위치를 그 경로로 변경한다. 저장 대화상자나 덮어쓰기 확인에서 취소하면 파일과 저장 위치를 유지한다.

`Recent files`는 최근 성공한 열기·이미지 가져오기·저장 경로 20개를 로컬에 보존한다. 이미지 경로는 다시 미리 보고 독립 그림으로 가져온다. 누락 파일은 표시하며 실패해도 목록과 열린 그림을 유지한다. 목록 전용 Undo/Redo·초기화·직전본 복원을 제공한다.

`Duplicate view`는 같은 그림을 다른 배율·각도로 보는 탭을 추가한다. 도구와 실행 취소 이력은 그림별로 공유하며 보기 위치는 탭마다 유지한다. 탭의 `×`로 닫는다. 미저장 그림의 마지막 탭을 닫을 때 저장·버리기·취소를 선택한다. 종료 도중 취소하면 열린 그림을 유지한다.

`Display view`에서 사용 가능한 모니터를 선택하고 `Show display view`를 누르면 도구 패널 없는 별도 캔버스 창을 연다. 현재 문서의 갱신을 공유하며 `Sync zoom and center with editor`를 끄면 그 창의 배율·중심·각도를 독립적으로 유지한다. 독립 보기는 휠 확대와 가운데/Space 드래그 이동을 제공한다. F11은 전체화면 전환, Escape는 창 모드 복귀다. 창을 닫아도 그림은 편집기에 남는다. 모니터 분리 시 사용 가능한 화면으로 회수하고 선호 모니터 재연결 시 돌아간다. 보기 설정 Undo/Redo·초기화·직전본 복원은 그림 실행 취소와 별개다.

새 그림과 크기 창은 px/mm/inch 단위와 비율 잠금을 제공한다. `Canvas presets`에서 크기 선택·저장·삭제·되돌리기·로컬 묶음 이동을 한다. `Keep pixel count when changing DPI`는 DPI만 바꾸며, 해제하면 물리 크기를 유지하도록 재샘플링한다. `Adjust each edge`의 양수는 투명 여백을 추가하고 음수는 해당 변의 픽셀을 제거한다.

`Resample…`은 픽셀 수와 그림 배율을 변경한다. `DPI…`는 픽셀을 유지하고 인쇄 크기만 변경한다. `Canvas size…`는 앵커를 기준으로 여백과 경계를 변경한다. `Crop…`은 왼쪽·위·가로·세로로 지정한 영역만 남긴다. 경계 밖 픽셀을 지울 때는 노란 윤곽과 제거 안내를 확인하고 체크한 뒤 `Apply`를 누른다. `Cancel`/Escape는 변경하지 않으며 `Undo` 한 번으로 확정 전 상태를 복원한다.

보기 도구의 `Mirror`는 화면만 좌우로 뒤집는다. `Image:` 줄의 반전·90도 회전은 그림 데이터 자체를 변경하며 `Undo`로 되돌린다. `Export PNG…`는 현재 크기의 RGBA8 합성 이미지를 별도 파일로 저장하고 편집 문서의 저장 위치·변경 표시를 유지한다. 현재 PNG 출력은 색상 프로필·DPI 메타데이터를 기록하지 않는다.

왼쪽 `Navigator`는 전체 그림과 현재 보이는 영역을 표시한다. 미리보기를 클릭하거나 드래그하면 해당 위치로 보기를 이동한다. 회전·Mirror·확대 상태를 유지하며 그림 데이터는 변경하지 않는다.

`References`로 참고 창을 연다. PNG나 이미지 클립보드를 추가하고 목록/Previous/Next로 전환한다. 휠로 확대하고 가운데 버튼 또는 Space+드래그로 이동하며 각도를 조절한다. `Pick color`로 클릭해서 색을 읽거나 `Auto pick`을 켠다. `Color ring`은 커서 옆에 투명도를 포함한 색을 보여준다.

`Open as new drawing`은 독립 새 문서를 만든다. `Remove reference`는 원본을 삭제하지 않는다. 참고 설정은 자동 저장하며 설정 Undo/Redo·직전 저장본 복원·초기화를 제공한다. `Save set…`과 `Load set…`으로 복사본을 포함한 참고 묶음을 다른 컴퓨터로 옮길 수 있다.

`Canvas aids`에서 픽셀/mm/inch 눈금, 격자·가이드 표시를 선택한다. 격자의 간격/원점은 `Apply grid`로 적용하고 가이드 위치를 입력해 추가한다. 이 편집은 문서에 저장되며 `Undo`로 복원한다. 인쇄 크기를 보려면 기준선의 실측 mm를 입력해 화면을 보정한 뒤 `Show print size`를 누른다. 실제 물리 크기는 측정 정확도에 의존하며 모니터를 바꾸면 다시 보정한다.

제거하려면 설치 폴더의 `./Uninstall.ps1`을 실행한다. 설치 기록에 있는 프로그램 파일만 제거하며 사용자 문서·소재·설정과 추가 파일을 보존한다. 재설치도 이 데이터를 삭제하지 않는다.

`Paste image layer…`는 이미지 클립보드를 새 레이어의 미리보기로 연다. 처음에는 중앙이며 미리보기를 드래그하거나 Left/Top을 입력한다. 원위치 정보가 있으면 `Original position`을 선택할 수 있다. `Place layer`로 확정해야 문서에 추가되고 Undo 한 번으로 제거한다. 취소는 원래 그림을 유지한다. `Copy top raster layer`는 최상위 래스터의 전체 픽셀과 앱 원위치 정보를 복사한다. 앱 전용 원위치 정보가 없는 외부 이미지는 중앙 배치를 제공한다. 캔버스 밖 픽셀도 자체 문서에 보존한다.

`Image quality`에서 보기 보간을 선택한다. 최근접은 픽셀 경계를 유지하고 양선형/쌍삼차는 부드러운 확대, 평균색은 축소 영역의 정확한 평균, 오버샘플링은 여러 지점의 평균을 사용한다. 해상도 변경 창의 보간은 별도 선택이며 보기 품질은 저장 픽셀을 바꾸지 않는다. 설정 되돌리기·초기화·직전본 복원을 제공한다.

`Zoom region`을 켜고 캔버스 영역을 드래그하면 그 영역을 현재 창에 맞춘다. `100%`, `0°`, `Center`, `Reset view`는 각각 배율·각도·위치·전체를 복원한다. `Views`에서 현재 순서의 보기를 선택하며 Ctrl+PageUp/Down과 Alt+1~9도 사용할 수 있다. 보기 배치와 위치는 로컬 저장되고 `Restore saved views`/`Restore previous view layout`으로 재적용한다. 다시 열 파일이 없는 미저장 그림은 재시작 후 위치만으로 복원되지 않으며 이유를 표시한다.

`Navigator settings`에서 패널 표시·분리 창·폭/높이·최소/최대 폭을 설정한다. 분리 창은 제목을 드래그해 이동하고 모서리로 크기를 바꾼다. 고정 패널은 남은 공간 안에 표시한다. 녹색 실선은 현재 보기 경계이며 파란 반투명 채움/점선은 선택 영역이다. 호버 때만 보기 경계를 표시하도록 설정해도 키보드 포커스가 있으면 경계를 유지한다. 선택 윤곽을 숨겨도 채움은 유지한다. 선택 없음과 빈 선택은 다른 상태 문구를 표시한다. 패널 설정 되돌리기·초기화·직전본 복원을 제공한다.

`Local file actions`에서 마지막 저장본으로 되돌릴 수 있다. 저장하지 않은 그림에는 사용할 수 없으며 변경을 버린다는 확인 뒤 실행한다. `.drawer` 파일 연결은 Windows 기본 앱 설정에서 Drawer.exe를 선택한다.

`Movie` 메뉴는 로컬 영상으로 새 애니메이션을 만들거나 현재 애니메이션에 별도 트랙으로 삽입한다. 로컬 FFmpeg/FFprobe 7.1이 필요하며 찾지 못하면 `Choose local FFmpeg…`로 지정한다. 앱은 코덱을 내려받지 않는다. 시간 범위·FPS·크기·보간·오디오 선택 뒤 `Decode range and preview`에서 셀과 프레임 대응을 확인하고 확정한다. 오디오는 채널 수를 유지한 48 kHz PCM이다. 취소는 원래 그림을 유지하고 삽입은 Undo 한 번으로 제거한다. 문서 위의 Frame으로 확인 프레임을 바꾼다. 지원 변형과 자원 제한은 [로컬 영상 지원](process/movie-import.md)에 기록했다.

`Panels`에서 Brushes/Color/Layers/Timeline 표시를 선택하고 썸네일 없음·크기·전체 그림/내용 범위·체커, 도구 아이콘/이름/획 미리보기, 속성/명령막대 위치를 바꾼다. `Animation tracks only`는 타임라인 목록만 줄이며 숨겨진 선택과 그림을 유지한다. `Restore all panels`, 설정 Undo/Redo와 직전본 복원을 제공한다. 저장 Ctrl+S, 다른 이름 저장 Ctrl+Shift+S, 취소 Ctrl+Z, 다시 실행 Ctrl+Y 또는 Ctrl+Shift+Z, Pen/Pencil/Eraser/Wash는 B/N/E/W다. 문자 입력 중에는 도구 키가 실행되지 않는다.

화면 배율은 모니터에 맞춰 자동 조절한다. `Interface size`는 추가로 50–200% 크기를 선택하며 설정 되돌리기·초기화·직전본 복원을 제공한다. 모니터/인터페이스 배율을 바꿔도 그림의 픽셀 배율과 보기 중심을 유지한다.

캔버스 커서는 브러시 외곽과 현재 도구 아이콘을 표시한다. Brushes 속성의 Size/Aspect/Tip angle으로 크기·타원 비율·팁 각도를 지정하며 보기 회전/반전/배율과 화면 배율을 따른다. 작은 브러시에서도 십자 중심을 표시한다.

`Workspaces`에서 패널을 Left/Right/Floating으로 도킹·분리하고 화면과 순서를 고른다. 각 패널의 Dock 메뉴에서도 바꿀 수 있다. 분리 창의 제목/모서리를 드래그하면 이동/크기가 로컬 저장되며 화면이 사라지면 현재 화면 안으로 회수한다. 이름을 저장한 작업공간은 전환·갱신·삭제·저장본 재적용·초기화를 제공한다. 로컬 JSON 가져오기나 저장본 재적용에서는 배치/단축키/명령막대/기타 설정군을 따로 고른 뒤 확정한다. 현재 설정은 자동 백업하고, 미저장 배치를 별도 이름으로 저장할지는 추가로 선택한다. 취소는 설정을 바꾸지 않는다. 누락 화면·도구·명령과 충돌 키는 목록으로 안내한다.

`Test painting`은 독립 시험 칠하기 창이다. 현재 도구·색·크기로 마우스를 드래그해 칠하고 지우개로 지울 수 있다. 내용/창 표시/도구는 다음 실행에도 유지하며 문서 픽셀이나 Undo에 포함되지 않는다. 전체 브러시 기능과 실제 펜 하드웨어 검증은 해당 기능 항목에서 추가한다.

`Input and commands`에서 단축키·도구 순환·빠른 접근/명령막대·원형 메뉴·장치 동작을 편집한다. 변경은 임시본이며 Apply로 한 번에 반영하고 Cancel은 기존 배정을 유지한다. 중복/예약 키·동명 목록·중복 도구는 즉시 알리고 확정을 막는다. 로컬 가져오기/내보내기·기본값·적용 전 백업 복원을 제공한다.

순환 목록은 도구 추가/순서 변경/역순/복제/삭제를 지원한다. 초기 T/Shift+T는 다음/이전 도구이며 이전 저장 설정에 없으면 명령을 직접 배정한다. 빠른 접근/명령막대에는 명령·도구·등록 시 고정색·구분자를 넣고 타일/목록/팝업과 검색을 사용한다. 항목은 드래그하거나 선택한 Ctrl+드래그로 순서를 바꾼다. 명령을 사용할 수 없는 이유는 호버로 보여준다. 원형 메뉴는 초기 R, 빠른 접근 팝업은 Q이며 키 배정을 바꿀 수 있다. 4/8방향 슬롯은 마우스와 1–8 키, 방향키로 같은 명령을 실행한다. 중앙·영역 밖·Esc는 취소한다. 공통 명령 선택은 기존 배정을 선택해 열고 Confirm으로만 임시본을 바꾼다.

포인터 어댑터의 추가 버튼 Extra1/Extra2 또는 이름 있는 장치 동작을 같은 명령에 배정할 수 있다. 중복 이벤트/버튼 반복은 한 번만 처리하고 연결 해제 뒤 입력 상태를 지운다. 사용할 수 없는 장치 동작은 이유를 표시하고 키보드로 같은 명령을 시험한다. 실제 전용 컨트롤러·펜 하드웨어 검증은 대기한다.

`Tool input behavior`에서 임시 도구 전환 시간(기본 300ms)과 드래그 판정 거리(기본 화면 4px)를 고른다. 도구 키를 짧게 누르고 놓으면 선택을 유지하며 오래 눌렀다 놓으면 이전 도구로 돌아온다. 키 반복은 유지 시작 시간을 다시 세지 않는다. 여러 도구 키와 마우스/펜 버튼 해제도 각각 처리하고 포커스/문서가 바뀌면 임시 입력을 끝낸다. 설정은 임시본에서 확정하며 적용 전 로컬 백업·초기값·이전본을 제공한다. 드래그 거리는 모니터/UI 배율을 반영한 실제 화면 픽셀이며, 임계값을 넘으면 처음부터 이동한 전체 거리를 반영한다. 임시 키를 누른 채 재시작하면 기존 도구를 복원한다.
