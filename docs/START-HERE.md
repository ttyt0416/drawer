# Drawer 실행·설치·제거

Windows 64비트에서 `Drawer.exe`를 실행한다. 기본 도구와 글꼴을 실행 파일에 포함해 별도 소재 다운로드가 필요하지 않다.

사용자 계정에 설치하려면 배포 폴더에서 PowerShell로 `./Install.ps1`을 실행한다. 기본 설치 위치는 사용자 LocalAppData의 `Programs/Drawer`이며 관리자 권한을 요구하지 않는다.

설정은 사용자 LocalAppData의 `Drawer/settings`, 사용자 소재는 `Drawer/materials`에 보관한다. 문서는 사용자가 선택한 위치에 보관한다.

`New canvas`로 새 그림을 만들고 `Open…`으로 로컬 `.drawer` 또는 PNG를 여러 개 연다. 위쪽 문서 탭으로 전환한다. 같은 이름의 파일은 탭에 마우스를 올려 전체 경로를 확인한다. `Save`는 편집 가능한 `.drawer`로 저장한다. PNG를 가져와도 원본 파일은 변경하지 않는다.

`Duplicate view`는 같은 그림을 다른 배율·각도로 보는 탭을 추가한다. 도구와 실행 취소 이력은 그림별로 공유하며 보기 위치는 탭마다 유지한다. 탭의 `×`로 닫는다. 미저장 그림의 마지막 탭을 닫을 때 저장·버리기·취소를 선택한다. 종료 도중 취소하면 열린 그림을 유지한다.

`Resample…`은 픽셀 수와 그림 배율을 변경한다. `DPI…`는 픽셀을 유지하고 인쇄 크기만 변경한다. `Canvas size…`는 앵커를 기준으로 여백과 경계를 변경한다. `Crop…`은 왼쪽·위·가로·세로로 지정한 영역만 남긴다. 경계 밖 픽셀을 지울 때는 노란 윤곽과 제거 안내를 확인하고 체크한 뒤 `Apply`를 누른다. `Cancel`/Escape는 변경하지 않으며 `Undo` 한 번으로 확정 전 상태를 복원한다.

보기 도구의 `Mirror`는 화면만 좌우로 뒤집는다. `Image:` 줄의 반전·90도 회전은 그림 데이터 자체를 변경하며 `Undo`로 되돌린다. `Export PNG…`는 현재 크기의 RGBA8 합성 이미지를 별도 파일로 저장하고 편집 문서의 저장 위치·변경 표시를 유지한다. 현재 PNG 출력은 색상 프로필·DPI 메타데이터를 기록하지 않는다.

왼쪽 `Navigator`는 전체 그림과 현재 보이는 영역을 표시한다. 미리보기를 클릭하거나 드래그하면 해당 위치로 보기를 이동한다. 회전·Mirror·확대 상태를 유지하며 그림 데이터는 변경하지 않는다.

제거하려면 설치 폴더의 `./Uninstall.ps1`을 실행한다. 설치 기록에 있는 프로그램 파일만 제거하며 사용자 문서·소재·설정과 추가 파일을 보존한다. 재설치도 이 데이터를 삭제하지 않는다.
