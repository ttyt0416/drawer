# Local current-state recovery

A local recovery session owns a marked folder and an OS file lock. Startup skips live sessions. Every checkpoint captures current editable document state without cloning session Undo/Redo, writes and verifies independent native blocks, then publishes a small versioned hash index last. Original document paths are display-only provenance. Recovery never reads or writes those paths. Previous blocks stay until a user decision; failed candidates remove only their exclusive staging directories.

The app attempts a checkpoint of dirty documents every60 seconds after pointer input/unfinished drawing has settled. Recovery storage is disabled in the implicit test/smoke app constructor and initialized explicitly in owned verification fixtures. The normal app scans at storage initialization and opens a chooser for unresolved sessions. Checkpoint now is also available. Cancel keeps snapshots. Opening rechecks the hash and creates a fresh, dirty document without a native destination or old session Undo. A corrupt independent document does not prevent recovery of other complete documents. Session deletion requires a separate irreversible-action confirmation and preserves both original files and already recovered drawings.

Normal exit clears the current session only after normal save/discard decisions or when all documents are clean. A crash leaves the synchronized current-state snapshot. A session helper test is actually killed from a parent test process, followed by restart scanning and semantic reopen. Generated verification also covers two dirty documents (saved/untitled), all block/index fault boundaries, live-session exclusion, partial corruption, cancel, provenance/source bytes, independent history, and pointer-driven chooser/discard/checkpoint. No original SAI/CSP runtime is used. Configurable retention/intervals and background writers are separate subsequent items.
