# 문서별 로컬 작업시간 (207·208 공통 기반)

`work-time` 명령은 현재 문서의 누적 시간을 표시한다. 캔버스에서 실제 누른 포인터/드래그 입력 또는 확정된 문서 수정이 관측되면 활성 편집 구간을 시작한다. 단순 포인터 이동과 시간 창 조작은 구간을 연장하지 않는다. 마지막 편집 입력으로부터5분까지만 집계하며 그 뒤 유휴로 멈춘다. 즉, 입력 이벤트 자체의 몇 밀리초만 합산하는 수치가 아니라 짧은 생각/도구 선택을 포함하는 활성 편집 세션 시간이다. 수동 일시정지/재개를 제공하고 재개 후 새 편집 입력부터 다시 집계한다.

하나의 단조시계와 활성 문서 소유자만 사용한다. Windows에서는 QueryUnbiasedInterruptTime의 가동 상태 시계를 사용해 짧은 수면/최대절전도 OS에서 제외한다. API 실패 표본은 시간을 더하지 않는다. 근거: [Microsoft API 계약](https://learn.microsoft.com/en-us/windows/win32/api/realtimeapiset/nf-realtimeapiset-queryunbiasedinterrupttime). 탭/문서 전환·저장·닫기 전에 이전 소유자의 시간을 정산한다. 같은 문서의 복수 보기와 백그라운드 문서를 중복 집계하지 않는다. 창 포커스를 잃으면 멈추고 복귀 후 새 편집 입력을 기다린다. 집계 중에는1초 간격으로 화면을 갱신하고 로컬 기록을 동기화한다. 이벤트 루프가5초 넘게 정지한 구간은 전부 제외하고 새 입력을 기다린다. 이는 수면/절전 시간을 포함하지 않기 위한 보수적 정책이며5초 넘는 앱 정지/긴 동기 작업도 제외한다. OS 시각/시간대 변경은 누적 시간에 사용하지 않는다. 정상 종료 때 마지막 시간을 정산한다. 강제 종료 시 마지막 성공한 로컬 체크포인트 뒤의 시간은 복구할 수 없다.

작업시간은 `Document.work_time`에 있고 그림의 상태 스냅샷/리비전/dirty/Undo에 들어가지 않는다. 일시정지·자동 집계·시간 초기화/복구·내보내기는 그림의 미저장 변경 표시를 만들지 않는다. 정상 자체문서 저장은 최신 값을 native103의 선택적 메타데이터에 포함한다. 그림을 수정하지 않았어도 사용자가 Save를 실행하면 최신 시간을 포함한다. Revert는 현재 시간 메타데이터를 보존한다.

문서 시간 ID는64자리 소문자16진수이며 앱에서 독립 문서에 처음 연결할 때 생성한다. 편집 미리보기/내부 셀용 `Document::create`에는 자동 ID를 넣지 않아 픽셀 원본의 바이트/해시를 불필요하게 바꾸지 않는다. Save As는 ID를 유지한다. ID 없는 구형 자체문서는 정규화된 기존 경로에서 레거시 ID를 유도해 첫 새 형식 저장 전의 로컬 시간도 재열기에 연결한다. 새 문서/가져온 이미지는 새 ID를 받는다. 이미 열린 ID와 같은 ID의 독립 복사 파일을 추가로 열면 누적값을 한 번 복사한 별도 ID를 부여한다. ID/누적 시간은 인증된 작업 증명이나 저작권 증명이 아니다.

로컬 사용자 데이터의 `work-time/<ID>.json`에 형식/버전·문서명/정상 저장 경로·ID·갱신 순번·누적 밀리초·일시정지·최대16개 초기화 되돌리기 값을 보관한다. 자체문서와 로컬 기록 중 갱신 순번이 큰 값이 최신이며, 초기화된0도 예전의 큰 누적값보다 우선한다. 같은 순번의 서로 다른 스냅샷은 충돌 오류로 보존한다. 레코드당32KiB, 문자열·100년 누적 상한을 검사한다. 파일은 새 개인 준비 위치에 쓰고 동기화 후 교체하며 이전 파일 해시를 재검사한다. 잠금 파일의 OS 파일 잠금을 세션 동안 유지해 여러 프로세스의 동시 집계를 막는다. 잠긴/손상된/외부 변경 기록은 덮어쓰지 않고 시간 집계를 비활성화해 안내한다. 잠금 파일은 의도적으로 남는 빈 메타데이터이며 OS가 핸들 잠금을 해제하므로 비정상 종료 뒤에도 다시 열 수 있다.

미저장 문서는 로컬 시간 목록에서 이름/ID/누적값을 찾아 현재 그림에 명시적으로 연결할 수 있다. 이는 시간 메타데이터만 복구하며 그림 픽셀을 복구하는 기능은 아니다. 기존 현재 문서의 시간 레코드도 보존한다. 다른 열린 문서나 프로세스가 쓰는 기록은 연결하지 않는다. 로컬 목록은8192개 파일까지 검사하며 손상된 레코드는 오류로 알리고 자동 삭제하지 않는다.

Reset은 현재 문서 ID에 대한 별도 확인을 요구하고 취소는 값을 바꾸지 않는다. Undo time reset은 제거한 시간을 현재 누적값에 다시 더한다. 초기화 이후 새로 집계한 시간도 유지하며 전용 되돌리기 기록은 로컬/자체문서에 저장된다. 이 조작은 그림 Undo/Redo와 독립이다. 로컬 JSON 내보내기는 새 파일명만 사용하고 기존 파일/열린 문서/가져온 원본을 덮어쓰지 않는다. CSV 보고서는 같은 집계 기반을 사용하는208에서 연결한다.
