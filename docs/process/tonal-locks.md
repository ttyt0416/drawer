# 082 — 톤 구간별 닷지·번과 저장 설정 잠금

독자 수식과 로컬 설정만 사용한다. 원본 프로그램 코드/소재를 포함하지 않는다.

## 닷지·번

Tool input → Pigment → Dodge and burn에서 Color brush/닷지/번, Shadows/Midtones/Highlights와 강도0–1을 고른다. 정수 휘도 `(54R + 183G + 19B)/256`의 0–84,85–169,170–255 세 구간을 사용한다. 문서의 획 시작 전 원본 픽셀로 톤을 고정 판정한다. 닷지는 각 RGB 채널 `v + (255−v)×강도×coverage`, 번은 `v×(1−강도×coverage)`이며 최종8비트 반올림한다. 알파와 완전 투명 픽셀의 숨은RGB는 보존한다. 구간 밖/강도0/불투명도0은 불변이다.

같은 획 안의 반복 도장은 최대 coverage로 처리해 톤 구간을 벗어나거나 밀도가 중복 누적되지 않는다. 새 획은 이전 확정 픽셀을 기준으로 한다. 선택/경계 참조/배치 레이어/전체 불투명도/팁 질감과 압력 coverage를 기존 순서대로 적용한다. 전경색과 그 알파는 밝기 조정의 공급색으로 쓰지 않는다. 닷지·번은 안료/수채 확산·종료 경계와 특수 합성보다 우선하며 지우개·복제·픽셀 덮어쓰기는 기존 기능을 유지한다. 다른 도구 옵션은 보존해 톤 조정을 끄면 다시 쓸 수 있다.

한 획은 한 그림 Undo/Redo이며 옵션은 프리셋/사용자 도구/로컬 설정, 확정 픽셀과 스타일은 문서v31에 저장한다. 이전 누락 tonal은 Off다.

## 설정 잠금과 임시값

Keyboard editing의 Lock saved tool settings로 현재 기본 도구 또는 사용자 도구를 잠근다. 기본 도구는 잠글 때의 전체 프리셋을 별도 기준값으로 보존한다. 사용자 도구는 그 순간의 현재값을 저장 기준으로 잡고 자동 갱신을 막는다. 같은 도구의 수치/질감/안료 등은 계속 조절할 수 있고 여러 획 동안 임시값을 유지한다. 같은 도구를 다시 선택해도 유지한다.

다른 기본 도구/사용자 도구/Move/Eyedropper로 바꾸거나 다른 도구의 문서 탭으로 바꾸면 떠나는 잠금 도구의 기준값을 복원한다. 수정자 임시 도구 전환에서도 컨트롤러의 눌림/놓임 상태를 유지하면서 떠나는 도구의 값만 복원한다. 다른 도구에서 돌아오면 원래 값이다. 설정 저장은 복사본만 정규화하여 임시값을 디스크에 기록하지 않고 현재 화면값을 유지한다. 재시작은 기준값으로 열린다. 기본/사용자 도구 상태와 잠금 기준은 로컬 작업공간에 저장한다. 더 최근의 개별 패널 설정 파일이 있어도 잠금 기준을 마지막에 적용한다.

로컬 프리셋 목록과 사용자 도구 편집기에서도 저장된 프리셋의 잠금 플래그를 선택한다. 잠긴 이름의 프리셋 덮어쓰기, 잠긴 사용자 도구 자동 갱신/초기화/지원 속성 변경은 거부한다. 명시적으로 잠금을 풀거나 다른 이름/새 도구로 복제 저장할 수 있다. 사용자 도구의 이동/정렬/삭제는 구조 편집이며 별도 초안/취소를 따른다. 잠긴 프리셋 파일 자체의 덮어쓰기도 거부하고 별도 파일로 저장한다. 잠긴 로컬 프리셋을 복원하면 해당 기본 도구 기준으로 연결한다. 현재 도구 잠금 해제는 연결된 로컬 원프리셋의 잠금도 명시적으로 해제하고 현재 임시값은 유지한다.

프리셋 payload에 없는 앱 전경색·보기·장치 전역 보정·작업공간 배치는 도구 잠금 범위 밖이다. 설정 잠금/해제와 도구 전환은 그림 이력에 넣지 않는다. 실제 펜 센서 검증은 대기한다.

## 검증

256회색×알파0/128/255×6종 톤 조합,85/170 경계,0/1 강도, 반복 도장과 한 이력/문서 재열기, 선택128×불투명도0.5의 독립 기준144, 지우개/픽셀 덮어쓰기 우선을 검사한다. 생산 이벤트 루프에서 투명 전경색과 수채/특수 합성 옵션을 함께 둔6종 닷지·번 결과를 검증한다.

기본/사용자 잠금 후 임시 크기/톤 설정, 실제 여러 획, 같은 도구 재선택, 다른 도구 전환/복귀, 설정 저장 중 라이브 값 보존과 재시작 복원, 이름 있는 원프리셋/파일 덮어쓰기 거부·별도 복제·잠금 해제, 비활성 기본 도구 기준의 저장, 구형 누락 기본값을 검사한다. 설치본도 같은 시험을 수행한다.
