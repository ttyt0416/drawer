# 101 — 채우기 참조 집합·제외·확장 모양

Fill options는 Current raster/단일 지정 Raster/All layers(Visible composite)/Reference layers/Selected layers/Layer in folder를 제공한다. Reference는 페이지에 Reference로 표시한 래스터·벡터를, Selected는 도구에서 체크한 래스터·벡터 집합을 읽는다. 폴더는 해당 래스터 폴더의 하위 폴더까지 포함한다. 전체 합성만 페이지 객체·애니메이션·3D 표시를 포함한다. 현재/단일 래스터는 기존처럼 원본RGBA를 읽고 집합은 기존 폴더/레이어 합성을 쓴다. 숨긴 층과 숨긴 폴더의 층은 항상 제외한다. 참조가 빈 경우는 투명 참조 버퍼이며 범위 안 같은 투명 영역을 선택한다.

Reference exclusions, expansion and layer sets를 펼쳐 Exclude text/balloon/draft/editing/paper/locked를 독립 설정한다. 편집층은 실제 쓰기 대상 래스터다. 문자 제외는 편집 가능한 Text 페이지 객체와Text 역할의 층에 적용한다. 말풍선/종이 제외는 해당 역할의 래스터·벡터에 적용한다. 초안/참조 표시는 픽셀을 바꾸지 않는 페이지 태그다. 역할은 Drawing/Text/Balloon/Paper 중 하나이며 실제 내용의 용도를 지정한다. 향후 전용 말풍선 편집기의 별도 개체 형식이 생기면 같은 정책에 연결한다. 현재 표시 가능한 말풍선 자료는Balloon 역할을 부여해 참조에서 제외한다. 벡터는 별도 Reference/Draft/Selected 체크를 제공한다. 잠긴 층도 제외 옵션이 꺼져 있으면 읽을 수 있고 쓰기 잠금은 우회하지 않는다.

Reference/Draft/역할 태그는 페이지에 저장하고 하나의Scene Undo로 변경한다. 래스터 태그는 기존 Paper 그래프의 인덱스 이동/복제 처리를 공유하고 벡터 태그는 고유ID 객체와 함께 이동한다. Selected 집합은 현재 층 순서의0~255 인덱스를 도구 설정에 저장한다. 다른 문서나 층 구성 변경 후에는 표시된 체크를 확인한다. 참조 집합/여섯 제외/확장/좁은 영역 옵션은 현재 도구의 fills와 로컬 브러시 프리셋에 보관한다. 구형 누락은 기존 옵션으로 복원한다. 문서v35는 페이지 태그를 보존하고v34 이하의 누락은 기본값이다.

제외한 래스터는 합성 그래프에서 숨기고 포함 층이 없는 폴더도 건너뛴다. 투명색으로 대체한 뒤 ReplaceAlpha 같은 특수 합성을 실행하지 않으므로 제외한 층이 남은 참조를 지우지 않는다. 페이지/픽셀/사용자 레이어 잠금은 참조 탐색 중 바뀌지 않는다. 미리보기의 설정·문서 리비전·프레임·입력원·보기 고정/취소와 놓기 한 문서 Undo는093의 경로를 공유한다.

영역 확장은0~32문서픽셀이다. 구형 기본 Diamond는4방향 맨해튼 거리,Rectangle은8방향 체비쇼프 거리,Round는반경 제곱의 정확한 원판이며작업 상한을 검사한다. To darkest pixel은 흰 배경에 합성한 참조 밝기가 증가하지 않는4방향 경로로 최대반경만큼 진행하고 다시 밝아지는 픽셀 앞에서 멈춘다. 원본 제품과 수치 호환을 주장하지 않는 독립 정책이다. 알파 허용치/색차/Strict/Close gaps/부분알파 AA는 별개로 유지한다.

Fill narrow areas는 틈 보정으로 빠진 원래 적격 영역 중 가로 또는 세로 폭이gap이하인 부분을 선택 영역에서 최대max(gap,1)단계만 복원한다. 부적격 경계나 넓은 외부 배경으로 재탐색하지 않으므로 긴 틈 너머 전체 배경을 다시 채우지 않는다. Strict에서 이미 연결된 적격 영역은 그대로다. 원형 확장·좁은 영역 판정은64Mi 작업,전체 캔버스4Mi픽셀·합성 참조64Mi 추정작업·Scene4MiB·문서/Undo 메모리 상한을 검사한다. 실패는 원본을 보존한다.

자체7×7의Text/Balloon/Draft/Paper 네 벽을 서로 다른 층에 배치해 전체/표시 참조/선택/폴더가 폐곡선을 유지하고 각각의 제외 옵션/숨김이 해당 벽을 열어 외부가 연결되는지 확인한다. 편집층 제외·잠긴 대상 쓰기 거절·현재 Text 개체 제외·벡터 참조/초안·제외한 ReplaceAlpha 합성 무효화를 검사한다. 한 점 반경1의사각/원형 대각 차이,원형 반경2,흰색→180→50→0→100에서 가장 어두운0까지 확장,좁은 삼각 끝 복원/부적격 밖 보존,페이지 태그 Undo/문서 재열기를 확인한다. 생산 마우스·합성 펜20조합에서90도/확대8·미확정 원본/dirty 불변·확정 결과·한 Undo/Redo·설정 변경 취소·프리셋/작업공간 재열기를 설치본에서도 검사한다. 실제 펜 센서는 별도다.
