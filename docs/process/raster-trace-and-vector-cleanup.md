# 150 — 래스터 윤곽 변환과 속성 보존 연결·짧은 선 정리

Layers의 Trace raster to vectors에서 선택한 래스터의 저장 픽셀을 읽는다. 최소 알파와 최대 명도는 경계를 포함하며 알파0은 항상 제외한다. 명도는 (54R+183G+19B)/256이다. 8비트 RGBA1–16개 색상군으로 묶으며 거리 계산은 premultiplied RGB와 알파를 사용한다. 실제 출력 색은 각 군의 RGBA 평균이다. HDR/높은 정밀도 원본과 다른 층·레이어 효과를 합치지 않고 원본 레이어 자료를 그대로 남긴다.

색마다 픽셀 가장자리의 방향 있는 윤곽을 추적한다. 대각선 접촉은4연결 윤곽으로 분리하고 구멍/떨어진 윤곽은 왕복 연결 변과 even-odd 채움으로 함께 보존한다. 출력은 새 벡터층의 편집 가능한 채움 경로다. 출력 위치에 현재 문서 변환의 역변환을 적용한다. 오차0은 픽셀 경계를 정확히 따르며 일직선의 중간 정점만 무손실로 없앤다. 양의 오차는 문서 픽셀에서 RDP로 단순화하며 자기 교차·윤곽 교차·포함 관계·방향이 바뀌면 해당 색의 원래 윤곽을 사용한다. 원본층이 보이면 새 반투명층과 함께 합성되므로 새 윤곽만 확인하려면 원본 표시를 끈다.

입력은1M픽셀·고유색65536개·경계 변65536개, 처리량64M으로 제한한다. 기존 문서와 합쳐 경로128개·한 경로4096점·전체8192점 및 JSON4MiB·Undo/작업공간 메모리 한도를 지킨다. 초과/잘못된 값/조건에 맞는 픽셀 없음은 문서를 바꾸지 않는다. 단순한 대형 사각형은 중간 정점을 줄인 뒤 저장점 한도를 검사한다.

Refine vector strokes의 Join endpoints는 열린 두 획의 가장 가까운 끝점을 문서 픽셀 거리로 고른다. 같은 스타일은 기존 단일 윤곽 연결을 유지한다. 다른 폭/RGBA이면 두 원본 구간의 개체ID·논리 곡선·기하·폭·색/알파·장치/편집 압력을 그대로 유지한다. 사이에 같은 팁·첫 획 색의 독립 연결 경로를 넣고 끝점의 실제 압력 반영 폭 사이를 선형 보간한다. 세 구간을 함께 선택하며 각각 편집할 수 있다. 거리가0이면 연결부를 추가하지 않고 두 원본 구간만 함께 선택한다. 서로 다른 팁/장치 압력 활성 상태와 채움 객체 연결은 거절한다. 연결 경로와 원본 구간은 일반 획과 동일하게 합성한다.

Remove short vector strokes/spans는 캡처한 다중 층 벡터 선택 또는 All eligible vector layers를 처리한다. 전체 획 선택은 전체 저장 윤곽의 길이, 제어점 선택은 인접 제어점 사이의 연결된 선택 구간 길이를 사용한다. 실제 문서 변환을 적용한 렌더 선분 길이를 더하며 제어 다각형 길이·화면 확대율을 사용하지 않는다. 임계값 미만만 제거하고 같은 길이와0임계값은 남긴다. 닫힌 시작/끝점에 걸친 구간은 한 길이로 판정한다. 선택 밖 경로·구간 기하·색/팁·비균등 장치 압력과 편집 배수는 유지한다. 채움 윤곽은 전체 선택일 때만 제거한다. 전체 범위는 숨김·잠금·위치 잠금·읽기 전용 연결층을 제외하고, 명시 선택에 이런 층이 있으면 거절한다.

두 창 모두 전후 미리보기 → Apply as one Undo로 적용한다. Escape/창 닫기는 원본과 기존 이력을 유지한다. 페이지·프레임·수정본·대상/선택이 바뀌면 이전 계획은 적용할 수 없고, 실패한 미리보기는 이전 적용 계획을 비운다. 빈 정리는 이력을 만들지 않는다. 기존 네이티브v68의 경로/채움/필압 및 선택 형식으로 저장하고 Undo는 전체 원본을 복구한다.
