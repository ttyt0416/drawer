# 로컬 수동 업데이트

배포 기록의 PACKAGE.json SHA256을 신뢰할 수 있는 경로에서 먼저 확인한다.
검토한 로컬 Install.ps1에 InstallDir과 ExpectedManifestSha256을 명시한다.
현재 자체 빌드는 서명이 없어 AllowUnsigned도 명시해야 한다. 이는 배포자 인증이
아니다. 배포 ZIP/설치 스크립트 자체도 받은 출처에서 독립적으로 확인한다.
자동 업데이트/원격 콘텐츠/통계/오류 보고 업로더는 없으며 자동 실행하지 않는다.

PACKAGE.json 버전1은 앱 버전·지원 Native 범위·설정 형식과12개 파일의 길이/해시를
포함한다. 명세 자체를 더해 배포13파일이다. 전체 해시와 WinVerifyTrust의 캐시 전용
신뢰 상태를 검사한다. 인증서/CRL/AIA를 다운로드하지 않는다. 잘못된 서명은
AllowUnsigned로 무시하지 않는다. 서명된 배포는 신뢰 검증 성공과 사용자가 확인한
인증서 SHA256을 요구한다. 현재 인증서가 없어 서명된 배포의 성공 시험은 하지 않았다.

로컬 드라이브·부모 구성요소·링크 없음·소유 기록·공간을 검사한다. 기존 설치와
사용자 추가 파일을 별도 준비 폴더로 복사하고 새 파일을 겹친 뒤 해시를 확인한다.
기존 설치의 변경 없음을 확인하고 이전 폴더로 이동한 다음 새 설치를 게시한다.
게시 실패 때 목적지가 비어 있으면 이전 설치를 복구한다. 알 수 없는 새 목적지나
변경된 준비 복사본은 덮거나 삭제하지 않는다. 성공해도 이전 앱 폴더와 추가 파일을
보존하고 위치를 알린다. 사용자 데이터는 변경하지 않으며 버전별 설정 로더가 읽는다.

낮은 버전은 AllowDowngrade 확인이 필요하다. 새 Native 형식은 이전 앱에서 열리지
않을 수 있어 원본을 보관해야 한다. Native1..125와 이전 필드 없는 설정 버전1이
현재 회귀 시험 범위다. test-local-update는 unsigned 기본 거절·핀/파일 변조·기존
설치를 실제 보존한 후 게시 실패 주입/복구·이전 앱/추가 파일/설정 보존·이전 설정
전체 실행·다운그레이드를 검사한다. 호스트 네트워크 차단/새 PC272와는 구분한다.

Windows 기본 PowerShell5.1에서 설치·재설치·제거도 실제 실행했다. 파일 해시는 .NET 스트리밍 SHA256으로 계산하며 PowerShell7 전용 경로 API에 의존하지 않는다. 내장 서명 표가 있는데 검증되지 않거나 손상된 경우 unsigned 허용으로 우회하지 않는다.
