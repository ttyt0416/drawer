# 로컬 탐색기 보완 (253)

248의 보기/정렬/즐겨찾기/파일 관리/썸네일에 직접 파일 경로·폴더 드롭·순차 파일 드롭·대소문자 변경·폴더 참조 정리를 연결했다. 주소 입력은 이미 파일과 폴더를 판별하던 기존 작업자를 재사용한다. 한 폴더 드롭은 탐색 이동, 최대128개 파일은 이미지 검토 창이 닫힌 다음 다음 파일을 연다. 폴더와 파일 혼합 드롭은 아무 대상도 열기 전에 거절한다. UNC/URL/네트워크 드라이브·재분석 경로는 기존 로컬 검사로 거절한다.

대소문자만 바꾸는 이름은 같은 부모·ASCII 대소문자 동등 이름·실제 같은 정규 경로인 경우만 기존 대상 충돌 검사에서 허용한다. 다른 하드링크 이름이나 별도 파일은 덮어쓰지 않는다. 실제 변경은 기존 Windows no-replace 이동을 사용한다.

물리 이름 변경 후 열린 문서/원본 경로·최근/즐겨찾기·참고 이미지 원본 경로와 연결 파일 경로를 갱신한다. 연결 파일은 보관된 그림 Undo/Redo 상태도 갱신하므로 Undo가 없어진 이전 경로를 복원하지 않는다. 연결 캐시/픽셀·이력 개수는 유지하고 새 연결 메타데이터는 문서에 저장할 수 있게 변경 표시한다. 이름 변경은 그림 Undo와 분리된다. 자동 갱신 어댑터가 없는 현재 장면의 절대 외부 참조는 최대128개 경로 목록으로 알린다. 다른 프로그램/닫힌 문서의 참조는 열거할 수 없음을 표시한다. 로컬 설정 저장 실패는 물리 작업을 거짓으로 되돌리거나 성공으로 숨기지 않는다.

PNG/JPEG/BMP/TIFF/WebP/자체 문서/PSD/PSB는 내용 서명과 확장자가 다르면 공통 진입점에서 명시적으로 거절하고 실제 형식에 맞는 파일 선택 또는 명시적 이름 수정을 안내한다. 확장자만으로 다른 형식인 것처럼 열거나 자동 이름 변경/저장하지 않는다. 기존 미지원 형식 거절 정책은 유지한다.

검증은 기존248의 긴 경로·정렬 동률·예약 이름·충돌·권한·썸네일 실패/취소·휴지통 거절/취소·열린 문서 보존에 추가하여 대소문자 이름 변경·내용 불일치·폴더 드롭·다중 이미지 검토 대기·직접 파일 주소·혼합/네트워크 거절·연결 경로와 보관 Undo 상태를 검사한다.
