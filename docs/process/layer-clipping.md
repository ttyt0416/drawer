# 알파 보호·클리핑·폴더 단독 표시

알파 보호는 래스터와 셀의 기존 알파를 유지한다. 알파0의 숨은 RGB도 바꾸지 않는다. 붓/마우스 재구성/픽셀 델타와 채우기·도형·그라디언트는 공통 보호를 적용한다. 일반 상태 편집은 보호 알파를 바꾸면 거절하며 전체층 이동과 전체 페이지 기하 변환은 허용한다.

클리핑은 같은 형제 목록의 아래쪽 비클리핑 기준층 식별자를 저장한다. 연쇄층은 그 기준을 공유하며 색은 source-atop, 묶음의 알파는 기준층의 알파로 고정한다. 예: 파랑128에 빨강128은 (128,0,127,128), 빨강255는 (255,0,0,128)이다. 기준층의 질감·불투명도를 포함한다. 래스터/일반 폴더와 벡터 스택을 지원하며 통과 폴더 자체는 외부 배경 의존성 때문에 기준/소유자로 지정하지 않는다. 통과 폴더 내부 자식끼리는 사용할 수 있다.

숨김/투명 기준층은 연쇄를 가린다. 기준층 이동·삭제·다른 폴더 이동으로 관계가 끊기면 연결은 비활성으로 보존하고 다른 층으로 자동 변경하지 않는다. 사용자가 중간층 클리핑을 명시적으로 해제하면 남은 위 연쇄는 그 층을 새 기준으로 삼는다. 복제는 속성을 복사하며 삭제는 소유자 속성만 제거한다. 독립 베이크에는 전체 클리핑 연쇄가 선택 폴더 안에 있어야 한다. 일반 참조 렌더에서 기준층이 제외되면 클리핑도 보이지 않는다.

Layers…의 Alpha protection / clipping / solo에서 복수 대상의 바꾼 설정만 한 Undo로 적용한다. 초안은 문서·수정본·프레임을 고정한다. 폴더 단독 표시는 바깥 층·트랙·벡터·페이지 개체를 숨기고 내부의 기존 숨김 상태를 유지한다. 복구는 기록한 각 층의 숨김 상태를 되돌리며 삭제된 식별자는 건너뛴다. 이 상태와 클리핑/알파 보호는 문서v47에 저장한다.

검증은 독립 반투명 색값, 투명/숨은 RGB, 연쇄/중간 해제, 기준 이동/숨김/삭제/Undo, 폴더 경계/단독 복원, 벡터, 질감과 선화의90도 회전, PNG/화면 픽셀 일치·재열기, 채우기/지우기/도형/붓과 실제 적용 버튼/마우스/가상 펜 입력을 포함한다. 물리 펜 센서는 별도다. 기존 문서·JSON4MiB·초안32MiB·이력/작업 한도를 공유한다.
