# 151 — 기준점 확대·축소·회전 변형

Scale and rotate 명령은 문서 픽셀 기준점에서 X/Y 배율·회전·이동을 조합한다. 음수 X/Y 배율을 허용하고0/너무 작은 값·비수·과도한 좌표·퇴화 행렬은 거절한다.90도 배수는 정확한 기저를 사용한다. 준비는 원본 문서에서 계산하며 뷰의 확대/회전과 독립적이다.

선택 픽셀은 래스터의 선택 강도를 잘라 역매핑한 뒤 남은 원본에 합친다. nearest 또는 premultiplied bilinear를 사용하고 보간 지원 범위까지 출력 경계를 확보한다. 선택 밖 자료가 보간 결과에도 영향을 받지 않는 곳은 기존 저정밀도/고정밀도 표본을 그대로 복사한다.8/16비트 자료와 문서 저장 정밀도를 유지한다. 선택은4×4 coverage로 역매핑한 페이지 소유 마스크가 되어 변형 결과를 따른다. 레이어 자체 마스크·종이·자 위치는 선택 픽셀 편집에서 고정된다. 아이덴티티는 기존 선택/픽셀을 재표본화하지 않는다.

전체 레이어는 기존 연결 변형 경로로 masks/texture/rulers와 함께 처리하고 원본으로부터 nearest 재표본화한다. 선택된 벡터/이미지 소재/연결 캐시는 기존 affine 프레임 편집을 재사용하며 SVG paint/clip·논리 곡선·필압을 유지한다. 선폭은 문서 행렬 면적 배율의 제곱근을 사용한다. 이미지 소재의 반복·타일·비선형 매핑과 원본 비트맵은 보존한다. 연결 변형에 참가하는 구성원은 전체 사전 검증을 거치며 지원되지 않는 조합은 일부만 변경하지 않는다.

텍스트/톤/그림자/3D/애니메이션처럼 현재 편집 표현이 변형을 담을 수 없는 단일 대상에는 사용자가 명시한 Convert unsupported 옵션이 있을 때만 기존 래스터 변환을 먼저 준비한다. 변환 설명을 전후 미리보기와 함께 표시하고 Apply 한 번에 적용한다. Undo는 편집 가능한 원본 자료·속성·마스크까지 복구한다. 기본은 자동 래스터 변환 비활성이다. 연결 구성원/폴더의 지원되지 않는 경우는 먼저 별도 래스터 변환을 선택하도록 거절한다.

미리보기는 문서·기존 이력·파일을 바꾸지 않는다. Escape/닫기로 버리고 Apply 한 번에 한 Undo를 기록한다. 페이지/프레임/수정본/대상 변경 뒤 오래된 계획을 적용하지 않고 실패한 준비는 이전 계획을 비운다. 문서 저장에는 미확정 상태가 들어가지 않는다.4M 출력 픽셀·32768축 길이·선택 마스크32768 runs·기존 문서/작업공간 메모리와 JSON/Undo 한도를 적용한다. 별도 네이티브 형식 변경 없이v68의 픽셀·배치·선택·프레임을 사용한다.
