# 애니메이션 안전 영역·출력 기본값·오디오·이름 (212)

`animation-finish`에서 현재 애니메이션의 마무리 설정을 준비·검토·확정한다. 출력 프레임/안전 영역/범위, 오디오와 일괄 이름 편집은 각각 한 문서 Undo다. 작업자는 고정된 문서 ID/리비전/재생 위치로 준비하며 진행 중 취소·창/문서 닫기·원본 변경은 결과를 버린다. 결과에 프레임/범위/오디오 및 이름 전후 목록을 표시하고 확인해야 적용한다. 셀 내용/텍스트/변형 초안과 메모리 예산은 기존 정책을 따른다.

## 문서 정의와 보기

출력 프레임 키는 기존 정의·생성 좌표계를 사용한다. 현재 시점의 사각형 키를 만들거나 활성 배치의 키 전체를 제거하고 한 Undo로 복원한다. 안전 영역은 출력 프레임(없으면 캔버스)의 가로/세로1..100%를 중앙에 배치한다. 생성 좌표계와 현재 페이지 변환으로 네 모서리를 계산한다.

출력 기본 영역은 캔버스/출력 프레임/캔버스와 오버플로/선택 영역이다. 명시적으로 기본값을 저장한 문서는 기존 재생 범위를 기본 출력 범위로 함께 사용한다. 새 이미지/영상 출력창은 이 영역·범위를, 새 WAV 출력창은 같은 포함 범위를 사용한다. 이미 열린 창이나 출력창 안에서 바꾼 설정은 해당 작업에만 적용한다. 기존 문서에 기본값이 없으면 이전의 전체 범위/출력 설정 정책을 유지한다. 선택 영역/큰 오버플로 등의 실제 출력 가능 여부는 캡처 시 기존 사전 점검을 따른다.

출력선·안전선·오버플로 경계·범위 밖 안내는 메인/보조 캔버스의 보기 전용이다. 오버플로 경계는 현재 프레임의 기본 출력 포함 정책으로 계산하며 재생 위치/리비전/보기 옵션이 바뀌면 갱신한다. 보조선 픽셀은 그림 합성·최종 PNG/영상에 포함하지 않는다. 보기 옵션은 로컬 설정이고 켜기/끄기는 문서 이력·dirty를 바꾸지 않는다. 정의/기본 출력 영역은 `animation_output.settings`, 포함 범위는 기존 `timing.playback`에 저장되어209의 배치 복제/전환에도 보존된다.

## 오디오

기존 원본 PCM·스팬·연결 정책을 사용하며 시작 프레임·음량0..400%·음소거를 검토해 적용한다. 잠긴 클립,10000프레임을 넘는 끝과 잘못된 입력은 거절한다. 원래 PCM을 변형하지 않고 합성할 때 음량/오프셋을 적용한다. 가져오기와 WAV 출력은 기존 오디오 관리자로 연결한다. 기본 출력 범위와 오디오의 정확한 프레임/샘플 경계를 공유한다.

## 셀/샷 이름

규칙은 `{n}` 번호·`{id}` 안정적인 ID·`{old}` 원래 이름 및 `{{`/`}}` 리터럴 괄호다. 번호 시작·양수 간격(1..1000)·최소 자릿수(0..9)를 지정한다. 안정적인 ID 순서로 번호를 정하고32비트 카운터 초과를 거절한다. 결과를 NFC로 정규화하여 최대48문자/180 UTF-8 바이트로 제한한다. 이 한도는 기존 셀 이름 방식의 PNG 교환 출력과 일치한다. 제어 문자/경로 문자·예약 장치명·앞뒤 공백/끝 점·빈 이름과 대소문자 중복을 거절한다. 하나라도 실패하면 전체 변경을 적용하지 않는다.

셀 원본 이름은 문서 공통이며 모든 물리 셀 슬롯과 저장된 배치의 샷 셀 이름 참조를 갱신한다. 셀 원본의 네이티브 바이트/픽셀/크기·오프셋과 키는 유지한다. 활성 타임라인의 샷 주석 이름은 별도로 일괄 변경한다. 샷 교환 출력은 공통 트랙 이름으로 주석을 덮지 않고 해당 배치의 샷 이름을 사용한다. 실제 파일/외부 원본을 이름 변경하지 않는다. 셀 이름 방식의 교환 PNG 파일명과 샷 교환 JSON/CSV의 이름에 변경을 반영한다.

카메라/키프레임의 원본 변경 검사는 이름과 점 라벨·카운터 같은 표시 메타데이터를 원본 픽셀과 구별한다. 네이티브 원본/연결·셀 크기/배치/픽셀 변경은 여전히 본래 좌표 편집 모드를 요구한다. 이름 변경과 동시에 픽셀을 바꾸는 시도도 거절한다.

## 저장과 검증

네이티브106은 안전 영역과 선택적 기본 영역을 저장한다. 기본값은 생략하며 이전 문서는 새 기본값을 추측해 추가하지 않는다. 비활성 배치에만 새 설정이 남아 있어도105 이하로 위장하면 거절한다. 기존 문서/이력·프레임/셀/샷·장면 메타데이터 한도를 유지한다. 보기와 이름 규칙 기본값은 로컬 `settings/animation-finish.json`에 저장하며 새 의존성이나 다운로드를 추가하지 않는다.

검증은 안전/출력/오버플로 좌표와 투명 여백의 실제 픽셀, 포함5프레임 PNG 출력, 보기 켜기/끄기 전후 출력 픽셀/그림/Undo/dirty 불변,12kHz 기준 음성 임펄스의 프레임 위치/50% 음량·WAV, 이름 전후 네이티브 원본 동일·카메라에서의 이름 변경/픽셀 수정 거절, PNG 파일명/샷 교환 이름,106 저장/재열기·구버전 위장 거절·이름 충돌/토큰/예약명/예산/취소/오래된 결과·프레임 제거 Undo를 포함한다. 앱/설치본은 포인터 출력 설정/검토·확정, 오디오/이름 확정, 로컬 보기 재시작, 계산 중 취소/원본 수정/문서 닫기와 기존 출력창의 문서 기본 범위 연결을 검사한다. 실물 펜 검증은 별도 대기 상태다.
