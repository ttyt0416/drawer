# 농담·섬유 소재, 도구 슬롯과 오프라인 묶음

기능077. 슬롯은 기능075의 안정 ID 사용자 도구다. 도구/분류 생성·설정·독립 복제·삭제·로컬 저장을 공유한다. Brush presets → User tools and categories에서 :: 손잡이를 다른 슬롯 위로 끌면 그 앞에 삽입한다. Ctrl을 누른 채 시작하고 끝까지 유지하면 새 ID로 복제한다. 설정·기본값·소재 참조 배열은 값으로 복사하고 등록 소재는 읽기 전용으로 공유한다. Esc/포커스 상실/Ctrl 놓침/목록 밖 놓기는 목록이나 ID를 바꾸지 않는다. 자기 자신 위 놓기는 무변경이다.

Undo tool list / Redo tool list는 최대16단계의 세션 목록 이력이다. 삭제/드래그·이름·설정·그룹 변경을 되돌리고 그림 Undo와 분리한다. Apply 후 관리 창을 다시 열어도 세션 이력을 유지하며 Cancel은 임시본/임시 이력을 버린다. 앱 재시작에는 확정 슬롯 순서·설정·소재가 남고 세션 이력은 남기지 않는다. 활성 슬롯 삭제는 기본 Pen으로 전환하며 목록 되돌리기는 활성 선택도 복원한다. 슬롯 삭제는 소재 등록이나 원본 파일을 제거하지 않는다.

Local image materials의 Gray value / alpha density는 회색값을 그대로 팁 밀도로 쓴다. 완전 불투명 이미지에서는 정수 휘도 `(54R+183G+19B+128)/256`, 투명 픽셀이 하나라도 있으면 알파값이다. 따라서 불투명 검정/128회색/흰색은0/128/255다. 이 모드에서는 빈 팁도 허용한다. 기존 Darkness / alpha는 어두울수록 진한 종전 규칙과 빈 팁 거부를 유지한다. 원본은 읽기 전용이고 PNG/JPEG/단일 TIFF 1–512px·32소재/회색조2MiB 한계는 공통이다.

Owned fibre tip editor에서 위치 X/Y(±1), 굵기(0–2), 길이(0–4), 방향(±180°), 밀도(0–1)를 편집하고 이름을 붙여 등록한다. Read own fibre JSON은 자체 `{version:1,fibres:[{position:[x,y],thickness,length,angle,density}]}`만 읽는다. 파일64KiB/128개 한계, 유한값·범위·버전 검증을 적용한다. 위치/길이/굵기는 팁의 ±1 좌표 단위이고 길이는 끝점 중심선 전체 길이다. 끝은 둥글고 겹침 밀도는 최댓값, 안티앨리어싱 폭은 명목128px 기준이다. 길이0은 점, 굵기0/밀도0/빈 목록은 잉크 없음이다. 팁 사각 경계 밖은0. 등록은 수정 가능한 초안의 독립 스냅샷이며 일곱 엔진/팁 시퀀스의 기존 선택기로 쓴다. 획은 소재 Arc를 고정하고 섬유 수를 픽셀 작업량 예산에 포함한다.

Export portable tools + materials는 선택 슬롯 또는 현재 분류와 현재/등록 기본값에서 참조하는 모든 자체 팁·질감을 포함한다(비활성 시퀀스 슬롯 참조도 포함). 고른 부모 폴더 아래 새 Drawer-tool-bundle 디렉터리를 만든다. 기존 디렉터리를 덮어쓰지 않는다. 일반 그룹 JSON은 계속 로컬 ID만 담는다. 휴대 묶음에는 manifest.json(version1/checksum fnv1a64-v1), tools.json, materials/<원래ID>.json이 들어간다. 각 파일의 상대경로·바이트 길이·16자리 FNV-1a64 해시를 기록한다. 해시는 손상 검사이며 배포자 인증 수단은 아니다. 등록한 회색조/섬유 정의를 포함하므로 원본 이미지나 네트워크가 필요하지 않다.

가져오기는 매니페스트64KiB/도구4MiB/소재 파일2MiB/전체12MiB·최대32소재를 제한한다. 허용된 정확한 상대경로·중복·링크/Windows reparse point·정규 경로 경계·파일 종류/크기/해시·모든 정의/참조/최종 용량을 전체 검증한 후 결과 두 개를 반환한다. 외부 파일·절대/상위 경로·누락/미참조/종류 불일치 소재는 거절한다. 기존 소재와 이름이 같아도 새 ID와 표시 접미사를 만들고 모든 현재/기본값 참조를 재매핑한다. 기존 ID/소재는 보존한다. 소재 등록을 저장한 뒤 슬롯을 임시본에 추가하며 Apply로 슬롯을 확정한다. Cancel/설정 저장 실패에도 이미 등록한 소재는 재사용을 위해 남는다. 손상 묶음은 소재나 슬롯 어느 쪽도 바꾸지 않는다.

독립 PNG 검정/흰색/회색·알파0/128/255·빈/1/다수 섬유·0굵기/길이/밀도·과다 목록/파일·버전/범위·독립 복제 편집·목록 Undo/Redo·실제 egui 드래그/수정키/취소·활성 삭제/복원·재시작 순서·다른 로컬 환경의 이름/ID 충돌 재매핑과 생산 입력 픽셀 동일성을 검증한다. 묶음 경로/크기/해시/누락/중복/잘못된 정의 실패와 기존 내보내기 보존도 시험한다. 실제 펜 하드웨어 검증은 대기다.
