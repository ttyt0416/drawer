# Local computation device policy

The local model window exposes a requested CPU/GPU device and an explicit CPU fallback choice. This distribution has the bundled CPU ONNX engine and no GPU execution adapter or GPU SDK. A GPU request without fallback is rejected before a helper starts; the message names the missing adapter/SDK and offers CPU. No driver, SDK, model or remote provider is searched for or downloaded. GPU acceleration is not advertised as available.

An opted-in fallback runs the same real, bounded CPU helper used by CPU mode. Every result reports its actual execution device. Model manifests/licenses/content hashes and local registrations continue to be validated as in item 280. Missing models, invalid inputs and resource shortages cannot produce adopted partial results. Only reviewed, explicitly adopted output enters document Undo. Low-confidence pose consent is independent of device consent.

**Save processing device preference locally** stores version 1 `settings/local-compute.json` under user data. Model registrations separately retain their content-addressed local paths. Settings use a verified exclusive temporary write, flush/sync/reopen validation, healthy predecessor retention and atomic publication. A foreign temporary file or write failure preserves the current policy. Unknown versions/fields/corruption are reported and preserved, not silently reset. Settings do not change a document or its native format.

Verification includes CPU defaults, unsupported GPU refusal with no worker/document mutation, an actual CPU fallback model execution, actual-device report, adoption/Undo, reloading preferences, Unicode storage paths, failed writes/foreign temporary preservation and corrupt-version refusal. Existing local inference scenarios cover five tasks, empty/transparent input, settings extremes, cancellation, stale/closed documents, native reopen and missing dependencies. Item 281 separately rechecks basic mouse editing/save/recovery after optional failures. Network behavior is observed in the packaged finite scenarios; a fresh offline PC remains a separate item 272 prerequisite.
