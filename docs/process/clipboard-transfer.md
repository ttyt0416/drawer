# 클립보드의 편집 개체와 공개 래스터

252: 내부 래스터 v2는 UTF-8 이름과 검증된 기존 원위치/정밀 색상 패킷을 묶는다. v1도 읽으며 중첩 이름 봉투·미지원 플래그·잘못된 길이/색 프로파일/미리보기 일치를 거절한다. 이름≤4096바이트·NUL 금지, 패킷≤전송 예산·그림4M픽셀, 깊은 중첩/외부 URL/코드를 실행하지 않는 데이터 구조다. 래스터 새 층에 이름·원위치·고정밀 색 프로파일을 유지한다.

벡터 v2는 기존 전체 획/인접 구간 정책(148)을 유지하며 선택된 원래 층 순서와 이름/획 개수를 기록한다. 점·정의·필압/색 스타일은 그대로 보존한다. 일반 붙여넣기는 새 층과 새 목적지 ID를 배정하고, 기존 명시적 vector-paste는 활성 층으로 합친다. 벡터 색은 기존 엔진 계약인 sRGB다. 다른 문서 DPI는 문서 픽셀 좌표를 유지한다. 서로 다른 문서 자체의 선형 변형 프레임은 기존 명세대로 공개 래스터 대체 또는 SVG 변환이 필요하다. 보기 확대/회전/반전은 이 문서 기하 제한과 별개다.

일반 래스터 복사는 선택 범위의 저장 가능한 알파가 있는 유효 경계를 계산하고, 선택 경계 복사는 선택 바운딩박스의 외부/투명 여백을 유지한다. 빈 선택/유효 알파 없음은 거절한다. 선택이 없으면 활성 층 전체의 유효 경계를 사용한다. 벡터 기본 복사는 선택점이 있는 전체 획이며 영역 클립으로 획을 자르지 않는다. 명시적 경계 복사는 선택한 전체 획의 렌더 경계 여백을 유지한다. 원문서는 변경하지 않는다.

Ctrl+X는 먼저 복사/삭제 상태를 준비하고 클립보드의 공개 이미지와 내부 기록이 모두 성공한 뒤에만 원자적으로 삭제한다. 실패/읽기 잠김에는 그림과 이력이 유지된다. 잘라내기와 붙여넣기는 각각 Undo1회이고 Undo가 OS 클립보드를 과거 내용으로 바꾸지 않는다. Ctrl+V는 내부 원위치, Ctrl+Shift+V는 현재 화면 중심의 문서 좌표에 복사 경계를 맞춘다. 벡터 상대 위치는 소수 좌표로 유지하고 래스터 오프셋은 기존 래스터 저장 격자인 문서 픽셀로 반올림한다. 보기 줌/회전/반전/디스플레이 배율은 복사 데이터에 저장하지 않는다.

기존 고정 버전 arboard의 Windows 어댑터는 공개 PNG와 CF_DIBV5를 함께 기록한다. 내부 기록 추가 시 clipboard sequence를 대조한다. 새 공개 읽기는 크기를 검사한 뒤 PNG와 DIBV5를 순서대로 검증하고 해독 예산을 제한한다. PNG는 CRC/채널/ICC와16비트를 기존 검증기로 해독한다. DIBV5는124바이트·표준24/32비트·표준 마스크·양/음 행 방향·sRGB/기본 색공간만 허용하며 외부 프로파일 참조를 따르지 않는다. 내부 버전이 없거나 손상됐을 때 공개 래스터 대체를 시도한다. 참고 이미지의 클립보드 읽기도 같은 제한을 사용한다.

검증: 반투명 공개 PNG/DIBV5·손상 헤더/프로파일·크기 제한, v1/v2/잘못된 버전/중첩 봉투, 한글/이모지 이름과 원위치·투명 여백·빈 선택, 가변 필압/색/층 순서·새 목적지 ID·다른 문서 DPI·Native 재열기, 잠긴 읽기/쓰기 주입·쓰기 성공 후에만 cut·한 번 Undo·클립보드 내용 유지, 실제 붙여넣기 Apply/Cancel 입력과 보기 변환별 위치를 포함한다. 자동 검증은 독립 임시 데이터와 주입한 클립보드를 사용하며 사용자의 실제 클립보드를 덮어쓰지 않는다.

공개 DIBV5 구조: [Microsoft 표준 클립보드 형식](https://learn.microsoft.com/en-us/windows/win32/dataxchg/standard-clipboard-formats). 고정 이미지 라이브러리의 headerless V5 읽기가 픽셀 위치를 12바이트 건너뛰므로, 검증된 헤더에 정확한 픽셀 시작 위치를 가진 BMP 파일 헤더를 붙여 해독한다. 2×2 알파·행 순서를 별도로 검사한다.
