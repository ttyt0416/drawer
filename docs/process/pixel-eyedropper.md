# 픽셀 펜 압력/좌표와 레이어 스포이트

기능073. Pixel pen의 팁 설정에 Pixel pen reacts to pressure와 Pixel precision을 제공한다. 기본값은 기존 필압 반응/정수 격자를 유지한다. 필압 끄기는 획 시작의 유효 스타일에서 크기/농도 매핑과 추가 압력 크기/혼색 곡선만 비활성화한다. 원래 설정 임시본/프리셋의 값은 유지하고 속도/기울기·기하 시작끝·불투명도는 각각 독립이다. 필압 필터/입력 속성 자체를 삭제하지 않는다. 압력0/1/단계형 또는 가상 마우스 압력의 결과가 같아진다.

정밀 좌표는 기존 홀수/짝수 크기의 정수 격자 맞춤이다. 끄면 두 픽셀 이상 팁의 중심은 자유 좌표이며 가장자리 coverage는 여전히 이진이다.1×1 팁은 두 설정 모두 정수 격자를 유지해 한 픽셀이 사라지지 않게 한다. 경도/렌더 품질로 픽셀 가장자리 안티앨리어싱을 만들지 않는다. 기존 도장별 농도/선택/브러시 질감과 색 알파는 독립이므로 부분 투명 잉크나 마스크가 있는 픽셀은 중간 알파를 가질 수 있다. 팁 설정은 S/자체 프리셋, 실제 획/고정 스타일은 문서v24에 보존한다. 구형 누락은 기존 필압 켬/격자 켬이다.

Eyedropper 선택 시 Current layer RGB / Current layer RGBA / Composite RGBA와 Single pixel / Average 3×3 / 5×5 / 9×9를 고른다. 레이어 모드는 대상 래스터의 원래 비연관 RGBA를 읽어 숨김/종이 효과/합성/선택 영역을 우회한다. RGB-only는 저장 RGB와 현재 그리기 알파를 결합한다. RGBA는 저장 알파도 사용한다. 알파0이어도 저장 RGB가 있으면 색으로 취급하고, 저장 RGB까지0인 완전 투명 픽셀만 색 없음으로 처리해 기존 그리기 색을 유지한다. Composite는 렌더러의 현재 합성 결과를 읽는다. 래스터가 없는 대상·잘못된 좌표/설정은 오류를 표시하고 색과 문서를 유지한다.

평균 범위는 캔버스 안으로 자르고 실제 포함된 픽셀 수를 사용한다. RGB-only는 숨은 RGB를 포함한 원래 RGB의 산술 평균이다. RGBA/합성색은 RGB를 알파 가중 평균하고 알파는 산술 평균해 투명색 테두리가 번지지 않는다. 전부 알파0이지만 저장 RGB가 있으면 RGB의 산술 평균을 유지한다. 반경 최대4/읽기81픽셀로 제한한다. 단일 픽셀과 평균 모드는 화면과 로컬 설정에 명시한다.

최근 색32개·샘플 모드·커널과 별도 색 Undo/Redo32단계를 작업공간 로컬 상태로 저장한다. 캔버스/참조/색 선택의 변경을 관찰해 색 이력에 기록하고 같은 색은 중복 기록하지 않는다. 색 칩 선택/Undo color choice/Redo color choice는 문서 실행 취소 밖에서 작동한다. 그림·변경 표시·레이어 픽셀·문서 이력은 스포이트나 색 이력으로 바뀌지 않는다. 재시작/작업공간 백업도 같은 상태를 복원한다. 계정/클라우드를 사용하지 않는다.

레이어/격리 폴더는 기존 paper 설정의 Hide를 통해 원본 픽셀을 보존한 채 합성에서 제외할 수 있다. 변경은 기존 Apply/Cancel/문서 이력을 따른다. Through의 자체 효과/숨김은 선택할 수 없다. 숨김이 있는 문서의 부분 굽기와 PSD Rendered layers는 원본을 잃지 않도록 거절하고 자체 문서 또는 Rendered image를 사용한다. 스포이트는 숨긴 층도 원래 값을 읽으며 합성색은 그 층을 제외한다.

검증은1픽셀 대각 계단/이진 가장자리·압력 켬/끔·두 좌표 모드·문서/프로필 재열기, 알파0/128/255의 같은 RGB에서 모드별 결과·숨은 RGB/완전 빈 픽셀·선택/종이/숨김 우회·합성 제외·평균의 독립 기대값/경계/오류, 색 이력 한도/Undo/Redo/저장, 생산 입력의 실제 캔버스 추출과 문서/변경 표시/이력 불변, 프리셋/모드/최근 색 재시작을 포함한다. 설치본도 독립 파일과 합성 입력으로 같은 검증을 실행한다. 실제 펜 검증은 대기다.
