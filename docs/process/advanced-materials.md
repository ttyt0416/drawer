# 139 — 로컬 소재 타일링·변형과 참조 선택·전체 갱신

## 진입과 확정

Layers… → Image tiling / source transform 또는 사용자 명령 material-transform은 선택한 소재/연결 파일/편집 가능한 벡터를 연다. Layer 목록에서 대상을 바꾸고 변형·타일링을 설정한 뒤 Prepare → 전후 이미지/마스크 안내 검토 → 확인 → Apply로 실행한다. 문서ID·수정본·프레임을 고정하며 옵션 변경은 준비/확인을 초기화한다. 취소/Escape·낡은 프레임은 무변경, 적용은 한 Undo다. 편집 대상의 전체/위치 잠금을 지키고 이미지의 원본 RGBA를 바꾸지 않는 매개변수 변형은 픽셀 잠금과 구별한다.

## 타일링

원본 이미지의 정수 픽셀 크기를 주기로 사용한다. 축은 None / Vertical and horizontal / Only horizontal / Only vertical이며 각 축을 독립 지정한다. Repeat는 같은 방향 반복, Reverse는 각 반복 축에서 홀수 타일만 그 축을 거울 반전, Flip은 두 타일 인덱스 합이 홀수인 타일의 두 축을 반전하여180도 회전한다. 반복하지 않는 축은 원본 밖에서 투명하다. 음수 좌표도 Euclidean 몫/나머지로 같은 주기를 유지한다. 별도의 소재 영역 밖은 항상 투명하며 원본 RGBA와 알파는 유지한다. 비트맵에 최근접 역샘플링을 사용한다.

## 변형 종류

- Scale/Rotate: 독립 X/Y 비율과 회전, 지정 피벗을 조합한다.
- Scale: 비율만 적용한다.
- Rotate: 회전만 적용한다.
- Free Transform: 두 기저 열과 이동의6개 자유 affine 수치를 적용한다.
- Skew: 가로/세로 기울기 각도를 적용한다.
- Distort: 네 모서리의 bilinear 매핑이다.
- Perspective: 네 모서리의 projective 매핑이며 직선을 유지한다.
- Mesh Transformation:2×2~5×5 제어점 격자의 셀별 bilinear 매핑이다.

좌표는 문서 픽셀, 왜곡/원근/메시 제어점은 원본 영역의 정규화 좌표다. 기본 (0,0)~(1,1)을 표시하고 모서리 교차/접힘/원근 수평선/특이 행렬/범위 밖 값은 준비 단계에서 거절한다. 피벗과 별도의 이동값을 적용하며 자유 행렬의 이동도 보존한다. 기존 소재 매핑 위에 affine 변형을 조합한다. 비선형 모드는 해당 소재 영역의 매핑을 명시적으로 교체한다. Reset mesh grid는 입력한 행/열 수에 맞는 정규 격자를 만든다.

편집 가능한 벡터는 경로점을 변형하고 Preserve editable vector stroke width로 선폭을 유지한다. 끄면 affine 행렬의 면적 배율 제곱근을 선폭에 적용한다. 비선형 편집은 선폭을 유지하며 매개변수 도형의 이미 계산된 점을 편집 가능한 polyline으로 남긴다. 비트맵/연결 이미지 캐시는 이 벡터 선폭 옵션의 대상이 아니다.

## 마스크

연결 마스크는 affine에서 자신의 좌표계가 같은 피벗/행렬을 따른다. 고정 마스크는 원래 페이지 좌표를 유지한다. 비선형에서 연결 마스크는 변형한 이미지 영역 안의 새 문서 픽셀 중심을 원래 마스크로 역샘플링하며 활성/연결/반전 상태와 회색조 강도를 유지한다. 이미지 영역 밖의 상세 마스크 데이터는 잘릴 수 있음을 전후 미리보기와 필수 확인에 명시한다. Undo가 그 영역까지 원본 전체를 복원한다. 반전 마스크의 바깥 기본 강도는 유지한다. 마스크 RLE32768개/4Mi 샘플 한도를 넘으면 거절한다.

## 참조 파일의 선택

Layers… → Refresh linked sources / linked-file-layer에서 로컬 경로와 Inspect source choices를 사용한다. .drawer는 전체 페이지, 안정ID로 선택한 레이어/폴더/개체/트랙/셀 또는 그 문서의 단일 Timeline only를 제공한다. 저장된 표시 컴프와1부터 표시하는 프레임을 함께 지정한다. 레이어 선택은 선택한 내용의 독립 결과와 자체 마스크/효과를 사용한다. PNG/JPEG/BMP는 단일 페이지, TIFF는 검증된 페이지 목록을 제공한다. 이미지 교환 입력에 존재하지 않는 레이어/컴프를 추정하지 않는다. 파일 캐시는 기존 sRGB RGBA8 스냅샷이며 원본 문서의8/16bit 편집 데이터는 원본에 남긴다.

존재하지 않는 레이어·컴프·프레임/타임라인이나 컴프의 누락 항목은 오류로 알리고 다른 항목으로 대체하지 않는다. 선택 정보는 내장된 캐시와 별도로 저장된다. 평소 그림 열기/표시/저장은 원본 파일을 다시 읽지 않으므로 삭제된 원본의 마지막 정상 결과도 재열린다.

## 전체 갱신과 파일 변경

Preview refresh all linked sources는 각 링크의 저장된 선택으로 새 결과를 먼저 만든다. 성공 목록과 실패 이유/경로를 표시하며 실패한 캐시는 그대로 남긴다. 성공한 결과 묶음은 별도 확인 체크 후 한 명령으로 적용한다. 모두 실패하면 적용할 초안을 만들지 않는다. Undo는 성공한 변경 전체와 원래 캐시/선택을 복원한다. 외부 원본을 덮어쓰지 않는다.

로컬 드라이브 경로만 받으며 자기/중첩 순환을 전체 의존 그래프에서 검사한다. 최대8단계/64파일이다. 파일 길이·수정 시각·내용 지문을 읽기 전후와 적용 직전에 확인한다. native/이미지 파서는 지문과 일치하는 캡처 바이트만 해석한다. 원본이 중간에 다른 파일로 치환되더라도 미리보기와 다른 바이트를 다시 열지 않는다. 의존 검사 중/캡처 중/미리보기 이후 변경, 누락·잘못된 형식·예산 초과는 캐시를 보존하며 새 미리보기를 요구한다. 중첩 문서의 저장된 캐시를 사용하며 중첩 링크를 몰래 갱신하지 않는다.

## 저장과 검증

자체형식v63 JSON의 선택적 material mapping과 source selection에 저장하고 기본값은 생략한다. 이미지 RGBA 페이로드와v62 정밀도 푸터는 그대로 유지한다. 이전 파일은 Repeat/매핑 없음/페이지0/컴프 없음이며 새 데이터를 이전 헤더로 위장하면 거절한다. 이미지당4Mi 픽셀·링크256·메시25점·파일64MiB·JSON4MiB와 문서/작업공간/Undo 예산을 적용한다.

비대칭2×2 RGBA 이미지로3모드×4축 조합·음수/양수 타일 경계를 독립 정수 기준과 비교한다. 왜곡/원근의 차이·정방향/역방향121개 좌표·회전/배율 뒤 실제 렌더·접힌/큰 격자 거절,8개 모드의 피벗·자유 이동·선폭·연결/고정 마스크와 저장 재열기/한 Undo를 검사한다. 참조 레이어/컴프/타임라인/프레임·TIFF 페이지, 둘 중 하나 누락한 부분 갱신·순환·읽기 중/검토 후 변경·누락 선택·오래된 헤더를 검증한다. 실제 Inspect/New/Refresh all/확인/Apply와 변형8모드의 Preview/확인/Apply, 확인 우회 거절·프레임 변경·Escape도 실행한다.
