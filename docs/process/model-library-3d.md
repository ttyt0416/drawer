# 로컬 모델·도형·배치/복제/정렬 (214)

`model-library`에서 독자 Box/Plane/Sphere/Cylinder/Cone/Chair/Room과 로컬 다각형 OBJ를 준비한다. 둥근 도형의 분할3..64, 중심 위치/회전/양수·음수 축척과 최대 변 길이 맞춤, 숨김 배치를 선택한다. 입력 조작은 문서를 바꾸지 않는다. 백그라운드 준비가 끝나면213의3D 창에서 미리 보고 한 Apply/Undo로 채택한다. 원래 OBJ/MTL/텍스처 파일을 고치지 않고 다운로드하지 않는다.

## 도형과 가져오기

도형은 이 저장소의 독립 수치/기하로 생성한다. 의자와 방은 직접 배치한 직육면체의 합성이다. 다각형의 면/모서리, 구의 법선을 함께 생성한다. 큰 메시의 픽셀 판정은 기존 경계 계층으로 가까운 투영 선분만 찾고, 직접 전체 선을 검사한 결과와 대조한다. 출력 스타일은 현재의 공통 와이어프레임이며 면/UV/법선/재질 배정은 후속 표면 도구에서도 사용할 수 있도록 문서에 보존한다.

지원하는 OBJ 부분은 UTF-8/ASCII의 v/vt/vn, f, l, o, s, mtllib/usemtl이다. 양수1 기반·음수 상대 인덱스와 서로 독립적인 UV/법선 인덱스, 논리 줄 이어쓰기를 처리한다. 오목한 평면 다각형도 교차/평면 검사를 거쳐 ear clipping으로 삼각 분할하며 와이어는 원래 다각형 외곽만 유지한다. o별로 개체를 나누고 전역 위치 관계를 보존한다. g는 개체 안에서 합치며 이를 안내한다. 비평면/교차/퇴화 면·0/범위 밖 인덱스·0 법선·비유한 좌표를 거절한다. 실행 문장/재귀 include는 실행하지 않고 거절한다. 알 수 없는 문장은 목록으로 안내하고 검토 후 지원된 형상만 채택할 수 있다.

로컬 MTL의 이름·RGB Kd·d/Tr·기본 map_Kd 참조를 읽는다. 사용하지 않는 재질 속성과 텍스처 옵션은 적용하지 않는 항목으로 표시한다. 텍스처 파일의 존재를 확인하지만 이번 와이어프레임 출력에 텍스처 이미지를 붙이지 않는다. 면의 재질 번호·색/투명도와 상대 텍스처 참조를 보존하고 와이어는 첫 면의 재질 색을 사용한다. 재질/텍스처 누락·미지원 데이터가 있으면 목록과 체크박스를 확인해야 Apply가 가능하다. 누락 참조의 상태는 가져온 시점의 기록이다. 모든 OBJ/MTL 속성이나 glTF/GLB 지원을 주장하지 않으며 그 검증 범위는 기능221에서 확장한다.

공개 문법 근거: [Wavefront 원문 Appendix B1](https://www.martinreddy.net/gfx/3d/OBJ.spec), [미국 의회도서관 OBJ 기록](https://www.loc.gov/preservation/digital/formats/fdd/fdd000507.shtml), [MTL 기록](https://www.loc.gov/preservation/digital/formats/fdd/fdd000508.shtml). 저장/검증·좌표/기하·경로 정책과 구현/시험 데이터는 이 프로젝트에서 별도로 작성했다. 원문 예제 메시나 구현 코드를 복사하지 않았다.

## 위치·복제·정렬과 수명

맞춤은 원본 전체 경계의 최대 변에 대한 균일 배율이다. 전체 경계 중심을 지정 위치로 옮기고 개체 사이의 원래 간격을 유지한다. 각 개체의 중심 피벗·개체 기저와 표면 속성을 함께 저장한다. 원본 단위에서 계산된 맞춤 비율은0.0001..10000이며 범위를 넘으면 단위를 조정하거나 맞춤을 끈다. 축척0은 거절하고 반전을 위한 음수는 허용한다.

미리보기/복제/정렬 버튼은 창 상단에 고정하고 입력 설정만 따로 스크롤한다. 복제는 선택된 부모 트리의 모든 개체를 한 번씩 복사한다. 원본을 유지하며 새 ID/독립 표면 배열·복제 부모 연결과 지정 월드 오프셋을 준다. 정렬은 X/Y/Z의 최소/중앙/최대 경계를 첫 선택 트리 또는 전체 선택 경계에 맞춘다. 부모·자식을 같이 선택해도 중복 이동하지 않고 첫 선택에 속한 트리의 순서를 유지한다. 잠김/숨김/위치 잠김/픽셀 잠김 하위 개체와 대체 파일 개체는 먼저 해제/분리하도록 안내한다. 단일 트리의 이미 맞은 정렬은 이력을 추가하지 않는다.

3D 초안과 새 모델 작업은 서로 덮지 않는다. 이전 미리보기를 적용/취소해야 새 준비를 시작한다. 작업 중 취소·문서 편집/닫기·다른 문서로의 결과 적용을 거절하고 개인 사본/작업자를 정리한다. 경고 확인 상태는 준비 결과마다 초기화한다. 문서를 변경하지 않는 설정은 Undo/dirty를 바꾸지 않는다.

## 저장·한도와 검증

native108은 삼각형/원래 외곽·UV/법선·재질/스무딩 번호·참조 기록을 저장한다.107 이하 위장 파일은 거절하고107의 기존3D 정의는 기본 표면 없이 읽는다. 기존 이동/복제·부모 삭제가 표면을 함께 유지/정리한다. 문서256개체·개체별65536정점/모서리·UV/법선65536·삼각형131072·다각형256꼭짓점·원본8MiB/논리줄16KiB·재질256·참조128과 문서/Undo·장면 메타데이터4MiB·작업 기하524288 한도를 적용한다. 재질 파일은1MiB다. 모델 사본의3배와 생성 기하·토폴로지 예상량을 함께 사전 점검하고 준비 결과도 가용 예산에 대조한다. 원본/재질 읽기는 남은 예산의1/32로 제한하고 참조 배열 복제 전에도 누적량을 검사한다. 상대 경로를 정규화하고 모델 폴더 밖/원격 경로와 링크 탈출을 거절한다.
