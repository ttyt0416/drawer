# 112 — 대상색·연결성·중심선·출력 프레임 채우기

기존 MatchSeed를 기본으로 유지하고 AllColors, Transparent, OtherThanTransparent, SurroundedByTransparent, Black, OtherThanBlack, SurroundedByBlack, WhiteAndTransparent, OtherThanWhiteAndTransparent, SurroundedByWhiteAndTransparent, AllEnclosedExceptTransparency, AllEnclosedIncludingTransparency를 제공한다. 각 옵션은 로컬 도구/브러시 프리셋에 저장된다.

알파 허용치 이하를 투명으로 분류한다. 별도 semi-transparent 옵션을 켜면 알파255 미만도 투명으로 분류하며 대상 모드와 독립이다. 검정/흰색은 RGB 각 채널의 색차 허용치를 적용한다. MatchSeed는 기존의 독립 알파/RGB 비교다. SurroundedBy 모드는 해당 경계색의 반대쪽4방향 연결 성분 중 활성 경계에 닿지 않는 것을 선택한다. AllEnclosed는 검정 경계로 둘러싸인 성분을 선택하고 ExceptTransparency는 그 안의 투명 픽셀만 쓰기에서 추가 제외한다. 연결만은 클릭 성분, 전체는 같은 판정의 분리 성분 모두다. 대각 접점은4방향 연결에 포함하지 않는다.

제외색은 알파가 있는 픽셀의 RGB 최대 채널 차이가 지정0–255 허용치 이하일 때 쓰기에서 제외한다. 발견/연결성은 끊지 않고 알파 차이와 숨은 RGB는 비교하지 않는다. 윤곽 포함은 지정1–32픽셀 아래 칠하기를 기존 확장 형태와 결합한다. AA/확장/아래 칠하기 뒤에도 제외색과 출력 프레임을 다시 제한하고 선택 강도를 한 번 곱한다.

벡터 중심선 참조를 켜면 합성/표시/선택/폴더 참조의 벡터를 문서 좌표의 폭1 중심선으로 판정한다. 실제 표시·선폭·내보내기 픽셀과 경로는 바꾸지 않는다. 현재/특정 래스터 참조에는 벡터를 추가하지 않는다.

Canvas / AnimationFrame을 경계로 선택한다. 프레임 밖은 발견/AA/확장의 닫힌 장벽이다. 애니메이션 출력 프레임은 문서v42에 원래 페이지 좌표계와 생성 좌표계를 저장하고 활성 시간에서 이전 키를 유지한다. 페이지 회전/배율을 따라가며 파랑 윤곽으로 표시한다. 설정 창의 적용은 한 Undo이며 취소/오래된 문서·프레임은 무변경이다. 애니메이션이 없으면24fps의 빈 로컬 타임라인과 출력 프레임을 함께 만들 수 있다. 이 항목의 프레임은 채우기 참조 경계다.

독립 검증은13모드×반투명 스위치의26개 예상 픽셀 수, 분리/대각 연결, 열린 변/대각 모서리, 프레임 밖 열린 선과 씨앗 거절·프레임 키 유지/전환·페이지 변환·문서 재열기, 제외색 허용치 경계와 알파 독립, 굵은 벡터 외곽/중심선 차이와 표시 불변, 윤곽 포함/부분128 선택/원본 보존·한 Undo와 도구 프리셋 재열기를 포함한다. 생산 검증은 실제 출력 프레임 적용/빈 타임라인 생성/Undo·닫기/오래된 상태,90도·확대4 프레임 내부10픽셀 채우기와 마우스/가상 펜의 외곽/중심선×128 선택 조합이다.

4Mi픽셀·24바이트/픽셀 작업 예산 사전 검사, 기존 표본/벡터 참조64Mi 비용, 문서/작업공간/JSON4MiB/Undo 제한을 공유한다. 외부 서비스나 실행 중 다운로드는 사용하지 않는다.
