# 로컬 브러시 프리셋과 빠른 크기

기능058. 자체 JSON v1은 이름·기본 팁 종류·일곱 수치·필압 매핑/응답·기하 시작/끝·마우스 동작/곡선/시드를 저장한다. 현재 팁/연필 질감은 실행 파일의 독자 절차적 정의이므로 같은 버전의 내장 참조를 함께 기록한다. 알 수 없거나 서로 다른 팁/질감 참조는 대체하지 않고 오류로 거절해 기존 설정을 보존한다. 외부 서버·계정·소재 다운로드를 사용하지 않는다. 크기 표시 단위/속성 표시 방식·색·다른 브러시는 프리셋 복원으로 바꾸지 않는다.

이름은 공백 제거 후1~64문자이며 제어문자를 거절한다. 이름은 파일 경로로 사용하지 않는다. 대소문자 중복을 감지하고 명시적으로 확인한 교체만 기존 슬롯을 바꾼다. 한 모음128개, 빠른 크기128개. 파일 읽기는 일반 파일에서 최대64KiB+1만 읽고 초과/손상/비유한 값/누락 의존성을 거절한다. 내보내기는 같은 폴더에 create_new 임시 파일→전체 쓰기/동기화→게시다. 신규 파일은 하드 링크로 게시해 중간에 생긴 파일을 덮어쓰지 않는다. 기존 파일은 사용자 확인 후 이름 교체한다. 다른 작업의 기존 임시 파일은 건드리지 않는다.

모음과 크기 순서는 로컬 작업공간 설정에 저장한다. 선택 복원/추가/삭제/정렬은 임시본에서 편집하고 Apply에서 전체 검증·적용 전 백업·설정 저장을 수행한다. Cancel은 기존 설정/그림을 보존한다. 파일 내보내기는 사용자가 요청한 독립 작업이다. 파일 읽기/복원 실패도 기존 설정과 그림 이력을 보존한다. 설정 창이 열리면 키보드·정렬 캔버스·분리 패널·시험 칠하기 입력을 차단한다.

빠른 크기는 .1~4096px의 현재 크기만 바꾸고 다른 속성/필압/혼색·색/보기/문서 이력을 유지한다. 같은 값은 변경으로 보고하지 않고 목록 중복은 재사용한다. 목록 정렬/삭제는 임시본 적용/취소/적용 전 백업으로 복원한다. 현재 도구의 Size slider 표시 상태는 기존 도구 속성의 Control로 저장한다. 이동·스포이트는 크기 적용을 거절한다. 구형 작업공간에 모음 필드가 없으면 독자 기본 목록을 사용한다.
