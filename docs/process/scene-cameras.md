# 장면 카메라와 보기 가림

`scene-cameras`는 문서의 카메라 목록·투영·프레이밍을 편집한다. Initialize list는 현재 장면 카메라를 보존한다. Create from draft는 현재 초안, Duplicate active는 확정된 활성 카메라의 독립 복사본을 만들며 Switch가 실제 출력 카메라를 바꾼다. 최대32개이고 마지막 한 개의 삭제를 거절한다. 활성 카메라 삭제는 다른 유효 카메라를 복원한다. 이름·카메라·투영·렌즈 시프트·수직 모드와 활성ID는 native116에 저장하고 각각 한 Undo로 복원한다. 다른3D 창에서 현재 카메라를 바꿔도 현재 장면 값이 활성 카메라의 단일 원본이다.

Lens shift X/Y는 페이지 폭/높이의 비율이다. 양수 X는 오른쪽, 양수 Y는 아래로 프레이밍을 옮긴다. 범위±4, 유한 값만 허용한다. 원근/평행투영·선/면·환경 배경·UV 광선·카메라 영역 가이드가 동일한 투영/역광선을 사용한다. 2D 카메라는 이후의 기존 합성 단계다.

Level verticals는 카메라 위치/방향의 yaw를 유지하고 pitch/roll을0으로 세운 뒤, 선택 목표점의 기존 화면 위치를 렌즈 시프트로 유지한다. 수직 모드에서는 pitch/roll을 잠그고 목표 세계점/화면 앵커/기준 시프트를 저장한다. yaw·위치·FOV·투영을 바꾸면 목표의 화면 위치를 계속 유지하며 수동 시프트는 그 앵커를 상대 이동한다. Fit은 선택 바운딩박스 중심으로 목표/앵커를 다시 설정한다. Release는 잠금만 해제하며 원래 카메라는 Undo로 복원한다. 위/아래 정면처럼 수평 카메라 앞에 목표가 없거나 필요한 시프트가 범위를 넘으면 원래 초안을 보존하고 오류를 표시한다. 다중 보기의 표준 방향 선택은 자유 모드/시프트0으로 초기화한다.

Fit은 선택 개체의 현재 포즈를 평가한 바운딩박스를 카메라 축에서 계산한다. 한쪽당2..40% 여백으로 원근 거리 또는 평행 스케일/위치를 맞추고 실제 깊이 범위가 near/far 안에 있도록 재설정한다. 렌즈 시프트를 보상해 대상을 중심에 유지한다. 점/평면은 작은 유효 폭으로 처리한다. 빈/삭제된 선택·잘못된 여백·카메라 위치/클리핑/메모리 범위 초과·취소는 적용하지 않는다.

편집 초안과128픽셀 미리보기는 확정 전 문서를 바꾸지 않는다. 준비는 취소 가능한 작업자가 수행하고 Apply/Cancel·한 Undo·편집 범위 이력 이름을 제공한다. 설정/선택·문서/리비전/프레임·Esc·포커스·창/문서 닫기는 오래된 작업과 결과를 취소/합류한다. 다른3D 편집 초안이 있으면 먼저 적용/취소해야 한다.

`world-views`의 Hide geometry in front of reference plane은 선택 보기의 기준 세계점보다 카메라에 가까운 부분을 잘라 뒤를 확인한다. 평면은 매번 카메라 방향에 수직이며 카메라 회전 시 재계산한다. 걸친 물체는 실제 광선/선분의 깊이 범위로 잘라 일부만 남긴다. 절단면을 새 면으로 막지 않는다. 기준이 원래 near보다 앞이면 기존 near를 유지하며 far 이후이면 모든 형상을 숨기고 환경 배경은 유지한다. 조명/그림자는 원래 장면을 참조한다. 전체 래스터 병합은 카메라 목록/포즈/환경을 함께 굽고 메타데이터를 제거하며 Undo로 복원한다.

기준점·켜짐은 보기별 작업공간 값으로 저장한다. 카메라 연결 상태에서도 각 보기의 절단 설정은 독립이다. Undo view/Redo view로 복원하고 문서의 형상·카메라·이력·기본 출력은 유지한다. Copy view to scene은 투영/프레이밍만 복사하며 가림 평면은 복사하지 않는다. 이전 작업공간 파일은 가림 끔으로 읽는다. 원본 바이너리/소재·네트워크·실물 펜 검증을 사용하지 않는다.
