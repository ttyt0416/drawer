# 같은3D 장면의 편집 카메라 보기 (222)

`world-views`는 한 문서의 확정된3D 장면을2개 또는4개의 편집 카메라로 보여 준다. 모델/재질/조명/숨김·레이어 표시와 현재 프레임을 같은 문서에서 읽고 변경 후 모든 보기를 갱신한다. 각 보기는 기존 렌더러의3D 기여만 합성하며 그림의2D 래스터/텍스트를 중복 표시하지 않는다. 다른3D 창의 미확정 초안은 Apply 이후에 공유한다. 보기 자체는 모델과 문서 이력을 바꾸지 않는다.

패널을 클릭해 편집 대상을 선택하고 Position/Rotation/FOV·평행투영 배율을 조절한다. Perspective/Front/Back/Left/Right/Top/Bottom은 대상 모델 경계 중심을 보며 원근 또는 정투영 방향으로 카메라를 배치한다. Orbit +15°와 Pan right는 마우스 버튼으로도 검증 가능한 이동이다. 방향 변경은 모델을 회전하지 않는다. 독립 모드에서는 선택 카메라만 변경한다. Link reference의 View 번호를 명시하고 Link all을 누르면 해당 카메라를4개 슬롯에 복사하고 이후 편집을 계속 동기화한다. Make cameras independent는 현재 위치를 유지한 채 동기화만 해제한다.

Copy selected view to scene camera는 선택 카메라를 문서 장면 카메라에 한 번 복사하며 한 Undo/Redo를 만든다. 다른3D/콘텐츠 초안이 있으면 적용/폐기 후 수행한다. Copy scene camera to selected view once는 편집 보기만 바꾸고 문서 이력을 만들지 않는다. 두 버튼은 지속적인 장면 카메라 연결을 시작하지 않는다. 이미 편집 보기끼리 연결되어 있으면 복사/방향 이동도 그 연결 규칙을 따른다. Undo view/Redo view는 최근32개 작업공간 변경을 복원하고 문서 Undo와 독립이다.

Scene camera / area guides는 실제 문서 카메라의 위치/가시 사각뿔을 선택 편집 카메라에서 투영한다. Face-edge guides는 모델의 저장된 메시 변 경계를 덧그린다. 이 가이드는 UI 오버레이이며 내보낸 그림과 미리보기 픽셀에 들어가지 않는다.2/4 분할과0.2..0.8 좌우 비율을 조절하고 Reset split layout은2개/반반/첫 보기 선택으로 복원한다. 카메라 값과 모델은 유지한다. 장면이 비어 있으면 투명한 빈 보기이고 카메라와 가이드 설정은 사용할 수 있다.

Save local view workspace는4개 카메라·선택/연결 기준·분할/가이드 값을 로컬 `settings/world-views.json`에 저장한다. 이전/손상본 백업을 보존하고 잘못된 수치/형식·쓰기 실패는 기존 파일을 유지한다. 재시작 시 같은 설정을 복원한다. 이 작업공간 카메라들은 다른 문서를 열어도 유지되며 Copy scene camera 버튼으로 해당 문서의 카메라를 명시적으로 가져올 수 있다. 문서에는 기존 장면 카메라와 모델만 저장되므로 형식은 native113을 유지한다.

각 보기는 긴 변128픽셀의 축소 렌더를 작업자에서 생성하고 원본/리비전/프레임/보기 설정이 바뀌면 오래된 결과를 버린다. 렌더 중 이전 이미지가 남아 있으면 갱신 상태를 표시한다. 창·문서 닫기/Esc는 작업자를 취소·합류하고 이미지를 정리한다. 최대4개·미리보기 픽셀×개체3200만 회·변 가이드65536개/장면·사본/가속/가이드 메모리 예산을 검사한다. 한계 초과는 안내하며 예산 내 설정으로 바꿔 다시 계산한다. 이는 축소 편집 보기이며 전체 해상도 내보내기는 기존 문서 출력 기능을 사용한다.
