# 299. 장치 분리·재연결·절전 복귀

상태: **실물 시험 대기**. 사용자의 펜 실물 검증 보류 지시를 유지한다. 이 문서와 빈 JSON 양식은 실행 결과가 아니며 완료 근거로 사용하지 않는다.

현재 배포 실행 파일의 해시와 Native 형식은 양식의 referenceBuild에 기록했다. 실제 시험 시 사용한 빌드·장치·드라이버·OS·모니터·도구 설정을 다시 확인해 기록한다. 물리 픽셀·논리 좌표·문서 픽셀과 원시 입력·앱 계산·화면 표시의 측정값을 구분한다.

원본을 유지하는 새 로컬 시험 문서와 별도 저장 경로를 사용하고, 데이터 수집 방법과 관측 가능한 항목부터 정한다. 수집하지 못한 값은 미측정으로 남긴다. 단위 시험이나 합성 이벤트의 수치를 실물 값으로 옮겨 적지 않는다.

1. **disconnect-during-stroke** — 획 도중 실제 장치를 분리하고 미확정 획이 시작 전으로 복원되며 새 이력을 만들지 않는지 확인한다.
2. **disconnect-held-button** — 펜/버튼을 누른 상태의 분리에서 접촉·버튼·누른 키 상태가 남지 않는지 기록한다.
3. **reconnect-fresh-press** — 재연결 후 누른 채 이동은 새 획이 되지 않고 들어 올린 뒤 새 누름으로 정상 시작하는지 확인한다.
4. **suspend-resume** — 실제 절전/복귀의 시간과 상태를 기록하고 미확정 획·입력 컨텍스트·복귀 후 첫 획을 확인한다.
5. **multiple-devices** — 서로 다른 장치와 실제 마우스를 전환해 소유권·중복 입력 억제·설정 분리를 확인한다.
6. **documents-preserved** — 분리/복귀 전후 저장 문서·미저장 복구본·도구·팝업 시험 칠하기·로컬 설정 보존을 비교한다.

289번의 합성 Cancel/포커스 이벤트와 293번의 프로세스 강제 종료는 실제 USB/무선 분리·드라이버 재초기화·절전 복귀의 대체가 아니다. 환경 설정을 바꾸거나 절전을 실행하는 실제 조작은 이번 작업에서 하지 않았다.

기록 양식: [physical-299-template.json](physical-299-template.json). 모든 사례는 not_run이고 수치·장치명·시각·결과는 비워 두었다.

완료 판정은 실제 시행 자료를 연결한 뒤 한다. 각 사례의 관측값·기대값·오차/실패와 해당 빌드·환경을 남기고, 미지원 속성은 지원 여부와 안내를 명시한다. 저장 전후 문서와 필요한 영상/이벤트 기록의 로컬 경로·해시를 보존한다. 필수 사례의 실제 결과가 없으면 체크리스트를 체크하지 않는다.
