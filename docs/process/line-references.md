# 081 — 참조 경계·벡터 자석·교차점 지우기

독립 설계이며 원본 프로그램 코드·파일·리소스를 포함하지 않는다. 완전 로컬 동작이다.

## 편집과 저장

Keyboard editing / All tools and commands의 Line references and vector layers에서 벡터층을 추가하고 문서 픽셀 좌표의 폴리라인/닫힌 경로를 입력한다. 자석을 먼저 적용한 뒤 페이지 원본 좌표로 저장한다. 벡터층은 래스터 합성 위, 페이지 개체 뒤에 표시한다. 경로 삭제·이름·잠금·숨김과 참조 설정은 초안으로 편집하고 Apply로 한 문서 이력에 확정한다. Cancel/창 닫기/Esc는 초안을 버린다. 편집 중 문서·리비전이 바뀌면 오래된 초안을 거부한다.

문서v30은 벡터층·경로의 재사용하지 않는 ID, 옵션과 참조 목록을 저장한다. 이전 문서의 누락 lines는 빈 기본값이다. 벡터는 기존 페이지 변환을 따라 크기 변경/회전·자르기와 출력에 반영된다. 래스터 참조는 문서 레이어 인덱스다. PSD 편집 레이어 내보내기는 벡터가 있으면 거부하며, 렌더링 이미지로 내보내기를 사용한다.

한 문서에 벡터층32, 경로128, 합계8192정점, 경로당4096정점, 너비0.1–512 원본px를 허용한다. 좌표는 유한 ±1e9이고 변환 후 ±1e12를 넘지 않는다. 메모리·교차점·작업량 한계를 넘는 명령은 원본을 보존한다.

## 참조와 채색

Boundary/magnet, Intersections, Erase 세 목록은 독립이다. 잠긴 참조는 읽기 전용으로 사용할 수 있다. 숨긴 참조는 무시하고 누락·미지원 참조는 실행 시 오류다. 자석은 선택한 벡터 참조층의 경로에만 가장 가까운 선분 투영으로 흡착한다. 거리0–1024는 변환된 문서px이며 화면 확대/회전/미러와 독립이다.

선택한 래스터의 `(255 − 정수휘도) × alpha / 255`가 문턱1–255 이상이면 장벽이다. 숨긴 부모 폴더도 판정한다. 흰 배경은 장벽이 아니다. 벡터는 표시 경로의 변환된 두께를 보수적으로 적용하고 최소 반대각선0.707px로 얇은 선의 격자 누수를 막는다. 시작점에서 네 방향으로 연결된 공간을 계산하며 캔버스 가장자리에 닿으면 열린 경계로 거부한다. 참조선 위·바깥 시작도 거부한다.

Apply and pick fill point는 주 탭 캔버스를 클릭해 선택한 래스터층에 전경 RGBA를 source-over로 채운다. X,Y 직접 실행도 제공한다. 기존 선택/배치 레이어 저장 범위를 함께 적용하며 참조층을 바꾸지 않는다. Restrict brush coloring을 켜면 첫 입력에서 같은 닫힌 영역을 동결해 모든 도장·혼색 샘플·확산·종료 경계에 적용한다. 지우개는 이 채색 제한에서 제외한다. Esc/초점 상실로 위치 선택을 취소한다. 펜 센서 실물 검증은 대기한다.

영역 계산은 캔버스4M픽셀·64M 참조 작업 이내, 명령은 문서256MiB/Undo64MiB 제한을 적용한다. 미리보기 재계산은 동일 문서와 첫 점에서 같은 영역을 만든다.

## 여러 층 지우기

실제 Erase 목록을 먼저 전부 검사한다. 숨김·잠금·누락·애니메이션/페이지 객체 등 미지원 대상은 사전 목록에 표시하고 선택되어 있으면 전체 명령을 거부한다. 래스터는 문서px 반경의 원 안에서 선택 마스크만큼 알파를 지우며 숨은RGB는 유지한다. 벡터는 지점 가까운 경로에서 별도로 선택한 Intersections 참조와 만나는 두 점 사이를 제거하고 나머지를 편집 가능한 열린 경로로 보존한다. 열린 경로의 끝도 구간 경계이며 교차점이 없으면 그 경로를 제거한다. 닫힌 경로는 처음/끝을 순환해서 처리한다. 평행·동일선 중첩은 교차점으로 세지 않는다. 래스터 선택이 있을 때 벡터 지우기는 사전 거부한다.

교차점은 명령 전 참조 경로로 계산한다. 참조만 선택한 층과 같은 위치의 선택하지 않은 숨김/잠금층은 변경하지 않는다. 여러 래스터 픽셀 차이와 모든 벡터 변경을 검증한 뒤 단일 이력으로 동시에 적용한다. 마지막 대상에서 경로/메모리 한계 오류가 나도 앞서 계산한 픽셀은 적용하지 않는다. Undo/Redo 한 번이 전체를 복원한다. 교차점 수는 경로당32768, 명령 작업64M 이내다.

## 검증

자체 생성 사각형·교차선·동위치 숨김/잠금/다른 벡터·두 래스터로 참조 보존과 교차 구간 양 끝을 비교한다. 열린/닫힌 벡터·래스터 경계, 선택 마스크, 부모 숨김, 자석 문서 거리/페이지 배율, 닫힌 경로 순환 절단, 두 벡터 동시 복원, 사전 오류와 마지막 경로 한계 오류의 원자성, 문서 왕복과 구형 기본값을 확인한다. 실제 앱 입력 루프에서 확대/회전/미러 보기의 채색 위치 선택·초안 Cancel 버튼·브러시 경계 제한을 시험한다. 설치 실행 파일도 같은 검증을 수행한다.
