# 톤·회색·먼지와 투명 틈 (173)

모든 처리는 로컬의 불변 래스터 스냅샷에서 계산한다. 원본4M픽셀/32MiB, 실제 이웃 수와 선택 래스터화의64M 계산, 문서/Undo/작업 메모리 한도를 사전 검사한다. 후보 판별·표본 계산·선택 래스터화 도중 취소할 수 있다. 새 외부 라이브러리나 모델·클라우드 경로는 없다.

## 픽셀 필터

`remove-tone`은 반경0~8의 알파 가중 RGB 평균, 강도0~1, 명도 연속선 허용차0~1을 사용한다. 어두운 중심에서 한 방향의 반대 표본이 이어지는 가는 선을 보호하고 반복 점망은 공간 평균한다. 대각 방향도 검사한다. 문서 경계에 닿은 선의 안쪽 연속성도 보호한다. 기본은 원래 알파를 유지한다. Also average transparent tone coverage를 켜면 투명 점망의 알파도 이웃 전체에 평균하여 점 사이로 분포시킨다. 숨은 색은 가중치0으로 배제하며 입력 없는 완전 투명 표본은 보존한다. 투명도 잠금은 이 옵션보다 우선해 원래 알파를 유지한다. 점망 이전 원본이나 인쇄 톤의 주파수를 복원한다고 주장하지 않는 독립 휴리스틱이다. 미세 선/질감을 보존할 필요가 있으면 선택 범위와 반경/강도를 조절한다.

`grayscale-filter`는 작업 RGB의 0.2126R+0.7152G+0.0722B를 세 채널에 쓴다. 원래8/16비트 정수 알파와 완전 투명 픽셀의 숨은 색을 유지한다. 문서의 색 프로파일이나 표현 모드를 변경하지 않는다.

`cleanup-dust`의 네 모드는 다음과 같다.

| 모드 | 입력 판별 | 수정 결과 |
|---|---|---|
| Remove dust from transparency | 알파>0이고 최소 먼지 불투명도 이상인 성분 | 해당 점을 투명하게 제거 |
| Remove dust from white background | 흰 배경에 합성했을 때 최소 대비 이상인 성분, 실제 주변은 충분히 불투명한 흰색 | 원래 알파를 보존한 흰색 |
| Fill transparent gaps with surrounding color | 최대 틈 불투명도보다 낮은 성분 | 주변 경계 표본의 알파 가중 RGB와 평균 알파 |
| Fill transparent gaps with foreground color | 위와 같은 틈 성분 | 저장한 전경 RGBA |

대각선을 포함한8연결 성분을 판별한다. 대각 선을 개별 먼지 점으로 나누지 않는다. 문서나 원본 저장 영역 경계에 닿은 성분은 보호한다. 연결 크기0~4096 중 최대 크기 이하만 대상으로 하며0은 픽셀 수정 없음이다. 최대값은 긴 선도 대상으로 삼을 수 있으므로 후보 지도와 선택 범위를 확인한다. 흰 바탕 모드는 투명 바탕의 점에 흰색을 새로 만들지 않는다. 틈은 반투명 표본도 포함할 수 있고, 경계에 열린 투명 영역은 구멍으로 채우지 않는다.

배경/전경은 픽셀값으로 명시하며 검정 배경이라는 모호한 분류를 쓰지 않는다. 전경색은 창을 열 때 현재 색을 캡처한다. 저장한 프리셋은 캡처한 RGBA를 그대로 복원하며 Use current foreground color로 현재 색을 다시 캡처한다. 알파를 바꾸는 제거/채움에는 투명도 잠금을 먼저 해제해야 한다. 흰색 먼지 수정과 색 필터는 정수 알파를 보존한다.

선택이 있으면 문서와 선택의 교집합 안에만 출력한다. 빈/문서 밖 선택은 픽셀을 바꾸지 않는다. 입력 연결 성분을 선택 경계에서 자르지 않으므로, 큰 성분의 일부만 선택해도 작은 먼지로 오판하지 않는다. 부분 선택은 해당 부분에만 결과를 적용한다. 선택 밖 원본의 숨은 색과16비트 값을 유지한다.

## 선택 전용 도구

`select-dust-transparency`, `select-dust-white`, `select-transparent-hole`은 픽셀 필터와 별도 명령이다. 위와 같은 성분 판별로 교체 선택을 만들고 픽셀 층은 그대로 둔다. 원래 선택과 문서 안으로 제한한 후보를 보존된 페이지 좌표로 래스터화한다. 원래 페이지 변환을 변경하지 않는다. 빨간 후보 지도는 선택 결과를 표시한다. 선택 전용 도구는 잠긴 래스터도 읽을 수 있으며 픽셀 일괄 적용 작업에는 허용하지 않는다.

## 미리보기·저장

먼지/틈/톤/회색 및 선택 전용 창은 처음 열 때 미리보기를 준비한다. 모드·크기·색·허용차가 실제로 바뀌면 이전 작업을 취소하고 최신 설정의 미리보기를 준비한다. 동일한 값의 재선택이나 단순 화면 갱신은 이미 준비한 결과를 재계산하지 않는다. 다른 일반 필터의 명시적 미리보기 경로도 유지한다. 오래된 원본/설정/프레임 결과는 적용할 수 없다. 계산 실패를 같은 값으로 무한 재시도하지 않는다.

취소/닫기는 원본/Undo를 유지한다. 미확정 저장은 기존 확정/취소/계속 편집 절차를 사용한다. 최종 Apply 한 번만 Undo에 추가한다. 픽셀과 선택 결과, 마지막 실제 설정은 네이티브v84에, 사용자 프리셋은 로컬 workspace에 저장한다. 이전 버전 헤더 위장과 잘못된 수치/열거형을 거절한다.

검증은 크기1/2 경계의 점, 수직/대각 연속선, 흰 테두리, 투명/반투명 구멍, 열린 경계, 부분/빈/문서 밖 선택, 점망 평균/회색 명도, 선택 도구의 픽셀 불변,16비트 알파1/선택 밖 원본, 취소/단일 Undo/Redo, 네이티브/로컬 프리셋 재열기를 포함한다. 앱 경로에서는 자동 갱신·동일값 계산 생략·픽셀/선택 Apply·취소·미확정 저장을 확인한다. 물리 펜 검증은 대기 상태다.
