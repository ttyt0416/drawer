# 146 — 로컬 SVG 가져오기·내보내기와 변환 안내

SVG 창에서 로컬 UTF-8 파일을 읽거나 SVG 텍스트를 붙여넣고 전후 미리보기 뒤 한 Undo로 가져온다. XML/변환/문서 한도 오류는 원본 페이지에 일부 개체를 남기지 않는다. 원본 SVG 파일과 참조 이미지 파일을 수정하지 않는다. 가져온 결과는 자체 문서에 포함되므로 원본 파일을 다시 읽어야만 표시되는 연결 자료가 아니다.

경로의 상대/절대 명령, 선·사각형·원·타원·다각형, SVG 단위와 viewBox 및 중첩 affine 변환을 정규화한다. 곡선은 문서 픽셀에서 제어 다각형 오차0.02를 기준으로 분할한 편집 가능한 윤곽이다. 원래 SVG 베지어 명령/핸들 형식을 유지하는 방식은 아니다. SVG 획은 cap/join/dash를 적용한 채움 윤곽으로 바꾸며 원래 중심선의 선폭 속성은 굳어진다. 윤곽 제어점 편집과 전체 변형은 가능하고 이 변환은 항목별로 알린다.

단색 채움, nonzero/evenodd와 여러 하위 경로의 구멍을 유지한다. 하위 경로는 왕복 연결선을 사용해 같은 winding 결과를 가진 단일 편집 윤곽으로 보존한다. 선형/방사형 그라데이션의 좌표 프레임·정지점·투명도·반복/반사와 clip의 합집합/교집합은 자체 수치 자료다. SVG의 색과 알파는 각각 보간한다. 전체 affine 이동/변형은 paint/clip 프레임도 함께 옮긴다. 점을 개별 편집하면 paint의 저장된 사용자 좌표는 유지된다. 벡터 색 변경은 가져온 그라데이션을 단색으로 바꾼다. SVG paint/clip의 비선형 변형은 먼저 래스터화하도록 안내한다.

정적 PNG/JPEG는 선택한 SVG 폴더 아래의 실제 파일 또는 data URI로 제한한다. 정규 경로 검사로 상위 경로·절대 경로·다른 폴더·URL을 거절한다. 클립보드/텍스트 원본에는 로컬 폴더가 없다. 이미지는 읽은 시점의 RGBA로 고정하며 문서 색 공간으로 변환한 래스터층에 보존한다. SVG 순서는 벡터 구간 사이의 래스터 배치 정보로 유지하고 기존 페이지의 벡터 영역 위에 삽입한다. 기존 3D 영역 등 앱의 다른 합성 영역 순서는 바꾸지 않는다.

텍스트·스크립트·foreignObject·use·pattern은 항목별 안내와 함께 제외한다. 외부 폰트나 네트워크 자원을 가져오지 않는다. opacity/isolation/mask/filter 같은 그룹 효과는 제한된 크기의 포함 래스터로 바꾸고 원래 하위 기하를 유지하지 못함을 알린다. SVG 표준 blend는 앱의 해당 합성 모드에 연결한다. 지원 목록 밖의 복잡한 자료를 조용히 완전한 SVG 편집 자료라고 취급하지 않는다.

내보내기는 일반 중심선·단색 채움과 SVG paint/clip을 경로로 작성한다. 가변 폭·사각/마름모/납작한 팁은 실제 휩쓴 영역의 채움 윤곽으로 바꾸며 단일 path의 여러 contour로 합쳐 반투명 겹침을 중복 적용하지 않는다. 원형/납작한 타원의 끝단과 접선, 다각형 팁의 convex hull을 사용한다. 래스터·질감·절차형 자료는 PNG data URI로 포함한다. 합성/색 공간/마스크/프레임 등을 SVG 요소로 정확히 나누기 어려우면 현재 프레임 전체를 포함 PNG로 대체하고 손실을 알린다. 파일과 SVG 텍스트 복사는 같은 생성 결과와 안내를 사용하며 문서·선택·Undo는 바꾸지 않는다.

출력 SVG의 width/height/viewBox는 페이지 픽셀 크기다. 외부 href/이미지 URL을 생성하지 않는다. 표준 SVG namespace URI와 내부 paint/clip ID 참조만 쓰며 그림 자료는 포함한다. 저장은 자신이 만든 임시 파일을 완전히 기록한 뒤 교체하고, 이미 있는 다른 임시 파일을 덮어쓰거나 지우지 않는다. 클립보드 읽기/쓰기 실패는 페이지와 입력 초안을 보존한다.

문서v68은 SVG paint/clip의 자체 수치 자료를 보존하고 구형 헤더 위장을 거절한다. 래스터 대체는 기존 위치·색 공간·합성 순서 형식을 공유한다. 로컬 표시/입력 초안은 문서 이력과 분리되며 페이지/수정본/프레임이 바뀌면 이전 미리보기 적용을 막는다.

한도는 UTF-8 SVG2MiB, XML8192노드/64깊이, clip16깊이, 그라데이션256정지점, 경로4096점/문서8192점·128획·32벡터층, 이미지당 압축8MiB/4M픽셀이다. 복합 래스터 작업은 픽셀 수×입력 태그 수1M 이하다. Scene JSON4MiB와 스냅샷/Undo 예산을 함께 검사한다. 출력은 SVG64MiB, 래스터 작업 총16M픽셀까지이며 자체 입력 한도보다 큰 출력은 재가져오기 제한을 알린다.

기하와 색 검증은 별도 SVG reader/renderer인 usvg/resvg의 출력과 비교한다. 벡터는8×8 coverage, 포함 래스터는 원래 픽셀 격자를 사용하고 도형 내부 색/알파는 별도 엄격한 probe로 확인한다. XML/자원/거대 경로 실패, 원본 파일 보존, 자체 문서 재열기·Undo, 파일과 클립보드 정책 일치도 검사한다. 실물 펜 검증은 별도 대기한다.
