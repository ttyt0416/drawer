# 091 선택 강도와 그리기/지우기

090의 페이지 선택 coverage를 기존 Stroke 경로의 단일 쓰기 제약으로 사용한다. 제한 없음(None)은255,빈 마스크는0이며 부분 coverage는 원래 픽셀과 도구 결과 사이의 가중치다. 보존된 페이지 좌표/문서 변환/문서공간 선택 이동을 Scene.selection_coverage로 읽는다. 도구를 바꾸거나 선택을 해제해도 이미 확정한 픽셀을 다시 계산하지 않는다.

감사에서 PixelPen RGBA overwrite가 선택 coverage를 입력 알파에 곱한 뒤 기존 픽셀을 전부 대체하던 문제를 재현했다. base=[20,80,160,128],ink=[220,40,20,128],선택128의 잘못된 결과는[220,40,20,64]였다. 수정은 브러시 농도/팁 coverage/질감으로 먼저 대체 RGBA를 만들고,선택 coverage로 원래 픽셀과 premultiplied RGBA 혼합하는 것이다. 결과는[120,60,90,128]이다. 전체 선택의 기존 RGBA 대체·브러시 농도/알파 규칙은 유지한다. 한 획 내 재통과는 처음 원본을 사용하고 새 획의 부분 선택은 현재 남은 픽셀과 다시 혼합한다.076의 수치 검증도 이 통합 규칙으로 갱신했다. 투명한 두 RGBA의 부분 혼합은 원래 숨은RGB를 유지하고 전체 대체는 입력 RGBA byte를 보존한다. 지우기/투명색의 숨은RGB 보존 경로는 원래 정상임을 시험으로 확인했고 불필요하게 변경하지 않았다.

모든 기존 래스터 팁,안료 모드,특수 합성,복제/이중 RGB/질감/산포/리본/장식과 수채 확산·가장자리 후처리에서 선택0 픽셀 쓰기를 거부한다. 부분 강도는 각 도구의 기존 농도/합성 정책에 적용한다. Dissolve는 확률,Compare density/Erase(compare)는 밀도 판정이므로 결과가 모든 픽셀의 선형 보간인 모드는 아니다. 수채 가장자리 강도도080에서 정의한 농도/선택 규칙을 따른다. 기존 래스터 다중 지우기의 원형 coverage와 선택도 함께 적용한다. 벡터/페이지 개체의 구조 편집은 래스터 브러시 쓰기 명령과 구분한다. 독립 혼색판/시험 칠하기는 자신의 버퍼 문서를 사용하므로 캔버스 선택을 물려받지 않는다.

직접 획·생산 마우스 입력 모두 선택0은 문서 픽셀/이력/dirty 불변이다. 실제 변경이 있을 때만 한 픽셀/마우스 획 이력을 만들며 Undo/Redo와 자체 문서에 픽셀/마스크를 보존한다. 배치 래스터는 원점으로 문서 좌표를 구하고 선택 밖의 캔버스 외 픽셀도 보존한다.

검증: RGBA 덮어쓰기54조합(base/ink 알파0/128/255,브러시 농도0.5/1,선택0/128/255)의 독립 수치 기대값,7팁의 동일 전체결과에 대한0/중간/전체 coverage,5안료 모드의 단일 강도 적용을 비교한다.38종 경로 각각 빈 선택/0·128·255 띠에서 확산/가장자리 포함 선택 밖 RGB/알파 불변과 한 이력/무변경을 검사한다. 복제는 선택 밖 원본을 읽을 수 있으나 쓰기는 선택 안으로 제한한다. 기존 래스터 다중 지우기의255/127/0 알파,지우개/7팁 투명색의 완전 투명 숨은RGB 유지,배치/캔버스 밖 보호·문서 재열기를 확인한다. 실제 마우스에서 ink 알파0/128/255×선택0/128/255의9조합을 입력하고 결과·확정/해제·한 Undo/Redo·마우스 메타데이터/마스크 재열기를 검사한다. 설치본도 같은 검증을 실행한다. 실제 펜 센서 검증은 별도다.
