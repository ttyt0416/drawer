# 비파괴 밝기·대비·색상·채도 레이어

보정층은 래스터 트리의 매개변수 노드다. 선택 부모의 맨 위에 새로 만들거나 기존 보정층의 값을 편집한다. 원본 래스터와 알파는 바꾸지 않고 앞서 합성한 같은 범위의 배경에 작용한다. 일반 폴더는 투명한 별도 배경, 통과 폴더는 진입 배경을 사용한다. 전체 보정 잠금을 존중하고 보정층에 붓/채우기로 픽셀을 쓰는 요청은 설명과 함께 거절한다. 이동은 연결된 마스크를 옮길 수 있다.

encoded RGB의 채널 c에서 밝기 b와 대비 k를 사용해 c′=clamp((c−0.5)f+0.5+b)로 계산한다. k≤0이면 f=1+k, k>0이면 f=1/(1−0.99k)다. 밝기/대비/채도는−1–1, 색상은−180–180도다. 색상은 순환하고 채도는 기존 채도×(1+s)를0–1로 제한한다. 기본 HSL은 명도를, HSV는 최댓값을 유지한다. 네 값0은 합성 내부를 재양자화하지 않는 정확한 무변경이다.

보정 결과 RGB에 마스크×불투명도 강도와 레이어 혼합 모드를 source-atop으로 적용해 배경의 실제 premultiplied 알파를 그대로 보존한다. 보정층을 숨기면 원래 배경으로 복귀한다. 마스크는121의 작성/대체 경로로 지정한다. 벡터/페이지 개체는 기존의 별도 상위 스택에 있으므로 래스터 보정보다 위에 표시된다.

문서v50은 보정의 HSL/HSV 식별자를 명시 저장한다. v49처럼 식별자가 없는 기존 보정은 HSV로 읽어 결과를 유지한다. 새 보정의 기본값은 HSL이다. 픽셀과 문서 구조/매개변수/마스크는 한 Undo로 복구한다. 미리보기는 별도 문서와 전후 이미지이며 원본을 수정하지 않는다. 값/대상 변경은 이전 미리보기를 무효화하고 문서/수정본/프레임이 달라지면 적용을 거절한다.
