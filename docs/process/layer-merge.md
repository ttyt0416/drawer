# 레이어 병합·전체 합치기

선택 병합은 같은 부모의 연속된 래스터/폴더 노드를 한 래스터로 바꾸고 아래와 병합은 바로 아래 형제를 함께 선택한다. 벡터·문자/페이지 개체·애니메이션을 함께 래스터화할 때는 전체 합치기를 사용한다. 각 변경은 문서 상태 한 번으로 기록해 픽셀·고유 식별자·계층·표시·마스크·보정·자/참조를 Undo로 복구한다. 합친 층에는 새 식별자를 부여한다. 소비한 폴더의 빈 내부 슬롯은 화면/대상 목록에서 제외한다.

숨김 제외가 기본이다. 선택된 숨김층은 소비하지 않으며 숨김 자식이 있는 폴더는 명시적 포함을 요구한다. 포함하면 해당 원본 숨김 상태만 미리보기에서 해제하고 합친 결과에 표시한다. 잠금층과 폴더 단독 표시 중에는 합치지 않는다. 클리핑은 기준과 전체 연쇄를 함께 포함해야 한다.

공통 노드 렌더가 종이질감·혼합·마스크·보정을 처리한다.120의 합성 검증을 위해 회색조 마스크/보정 매개변수의 공통 저장·렌더 기반을 함께 추가했다. 폴더/마스크 편집과 보정층 작성 화면은121/122의 별도 항목이다. 통과 폴더는 마스크×불투명도로 진입 배경과 내부 결과를 premultiplied 보간한다. 보정은 밝기·대비와 HSV 색상/채도의 독립 수식이며 원본 알파를 유지한다.0값은 정확한 무변경이다. 문서v49에 보관한다.

선택 병합은 음수 오프셋을 포함한 원본 저장 영역의 합집합을 보존한다. 전후 전체 래스터 트리를 합집합의 모든 픽셀에서 비교하며8비트 중간 저장의 채널 최대1 반올림을 허용한다. 이보다 다르면 외부 배경 의존성으로 거절한다. Include lower siblings는 선택 마지막 노드까지의 아래 형제를 명시적으로 포함한다. 통과 폴더 밖 배경까지 의존하면 바깥 묶음과 병합하거나 전체 합치기를 사용한다.

전체 합치기는 현재 프레임의 공통 페이지 렌더를 저장하므로 픽셀이 정확히 일치한다. 캔버스 밖 픽셀·편집 개체/효과·애니메이션과 오디오는 한 래스터로 대체되며 이 영향과 프레임 번호를 미리보기에서 표시한다. 미리보기·대상 변경·취소는 문서를 바꾸지 않는다. 실제 Apply는 미리보기와 영향 확인을 마친 뒤에만 활성화한다. 문서/수정본/프레임이 달라지면 재작성해야 한다.
