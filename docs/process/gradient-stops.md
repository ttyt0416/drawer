# 그라데이션 색상 지점과 로컬 프리셋

그라데이션 창의 Color stops, mixing and local presets를 펼쳐 다중 색상/알파 지점을 켠다. 2~32개 지점의 위치0~1·RGBA·다음 구간 중간점0.01~0.99·Linear/Smooth/EaseIn/EaseOut 곡선을 편집한다. 위치가 같으면 해당 위치의 마지막 지점을 택하는 오른쪽 연속 hard edge다. 양끝 바깥은 첫/마지막 지점으로 유지하고 반복/왕복은103의 위치 변환을 공유한다. 위치 변경 뒤 안정 정렬해 같은 위치 지점의 순서를 보존한다. 두 개 미만 삭제는 거절한다.

혼색은 Standard(감마 부호화 sRGB), Perceptual A(Oklab), Perceptual B(CIELAB D65), Linear RGB의 네 독립 선택값이다. A/B는 독립 수학적 정의이며 타제품 수치 호환을 뜻하지 않는다. premultiplied alpha 가중치로 색을 혼합해 완전 투명 지점의 숨은 RGB를 중간색에 섞지 않는다. 중간 결과는 부동소수점으로 유지하며 디더를 더한 뒤 마지막에만8비트 양자화한다.

밝기 보정은 Off/Low/Medium/High/Highest(0/25/50/75/100%)다. 혼합 결과의 선형 RGB 상대휘도를 입력 색의 알파 가중 상대휘도 쪽으로 이동한다. 더 밝게 할 때는 선형 RGB를 흰색으로, 어둡게 할 때는 검정으로 섞어 목표 휘도를 맞춘다. 지점 색/알파는 보정하지 않는다. 곡선·중간점을 반영한 혼합 비율을 RGB와 알파에 함께 사용한다. 지점 위치/색/곡선/혼색/보정은 편집 가능한 문서 레이어에 저장되고 한 문서 Undo로 바뀐다(v37; 구형 지점 누락은 기존 두 색상).

프리셋은 최대32개이며 이름·안정ID·전체 그라데이션 설정(반복/왕복 포함)을 로컬 작업공간에 보존한다. 새 저장·수정/이름 변경·불러오기·삭제·초기화·자체 Undo/Redo(16단계)를 제공한다. 불러오기는 편집 초안만 바꾸며 Apply 전에는 그림을 바꾸지 않는다. 로컬 JSON 내보내기는 기존 원자적 기록 함수를 사용한다. 가져오기는256KiB·버전·개수·중복ID/이름·지점·수치를 검사하며 실패 시 라이브러리와 그림을 보존한다. 정상 가져오기/초기화 전 라이브러리는 자체 Undo 백업에 남는다. 그림 Undo와 섞지 않는다.

독립 검증은 원색 중간색 Standard128/0/128·Linear RGB188/0/188·Oklab140/83/162·CIELAB202/0/136, 다섯 보정의 상대휘도, 투명 숨은색의20개 조합, 같은 위치 hard edge·최소 개수/비정상 위치/알파, 네 곡선·중간점, 반복/곡선 프리셋 재열기·원자적 저장 충돌 보존·자체 Undo/Redo·문서 재열기와 다중 지점 디더를 비교한다. 실제 그라데이션 Apply의 네 혼색 공간과 실제 프리셋 저장 버튼/설정 재열기를 설치본에서도 실행한다.
