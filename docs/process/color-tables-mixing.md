# 084 — 로컬 색상표·슬라이더·혼색판과 독립 시험 이력

## 색상표와 이력

Color 패널의 RGB/HSV 수치에 슬라이더를 더했다. Local swatches and mixing palette에서 최대16개 로컬 색상표를 생성·선택·이름 변경·삭제한다. 표당256색/전체2048색,이름1–64자다. RGBA가 같은 색은 같은 ID를 유지해 표 끝으로 이동하고 알파가 다르면 별개다. 현재색/사용색 이력 전체를 추가하고 순서 이동/삭제한다. 묶음 추가는 먼저 복사본 전체를 검증해 용량 오류이면 적용하지 않는다. 색상표 전용 Undo/Redo16단계는 그림과 분리한다.

사용색 이력은32색이며 타일12–64px,열1–32를 저장한다. 색 이력 비우기에는 별도 Restore cleared used colors가 있고,이력 비우기가 현재색/그림 이력을 변경하지 않는다. 색 선택 Undo/Redo는 기존 명령으로 분리한다.

Register sampler color on pointer release를 켜면 유효한 canvas Down에서 원시/합성 RGBA와 등록 표를 동결하고 같은 입력원의 Up에서 확정한다. 확정 전에는 전경/색상표/이력을 바꾸지 않고 이동 중 반복 등록하지 않는다. Esc·장치 취소·초점 상실·모달·캔버스 밖 놓기는 폐기한다. 등록 대상 표가 삭제되면 표를 재생성하거나 다른 표로 돌리지 않고 오류를 표시한다. 옵션을 끄면 이전의 Down 확정을 유지한다.

## 혼색판과 시험 영역

Open local mixing palette는 별도128×96 RGBA 버퍼다. 기존 Popup test painting과 서로 다른 그림/이력이며 둘 다 실제 문서를 바꾸지 않는다. 캔버스 도구의 형태·필압/안료/질감/시퀀스 등을 획 시작 시 복사하며 Blend/Smear 안료 도구를 사용해 색을 섞을 수 있다. 혼색판의 Pick mixed RGBA는 배경을 제외한 그린 색을 추출한다.

전용 도구 슬롯 최대8개를 등록/선택/재등록하고 크기0.1–64px를 별도 변경한다. 전용 슬롯은 전체 로컬 프리셋을 보관해 캔버스 도구 변경이 덮지 않는다. 캔버스 복제 원점은 전용 슬롯에 저장하지 않으며 해당 도구 등록 시 이유를 표시한다. Shared 모드는 현재 도구를 사용하고 복제는 혼색판 픽셀에서 읽는다. 소재는 기존 로컬 라이브러리의 불변 스냅샷이다.

보기 확대0.25–2(기본 표시 배율3배),보기 복원,투명/흰색/회색/검정 배경을 제공한다. 배경은 표시 때만 합성하고 RGBA를 평탄화하지 않는다. 화면 크기 브러시는 현재 보기/표시 배율에 맞게 계산한다. 보기/도구 변경은 그림 이력 밖이다.

혼색 획과 Clear는 혼색 전용 Undo/Redo32단계다. 기존 시험 칠하기에도 별도 Undo/Redo32단계와 Clear 복원을 추가했다. 미리보기는 확정 전 저장 복사본에 넣지 않고 Esc/초점 상실/창 닫기는 획 시작값을 복원한다. 시간 분사·수채 등 기존 PadPaint 경로를 공유하며 정상 놓기 후처리까지 한 이력이다. 다른 작업공간의 버퍼/색상표로 바뀌면 그 이전 전용 이력을 제거해 다른 그림을 되살리지 않는다.

색상표·자동 등록·이력 표시와 혼색판 픽셀/보기/배경/전용 도구는 로컬 작업공간에 저장한다. 실행 취소 스택은 현재 세션에서만 보관한다.128×96 버퍼와 최대32단계로 이력 메모리를 제한하고 기존 문서 예산/슬롯/소재 검증을 사용한다. 실제 펜 센서는 별도 대기다.

## 검증

스와치 RGBA/알파 중복·순서·표 삭제·삭제된 표 자동등록 거부·용량 오류 원자성·표 전용 복원과 픽셀 전용 복원을 검사한다. 실제 앱 이벤트로 혼색 반투명 획/저장 미리보기 제외·전용 Undo/Redo/Clear·배경/확대/복원·도구 등록/캔버스 전환·포커스 취소/재시작을 검증한다. 기존 시험 영역도 실제 입력과 전용 버튼으로 Undo/Redo한다. 자동 스포이트 Down/Up/Esc의 등록 여부와 전경·문서 이력 불변을 확인한다. 설치본도 같은 시험을 실행한다.
