# 157 — 공간 블러

모션은 길이0–128px와 방향, 방사는 문서 좌표 중심과 길이0–64px, 회전은 중심과 −360–360도 노출각을 사용한다. 궤적의 양 끝은 반 가중치로 적분하고 최대257개 위치에서 원본을 bilinear 표본화한다. 중심은 캔버스 밖도 허용한다. 방사의 중심 픽셀은 고정하며 회전 출력 경계는 네 모서리 궤적의 극값까지 포함한다.

렌즈 반경0–64px와3–8각형을 제공한다. 각 다각형의 꼭짓점은 회전0일 때+X에 놓인다. 다각형 외곽의 방사 거리와 원 사이를 둥글기0–1로 보간한다. 픽셀별4×4 면적 표본으로 조리개 커널을 정규화한다. 각도는360/각수 주기이며 완전한 원은 회전과 무관하다. 조리개의 비대칭 방향이 점광원의 흐림 모양에 그대로 나타난다. 하이라이트0–4는 문서 RGB의 가중 밝기0.5 초과 색에 에너지를 더하며 커버리지를 바꾸지 않는다. 일반 가우시안 커널과 별개다.

RGB×알파와 알파를 누적한 뒤 straight RGB로 돌려8/16비트로 저장한다. 투명 픽셀의 숨은 색은 흐림에 들어가지 않는다. 문서 프로필과 정밀도를 유지하며 원본8비트 숨은RGB와 선택 밖 원자료는 보존한다. Amount0–1과 선택 coverage를 곱해 원본과 섞는다. 알파 잠금은 원래 경계/알파를 보존하고 색만 섞는다. 마스크는 움직이지 않는다. 길이/반경0·회전0·Amount0·빈 선택·완전 투명·저장 결과 무변화는 정확한 원본 상태를 돌려주어 dirty/Redo/기록을 바꾸지 않는다.

원본 스냅샷32MiB, 출력4M픽셀/축32768/좌표±1M,64M 궤적 표본과256MiB 작업공간 한도를 적용한다. 렌즈 커널과 빈 이미지 검사 도중에도, 픽셀과 커널 표본128개마다 취소 신호를 확인한다. 비수·조리개 범위·회전 범위·메모리 초과는 확정 전에 거절한다.

미리보기는 원본 스냅샷의 별도 작업에서 계산한다. 화면은 기다리지 않으며 Cancel/Escape/닫기는 취소 플래그를 설정하고 초안을 버린다. 정리될 때까지 이전 작업을 보유해 여러 대형 작업을 겹치지 않는다. 취소된 작업의 늦은 결과, 바뀐 문서ID/수정번호/프레임/대상/설정을 거절한다. 매개변수 변경이나 실패는 이전 준비 결과를 폐기한다. Apply만 한 Undo로 문서 픽셀과 마지막 설정 기록을 함께 바꾼다. 앱의 저장/다른 이름 저장은 미확정 블러를 확정하거나 취소하도록 안내하고 현재 저장을 중단한다. 저수준 저장은 원본만 기록한다.

자체 문서v70은 선택적 Scene.last_spatial_blur에 마지막으로 확정한 설정을 보존한다. 기록은 구워진 결과의 설명이며 실시간 필터가 아니다. Restore last applied settings로 다시 불러온다. 모드별 최근 확정값은 로컬 workspaces.json에 저장한다. 취소·실패·무변화는 프리셋을 덮어쓰지 않는다. 이전 문서/설정에는 안전한 기본값을 제공하며 잘못된 값과v69 이하 위장 헤더를 거절한다.

검증은 독립적인 모션 적분값, 수학적 삼각형 경계, 각형/원·회전 주기·강조 분리, 일반 블러와 구분, 중심 밖·문서 밖 광원, 반투명 숨은RGB·16비트 극저알파·선택·알파 잠금·큰 반경 취소·자체 문서 왕복/Undo/Redo와 로컬 설정 왕복을 포함한다. 실제 앱 입력 경로에서4종 마우스 미리보기/적용, 원본 저장, 비동기 취소, 오래된 작업 결과, 실패한 계획 폐기와 무변화의 dirty/Redo를 검사한다. 실물 펜 검증은 별도 대기한다.
