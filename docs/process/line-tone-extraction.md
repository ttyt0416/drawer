# 이미지·3D 윤곽선과 단계톤 레이어 (220)

`line-tones`에서 Raster image layer 또는3D surface render를 고르고 Contour / Stepped-tone 레이어를 준비한다. 명도 경계, 상대 카메라 깊이 차이, 표면 법선 각도와 알파 실루엣을 독립 선택한다. 경계 반경1..4픽셀·명도/상대 깊이 임계값·법선1..180도, 선형 명도2..16단계와 결과 강도0..1을 설정한다. 강도0과 완전히 빈 결과는 레이어/Undo를 만들지 않는다.

이미지 입력은 선택 래스터 층의 현재 표시 기여를 RGBA8 sRGB로 표본화한다. 잠긴 원본도 읽기만 하며, 숨긴/투명 원본은 표시 기여가 없다. 명도는 sRGB를 선형광으로 바꿔 계산하고 단계톤도 선형 명도로 양자화한 뒤 sRGB로 출력한다. 새 결과는 프로젝트의 작업 프로파일과8/16비트 저장 정밀도를 따른다. 고정밀/HDR 원본을 변경하지 않으며 이 파생 결과의 입력 표본은 표시용 RGBA8이다.

3D 입력은 현재 장면의 보이는 표면·레이어 순서/표시 기여에서 색을 읽고, 표면의 최근접 깊이와 보간 법선을 이용한다. 불투명한 앞 개체 뒤의 면 경계는 제외한다. 법선 패스는 제공된 보간 법선을 사용하고 없으면 기하 법선이다. Wire/조명 없음 장면은 임시 Unlit 사본에서 면을 표본화하며 원래 장면 설정은 유지한다. 페이지·레이어/2D 카메라 변환을 역으로 적용하며, 카메라 출력 상태에서 실제 새 층 생성은 기존 보호 규칙에 따라 명시적 기본 콘텐츠 편집을 요구한다.3D 면이 없는 참조 와이어만으로 깊이/법선 레이어를 만들지는 않는다.

윤곽선은 보이는 원본 알파 안쪽에 검정으로 만들며 투명 영역의 숨은 RGB를 선으로 만들지 않는다. 단계톤은 원본 알파를 유지하고 강도는 각 결과의 알파에 적용한다. 새 Normal/100% 래스터 층은 기존 소스보다 위에 배치하며, Tone 후 Contour 순서이다. 원본 이미지·메시·카메라·재질·효과는 그대로 남는다. 결과는 시간에 자동 연결되는 필터가 아닌 해당 프레임의 독립 스냅샷이다. 원본이 계속 보이므로 반투명 결과의 합성 알파는 원본과 중첩될 수 있다.

미리보기 작업자는 취소 가능하고 원본/프레임 변경·문서/창 닫기·Esc/포커스 상실은 결과를 버린다. 설정을 바꾸면 다시 준비해야 한다. 선이 보이는 픽셀의25%를 넘으면 과다선 미리보기 경고를 표시하고 확인 전 적용을 막는다. Apply 한 번이 생성 층 전체의 한 Undo/Redo이다. 복원 이후 새 이미지/장면 상태는 다시 준비해야 한다.

최대4Mi 픽셀·3D 픽셀×개체 검색3200만 회·래스터256층·사본/표본/고정밀 결과/가속 메모리 예산과 잘못된 선택·수치·취소·오래된 결과를 검사한다. 기존 자체문서 형식의 래스터/프로파일 필드로 저장하므로 native112를 변경하지 않는다. 균일면·투명배경/숨은 RGB·강도0·과다선·앞면으로 가려진 법선·깊이 경계·잠긴 이미지·16비트·저장/PNG/Undo를 검증한다. 물리 펜 시험은 유보한다.
