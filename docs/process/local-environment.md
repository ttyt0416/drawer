# 로컬 파노라마·환경광 (223)

`scene-environment`에서 로컬 PNG/JPEG/Radiance HDR 파일을 선택하고 Preview local file을 실행한다. 배경·확산 환경광을 독립 선택하고 yaw·환경광 강도0..64와 배경 노출 -16..16EV를 조절한다. 기존 내장 이미지의 값만 변경하거나 제거 미리보기를 만들 수 있다. 표시된 전송/용량/렌더 범위와 결과를 확인해야 Apply한다. 한 Apply/Undo/Redo로 이미지와 설정·필요한 셰이딩 전환을 함께 복원한다. 원본 이미지·메시·모델 행렬은 수정하지 않는다.

입력은 저장된 픽셀 방향의2:1 equirectangular panorama이다. 가로는 경도, 위쪽은 +Y 극점이며 중앙은 -Z 방향이다. sRGB LDR은 역전달함수로 선형화하고 ICC는 기존 색 관리 판독기를 이용해 sRGB로 바꾼 뒤 선형화한다. ICC/sRGB가 없는 PNG의 gAMA는 별도 지수로 적용하고, 무표기 PNG/JPEG는 sRGB로 해석한다. LDR16비트는 기존8비트 색 관리 브리지를 사용한다는 안내를 표시한다. 투명 픽셀은 사전 평탄화를 요구한다. EXIF 회전은 적용하지 않는다. 일반 Radiance RGBE는 RGB32F 선형으로 읽고1을 넘는 값을 유지한다. HDR 헤더의 노출/감마 주석은 별도 적용하지 않으며 이를 안내한다. EXR/게인맵 JPEG/임의 HDR 형식까지 지원한다고 주장하지 않는다.

최대2048x1024/입력16MiB와 디코드·사본 메모리를 검사하고, 저장용 이미지는 최대512x256으로 선형광 평균 축소한다. 축소 사실을 알리고 RGB32F 값과 출처 파일명·입력 해석·설정을 문서에 내장한다. radiance는 유한/비음수 RGB32F 범위로 검사하고 태양처럼 밝은65504 초과 값도 유지한다. 외부 URL/네트워크 경로를 선택하거나 다운로드하지 않으며 로컬 파일만 읽는다. 내장 이미지가 있으면 외부 원본을 삭제해도 값 편집·재열기·출력이 된다. 재불러오기는 Preview local file로 명시적으로 수행한다.

파노라마는 무한 거리 배경이며 원근 카메라의 광선 방향에 따라 표본화한다. 평행투영에서는 모든 광선 방향이 같아 배경도 한 방향의 색이다. yaw는 환경 좌표만 회전시키며 모델/카메라를 움직이지 않는다. 카메라 회전은 보이는 파노라마 방향만 바꾸고 저장된 환경 값은 유지한다. 배경 노출은 선형광에 적용한 뒤 표시 범위0..1로 자르고 sRGB로 변환한다. 원본 HDR radiance는 문서에 유지되며 배경 노출과 확산 환경광 강도는 독립이다.

배경은 기존3D 합성 규칙에 따라 앞선2D 내용 위, World 렌더 그룹의 맨 앞에 불투명하게 넣는다. 이후의 World 개체/그룹에 배치된 래스터는 배경 위에 남는다. 배경 스위치로 숨길 수 있고 solo/장면 clip·일반 합성 참조 범위를 따른다.8비트와 작업 프로파일/16비트 부동 합성·PNG 출력, 공유3D 보기와 윤곽선/톤의3D 입력에 같은 배경을 사용한다. 고정된 이미지 레이어로 굽지 않아 카메라 변경에 따라 갱신된다.

환경광은 회전된 이미지의 저주파 확산 성분을9개 구면조화 항으로 계산한다. 재질의 선형 RGB와 곱하고 기존 광원/ambient에 더한다. 이는 거친 확산 조명의 근사이며 국소 차폐/AO·specular 반사·환경광 자체의 ray-traced 그림자는 없다. 환경광을 처음 활성화하면 Wire/Unlit은 Smooth로 바꾸고 기존 광원은 유지한다고 안내한다. 기존 조명이 없으면 환경광만 사용하는 Smooth 상태를 만든다. 이후 사용자가 Unlit/Wire를 선택하면 환경광 조명은 표시하지 않는다. 기존 조명과 스타일의 다른 동작은 유지한다.

작업자는 로컬 읽기·축소·미리보기에서 취소를 확인하며 문서/리비전/프레임/입력 변경·Esc/포커스 상실·창/문서 닫기는 오래된 결과를 폐기한다. 다른3D/콘텐츠 초안을 덮어쓰지 않는다. 동일한 설정과 빈 환경 제거는 문서/이력을 바꾸지 않는다. 이미지·장면·가속 구조·Undo 예산과 native 장면4MiB를 확정 전에 검사한다. native114는 내장 선형 이미지/설정을 보존하고113 위장은 거절한다. 물리 펜 검증은 유보한다.

구면조화 확산 근사는 [Stanford의 원 논문 소개](https://lightfield.stanford.edu/papers/envmap/)에 설명된9항 표현의 수학적 접근을 바탕으로 독립 구현했다. Radiance 판독은 잠금 버전 image0.25.10의 HDR 기능을 사용하며 새 라이브러리는 추가하지 않는다. 원본 SAI/CSP 코드·자산을 사용하지 않는다.
