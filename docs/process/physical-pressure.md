# 296. 실물 펜 필압 시작·곡선·최대 응답

상태: **실물 시험 대기**. 사용자의 펜 실물 검증 보류 지시를 유지한다. 이 문서와 빈 JSON 양식은 실행 결과가 아니며 완료 근거로 사용하지 않는다.

현재 배포 실행 파일의 해시와 Native 형식은 양식의 referenceBuild에 기록했다. 실제 시험 시 사용한 빌드·장치·드라이버·OS·모니터·도구 설정을 다시 확인해 기록한다. 물리 픽셀·논리 좌표·문서 픽셀과 원시 입력·앱 계산·화면 표시의 측정값을 구분한다.

원본을 유지하는 새 로컬 시험 문서와 별도 저장 경로를 사용하고, 데이터 수집 방법과 관측 가능한 항목부터 정한다. 수집하지 못한 값은 미측정으로 남긴다. 단위 시험이나 합성 이벤트의 수치를 실물 값으로 옮겨 적지 않는다.

1. **slow-ramp** — 천천히 접촉하고 정상 범위까지 눌렀다가 들어 올린다. 시작 압력과 크기/불투명도 반응을 각각 기록한다.
2. **fast-ramp** — 빠른 접촉과 빠른 압력 변화를 반복하고 빠진 접촉·튀는 굵기·고착을 기록한다.
3. **light-dots** — 가벼운 점을 반복해 원시 접촉이 보고된 경우와 앱의 클릭 임계값에 의해 차단된 경우를 구분한다.
4. **maximum** — 장치가 보고한 최대값과 선택한 최대값 설정의 실제 포화를 기록한다. 보고 범위를 임의로 0~1이라고 가정하지 않는다.
5. **curves** — 선형/비선형 곡선과 최소/최대값 설정별로 느린 선·빠른 선의 결과를 비교한다.
6. **lift-new-press** — 완전히 들어 올린 뒤 새 접촉을 반복해 이전 필압·버튼 상태가 재사용되지 않는지 확인한다.

295번은 가상 이벤트와 계산 검증이다. 실제 접촉 임계값·드라이버의 압력 범위·필압 누락을 대신하지 않는다. 원시 압력을 직접 수집하지 못하면 출력 굵기에서 추정한 값을 원시 측정값으로 기입하지 않는다.

기록 양식: [physical-296-template.json](physical-296-template.json). 모든 사례는 not_run이고 수치·장치명·시각·결과는 비워 두었다.

완료 판정은 실제 시행 자료를 연결한 뒤 한다. 각 사례의 관측값·기대값·오차/실패와 해당 빌드·환경을 남기고, 미지원 속성은 지원 여부와 안내를 명시한다. 저장 전후 문서와 필요한 영상/이벤트 기록의 로컬 경로·해시를 보존한다. 필수 사례의 실제 결과가 없으면 체크리스트를 체크하지 않는다.
