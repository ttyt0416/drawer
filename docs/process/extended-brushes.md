# 마커·색 운반 번짐·픽셀 펜

BrushTip에 Marker/Smudge/PixelPen을 추가해 일곱 도구를 독립적으로 선택한다. 도구 속성·필압·커서·안료·시작/끝·질감·가상 필압 슬롯을7개로 확장했다. 레거시 네 슬롯은 제자리 값을 보존하고 새 슬롯만 독자 기본값으로 채운다. 길이4/7 외의 배열은 거절한다. 옛 속성 도구 맵에는 새 도구만 추가하고 기존 도구 누락은 여전히 검증 실패다. v1 속성은 옛4속성 구조를 먼저 복원한 뒤 v2로 확장한다. 기존 단축키와4방향 원형 메뉴는 유지한다. 새 기본 키는 Y/U/P, 새 기본 도구 순환에는 일곱 도구를 포함한다.

Marker는 원형 경계×.22 도장 농도, 기본 전체 농도.65·간격.3이다. 같은 획의 재방문을 누적하며 필압 농도도 도장별로 곱한다. 선택/전체 획 농도/질감은 최종 원본 혼합에 한 번 적용한다. 전체 농도를 중복 곱하지 않는다.

Smudge는 코어 스타일 확정 단계에서 Mode::Smudge·공급0·무색 운반을 강제한다. Stroke의 예산 지정 생성 경로와 Replay도 같은 규칙을 사용한다. 선택색이 투명해도 기존 안료 운반을 계속하고 완전히 빈 층에 주색을 공급하지 않는다. 픽업·유지·거리·희석/농도/알파 잠금은 공통059 모델이다. 설정 창에서 주색 모드로 바꾸는 선택은 비활성화한다.

Pixel pen은 양수 크기/비율을 정수 폭/높이(최소1)로 반올림하고 홀수/짝수 폭의 문서 격자 중심에 맞춘 직사각형을 사용한다. 중심 샘플의 내부/외부를0/1로 판정한다. 경도/기하 안티앨리어싱을 적용하지 않는다. 회전 직사각형의 범위는 타원 범위로 잘라내지 않는다. 같은 획에서 농도를 누적하지 않아 기본 반투명 픽셀과 경계를 그대로 보존한다. 명시적인 필압·질감·수채 후처리의 농도 변화는 유지한다.

각 획은 기존 명령/실행 취소에 참여한다. 자체 문서v13은 새 안정된 팁 식별자를 포함한 고정 스타일/결과를 저장한다. 로컬 프리셋은 새 독자 팁 참조를 지원한다. 시험 칠하기는 같은 Stroke 엔진을 사용해 새 번짐이 주색을 칠하는 잘못된 미리보기를 피한다. 캔버스 보기 변환은 저장 픽셀에 포함하지 않는다. 실제 펜 장치 검증은 대기다.
