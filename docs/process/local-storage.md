# 로컬 저장과 진단 범위

| 기록 종류 | 쓰기 위치 | 사용자 제어 |
| --- | --- | --- |
| 설정·배정·보기·프리셋 | UserStorage/settings | 환경설정·초기화·로컬 데이터 이동 |
| 팁·질감·참고 복사본·자산 묶음 | UserStorage/materials | 로컬 등록·복원·삭제 명령 |
| 자산 검색 색인 | UserStorage/asset-index.json | 로컬 재구축·이동, 손상 원본 보존 |
| 작품 목록·검색 | 로컬 작업 라이브러리 설정/색인 | 사용자 폴더 선택, 외부 게시 없음 |
| 그림·프로젝트·출력 | 사용자가 고른 로컬 파일 | 저장·다른 이름 저장·내보내기 |
| Undo/Redo | 현재 프로세스의 제한된 메모리 | 취소·재실행·확인 후 지우기 |
| 복구·작업 시간·타임랩스 | 로컬 복구/scratch 또는 사용자 폴더 | 보관 설정·명시적 정리/출력 |
| 데이터 이동 기록 | bootstrap 옆 .drawer-location/journal | 검증 후 원자 전환, 이전 자료 보존 |

코어 storage/asset_catalog/work_index/work_time/recovery/storage_migration 및
앱의 해당 쓰기 경로를 조사했다. 네트워크 클라이언트·원격 색인·업로드·통계
저장기가 없다. 앱 오류는 화면 상태로 알리고, 정상 실행은 그림/사용자 경로를
진단 파일로 자동 직렬화하지 않는다. CLI 실패의 stderr와 사용자가 명시한
--smoke-test/DRAWER_SMOKE_DIAGNOSTICS는 자체 시험 경로다. 시험 외부 서비스는 없다.

test-local-storage.ps1은 새로운 합성 사용자 폴더에서 설치본 전체 시험을 실행하고
파일별 상대 위치/길이/SHA256을 수집한다. 실제 사용자 자료를 수집하지 않는다.
API 검사기는 호출 인자/픽셀/원시 사용자 경로를 기록하지 않고 API 이름과
정규화한 모듈 이름만 기록한다. 네트워크 호출은 실행 전 실패 처리하며 실패할
호출도 시도로 센다. local-storage-evidence.json은 관측된 유한 시나리오의 증거다.
다른 Windows 서비스/직접 시스템 호출/커널 SMB까지 포괄한다고 주장하지 않는다.
