# 참조 레이어·밑그림·출력 정책

참조/밑그림 플래그는 문서에 저장한다. 속성 화면의 확인 전 초안은 원본을 바꾸지 않고 적용은 한 문서 명령이다. 폴더와 애니메이션 폴더의 플래그는 자식에게 합집합으로 상속한다. 일반 폴더의 플래그는 종이 효과와 별도 메타데이터로 저장하므로 통과/일반 합성이나 캔버스 픽셀을 바꾸지 않는다. 검색 상태와 부속 초안 조건도 이 상속을 사용한다.

채우기와 마술봉은 같은 참조 샘플러를 사용한다. 종류/마킹/선택 집합/폴더 범위, 밑그림·잠금·역할 제외와 숨김 참조 포함 여부는 각 도구 설정이다. 숨김 포함은 기본 꺼짐이며 프리셋과 로컬 작업공간에 보존한다. 문서 플래그나 출력 정책을 바꾸지 않는다. 숨김 포함과 밑그림 제외는 독립 조건이다. 참조를 허용해도 편집 대상의 잠금·숨김 보호는 유지한다.

복합 참조는 원본을 수정하지 않는 제한된 문서 뷰로 만든다. 선택된 소스의 표시 상태만 이 뷰에서 평가하고 실제 마스크·클리핑·불투명도·혼합·셀/트랙 합성을 그대로 사용한다. 래스터의 현재층/지정층 참조는 기존 원본 픽셀 정책을 유지한다. 페이지 개체·그라데이션·3D·애니메이션 셀도 공통 플래그와 렌더 뷰를 사용한다. 참조를 켜도 원본 표시와 문서 이력에 변화가 없다.

일반 .drawer 저장은 숨김·밑그림·참조 소스와 원본 픽셀을 전부 보존한다. 문서v52의 include_drafts_in_output은 기본 false이며 이전 문서의 누락 값도 false다. PNG와 PSD의 Rendered image는 출력 전용 뷰에서 밑그림을 제외한다. 켜면 밑그림을 포함한다. 출력은 원본 문서의 경로·내용·보기·선택·이력을 바꾸지 않는다. PSD Rendered layers는 밑그림 제외 정책에서 구조를 일부 버리지 않도록 Rendered image를 안내하고 거절한다. 출력 뷰와 인코딩 버퍼를 함께 예산에 계산한다.

폴더 해제는 삭제되는 폴더의 자체 플래그를 직접 자식에게 넘긴다. 선택 병합과 종이 베이크는 모든 실제 래스터 소스의 유효 플래그가 같아야 하며 새 래스터에 그대로 기록한다. 다른 플래그가 섞이면 원자적으로 거절한다. 전체 합치기는 미리보기의 명시적 손실 확인에 따라 현재 캔버스의 밑그림까지 픽셀로 굳히고 개별 속성을 제거한다.

검증은 반투명 밑그림의 캔버스/원본 불변, PNG·PSD의 투명 출력과 명시 포함, 일반 저장 재열기, 정책 Undo, 숨김 마킹 경계의 채우기/마술봉 유출 방지, 밑그림 제외와의 조합, 벡터/개체/폴더/트랙/셀 및 검색 상속을 포함한다. 실제 속성 체크박스/적용/취소/Undo/Redo/재열기와90도/8배 보기에서 마우스·가상 펜의 채우기/마술봉을 검사한다. 원본 숨김 상태·참조 픽셀·이력과 로컬 프리셋도 확인한다. 기존 문서256MiB·초안32MiB·이력64MiB·JSON4MiB와 샘플4Mi픽셀/64Mi작업 한도 및 작업공간 예산을 적용한다.
