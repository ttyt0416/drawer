# 새 Windows 오프라인 검증 — 실행 환경 대기

272는 아직 미완료다. 현재 호스트에는 WindowsSandbox.exe가 없고, Hyper-V 서비스/명령은 있으나 일반 실행과 별도 권한 실행 모두 Windows 자체 권한 때문에 VM 목록을 조회할 수 없었다. 기존 개발 PC에서 PATH만 지운 설치 시험을 새 PC/네트워크 차단 시험으로 간주하지 않는다.

`scripts/test-offline-sandbox.ps1 -CheckOnly`는 준비 상태만 보고하며 검증 성공을 반환하지 않는다. Sandbox가 준비되면 새 증거 폴더를 지정하여 실행한다. 기존 Sandbox가 실행 중이면 그 세션을 보호하고 거절한다. 네트워크/클립보드 차단 설정, 읽기 전용 패키지/시험 코드 매핑, 쓰기 가능한 지정 증거 폴더만으로 새 게스트를 시작한다. 호스트의 어댑터·시계·사용자 계정·기존 VM은 변경하지 않는다.

게스트는 소유 토큰·가상화 환경·Sandbox 로컬 계정을 먼저 확인한다. 개발 실행 도구 없음(스토어 실행 별칭 제외), 앱 전용 설치/캐시 경로 없음, 활성 어댑터0과 캐시 제거 후 실제 서버 DNS 해석 실패를 검사한다. 패키지 실행 파일의 SHA256을 확인하고 설치한 뒤 마우스 그리기·저장·재열기·복구·도움말·로컬 추론을 포함한 설치본 시험을 두 별도 프로세스에서 실행한다. 결과·실행 증거는 지정한 로컬 폴더에 남긴다. 시험 게스트만 종료한다.

아직 실제 게스트 영수증이 없으므로 체크리스트272는 열어 둔다. 그래픽 드라이버 등 실제 게스트에서 발생하는 실패도 통과로 바꾸지 않는다. 사용자에게 실행 가능한 새 Windows VM/PC 정보를 요청했다.
