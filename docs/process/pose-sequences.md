# 로컬 포즈 시퀀스와 명시적 타임라인 배치

`pose-sequences`에서 자체 Body/Head/Hand 인체의 기본 포즈를 등록하고 포즈를 추가·정렬·제거한다. 로컬 `.drawerposes` JSON은 자체 골격의 버전·종류·이름·부모·바인드 회전축·각도범위를 모두 비교한다. 뼈 이름만 같은 외부 골격, 가져온 glTF skin의 자동 매핑은 지원하지 않는다. 최대32개 시퀀스·시퀀스당256포즈·로컬 입력2MiB·native 장면4MiB·사본/Undo/렌더 메모리 한도를 적용한다. 빈 시퀀스는 보관할 수 있으나 배치하지 못하며 마지막 포즈를 지우면 기존 배치를 해제한다.

등록은 스냅샷 저장만 수행한다. `Prepare explicit link to active timeline`에서 대상 자체 인체·시작 프레임(0기준)·포즈당 프레임·반복 수를 선택하고 미리보기 후 Apply해야 현재 타임라인의 포즈가 바뀐다. 배치는 타임라인 전체 길이에 들어와야 한다. 이후 타임라인을 줄이거나 시퀀스를 늘리면 저장된 배치는 유지하고 범위 안내를 표시한다. 배치 이전은 첫 포즈, 끝 이후는 마지막 포즈를 유지하고 구간 안에서는 지정 횟수만큼 순환한다. 기본 Fixed는 포즈 사이를 고정하며 명시적 Linear/Ease 선택만 해당 포즈 채널의 Euler 각도를 보간한다. 각 주기의 마지막 포즈에서 처음으로 넘어갈 때는 절단한다. 반전 여부가 다른 포즈는 Fixed만 허용한다. 2D 레이어·카메라 키나 인체의 기본 메시를 생성·변경하지 않는다.

`Edit selected sequence pose`는 선택한 포즈 스냅샷만 수정한다. `Edit base scene pose`는 기본 인체만 수정한다. 포즈가 연결된 기존 인체 편집 창은 명시적 기본 장면 선택을 요구한다. 각 변경은 한 Undo이며 이력에 편집 범위를 표시한다. 연결 해제는 현재 타임라인의 배치만 제거하고 기본 자세로 돌아온다. 인체 복제는 포즈 자산도 복사해 원본과 독립이며 타임라인 복제는 배치 시간을 복사한다. 타임라인 사이 같은 자산의 포즈 내용은 공유하고 배치는 독립이다. 인체·타임라인 삭제는 관련 배치를 제거한다.

128픽셀 미리보기는 선택 포즈를 임시 사본에서 렌더하며 현재 재생 위치와 독립이다. `Play saved sequence preview`는 저장된 포즈·기본 노출시간을 사용하고 Preview loop로 반복한다. 문서의 프레임·이력·타임라인 반복 설정을 바꾸지 않는다. 준비한 변경이 있으면 Apply/Cancel을 요구한다. Stop은 초안 값을 유지한다. 선택/설정·문서/리비전/프레임 변경·Esc·포커스 상실·창/문서 닫기는 오래된 준비 결과와 작업자를 취소/합류한다. 일반 타임라인 재생은 기존 타임라인 창에서 수행한다.

확정 시 골격/포즈/배치·보간·대상ID·원본 경로를 native115에 내장한다. 로컬 파일 변경/삭제는 문서 스냅샷에 영향을 주지 않고 Reload만 입력을 다시 읽는다. Export는 새 로컬 `.drawerposes`에 저장하고 등록 원본의 덮어쓰기/삭제 후 재생성을 거절한다. 네트워크·다운로드는 없다. native114 이하 위장 파일은 새 데이터와 함께 열지 못한다.

렌더러·음영/UV 보기·다중3D 보기·윤곽선/톤·PNG는 현재 프레임의 포즈를 읽기 전용으로 평가한다. 기존 2D 카메라는 그 뒤에 적용한다. 수동 물리 배치와 메시/기본 장면 조작은 기본 형상을 다루며 시뮬레이션 중 포즈 애니메이션을 수행하지 않는다. 실물 펜 검증은 별도다.
