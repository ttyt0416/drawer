# 형태키·관절 제어·본 부착

`model-controls`는 원래 모델을 읽기 전용 사본으로 준비하고128픽셀 미리보기 후 Apply한다. 한 동작은 포즈·모프·계층·붙은 자식 형상까지 한 Undo로 복원한다. 취소/Esc/포커스 상실·설정/선택·문서/리비전/프레임 변경·창/문서 닫기는 작업자를 취소/합류하고 준비 결과를 폐기한다. 다른3D/콘텐츠 편집 초안이 있으면 먼저 적용/취소한다.

자체 Body/Head의 Blink·Surprise·Cheek puff는 각각0..1의 독립 표정 가중치다. 기존 눈·아래 얼굴·볼의 독자 절차 형상을 변형하며 정점/면 인덱스와 관절 각도는 유지한다. 가중치0은 이전 형상과 정확히 같고 Hand에는 얼굴 모프를 적용하지 않는다. 기존 rig 버전1은 새 값이 없으면 모프0/추가 관절 제약 없음으로 읽는다.

일반 메시에는 로컬 정점의 원본과 최대32개의 독립 형태키를 저장한다. Register shape target는0.1..4의 축별 목표 배율로, Capture frozen target는 정점 수·간선/삼각형 인덱스가 같은 다른 로컬 모델의 형상으로 대상을 만든다. 이름은 중복 없이128바이트 이내이며 가중치0..1로 원본에 델타를 더한다. 원본 대상 모델을 바꿔도 캡처는 변하지 않는다. 자체 rig는 표정 모프를 사용하고 일반 정점 키를 쓰려면 먼저 rig를 분리한다. 비영 가중치에서는 면에서 법선을 다시 구하며 모두0/마지막 키 제거 시 원래 정점·법선 연결을 복원한다. UV·색·질감은 유지한다. 형태키·원본·가중치는 모델 복제 시 독립 복사된다.

관절 제어는 자체 골격의 축별 기본 범위 안에서 min/max와 잠금을 지정한다. 잠금은 적용 시 각도를 앵커로 삼고 포즈 편집·기존 인체 편집·좌우 복사도 이를 넘지 못한다. 현재 자세가 범위 밖이면 먼저 자세나 범위를 바꿔야 한다. 포즈 열에 연결된 인체는 기본 장면 범위를 명시적으로 선택하며 연결된 포즈 중 하나라도 새 제약에 어긋나면 변경을 거절한다. 저장된 포즈/키를 자동으로 자르거나 새 키를 만들지 않는다.

좌우 복사는 자체 Body의 L/R 뼈 전체 매핑만 사용한다. 버전·종류·이름·부모·축·기본 가동범위를 확인하며 이름만 같은 구조·누락 매핑을 거절한다. Left→right/Right→left/Swap은 중심 뼈를 그대로 두고 대칭 회전값을 복사한다. 대상의 잠금/범위 위반은 부분 적용 없이 실패한다. 자체 Head/단독 Hand에는 이 좌우 쌍이 없으며 기존 손 반전과 구분한다.

부모는 일반 모델 축 또는 자체 rig의 본/부위로 지정한다. Keep current world pose는 현재 재생 프레임의 월드 위치, Keep current local pose는 이전 부모에 대한 현재 로컬 변환을 유지한다. 본 부착의 상대 행렬과 골격 매핑을 저장하고 기본 자세/체형 편집과 명시적 포즈 시퀀스 재생을 모두 따라간다. 일반 자식도 붙은 부모를 따라가며 직접 자식을 옮기면 상대 오프셋을 갱신한다. 자기/자손 부모·16단계 초과·없는 본/다른 골격을 거절한다. rig/부모가 없어지면 생존 자식은 기본 장면 위치에서 연결 해제된다. 본 부착 변경은 이 창에서 수행하며 기존3D 창의 일반 부모 기능은 본 연결을 덮어쓰지 않는다. 수동 물리 질의는 기존처럼 기본 장면을 사용한다.

자산·관절 제약/표정·골격 매핑/부착 행렬·대상ID·계층은 native117에 내장한다. 이전116 위장·잘못된 수치/범위/인덱스·숨김/잠금·파일 개체 대체·문서 사본/Undo/가속 메모리와 native 장면4MiB 한도를 검사한다. 외부 다운로드·원본 바이너리/소재는 없고 실물 펜 검증은 별도다.
