# PSD/PSB 로컬 교환 계약

구현: `drawer-core::psd_exchange`, `drawer-app::psd_exchange`. 기존 `psd::export/open` 호출도 같은 엔진을 사용한다. 자체 문서 Native121과 원본 편집 데이터는 바꾸지 않는다.

형식 구조는 [Adobe 공개 파일 형식 명세](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)를 기준으로 독립 작성했다. 타사 프로그램 코드·리소스·비공개 문서 형식을 사용하지 않는다. 아래 범위는 Drawer에서 검증하는 교환 범위다.

| 요소 | 읽기 | 쓰기·손실 |
|---|---|---|
| PSD v1 / PSB v2 | 길이 구간·큰 길이·헤더 검증 | PSD는30000, PSB도 앱의32768 치수 한계 적용 |
| RGB8, RGB 또는 RGB+투명 | raw / PackBits RLE | raw RGB8 sRGB; 16비트 원본은 출력만8비트 |
| CMYK/Lab/회색/인덱스/16·32비트 | 변환 안내 후 거절 | 지원되지 않는 편집 호환을 표시하지 않음 |
| ZIP / 예측 압축 | 명시적 미지원 오류 | 출력하지 않음 |
| 래스터 | 이름·범위·순서·알파·숨김·불투명도 | 캐시 픽셀과 검증한 메타데이터 유지 |
| 그룹 | 격리/통과·중첩·마스크 | 검증한 구조 유지; 효과 의존 범위는 합성 |
| 마스크 | 래스터·기본색·켜짐·반전·상대 위치 | 현재 캔버스 좌표로 샘플링; 링크/변형/밖의 범위는 손실 표시 |
| 혼합 모드 | 검증된25개 키 | Soft Light·Glow Dodge·Add Glow는 아래층과 합성 |
| 텍스트·스마트개체 | 캐시 합성이 내장 미리보기와 맞을 때만 래스터 대체 | 원문·폰트·루비·배치·원본 링크 편집은 보존하지 않음 |
| 보정·효과·벡터 마스크·추가 채널 | 미지원 블록과 손실을 표시하고 실제 내장 합성 사용 | 원본 개체명과 실제 최소 의존 범위·손실 확인 후 합성 |
| ICC·DPI | ICC 검증, 없으면 sRGB 안내; 해상도 리소스 또는300 DPI | sRGB ICC·해상도 기록; 임의 RGB ICC의 레이어 혼합은 합성 대체 |

PSB의 큰 구간 길이와 RLE 행 길이를 별도로 처리한다. 레이어 기록/채널은 아래층부터 쓰며 그룹 경계가 자식보다 먼저 나온다. 투명 합성의 RGB는 흰 바탕에 합성한 값으로 쓰고, 읽을 때 독립 알파로 복원한다. 알파가 작은 영역의 RGB 역변환에는8비트 양자화 오차가 있어 프리멀티플라이드 RGBA로 비교한다. 레이어 자체의 RGB/알파는 이 합성 미리보기 처리와 분리한다.

## 최소 변환과 미리보기

1. 원문서의 ID·개정·현재 프레임과 스냅샷을 고정한다. 계산은 별도 스레드의 복사본에서 수행한다.
2. 독립적으로 외관을 유지하는 텍스트/루비·벡터/그라데이션·3D를 기존 검증된 래스터 변환으로 대체한다. 표시/종이/표면 효과·파일 캐시도 해당 개체에서 굽는다.
3. 보정층·통과 폴더·클리핑·미지원 혼합처럼 바깥 아래층에 의존하면 같은 부모의 연속 구간을 작은 것부터 비교한다. 클리핑 기반과 전체 런을 포함해야 하며 필요하면 부모 폴더와 그 아래층까지 확장한다.
4. 변환 뒤 편집 가능한 교환 구조를 다시 문서로 구성해 원본 출력과 비교한다. 프리멀티플라이드 RGBA8 정수 차이가1보다 크면 부분 교환을 제공하지 않는다. 비교 예산을 넘는 경우도 이유와 전체 합성 대안을 표시한다.
5. 미리보기·원본 개체명·변환 범위·편집 손실을 확인한다. 전체 합성 선택 시 실제 범위는 모든 원본 개체이며 모든 분리 편집이 사라진다는 문구를 표시한다.

원문서의 잠금을 풀어 내보내는 것이 아니다. 잠금 편집 검사는 작업 복사본에서만 중립화하고, 출력에는 잠금·가이드·이력·책/타임라인·앱 설정을 보존하지 않는다고 알린다. 밑그림 제외·페이지 변형·타임라인 등으로 검증된 부분 합성이 불가능하면 전체 합성만 제공한다. 숨김 래스터는 가능한 편집 구조에 보존하며 숨김 원본을 조용히 부분 굽기에서 버리지 않는다.

## 파일 안전성과 취소

원본 `.drawer`와 가져온 PSD/PSB 경로는 대체할 수 없다. 기존 다른 출력은 별도 대체 확인이 필요하다. 문서 ID·개정·프레임이 달라진 준비 결과는 쓰지 않는다. 준비/쓰기 취소와 오류는 원문서의 픽셀·기하·텍스트·3D·경로·변경 표시·실행 취소 이력을 바꾸지 않는다.

로컬의 일반 파일만 사용한다. 독점 임시 파일에 전체 데이터 기록·동기화를 마친 뒤 새 목적에 독점 게시하거나 확인한 기존 목적을 교체한다. 자신이 만든 임시 파일만 정리하며, 이미 있던 임시 파일은 거절하고 보존한다. 이 정상 오류/취소 처리를 정전이나 강제 종료 뒤의 다중 파일 복구라고 주장하지 않는다.

읽기는 헤더·색 모드·깊이·모든 구간 길이·채널 중복·압축·행 길이·그룹 균형·마스크·ICC·정밀도·메모리를 검사한다. 편집 캐시의 합성이 내장 미리보기와 맞지 않으면 실제 내장 합성을 한 층으로 사용하고 손실을 알린다. 합성이 없거나 손상되면 임의의 빈 층으로 대체하지 않는다.

## 예산과 검증

캔버스/레이어/마스크당400만 픽셀, 래스터256개·그룹256개·깊이16·기록768개·마스크 런32768개를 제한한다. 현재 작업공간 메모리 예산과64Mi 비교 작업 한계를 함께 적용한다.

Rust 검증은 그룹/마스크/숨김/불투명도·PSD/PSB·DPI·와이어 순서·독립 RLE 표본·중복/초과/잘림·외부 임시 파일·원본 보호·확인 취소·오래된 준비를 포함한다. 통과 폴더 내부 보정, 클리핑 그림자, 텍스트+루비+3D 혼합을 내보내고 재가져와 합성과 변환 목록을 비교한다. UI 검증은 실제 egui 포인터 입력으로 확인·출력·취소를 거치고 원본 이력을 확인한다.

추가로 로컬의 독립 판독기 `psd-tools 1.10.9`와 NumPy/Pillow를 검증 도구로 사용한다. 앱 런타임이나 배포 의존성이 아니다. `scripts/verify-psd-exchange.py <표본 폴더>`는 내장 합성 대신 각 레이어를 독립 합성하고, 흰 바탕/알파 복원과 독립8비트 반올림을 포함한 차이가2단계를 넘으면 실패한다. 그룹·이름·숨김·마스크·불투명도와 미검증3모드의 합성 대체도 확인한다. 이는 모든 타사 버전/수식과의 비트 단위 일치나 모든 PSD 변형의 지원을 의미하지 않는다.

## 237 교환 결과표

입력 결과 창은 실제 헤더의 PSD v1/PSB v2와 치수를 표시하며 레이어·그룹·마스크·혼합 키별 유지/래스터 대체를 구분한다. 미지원 색·깊이·압축·편집 정보도 따로 표시한다. 같은 파일을 반대 확장자로 바꿔도 헤더를 따르며, PSB의 u64::MAX 구간 길이와 부족한 메모리는 할당 전에 거절한다. 출력 결과표는 선택한 구조 및 원본 변환 범위를 함께 제공한다.
