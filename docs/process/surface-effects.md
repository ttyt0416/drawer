# 161 — 편집 가능한 발광·부풀리기·그림자·결정화

레이어의 안정 ID에 순서 있는 효과 목록을 연결한다. 원본 RGBA/정밀도는 보존하고 목록/활성 상태/색/매개변수/복사한 선택/출력 마스크를 자체 문서v74에 저장한다. 효과 참조는 자기 소스에만 연결하며 다른 효과의 결과를 입력으로 참조하지 않는다. 기존 파일의 빈 데이터는 기본값이고 이전 버전으로 위장한 효과 데이터와 존재하지 않는 소스 ID는 거절한다.

그림자는 소스 알파에 독립 RGB와 불투명도0–1을 지정하고 방향(오른쪽0°, 아래90°)/거리0–256px로 이동한다. 흐림0–32px는 투명한 바깥 표본의3회 분리 box 평균으로 계산하고 이동은 bilinear 표본을 사용한다. 원본 아래에 합성하므로 저장된 원본 색/알파는 바뀌지 않는다. 색은 직접/검정/현재 주색/현재 보조색을 복사한다.

발광은 알파×명도의 밝은 내용에서 시작하여 퍼짐0–32px의 사각 최댓값과 별도의 흐림0–32px를 적용한다. 세기0–4는 색/알파 기여만 바꾸며 패턴의 반경과 흐림을 바꾸지 않는다. 색을 지정한 발광을 원본 아래에 합성한다. 세기0은 원래 출력이다.

부풀리기는 알파×명도×최대 높이0–32px에서 높이장을 만들고 평활화0–32px로 작은 요철을 줄인다. 중심차분 법선과 두 축 광원 X/Y−1–1, 고정된 양의 Z를 정규화한다. 음영0–2와 반사 광택0–2를 독립 적용하며 원본 알파를 유지한다. 높이0 또는 음영/광택 모두0은 원래 출력이다. 저장 광원은 X/Y를 한 쌍으로 읽고 어느 한 축 누락/비수치/범위 밖이면 두 축 모두 명시적 기본값(−0.6,−0.8)으로 복원한다. 유동화 도구와 별개다.

결정화는 셀1–256px, 불규칙도0–1, 문서 픽셀 오프셋 X/Y, 타일링과 정수64비트 시드를 받는다. 독립 해시로 셀 중심을 흔들고 이웃3×3에서 가장 가까운 중심의 색/알파를 읽는다. 오프셋은 패턴을 이동한다. 타일링은 셀 간격을 소스 길이에 맞추고 셀 해시와 색 표본을 함께 주기화하여 소스 가로/세로 길이만큼 이동하면 같은 출력이다. 셀1/불규칙도0은 항등이다.

원본 렌더/표현색→소스 마스크와 효과 전 기초층 알파 클리핑→기존 테두리/수채 경계→목록 순서의 공간 효과→출력 마스크→레이어 불투명도/혼합→상위 폴더 마스크 순서다. 색 계산은 명시적sRGB에서 하고 문서 작업 프로필로 되돌린다. 소스 마스크가 지운 부분은 효과를 생성하지 않지만 생성된 테두리/발광/그림자는 소스 마스크 밖으로 퍼질 수 있다. 클리핑 기초층의 효과 전 알파를 사용하고 다른 효과 캐시는 생성 중 읽지 않는다. 클리핑 묶음의 원래 알파를 유지하며 실제로 확장된 효과 커버리지는 묶음 밖에 나타난다. 선택 제한은 최종 효과 결과를 원본과 coverage 혼합하며 원본 저장 픽셀을 변경하지 않는다. 선택/좌표계/이동을 생성 시 복사하여 이후 활성 선택에 영향받지 않는다.

출력 마스크는 현재 선택을 문서 픽셀 coverage로 복사한다. 소스 마스크와 따로 저장하고 활성/반전을 편집할 수 있다. 같은 효과 창의 목록 추가/제거/순서/매개변수/출력 마스크 초안은 Prepare/Apply 하나의 사용자 확정으로 한 Undo가 된다. 기존 소스 마스크 편집은 기존 마스크 명령의 한 Undo를 유지하며 다음 렌더에서 효과를 재계산한다.

별도 래스터 확정은 같은 작업 프로필/8·16비트로 결과를 저장하고 원본을 숨겨 보존한다. 원본에 이미 있던 효과 목록도 유지하며 결과 레이어에는 확정 레시피를 별도로 보관한다. 클리핑 관계가 있으면 전체 묶음을 렌더해 같은 위치에 결과를 놓고 원래 묶음을 보존·숨긴다. 복합 모드/투명 마스크와 묶음 결과를 미리보기에서 확인한다. 일반 병합/평탄화/종이 래스터화도 같은 효과 렌더와 확장 경계를 사용하고 소비한 효과 메타데이터를 제거한다. 클리핑된 단일 표현색 변환은 묶음 래스터화를 안내하고 연결 파일 변환은 효과를 별도 결과로 먼저 확정하도록 안내하여 이중 마스크/효과를 방지한다.

미리보기는 고정 문서/수정번호/프레임/대상을 별도 계산 작업에서 처리한다. 커널/표본/픽셀 중단을 확인하고 취소/닫기/Escape는 원본과 구조를 변경하지 않는다. 중단 중 중복 계산을 거절하며 오래된 결과, 바뀐 옵션, 실패한 이전 계획을 적용하지 않는다. 전후 축소 이미지는 계산 작업에서 생성한다. 미확정 저장은 확정/취소를 안내하고 저장을 중단한다. 마지막 종류별 도구 설정은 적용 성공 후에만 로컬 작업공간에 원자적으로 저장한다. 문서 실행 취소는 도구 최근값을 되돌리지 않는다. 로컬 저장 실패는 이전 설정을 유지하고 문서 적용 여부를 설명한다.

최대16효과/레이어,256개 레이어 레코드,출력1M픽셀/축32768/64M 추정 작업량,장면JSON4MiB와256MiB 문서/작업공간 예산을 사전 검사한다. 소스와 프리뷰/Undo 메모리를 함께 확인한다. 효과 캐시를 파일에 대신 저장하지 않는다. 외부 모델/클라우드/원제품 코드나 자산은 사용하지 않는다. 실물 펜 검증은 별도로 대기한다.

클리핑 기초층의 별도 종이 합성이 지우기 등 배경에 의존하면 묶음만의 래스터 확정을 거절하고 실시간 효과 유지 또는 배경을 포함하는 Flatten page를 안내한다. 일반 레이어 혼합 모드는 결과 층에 보존한다. 매개변수 누락은 효과 종류별 안전한 항등값(결정화 셀1, 나머지 효과량0)으로 복원한다. 새 효과 상태·최근 도구 설정·패널은 힙에 두어 기존 앱96KiB 크기 제한을 유지한다.
