# 136 — 문서 정밀도와 RGB 색 경계

새 문서 창은 RGBA 채널당 16bit를 기본 선택하며 8bit도 제공한다. 새 8/16bit 문서는 부동소수점 계산을 사용한다. 종래 파일과 내부 호환 시험의 `LegacyEight`는 과거 외관/계산을 유지한다. Document color 명령의 미리보기/적용으로 새 계산에 전환한다. 프로파일 없는 과거 RGB는 sRGB로 해석한 사실을 편집기에 표시한다.

저장형은 정수 RGBA8 또는 RGBA16이고 합성은 unassociated RGB와 별도 alpha를 float64로 운반한다. source-over/선택 보간은 premultiplied 수식이다. 테두리/수채 표시 캐시는 RGBA float32다. 각 혼합 규칙의 성분 제한/문서 색역 제한과 정수 양자화는 구분한다. 브러시 획 안의 도장·운반색·혼색·희석·번짐·수채 가장자리, 레이어/폴더/클리핑/보정·그라데이션 합성은 중간 RGBA8로 내리지 않는다. 기본 정수 저장은 clamp[0,1] 후 floor(x×255/65535+0.5)이며 alpha가 0이면 RGB도 0이다. 16bit 원본의 RGBA8 배열은 미리보기 사본이고, 검증/잠금/알파 보호/Undo는 실제 16bit 평면을 비교한다.

디더링은 기본 끔이다. 켜면 문서에 고정 시드를 보존하며 문서 좌표와 채널의 독립 해시로 최종 RGB 양자화에 반 단계 미만의 잡음을 더한다. 알파는 디더링하지 않는다. 정확한 저장 정수를 다시 저장할 때 경계 부동소수점 오차로 값이 바뀌지 않도록 반 단계 끝점을 피한다. 자체문서 재열기는 저장 정수를 그대로 복원한다.

픽셀은 문서 RGB ICC에 속한다. 혼합/보정은 문서 RGB→sRGB 성분→정의된 계산→문서 RGB 순서다. ICC 변환의 중간 sRGB가 색역 밖으로 나가도 Normal 합성 전에 잘라내지 않으며 float64 CMS 경로를 사용한다. 같은 프로파일 바이트는 이름만 달라도 항등변환이다. RGB ICC만 최대 4MiB로 허용하고 알파는 CMS를 통과시키지 않는다. Gray는 선형 sRGB의 .2126/.7152/.0722 명도를 다시 부호화하며 Mono는 명도/알파 >= 임계값을 통과로 판정한다.

Document color 편집기는 정밀도·시드·로컬 ICC와 Convert/Assign을 동결 미리보기한 뒤 한 번 적용한다. 16→8에서 달라지는 저장 채널 수/최대 차이와 전후 화면을 표시한다. Assign은 숫자를 유지하면서 의미/외관이 바뀔 수 있음을 알린다. 실제 프로파일 변환에서 벡터/소재/애니메이션 또는 고정 8bit 표시색을 보존할 수 없으면 자동 변경하지 않는다. 사용자가 현재 프레임 래스터화 옵션을 명시적으로 선택하면 전체 표시를 부동소수점으로 합성/변환하고 최종 정밀도에 한 번 저장한다. 이 옵션은 숨김/문서 밖 데이터와 편집 구조를 없앤다는 경고가 있으며 한 Undo가 원본 구조·정밀도·프로파일을 모두 복원한다. 프레임/문서 수정 뒤 낡은 미리보기 확정과 Escape 취소는 무변경이다.

래스터 채우기·그라데이션·선택 픽셀 이동·크기 변경/회전·마스크/종이 굽기·래스터화·병합·아래 층 전송·표현색/톤 편집에도 실제 샘플 경로를 연결한다. 새 래스터는 문서 전체의 빈 편집 영역을 만든다. 내부 클립보드는 16bit 샘플과 RGB 프로파일을 보존하며 외부 시스템 클립보드는 sRGB RGBA8이다. 로컬 비트맵 소재와 파일 참조 캐시는 명시적 sRGB RGBA8 입력 어댑터이며 문서 색역으로 변환한 뒤 합성한다. 가져오기 코덱의 기존 RGBA8 지원 범위를 16bit 파일 가져오기로 확대했다고 간주하지 않는다.

화면과 각 독립 보기는 문서 RGB에서 표시용 sRGB로 변환하고 소프트프루프를 적용한다. 최종 화면 텍스처만 RGBA8이며 문서 샘플/변경 상태/이력은 변하지 않는다. PNG8은 문서 RGB의 최종 정수 출력과 해당 ICC를 기록하고 문서 정밀도를 바꾸지 않는다. PSD 교환은 명시된 RGB8 sRGB 출력이며 정밀도 손실을 안내한다. CMYK는 기존 검증된 입출력 어댑터 경로만 사용한다.

검증 범위는 정수 양자화의 모든 반 단계 양쪽·0/1·모든 65536단계·알파0 정규화·8/16 왕복·실제 8/16bit 브러시 1000회 저농도 도장·저알파 혼색/복제/번짐·선택/잠금·마스크·ICC 색역/흰점·자체문서 재열기·PNG/PSD·클립보드·마우스/가상 펜·실제 버튼 미리보기/Undo·독립 보기/화면 업로드다. float64 별도 수식과 정수 1LSB를 기준으로 비교한다. 실제 GPU 검증은 설치 실행의 현재 OpenGL 문맥에서 RGBA32F 셰이더를 실행하여 28개 모드×6패치×4불투명도, 1000회 누적 3종과 알파 반 단계 양쪽/정확한 경계를 각각 GPU 안에서 8/16bit 정수로 변환한 1362개 출력을 CPU float64와 비교한다. 일반 문서 합성은 CPU 경로이며 GPU 검증이 GPU 가속 편집 전체를 의미하지 않는다. 물리 펜 검증은 사용자의 지시에 따라 추후 실시한다.

고비용 래스터 연산은 평면당 4Mi 표본, Undo 상태는 기존 64MiB, 전체 작업공간은 256MiB 예산을 따른다. 실패/취소 시 원본과 기존 파일을 보존한다. 원본 앱 코드·소재·런타임은 사용하지 않는다.
