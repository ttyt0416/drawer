# UV 표면 채색·UV 보기와 로컬 텍스처 (219)

`uv-paint`에서 UV가 있는 모델을 고르고 왼쪽 페이지 투영 위에 마우스로 한 획을 그린다. 오른쪽은 색 텍스처와 UV 선을 겹쳐 보는 단위 타일이다. 획을 놓으면 원본과 분리된 미리보기가 생기고 Apply stroke 한 번이 한 Undo이다. 진행 중 새 획은 먼저 적용/폐기한다. 다른3D 초안과 겹치지 않으며 Discard/Esc/포커스 상실·창/문서 닫기·리비전/프레임 변경은 초안을 버린다. Esc/포커스 상실 후에는 버튼을 놓아야 새 획을 시작한다.

화면 점은 페이지/레이어·2D 카메라 변환을 역으로 적용하고3D 광선의 가장 가까운 모델 면에서 UV를 보간한다. 다른 앞쪽3D 개체와 UV 없는 앞면을 관통해 그리지 않는다. 화면 경로를 촘촘하게 표본화하고 UV가 이어진 같은 면/인접 면만 텍스처 좌표 사이를 연결한다. 불연속 UV 섬 사이에는 연결선을 그리지 않으며 타일 가장자리는 반복해서 칠한다. UV 겹침은 제한된 공간 격자/정확한 삼각형 교차 면적으로 검사하고 공유 픽셀·부분 UV·타일 밖 반복이나 분석량 초과를 안내한다. 실제 경고가 있는 획은 검토 확인 전에는 적용할 수 없다. UV가 전혀 없으면 채색 불가 안내를 표시한다.

이 기능은 불투명 RGB diffuse 색 맵이다. 색과0..1 불투명도를 기존 불투명 색에 섞으며, 투명도 지우기·노멀/금속/거칠기 맵 생성은 제공하지 않는다. 초기 흰 맵은 기존 재질 색을 유지하고 색 맵은 재질 색과 선형광에서 곱해진다. Wire/조명 설정 없음의 경우 Apply에 Unlit 채택을 포함해 텍스처가 보이게 한다. 이미 선택한 면 렌더 스타일은 유지한다. 이 변경도 같은 Undo에 포함된다. 픽셀 샘플은 반복 타일의 최근접 방식이다.

새 맵은64/128/256/512/1024 정사각형, 브러시 반경0.5..64텍스처 픽셀이다. 기존 맵의 크기는 유지한다. 획8192입력점·65536화면 표본·UV 보간 구간4096도장·전체1600만 픽셀 작업량과 사본/디코드/가속 구조 메모리 예약을 검사한다.0 불투명도는 이력을 바꾸지 않는다. 숨김/각종 잠금/파일 개체 대체, 잘못된 수치·예산·취소·오래된 결과를 보호한다. 타일을 공유하는 다른 면도 함께 색이 바뀌며 겹침 경고로 이를 명시한다.

문서에는 자체 version1의 크기/불투명 RGBA8 PNG를 내장해 외부 원본에 의존하지 않는다. native112가 이 맵을 저장하고111 위장을 거절한다. PNG 디코드에 최대1024변/16MiB 할당과 인코드/메타데이터 한도를 적용한다. 텍스처는 디코드 픽셀까지 문서 메모리로 계상하며, 확정 전에 자체 문서의 전체4MiB 장면 메타데이터 용량도 검사한다. 복잡한 장면/고밀도 맵이 이 한도를 넘으면 원본을 보존하고 획을 거절한다. 해상도를 낮춰 새 맵을 시작하거나 장면을 나누어 저장할 수 있다. 복제된 표면 맵은 독립이며 리그 체형/포즈 재생성 때도 맵을 보존한다.

Export texture PNG는 현재 확정 맵만 로컬 PNG로 내보내고 별도 준비 파일을 기록·동기화 후 교체한다. 모델/OBJ·원본 재질 참조 파일은 수정하지 않는다. PNG 이외의 경로는 거절한다. 물리 펜 검증은 유보한다.
