# 110 — 선택 바로가기 막대와 윤곽 변환

선택이 있는 문서에 표시하는 바로가기 막대를 제공한다. 표시 여부와13종 명령의 추가·제거·순서를 임시 편집한 뒤 적용하며 취소/초기값을 지원한다. 설정은 작업공간에 보존하고 가져오기의 막대 범위에 포함한다. 그리기 이력을 바꾸지 않는다. 선택 창의 설정 버튼으로 선택이 없는 문서에서도 편집할 수 있다.

벡터 경로나 연결된 직선 자의 유한 끝점 윤곽을 선택 마스크로 바꾼다. 숨긴/잠긴 벡터를 명시적으로 읽을 수 있고 선폭·색·원래 경로/자/픽셀은 바꾸지 않는다. 닫힌 벡터는 중심 경로가 둘러싼 영역이며 자는 선택한2–32개 유한 선분을 끝점 허용 오차1e-6으로 연결한다. 선분 순서/방향은 무관하다. 분기·중복·분리·면적 없는 윤곽은 거절한다. 대칭/원근 자의 무한 보조선은 유한 폐영역으로 해석하지 않는다.

원래 페이지 좌표를 현재 문서 좌표로 바꾼 뒤 기존4×4 면적 표본·Replace/Add/Subtract/Intersect 연산을 적용한다. 열린3점 이상 경로/자 사슬은 닫힐 마지막 선을 자홍색으로, 결과 선택을 파랑으로 미리 보여준다. 자동 닫기 확인 전 적용 버튼은 비활성이다. 원본은 열린 상태를 유지한다. 윤곽/연산을 바꾸면 동의는 초기화한다. 미리보기는 문서ID/수정본/프레임을 고정하고 입력 변경 때만 다시 계산하며 변경된 문서에 적용하지 않는다. Escape/Cancel은 무변경, Apply는 한 Undo다. 막대의 윤곽 표시 전환은 선택/이력을 유지하고 Undo/Redo는 기존 그리기 이력을 이용한다. 영역→제어점/교차 획 선택은108 구현을 연결한다.

기존4Mi 격자·32768 runs·64Mi 표본 연산과 JSON/메모리 한도를 사용한다. 새 문서 형식은 필요 없다. 창 너비를 고정하고 자 목록만 높이 제한 스크롤하여 입력 중 적용 버튼 이동을 방지한다.

독립 검증: 부분128 선택과 네 연산의128/192/64·255/128/0 결과, 원본 보존/한 Undo, 열린 경로 확인/원본 열린 상태, 뒤섞인 역방향 자/분기·중복 거절, 페이지 회전·배율, 문서/설정 재열기, 막대 가져오기 범위와 중복 거절. 생산 검증: 벡터/자×열림/닫힘의 네 조합에서 실제 확인/적용/윤곽/Undo/설정 적용 버튼, 무변경 미리보기, 순서·저장, 오래된 상태 거절과 Escape 취소.
