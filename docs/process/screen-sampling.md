# 088 캔버스 참조 스포이트와 로컬 화면색

캔버스 Composite RGBA는 문서의 저장 RGB 공간을 기준으로 기존 렌더러를 사용한다. 표시 프로필/선택 테두리/커서는 포함하지 않는다. 참조 기능을 켜면 전체 또는 명시적 래스터층 목록을 포함하고 제외 목록을 우선한다. 현재층 raw RGB/RGBA 모드는 이 참조 설정과 무관하다. 종이/폴더 효과, 숨김/클리핑을 존중하며 페이지 개체/3D, 벡터, 애니메이션 포함을 각각 선택한다. 참조는 로컬 설정이며 저장 경로(미저장 문서는 세션/문서 ID)에 묶어 다른 문서의 레이어 인덱스에 적용하지 않는다. 현재 단계의 래스터 참조는 인덱스다. 삭제로 존재하지 않는 참조가 생기면 합성 추출을 거절하고 목록 새로 고침을 요구한다. 향후 레이어 재정렬 명령은 이 인덱스 참조도 함께 갱신해야 한다.

샘플 반경 0–4는 홀수 1/3/5/7/9 사각 커널이다. UI는 1/3/5/9를 제공한다. RGBA와 합성 평균은 premultiplied RGB/알파, RGB-only는 숨은 RGB도 포함한 저장 RGB 평균이다. 전체 알파0의 저장 RGB는 유지하며 값이 모두0이면 현재색을 유지한다. 캔버스 경계에서 유효 픽셀만 평균한다. 선택 영역은 추출 범위를 제한하지 않는다.

화면 추출은 화면색 전용 명령이다. 사용자가 명령한 후 별도 로컬 UI 스레드의 전체 가상 화면 선택 창이 클릭을 받아 아래 프로그램에 전달하지 않는다. 명령을 시작한 마우스의 남은 Up은 새 Down 전까지 무시한다. 클릭 확정 전에는 화면 픽셀을 읽지 않는다. Esc/오른쪽 클릭/포커스 상실/작업공간 변경/앱 종료는 취소하고 5분 타임아웃이 있다. 작업은 동시 한 개만 실행한다.

확정 시 선택 창을 숨기고 DWM 동기화 뒤 GDI로 최대81개 화면 RGB만 읽는다. 영상을 저장하거나 외부 전송하지 않는다. 물리 커서 좌표와 Per-monitor-v2 스레드 DPI 문맥을 사용하고 음수 좌표/다중 DPI를 별도 배율로 다시 변환하지 않는다. 가상 화면 경계의 커널을 자르고 실제 모니터 사이 빈 공간은 제외한다. 화면 RGB는 산술 평균이며 알파가 없으므로 명령 시작 시 그리기 알파를 유지한다. 프로필·모니터·HDR/보호된 콘텐츠의 원래 문서값을 추정하지 않는다. 취득 불가는 실패로 표시한다.

창 숨김 옵션의 원래 표시/최대화/위치와 원래 포커스를 보존한다. 성공/취소/오류/스택 되감기에서 복원 가드가 실행된다. Windows가 포커스 복원을 거절하면 창은 복원하고 오류를 표시하며 색을 바꾸지 않는다. 화면 추출 성공만 색 이력/선택색을 갱신하고, 자동 색상표 등록은 시작 시 고정한 표로 확정한다. 삭제된 표를 재생성하지 않는다. 명령 키 반복은 재시작하지 않는다. 원본 문서 픽셀/그림 Undo/dirty와 분리된다.

검증: 3×3의 알파0/128/255 가중 기준값, raw RGB 독립, 참조/제외 우선순위/빈 명시 목록/다른 문서/누락 참조, 벡터/페이지 개체 제외, 음수 가상 화면/끝점/커널/모니터 틈 fixture를 확인한다. 생산 캔버스 입력의 제외층 영향, 화면 성공/실패/취소의 색/알파/이력, 자동 색상표 등록·설정 재시작과 문서 불변을 검사한다. Windows에서는 숨겨진 자체 창의 성공/취소/오류 배치·표시 복원과 선택 창 hit-test를 검사하고 자체 3×3 메모리 비트맵을 실제 GDI로 읽는다. 자동 시험에서 다른 프로그램 화면을 읽거나 물리 입력을 생성하지 않는다. 실제 여러 모니터의 대화형 클릭/운영체제 포커스 정책은 이 fixture 검증과 구분된다.
