# 구현 명세 검토 기록

전달 입력은 `docs/specs/feature-checklist.md`다. 309개 항목은 사용자 입력·관찰 가능한 결과·새 앱의 저장/취소 규칙·완료 검증으로 구성돼 있다. 독립 설계 기본값은 원본 상수를 복사한 값이 아니라 새 앱의 결정으로 명시돼 있다.

본문 구조와 원본 코드로 의심되는 표기 검색 결과를 검토했다. 내부 함수명·원본 메모리 주소·디컴파일 자료구조·원본 설치 경로를 구현 명세에 포함하지 않았다. 조사 파일과 추출 자산은 전달 목록 밖에 있으며, 구현 전달 묶음에 없다.

`xtask audit-specs`는 전달 목록의 `docs/specs` 파일 전부를 검사한다. 의심 표기를 발견하면 경로와 유형을 표시하고 실패한다. `prepare-handoff`도 같은 검사를 통과해야 복사한다. 자동 검사는 명세 검토를 보조하며 변경된 명세는 커밋 전에 다시 검토한다.

Rust 소스·관리 도구는 이 저장소에서 새로 작성한 파일이다. 자동 검사 도구의 거절 시험에는 검사 대상 표기 예시가 있지만 원본 코드·추출 자료를 복사한 것이 아니다.
