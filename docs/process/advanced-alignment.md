# 115 — 세부 정렬·분배·개체 스냅

Align and distribute objects에서 선택 개체·캔버스·선택 영역·기준 개체·페이지 가이드를 기준으로 여섯 변/중심을 맞춘다. 기준 개체는 움직이지 않는다. 문서 좌표에서 해당 축에 수직인 가이드만 정렬 기준으로 허용하며 기울어진 가이드는 무변경 거절한다. 가이드는 한 위치를 제공하므로 변/중심 분배의 목표 간격은0이고 음수 빈 간격은 거절한다.

왼쪽/오른쪽/위/아래 변과 수평/수직 중심의 분배, 수평/수직 빈 간격 분배를 구별한다. 선택 기준의 변 분배는 처음/마지막 해당 변의 위치를 보존한다. 명시적 캔버스/선택 영역/기준 개체는 그 경계 사이로 해당 변을 분배한다. 기존 중심/빈 간격 명령은 첫/마지막 개체를 기준 경계 안에 유지하며 간격이 모자라면 전체를 거절한다. 분배는 움직일 개체가 세 개 이상 필요하다. 모든 이동과 적용한 선택 목록/기준/경계 옵션을 하나의 문서 상태/Undo에 보존한다. 문서v44이며 이전 문서의 누락 필드는 기본값이다.

Align to text pixels는 로컬 내장 글꼴의 실제 렌더 경로와 문서 격자의 픽셀 중심 점유를 사용한다. 문자 상자의 공백·행 여백과 구별하고 투명 문자/공백만 있는 문자는 적용하지 않는다. 다른 층의 색은 경계 판정에 쓰지 않는다. 캔버스 밖 글자도 정렬로 가져올 수 있도록 페이지 경계로 자르기 전의 격자 경계를 사용하며 문서 클립은 반영한다. Align to vector paths는 저장한 경로 중심선의 경계이며 선폭을 포함하는 외곽선과 구별한다. Ignore transparent raster margins는 알파0인 래스터 여백을 제외한다. 래스터는 정수로 이동하고 기존 픽셀을 보존한다.

Snapping priority and temporary disable의 Object bounds and center lines / Vector control points / Canvas edges를 독립적으로 켠다. 기본값은 모두 꺼짐이다. 활성 자→페이지 가이드→가장 가까운 개체/제어점/페이지 변→격자 순으로 적용한다. 새 표적은 유한 선분/점이며 거리는 실제 화면 픽셀에서 문서 단위로 환산한다. 동률은 정확한 제어점을 먼저, 나머지는 문서 순서를 사용한다. 개체 경계 스냅은 외곽 상자와 중앙 선분이며 정렬의 픽셀/경로 경계 옵션과 독립이다. 숨긴 표적은 제외하고 잠근 표적은 읽기 참조할 수 있다. 수정키 해제는 기존 스냅과 공유한다.

브러시·도형·벡터 자유획의 공통 입력에 새 표적을 연결한다. 래스터 전체층 이동은 원래 경계의 네 모서리/중심으로 표적을 찾고 자기 층을 제외한 채 이동량을 보정한다. 원본에서 매번 계산하므로 중간 표본 수에 따라 누적되지 않는다. 설정·문서·보기·장치가 달라지면 진행 중 이동을 취소한다. 확정은 한 Undo, 놓기 전 미리보기는 원본 불변이다.

정렬 대상8192·개체 표적65536·픽셀 경계4Mi/32k차원·합계64Mi 문자/래스터 경계 작업과 기존 문서/작업공간/JSON4MiB/이력 한도를 검사한다. 스냅 표적 메모리를 획 예산에 포함하고 누적64Mi 판정 초과 시 취소한다. 독립 수치·실제 렌더 픽셀·저장/설정 재열기·실제 버튼·마우스/가상 펜 입력을 검사하며 실제 펜 센서 검증은 별도다. 외부 서비스나 다운로드는 사용하지 않는다.
