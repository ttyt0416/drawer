# 기본 브러시

기능 055. Pen/Pencil/Eraser/Airbrush 네 독자 프리셋은 내장 수식과 수치로 생성한다. 외부 소재/네트워크/원본 리소스에 의존하지 않는다. 공통 크기12px, 비율1, 각도/안정화0. Pen/Pencil/Eraser는 농도1·경도1·간격.15, Airbrush는 .6/0/.1이다. Pen은 단단한 원, Pencil은 문서좌표 결정적 입자, Eraser는 기존 RGB를 유지하는 알파 제거, Airbrush는 세제곱 중심 감쇠와 부드러운 가장자리다. Airbrush는 팁·별도 획에서 누적하며 농도 상한은 한 획에 적용된다. 정지 시간 분사는 별도 선택 동작이다.

기존 Wash 직렬화/명령 ID는 유지하고 화면 표시만 Airbrush로 분리한다. 구형 문서·단축키·순환·설정 값을 강제 초기화하지 않는다. fresh panels/default properties만 새 기본값을 사용한다. 기본값 복원은 선택 브러시의 값·필압 매핑·마우스 동작을 임시본으로 미리 보고 수락/적용해야 저장한다. 속성 표시·다른 브러시·장치/UI설정·색·문서 이력은 유지한다. 여러 브러시 복원을 같은 임시본에 모을 수 있다. 전체 취소·미리보기 취소·적용 전 백업·재시작은 기존 로컬 작업공간 트랜잭션을 따른다.

동일 경로의 네 팁 픽셀 차이, 에어브러시의 별도 획 누적, 지우개 외부 보존, Undo/Redo, 기본값/표시 분리, 구형 ID, 실제 설정 창의 미리보기 취소/전체 취소/적용/백업/재시작을 검증한다. 설치본에서도 같은 픽셀 경로를 실행한다. 실제 펜 검증은 별도 대기한다.
