# 텍스트 입력과 기본 배치 (175)

`text-editor`는 선택한 텍스트 개체를 편집하고, 텍스트가 선택되어 있지 않으면 새 편집 개체를 만든다. 문자열·글꼴·크기·좌/중앙/우 정렬·줄 간격·자동 줄바꿈 폭·기준선 위치·색을 문서에 보존한다. 원래 래스터 픽셀은 바꾸지 않는다. 새 개체는 보이는 소스 순서의 끝에 놓으며 기존 개체 편집은 안정적 ID와 합성 위치를 유지한다.

## 글꼴과 배치

- Ubuntu Light / Hack Regular / Noto Emoji는 기존 의존성의 고지된 내장 글꼴을 사용한다.
- Malgun Gothic은 기존 UI 글꼴과 마찬가지로 로컬 Windows의 `Fonts/malgun.ttf`를 읽는다. 설치/수정하거나 배포 묶음으로 복사하지 않는다. 네트워크 글꼴이나 다운로드는 없다.
- 기본 글꼴에서 글리프가 없으면 로컬/내장 글꼴을 조회한다. 다른 글꼴을 쓴 문자 수와 누락 글리프 수를 미리보기에 표시하며 원문 Unicode는 유지한다. 이모지는 흑백 윤곽이다.
- 글꼴의 실제 가로 진행 폭을 사용한다. 지정 폭이0이면 자동 줄바꿈 없이 가장 긴 줄을 기준으로 정렬하고, 양수이면 그 폭 안에 줄을 배치한다. 줄바꿈은 현재의 문자 단위 기본 배치이며 고급 세로쓰기/합자/문자군 서식은 별도 항목의 범위다.
- 줄 간격은 글자 크기에 대한 기준선 간격 배수0.5~8이다. 글자 크기는0.1~4096, 줄바꿈 폭은0~32768 페이지 픽셀이다. 문서/개체 변환은 기존 페이지 좌표 정책을 따른다.

곡선 윤곽은 기존 글리프 렌더 경로를 사용한다. 긴 텍스트가 매 픽셀마다 모든 윤곽을 훑지 않도록 윤곽 경계 계층을 만든다. 텍스트4096문자/64KiB, 개체별512K·페이지 전체1M 윤곽 점과 기존 문서/Undo/장면 예산을 적용한다. 전체 텍스트의 기존 페이지 문자열 예산도 유지한다. 범위를 넘는 입력은 미리보기/저장 시 오류로 거절한다. 빈 문자열은 편집 가능한 빈 개체로 저장한다.

## 편집과 확정

필드 안의 입력/IME 조합은 임시 편집 상태다. 조합 확정값마다 필드의 실행 취소 단위를 분리하며 조합 중간 문자열을 필드 이력에 누적하지 않는다. 조합 중 Escape/필드 취소는 확정 전 문자열과 커서를 복원한다. 조합을 끝내거나 취소하기 전에는 결과 준비/문서 적용을 막는다. 미리보기는 원본을 유지하고 설정/원본/프레임 변경 후 이전 결과를 적용할 수 없다.

Apply는 개체 생성 또는 수정 전체를 한 Document Undo로 확정한다. 취소/닫기는 원본을 유지한다. 편집 중 저장/문서 닫기는 적용 또는 취소를 안내하며 문서를 보존한다. 글꼴 변경은 파일을 수정하지 않는다. 기존 레이아웃 없는 텍스트는 파일을 열기만 할 때 기존 렌더를 유지하고, 편집 확정 때 새 레이아웃 속성으로 저장한다.

네이티브v86은 원문·글꼴 참조·크기·색·정렬·줄 간격·폭·기준선을 저장한다. 윤곽/글꼴 캐시는 원문과 매개변수에서 재생성하며 문서의 유일한 원본으로 사용하지 않는다. 글꼴 참조와 윤곽 예산을 읽기/쓰기에서 확인하고 이전 버전 헤더 위장을 거절한다.

검증 범위는 빈 텍스트·긴 줄/여러 줄·한글/숫자/이모지·글꼴별 진행 폭·좌/중앙/우 정렬·기준선 간격·잘못된 수치/크기·원본 래스터 보존·개체 ID 유지·미리보기/취소·필드 조합/확정 단위 취소·미확정 저장/닫기·한 Undo·네이티브 재열기다. 실물 펜 검증은 대기한다.
