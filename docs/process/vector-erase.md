# 142 — 선 단위 선택·삭제와 지우기 모드

Layers의 Select vector strokes로 점이나 곡선을 클릭해 획 전체를 선택한다. Shift는 추가 선택이며 기존 후보 표시/Tab 순환·일시 점편집을 공유한다. 선택한 획의 경로를 노란색으로 표시한다. Delete selected strokes는 선택 획만 한 Undo로 삭제한다. 층과 다른 획·스타일·참조를 유지하고 선택 데이터를 정리한다.

Vector eraser는 네 벡터 모드를 제공한다. Do not erase는 벡터를 유지하고 래스터 접촉 지우기는 허용한다. Erase touched areas는 원형 지우개와 실제 가변 굵기의 접촉 구간을 잘라낸다. Erase up to intersection은 가장 가까운 중심선 점이 속한 교차점 사이 구간을 지운다. 정확히 교차점인 경우 진행 방향의 다음 구간을 선택하며 열린 선의 마지막 끝점은 앞 구간을 선택한다. Whole line은 닿은 획 전체를 지우고 채움이 있는 객체는 내부 클릭도 허용한다. 부분/교차 지우기는 채움을 가진 객체에서 손실을 만들지 않고 전체 선 모드를 안내한다.

Refer all layers는 보이는 벡터 중심선을 교차 참조로 읽는다. 잠긴 참조도 읽을 수 있으며 참조 확장만으로 다른 층을 편집하지 않는다. 기본 범위는 현재 벡터층과 기존에 명시한 교차 참조층이다. 자기 교차는 포함하고 자기 자신/인접 선분의 일반 연결점은 교차점으로 세지 않는다. 숨김·보이지 않는 선은 참조하지 않는다. 래스터 픽셀에서 벡터 교차점을 추정하지 않는다.

Erase on all layers는 별도의 실제 편집 스위치다. 보이는 편집 가능한 래스터와 벡터층을 함께 처리한다. 전체/픽셀/알파 보호·연결 원본 캐시는 유지하고 다른 객체 종류도 유지한다. 명시적으로 고른 편집 불가능한 대상은 오류로 안내한다. 부분 래스터 선택은 래스터 지우기에 적용하며 편집 가능한 벡터 지우기에서는 선택 해제를 안내하고 전체 작업을 취소한다. 실패 시 부분 결과를 문서에 적용하지 않는다.

지우개 반경은 문서 픽셀이다. 캔버스에는 원형 반경과 확정 전 결과를 표시한다. 드래그를 반경 절반 이하 간격으로 보간하고 한 드래그의 결과를 한 Undo로 확정한다. 놓기 전 원본/이력은 불변이다. Escape·포커스 상실·입력 취소·문서/수정본/프레임/보기/대상/도구/설정 변경은 전체 임시 결과를 버린다.4,096 입력 표본·스냅샷 크기/누적 작업량·교차 계산/개수·기하/JSON/Undo 메모리 한도를 검사한다. 모드·반경·두 범위 스위치는 로컬 작업공간에 저장한다.

균등 문서 변환은 원형 단면과 선형 반경의 접촉식을 사용한다. 비균등 확대/기울임은 변형된 타원 단면까지의 거리와 접촉 매개변수 구간을 계산한다. 최대 확대율만으로 얇은 쪽의 빈 공간을 지우지 않는다. 거리/구간 탐색은 유한 반복과 공통 작업량 제한 안에서 실행하며 서브픽셀 허용값을 사용한다. 매우 긴 문서 밖 선은 큰 판별식의 상쇄를 피하도록 중심에서 접촉식을 평가한다.

분리된 경로는 열린 폴리라인으로 보존하고 원래 스타일 폭·RGBA·장치 필압 사용 여부를 유지한다. 곡선은 기존에 계산한 기하를 분리하며 원래 곡선 정의를 재해석하지 않는다. 원래 기하 정점을 그대로 복사하고 새 잘림 경계만 보간한다. 중심선 매개변수로 분리 위치를 추적하므로 자기 교차에서 가까운 다른 선분으로 압력을 잘못 붙이지 않는다. 닫힌 경로의 시작점을 넘는 남은 구간은 하나의 열린 경로로 잇는다.

문서v65는 장치 샘플과 편집 배수 각각에 선택적인 비균등 위치 목록을 저장한다. 분리 뒤 원래 압력 절점과 None 장치 샘플을 보존하며 새 끝점 값만 보간한다. 닫힌 마지막 구간은 장치 압력과 편집 배수를 각각 끝→시작으로 보간한 뒤 곱한다. 기존v64 필드는 그대로 읽고 비균등 위치를v64 이하 헤더로 위장하면 거절한다. 편집 배수를 다시 수정할 때 현재 제어점 위치로 재표본화하고 장치 샘플/위치 목록은 유지한다. 가변 폭 렌더링의 기존 구간 근사는 vector-edit.md를 따른다.
