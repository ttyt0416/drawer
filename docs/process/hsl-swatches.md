# 087 RGB/HSV/HSL 및 로컬 색상표 편집

내부 색은 비연관 8-bit RGBA 한 개다. RGB/HSV/HSL 표시 변경은 해당 값의 수치 표시만 바꾸며 변환 결과를 다시 대입하지 않는다. HSL은 H 0–360도, S/L 0–1(표시는 S %)이며 알파는 별도 0–255다. 무채색 H는 마지막 유효 H 메타데이터를 사용한다. 색감보존 명도 옵션은 HSL H/S 및 알파를 조작 시작 시 고정하고 L만 바꾼다. 같은 드래그가 검정/흰색을 지나도 원래 H/S로 돌아오며 놓은 뒤 새 조작은 현재 RGBA에서 시작한다. 8-bit 반올림은 색 편집 시에만 발생한다.

색상표별 크기 12–64, 자동 열 또는 고정 1–32열, 스크롤을 저장한다. 이름 수정, 현재 RGBA로 교체, 삭제, 앞/뒤 이동, 드래그 대상 앞 이동과 Ctrl 드래그 복제를 제공한다. 이동은 ID 유지, 명시적 복제는 새 ID와 copy 이름으로 같은 RGBA도 허용한다. 일반 Add/자동 스포이트 등록은 기존 같은 RGBA를 재사용하여 끝으로 이동한다. 알파가 다른 색은 별도다. 표 16개, 표당 256색, 전체 2048색 한도와 잘못된 이름/목적지 오류는 복사본 검증 후 원자적으로 거절한다.

색상표 패널의 전용 Undo/Redo 16단계는 값/순서/레이아웃을 복원하며 그림의 Ctrl+Z와 분리된다. Esc, 초점 상실, 영역 밖 놓기, Ctrl 복제 중 Ctrl 해제, 표/작업공간 변경은 드래그를 취소한다. 로컬 설정은 모델/명도 옵션/마지막 H, 색상표 ID/이름/RGBA/순서/표시를 보존한다. 기존 설정의 새 옵션/레이아웃 누락은 기본값으로 읽는다.

검증은 독자 생성 데이터만 사용한다. 4096 RGB×알파 0/128/255의 HSL 왕복, 원색/흑백/회색/H 0=360/거절 범위, L 0~1, 실제 패널 100회 RGB→HSV→HSL 표시 순환과 버튼 선택, 검정→흰색→중간 명도 드래그를 확인한다. 실제 스와치 드래그 이동/Ctrl 복제/취소 및 전용 이력, 용량 오류 원자성/빈 표/동일색/폭 변경/로컬 재시작, 그림 픽셀/Undo/dirty 불변을 검증한다. 설치된 앱도 같은 headless 입력 검증을 실행한다. 물리 펜 센서 검증은 별도 대기다.
