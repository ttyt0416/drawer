# 로컬 포즈·체형·카메라 프리셋 (216)

`3d-presets` 명령의 Capture / save preset은 선택한 모델의 현재 확정된 Pose / Shape 또는 문서 Camera를 로컬 자산으로 저장한다. 문서·dirty·실행 취소 이력은 바꾸지 않는다. 진행 중인 3D/마네킹 미리보기는 먼저 확정하거나 버린다. 이름은 1..80문자/512바이트, 제어 문자를 제외한다. 같은 이름도 독립 ID로 저장하여 기존 프리셋을 덮어쓰지 않는다.

Pose는 리그 버전·종류와 순서 있는 관절 이름/부모 표, 관절 각도와 손 좌우 방향을 저장한다. Shape는 같은 뼈 구조 서명과 체형 값만 저장한다. 적용할 모델의 뼈 구조가 정확히 같아야 한다. 다른 종류·버전·관절 이름/부모 순서는 자동 매핑하지 않고 거절한다. 리그가 없는 모델에도 적용하지 않는다. Pose 적용은 기존 체형을 유지하고 Shape 적용은 기존 포즈와 손 방향을 유지한다. 개체의 위치·축척·부모는 유지한다.

Camera는 위치, 방향, 원근/직교 방식, FOV·직교 배율, near/far와 페이지 프레임을 함께 저장한다. 대상 모델이 없어도 적용할 수 있다. 페이지 프레임은 저장한 값 그대로이므로 다른 크기의 문서에서는 미리보기로 구도를 확인한다.

목록에서 선택하고 Preview selected preset을 누르면 기존 3D 창에 원본을 바꾸지 않는 준비 결과를 표시한다. Apply 한 번이 한 Undo이며 Discard/Esc/포커스 상실/창·문서 닫기/원본 리비전 변경은 준비 결과를 버린다. 숨김/잠긴 리그·파일 개체 대체와 촬영 원본 보호, 관절 한계와 기존 준비/결과 메모리 예산을 지킨다. 변경이 없는 적용은 이력을 늘리지 않는다. 로컬 자산 삭제는 그림에 이미 적용한 상태를 되돌리지 않는다.

저장 위치는 사용자 데이터 폴더의 `settings/model-presets.json`이다. 자체 version1 JSON 컬렉션으로 최대128개/1MiB이며 독립 ID는 삭제 후 재사용하지 않는다. 새 파일을 별도 임시 경로에 완전히 기록·동기화한 뒤 교체하며 실패한 기록의 준비 파일을 제거한다. 손상·미지원 버전/뼈 구조·중복 ID·잘못된 수치·범위/크기 초과는 거절한다. 불러오기 실패 시 기존 파일을 유지하고 편집 창을 닫아 오래된 목록으로 덮어쓰지 않는다. 재시작 시 로컬 목록을 복원하며 네트워크/클라우드 자산을 사용하지 않는다. 문서에 적용한 결과는 기존 native109의 리그·형상/카메라 필드로 저장한다.
