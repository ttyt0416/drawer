# 094 — 마술봉·선택 브러시

Wand/H는 읽기 전용 참조에 대해 연결 영역 또는 같은 색 전체를 선택한다.093의 독립 색차/알파 판정과 경계 coverage를 재사용하며 전체색은 연결 탐색 대신 모든 적격 픽셀을 사용한다. 현재/지정 래스터와 보이는 합성 참조를 선택한다. 기존 선택과 Replace/Add/Subtract/Intersect를 제공한다. 알파0의 숨은RGB는 투명 영역 판정에서 무시한다. 부분 알파 경계는 부드러운 선택 강도가 된다. 원본 프로그램의 비공개 판정식은 사용하지 않는다.

선택 합성은 정수 coverage로 계산한다. a,b가0~255일 때 Add=a+b-round(a*b/255), Subtract=round(a*(255-b)/255), Intersect=round(a*b/255)이다.128과128은 각각192/64/64가 된다. 명시적 선택없음에서 Add는 빈 바탕에 새 선택을 만들고 Subtract/Intersect는 캔버스 전체에서 시작한다. 명시적 빈 마스크는 실제 빈 선택이다. 기존 선택의 이동/페이지 변환을 반영하고 Add/Subtract에서 캔버스 밖으로 이동한 선택도 보존한다. 새 입력은 캔버스 안으로 제한한다.

Selection brush/J와 Erase selection/Shift+J는 선택 강도만 추가/지운다. 지름0.5~4096 문서 픽셀, 경도0~1, 강도0~1과 펜 압력을 사용한다. 선분을 문서 좌표 원형 붓으로 평가하고 원래 페이지 좌표의4×4 표본으로 경계를 계산한다. 마우스 압력은1, 펜은 전달된 압력으로 강도를 배율한다. 같은 획의 겹친 표본은 최대 coverage를 사용해 이벤트 빈도나 재방문으로 중복 누적하지 않는다. 새로운 획은 기존 선택 강도와 다시 합성한다. 강도0의 초안은 메타데이터/dirty/이력도 바꾸지 않는다. 미리보기의 페이지 선택 namespace는 한 획 동안 고정한다.

Down에서 문서/리비전/프레임/입력원/대상/설정/보기 투영을 고정한다. 누른 동안 임시 문서에 선택 초안을 표시하고 Up에서 Scene 명령 하나로 확정한다. 그림 레이어/셀 픽셀에는 쓰지 않는다. Esc·초점 상실·보기/설정/활성층/도구/문서/프레임 변경·모달 진입·입력Cancel은 초안을 버린다. 입력원 소유권과 반복 도구 키를 기존 선택/채우기 경로와 공유한다. 확정 선택과 최근 선택은 기존v33 문서에 저장하고 설정은 로컬 작업공간에 보존한다. Undo 한 번으로 획 전체를 복원한다. 마우스와 합성 펜 경로를 제공하며 물리 펜 검증은 별도다.

원래 페이지 격자4Mi 픽셀·32768변/coverage run·원래 좌표±100만·한 브러시 획64Mi 표본 작업·선택 Scene4MiB와 문서/작업공간 미리보기 용량 상한을 검사한다. 변환·부분 픽셀 이동 후 선택은 이4×4 격자로 정규화한다. 과도한 범위/비정상 값/낡은 문서/직렬화 상한 초과는 원본 변경 없이 실패한다. 클라우드·원본 앱 자원·새 라이브러리는 사용하지 않는다.

검증: 떨어진 같은 색3개에서 연결/전체색 구분, 부분 선택 합성, 투명 경계127, 강도128·기하 경계88(16표본 중11개×강도0.5)·추가192/지우기64·마우스/펜 강도 차이·한 획 반복 비누적·강도0, 페이지 회전/이동/캔버스 밖 기존 선택 보존·무효 입력을 확인한다. 실제 egui 입력에서90도/확대1.5 보기, H/펜Down 동시·반복H·마우스/펜 브러시 선분/지우기·초안 원본 불변·Esc/초점/보기/설정/모달 취소·입력 해제·한 Undo·문서/설정 재열기를 검증한다. 동일 검증을 숨긴 설치본에서도 실행한다.

설치본 검증 중 Windows 기본 메인 스택1MiB에서 앱 상태가109944바이트인 경로의 스택 초과를 재현했다. 그리기 런타임25176바이트를 Box로 보관해 앱 상태의 값 복사 부담을 줄였다. 앱 상태96KiB 상한 회귀 시험과 같은1MiB 실행 파일의 숨긴 설치본 검증으로 재확인했다.
