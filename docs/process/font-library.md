# 로컬 글꼴 목록과 문자표 (179)

font-library 명령 또는 글꼴 선택기의 Manage font lists and characters를 연다. Windows 시스템 Fonts, 현재 사용자 설치 글꼴 폴더와 앱 데이터 fonts 폴더를 읽기만 한다. 추가·복사·등록·삭제는182의 별도 기능이다. 검색은 대소문자를 구분하지 않는 이름 검색이며 백그라운드 갱신은 취소 신호와 파일/글꼴 면 수 제한을 따른다. 최대2048개 후보 파일/1024개 면, 파일32MiB/파일당64개 면을 읽는다. 손상/지원하지 않는 파일은 건너뛰고 개수를 안내한다. 네트워크 조회/글꼴 다운로드는 없다.

로컬 글꼴은 파일 내용과 면 번호의 SHA-256 및 최대128 UTF-8 바이트의 표시 이름을 참조한다. 문서에 PC 경로나 폰트 바이너리를 넣지 않는다. TTF/OTF/TTC/OTC의 실제 면 인덱스를 사용한다. 기본 글꼴 외에 루비/수동 범위/혼합 매핑의 글꼴도 로드하고 실제 글리프에 사용한다. 문서v89에 참조를 저장하며 이전 헤더 위장을 거절한다. 누락/내용이 바뀐 파일은 대체/누락 안내를 제공하고 원문을 유지한다. 같은 파일을 다시 설치하면 동일 식별자로 사용한다. Refresh local fonts는 파일 데이터·본문/별도 캔버스 표시 캐시·미확정 텍스트 미리보기를 다시 준비하게 한다. 문서 내용/dirty/Undo는 바꾸지 않는다. 일반 환경에서는 앱의 기본 저장 경로 또는 DRAWER_DATA_DIR를 사용하는 앱 로컬 fonts 폴더가 재시작 후 탐색 대상이다.

목록은 안정적 ID/이름/포함 글꼴/표시방식을 갖는다. 새 목록은 글꼴0개이며 이름을 편집할 수 있다. 최대32개/이름64문자, 목록당1024개 글꼴, 즐겨찾기1024개다. 복제는 구성원을 복사한 독립 목록이다. 중복 이름은 이유를 표시하고 기존 목록을 덮어쓰지 않는다. 삭제는 정확한 목록 이름을 입력해야 하며 파일/기존 문서 서식을 지우지 않는다. 마지막 목록 삭제 후 목록 관리의 이름변경/복제/삭제/표시변경/일괄변경은 비활성화하고 생성만 허용한다. 즐겨찾기·문자표·설정 확인/취소는 별도 기능이다.

선택 목록이 있으면 글꼴 선택기 항목을 그 구성원으로 제한하며 비어 있는 목록은 별도 안내한다. 필터가 기존 문서의 적용 글꼴을 지우거나 바꾸지 않는다. 목록 편집 표는 전체 탐색 결과를 대상으로 체크하고 검색 결과 전체 포함/제외는 현재 표시된 결과에만 적용한다. 검색을 비우면 전체 탐색 결과에 적용한다. 숨긴 구성원과 누락 참조는 보존한다. 누락 구성원/즐겨찾기는 표시하고 참조만 제거할 수 있다. 글꼴이 다시 발견되면 같은 식별자로 연결한다.

이름 표시를 공통 UI 글꼴/해당 글꼴로 고른다. 이름의 글리프가 없거나 미리보기를 로드하지 못하면 UI 글꼴을 사용한다. 미리보기는 최대32개/64MiB이며 문서 글꼴 데이터에도64MiB 작업 한도를 둔다. 글꼴 파일 캐시는 읽기 메타데이터와 검증된 해시 상태로 재사용하고 파일마다32MiB를 넘지 않는다. 파일을 시스템에 설치하거나 수정하지 않는다.

목록/즐겨찾기/표시 방식은 확인 전 임시 설정이다. Apply font preferences만 로컬 workspace에 저장하며 실패하면 이전 값을 복원한다. Cancel/닫기/Escape는 임시 목록을 폐기한다. 초기화도 확인 전에는 임시 상태다. 마지막 저장 전 설정을 복원 기록으로 저장해 재시작 후에도 복원할 수 있다. 복원 시 ID 카운터를 뒤로 돌리지 않는다. 그림 내용과 Undo를 바꾸지 않으며 workspace other 범위에 포함한다. 문서가 쓰는 실제 글꼴은 목록 삭제/변경에 영향을 받지 않는다.

문자표에서 글꼴·영역·U+코드를 고르고 선택 글꼴의 글리프 유무를 확인한다. 서로게이트/제어 문자 코드는 거절한다. 글리프가 없어도 사용자가 선택한 유효 Unicode는 삽입할 수 있고 문서 대체/누락 상자를 사용한다. 삽입은 텍스트 편집의 현재 선택/커서에 글자군 경계로 적용하고 선택 글꼴을 해당 글자군의 범위 서식에 보존한다. IME 중에는 삽입을 거절하고 문자 수 한도를 넘으면 전체 입력을 거절한다. 문서 Apply 전 원본은 불변이며 Apply는 한 Undo다. 설정 Escape가 뒤에 열린 미확정 텍스트 편집을 폐기하지 않도록 분리한다. 실물 펜 검증은 대기한다.
