# 109 — 채우기·마술봉 투명도 판정

두 도구는 같은 영역 판정기를 사용한다. 투명 시작점은 alpha/255 ≤ 알파 허용치인 픽셀만 통과한다. 허용치0은 알파0만 의미하며 숨은 RGB는 무관하다. 불투명 시작점에서는 알파 허용치를 넘는 픽셀 중 각 RGB 채널의 정규화 차이가 색차 허용치 이하인 픽셀을 통과시킨다. 이때 알파 차이를 RGB 차이로 다시 비교하지 않는다.

Strict는 연결성분 그대로, Loose / close gaps는 설정 거리의 틈을 먼저 닫는다. AA는 발견한 영역 가장자리의 부분 강도이며 발견 조건을 바꾸지 않는다. 확장 거리/형태와 좁은 영역 포함도 독립적이다. 마술봉 화면에도 모드·틈·확장·형태·좁은 영역 설정을 제공한다. 원래 설정 형식을 사용하므로 기존 작업공간과 도구 프리셋을 유지한다.

독립 검증은 알파127 임계값 직전/일치/직후,128/129, 허용치0, 숨은 RGB, 불투명 같은 RGB/다른 알파, 다른 RGB/같은 알파, 연결/분리 영역, 틈0/1/3, AA128와 확장255, 현재/지정/합성 참조를 비교한다. RGB/알파 결합 오류는 실패를 재현한 뒤 수정했다. 생산 입력은 마우스/가상 펜×채우기/마술봉×두 모드×틈3종의24조합에서90도·확대4, 미리보기 불변·확정 한 Undo/Redo를 확인한다. 실제 펜 센서 검증은 별도다.

영역4Mi픽셀·32768 마스크 runs와 기존 표본/메모리/취소 검사를 공유하며 외부 서비스나 실행 중 다운로드를 사용하지 않는다.
