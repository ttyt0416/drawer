# 148 — 벡터 선택 범위·기준점 변형·복사

점과 획 선택을 구별한다. 문서 픽셀의 기준점·이동량·X/Y 배율·회전각을 지정해 전후 미리보기를 만들고 한 Undo로 확정한다. 기준점은 수치 입력, 첫 선택 제어점, 마지막 캔버스 레이어 선택 지점으로 지정한다. 선 전체는 모든 기하와 곡선 프레임·SVG paint/clip을 함께 옮기고, 점 선택은 해당 앵커와 노드 핸들만 바꾼다. 비균등 장면 변환을 역변환한 같은 문서 좌표에서 계산한다. 기본 선폭은 유지한다. 복제 이동은 대상 획을 새ID로 복제한 뒤 복제본의 선택 범위만 바꾸며 원본 기하·속성·ID를 유지한다. 기존143번의 각진/부드러운 점,144번의 연결/분할 도구를 함께 사용한다.

Layers의 Vector selection, pivot and transfer에서 현재 점/획을 읽는다. 영역 선택의 겹침은 중심선과 한 점 이상 교차, 포함은 중심선 전 구간이 내부인 경우다. 경계 접촉은 내부이며 폭이 넓어 닿는 것만으로는 선택하지 않는다. 마스크 행 구간의 교집합을 선의 매개변수 구간으로 합치므로 양 끝점이 내부여도 중간 구멍을 지나는 선은 포함되지 않는다. 현재층 또는 모든 편집 가능한 벡터층에 적용하고 숨김/잠금/읽기 전용 연결층을 제외한다. 점으로 영역 선택을 변환하는 기존108번과 레이어 바로 선택123번을 함께 사용한다.

벡터 범위 선택은 세션 자료로 유지하고 전용 선택 Undo/Redo 최대16단계를 제공한다. 그림·저장 문서·그림 Undo를 바꾸지 않는다. 페이지/프레임/그림 수정이 달라지면 옛 선택 이력은 버리고 살아 있는 범위를 검사한다. 미리보기 적용은 문서·수정본·프레임·선택 집합의 일치를 확인한다. Escape/창 닫기는 변형 미리보기를 버린다.

기본 벡터 복사는 선택점을 하나 이상 포함한 획 전체를 복사한다. 곡선 정의·핸들·폭·장치 압력과 편집 배수·색/알파·팁·채움·SVG paint/clip을 보존한다. 여러 층은 합성 순서의 경로 순서로 복사한다. 구간만 복사는 인접한 선택 제어점 사이를 분리하며 연속 구간은 합친다. 닫힌 경로의 마지막/처음 선택도 하나의 이음매 구간으로 처리한다. 고립 선택점은 기본 전체 획 복사를 사용하도록 안내한다. 구간 결과는 새 끝점과 보간 압력을 가진 열린 편집 윤곽이며 원래 전역 곡선 정의는 굳어진다. 채움 있는 객체는 전체 획 복사를 사용한다.

잘라내기는 삭제 상태와 클립보드 두 형식을 모두 먼저 준비하고 기록 성공시만 한 Undo로 삭제한다. 구간 밖은 열린 잔여 경로로 보존하며 Undo는 원래 연결성과 정의를 복구한다. 붙여넣기는 새ID를 부여해 현재 편집 벡터층에 삽입하고 한 Undo로 기록한다. 경로의 폭과 팁은 페이지 선형 좌표 프레임을 공유하므로 네이티브 벡터 붙여넣기는 페이지 배율/회전 프레임이 같을 때 정확히 보존한다. 평행 이동 차이는 정규화하며 다른 선형 프레임에는 래스터 대체 또는 SVG 변환을 명시적으로 사용한다.

클립보드는4MiB 헤더/JSON의 자체 벡터 형식과 표준 래스터 이미지를 함께 기록한다. 래스터는 복사 대상 벡터 원자료를 투명 바탕에서4×4 표본으로 렌더한 실제 불투명 경계로 자른다. 작은 영역 선택으로 긴 획을 복사해도 원래 획을 잘라내지 않는다. 층/페이지의 별도 합성 효과는 벡터 원자료 복사에 포함하지 않는다. 단일 이미지4M픽셀·이미지 픽셀 수×유효 경로/필압/clip 작업량32M·기하/메모리 한도를 검사한다. 원격 자료나 외부 파일을 만들지 않는다. 다른 프로그램의 클립보드 변화와 형식 추가 실패는 잘라내기 삭제를 막는다.

실물 펜 검증은 별도 대기한다.

현재 벡터층에서 일반 Copy는 전체 획 복사, 자체 벡터 형식이 있는 일반 Paste는 편집 가능한 붙여넣기로 연결한다. 자체 벡터 형식이 없는 이미지 클립보드는 기존 이미지 붙여넣기를 유지한다. 복사/붙여넣기는 모든 열린 문서의 사용량을 포함한 작업공간 메모리 예산을 확인한다.

잘라낸 획의 문서 내 옛 제어점/획 선택은 잔여 경로의 다른 점을 가리키지 않도록 제거한다. 잘라내기 밖의 문서 내 선택은 유지하며 이 정리도 기하와 같은 Undo로 복구한다.
