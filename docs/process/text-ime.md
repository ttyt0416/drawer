# 캔버스 한글 조합과 글꼴 대체 (176)

텍스트 필드의 현재 Unicode 문자열을 편집 중인 페이지의 임시 문서에 배치한다. IME preedit와 받침 교체도 본문 캔버스에 표시한다. 확정 전 개체·래스터·Undo·저장 원본은 바뀌지 않는다. 미리보기는 원래 페이지의 보기 위치/배율을 따르고, 실제 설정이 같으면 재사용한다. 문서 ID/수정번호/프레임을 검사하고 오래된 결과를 표시하지 않는다. 텍스트 편집 중 캔버스 그리기는 잠시 막으며 보기 조작은 유지한다.

조합 중 Escape/필드 실행 취소·빈 preedit·앱 포커스 이탈은 마지막 확정 문자열과 커서를 복원한다. OS가 포커스를 잃기 전에 Commit을 전달한 경우 그 확정값을 유지한다. 앱 전환 후 전달되지 않은 글자를 추측해 확정하지 않는다. 결과 준비와 Apply는 조합 종료를 요구한다. 필드 이력과 문서 이력은 별개이며 Apply는 문서 한 Undo다.

요청 글꼴이 없으면 이름을 표시한다. 글리프 대체 시 사용한 실제 로컬/내장 글꼴 이름과 문자 수를 안내한다. 어떤 글꼴에도 없는 문자는 독립 테두리 상자로 그리고 U+코드와 수를 표시한다. 폰트의 비어 있는 .notdef 윤곽에 의존하지 않는다. 누락 목록은 서로 다른 최대16개 코드까지 표시하고 전체 누락 수는 따로 유지한다. ZWJ/variation selector는 원문에 보존하며 현재 단순 배치에서는 독립 누락 상자로 그리지 않는다. 색 이모지/ZWJ 시퀀스 조형을 지원한다고 표시하지 않는다.

문서는 원문과 요청 글꼴 참조를 저장한다. 대체 글꼴이나 누락 상자로 원문을 치환하지 않는다. 기존v86 속성으로 보존 가능하므로 이 항목은 파일 버전을 늘리지 않는다. 글꼴 파일은 읽기만 하고 네트워크 조회/다운로드/클라우드 소재는 사용하지 않는다. 미리보기의 문서 복사/작업 메모리는 기존 문서 예산에 포함한다.
