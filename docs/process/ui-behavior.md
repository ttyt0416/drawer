# 패널 표시·가장자리 이동·절전 정책

버전형 작업공간에 표시 설정을 저장한다. 패널 유휴 접기는 브러시·색·레이어·타임라인 내용에 적용하며 마우스/키보드 접근과 누른 버튼은 펼친 상태를 유지한다. OS 분리 창은 전체 물리 크기를 보존하고 접힌 높이만 요청하며 펼친 뒤 크기 사건을 안정화한 후 전체 크기를 읽는다. 모든 기존 스크롤 영역/스크롤 창의 표시 정책을 함께 연결했다. 커서 끔은 기존 시스템 커서를 사용하며 입력 좌표는 유지한다.

가장자리 이동은 primary 캔버스 입력이 활성인 동안만 실제 화면 픽셀의 여백과 초당 속도로 화면 pan을 계산한다. 첫 press는 기존 위치에 수집하고 다음 프레임부터 이동한다. 큰 프레임 지연은 50ms로 제한하며 해제/포커스 상실/영역 확대/Space 이동은 대상에서 제외한다. 이동은 보기 설정이며 문서 픽셀/이력을 수정하지 않는다.

절전 억제는 기본 꺼짐이다. 명시적으로 켠 경우 칠하기와 처리 작업 동안 keepawake 0.6.1의 안전한 Rust 인터페이스로 Windows 유휴 절전 요청을 한 개 유지한다. 표시 유지 옵션은 별도이며 사용자 요청 절전을 막는 away mode는 사용하지 않는다. 저장과 PNG 출력은 같은 UI 스레드의 짧은 소유 범위로 요청한다. 원래 상태 복원은 객체 해제에 연결되며 스레드가 바뀌지 않도록 Rc에 보관한다. 작업/취소/실패/꺼짐/종료에서 소유 요청을 해제하고 생성 실패는 원래 시스템 정책으로 진행하며 이유를 표시한다.

API와 의미는 [Microsoft 시스템 절전 조건](https://learn.microsoft.com/en-us/windows/win32/power/system-sleep-criteria), [keepawake 작성자 문서](https://docs.rs/keepawake/0.6.1/keepawake/)와 고정된 의존성의 Windows 소스로 확인했다. 의존성은 개발 때만 받아 Cargo.lock에 고정하고 앱은 실행 중 다운로드하지 않는다. 새 Windows 빌드 의존성 고지를 생성해 외부 라이브러리 142개/내장 글꼴 4개의 고지를 보존한다.
