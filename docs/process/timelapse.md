# 로컬 타임랩스 기록 (206)

`timelapse`는 한 캔버스의 확정된 그림 상태를 독립 로컬 폴더에 기록한다. 기록 폴더는 새로 생성하거나 자체 `timelapse.json`이 있는 폴더를 명시적으로 다시 연다. 열린 기록은 시작할 때 선택한 캔버스에 묶이며 탭 전환으로 다른 그림에 자동 연결하지 않는다. 캔버스가 닫히면 기록을 일시정지한다. 기록 창만 닫으면 기록은 계속되고 Stop 또는 앱 종료는 마지막 확정 상태와 기록 목록을 동기화한다. 재실행 후 기존 폴더를 선택해 현재 캔버스에서 이어갈 수 있다.

실시간 획/포인터 표본 대신 완료된 문서 수정 번호를 관찰해 최대 초당2개의 스냅샷을 기록한다. 일시정지/중지/종료는 간격과 무관하게 마지막 확정 상태를 추가 확인한다. 같은 픽셀과 크기가 유지되면 PNG를 중복 저장하지 않는다. 더 빠른 중간 수정은 다음 관찰의 최신 상태로 합쳐질 수 있다. 보이는 합성 그림·용지층·밑그림을 포함한8비트 sRGB PNG이며 어니언/라이트테이블 등 화면 보조 표시, 오디오, 미확정 도구 미리보기는 포함하지 않는다. 원본의 편집 구조/고정밀/픽셀/dirty/저장 위치/그림 Undo는 기록으로 바뀌지 않는다.

별도 단조시계로 기록 중 경과 밀리초를 누적하고 일시정지한 구간은 제외한다. 시스템 시각 조정은 사용하지 않는다. 이는 문서별 실제 작업시간 기능207/208과 별개의 기록 경과 시간이다. 재개는 저장된 누적값에서 이어지며 기록을 끄거나 폴더를 다시 여는 것이 원문서 데이터를 초기화하지 않는다.

v1 JSON에는 형식/버전·용량 한도·누적 시간·다음 ID, 각 확정 프레임의 번호/상대 PNG 파일명/크기/문서 수정 번호/누적 밀리초/파일 크기/파일 SHA256/디코딩 픽셀 SHA256을 저장한다. 개인 준비 폴더에서 PNG를 쓰고 다시 디코딩한 뒤 원래 이름으로 게시한다. 목록도 별도 파일에 쓰기·동기화 후 교체한다. 목록 교체가 확정 경계다. 취소나 교체 실패 시 자신이 게시한 미확정 PNG만 해시 확인 후 회수한다. 외부에서 바뀐 목록은 덮어쓰지 않으며 기존 확정 PNG는 유지한다. `.timelapse.lock`은 동시 쓰기를 막는 영구 빈 메타데이터 파일이다. 파일 핸들 잠금은 종료/비정상 종료 때 OS가 해제하므로 남은 파일 자체가 재개를 막지 않는다.

열 때 목록 구조와 확정 PNG의 길이·해시를 검증한다. 누락/변조 파일은 오류로 표시한다. 비정상 종료로 목록에 포함되지 않은 PNG나 낯선 파일이 있어도 덮어쓰거나 재귀 삭제하지 않는다. 다음 기록은 사용되지 않은 번호를 선택한다. 용량 한도 도달·쓰기 실패·렌더/메모리 실패는 기록을 일시정지하고 안내한다. 한도를 높이거나 새 폴더로 기록할 수 있으며 자동으로 이전 프레임을 지우지 않는다. 한도는 확정 PNG와 목록 파일의 크기 합계이며 폴더/파일시스템 할당량이나 낯선 파일의 크기를 뜻하지 않는다. 기본512MiB, 최대2GiB·10000프레임·PNG당64MiB·목록4MiB·축32768픽셀과 기존 문서/작업 메모리 한도를 적용한다.

출력은 선택한 기록 범위와 유리수 FPS로 독립 애니메이션을 준비한 뒤 기존 `animation-export` 창에서 PNG연속/GIF/APNG/Animated WebP 또는 검증된 로컬 동영상을 선택한다. FPS는 출력 시간축의 속도이며 출력 길이는 선택한 확정 프레임 수÷FPS다. 기록 중 조용한 구간을 실시간 대기로 넣지 않는다. 도중 캔버스 크기가 달라졌다면 선택한 캡처 중 가장 큰 크기의 투명 캔버스 중앙에 원래 픽셀을 리샘플링 없이 배치한다. 모든 출력 프레임의 크기는 동일하다.

준비 때 확정 목록의 끝과 PNG 픽셀을 고정한다. 이후 기록 추가·문서 편집·플레이헤드 이동은 해당 출력에 반영하지 않는다. 출력 창은 이 독립 소스를 사용하며 편집 중 캔버스로 전환하지 않는다. 기록 폴더 안으로의 출력을 거절해 목록/기록 PNG와의 충돌을 막는다. 준비·출력 취소는 원문서와 확정 기록을 유지하며 생성 중인 개인 출력 파일만 정리한다. 출력 형식의 양자화/알파/인코더 정책은 [애니메이션 출력](animation-output.md)을 따른다.
