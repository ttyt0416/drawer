# 로컬 레이어 검색과 캔버스 직접 선택

레이어 목록의 Search / select layers 또는 layer-search 명령으로 연다. 이름과 태그는 대소문자를 접고 NFC로 정규화한 리터럴 부분 문자열이다. 공백, 별표, 물음표는 그대로 검색한다. 한글 조합·분해, ß→ss, 그리스 시그마도 같은 Unicode 기본 접기를 따른다. 검색 조건은 작업공간 설정에 저장하며 문서 식별자나 현재 폴더 ID는 설정에 넣지 않는다.

컬러/회색/흑백 래스터와 벡터, 보정·그라데이션·단색·텍스트·말풍선·이미지·집중선·속도선·3D·일반/컷/애니메이션 폴더·셀·톤·선택의 종류 및 자·마스크·초안·문서보다 넓은 표현색 조건을 제공한다. 선택한 종류와 부속 기능 중 하나 이상을 만족하면 종류 조건을 통과한다. All types는 종류 조건만 없애며 Clear types는 빈 결과다. 검색 분류는 실제 소스와 해당 소스의 문서 메타데이터에서 읽는다. 후속 항목에서 만드는 종류의 작성기는 해당 항목에서 추가하며 검색 조건을 고르는 것만으로 기존 층의 종류나 픽셀을 변경하지 않는다.

종류 조건에 이름·태그·표시·전체 잠금·투명 픽셀 보호·위치 잠금·이미지 픽셀 잠금·참조·초안 조건을 모두 교차 적용한다. 상태마다 Any / Include / Exclude 중 하나만 선택한다. 표시와 편집 잠금은 부모의 영향을 반영한다. 부속 마스크·자 조건은 별도 가짜 층 대신 소유 층을 반환한다. 현재 일반/컷/애니메이션 폴더의 안/밖은 활성 문서의 선택에서 매번 계산한다. 해당 폴더가 없는 대상에서는 안과 밖 모두 빈 결과다.

Ctrl로 선택을 토글하고 Shift로 현재 정렬의 범위를 선택한다. 현재 결과 전체 선택은 결과 밖의 선택도 보존한다. 창에는 전체 결과·현재 결과에서 선택한 수·결과 밖 선택 수를 표시한다. 검색·정렬·결과 선택은 문서 수정 표시와 그림 이력에 들어가지 않는다. 표시·잠금·투명 픽셀 보호·이름·태그·삭제는 명령 실행 때 검색을 다시 계산해 현재 결과와 선택의 교집합만 편집한다. 전체 명령은 한 Undo다. 폴더나 애니메이션 폴더의 보이지 않는 자식을 삭제에 묵시적으로 포함하지 않으며 명시적으로 자식까지 선택해야 한다. 사용 중인 셀이나 마지막 래스터를 단독 삭제하는 요청은 거절한다.

래스터·벡터·폴더·페이지 개체·그라데이션·3D·이름 붙인 선택·애니메이션 폴더·셀을 공통 대상으로 다룬다. 배열 삭제로 앞 항목이 없어져도 페이지 개체·3D·폴더·셀의 식별자는 재사용하지 않는다. 애니메이션 삭제는 셀 노출과 잠금/투명 픽셀 보호의 기존 숫자 인덱스를 안정 식별자로 대응시켜 다시 배치한다. 문서 v51은 이 식별자와 검색용 이름·표현색·태그·부가 속성을 보존한다. 기존 문서는 가상 순번 식별자로 읽고 실제 구조 편집이 필요할 때만 실체화한다.

이동/선택 도구의 설정된 수정키+클릭은 렌더링된 유효 알파가 있는 맨 위 대상을 고른다. 숨김·잠금 포함 정책·마스크·클리핑·폴더 후보 옵션을 따른다. 빈 공간은 현재 대상을 유지하고 Next overlapping candidate는 후보를 순환한다. 선택 자체는 이력에 넣지 않고 뒤따르는 드래그만 한 명령으로 확정한다. 개체·그라데이션·벡터·셀·트랙·폴더 이동도 같은 입력 소유권·문서 수정본·프레임·보기 고정과 취소 규칙을 사용한다. 래스터 이동의 기존 맞춤을 보존하며 다른 소스의 직접 드래그는 정수 문서 좌표 이동을 사용한다. 잠금은 선택 옵션으로 해제되지 않는다.

검색은 최대16384개 결과, 태그16개/각128바이트와 기존 문서256MiB·초안32MiB·이력64MiB·JSON4MiB 예산을 적용한다. Unicode 처리는 이미 로컬에 있는 고정 버전 라이브러리로 수행하며 네트워크 요청을 하지 않는다. CPU 입력 재생에서 복수 선택·결과 밖 보존·일괄 숨김/Undo·설정 재열기·90도/3배 보기에서 개체 선택 후 수정키를 놓고 드래그·한 Undo를 검사한다. 독립 조건/범위/Unicode와 실제 마스크·자·중첩 폴더, 안정 셀/트랙 삭제, 원본 픽셀·이력 보존 및 문서 재열기도 검사한다.
