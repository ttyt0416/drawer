# 로컬 그라데이션

103번은 그라데이션 창에서 시작/끝 문서 좌표, RGBA, Straight line·Circle·Ellipse·Cone·Freeform, 타원 단축/장축 비율, Dithering을 설정한다. 범위 밖은 Do not repeat(끝색 유지), Repeat(주기1), Reverse(왕복 주기2), Not draw(미출력)를 선택한다. 시작과 끝이 같으면 시작색을 사용한다. 알파는 선형, 색은 premultiplied encoded RGB로 보간하며 완전 투명 지점의 숨은 RGB는 중간색에 섞이지 않는다. 디더는 고정 4×4 Bayer의 RGB 양자화 오프셋으로 알파를 바꾸지 않는다.

Draw on editing layer는 현재 래스터에 굽고, Create gradient layer는 문서에 편집 가능한 레이어를 만든다. 레이어는 래스터 위·페이지 객체/벡터 아래에 순서대로 합성한다. 같은 창에서 Edit/Show/Hide/Delete/Up/Down을 사용한다. 레이어는 생성 시점 좌표계와 선택 강도를 저장해 선택을 바꾸거나 페이지를 확대/잘라도 결과와 편집 좌표계가 안정적으로 유지된다. 각 생성·수정·레이어 작업은 한 문서 Undo이며 문서 v36에 저장한다. 구형 문서의 누락 필드는 빈 목록으로 읽는다.

Freeform은 현재 래스터 또는 표시 합성에서 흰색(RGB 각각250 이상)/투명 픽셀의 4방향 연결 성분을 구한다. 캔버스 끝 또는 원래 선택 밖에 닿는 성분은 닫힌 영역으로 보지 않는다. 유색 섬은 구멍으로 보존한다. 각 닫힌 영역에서 요청한 시작/끝에 가장 가까운 내부 픽셀을 두 색상의 앵커로 잡고 두 거리의 비율로 색을 혼합한다. 타제품의 수치 호환을 주장하지 않는 독립 정의다.

검정(RGB 각각32 이하) 경계와 완전 투명 내부는 각각 Do not cover / Cover / Replace with drawing color를 선택한다. 반투명 검정 경계는 원래 알파를 덮기 강도에 곱한다. Do not fill this color는 정확한 RGBA 일치를 제외한다. 검정·투명·일반 강도를 따로 캡처하므로 레이어 색·방향·덮기 정책을 나중에 편집해도 자기 출력을 재참조하지 않는다. 모양의 일반/자유형 전환, 제외색, 벡터 범위 변경은 새 그라데이션으로 만든다.

Fill adjacent vector lines는 닫힌 영역에 인접한 표시/참조 벡터만 처리한다. Erase up to intersection은 교차점 사이의 접촉 구간, Whole line은 접촉 경로 전체를 제거하고 그 자리에 그라데이션 잉크를 남긴다. 잠근 벡터는 교차점 참조로만 읽고 수정하지 않는다. 부분 래스터 선택은 편집 벡터의 일부 강도로 표현할 수 없어 벡터 교체 시 명시적으로 거절하며 원본을 바꾸지 않는다. 벡터 분할과 레이어 생성/래스터 칠은 같은 상태 명령으로 취소한다.

4Mi 캔버스 픽셀, 256 닫힌 영역, 32 레이어, 합계32768 RLE, 4MiB Scene JSON, 64Mi 벡터 작업과 기존 문서/Undo 메모리 예산을 적용한다. 실패·취소·페이지/프레임 변경은 적용 전에 거절한다. 실제 펜 센서 검증은 별도다.

검증은 독립 중간색·범위 밖 반복·투명 숨은RGB·0길이·원형/타원형/원뿔형·디더·선택 구멍과 반강도·자유형9개 덮기 조합·열린 영역·유색 섬·벡터 교차점 안팎·잠금·한 Undo/Redo·문서 재열기와 실제 egui Apply/Cancel/오래된 상태 검사를 포함한다. 설치본도 같은 생성 fixture를 실행한다.
