# 문서 명령의 원자적 실행 취소·다시 실행 (260)

그리기 한 스트로크, 여러 층의 한 페인트 명령, 레이어 구조 변경, 선택 편집과 변형 적용은 각각 완전한 한 명령으로 기록한다. 픽셀 차이·복수 층 차이·선택을 포함한 Scene 또는 전체 DocumentState를 해당 작업에 맞게 유지한다. 준비/미리보기는 원문서를 읽고 성공한 적용만 기록하며 실패/취소/실제 변화 없음은 새 이력을 만들거나 기존 redo 분기를 버리지 않는다. 한 문서의 새 유효 편집만 그 문서의 redo 분기를 폐기한다.

Undo/Redo는 Ctrl+Z / Ctrl+Y와 기존 명령/도구모음에서 사용한다. 문서마다 독립이며 다른 탭의 편집이나 문서 닫기가 이력을 다른 문서에 옮기지 않는다. 저장 리비전을 따로 추적해 저장된 정확한 상태로 돌아오면 미저장 표시가 해제되고 다시 벗어나면 켜진다. Undo/Redo 자체는 저장 파일을 덮어쓰지 않는다. 보기 확대/회전/이동과 출력·로컬 파일 관리·작품 목록 복구는 각자의 범위이며 그림 이력에 넣지 않는다. 물리 경로 변경은 기존253/254처럼 남은 스냅샷에도 반영해 옛 링크가 Undo로 부활하지 않게 한다.

보존 한도는 문서당100단계 또는 기본 문서 예산256MiB의1/4(64MiB)이다. 초과하면 가장 오래된 완전한 명령부터 버린다. 개별 명령의 Undo 메모리와 전체 문서 예산을 검사하며 저장 후 병합/타 문서 변경과 잘못 연결하지 않는다. 세션 이후 이력의 저장·복구 정책은 기능261의 자체 문서 명세와 구분하며 현재 문서 Undo/Redo는 세션 단위다.

픽셀 묶음의 중복 위치를 적용 전에 정렬/검사해 거절한다. 함께 적용할 Scene도 구조·레이어 수를 먼저 검증한다. 잘못된 상태를 픽셀 일부와 함께 기록하는 경로를 차단하며 잠금·낡은 픽셀·범위 밖 위치·복수 층 중 한 층의 실패는 적용/리비전/dirty/undo/redo를 바꾸지 않는다. 정상 복수 층 페인트는 한 번의 Undo/Redo로 전체를 복원한다.

코어 검증은 그리기→층 생성→선택→픽셀 변형의 다섯 경계 상태를 저장하고 Undo 전체/Redo 전체를 대조한다. 저장 리비전, 빈 이력, 실패/변화 없음과 redo 보존, 새 편집의 분기 폐기, 중복/낡은/범위 밖 픽셀·잘못된 Scene/전체 상태·잠금·두 번째 층 실패, 복수 층 성공의 원자성과 보기 분리를 검사한다. 앱 검증은 egui 입력 재생의 마우스 스트로크/선택 드래그·레이어 명령·변형의 미리보기/적용 경로와 Ctrl+Z/Y를 연속 실행한다. 다문서 전환/빈 이력/실패/새 스트로크/문서 닫기를 검사하며 저장 파일 바이트가 그대로인지 확인한다.
