# 089 보기별 ICC, 톤 커브/레벨 미리보기와 명시적 적용

문서의 기존 작업 공간은 sRGB RGBA8이다. 이 기능은 문서 공간이나 원본 파일의 프로필을 재지정하지 않는다. 각 캔버스 보기와 별도 표시 창에 독립적인 로컬 ICC 경로, 렌더링 의도, 다섯 지점 톤 커브와 입력 black/white/gamma·출력 black/white를 저장한다. 보기를 복제하면 값을 복사하고 이후 각각 편집한다. 캔버스 보기 설정은 views.json, 별도 표시 창은 기존 display/workspace 설정에 보존한다. 구형 설정의 누락 값은 비활성 기본값이다. 미확정 초안은 저장에 포함하지 않는다.

ICC는 기존 moxcms 0.8.1로 sRGB → 대상 → sRGB의 양방향 변환을 만든다. RGB/Gray/CMYK와 Perceptual/Relative/Saturation/Absolute를 제공하고 실제 선택 의도를 두 변환에 전달한다. 해당 ICC에 필요한 방향이 없거나 손상/한도 초과이면 설명 후 거절하며 추정 CMYK 계산으로 대체하지 않는다. 파일4MiB·CLUT4MiB·TRC1,000,000 한도다. 33³ RGB 격자를 실제 ICC 변환하고 정수 격자 위치 사이를 trilinear 보간한다. 8-bit gamut 왕복 근사이며 모니터 측정/하드웨어 검교정·인쇄 결과 일치·별도 종이색/잉크 모델을 주장하지 않는다. 원본 ICC는 읽기만 한다.

톤/레벨은 먼저 sRGB RGB를 보정하고 그 결과에 ICC 왕복 시뮬레이션을 적용한다. 커브 입력 위치는0/25/50/75/100%로 고정하고 각 출력0–1을 독립 편집한다. 레벨은 input normalize/clamp → gamma(1/gamma) → piecewise-linear curve → output range/8-bit 반올림 순서다. 입력 white−black≥0.0001, gamma0.1–10, output black≤white가 필요하다. 역방향 커브는 허용한다. 미리보기에서 알파/숨은RGB는 보존한다. 톤은256-entry 표로 미리 계산하고 ICC는 고정 격자로 캐시해 픽셀마다 메모리 할당이나 프로필 파일 읽기를 하지 않는다.

Color proof and tone preview에서 초안을 편집하고 Preview draft를 누르면 해당 보기만 달라진다. Preview/Save는 ICC를 다시 읽어 명시적 새로 고침도 수행한다. Save view preview settings만 해당 보기의 로컬 값을 확정한다. Cancel/창 닫기/Esc/작업공간 변경은 초안과 임시 표시를 폐기한다. ICC가 없어진 저장 설정을 열면 문서색을 표시하고 캔버스에 오류를 표시한다. 이미 로드한 ICC 파일이 외부에서 변경되면 Preview/Save로 새로 읽는다.

Apply tone/levels to selected raster는 별개의 그림 명령이다. 해당 캔버스 보기를 활성화한 상태에서 선택한 래스터층과 선택 마스크 coverage에만 커브/레벨을 굽는다. 합성 미리보기 전체를 평면화하지 않으며 UI에서 선택층 적용이라고 명시한다. RGB만 바꾸고 기존 알파0의 숨은RGB와 알파0/128/255,배치/다른층/장면/작업 공간/ICC는 유지한다. 잠금/잘못된 대상/취소/Undo 메모리 한도는 수정 전 거절한다. 성공은 한 Undo/Redo이며 이중 보정을 피하려고 해당 보기의 톤 미리보기를 identity로 돌린다. ICC 시뮬레이션은 굽지 않는다. Undo는 픽셀을 복원하며 보기 미리보기 설정은 별도다. 적용 후 로컬 표시 설정 저장이 실패해도 픽셀 적용을 실패로 가장해 재실행하지 않고 별도 오류를 표시한다.

보기의 이미지 캐시는 설정 변경/새로 고침에 무효화한다. 일반/타일 캔버스·네비게이터·별도 표시 창과 화면 보간 후의 픽셀에 연결한다. 문서 Renderer/스포이트/내보내기는 보기 보정과 무관하다.

검증: sRGB4096색 왕복,흑백/색역 끝/알파와 gamma·레벨·클리핑,Gray와 독자 생성 CMYK 양방향 LUT/방향 누락 거절,네 의도를 확인한다. 실제 UI의 두 보기/타일·보간 텍스처,초안 미리보기/저장/비활성/취소/누락ICC 거절,선택층 적용 버튼/Undo/Redo와 다른 보기 활성화 거절,설정/문서 재열기·프로필 원본 bytes 불변을 검사한다. 원래 문서색 스포이트/픽셀/dirty/그림 이력은 미리보기 중 불변이다. 설치본도 같은 독자 데이터 시험을 실행한다. 실제 모니터 측정과 물리 펜 센서 검증은 별도다.
