# 147 — 선택·전체 벡터 필압 초기화

선택한 점의 편집 필압 또는 선택한 획 전체의 편집 필압을1.0으로 되돌린다. 전체 명령은 현재 벡터층의 모든 획에 적용한다. 점과 선이 함께 선택되면 선 전체를 우선한다. 부분 선택은 모든 기존 압력 매듭과 다른 논리 제어점의 값을 보존한 채 선택점의 배수만 바꾼다. 전체 획은 내부 매듭까지 제거해 전 구간이 기본 배수가 된다. 장치 압력 표본·위치·활성 여부, 기하·핸들·폭·색·알파·채움·팁·선택은 보존한다.

두 명령과 편집 창의 버튼은 전후 미리보기를 만들며 Apply로 한 Undo를 기록한다. Escape/창 닫기는 원본을 유지한다. 페이지/수정본/프레임/층 변경 뒤의 오래된 미리보기 적용을 거절한다. 숨김·잠금·읽기 전용 연결층과 잘못된 선택은 거절한다. 한도와 Undo 예산은 기존 벡터 편집과 같다. 이미 기본값인 전체 초기화는 이력을 만들지 않는다. 문서v68의 기존 압력 저장 형식을 그대로 사용한다.

논리 제어점과 평탄화 표본 수가 다른 곡선, 비균등 압력 매듭·장치 입력·부분/전체/혼합 선택·닫힌 선·다른 층 보존·저장/재열기·Undo/Redo·미리보기 취소·오래된 적용·잠금 거절을 검증한다. 실물 펜 검증은 별도 대기한다.
