# Deterministic mouse stroke reconstruction — item 053

The normal path keeps mouse pressure at one. Per-tool local settings optionally multiply distance-based start/end tapers and a separate speed factor. Stabilization is evaluated once for each actual event; the resulting document path defines cumulative length. Fixed endpoint curves interpolate at 0/25/50/75/100%, overlapping ramps multiply, zero-length dots use pressure one, and a zero taper length disables that ramp. Speed is document pixels/second from recorded clocks, clamped toward a configurable minimum factor. Missing, repeated, backwards or wrapped clocks use factor one and never generate a velocity from distance alone. Existing pressure size/opacity targets remain independent.

At Down, settings, shape/color, pressure mapping, material behavior and seed are frozen. Raw document points and optional microsecond clocks are bounded and retained while pending. Windows mouse messages carry their reported queue clock; the generic UI path uses its observed frame clock if no event clock is supplied. Prediction marks never enter this log. Input replay JSON additionally persists the complete event/time sequence, settings, seed and cursor display settings. A stored PASS is still not trusted: the production path must run again.

Original document pixels stay unchanged until commit. Preview is a separate Stroke with original-before deltas and a unique cache identity. Move batches regenerate at most once per drawn frame. At release, the complete start/end profile is evaluated from the frozen original. Half-pixel arc samples plus curve knots retain short ramps and avoid a two-endpoint zero-pressure line disappearing. The ordinary stamp engine reads the candidate pixels generated earlier in its fixed order, never a displayed preview. Failed allocation/budget/revision/lock checks and cancellation discard the whole temporary stroke.

The reconstruction path includes explicit mouse behaviors: Normal uses the brush; Blend mixes selected pigment with the current layer's candidate color at each dab; Smudge carries pigment from the initial layer sample and reloads it from subsequent candidate samples; Wet applies one premultiplied 3×3 diffusion pass after the final stroke, extending by at most one neighboring pixel and respecting selection; Spray emits a fixed number of seeded particles at exact recorded period boundaries. Spray scatter follows brush ellipse/angle and mapped pressure. Its particle tip is 15% of brush diameter. These rules are local, documented algorithms, with no original application code or assets.

Spray includes tick zero. Repeated/missing/backward times add no time; monotonic clocks cannot create a backwards or delayed backlog. Idle held input records provisional frame clocks and requests bounded redraws; preview can grow without changing document pixels. A real Up timestamp removes provisional clock samples after the authoritative release before reconstruction. Consequently host frame segmentation or a delayed release message cannot add final particles. An instantaneous connected-line command has no measured duration, so timed spray explains that a held stroke is required. Other mouse behaviors apply to connected lines using full speed factor when no interval is available.

Normal, mixed, smudged, wet and timed results share the same one-entry pixel/metadata commit. Native version 8 geometry stores frozen settings/seed/style and per-layer run counts; consecutive identical configurations compress. The reader accepts versions 1–8, including version 7 locks without mouse records. Pixel undo/redo stores original and final pixels together with metadata states, so redo never depends on a later wall clock or random stream. It does not need to re-execute historical input. Reusable virtual input records retain the complete ordered events and clocks for actual replay. Native documents and local workspace profiles validate the new defaulted fields; older profiles preserve disabled mouse taper defaults. The geometry payload remains limited to 4 MiB, with at most 4096 distinct metadata runs, and failed metadata reservation cannot commit pixels first.

Pending input is limited to 4096 samples, 131072 document pixels of reconstructed path and 262144 reconstructed sample/knot positions or timed particle dabs. An additional 64-million pixel-work bound rejects pathological brushes/elapsed spray, while three-way transient allocation plus a 16-MiB reserve stays within the document budget. Overflow does not silently accept a partial stroke. Cooperative checks interrupt reconstruction and diffusion. The Windows app can also poll Escape only while its retained own root window is foreground, allowing cancellation during synchronous calculation without reading another app's keys. It checks again before publication. Focus/capture/device loss and normal Escape drop the pending log and pixels.

Tests verify original/preview/final separation, mixed candidate reads, repeat and redo equivalence for all behaviors, one wet pass, fixed particle counts across time segmentation, authoritative release trimming, seeded variation and repeatability, point/short/overlap rules, clock failures, configuration freeze/toggle, source limits and metadata exhaustion, cancellation during computation, selection/lock integration, native reopen, profile restart and complete input-record round trips. Actual application tests compare prediction on/off final pixels and retain a blank document after missing release or failure. Native smoke runs the same isolated production path; no physical tablet/device performance validation is implied.
