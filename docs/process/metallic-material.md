# 금속 재질 레이어 (168)

Layers → Metallic foil material을 열거나 기존 Editable material layer에서 Metallic foil을 고른다. 금속 색(sRGB), 강도0~1, 광택0~1, 광원 방향0~360도를 편집한다. 이미지 재질을 금속으로 바꾸면 현재 질감을 유지한다. Load image로 사용자 PNG/JPEG/BMP/TIFF 첫 페이지를 선택하면 방향/ICC 처리한 sRGB RGBA8을 내장 질감으로 사용한다. 원본 파일을 덮어쓰지 않는다. 레이어는 기존 재질의 이동/축척/회전·영역·반복/타일·원근/메시 기능을 유지한다.

질감 명도를 높이장으로 사용하며 양 옆/위아래의 중앙 차분으로 기울기를 구한다. 방향 벡터와 표면 기울기에서 확산광을 구하고 광택으로 반사 항의 지수/세기를 정한다. 금속 색을 넣은 결과와 원래 질감을 강도로 섞는다. 원본 제품의 비공개 효과를 재현하는 식이 아니다. 표면·광원 방향은 이 재질의 로컬 좌표에 속한다.

강도0은 보이는 원래 질감 RGB/알파를 그대로 보여준다. 강도와 광택을 바꾸어도 질감 픽셀은 수정하지 않는다. 투명 픽셀은 출력하지 않고 α1/128 같은 낮은/부분 알파를 유지한다. 투명 이웃의 숨은 RGB는 표면 기울기에 쓰지 않으며 비반복 이미지 경계는 현재 높이를 대신 사용해 잘못된 테두리를 막는다. 범위 밖/반복하지 않는 질감 밖은 투명하다.

질감을 지정하지 않으면 자체 수식으로 만든 foil 패턴을 쓴다. Use procedural fallback으로 내장 질감을 초안에서 제거할 수 있다. 금속 모드의 Load image가 실패하면 이유와 대체 패턴 사용을 표시하고 초안을 대체 모드로 바꾼다. 확정 전 원래 문서/질감은 그대로다. 금속이 아닌 기존 이미지 모드의 읽기 실패 동작은 유지한다. 모델·서버·클라우드·다운로드는 없다.

Preview material은 원본을 바꾸지 않는다. Apply material 한 번은 새 재질 생성 또는 기존 매개변수 변경 한 Undo다. 창 닫기/Escape는 초안을 버리고 오래된 문서 수정/프레임 결과는 적용하지 않는다. 매개변수 변경/읽기 실패/대체 변경은 이전 준비 결과를 제거한다. 문서v79의 Source.Metal에 매개변수/질감 치수를 저장하고 기존 제한된 재질 이미지 페이로드에 질감 RGBA를 저장한다. 원본 파일을 삭제해도 저장 문서만으로 재열기/출력을 재현한다. v78 이하 헤더로 위장한 금속 데이터는 거절한다. 손상된 네이티브 이미지 페이로드는 임의 대체로 숨기지 않고 거절한다.

일반/부동 렌더러·ICC 문서에서 sRGB 재질 결과를 작업 색상으로 변환한다. 기존 레이어 불투명도/효과와 래스터 변환/파일 내보내기를 통해 같은 결과를 사용한다. 일반 질감과 마찬가지로 최대4M픽셀, 전체 작업/미리보기/Undo 예산을 적용한다. 새 외부 의존성이나 외부 소재는 없다.

검증은 독립 확산광 기대값 `[60,30,15,255]`, 광택0/반대 방향, 강도0 원본, 투명/극저알파/비반복 경계, 반복/변환, 질감 없음/캐시 누락 대체, 잘못된 값, 원본 불변/한 Undo, v79 재열기/이전 헤더 거절, 래스터 출력 일치를 포함한다. 앱에서는 실제 명령/질감 로드/Preview/Apply·삭제된 외부 질감 재열기·저장 값 재편집·읽기 실패 대체·대체 변경 준비 폐기·Escape/오래된 프레임을 검사한다.
