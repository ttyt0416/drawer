# 로컬 참조 입장 검사와 캐시 보존

문서/이미지·연결 파일·소재·모델/텍스처·SVG 이미지·글꼴·동영상·추론 모델을
읽을 때 URI/UNC/부모 탈출을 먼저 검사한다. Windows GetDriveType을 안전한
고정 winsafe 래퍼로 호출하여 네트워크 드라이브/없는 드라이브를 거절한다.
그다음 경로 구성요소별 링크/재분석 지점을 검사하고 해석/열기/쓰기를 수행한다.
새 목적지도 기존 부모 구성요소와 최종 파일을 확인한다. UserStorage bootstrap과
이동 후 위치를 디렉터리 생성 전에 검사한다.

저장된 참조의 문자열 검증은 실제 접근 검사와 구분한다. 캐시 문서를 열 때
연결 원본을 자동 새로고침하거나 네트워크 경로를 해석하지 않는다. 동일 파일
검사도 먼저 로컬 입장을 검사하며 읽을 수 없는 저장 참조는 문자열로 비교한다.
연결 파일이 없어도 Native에 담긴 픽셀로 열리고, 실패한 새로고침은 캐시를 유지한다.
사용자가 로컬 파일을 선택해 다시 연결할 때만 검증된 결과를 한 Undo로 반영한다.

SVG의 http/https/UNC/상대 탈출·percent-encoded 탈출은 이미지 누락 경고로 남기고
도형을 가져온다. 모델의 허용되지 않는 외부 URI/탈출은 읽기/다운로드 전 거절한다.
허용된 모델 폴더 안의 누락 자료는 기존 로컬 누락/다시 연결 절차를 따른다.
모델 메타데이터의 source URL은 출처 표시 문자열이며 실행/다운로드하지 않는다.
선택 코덱은 같은 폴더의 로컬 FFmpeg/FFprobe만 검사하고 file/pipe 프로토콜을 쓴다.

local_paths_verify는 직접 URI/UNC/탈출 입력·상태 무변경·차단 SVG 경고·원본 없이
캐시 열기·명시적 로컬 재연결/Undo를 검사한다. test-local-references는 실제 소유
로컬 Junction을 만들고 문서/저장소/모델/코덱이 내용 파싱 전에 거절되는지,
연결 대상 파일이 변하지 않는지 확인한다. 네트워크 드라이브 분기는 결정적 분류
시험이며 호스트 매핑/원격 UNC 서버를 만들거나 접속하지 않는다.
