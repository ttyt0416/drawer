# 선폭·기준점·메시 편집 계약 (170)

기본 변형과 벡터 선택 변형은 선폭 유지를 기본값으로 사용한다. 해제하면 선폭에 `sqrt(abs(sx * sy))`를 곱한다. 음수 축은 반전이며 2×0.5배의 선폭은 원래와 같다. 전체 벡터 경로만 이 정책으로 폭을 바꾸며 부분 앵커 선택은 기하만 바꾼다. 압력 표본과 효과의 숫자는 유지한다. 기존 재질 변형의 폭 유지 옵션과 같은 정책이다.

기본 변형의 집합 중심 버튼은 연결된 개체 전체의 문서 경계 중심을 사용한다. 개별 중심을 선택하면 각 내용 개체의 경계 중심에 같은 회전/축척과 입력 이동량을 적용한다. 각 개체의 연결 마스크와 자도 그 행렬을 따른다. 벡터 선택에서는 선택한 각 경로 또는 해당 경로의 앵커 집합을 개별 개체로 취급한다. 사용자 지정 기준점도 그대로 사용할 수 있다.

변형 프레임은 기존 안정 ID별 layer_groups 프레임에 저장한다. 벡터/재질도 방향을 보관하며 다시 연 기본 변형의 경계 상자와 조작축은 이 방향을 따른다. 래스터 상자는 저장된 픽셀 영역을 해당 방향으로 감싸므로 투명 여백이 포함될 수 있다. 그림자 등의 효과 확장은 기하 상자에 넣지 않는다. 보기 확대/회전은 문서 값에 영향을 주지 않는다.

메시 창에서는 Shift-click으로 점 선택을 추가/해제하고 선택한 점을 드래그하여 집합 이동한다. 전체 선택/해제와 선택점 X/Y 이동도 제공한다. 드래그 시작의 점들과 접촉 오프셋에서 계산하므로 프레임별 이동이 누적되지 않으며 선택 밖 점은 바꾸지 않는다. 일반 메시의 뒤집힘/겹침과 모든 모드의 축퇴 삼각형은 확정하지 않는다.

퍼펫은 원본 격자 삼각형의 중심에서 가장 가까운 핀에 삼각형을 귀속한다. 거리 동률은 나중에 만든 핀으로 결정한다. 삼각형이 겹치면 정수 깊이가 큰 면을 앞에 놓고 깊이 동률은 핀 생성 순서, 같은 핀 안에서는 삼각형 순서로 정한다. 이는 원본 제품의 알고리즘을 사용하지 않은 독립적인 표면 가림 규칙이다. 앞면의 투명 픽셀은 투명하며 뒤면을 합성하는 방식은 아니다. 핀의 회전 보정은 저장된 기준각 유지와 현재 각도 따라 회전을 구분한다. 기준각 캡처 버튼은 현재 각도를 저장한다. 고정 핀은 원래 위치/각도를 유지한다.

확정한 마지막 메시/퍼펫은 문서 v81에 편집점, 다중 선택, 핀 생성 순서/깊이/각도 정책, 원래 선택과 원본 래스터 페이로드를 저장한다. 결과는 보통의 그릴 수 있는 래스터층으로 남는다. Resume saved mesh / pins 버튼은 저장한 원본에서 다시 계산하여 이중 변형과 반복 보간을 피한다. 같은 설정을 재확정하면 Undo/dirty를 늘리지 않는다. 대상 픽셀·정밀도/프로필·문서 크기/좌표계·프레임·해당 선택이 달라졌으면 재편집을 거절하고 새 편집을 사용한다. 무관한 레이어 속성은 유지한다. 원본 최대32MiB, 개별 소스4M픽셀, 기존 처리32M/문서256MiB/장면4MiB/Undo 한도를 함께 검사한다. 원본 정수8/16비트 표본을 파일 내부에 보존하며 외부 파일/서비스는 필요 없다.

일반 개체 이동/회전/축척은 원본을 이동한 뒤 효과를 다시 계산하므로 효과 거리/반경/패턴 값이 바뀌지 않는다. 문서 전체의 크기 변경/반전/회전은 효과 출력 좌표 프레임도 합성하며 원래 효과 숫자를 유지한다. 효과는 그 프레임의 픽셀 격자에서 계산하고 문서 재샘플링 필터로 출력에 옮긴다. 확대·축소 시 원본 픽셀의 정보 손실은 일반 재샘플링과 같다. 로컬/출력 효과 영역 각각1M픽셀과 둘의 작업 메모리를 검사한다. 3D 기하와 카메라는 별도 장면 좌표로 유지한다. 213의 3D 피벗 조작은 그 항목에서 구현한다.

미리보기는 원본 문서와 이력을 바꾸지 않는다. Apply 한 번에 결과와 편집 상태/연결 마스크가 함께 기록되며 Undo가 함께 되돌린다. Escape와 창 닫기는 초안을 버린다. 비동기 요청의 실제 편집 설정·재편집 여부·원본 영역을 비교해 오래된 결과를 확정하지 않는다. 미확정 저장은 기존 적용/버리기/계속 편집 선택을 따른다.
