# 복수 타임라인과 재생 (209)

`timelines-playback` 명령은 현재 애니메이션 문서의 시간 배치를 생성·복제·전환·이름 변경·삭제하고 미리보기 옵션을 관리한다. 변경은 작업자 스레드에서 준비한 뒤 별도 검토·확정으로 문서 이력 한 단위를 만든다. 오래된 문서 ID/리비전의 준비 결과와 셀 내용 편집 중 전환은 거절한다. 진행 중 준비는 취소할 수 있다.

## 시간 배치와 공통 원본

문서의 그림 레이어·트랙 구조·물리 셀 슬롯과 셀 원본은 공통이다. 각 시간 배치는 FPS 분자/분모, 프레임 수, 노출/트랙 끝, 셀 라벨, 키프레임/카메라, 출력 프레임, 오디오 PCM/타이밍/재생 범위와 샷 주석을 따로 보존한다. 활성 배치는 기존 편집기를 그대로 사용하고 비활성 배치만 별도 저장한다. 전환은 배치만 교체하므로 원본의 잠금이나 키프레임을 우회해 그림을 수정하지 않는다.

공유 복제는 같은 물리 셀과 편집 가능한 원본을 참조한다. 한 원본 변경은 공유 참조에 함께 나타나지만 노출/키/라벨 변경은 다른 배치에 반영하지 않는다. 독립 복제는 해당 배치가 사용하는 셀 슬롯과 원본을 새 ID로 복제하며, 복제 안에서의 원래 공유 관계와 오프셋/속성/개체를 유지한다. 파일 개체 참조는 기존 파일 개체 정책을 따르며 독립 복제로 외부 원본 파일을 복사하거나 바꾸지 않는다.

전역 트랙·셀 삭제와 슬롯 이동은 저장된 배치의 해당 참조에도 적용한다. 불변 원본의 좌표를 바꾸는 편집은 저장된 활성 키가 있으면 기존 키 보존 규칙에 따라 거절한다. Undo/Redo는 공통 원본과 모든 배치의 변경을 함께 복구한다. 배치 삭제는 공통 원본을 삭제하지 않는다. 최대32배치·배치당10000프레임, 기존32트랙/10000슬롯/512셀 정의·문서 메모리·64MiB 이력 및 장면 메타데이터 한도를 적용한다.

네이티브104는 비활성 배치의 구조/해시를 장면 메타데이터에, PCM과 타이밍의 원래 오디오를 길이가 검증되는 뒤쪽 페이로드에 저장한다. 활성 배치와 공통 셀 페이로드를 중복 저장하지 않는다. 메모리 예산·참조·해시·누락/변조를 검사하고 구버전으로 위장한 새 데이터를 거절한다. 기존 단일 타임라인 문서는 기본값으로 읽힌다.

## 시간코드와 재생

드롭프레임 표기는 정확한30000/1001 또는60000/1001 FPS에서만 켠다. 전자는 분 경계에서 시간코드 번호2개, 후자는4개를 건너뛰되10분 경계에는 적용하지 않는다. 실제 그림/셀/프레임 수와 출력은 그대로다. 초당 번호는 각각00..29/00..59이며 `HH:MM:SS;FF`로 표시한다. 29.97의1799/1800프레임은00:00:59;29/00:01:00;02,17982는00:10:00;00이다. 59.94의3600은00:01:00;04,35964는00:10:00;00이다. 다른 FPS로 바꾸기 전 표기를 해제한다. 표기 계산은 [Apple TN2310의 SMPTE 시간코드 설명](https://developer.apple.com/library/archive/technotes/tn2310/_index.html)을 참고해 독립 구현했다.

실시간 재생은 경과 시간 또는 기존 오디오 장치 시계로 계산하며 느린 표시 프레임은 건너뛸 수 있다. 전체 프레임 모드는 실제 표시를 확인한 다음 UI 갱신에서 한 프레임씩 진행한다. 따라서 느린 렌더링에서는 실제 재생 시간이 길어진다. 기본 실시간 모드의 오디오는 기존 재생 범위/장치 시계를 유지한다. 전체 프레임 또는 문서와 다른 사용자 FPS는 무음으로 동작한다. 반복/한 프레임/끝 정지·유효하지 않은 시계 입력을 처리한다.

재생 FPS·실시간/전체 프레임·표시 해상도·카메라 토글은 로컬 `settings/timeline-playback.json`에 저장하며 문서의 FPS/출력 설정/그림 Undo/변경 표시를 바꾸지 않는다. 품질 우선은 최대256px, 속도 우선은 최대96px 미리보기다. 카메라 토글은 고정된 미리보기 사본에만 적용한다. 재생 중이나 카메라를 끈 촬영 보기에서는 그림 입력을 막고 팬/확대는 허용한다. 최종204 이미지/영상 출력은 저장된 설정에 따라 요청한 모든 프레임을 렌더링한다.

## 미리 계산

현재 재생 범위 전체를 작업자에서 계산하고 완료 프레임 수·취소를 제공한다. 픽셀 캐시64MiB와 사용 가능한 작업 메모리를 먼저 검사한다. 부족하면 범위를 줄이거나 속도 우선 표시를 선택한다. 캐시는 RAM에만 보관하며 디스크 임시 파일을 만들지 않는다.

문서 ID/리비전·활성 배치·내용 보기·재생 범위·트랙/어니언 보기·재생 옵션을 결과에 묶는다. 편집/원소재 적용·범위/보기 변경·문서 닫기는 이전 캐시를 버리고 진행 중 결과도 취소한다. 단순 재생 위치 이동은 캐시를 유지한다. 취소는 픽셀/이력을 유지하고 닫기/교체는 작업자를 합류시킨다. 오래된 준비 결과가 새 편집을 덮어쓰지 않는다. 잘못된 로컬 설정 파일은 보존하고 오류를 안내한다.

## 검증 범위

코어에서는1분/10분/1시간 시간코드 경계, 공유/독립 원본과 속성, 독립 노출/키/라벨/오디오/출력 프레임, 전환 Undo/Redo,104 저장·재열기·구버전/오디오 변조 거절과 전역 삭제 뒤 참조를 검사한다. 느린 렌더 상황의 실시간/전체 프레임, 한 프레임 반복, 캐시 품질/카메라·메모리/취소/범위/원소재 변경과 최종 출력 픽셀 불변·PNG4장도 검사한다.

앱에서는 합성 포인터 입력으로 공유 복제·검토/확정·전환·미리 계산·보기 옵션을 조작한다. 계산 중 편집/취소·오래된 배치 결과 거절·로컬 설정 재시작, 느린 화면 갱신에서12프레임 순서·무음/이력 불변,32배치 제한·이름 변경·삭제 Undo를 확인한다. 설치본도 같은 검사를 실행한다. 화면 자동화나 실물 펜 검증은 수행하지 않는다.
