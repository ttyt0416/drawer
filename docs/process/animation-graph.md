# 애니메이션 그래프 편집 (211)

`animation-graph`는 기존 레이어/셀/트랙/카메라 키를 시간/값 그래프로 표시한다. 원본 그림·정밀도·레이어 구조를 보존하고 키 메타데이터만 고친다. 오프셋X/Y·스케일X/Y·회전·피벗X/Y·불투명도를 선택한다. 값 편집은 선택 채널에 적용한다. 기존 파일 형식의 한 구간 곡선은 포즈 전체가 공유하므로 곡선 모양은 모든 채널의 보간에 적용하며 화면에서도 알린다.

## 드래그와 스냅

키나 선택 키의 들어오는/나가는 핸들을 직접 끈다. 드래그 중에는 고정 리비전에서 만든 준비 결과를 표시하고 원문서를 바꾸지 않는다. 마우스를 놓으면 한 Undo로 확정하며 Esc·창 닫기·포커스 상실은 준비 결과를 버린다. 문서/키 변경·문서 닫기는 오래된 준비/드래그를 해제한다. 확정 직전 문서ID/리비전을 다시 확인한다. 기존 내용 편집/변형/텍스트 초안과 잠긴 소유자는 이유를 표시하고 거절한다.

Free/Time only/Value only는 움직일 축을 고른다. 시간과 값의 스냅 간격·사용 여부는 독립적이다. 시간 스냅은 첫 내부 프레임을 기준으로 적용하고 키 시간은 정수 프레임으로 기록한다. 핸들은 구간 안의 실제 시간/값 좌표를 해당 베지어 제어점으로 변환한다. 제어점은 기존 단조 시간·0..1 곡선 한도를 유지해야 하며 벗어나면 적용하지 않는다.

Split adjacent tangent handles를 끄면 선택 키를 중심으로 같은 시간/값 벡터를 반사해 반대쪽 인접 구간 핸들도 갱신한다. 켜면 선택한 쪽만 바꾼다. 첫/마지막 키에는 실제로 있는 쪽만 제공한다. 평평한 선택 채널은 같은 값에서 시간 핸들을 조절할 수 있다. 이웃 구간의 길이/값 범위가 연결된 접선을 허용하지 않으면 독립 편집 또는 다른 제어점을 선택하도록 안내한다. 고정/선형 구간의 핸들을 끌면 베지어 구간으로 전환한다.

## 시간/값 확대와 라벨

선택 키 범위·시간 기준 프레임·시간 분자/분모·값 배율/기준값으로 키를 확대한다. 시간 비율은1..1000의 양수 정수이며 부호 있는 프레임 거리를 반올림해 결정한다. 값 배율은−1000..1000이며 결과가 선택 채널의 기존 한도를 만족해야 한다. 빈 범위·유효하지 않은 배율·문서 밖 시간·채널 범위 밖 값은 원본을 유지하며 거절한다.

다른 키나 확대된 키끼리 같은 시간에 겹치면 기본 거절이다. 명시적인 교체를 고르면 선택 키가 기존 키를 대체하고 여러 선택 키가 겹칠 때 원래 시간이 나중인 선택 키를 유지한다. 다른 채널·소스 그림·FPS·셀 노출은 변경하지 않는다. 준비된 요약을 보고 Apply하거나 Cancel한다.

타임라인 점 라벨과210의 트랙 범위 라벨을 새 시간으로 옮긴다. ID/이름과 범위 길이·클립 관계를 유지하고 문서 끝을 넘으면 거절한다. 트랙 소유자의 잠금도 적용한다. 명시적인 라벨 이동은 클립 이동과 별도이며 기존 라벨 연동 정책을 유지한다.

## 보기·저장·검증

시간/값 축의 보기 확대·Fit·정확한 표시 범위는 문서 이력/dirty와 독립이다. 축/스냅/채널·핸들 편집 방식과 함께 로컬 `settings/animation-graph.json`에 명시 저장한다. 잘못된 파일은 보존하고 오류를 안내한다. 키/곡선/라벨은 기존 자체문서105에 저장하며 새 형식이나 의존성을 추가하지 않는다. 기존10000프레임/전체 키10000개·소유자1024개와 작업/이력 메모리 한도를 따른다.

검증 범위는 연결/분리 핸들의 인접 곡선·그래프와 렌더러의 보간 일치, 시간/값/축 스냅, 시간/값 확대·빈 범위/키 충돌/교체·최대 프레임9999와값1e9/범위 초과/예산/오래된 결과, 라벨 이동과 Undo/Redo, 저장·재열기 및 로컬 보기 재시작이다. 앱과 설치본은 합성 포인터로 키 드래그 중 원본 불변·놓기 한 Undo·핸들 취소/확정·보기 확대/저장·문서 닫기를 검사한다. 실물 펜 검증은 별도 대기 상태다.

기존 출력창의 미리보기 이미지가 비동기로 도착할 때 취소 버튼이 이동하는 오류도 확인했다. 취소를 이미지 앞의 고정 위치에 배치하고 도착 전후 버튼 좌표와 실제 취소·설정 복귀를 검사했다.
