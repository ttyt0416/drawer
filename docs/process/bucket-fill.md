# 093 — 영역 채우기와 선택 전체 채우기

Fill/G는 누르는 순간 참조/설정/색/대상/문서 리비전/프레임/입력원/보기 투영을 고정한다. 임시 문서로 결과를 표시하고 캔버스 안에서 놓으면 원본에 한 명령으로 적용한다. Esc·초점 상실·입력 취소·보기/설정/활성층/문서/프레임 변경·모달 진입과 캔버스 밖 놓기는 버린다. 취소 뒤 눌린 접점이 끝나기 전 다른 Down을 새 클릭으로 간주하지 않는다. 미확정 결과는 문서·dirty·그림 Undo에 포함하지 않는다. 기존 선택·애니메이션·페이지 개체·참조층은 보존한다.

설정은 현재 도구의 일곱 슬롯별 fills에 저장하고 자체 도구 프리셋의 capture/encode/decode/apply에도 포함한다. 구형 설정/프리셋의 누락 값은 기본값이다. 참조는 현재 래스터, 지정 래스터, 보이는 합성으로 선택한다. 지정 래스터는 원본 RGBA를 읽으며 합성은 기존 렌더러의 폴더·종이·벡터·페이지 개체·노출 셀 결과를 읽는다. 참조를 읽어도 그 층을 변경하지 않는다.

독립 판정 규칙: 클릭 알파가 공통 알파허용치 이하이면 투명 영역 모드로 해당 알파허용치 이하의 픽셀을 4방향으로 탐색한다. 알파0의 숨은RGB는 판정에서 제외한다. 클릭 알파가 그보다 높으면 같은 불투명 구간에서 클릭RGBA와 각 채널 최대 차이가 색차허용치 이하인 픽셀을 탐색한다. 알파허용치와 색차허용치는 각각0~1이며 동등 값은 포함한다. 알파허용치0의 투명 영역은 알파0만 탐색한다. 엄격 모드는 gap 값을 사용하지 않는다. 틈 보정 모드는 원래 적격 비트에서 수평/수직으로 양끝이 막힌 길이 gap 이하의 좁은 통로를 닫은 뒤 같은 탐색을 수행한다. 이는 독립 격자 정책이며 대각선/임의 곡선의 모든 틈 폐쇄를 보장하지 않는다. 닫힌 틈 위를 클릭하면 내부 클릭을 요청하며 원본을 유지한다.

영역확장은 탐색 뒤 4방향 맨해튼 거리0~32픽셀의 팽창이다. 안티앨리어싱은 탐색의 연결성을 바꾸지 않고 투명 모드에서 영역에 인접한 부분 알파 경계에 255-알파의 강도를 더한다. 적격 내부는255이며 불투명 경계는 자동 확장하지 않는다. 따라서 허용치·틈·안티앨리어싱·영역확장을 독립적으로 시험/조절할 수 있다. 마지막에 문서 선택 coverage를 한 번 곱해 현재 래스터에 그리기RGBA를 source-over 적용한다. 투명색은 알파만 지우며 숨은RGB를 유지한다. Protect target alpha는 기존 알파를 고정하고 알파0 쓰기/투명색 지우기를 막는다. 기존 페이지 선택 판정을 공유한다. 후속 레이어 마스크/클리핑은 해당 레이어 합성 모델 도입 시 연결한다.

Fill entire selection은 클릭이나 색차/틈 탐색을 사용하지 않는다. 분리된 선택과 반투명 선택 강도도 그대로 적용하며 선택없음은 캔버스 전체, 명시적 빈 선택은 무변화다. 캔버스 밖 저장 픽셀은 건드리지 않는다. 작은/배치된 래스터는 필요한 캔버스 영역까지 늘리면서 원래 밖 픽셀을 보존한다. 바뀐 픽셀이 없으면 배치/dirty/이력도 유지한다. 숨김/잠금/미지원층·존재하지 않는 참조·잘못된 설정/좌표는 확정 전에 실패한다. 전체 변경은 한 Undo/Redo이고 자체 파일에 확정 픽셀만 저장한다.

한 탐색/선택 채우기는4Mi 픽셀, 합성 참조는 추정64Mi 원시 판정 작업, 틈/팽창32픽셀과 기존 문서/확장래스터/Undo 메모리 상한을 적용한다. 상한 초과는 부분 적용하지 않는다. 네트워크·계정·원본 프로그램 자원은 사용하지 않는다.

검증: 독립7×7 폐곡선/0·1·큰틈, 두 모드의 알파127/255 직전·같음·직후/128 경계, 색차0/1채널, 경계AA와 연결성 분리, 확장/모서리, 현재/지정/합성 참조 변경을 시험한다. 분리된128/255 선택 강도의 독립 RGBA 기대값·빈 선택·선택없음·투명색/숨은RGB·알파잠금·잠금/오류·캔버스 밖 보존/작은층 확장·한 Undo/Redo/재열기·프리셋 재적용을 확인한다. 실제 생산 마우스/합성 펜에서 확대1.5/90도 보기, G와Down 동시 입력·반복G·놓기/해제, 초안 원본 불변과 Esc/초점/보기/밖 놓기/참조 변경/입력Cancel을 확인한다. 물리 펜 센서는 별도 검증한다.
