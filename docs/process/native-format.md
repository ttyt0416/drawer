# Drawer 로컬 문서 형식

편집 문서는 `.drawer`에 저장한다. 현재 형식 버전 72는 독자적으로 정의하며, 모든 정수와 DPI의 IEEE 754 비트는 little endian이다. 버전 1~71도 읽는다. 아래는 기본 컨테이너와 주요 확장 설명이다.

파일 순서는 8바이트 `DRAWER\r\n`, u32 버전, u32 가로·세로, f64 DPI, u32 레이어 수, 레이어별 u32 이름 바이트 수·UTF-8 이름·u64 픽셀 바이트 수·RGBA8 픽셀이다. 레이어는 아래에서 위 순서이며 픽셀은 왼쪽 위부터 행 순서의 straight alpha다.

버전 2는 레이어 데이터 뒤에 u32 페이지 기하 바이트 수와 UTF-8 JSON을 추가한다. JSON은 문서 변환, 잘림 다각형, 텍스트/선/톤/그림자 객체, 선택, 가이드, 카메라와 3D 세계 기하를 보존한다. 수치의 f64 왕복을 사용한다. 페이지 기하는 4 MiB 이하이며 알 수 없는 필드와 잘못된 기하를 거절한다. 현재 기본 텍스트 기하의 총 UTF-8 크기는 16 KiB 이하이다.

버전 3은 페이지 기하 JSON에 격자의 간격·원점을 추가한다. 격자 없는 버전 2는 기본 격자로 읽는다. 표시 토글과 모니터 보정은 문서가 아닌 로컬 보기 설정에 저장한다.

보기·선택한 도구·실행 취소 이력은 문서가 열린 동안 유지하며 파일에 넣지 않는다. 저장은 같은 폴더의 새 임시 파일에 기록·동기화한 뒤 목적 파일을 교체한다. 실패하면 기존 파일과 문서를 보존한다. 손상된 헤더·지원하지 않는 버전·크기·DPI·이름·픽셀 길이·후행 데이터와 메모리 예산 초과를 거절한다.

앱의 이미지 가져오기는 PNG/JPEG/TIFF의 선택 페이지를 독립 미저장 문서로 만든다. ICC 색을 sRGB RGBA8로 변환하고 선택한 방향을 픽셀에 적용한다. 변환 결과를 자체 문서에 저장하므로 재열기에서 외관이 유지된다. 원본 프로필/16비트 샘플/방향 메타데이터의 원문은 자체 문서에 복제하지 않는다. 기본 DPI는 300이며 입력 물리 해상도는 후속 메타데이터 항목에서 구현한다. 검증된 지원 범위는 `image-import.md`에 있다. v62의 새 계산 문서는 PNG8 출력에 문서 RGB ICC를 기록한다. DPI 출력은 후속 파일 형식 항목의 범위다.

버전 4는 각 레이어 이름 뒤에 u32 배치 태그를 추가한다. 0은 기존 캔버스 크기 래스터이며 1은 u32 독립 가로/세로와 i64 문서 픽셀 원점 두 값을 포함한다. 그 뒤 기존 u64 픽셀 바이트 수와 전체 RGBA8 데이터를 기록한다. 배치 래스터는 캔버스 밖 픽셀도 저장하며 합성할 때만 출력 경계로 자른다. 레이어 원점은 축당 ±10억 픽셀이다. 버전 1~3은 기존 캔버스 크기 래스터로 읽는다.

버전33은 Scene.selections에 페이지 식별자,최근 선택 snapshot,이름/페이지 내 ID가 있는 저장 선택을 추가한다. 활성 마스크/사각형/문서공간 이동은 기존 필드를 사용한다. 새 필드 누락은 비어 있는 선택 저장소로 읽으며 기본 저장소는 JSON에서 생략한다. 페이지 복사는 식별자 namespace를 다시 만든다. 추가 선택도 Scene JSON4MiB 및 coverage run/이력 메모리 한도를 지킨다. 입력/편집/검증 계약은 page-selections.md에 있다.

버전34는 Scene.rulers에 독립 ID/이름/종류를 가진 직선·축/방사 대칭·1/2/3점 원근 보조와 활성 ID를 보존한다. 좌표는 기존 페이지 transform의 원래 좌표이며 임시 스냅 상태는 문서에서 제외한다. 구형 문서의 누락 필드는 빈 보조 저장소로 읽는다. 한 활성 보조,32개 개체,방사2~16개 복제와 기존Scene4MiB 한도를 적용한다. 상세 계약은 drawing-rulers.md에 있다.

버전35는 래스터 Paper와 벡터 Layer의 선택적 fill 태그(role/draft/reference)를 저장한다. 기본 태그는 JSON에서 생략하고v34 이하 누락은Drawing/false/false다. 태그는 그림 픽셀에 영향을 주지 않으며 채움 참조 정책에만 사용한다.

문서 버전58은 안정 ID로 연결한 레이어 컴프와 다음 컴프 ID를 보존한다. 비어 있는 컴프 데이터는 직렬화에서 생략하여 기존 기본 문서 호환성을 유지한다. 버전58 미만으로 표시된 파일의 컴프 데이터는 거절한다.

문서 버전59는 연동 그룹·안정 ID 표시 스냅샷, 개별 종이/마스크/표시 범위/자의 좌표계 및 검증 가능한 래스터 기하 변형 기록을 보존한다. 새 데이터는 기본값이면 생략하며, 이전 버전으로 표시한 파일의 새 데이터와 존재하지 않는 그룹/변형 대상 ID는 거절한다.

문서v60은 새 표현색의 선형 sRGB 명도 계산과 명도/알파 임계값을 appearance 스타일에 저장한다. 설정이 없는 과거 문서는 기존 표현색 계산을 유지하며 새 편집기에서 미리보기/확정할 때 새 규칙으로 전환한다. 실제 잉크 변환은 변환된 RGBA/선색과 Color 표시를 저장하며 한 Undo가 이전 픽셀/설정을 복원한다.

문서v61은 출력 종이 배경 래스터의 안정ID를 scene.paper_background에 저장한다. 색/표시는 일반 픽셀/층 속성이며 체크색은 문서에 넣지 않는다. 삭제/병합 등으로 층이 사라지면 참조를 정리하고 Undo로 복원한다. 오래된 헤더의 종이ID와 실제 없는ID를 거절한다.


문서v62는 기존 소재 페이로드 뒤에 선택적 DCOLOR01 확장을 기록한다. 채널 깊이(8/16), 디더 사용 여부/u32 시드, 계산 구분(기존8/float64), RGB 프로파일 구분(sRGB/무프로파일 sRGB 해석/이름과 원문 ICC), 래스터별 16bit 평면 유무와 little-endian RGBA16을 보존한다. 기본 컨테이너의 RGBA8은 16bit 평면의 검증 가능한 최종8bit 미리보기 사본이다. 16bit의 alpha0 RGB0, 사본 일치, 프로파일/길이/예산을 검사하고 구형 헤더로 위장한 확장을 거절한다. 종래 기본 문서는 확장을 생략하며 이전 계산/숨김 RGB 호환성을 유지한다. 실제 픽셀 정밀도/프로파일을 담은 DocumentState가 Undo를 보존한다. 자세한 계산/입출력 경계는 document-color.md에 있다.


문서v63은 소재/파일 캐시의 선택적 mapping(타일 모드·왜곡/원근/메시)과 링크별 source selection(안정 레이어 키·컴프·프레임·타임라인)을 JSON에 보존한다. 기본값은 생략하며v62 이전 파일은 기존 Repeat/매핑 없음/첫 페이지/컴프 없음이다. 새 필드를 구형 헤더로 표시하면 거절한다. 격자는 최대5×5이고 접힘/원근 수평선/잘못된 수치를 거절한다. 기존 material RGBA 스트림과 DCOLOR01 정밀도 푸터 순서는 바뀌지 않는다. 외부 파일은 열기/표시/저장 때 읽지 않는다. 상세 계약과 비선형 연결 마스크의 영역 제한은 advanced-materials.md에 있다.


문서v69는 래스터 보정층 Adjustment의 선택적 invert:true를 저장한다. false는 생략하고 이전 문서는 false로 읽는다. 반전은 문서 RGB 숫자에서 각 색성분을1−값으로 바꾸고 기존 마스크·불투명도로 하위 합성에 적용하며 알파를 유지한다. ordinary 밝기/대비/HSL/HSV 뒤에 문서 RGB 반전을 적용한다. 활성 반전 데이터를v68 이하 헤더로 표시하면 거절한다. RGBA/정밀도 스트림은 바뀌지 않는다. 격자/유동화·픽셀 색 보정의 초안은 파일에 넣지 않으며 확정 결과의 픽셀/배치만 저장한다. 프로파일 지정은 숫자/반전 매개변수를 유지하며 프로파일 변환은 보정층이 있으면 기존의 명시적 현재 프레임 래스터화를 요구해 합성 외관을 보존한다.

버전70은 Scene.last_spatial_blur에 마지막으로 확정한 모션/방사/회전/렌즈 블러의 설정을 선택적으로 저장한다. 결과는 기존8/16비트 픽셀/배치에 구워져 있으며 이 기록은 실시간 효과나 레이어 참조가 아니다. 누락은 기록 없음이다. 영효과/취소는 이전 기록을 보존한다. 한 Undo가 픽셀과 기록을 함께 복원한다. 기록을 가진v69 이하 위장 헤더와 잘못된 설정을 거절한다. 로컬 모드별 프리셋은 workspaces.json에 저장한다.

버전71은 Scene.last_detail_filter에 마지막으로 확정한 Sharpen/Unsharp/Denoise의 선택적 설정을 저장한다. 실제 결과는 기존8/16비트 픽셀과 배치에 있으며 실시간 효과가 아니다. 누락은 기록 없음이고 잘못된 값과 기록이 있는v70 이하 헤더를 거절한다. Undo가 픽셀과 기록을 함께 복원한다.

버전72는 last_detail_filter.operation의 Pixels 변형에 모자이크 셀/문서 격자 원점, 노이즈 강도/정수64비트 시드/단색 옵션, 먼지 면적/임계/대상과 선폭 증감을 저장한다. 결과는 기존8/16비트 픽셀/배치에 구워진다. 새 변형이 있는v71 이하 헤더를 거절하고 기존3종 detail 변형은v71 규칙을 유지한다.
