# 폴더·회색조 레이어 마스크

새 빈 폴더와 중첩, 같은 부모의 연속 래스터/폴더 감싸기, 폴더를 다른 부모/슬롯으로 이동, 해제와 일반/통과 모드를 제공한다. 감싸기는 상대 순서를 유지하고 기본 통과 모드로 배경을 보존한다. 다른 부모/불연속 선택·자기/자손 안 이동·클리핑 연쇄 분리·잠금·깊이/슬롯 초과를 부분 변경 없이 거절한다. 애니메이션 트랙은 자체 셀 계층을 유지하며 이 래스터 폴더로 감쌀 수 없다.

해제는 같은 위치의 부모 목록에 자식을 올린다. 숨긴 폴더의 자식은 숨김으로 보존한다. 마스크·불투명도·혼합·종이·클리핑의 영향이 있으면 해제 대신 하위 배경을 포함한 병합 또는 전체 합치기 미리보기를 제안한다. 단순 폴더도 저장 영역 전체의 전후 합성을 비교해 외부 배경 의존성을 검사한다. Open raster preservation preview는120의 영향 목록/선택/미리보기·확인 화면을 연다. 보존 불가능한 해제를 자동 실행하지 않는다.

래스터·벡터·폴더에 회색조 마스크를 붙이거나 제거한다. 사각 영역과0–255 강도를 지정해 대체하며 밖은0이다. 위치는 페이지 좌표로 지정하고 원래 좌표의 비중첩 행 구간으로 보관해 회전/배율을 보존한다. 강도는 기존 층 알파·부모 마스크와 곱한다. 통과 폴더는 마스크×불투명도로 진입 배경과 내부 결과의 premultiplied 색/알파를 보간한다. 기본 연결 마스크는 전체 래스터/벡터층 이동을 따라가며 부분 픽셀/개별 경로 이동은 층 이동으로 취급하지 않는다. 캔버스 선택 후보도 자기/부모 마스크를 반영한다.

각 버튼은 원본 픽셀을 바꾸지 않는 상태 한 Undo다. 작성 중 문서/수정본/프레임을 고정하고 성공한 편집 뒤만 초안을 갱신한다. 문서v49의 공통 효과 저장을 사용한다. 폴더 식별자256슬롯(소비 슬롯은 재사용하지 않음)·깊이16·마스크32768행 구간/4Mi 작성·비교64Mi 작업과 기존 문서/초안32MiB/이력64MiB·JSON4MiB를 검사한다. 폴더 종류·마스크 반전/복사/영역 보기 등 추가 동작은 해당 후속 항목에서 제공한다.

검증은 감싸기/빈 중첩/이동·자손 순환/다른 부모·잠금·해제 순서/효과 대안, 층128×부모128의 알파64·0/255·재열기, 연결 마스크 반복 이동/Undo·90도 후 작성과 벡터 표시/선택 후보를 포함한다. 실제 Wrap/Create/Unwrap/Mask/Remove 버튼·구조 Undo/Redo/저장·오래된 프레임/Escape/닫기를 검사한다.
