# 111 — 마그네틱 올가미·다중 입력·선택 밖 삭제

현재 래스터/표시 합성의 알파·premultiplied RGB 차이로 픽셀 경계 격자 그래프를 만든다. 투명 픽셀의 숨은 RGB는 경계가 아니다. 지정 반경의 가장 가까운 경계 꼭짓점에 붙이고 두 입력 사이를4방향 경계 그래프의 최단 경로로 잇는다. 대각 접점은 공유 꼭짓점이며 동률은 위/오른쪽/아래/왼쪽 순서로 결정한다. 경계가 없거나 서로 연결되지 않으면 입력/스냅 끝점 사이 직선을 사용한다.

지정 벡터 경로는 표시 선폭 대신 변환된 중심선에 투영하고 경로의 중간 꼭짓점을 보존한다. 닫힌 경로는 짧은 쪽 호를 사용하며 열린 경로는 순서대로 잇는다. 숨긴 참조는 거절하고 잠긴 참조는 읽기만 한다. 반경은 문서 픽셀이다. All / Freehand only / Polyline only가 자석 적용 범위를 정하며 자석을 끈 다중 입력도 사용할 수 있다.

Single stroke는 한 드래그를 놓을 때 확정한다. Multiple input은 클릭을 직선 입력으로, 드래그를 자유선 입력으로 합쳐 다음 접촉까지 미확정 상태를 유지한다. Polygon 도구는 직선 범위를 사용한다. Enter는 마지막 점과 첫 점을 연결해 확정하고 Backspace는 마지막 입력 점/구간을 지운다. 닫기에도 한 획에서는 자유선, 다중/다각에서는 직선 자석 범위를 적용한다. Escape/포커스/문서/프레임/보기/장치/설정 변경은 초안을 폐기한다. 결과는 기존4×4 표본과 네 집합 연산으로 선택만 바꾸고 한 Undo로 복원한다.

재선택은 마지막으로 해제한 선택을 별도 문서 상태로 보존한다. 다른 선택을 새로 만들어도 이 상태를 덮지 않는다. 반복 해제는 무이력이며 Undo/Redo·페이지 복제·좌표 이동·문서v41 재열기를 지원한다. 과거 파일은 기존 last 필드를 호환 경로로 읽는다.

Delete outside selection은 일반 지우기와 별도 명령이다. 선택 강도A에 대해 대상 픽셀 알파를 oldAlpha×A/255로 보존한다. 일반 내부 지우기의 oldAlpha×(255−A)/255와 반대다. 선택없음/빈 마스크/잠긴 대상에서는 비활성이고 선택이 래스터와 아예 겹치지 않으면 무변경 거절한다. 선택·다른 레이어·원래 RGB를 보존하고 삭제되는 알파0 픽셀만0으로 정리한다. 전체 강도255 영역은 숨은 RGB도 바꾸지 않는다. 한 Undo로 원본을 복원한다. 선택 바로가기 막대와 선택 창에서 사용할 수 있다.

참조 그래프4Mi픽셀, 경계 탐색65536꼭짓점/구간, 입력·결과4096점, 누적64Mi 작업, 기존 문서/작업공간/JSON/Undo 메모리 제한을 적용한다. 초안은 원본을 바꾸지 않으며 그래프는 해당 문서 수정본에 고정한다. 외부 서비스나 원본 제품 코드는 사용하지 않는다.
