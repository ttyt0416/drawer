# 키보드 탐색·고대비·배율 (306)

F10은 명령 검색창을 연다. 검색칸에 포커스가 있을 때 Up/Down은 항목을 고르고 Enter는 선택한 명령을 실행한다. Tab/Shift+Tab으로 항목·실행·고대비·닫기 버튼을 탐색할 수 있다. 버튼에 포커스가 있으면 그 버튼의 Enter 동작을 사용한다. 닫기 버튼의 Enter가 선택 명령을 실행하지 않는지 별도로 검사한다. Esc는 명령창을 닫고 이전 포커스로 돌아가며 인터페이스/패널 설정창도 닫는다. F1은 포커스에 맞는 로컬 도움말을 연다. 미지원 명령과 진행 중인 결정 대화상자는 이유를 표시한다.

명령창에서 Panel settings/Interface size/Information/Help에 접근한다. 도구와 등록된 명령도 검색할 수 있다. 명령창 동안 미확정 획은 포커스 손실과 같은 경로로 취소하며 새 누름을 요구한다. 문서 명령 이외의 탐색·대비·배율 조정은 문서 픽셀/메타데이터와 Undo를 바꾸지 않는다.

고대비는 UI 배율 설정의 기본값 false인 새 필드다. 예전 설정은 기본값을 적용하고, 저장·재시작 후 선택을 유지한다. 검은 패널/흰 글자·2포인트 테두리와 텍스트 선택 표시를 제공한다. 문서의 색이나 출력 색은 변경하지 않는다. 도움말 버튼/선택 항목에는 F1 안내를 제공한다.

`scripts/test-checklist.ps1 -Item 306`은100%/200%에서 실제 앱 CPU egui 이벤트로 Tab/ShiftTab·검색·화살표·Enter·Esc·이전 포커스·F1·설정창을 검사한다. 창이 콘텐츠 영역 안에 있고 텍스트 대비율이7 이상이며 포커스/선택 테두리가2포인트 이상이어야 한다. 설정 재시작과 문서/이력 불변을 확인한다. 이는 실제 보조 장치나 모든 운영체제의 접근성 검증을 대체하지 않는다.
