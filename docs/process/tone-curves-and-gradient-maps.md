# 152 — RGB·채널 톤 커브와 명도 그라데이션 맵

Layers의 RGB and channel tone curves는 마스터와 R/G/B별2–32개의 입력/출력 제어점을 제공한다. 입력은0–1이며 양 끝 입력은0/1로 고정한다. 그래프의 점을 드래그하거나 수치를 편집하고 가장 큰 입력 간격에 점을 추가·중간점을 삭제·채널 초기화/반전할 수 있다. 입력 순서는 증가해야 하며 중복/1e-9 미만 간격·비수·범위 초과는 적용하지 않는다. 출력은 역전/평탄 구간을 허용한다. 선형 또는 제한 기울기의 cubic Hermite로 보간하며 이웃 출력값 밖으로 넘지 않도록 한다. 마스터를 먼저 적용한 뒤 각 채널을 적용한다. 항등곡선은 픽셀·저장 정밀도·이력을 그대로 유지한다.

Luminance gradient map은 sRGB 명도0.2126R+0.7152G+0.0722B를 로컬2–32개 RGB 색 지점에 대응한다. 색/위치와 Standard/Oklab/CIELAB/Linear RGB 혼색을 고르고 명시적으로 정렬한다. 같은 위치의 색 지점은 마지막 지점을 택하는 계단 경계다. 지점 밖 값은 양 끝 색으로 제한한다. 기존 그라데이션 혼색 수식을 재사용하되 지점 알파는 색 혼색에 관여하지 않도록255로 정규화하고 원래 픽셀 알파를 유지한다.

문서 RGB 프로필을 sRGB로 변환해 보정하고 원래 프로필로 돌린다.8/16비트 저장 정밀도를 유지하며 픽셀의 원래 알파 표본을 그대로 기록한다. 알파0의 숨은 RGB·선택 밖 자료·기하·레이어 속성은 그대로 둔다. Only within the area selection은 선택 강도로 결과를 섞고 명시적으로 빈 선택은 문서를 바꾸지 않는다. 결과가 실제 저장값에서 달라지는 때에만 고정밀도 자료를 만들고 기록한다. RGB 계산/보간은 부동소수이며 양자화 반 단계 경계의 RGB는 가장 가까운 저장값을 사용한다.

전후 미리보기 뒤 현재 래스터 픽셀에 한 Undo로 확정한다. Escape/닫기는 버리고 페이지/프레임/수정본/대상 변경 뒤 계획을 거절한다. 준비가 실패하면 이전 적용 계획을 비운다. 출력 픽셀·기하·선택은 기존v68 자체 문서에 저장되며 보정 레시피는 미확정 창의 임시 상태다.4M픽셀·기존 JSON·문서/작업공간/Undo 한도를 적용한다.
