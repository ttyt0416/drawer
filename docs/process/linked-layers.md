# 연동 그룹과 이동 도구 (133)

안정 Key로64그룹×256직접 구성원을 저장하며 구성원과 폴더/트랙 하위 트리의 중복 소속을 거절한다. 이동/변형/잉크 필터의 자동 확장을 각각 저장하고 표시 일괄 전환은 연동 스위치와 독립이다. 모든 구성원의 잠금과 지원 종류를 먼저 검사하고 임시 상태에서만 계산하여 실패 시 부분 적용이 없다. 삭제 시 사라진 구성원을 정리하며2미만인 그룹은 해제하고 ID 고수위는 유지한다. 단독 표시는 자체 hidden을 안정 ID로 기록하여 부모를 보이게 해도 원래 숨김 자식 상태를 보존한다. 복원은 삭제를 건너뛰고 새 층을 유지한다. 기존 폴더 solo와 상호 배제하고 컴프 캡처/전환도 solo 복원 후 사용한다.

현재층 포인터 이동·검색 이동과 래스터 방향키가 같은 그룹 이동 경로를 사용한다. 방향키 반복은 고정 원본/총 변화량에서 계산하고 한 이력으로 합친다. 폴더 하위 숨김 래스터는 이동/변형 때 숨김을 유지하며 필터는 먼저 표시하도록 요구한다. 이동은 기존 마스크/자/종이 이동 경로를 사용한다. 변형은 문서 공간 affine을 래스터 최근접 샘플링과 벡터/소재/그라데이션 좌표로 적용한다. 원래 페이지 좌표의 개별 종이·마스크·표시 범위·자 공간을 따로 저장하여90도와 후속 이동에서 질감/마스크/선화/자가 한 번만 변한다. 연결 파일 캐시는 변환하고 원래 데이터는 보존한다.

벡터는 원래 공간의 similarity인 경우 선 굵기/점/정의를 보존하고 비균일 페이지 축에서 비틀리는 선 폭은 래스터화를 요구한다. 편집 텍스트/톤/그림자/3D/애니메이션 전체 변형과 래스터/벡터 이외 잉크 필터는 해당 종류를 먼저 래스터화하도록 전체 거절한다. 이미지/위치/전체 잠금은 유지한다. 알파 보호와 숨김 자식은 정확한 최근접 기하 결과를 재계산하는 검증으로만 허용하며 임의 색/알파 편집은 허용하지 않는다. 검증 행렬은 JSON 프레임 배열로 저장하고 존재 ID/중복/유한값을 검증한다.

이동 도구 설정은 workspace.layer_move에 current/click/area·자동선택·원본유지·7종 제외를 저장하며 other 범위의 설정 병합과 기본값 복원을 지원한다. 클릭은 기존 렌더러의 실제 알파/부모 가중치를 사용하고 영역은 실제 선택 강도와 원본 기여 알파의 교집합을 검사한다. 부분만 닿아도 전체 층을 고른다. 소속 그룹이 제외 대상을 포함하면 전체 거절한다. 현재층 전체/영역 대상과 선택 픽셀 이동을 분리한다.
