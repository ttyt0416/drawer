# 143 — 제어점 추가·삭제와 각진/부드러운 접선

Layers의 Add vector node / Delete vector node / Corner vector node / Smooth vector node 또는 Vector numeric editor의 Node tools를 사용한다. 선분 안쪽이나 점을 누르면 결과를 미리보고 같은 위치에서 놓으면 한 Undo로 확정한다. Escape·포커스 상실·입력 취소·문서/수정본/프레임/보기/대상/설정/도구 변경은 원본과 임시 선택을 복원한다. 고른 위치에서 선택 반경보다 멀리 끌어 놓아도 취소한다. 기존 교차 후보 표시/Tab 순환과 수정키 일시 점편집을 공유한다.

기존 형식의 선은 현재 저장된 윤곽 정점을 독립적인 cubic 노드로 전환한다. 원래 전체 도형/전역 곡선 정의는 Undo에 남는다. 이는 기존 렌더링 윤곽을 그대로 사용하는 선택이며 원본 앱의 수치 규격을 뜻하지 않는다. 새 노드는 위치와 상대적인 들어오는/나가는 핸들, 각진/부드러운 상태를 보존한다. 원래 도형 정의를 계속 사용할 때는 기존 점 이동 도구를 사용하고, 노드 전환 뒤 원형을 복구하려면 Undo한다.

삽입은 현재 cubic 구간을 de Casteljau로 두 구간으로 나누므로 그 수학적 형태를 유지한다. 직선은 일직선의 두 cubic 구간이 된다. 기존/새 곡선의 표시 표본 밀도는 달라질 수 있다. 삭제는 해당 점과 두 핸들을 제거하고 앞/뒤 구간을 잇는다. 열린 선은 최소2점, 닫힌 선은 최소3점을 남기며 닫힌 마지막 구간 삽입과 마지막 점 삭제도 처리한다. 끝점과 같은 위치에 중복 삽입하지 않는다.

Smooth는 인접 위치에서 공통 접선 방향을 정하고 양쪽에 반대 방향·같은 길이의 핸들을 만든다. Corner는 각 인접점 쪽으로 핸들을 독립적으로 정렬한다. 분할된 부드러운 점은 핸들 길이가 다를 수 있어도 방향이 이어진다. 선택된 핸들 선을 표시하고 부드러운 점은 원, 각진 점은 사각형으로 표시한다. 접선 계산의 영 길이 입력도 유한하게 처리한다.

원래 정점과 선폭·RGBA·채움·선 ID·다른 선을 유지하며 새 끝점/기하만 계산한다. 기존 점 이동은 핸들을 점에 붙인 채 이동한다. 기하 표본 수가 바뀌면 원래 매개변수로 장치 압력과 편집 배수를 재배치한다. 필압 조회/수정은 논리 번호 비율이 아니라 현재 기하에서 점이 놓인 실제 매개변수를 사용한다. 필압 수정은 노드 위치에서 배수를 재표본화하고 선택하지 않은 노드의 값·장치 샘플/위치를 유지한다. 닫힌 마지막 표시점의 보간 배수도 갱신해 전체 기본값 복원 뒤 잔여 배수가 남지 않는다.

문서v66에 위치·상대 핸들·상태를 원래 도형의 선택적 노드 필드로 저장한다. 기존 정의는 같은 방식으로 읽으며 노드 데이터를v65 이하 헤더로 위장하면 거절한다. 기존 생성 좌표계/레이어 변환을 공유해 변형 뒤에도 점을 편집한다. 일반/픽셀/위치 잠금과 참조 캐시를 우회하지 않는다.

정규 직선 핸들은 구간당1개, 다른 cubic은32개 구간으로 표시한다. 논리 점4096·경로 기하4096·전체 기하8192점/128경로·Scene JSON4MiB와 스냅샷/Undo 메모리 제한을 검사한다. 세밀한 기존 윤곽에서 곡선화로 표본 수를 넘기면 단순화가 필요함을 안내하고 원본은 유지한다. 잘못된 수치·불일치 핸들 배열·최소 점 수 위반은 부분 적용하지 않는다.
