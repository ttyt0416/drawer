# 3D 스냅·간격 복제와 명시적 중력 정착 (218)

`world-physics`는 선택한 개체 트리의 Floor / Surface / Array / Gravity settle과 Collider 역할 표시/해제를 준비한다. 결과는 기존3D 창에서 원본과 분리된 미리보기로 보며 Apply 한 번이 한 Undo이다. Discard/Esc/포커스 상실·창/문서 닫기·원본 변경은 버린다. 경고가 있으면 검토 확인 전에는 적용하지 않는다. 자동 재생·편집 중 임의 이동·숨은 물리 타이머는 없다.

Floor는 트리 전체의 월드 축 기준 경계 하단을 지정한 Y 높이에 맞춘다. Surface는 같은 하단 경계의 중심을 기준으로 아래쪽에 있는 별도 Collider 표시 모델의 실제 삼각형까지 탐색한다. 탐색 거리와 현재 접촉을 처리하며 방향/회전은 유지한다. 면 없는 대상/범위 밖/하단 중심 아래 면 없음은 안내한다. 표면 스냅은 하단 중심 앵커의 배치 기능으로, 경사면 전체에 대한 정밀 메시 접촉이나 회전 정렬을 주장하지 않는다. 필요하면 별도로 정착 명령을 적용한다. 명시한 투명/불투명도0 대상도 기하가 있으면 스냅할 수 있으며 숨김/파일 개체 대체 기하는 제외한다.

Array는 X/Y/Z 각1..16개(원본 포함)와 축별 양수/0/음수 월드 간격의 격자를 만든다. 원본은 유지하고 각 새 트리의 부모 링크·루트 행렬·표면/리그·Collider 역할을 독립 ID로 복제한다. 부모/자식 동시 선택은 한 트리로 한 번 처리한다. 전체 모델256개·기하/메모리/기존 인체 수 한도를 넘는 결과는 전체를 거절한다.1×1×1은 이력을 추가하지 않는다.

Collider는 월드 축 기준 바운딩 박스 프록시이다. 선택 트리의 역할을 문서에 저장하며 복제/삭제 시 역할 ID도 재매핑/정리한다. 이 역할 변경은 물체를 움직이지 않는다. 잠긴 Collider는 정적 장애물로 사용할 수 있다. 복잡한 방/오목 모델의 전체 경계 상자는 내부도 막으므로, 필요한 벽·선반을 별도 개체의 Collider로 선택한다. 정밀 메시 충돌·강체 회전/마찰/반발·관절 ragdoll 기능은 제공하지 않는다.

Gravity settle은 선택 트리를 회전 없이 월드 -Y로 정착한다. 선택되지 않은 표시 Collider와 다른 선택 몸체의 프록시, 지정 Y 바닥을 사용한다. 낮은 몸체부터 안정 ID로 처리하고 초기 겹침은 움직이는 몸체만 위로 분리하여 보고한다. 잠금/숨김/위치·픽셀 잠금/파일 개체 대체가 있는 선택 몸체나 하위는 거절한다. 정적 Collider는 이동하지 않는다. 큰 timestep은 최대1/120초로 나누고 최소1/240초, 기간0..10초·중력0..100·요청 timestep1e-6..1e6·움직이는 트리64개와 접촉 계산량3200만 회 예산을 검사한다. 낙하 경로의 바닥/Collider 상단을 검사해 큰 시간 간격의 관통을 방지한다. 같은 입력은 같은 결과를 낸다. 기간이 끝났는데 떨어지는 몸체가 있으면 알리고 그 미리보기 위치만 적용할 수 있다.

준비 사본/결과와 삼각형262144개·가속 구조 예약 예산, 유한 좌표/범위·선택/빈 입력·취소·오래된 결과를 검사한다. 실제 위치/루트 행렬과 Collider 역할만 native111에 저장하고 속도·적분 시간·시뮬레이션 중간 상태는 저장하지 않는다. 이전110으로 위장한 Collider 문서는 거절한다. 219번 UV 채색과 물리 펜 검증은 미완료다.
