# 246 — Content-dependent export loss review

Raster Prepared captures source structure facts and color-conversion outcomes without owning/mutating the source. Layer catalog rows include hidden entries; multiple layers/non-raster objects, masks, nondefault layer properties or placed-raster geometry report flattening. Text entries report lost font/text/ruby editing, a multiframe timeline reports current-frame-only export, and hidden RGB normalized by compositing is explicit. Selected channel depth, actual composite alpha and lossy JPEG determine pixel-loss warnings. RGB conversion, ICC reassignment/omission for non-sRGB and gamut clipping are separate color-space losses.

Information and losses are separate APIs: notices describes format/intent/ICC/metadata rounding; losses contains only content-dependent editing/pixel changes. Encoding8→16 or embedding the same RGB ICC does not produce a loss warning. TIFF/PNG/WebP's default color information is not an automatic warning. A source has no extra loss prompt when its simple raster/alpha/depth/working-space is preserved. DPI rounding/unsupported DPI storage remains ordinary output information.

The still-image UI conditionally shows the loss-confirmation checkbox and only requires it for a nonempty list; core write enforces the same rule. Option edits clear confirmation. Output-batch plans carry both lists for each file; their existing preview/name/geometry confirmation remains necessary to authorize writing. PSD/PSB already reports preserved versus raster-replaced dependency ranges,8bit/color-space changes, omitted native data and optional whole-composite fallback. Native document saving is unaffected.

All export adapters operate on independent prepared composites. Core and app checks compare source path/source_path, dirty, revision, history, snapshot and original file bytes, including saved and dirty source states. Tests cover zero-loss TIFF without confirmation, blocked unreviewed JPEG, source16bit reductions, actual versus absent transparency, hidden/multiple layers, editable text, non-sRGB conversion and cancellation creating no file. Pointer replay checks the conditional prompt, export and cancel; installed hidden app smoke repeats it.
