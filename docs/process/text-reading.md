# 가로·세로쓰기, 자간, 합자와 루비 (177)

text-editor에서 가로/세로, 자간, 표준 합자를 선택한다. 세로쓰기는 위에서 아래로, 열은 오른쪽에서 왼쪽으로 흐른다. 한글/한자/가나/전각 문자/이모지는 세우고 라틴 등의 가로 글리프는90도 회전한다. 기준선 위치는 첫 열 기준이며 Wrap length는 가로에서 줄 폭, 세로에서 열 높이다. 명시적 줄바꿈은 다음 줄/열로 이동한다. 자간은 글자 크기의-0.5~4배, 전진량은 최소0.05em으로 제한해 역주행하지 않는다. 열/줄 간격은 기존 기준선 간격을 사용한다.

표준 합자는 공개 Rustybuzz 라이브러리로 실제 글꼴의 liga/clig를 적용한다. 꺼진 경우 해당 기능을 끈다. 적용할 기능이 없는 실제 글꼴은 이름과 별도 글리프 유지 안내를 표시한다. 이 항목은 수동 커닝·문맥 대체·RTL 문단 조판·세로중가로 도구를 제공한다고 표시하지 않는다. 해당 확장은181의 별도 범위다. 기존 확장 속성이 없는v86/이전 텍스트는 기본 배치를 그대로 유지한다. 글꼴 파일을 변경하거나 원제품 코드를 사용하지 않는다.

루비는 본문 Unicode scalar 범위와 별도 읽기 문자열을 갖는다. 선택 범위 또는 커서의 한 문자에 추가하고 범위를 숫자로 조절할 수 있다. 글꼴·크기비율0.1~2·시작/중앙/끝 정렬·위/아래(세로는 오른쪽/왼쪽)·본문 거리0~4em·독립 자간을 편집한다. 본문/루비 진행 폭 중 큰 쪽을 예약한다. 연결 범위를 하나의 줄바꿈 단위로 유지하며 줄 길이보다 긴 루비는 독립 줄/열에서 넘쳐 표시한다. 본문이나 읽기를 잘라서 숨기지 않는다. 서로 겹친 범위, 범위 밖, 명시적 줄바꿈을 가로지르는 연결은 오류로 안내하고 적용하지 않는다.

본문 앞 삽입은 범위를 이동하고 범위 안 삽입/치환은 범위를 확장한다. 연결 본문 전체를 삭제하면 루비를 제거한다. 여러 범위를 통째로 바꾸어 겹치게 된 경우 앞 범위만 유지한다. 필드 실행 취소를 위한 최근32개/512KiB 연결 스냅샷과 문서 Apply의 전체 상태 실행 취소를 구분한다. 본문 IME의 조합/확정/취소는 연결 범위도 함께 임시 갱신/확정/복원한다. 루비 입력 필드도 같은 조합 처리와 취소/앱 전환 규칙을 따른다. 조합 중 적용과 연결 서식 변경은 끝내거나 취소하도록 안내한다.

루비 최대64개, 읽기당1024문자/4KiB·개체 읽기 합계4096문자, 본문4096문자/64KiB, 장면 문자열16KiB와 윤곽512K/장면1M 점·기존 문서/작업/Undo 예산을 적용한다. 본문과 루비 모두 실제 대체 글꼴/누락 안내 및 원문 보존을 사용한다. 문서v87에 방향·자간·합자·연결 범위·읽기·개별 서식을 저장한다. 확장 속성의 이전 헤더 위장을 거절한다. 미리보기 취소는 원본을 유지하고 Apply는 한 문서 Undo다. 물리 펜 검증은 대기한다.
