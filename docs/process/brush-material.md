# 혼색·번짐·수채의 독립 모델

기능059. 독자 RGBA 안료 모델이며 원본 프로그램의 계산식을 복사하지 않는다. 모드는 Paint/Blend/Smudge/Water. 주색 공급, 현재층 색 픽업, 획 안의 혼합색 유지, 번짐 거리, 수분, 희석, 농도 유지, 원래 알파 잠금, 무색 번짐을 별도로 저장한다. 수치 공급/픽업/유지/수분/희석0~1, 거리0~4096px. 값/시드는 Down에서 고정한다. 현재 래스터 층과 앞선 임시 팁만 읽으며 합성층을 샘플링하지 않는다.

거리 d의 픽업은 mixing×(1−retention^(d/smudge_distance)), 주색 보충은 1−(1−supply)^(d/base_size)다. 첫 팁의 주색 보충은 supply 자체다. 거리가0이면 현재 위치의 색을 사용한다. Premultiplied RGBA 보간으로 투명 RGB의 검은 테두리를 피한다. 유지1은 기존 운반색, 픽업0은 새 층 색을 줍지 않음, 공급1은 선택색 공급 최대다. Smudge/무색 옵션은 주색 공급0을 강제하고 보간으로 기존 안료를 운반한다. 선택색 알파0도 무색 번짐을 중단시키지 않는다.

농도 유지는 픽업 과정에서 이전 안료의 알파 하락을 막으며 빈 색을 샘플링할 때 기존 색상도 유지한다. 이후 주색을 별도로 보충하므로 유지와 공급이 섞이지 않는다. 희석은 출력 안료 알파에 (1−water×dilution)를 곱하며0은 추가 희석 없음이다. 빈 곳에도 운반 안료를 칠할 수 있다. 알파 잠금은 픽셀의 시작 전 알파를 고정하고 시작 전 알파0은 RGB까지 보존한다. 농도 유지보다 잠금이 우선한다. 지우개도 이 제약을 따른다.

Water는 정상 종료 때 한 번의3×3 premultiplied 확산을 수행한다. 원본과 마스크/획 농도 적용 전 임시 결과를 사용해 계산한 뒤 선택 마스크×획 농도로 원본과 한 번 혼합한다. 기존 불투명 픽셀에 둘러싸인 투명 구멍도 획 농도 상한을 넘지 않는다. 확산도64Mi 후보 픽셀 연산/변경 픽셀 메모리·계산 중 취소 한도에 포함하고 반복 확정으로 중복 실행하지 않는다. 취소/실패는 원본에 부분 확정하지 않는다.

기존 마우스의 간단 혼색/번짐/수채 설정은 유지한다. 새 공통 모델은 마우스와 펜 모두 같은 스타일에서 사용하고 실제 압력을 가상 압력으로 바꾸지 않는다. 가상 필압/분사와 공통 안료 모델은 함께 사용할 수 있다. 도구 설정/이전 백업/초기화·재시작·프리셋/가상 입력 JSON에 보존하며 자체 문서v11은 고정 스타일과 결과를 저장한다. 구형1~10과 옛 프리셋의 누락 필드는 기본 Paint로 읽는다. 실제 펜 장치 검증은 대기한다.
