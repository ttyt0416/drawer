# 로컬 입력 기록과 반복 비교 (301)

도움말의 Input replay 창에서 입력 JSON을 저장·불러오고 실행 결과를 `.result.json`으로 저장한다. 버전1 Sequence는 시간(마이크로초), 좌표, 압력, 기울기, 장치/접촉 종류와 브러시 설정·개별 난수 시드를 포함한다. 결과 파일도 같은 입력을 내장하므로 다시 불러올 수 있다. 이전 결과의 measurement 누락은 허용한다.

새 결과는 정규 직렬화 입력 SHA-256, RGBA SHA-256, 앱/파이프라인 버전, 프레임별 CPU 처리 시간과 전체 재생 CPU 시간을 기록한다. 입력 파일과 Cargo.lock/배포 해시를 함께 보관해 비교한다. 표시 지연은 null이고 실물 장치 검증은 false다. 재생은 기록된 시간·순서를 파이프라인에 전달하며 실제 시간만큼 기다리지 않는다. 따라서 CPU 시간과 실제 입력→화면 지연을 혼동하지 않는다. 외부 초기 픽셀을 주입하는 내부 시험은 전체 입력이 공개 형식에 없으므로 이 measurement를 생성하지 않는다.

`scripts/test-checklist.ps1 -Item 301`은 시드301의 펜(압력·기울기)/마우스를 각각 저장/재열기 후3회 재생한다. 동일 픽셀·입력 해시·버전·유한 CPU 측정·한 획 Undo/Redo·접촉 정리와 결과에서 입력 복원을 검사한다. 입력은 최대2MiB/4096이벤트/512프레임/100시작이며 역행 시간과 비유한 값은 거부한다.
