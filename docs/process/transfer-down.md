# 내용 전송 (132)

위층의 안정 ID로 같은 부모의 앞쪽 형제 목록을 역순으로 찾아 래스터 대상(보정층 제외)을 결정한다. 가장 가까운 적격 저장 종류가 잠겨 있으면 전체 거절한다. 두 레이어 자체/이름/안정ID/순서/설정·소스 저장영역은 유지하며 목적 저장영역만 부호 있는 합집합으로 늘린다. 선택 없음은 전체, 명시적 빈 선택은 그림/Undo 불변이다. 선택강도0 밖 픽셀은 그대로 유지한다. 알파0 숨은RGB는 완전 선택 전송에서 소스에서만 정리한다.

부분 전송에서는 새 위 알파=round(Au*(255-c)/255). 아래 premultiplied 결과를 역산해 위/아래 Normal source-over 결과를 유지한다. 원래 combined alpha를 O, 남은 위 alpha를 R라 하면 새 아래alpha=(O-R)/(1-R), 새 아래 RGB는 combined premul에서 남은 위 premul을 빼서 복원한다. 단순히 두 반투명 조각을 겹쳐 경계가 옅어지는 것을 피한다. c>0에서만 계산하며 완전 선택은 보통 source-over 전송이다.

공통 그리기 잠금/숨김 검증과 참조·밑그림 역할 일치를 사용한다. 양쪽 Normal/color/opacity100, 알파 보호/활성 클리핑/자체 효과 없음이 전제다. 파일 캐시는 공통 readonly 검증으로 거절한다. 개체 위치의 분리된 래스터는 일반 스택 이동을 요구한다. 전체 래스터 트리의 전송 전후 RGBA를 캔버스 밖까지 비교하여 중간 형제/부모 배경 의존과 8비트 양자화 오차1 초과를 확정 전에 거절한다. 다른 장면 소스는 수정하지 않는다.

4Mi 처리 픽셀/32768차원·64Mi 비교작업,128Mi 렌더 여유·문서/이력/작업공간 한도. 전후 미리보기는 원본 불변이고 확정은 한 Undo이며 문서ID/리비전/프레임 고정 및 Escape 취소. 결과는 기존 래스터 저장으로 유지한다.
