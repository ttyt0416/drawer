# 로컬 경로·저장 실패 검증 (305)

`scripts/test-checklist.ps1 -Item 305`는 실제 편집기 저장 경로로 한글·이모지·결합 문자를 포함한 파일을 저장/재열기하고 이름과 문서 상태를 비교한다. 5단계 로컬 폴더로260 UTF-16 단위를 넘는 경로를 만들어 저장·재열기를 검사한다. 경로 길이를 증거에 기록한다.

자기 시험 파일에만 읽기 전용 속성을 적용한 경우와 Windows 공유 모드0의 배타적 파일 잠금에서 저장 오류와 안내를 검사한다. 정상본 바이트·미저장 문서·이력·수정 표시·원래 경로가 유지되어야 한다. 속성은 RAII로 복원하고 잠금은 해제한다. 이어서 정상 경로로 재시도한다. 읽기 전용 속성이 디렉터리 ACL과 같다고 간주하지 않는다.

다른 작업의 임시 파일과 충돌하면 해당 파일과 정상본을 유지한다. 예약 장치 이름·위 첨자 장치 번호·끝 공백/마침표·콜론·부모 이동·파일인 부모 경로를 거부한다. 오류 안내는 대상 경로와 읽기 전용/잠금/접근 거부에 맞는 재시도 방법, 원래 OS 오류를 포함한다. 타 사용자 계정·다른 파일 시스템의 권한 정책은 별도 환경 검증이며 이 로컬 Windows 결과로 대체하지 않는다.
