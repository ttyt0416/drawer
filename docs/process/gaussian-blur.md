# 153 — premultiplied 가우시안 블러

Layers의 Gaussian blur는 현재 래스터 저장 픽셀을 문서 픽셀 단위 반경0–64로 흐린다. 반경은 커널의 유한 지원 범위이며 sigma=max(radius/3,0.5), 양의 정규화 가중치를 사용한다.0은 기존 픽셀·정밀도·배치·dirty/Undo/Redo를 그대로 둔다. 실제 저장값이 달라지지 않는 결과도 이력을 만들지 않는다.

원래8/16비트 표본을 unassociated float64 RGB/alpha로 읽고 RGB×alpha와 alpha를 별도로 가로/세로 합성한다. 두 축 뒤 알파로 나누어 RGB를 복원하고 문서 정밀도/디더로 저장한다. 알파0의 숨은 RGB는 커널에 기여하지 않아 검은/색 테두리를 만들지 않는다.8비트 미리보기에서 알파0인16비트 희미한 잉크도 실제 알파를 사용한다. 문서 프로필을 바꾸지 않고 문서 RGB 공간에서 계산한다.

보호되지 않은 레이어는 반경만큼 투명 여백을 포함한 출력 배치를 만든다. 캔버스 밖 결과도 레이어 자료에 보존한다. 레이어 투명도 잠금이 있으면 기존 경계와 알파 표본을 유지하고 기존 불투명 영역의 색만 흐린다. Only within the area selection은 전체 원본층을 참조해 계산한 결과를 선택 강도로 섞으며 선택 밖 원자료/숨은 RGB를 그대로 복사한다. 명시적으로 빈 선택은 무변경이다. 레이어 마스크·질감·역할·선택 기하는 고정한다.

4M 출력 픽셀·32768축 길이·64M 커널 처리량과 원본/수평 버퍼/출력·Undo/작업공간 메모리를 사전 검사한다. 지원 범위를 넘는 반경·과도한 경계/처리량·잠금·숨김/읽기 전용층은 부분 결과 없이 거절한다. 큰 반경과 큰 이미지를 함께 사용할 때는 반경이나 원본 크기를 줄인다.

전후 미리보기는 원본에서 매번 계산하며 문서/파일/기존 이력을 바꾸지 않는다. Apply 한 번에 한 Undo로 픽셀을 확정하고 Escape/닫기는 버린다. 페이지/프레임/수정본/대상이 바뀌면 다시 열고, 실패한 준비 뒤 이전 계획은 적용하지 않는다. 기존v68 자체형식으로 원래 저장 정밀도와 출력 배치를 저장한다. Undo는 원본 픽셀/숨은 RGB·정밀도·배치를 복구한다.
