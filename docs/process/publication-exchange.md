# Local publication and shot exchange contract

EPUB remains the static, fixed-layout image profile from book-io.md. Metadata adds a256-character title/author, a32-byte ASCII language-tag subset, a locally generated SHA256 identifier, optional cover index and left-to-right/right-to-left spine direction. The identifier hashes content and metadata while excluding the previous identifier, so unchanged reimport/export is stable. One optional white blank page is inserted at an explicitly chosen output position; its dimensions/DPI follow the neighbouring page. Cover numbering uses the final output including that blank. Selected-page import remaps the cover, and imported native pages retain title/author/language/direction/page numbering. The source EPUB retains the complete publication metadata. Archive/static-content/memory protections from192 remain. No remote publication or reflowable/DRM/scripted reader is added.

Drawer shots v1 JSON uses .drawer-shots; own CSV uses.csv with an exact17-column header. Both carry canvas width/height/DPI, shot ID/name, zero-based inclusive start and exclusive end, exact rational FPS, dialogue, cell exposure frames, local cell paths, offsets and optional cell names. JSON denies unknown fields. CSV supports escaped quotes, commas, CRLF and embedded dialogue newlines. Identical shot-ID rows describe one CSV shot and must have identical shot metadata; contradictory or repeated exposures are rejected. Distinct shots may share names. All shots in one imported document must use the same exact FPS fraction; mixed fractions require separate documents and are rejected without resampling.

Prepare verifies every source and bounded single-image raster, then builds an independent native timeline. Repeated path/offset/name references in one shot use one cell ID; different cell names or different shots remain independently editable. Native95 stores shot metadata with stable track/cell bindings and normal embedded timeline pixel payloads, so later source-file removal does not prevent native reopen. One drawing Undo/Redo removes/restores the complete imported timeline and metadata. Existing drawings and source files remain. Names/dialogue can be edited as one checked transaction; stale document revisions require reloading. Creating/refreshing metadata from existing animation tracks preserves existing shot IDs and dialogue. Deleted source tracks/cells prune obsolete bindings; explicit full flattening clears shot metadata.

Export writes a new local own-format file with an owned resource folder containing a native backup and one PNG per exposed cell, reused for repeated references. Paths are relative to the output folder; move the resource folder with the JSON/CSV. Current timeline FPS, names, exposure positions, end, offsets and pixels are exported; source provenance paths are not required to exist. Resources are staged under an exclusively created guard and the exchange file is published last without overwriting. Cancellation/failure removes only new owned resources. Preparation hashes the sheet and local cell sources; changes before confirmation reject the whole import. Adapters for unknown external proprietary formats/foreign CSV are unavailable and explicitly rejected.

Limits:32 shots/tracks,10000 total exposure references/cells,10000 frames,4MiB JSON/CSV,64MiB encoded source per image, native scene/Undo/document budgets,256 app views. Frame values are unsigned and ranges must be nonempty with the first exposure at the shot start. Each transfer uses cancellable joined workers. No scanner/pen or external animation application is used for these tests. Verification covers Korean bibliography/cover/direction/blank/identifier stability, rational FPS, empty/quoted dialogue, duplicate IDs, negative/reversed ranges, missing/changed cells, shared/independent names, native95 reopen without source images, native94 rejection, source/history preservation, one Undo/Redo, late publication failure/cancel, and pointer confirmation of EPUB/shot imports.
