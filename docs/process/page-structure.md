# Editable page and frame structure contract

Nativev94 adds page_parts metadata and a final length-prefixed native payload per contained page. SHA256, dimensions, DPI, frame, original page ID, stable outer object ID and depth1..4 are validated during hydration. Payloads are64MiB each, recursively decoded with a thread-local depth guard and document budgets. Metadata stays within the existing scene JSON limit; payload memory is separately deducted from that geometry limit and included in normal document/history accounting. Native saving retains streaming output; source encoding reuses the same validated writer. A new-native-file writer uses create_new and never overwrites an existing path. Old headers with new containers/compound-frame fields are rejected.

Contained sources are immutable scoped native documents, with copy-on-write replacement at the container boundary. Existing material transforms locate them; prepared nested renderers sample typed text/vector/world/raster/timeline content directly at the requested coordinates rather than flattening it. Float renderers convert through floating working spaces. Source cameras, animation FPS/exposures and selected source frame remain independent of the outer page. Export variants respect each source's draft and output-guide policies. Layer duplication remaps container IDs, deletion/raster conversion prunes them, and explicit full flattening clears container data. SVG uses the existing warned raster-substitute policy. Child editing opens an independent document and atomically replaces the expected parent source with one drawing Undo; stale/closed parent checks precede mutation. Child size/DPI changes require a separate project replacement/size operation.

Project replacement assigns a new stable page ID, preserving the old ID and live-document binding for Undo. A batch validates every new canonical path, duplicate/removal/index/count constraint on a copy and records one order operation. Binding/start-side and retained IDs survive. Newly combined and split results follow the project's reading direction; unpaired cover/end pages are identified by existing facing logic. Result page metadata is assigned in the resulting project order. Original files and open drawings remain, including when the explicitly reviewed original memberships are removed. Permanent result resources remain available for Redo and are included by manifest-last project snapshots.

Batch input snapshots cover native pages, supported raster files and the static PDF/image-EPUB profile. Encoded bytes supply both decoded pages and source hashes. Natural numeric filename sort avoids integer overflow and manual order remains available. Broken, duplicate, unsupported or over-budget inputs appear as rejected rows and require explicit exclusion after review. Source changes require preparation again. Native/PNG pHYs/JFIF/EXIF/basic TIFF/BMP physical DPI is retained when supported; missing physical DPI defaults to300 and non-square/invalid values are rejected. Orientation/ICC use the existing image importer. Size-fit resamples editable document states and scales print trim/margins to the new physical page.

Both preparation and resource writing use cancellable joined workers. New resources are written to an exclusively created local directory, synchronized, and handed to the UI as an owning guard. Only after project/source freshness checks and the atomic model edit is ownership retained. Cancellation, closed UI, a changed model/source or file failure drops the guard and removes only owned files; a foreign file inside the directory is preserved. Source input hashes are rechecked. Native path existence races fail create_new. No original file is renamed, removed or overwritten.

Compound frames store original polygons plus per-component clip polygons and derived exterior segments. Coverage is the union of clipped components; edge arrangements split at intersections and retain exterior segments. Equal division adds editable strip clips, preserving concave/disconnected components and source references. Existing frame masks move into component scope during union/division, preventing the surviving frame's old mask from clipping every component. Common-source families retain their union semantics, including a merge of only some sibling frames while the other siblings remain. Coincident-border hiding stores local overlapping collinear segments and changes only border drawing. Bounds include clip intersections. Controls expose extra contour and clip vertices. Frame edits prepare a state and commit with one drawing Undo, including IDs/masks/references. Limits:32 selected frames/components,32 equal strips,2048 input edges and4096 exterior/hidden segments, plus existing scene/memory limits.

Checks cover precise cross-boundary text/vector/world objects, two different FPS timelines with distinct displayed cells, source camera/frame scope, direct and physical-DPI placement, split/duplicate independence, generic layer copy/raster conversion, source draft exclusion, nesting limits, payload corruption/old headers, parent edits/closure, convex/concave/clipped frame union/division/borders, maximum counts, natural/manual ordering, mixed DPI/fit and print-guide fit, rejected inputs/cancellation/freshness, partial file failure/foreign-file preservation, actual pointer confirmation, project/drawing Undo, native and full project snapshot reopen. Physical pen validation remains deferred.
