# 092 — 선택 이동·복사·새 레이어 붙여넣기

Move boundary와 Move selected pixels는 서로 다른 명령이다. Move의 대상 선택과 문서 픽셀 단위 화살표 이동도 같은 정밀 이동 엔진을 사용한다. 마우스/펜 Down에서 문서·리비전·입력원·보기 투영·대상을 고정하고 Move는 원본에서 정수 문서 픽셀 변위를 다시 계산한다. 화면 미리보기만 임시 문서에 그린다. Up에서 원위치 지움과 도착지 합성을 한 명령으로 확정한다. 0변위는 무변경이며 Esc·초점 상실·도구/대상/보기 변경·모달 진입은 초안을 버린다. 다른 문서의 Up이나 입력원은 현재 접점을 확정하지 않는다. 보기 확대/회전과 캔버스 밖 위치에서도 문서 좌표를 사용한다.

경계 이동은 픽셀을 건드리지 않는다. 픽셀 이동은 선택 coverage에 비례하는 알파 성분을 원위치에서 빼고 목적지에 source-over 합성한다. 원위치의 숨은 RGB는 지우기 정책대로 보존한다. 부분 선택을 재표본화하지 않으며 레이어 배치 영역을 필요만큼 확장한다. 한 축 100만 픽셀, 결과 32768변·문서/Undo 용량 상한을 먼저 검사한다. 이동 시작에는 비어 있지 않은 명시적 선택이 필요하고 잠긴 픽셀 대상은 거절한다.

Copy selected pixels는 최상단층 대신 현재 래스터를 읽는다. 선택의 변환/이동된 경계 상자와 레이어 저장 영역의 교집합을 복사하며 캔버스 밖 저장 픽셀도 보존한다. 선택없음은 현재 레이어 전체, 명시적 빈 선택·교집합 없음은 실패이다. coverage 0은 RGBA 0으로 제외하고 나머지는 원본 RGB를 유지하며 알파에 coverage를 한 번 적용한다. 따라서 선택된 완전 투명 픽셀의 숨은 RGB도 보존된다. 복사는 원본·dirty·그림 이력을 바꾸지 않는다. 로컬 이미지 클립보드와 자체 위치 패킷을 함께 쓰고 용량/좌표/차원을 전송 전에 검사한다. 기본 키 설정에는 Ctrl+C/V를 추가했으며 기존 사용자 키 설정은 유지한다.

Paste to new layer는 기존 붙여넣기 미리보기를 사용한다. 기본 중앙 배치, Original position, 좌표 입력/드래그, 취소를 제공하며 확정 시 새 래스터가 활성층이 된다. 알파가 이미 적용된 복사본에 선택을 중복 적용하지 않는다. 원본층·선택·페이지 개체·애니메이션 셀/노출/현재 프레임을 유지한다. 문서 변경으로 미리보기가 낡으면 확정하지 않는다. 새 레이어 삽입 전체를 Undo 한 번으로 복원한다.

123 연계: Move/사각/올가미 도구의 Alt+클릭으로 클릭 지점의 위쪽 보이는 편집층을 고른다. 수정키 Alt/Ctrl/Shift, 잠긴층 포함, 폴더 별도 선택은 로컬 작업공간 설정이다. 레이어 목록과 후보 순환 명령도 제공한다. 현재 래스터·애니메이션 노출 셀·벡터·폴더를 실제 합성 순서로 평가한다. 래스터는 기존 합성 그래프의 숨김/알파 결과, 벡터는 기존 페이지 클립과 선 hit 판정을 사용한다. 투명 구멍·숨김·알파0 후보는 제외한다. 빈 곳은 활성층을 유지한다. 후보 순환은 같은 문서의 마지막 클릭 위치에서 다시 계산하며 문서 변경 후 낡은 후보 배열을 재사용하지 않는다. 선택은 문서별 세션 상태이며 픽셀/그림 Undo를 바꾸지 않는다. Move에서 고른 래스터를 계속 끌면 한 레이어 이동 명령이다. 수정키를 도중에 놓아도 대상을 바꾸지 않으며 잠금은 해제하지 않는다. 폴더/벡터/애니메이션 선택은 래스터 이동/복사에 잘못 대입하지 않는다. 전체 레이어 검색/필터 기능 123 자체는 계속 미완료다. 후속 마스크·클리핑 레이어 기능은 도입 시 해당 합성 그래프와 후보 판정을 함께 확장한다.

검증은 소유 코드의 실제 egui 입력 경로와 숨긴 설치본에서 수행한다. 2종 이동 × 마우스/합성 펜, 확대1.5/90도 회전, 음수 도착지, 원위치 지움/한 Undo/Redo, 미리보기 중 원본/dirty 불변, Esc/초점/보기/도구/모달 취소를 검사한다. 복사 RGBA0/128, coverage0/128/255, 띄엄띄엄 선택·빈 선택·비중첩·회전/이동된 선택·캔버스 밖 레이어·직렬화 용량을 검사한다. 2셀 애니메이션 붙여넣기와 자체 문서 재열기, 3개 겹친 층/투명 구멍/잠금/숨김/폴더/벡터 클립/셀 후보·순환·수정키 해제 후 드래그·설정 재열기를 검사한다. OS 클립보드 테스트는 주입한 패킷으로 수행해 사용자의 클립보드를 바꾸지 않는다. 실제 펜 센서 시험은 별도다.
