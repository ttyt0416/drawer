# 로컬 폴더 소재 라이브러리

명령 asset-library. 외부 프로그램 코드/소재나 클라우드 서비스 없이 자체 색인과 기존 로컬 파일 어댑터를 사용한다.

## 목록과 저장

루트/하위폴더를 취소 가능한 작업자에서 색인한다. 이미지의 첫 페이지/프레임, 자체 브러시JSON/도구폴더 manifest, JSON/GPL/CSV 색상표와 자체 그라데이션JSON을 검증한다. 이미지 썸네일은16×16 RGBA의 제한된 복사본이다. 미지원 JSON/손상/권한 오류/누락은 이유를 표시하고 적용을 차단한다. 파일 이동은 이전 항목을 사용불가로 남기고 새 경로를 색인한다. 파일 내용SHA256을 매번 검사하고 중복도 표시한다. 단순 타임스탬프로 변경을 추정하지 않는다.

이름·태그·논리 폴더·핀·즐겨찾기·사용 횟수를 로컬 asset-index.json에 보존한다. 검색·유형·하위폴더 포함·상세/썸네일·이름/경로/빈도 정렬을 제공한다. 문서 이력과 별도의 라이브러리Undo/Redo를 최대20회/64MiB로 제한한다. 원자적 임시 쓰기와 파일해시로 외부 변경/외부 임시파일을 감지한다. 읽을 수 없는 색인은 명시적 확인 없이 덮어쓰지 않는다.

한계는4096소재/32768방문/깊이32/파일32MiB/회당512MiB/색인 상주16MiB·JSON32MiB다. 심볼릭 링크·재분석 지점·경로탈출·비로컬 루트는 거절한다. 제한 초과/취소는 기존 색인을 유지한다.

## 등록·적용·버전

현재층/선택의 읽기 전용 스냅샷을 Registered에 자체PNG 복사본으로 저장한다. 비래스터는 지원하는 원본 변환 경로의 별도 복사본으로 굽는다. 문서 작업RGB 프로파일을 포함하고 정밀 래스터는16비트PNG로 출력한다. 자체 표준sRGB 프로파일은16비트 재입력 시 동일 공간으로 처리해 불필요한 재변환 오차를 막는다. 같은 콘텐츠/설정은 기존 등록본을 재사용하며 기존 이름을 자동 대체하지 않는다. 등록 파일 쓰기 이후 색인 저장만 실패하면 복사본 경로와 재색인 안내를 남긴다.

소재 삽입/선택 이미지 개체 교체는 비동기 미리보기와 확인 후 한 문서Undo로 적용한다. 이미지 개체는RGBA8 복사본이며16비트 양자화를 안내한다. 정밀 래스터 삽입은236의 이미지 새 레이어 가져오기를 사용한다. 교체는 위치/아핀/반복/워프와 로컬 크롭 원점을 유지하고 원 픽셀 크기 또는 기존 픽셀 크기로 최근접 맞춤을 선택한다. 문서/프레임 개정이 바뀌면 재준비한다. 소스가 미리보기 뒤 없어져도 확인한 포함 버전을 적용한다.

Native122는 이미지의 원본SHA256·적용 스냅샷 해시, 사용 브러시의 팁/질감 정의 해시와 기존 설정 스냅샷, 명시적 벡터 팁 적용의 정의/설정 해시, 혼합글꼴 매핑 값/해시를 보존한다. 재료/프리셋 목록 수정·삭제로 이미 그린 픽셀/기존 벡터/텍스트는 자동 변경하지 않는다. 폰트 파일의 허용된 포함 정책은283에 남으며 로컬 폰트 콘텐츠 식별자와 혼합 매핑은 문서 값이다. 명시적 링크 소스만 기존 별도 재불러오기 정책을 사용한다.

## 삭제·복원

현재 열린 문서의 참조 수와 정확한 소스 경로, 목록만/소스파일 범위를 확인받는다. 기본은 목록만 제외이며 재색인에서도 제외를 유지한다. 소스 포함을 명시하면 해당 파일 하나만 같은 루트의 소유권 표식이 있는 .drawer-trash로 이동한다. 원래 경로/해시/목록 메타데이터를 가진 JSON 복원 기록을 먼저 동기화한다. 폴더/종속파일은 재귀 삭제하지 않는다. 이전 파일/휴지통 파일이 바뀌거나 복원 경로에 파일이 있으면 덮어쓰지 않는다. 색인 저장 실패 시 파일 이동을 되돌리고 실패 시 양쪽 복구 경로를 알린다. 세션Undo/Redo 외에 재시작 뒤 기록 파일을 선택해 명시적으로 복원할 수 있다. 강제 종료/정전의 다중파일 트랜잭션 복구를 주장하지 않는다.

기존 팁/질감 등록 편집기도 삭제 전 현재 열린 문서의 동결된 획 참조 수를 확인하며 자체 정의만 제거한다. 별도 라이브러리Undo/Redo20회·64MiB를 제공하고, 사용자도구 묶음 적용 실패 시 정의와 복원 이력을 함께 되돌린다. 콘텐츠 해시가 남은 과거 획은 새 그리기에 쓸 정의가 없음을 안내하면서 저장된 픽셀과 동결 설정이 보존됨을 구분한다. 구형 해시 없는 기록은 기존 안내를 유지한다.
