# 편집 가능한 텍스트 변형과 자체 레이아웃 전환

텍스트는 기존 변형 도구에서 이동·회전·반전·비균등 확대·기울이기를 적용할 수 있다. 원문/크기/글꼴/범위/루비를 유지하고 별도 아핀 행렬을 저장한다. 연결 변형도 같은 사전 검사와 한 Undo를 사용한다. 윤곽을 변형하며 펜 폭 유지 옵션은 범위 테두리에 적용한다. 변형 후 이동/정렬은 문서 이동량을 한 번만 적용하며 경계에 변형 전 기준점을 섞지 않는다. 잘못된/과도한 행렬·윤곽·문서 예산은 전체 거절한다. 톤/그림자 등 미지원 개체의 기존 명시적 래스터 변환 경로는 유지한다.

Drawer 레이아웃 세대는 원제품 포맷과 독립적이다. 0은 초기 내장 Ubuntu 배치, 1은 기존 편집 가능 속성 배치, 2는 현재 글자군 조형이다. 과거 문서는 열기/저장만으로 세대를 바꾸지 않는다. 초기 배치를 편집기로 열고 변경 없이 적용해도 암묵적 표현을 유지한다. 세대0의 고급 서식은 먼저 명시적으로 변환해야 하며 원문·색·위치·크기 편집은 가능하다.

`text-layout-convert`에서 선택 텍스트 또는 현재 페이지의 전체 텍스트를 고른다. Prepare에서 전후 이미지와 대상별 자체 세대/글꼴 대체·누락 안내를 확인한다. 배치·줄바꿈·대체가 달라질 수 있음을 표시하며 검토 확인 뒤 Apply가 한 Undo로 적용한다. Cancel/닫기/Escape는 원본 불변이다. 원본 문서/수정번호/프레임이 바뀌면 적용을 거절한다. 서로 다른 세대의 혼합 문서에서 지정한 대상만 바꾼다. 변형과 실제 서식값은 복사하고 루비 범위가 글자군 중간이면 조정 안내와 함께 전체 거절한다. 편집기 안의 명시적 현재 배치 전환도 임시 상태이며 Prepare/Apply 전에는 원본을 바꾸지 않는다.

네이티브 v90은 세대와 행렬·원문·서식을 보존한다. v89 이하의 기존 속성은 세대1/단위 행렬로 읽으며 새 기능을 낮은 헤더로 위장한 파일은 거절한다. 없는 로컬 글꼴은 원래 참조와 원문을 유지하고 대체/누락을 안내한다.

PSD 내보내기는 검증된 편집 가능 텍스트 어댑터를 제공하지 않는다. 텍스트 개수와 원문/글꼴/세대/변형의 편집성이 사라짐을 출력 전에 표시한다. 텍스트가 있으면 전체 이미지의 래스터 대체 출력을 선택하며 자체 .drawer 원본을 보존한다. 취소는 출력 파일과 원본/Undo/수정 상태를 바꾸지 않는다. 출력 PSD의 병합 픽셀을 같은 문서의 실제 렌더링과 비교한다. 새 의존성·글꼴·클라우드 경로는 없다. 실물 펜 검증은 대기한다.
