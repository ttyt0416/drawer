# 113 — 획 끝 유지·도형 보정·원래 자유획 복귀

로컬 작업공간의 자동 보정 스위치, 유지0–5000ms(기본600), 실제 화면 이동 허용0–64px(기본3)을 제공한다. 자유획 끝의 이동이 허용 범위를 벗어나면 유지 시간을 다시 센다. 범위 안 흔들림은 시간을 다시 세지 않는다. 한 점은 도형으로 바꾸지 않는다. 시계 역행/비정상 좌표를 거절하고 입력은4096점으로 제한한다. 입력이 없어도16ms 간격의 다음 그리기를 예약하여 유지 검출을 진행한다. 유지 경계의 Up도 보정을 시작한다.

독립 인식은 끝점 거리·선에서의 편차·경계 상자와 제한된 RDP 꼭짓점을 사용한다. 후보는 원/타원/삼각형/사각형/직선/3차 곡선/다각형이다. 인식 결과와 관계없이 후보를 바꾸고 확정 전 제어점·둥근 모서리·선폭/RGBA를 수정할 수 있다. 점128개/생성4096점과 기존 도형 작성 한도를 적용한다. 도형은 기본적으로 균일 선이며 원래 브러시의 기본 문서 선폭/RGBA를 사용한다. 페이지 좌표계의 저장 폭은 최대 배율로 환산한다. 원의 비율은1:1이다.

래스터 입력은 기존 Stroke/재계산 세션을 보유하여 압력·재질·패턴을 포함한 원래 자유획을 따로 유지한다. 벡터 입력은 원래 문서 좌표의 점열과 균일 선폭/RGBA를 보유한다. 보정 초안이 열린 동안 원본 획은 고정하고 문서는 바꾸지 않는다. 후보 미리보기는 별도 문서 상태다. Apply는 원래 자유획 대신 래스터 도형 또는 작성 정의/원래 제어점을 가진 벡터를 한 번에 확정한다. Cancel correction은 놓은 뒤에는 원래 자유획을 한 번 확정하고, 펜을 누른 중에는 원래 세션으로 복귀한다. 움직이기 전 같은 유지 상태에서 보정을 반복하지 않는다. Cancel whole stroke / Escape는 획 전 문서로 돌아간다. 지우기 획은 기존 동작을 유지한다.

초안은 원본 문서ID·수정본·프레임·보기·화면 배율/범위·설정·장치 접촉을 고정한다. 서로 다른 장치의 모달 버튼 입력을 일반 그리기 종료 처리에 넣지 않는다. 펜을 놓은 뒤 장치의 종료/근접 이탈 알림은 보정 초안을 지우지 않는다. 기존 문서 형식의 도형 작성 정의를 사용하므로 이 항목의 추가 문서 버전 변경은 없다.

독립 검증은 유지 직전/일치/직후·한 점·흔들림·소비/이동 후 재개·시계 역행, 직선/곡선/삼각/사각/원/타원 인식, 일곱 후보×래스터/벡터의14조합·제어점/모서리·원본 보존/한 Undo/Redo·문서 재열기, 벡터 원래 획/잠금과 설정 재열기를 포함한다. 생산 검증은 마우스/가상 펜×래스터/벡터×적용/원래 획/전체 취소12조합에서90도·확대2·유지 경계·후보 변경/제어점/모서리·실제 버튼/저장/한 Undo를 확인한다. 추가6조합으로 자동 보정을 켠 점, 유지 경계에 바로 놓기, 펜을 누른 중 보정 취소/재유지 방지/Escape의 무변경을 검사한다. 펜으로 연 초안을 마우스 버튼으로 조작할 때 종료 처리에 의해 지워지던 오류를 실패 재현 후 수정했다. 실제 펜 센서 검증은 별도다.

최종 형상의 픽셀/점·JSON4MiB·원래 획/재계산·작업공간/이력 메모리 예산을 함께 확인한다. 외부 서비스나 다운로드는 사용하지 않는다.
