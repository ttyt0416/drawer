# 레이어 표시 효과와 종류별 기본값

래스터/벡터 원본에 비파괴 표시색, 사각 테두리, 수채 경계 레시피를 저장한다. 폴더 종이질감은060의 별도 합성 후1회 적용 경로를 유지한다. 보정층은122의 매개변수 편집기를 사용한다. 표시색은 원본 알파를 유지하며 RGB를 대체한다. 수채 경계는 상하좌우 최소 알파와 중심 알파의 비율로 경계 강도를 구해 encoded RGB를 어둡게 한다. 강도0은 무변경이다. 테두리0–32문서픽셀은 분리된 두 최대 필터로 원본 알파를 사각 확장하고 원래 알파와의 차이를 지정 색/알파의 배경으로 합성한다. 겹침/부분 알파를 이중으로 진하게 하지 않으며 원본은 보존한다.

선택 제한은 당시 사각/회색조 마스크와 문서좌표 이동을 보존 페이지 좌표에 고정한다. 효과 전후 premultiplied RGBA를 선택 농도로 혼합하므로 선택 밖은 변하지 않는다. 전체층 이동은 고정 영역도 옮긴다. 표현색은 별도 속성이며 회색은(54R+183G+19B+128)/256, 흑백은 그 값128기준으로 표시한다. 원본 RGB와 알파는 유지한다. 표시색 효과는 표현색 변환 뒤 적용한다.

공통 렌더·마우스 획 미리보기·참조 합성·PSD/PNG·직접 선택·썸네일과 병합/종이 베이크가 동일 효과 캐시를 사용한다. 테두리 여백을 포함한 저장 범위를 계산해 음수 좌표에서도 보존한다. 병합/베이크는 효과와 표현색을 픽셀에 굳힌 뒤 레시피/이미 굳힌 마스크를 제거하고 원래 문서는 Undo로 복원한다. 래스터의 파괴적 확정은 전후 미리보기 뒤 별도 Bake 버튼이다. 벡터는 기존 전체 합치기의 손실 확인을 사용한다. 독립 보정층은 배경과 병합하도록 안내한다. 문서v53은 레시피·고정 영역·원본을 보존한다.

설정은 종류와 실제 저장 대상의 분류를 함께 사용한다. 래스터/벡터의 컬러·회색·흑백은 같은 기본값 계열이며 표현색 자체를 선택 속성으로 저장한다. 현재 대상이 지원하는 표시 효과/표현색·불투명도·혼합·식별색만 선택한다. 셀은 트랙 혼합을 따르고 선택 마스크 층은 식별색만 지원한다. 레시피의 선택 제한, 소스 이름/ID/파일/픽셀/마스크/잠금은 복사하지 않는다. 값만 로컬 작업공간 설정에 저장하며 설정 복구/종류별 초기화/재시작을 지원한다.

명시적 새 래스터/벡터, 일반 폴더 작성/감싸기, 새 보정/그라데이션, 이미지·클립보드 새층, 선 편집기의 새 벡터, 타임라인 삽입의 새 트랙/셀 및 새 이름 선택에 공통 생성 기본값을 연결한다. 새 빈 문서에도 적용한다. 기존 문서/이미지/영화를 문서로 열거나 복제·병합·베이크할 때는 새 기본값을 덮어쓰지 않는다. 기존 대상은 그대로이며 실제 층 작성과 기본값 적용은 같은 문서 명령이다. 설정 변경은 그림 이력을 바꾸지 않고 설정 자체 복구 기록을 사용한다. 이후 종류의 작성기는 공통 생성 API로 연결한다.

캐시는 층4Mi픽셀·페이지16Mi픽셀과64Mi계산 작업으로 제한하며 벡터 점 수와 선택 마스크 검색 비용도 센다. 저장 범위32768, 문서/스냅샷/이력/JSON과 작업공간 예산을 함께 검사한다. 범위/복잡도 초과는 적용·구조 편집·열기/저장에서 거절하고 렌더 오류도 표시한다. 효과 없는 문서는 기존 픽셀 경로를 유지한다.

독립 RGBA10/20/30/128·사각 경계 알파128·선택 밖0·강도0/효과 끔·선택 고정 이동·음수 저장 범위 베이크·벡터 원본/후보·혼합 병합 전후와 문서/PNG/PSD를 검사한다. 실제 Preview/Apply/Bake·미리보기 무변경·Undo/Redo·프레임 변경/Escape 및 기본값 Save/New/Reset·종류 차이·불가 속성·새 문서/복제/설정 재열기를 확인한다. 원본/식별자/내용/선택/잠금이 기본값 JSON에 복사되지 않는 것도 검사한다.
