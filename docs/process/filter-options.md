# 필터 세부 매개변수와 경계 처리 (172)

필터 창의 Filter-specific options와 공간 블러의 Direction and boundary에서 해당 계산에 사용하는 옵션만 표시한다. 일반 필터와 일괄 적용은 같은 설정·계산 경로를 쓴다. 미리보기는 불변 원본에서 계산하고 변경한 설정으로 이전 결과를 적용할 수 없다. 취소는 원본/Undo를 바꾸지 않으며 확정은 한 Undo다.

## 문서 경계

Transparent(기본), Repeat edge pixels, Wrap around, Mirror repeat를 제공한다. 정수 좌표를 문서의 0..폭/높이에 매핑한 뒤 해당 층을 읽으며 층의 저장 사각형이나 선택 사각형을 반복 경계로 사용하지 않는다. 거울 반복은 끝 픽셀도 반복한다(ABC → CBA|ABC|CBA). 음수·여러 주기 바깥 좌표에도 같은 규칙을 쓴다. 실수 좌표는 미리 곱한 알파로 보간한다. 보간에 참여하는 각 정수 표본이 경계 정책을 따른다.

선택은 출력 혼합 범위다. 선택 밖은 숨은 RGB와 16비트 정수 값까지 보존한다. 이웃 표본은 선택 밖에서도 읽는다. 색 보정 계열은 원래 정수 알파를 유지하며 공간 변형은 원래 정책에 따라 알파를 이동한다. 알파 잠금은 기존 알파를 보존한다. 모자이크/노이즈/연결 성분 먼지 제거 등 문서 밖 표본을 요구하지 않는 필터에는 경계 옵션을 표시하지 않는다.

## 방향과 커널

모션: Both directions / Forward / Backward. 양방향은 길이의 절반씩, 단방향은 전체 길이를 사용한다. 정방향은 표시 각도의 양의 방향으로 잔상을 만든다.

방사: Both directions / Outward / Inward. 원본 중심점에서 멀어지는 방향/다가오는 방향의 잔상을 구분한다. 회전: Both directions / Rotate right / Rotate left. 양의 회전은 화면의 시계 방향이다. 단방향의 지원 범위도 출력 메모리 사전검사에 포함한다.

Box는 균일 가중 선적분, Smooth는 중앙이 강한 삼각 가중 선적분이다. 끝점의 사다리꼴 가중을 포함해 합을 정규화한다. 길이가 작은 경우에도 최소 두 구간을 사용한다. 렌즈 블러는 기존 다각형/원형 조리개 적분을 사용한다.

## 필터별 옵션

- 언샤프: 반경 0~32, 강도 0~5, 임계 0~1. 반경/강도 0은 픽셀을 바꾸지 않는다. 경계 정책은 가로·세로 가우스 계산에 모두 적용한다.
- 파형: Sine / Triangle / Rectangular. 위상은 주기 단위로 정규화하며 파장은 기존 안전 범위 0.25~32768px, 진폭 0~1024px다. Wrap around / Repeat edge pixels는 공통 경계 정책이다.
- 구/원통 곡면, 렌즈 왜곡, 핀치, 소용돌이, 지그재그, 잔물결: Specify area는 저장한 중심/반경과 Shape(타원 가로/세로 0.1~10)를 사용한다. Entire selection은 실제 선택 마스크/사각형을 문서 좌표로 변환한 경계로 중심·반경·종횡비를 계산한다. 선택이 없으면 문서 전체를 쓴다. 숨긴 Specify 값은 Entire 결과에 영향을 주지 않는다.
- 극좌표: Rectangular to polar / Polar to rectangular에 별도의 Spherize를 제공한다. Spherize는 중심을 고정한 asin 구면 역매핑이며 극좌표 띠 변환과 구분한다.
- 색수차: 기존 X/Y offset, Lateral(use Angle), Radial(use center point). Lateral은 오프셋 크기를 각도로 회전하고 Radial은 문서 반경에 대한 중심 거리 비율로 채널 이동을 계산한다. 중심은 변하지 않는다.
- 노이즈: Color / Gray는 기존 채널별/단일 시드 잡음을 쓴다. 노멀맵: Y up / Y down은 기존 녹색 방향 반전을 쓴다.
- 선·색 추상화: Color and lines / Color only / Lines only. 채널 양자화와 명도 윤곽을 분리한다. Lines only는 흰 바탕의 회색 윤곽이다.
- 선폭: Thicken / Narrow. Narrow의 At least 1 pixel은 Chebyshev 거리 능선으로 한 픽셀 코어를 보존한다. 연속적인 벡터 골격 복원 기능은 아니다. 실행 중 취소와 추가 계산/메모리 예산을 적용한다.
- 필름: None / Sepia / Light leak(slant/all) / Sepia + Light leak(slant/all). None은 추가 색조/빛샘 프리셋을 끄며 기본 대비·페이드·온도·그레인 조절은 유지한다. 기본 조절이 모두 0이어도 선택한 세피아/빛샘은 실행한다. 알파와 투명 색을 보존하며 난수는 저장한 시드를 쓴다.

## 저장과 검증

로컬 사용자 프리셋에 세부 옵션 전체를 보존한다. 공간 블러는 모드별 마지막 확정값을 로컬로 저장한다. 네이티브 v83은 결과 픽셀과 마지막 설정 및 일괄 적용 기록을 저장한다. 오래된 파일에서 옵션 누락은 기본값이며, 새 옵션을 이전 버전 헤더로 위장한 파일은 거절한다. 잘못된 수치/열거형/필드도 거절한다.

독립 색 표본으로 음수·여러 주기 경계 매핑을, 비대칭 점으로 모션/방사/회전 방향을 검사한다. 파형 기울기, Box/Smooth 차이, 색수차 중심/90도, 필름 6종, 추상화 3종, 최소 선폭, 전체 선택 모드의 숨긴 값 독립성, 선택 밖 보존, 결정성, 취소, 네이티브/프리셋 재열기와 한 Undo를 확인한다. 설치본도 같은 검증을 실행한다. 물리 펜 검증은 대기 상태다.
