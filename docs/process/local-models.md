# 로컬 모델 추론 (167)

Layers → Local model inference에서 작업과 입력을 고른 뒤 Freeze and preview input → Run verified local model → Adopt 순서로 사용한다. 몸/손은 새 **2D 벡터 포즈**이며 3D 관절 회전 복원은 아니다. 일반 벡터 노드/선 편집으로 수정한다. 채색·보정은 새 래스터 레이어다. 확대 결과는 실제 확대 픽셀 크기로 좌상단에 놓이고 캔버스 크기를 자동 변경하지 않는다. 캔버스 밖 픽셀도 레이어/네이티브 파일에 보관한다.

## 입력과 채택

로컬 PNG/JPEG/BMP/TIFF의 지정 페이지, 현재 페이지 합성 또는 영역 선택을 사용한다. 파일은 EXIF 방향과 ICC를 처리해 sRGB RGBA8로 읽는다. 문서도 프로필 변환한 합성을 고정한다. 선택은 페이지 크기/좌표를 유지하고 선택 밖을 투명하게 한다. 선택 없음과 명시적 빈 선택을 구별하며 완전 투명 입력은 거부한다. 입력은 최대1,048,576픽셀, 이미지 결과는 최대4,194,304픽셀이다. 모델에 넣는 RGB는 투명도를 흰 바탕에 합성한다. 출력 알파는 원본 알파를 보간하며 숨은 RGB는 입력/출력에서 제외한다. 원본8/16비트와 프로필·레이어 바이트는 그대로 남고 새 sRGB 결과만 대상 프로필/비트 깊이로 변환한다.

힌트 채색은 같은 크기의 로컬 RGBA 힌트 이미지를 받는다. RGB가 원하는 색이고 알파가 힌트 강도다. 배경 알파0, 힌트만 알파>0으로 작성한다. 힌트가 없거나 전부 투명하면 실행하지 않는다. 모델이7채널 입력을 받아 실제로 힌트에 반응해야 한다.

입력 선택/미리보기/실행/취소는 문서 이력에 들어가지 않는다. 확인 후 채택만 한 Undo다. 문서 ID·수정 번호·프레임·작업/입력/모델 설정을 비교해 오래된 결과를 버린다. 원본 편집 중에도 실행 입력은 바뀌지 않는다. 미확정 창이 열린 동안 저장은 채택/취소 안내와 함께 중단한다. 다른 무거운 보정/변형 창과 중복 시작하지 않는다.

몸17관절은 COCO 순서(코, 양 눈/귀, 양 어깨/팔꿈치/손목/엉덩이/무릎/발목), 손21관절은 손목0 다음 엄지부터 각 손가락의4관절이다. 입력 이미지는 한 몸 또는 한 손의 적절한 crop을 사용한다. 여러 사람/손 검출 단계는 이 단일 포즈 어댑터에 포함하지 않는다. 결과는 정규화 x,y,신뢰도이며0~1 밖/NaN/무한대는 거부한다. 미리보기는0.5 미만 관절과 연결된 선을 주황색으로 표시한다. 채택 임계값을 바꾸면 채택 색도 바뀐다. 임계값 미만 관절은 검토 확인을 해야 채택된다. 신뢰도는 모델 출력이며 정확도 보증이 아니다.

## 로컬 모델 번들 계약

자동 설치/다운로드/클라우드/원격 API를 사용하지 않는다. 실제 학습 모델은 동봉하지 않는다. 모델이 없으면 설치 안내만 표시하고 결과를 만들지 않는다. 사용 권한을 확인한 모델 제공자가 아래 계약에 맞춘 독립 ONNX export를 준비해야 한다. 임의 ONNX 모델이나 기존 제품의 모델이 자동 호환되는 것은 아니다.

한 폴더에 manifest.json, weights.onnx, LICENSE.txt를 둔다. weights.onnx와 LICENSE.txt는 번들 폴더 밖 링크를 허용하지 않는다. 외부 데이터 ONNX, 사용자 정의 연산, 함수/학습 그래프/서브그래프/희소 텐서는 실행하지 않는다. 선택된 manifest에 적힌 해시와 **실행에 쓰는 스냅샷 바이트**를 비교한다. LICENSE.txt는 비어 있지 않은 UTF-8 텍스트여야 한다. 해시 일치는 바이트 무결성 검사이며 출처의 진위·라이선스 적합성·재배포 허락·모델 품질을 보증하지 않는다. 모델명/버전/신고 라이선스/출처/실제 일치 해시를 결과 화면에 표시한다.

```json
{
  "format": 1,
  "name": "모델 제공자가 정한 이름",
  "version": "모델 버전",
  "license": "모델 제공자가 신고한 라이선스",
  "source": "출처/내부 모델 식별자 (표시만 하며 접속하지 않음)",
  "weights_sha256": "weights.onnx 바이트의 소문자64자리 SHA-256",
  "license_sha256": "LICENSE.txt 바이트의 소문자64자리 SHA-256",
  "task": "Body",
  "width": 256,
  "height": 256,
  "scale": 1,
  "mean": [0, 0, 0],
  "std": [1, 1, 1]
}
```

format은1, task는 Body/Hand/HintColor/Upscale/Denoise 중 하나다. width/height는1~512 고정 크기이며 흰 바탕 RGB를 알파 보존 보간으로 이 크기에 맞춘다. 입력은 f32 NCHW의 단일 텐서 `[1,C,height,width]`; RGB0~1에 `(값-mean)/std`를 적용한다. mean은 유한 ±10, std는0.0001~10이다. 일반 작업C=3, HintColor C=7(RGB3, 비정규화 힌트RGB3, 힌트알파1)이다. HintColor 모델은 휘도/색 공간 변환을 export 그래프 안에서 처리해야 한다.

Body 출력은 f32 `[1,17,3]`, Hand는 `[1,21,3]`의 x,y,신뢰도. 다른 작업은 f32 `[1,3,height×scale,width×scale]`의 sRGB0~1이다. Upscale만 scale1~4, 다른 작업은1이다. 이미지 모델 출력은 원본 크기×scale로 보간하고 알파를 별도 복원한다. 범위 밖 RGB는 제한하고 개수를 표시한다. 출력의 모든 값은 유한해야 한다. 입력/출력 수는 각각1개다. shape가 어댑터와 다르거나 중간 텐서 크기가 동적으로 남으면 실패하며 원본을 유지한다.

실행기는 tract-onnx0.21.15와 잠금 파일의 tract0.21.19 구성요소를 사용한다. 허용 연산은 lib.rs의 preflight에 명시되어 있으며 Conv/Gemm/MatMul, 일반 활성화·정규화·pool, Resize/DepthToSpace, reshape/transpose/concat 등 표준 ONNX 부분집합이다. 사용 중인 모델 export의 연산/버전이 tract에서 지원되지 않으면 오류를 표시한다. 이 앱은 모델 변환기나 임의 모델 호환성 보증을 제공하지 않는다.

## 취소·메모리·임시 파일

실행은 같은 앱의 숨겨진 별도 CPU 프로세스다. Windows의 전용 Job Object에512MiB 프로세스 메모리 한도/부모 종료 시 종료를 먼저 설정하고 stdin 게이트를 연 뒤 모델을 읽는다. 원본 프로그램/다른 프로세스는 작업에 넣지 않는다.120초 제한, Cancel/Escape/창 닫기/문서 전환 시 취소 플래그를 확인해 자식을 종료·회수한다. 프로세스 중단/메모리 부족은 원본 불변 오류로 표시한다. 입력/결과는 해당 작업이 독점 생성한 임시 하위 폴더에서만 교환하며 성공/실패/시간 초과/취소 모두 자식 종료 후 제거한다.

문서/미리보기/Undo는 기존256MiB 작업 예산도 별도로 적용한다. 모델64MiB, manifest16KiB, 라이선스64KiB, 노드/가중치4096개, 단일 중간 텐서8M원소, 중간 텐서 합계128MiB 추정 한도를 검사한다. 실제 추론기 임시 메모리는 OS 한도가 추가로 제한한다.

## 고정 비교 입력과 검증 경계

crates/drawer-infer/src/fixtures.rs의 독자2×2 RGBA 입력은 빨강/초록/반투명 파랑/숨은 색을 가진 투명 픽셀로 고정한다. 파란 RGBA 힌트, 초록 대체 힌트, 빨강 성분을 바꾼 입력을 사용한다. 실제 ONNX Conv, Resize, Flatten/Gemm/Reshape 그래프로 다섯 어댑터를 실행한다. 이 검사용 가중치는 수식을 검사하기 위한 **비학습 시험 자료**이며 학습 성능이나 예술적 품질로 주장하지 않는다.

화면의 Fixed comparison 입력은 모델 교체 비교용 독자 합성 세트v1을 쓴다. 몸/손은64×64 관절선과 정답 관절, 채색은 두 색 도형의 회색 입력/컬러 힌트/정답, 확대는64픽셀 정답을32픽셀로 평균 축소한 입력, 노이즈는 고정 시드0x167로 정답에±24를 더한 입력이다. 결과 화면에 관절 RMSE(64픽셀 기준) 또는 RGB MAE와 입력/보간 기준값을 보여준다. 서로 다른 출력 크기도64픽셀 정답에 정렬한다. 이 모드는 미리보기·비교만 제공하고 문서 채택을 막는다. 수식/크기/색 반응을 검사할 뿐 실제 인물 사진·일러스트의 일반화 성능을 뜻하지 않는다.

비교는 힌트 변경 시 출력 변화와 독립 RGB 기대값, 입력 빨강 변경 시 추정 x 변화, 관절 수/신뢰도,3×3 평균 필터,2배 출력 크기, 투명 경계/알파를 확인한다. 앱/설치본에서도 같은 고정 입력으로 실제 별도 추론 프로세스·미리보기·한 Undo·네이티브 재열기를 반복한다. 실제 학습 모델을 추가 평가할 때는 모델 버전/해시를 고정하고 동일 입력 파일/전처리/힌트/정답 포즈·화질 기준으로 비교해야 한다. 학습 모델은 아직 동봉하지 않았으므로 그 정확도/채색/복원 품질을 검증 완료라고 기록하지 않는다.
