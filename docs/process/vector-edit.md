# 141 — 벡터 제어점·폭·색·필압 편집

Layers 메뉴의 Edit vector points / Edit vector pressure / Recolor vector strokes와 Vector numeric editor를 제공한다. 현재 벡터층만 편집한다. 숨김·전체/픽셀 잠금·연결 파일 캐시는 편집하지 않으며 위치 잠금은 제어점 이동만 막는다. 래스터 또는 빈 곳을 눌러도 그리기 도구로 넘어가지 않는다.

점을 드래그하면 선택한 점만 문서 좌표로 이동한다. Shift로 점을 추가 선택할 수 있다. 곡선은 원래 정의의 제어점을 수정하고 기하를 다시 계산한다. 제어점 필압은 기본1, 범위0..2, 간격0.01의 배수다. 가로 화면 이동×로컬 감도로 바꾸므로 문서 확대율과 무관하다. 캔버스에 점·대상 후보·변경 수치를 표시한다. 겹친 대상은 Tab으로 순환한다. 색 도구는 점 또는 선 위 클릭으로 현재 RGBA를 선택 획 전체에 적용한다.

Ctrl(기본), Alt, Shift 또는 없음으로 일시 점편집 키를 설정한다. 키를 누르면 현재 벡터 편집 도구가 잠시 점편집이 되고 놓으면 원 도구로 돌아온다. 전환만으로 문서/이력은 바뀌지 않는다. 드래그 중 도구/수정키/문서/수정본/프레임/보기/대상/설정이 바뀌거나 Escape·포커스 상실·입력 취소가 오면 미리보기와 임시 선택을 버린다. 놓기 전 원본은 불변이며 한 드래그 또는 색 적용은 한 Undo다.

숫자 편집기는 현재 선택 불러오기·층 전체 점 선택, 폭0..512, RGBA, 선택 점 필압·기본값 복원, 점 이동량을 제공한다. 서로 다른 속성은 혼합값으로 표시하며 명시적으로 켠 속성만 바꾼다. Prepare의 전후 이미지 뒤 Apply로 확정한다. 문서/프레임 변경 뒤 낡은 미리보기는 확정할 수 없다. 수치 편집도 한 Undo로 전체 원본을 복원한다.

자체 문서v64는 장치 입력압력 샘플(0..1, 없는 샘플은1), 크기 필압 사용 여부, 후편집 배수(0..2)를 별도로 저장한다. 기본 스타일 폭×장치 압력(사용할 때)×편집 배수를 실제 선폭으로 계산한다. 장치 필압 크기 사용을 꺼도 원래 샘플은 보존한다. 자동 도형 보정이 꺼진 벡터 자유선도 장치 샘플을 기록한다. 마우스에는 장치 샘플을 만들지 않는다. 예전 문서는 장치/편집 배수가1이며 새 필드 또는 폭0을 구버전 헤더로 위장한 파일은 거절한다.

압력 샘플과 배수는 각각 경로의 정규화된 매개변수에서 선형 보간한다. 곡선의 기존 기하 표본을 사용하며 가변 폭은 경로당 최소64 구간(더 많은 입력/기하가 있으면 그 수 이상)의 작은 선형 반경 구간으로 계산한다. 이는 독립적으로 정의한 근사이며 원래 장치 샘플은 그대로 보존한다. 닫힌 경로의 마지막 구간은 끝 압력에서 시작 압력으로 잇는다.8bit/16bit 렌더러·알파 판정·선택 경계·참조 영역에 가변 폭을 연결한다. 폭/전체 압력0은 머리카락 선을 남기지 않으며 별도의 채움은 유지한다. 점 선택은 보이지 않는 제어점도 다시 수정할 수 있다.

문서 스냅샷·기하/JSON·Undo 메모리 한도를 적용하며 잘못된 수치나 잠금은 원본을 바꾸지 않는다. 실물 펜 검증은 요청대로 별도 대기한다. 가상 펜과 마우스는 실제 앱 입력 경로로 검증한다.
