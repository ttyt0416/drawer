# 셀 플립·클립 편집·분할 보기 (210)

`timeline-clips`에서 클립 시간 편집과 독립된 두 프레임 보기를 연다. 그림/시간 편집은 고정 사본에서 준비하고 범위·키·라벨·교체 정책을 검토한 뒤 한 Undo로 확정한다. 문서 ID/리비전이 바뀐 준비 결과, 미확정 셀 내용/변형/텍스트, 잠긴 관련 트랙/셀은 거절한다. 창 닫기와 취소는 준비 결과를 버리고 원본을 유지한다.

## 잠시 셀 넘기기와 두 보기

Alt+좌/우를 누르면 선택 트랙의 이전/다음 다른 셀로 이동한다. 유지 노출의 같은 셀은 건너뛴다. 처음 누르기 전 문서·프레임·확대/회전/이동/반전을 기억하며 키를 모두 놓거나 포커스 상실·창 닫기·문서 전환/내용 갱신 때 원래 보기를 복원한다. 글 입력/IME·미확정 내용 편집 중에는 시작하지 않는다. 플립 중 마우스로 그림을 바꾸지 않으며 팬/확대 후에도 원래 보기를 복구한다. 그림 이력/dirty를 바꾸지 않는다.

좌/우 타임라인 보기는 각각의 슬라이더와 그 시간의 클립 목록·프레임 이미지를 가진다. 미리보기는 사본을 사용하여 문서 현재 프레임과 그림 이력을 바꾸지 않는다. 각 미리보기의 문서/리비전/배치/시간/209옵션이 바뀔 때만 다시 렌더링한다.209의 카메라/표시 품질은 미리보기에만 적용한다. 작업 메모리를 먼저 확인하고 창을 닫으면 두 텍스처를 해제한다. 로컬 `settings/timeline-clips.json`은 분할 표시·두 시간 위치와 새 클립의 기본 라벨 연동을 저장한다. 잘못된 파일은 보존하며 오류를 안내한다.

## 클립과 라벨

기존 `timeline_timing`의 안정적인 클립 ID·트랙 ID·반개방 구간을 사용한다. 화면의 첫/마지막 프레임은1부터다. 클립 나누기는 경계 전/후 메타데이터를 만들고 합치기는 같은 트랙의 인접 범위를 묶으며 노출/키 위치와 그림 픽셀을 바꾸지 않는다. 수동 범위 조절은 메타데이터를 조절하며 노출을 자르지 않는다. 이웃 클립을 침범하면 거절한다.

선택 클립/폴더의 이동·복제·삭제는 해당 구간의 노출과 트랙/셀 키를 함께 처리한다. 복제는 새 클립/라벨 ID를 만들고 기존 편집 가능한 셀을 공유한다. 대상 클립/노출/키 충돌은 기본 거절이며 명시적인 교체 옵션을 검토해야 바꾼다. 교체는 경계에서 대상 클립을 나누고 바깥 구간을 유지한다. 이동은 선택 원본을 먼저 비워 자기 구간과 겹치는 이동도 원자적으로 처리한다. 비우기에는 명시적인 투명 노출을 사용하여 앞 셀이 다음 구간까지 유지되는 것을 막는다.

범위 클립보드는 선택 구간 양쪽 경계에서 잘린 클립·노출·키·라벨을 보관한다. 잘라내기 확정과 클립보드 교체를 함께 처리하며 취소는 이전 클립보드를 유지한다. 붙여넣기는 같은 문서/배치의 기존 안정적인 셀 슬롯 ID를 해석한다. 삭제/이동되어 없는 슬롯은 거절하고 다른 문서/배치에는 적용하지 않는다. 원본 정의는 잘라내기/클립 삭제 후에도 남고 이후 원본 수정은 공유 참조에 반영된다. 클립보드는 세션 메모리이며 외부 파일이나 시스템 클립보드에 쓰지 않는다.

범위 라벨에는 안정적인 ID·이름·첫/끝·선택적 클립 관계가 있다. 문서의 라벨 연동이 켜지면 이동/복제/삭제/잘라내기/붙여넣기와 함께 처리하며 경계에 걸치면 교집합 두 조각으로 나눈다. 끄면 원래 이름/시점을 유지하고 삭제된 클립의 관계만 해제한다. 클립 범위를 넓힐 때 라벨 시간을 늘이지 않는다. 축소는 연결 라벨의 교집합을 보존하며 FPS 변환은 비례 시간을 반영한다. 기존 셀의 점 라벨과 별도 범위 라벨이므로 원래 점 라벨 편집도 유지한다.

자동 길이는 클립별로 선택하며 이웃 클립의 범위를 침범하지 않는 첫/마지막 노출 시작점·소유 키에 맞춰 범위를 확장한다. 기존 길이를 자동 축소하지 않는다. 클립 폴더는 클립과 하위 폴더를 묶고 전체 자식의 최소 시작/최대 끝을 범위로 표시한다. 하위 클립 확장/분할/이동을 즉시 반영하며 순환/깊이16 초과를 거절한다. 여러 폴더가 같은 하위 폴더를 공유하면 범위와 높이 계산 결과를 재사용하고 하위 클립 수집도 한 번씩만 수행한다.256폴더/16단계의 공유 그래프를 검사했다. 전역 셀/트랙 삭제는 비활성 배치의 관계도 정리한다.

## 트랙 나누기와 합치기

트랙 나누기는 기존 트랙 복제 경로로 셀 원본을 공유하고 속성/오프셋·키/개체 참조를 보존한다. 왼쪽 노출은 경계 전, 새 트랙은 경계 후에만 보인다. 해당 클립과 연결 라벨을 양쪽 범위에 교차시킨다. 다른 저장된 배치는 기존 트랙의 시간 배치를 유지하고 새 전역 트랙을 비워 둔다.

합치기는 인접한 두 트랙의 가시성/불투명도/혼합과 트랙 키프레임이 일치할 때 제공한다. 트랙 수준 알파 클리핑/파일 개체 또는 변형 차이가 있으면 이유를 표시하며 먼저 해결하도록 한다. 셀 원본·오프셋·속성·키/마스크/파일 개체는 새 목표 슬롯으로 옮기고 원본 트랙을 삭제한다. 겹치는 노출은 기본 거절이며 명시적 원본 프레임 교체를 선택해야 한다. 다른 저장된 배치에도 각각의 독립 시간 배치를 같은 방식으로 합치며 그 배치의 충돌/트랙 키 불일치도 거절한다. 비활성 배치에서 한쪽 트랙에 노출이 없으면 노출이 있는 쪽의 키를 유지하므로 비어 있는 새 트랙이 합치기를 막지 않는다. 합쳐진 클립의 라벨/폴더 관계를 새 범위에 연결한다. Undo는 구조·키·클립·라벨을 동시에 복원한다.

## 저장과 검증

네이티브105는 `timing.edit`에 자동 길이·범위 라벨·클립 폴더 관계를 저장한다.209의 비활성 배치에도 같은 형식을 보존한다. 기본값은 생략하여 기존 문서는 읽을 수 있고, 새 관계가 있는데104 이하로 위장하면 거절한다. 기존2048클립·32트랙·10000프레임/셀 슬롯 및 문서/이력/메타데이터 예산,2048범위 라벨·256폴더·깊이16을 적용한다. 외부 의존성/라이브러리는 추가하지 않는다.

코어 검증은 클립 분할/합치기의 전체 프레임 픽셀 불변, 경계 라벨·중첩 폴더·부분 잘라내기/복원·라벨 연동 해제·교체 충돌·클립 밖에 남은 키의 충돌/명시적 교체·비활성 배치의 빈 트랙·오래된 결과·취소/예산·자동 노출/키 길이·트랙 분할/합치기의 편집 가능한 원본과 픽셀/Undo,105 저장/재열기·구버전 위장을 포함한다. 앱/설치본 검증은 합성 키 누르기/떼기·포커스 상실/창 닫기 복원과 실제 포인터 분할/검토/확정, 취소/계산 중 수정, 두 보기의 독립 시간/이력 불변과 로컬 설정 재시작을 포함한다. 실물 펜 시험은 별도 대기 상태다.
