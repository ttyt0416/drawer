# 계정과 접속 기한 없는 로컬 실행

앱 진입점은 보조 작업/시험 인자를 처리한 뒤 로컬 저장소와 GUI로 진입한다. 앱 계정·로그인·온라인 활성화·체험기한·권한 서버·인증 토큰 저장 경로를 두지 않는다. 보조 추론 프로세스의 stdin gate는 메모리 제한 job을 먼저 배정하는 시작 안전장치다. 모델의 LICENSE.txt/해시/허용 형식 검증은 사용자가 고른 모델의 배포 조건/데이터 검증이며 앱 활성화가 아니다.

시계에 기능 사용권을 결부하지 않는다. 조사에서 임시 이름 생성4곳이1970년 이전 시각을 오류로 처리하는 것을 발견해 수정했다. 이 값은 날짜 표시가 아니라 독점 생성 경로/표식용 숫자이므로 epoch 앞뒤 모두 무부호 시간 크기를 사용한다. 기존 충돌 거절·독점 생성·카운터는 유지한다. 실제 파일 수정 날짜를 절댓값으로 바꾸지 않는다. 보기 세션도 이전 시각에서0으로 고정하지 않고 프로세스 식별자를 함께 사용한다.

검증기는 명시적으로 시작한 자체 Windows 프로세스와 그 자식만 관찰한다. 자체 실행 이미지의 벽시계 API 반환을1960년/2099년으로 움직이며, OS/드라이버의 날짜는 실제 시각을 통과시킨다. 단조 시계는 그대로다. 호스트 시계·다른 앱·대상 파일은 변경하지 않고, 프로세스 메모리의 API 진입점과1바이트 RET 반환 조각만 사용한다. API 인자·그림·사용자 파일 경로는 기록하지 않는다.

각 날짜에서 실제 설치 패키지의 전체 내장 그리기/저장/재열기/추론/취득/자산/저장소 이동 시험을 수행하고 시각 API hit와 정상 종료를 확인한다. 소켓·DNS·HTTP 대조군은 원래 API를 실행하기 전에 관측·중지하여, 실패할 통신 호출도 실패로 판정됨을 확인한다. 관측 범위는 명시한 Windows 사용자 모드 API와 해당 유한 시나리오이며 직접 시스템 호출·별도 OS/벤더 서비스는 포함하지 않는다. 새 PC의 실제 네트워크 차단 검증272와 구분한다.

REA의 현재 Windows 프로세스 캡처는 하위 프로세스 정리 보장 미지원으로 capability_unavailable/unsupported_provider를 반환했다. 네이티브 호출 관찰도 Mach-O용이다. 설치를 반복하지 않았고, 여기의 실행 증거는 별도 Windows API 검사 결과이며 REA Evidence로 표현하지 않는다.

동적1960년 실행에서 moxcms0.8.1의 ColorDateTime::now → Default → now 재귀가 발생했다. 로컬 PDB로 실제 스택의 반복 함수를 확인했고, 캐시의 잠긴 원본에서 해당 오류 분기를 확인했다. vendor/moxcms/src/dat.rs만 수정하여 부호 있는 UTC 초와 음수 날짜의 내림 나눗셈을 사용하고 표현 범위 밖 메타데이터를 제한했다. 원본 BSD-3-Clause/Apache-2.0 고지·배포 아카이브 SHA·정확한 수정 파일 해시는 patched-sources.json과 패키지 고지에 포함한다. 달력5개 사례는 실제 수정 파일을 포함한 독립 Rust 시험으로 검사한다.
