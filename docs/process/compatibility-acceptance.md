# 재시작·형식 호환성과 원본 보존 (304)

`scripts/test-checklist.ps1 -Item 304`는 작업공간·UI 배율·보조선·내비게이터·패널·보간·보조 표시·보기 배치·모니터 색상·캔버스 프리셋·자원·로컬 연산 설정12종을 저장한다. 버전999와 미지원 필드를 각각 넣은 뒤 저장 거부와 원본 바이트 불변을 검사하고, 정상 설정으로 돌아왔을 때 다시 저장·재열기한다.

`settings_compat` 공통 검사는 더 높은 설정 버전과 알 수 없는 필드를 덮어쓰지 않는다. 주요 설정의 백업/복구 처리 이전에 적용하며, 공유 JSON 저장·원자적 JSON 공개에도 적용한다. 기존의 알려진 손상 설정 복구 정책은 유지한다. 오류 안내에 따라 해당 버전 앱이나 별도 로컬 프로필을 사용한다. 미지원 설정을 자동으로 정상 기본값으로 교체하지 않는다.

독자 생성 Native1 파일을 현재 판독기로 열어 픽셀/상태를 확인하고 새로운 경로에 현재 형식 사본을 저장한다. 열기와 사본 저장 모두 이전 원본 바이트를 바꾸지 않아야 한다. 미지원 미래 Native 버전은 거부하고 원본을 보존한다. 기존 전체 시험은 Native1/2/6/7/9/10 등 이전 구조와 기본값 보완도 검사한다. 원본 제품의 문서나 자산은 필요하지 않다.
