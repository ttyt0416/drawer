# 독립 위치 보정과 장치 필압 평활

도구별 position_enabled·pressure_enabled·pressure_strength(유한0~.95)를 저장한다. 기본은 기존 위치 보정 허용/장치 필압 평활 끔/.5강도다. 위치 강도는 기존 smoothing 속성으로 유지해 표시/값 복사와 장치별 안정화 우선순위를 보존한다. 위치 보정 비활성은 그 유효 강도를0으로 만든다. 입력 설정·커서·별도/배치 캔버스·시험 칠하기에 연결했다.

압력 상태는 첫 실입력을 그대로 사용하고 다음 실입력마다 raw+(previous−raw)×strength로 갱신한다. 원시0~1 압력을 먼저 평활한 뒤 기존 Response 곡선·출력 최소값을 적용한다. 위치 보정 강도는 이 계산에 들어가지 않는다. 압력 강도도 Trace 좌표에 들어가지 않는다. 같은 위치에서 압력만 변해도 압력을 한 번 갱신한다. 틀린 입력은 상태를 전진하지 않는다.

직접 Stroke는 실제 sample_pressure에서 한 번 처리한다. 재생은 변경하지 않은 입력 벡터에서 새 임시 평활 벡터를 만든 뒤 그 값을 보간한다. 생성한 도장/곡선 중간점은 sample_processed_pressure로 전달해 재평활하지 않는다. 시간 표본은 직전 필압을 유지하고 상태를 전진하지 않는다. 각 미리보기/최종 재계산은 같은 원시 표본에서 새 상태로 시작한다. 위치 마지막점 따라잡기·예측 표시와 압력 평활은 독립적이다.

이 필터는 장치 압력에 적용한다. 마우스 필압 누락은1이며 거리/시간으로 계산하는 기존 가상 마우스 필압 곡선은 별도 모델로 유지한다. 실제 샘플과 원시 기록/압력 보정 곡선을 덮어쓰지 않는다.

설정은 누르기 때 고정되고 취소/새 획은 상태를 재사용하지 않는다. 픽셀과 고정 스타일은 한 번 실행 취소한다. 입력 임시본/적용/취소/직전 백업/초기화·재시작, 프리셋, 가상 기록, 자체 문서v15에 보존한다. 구형1~14의 누락 필드는 기존 위치 보정 동작·장치 필압 평활 끔이다. 실제 펜 장치 검증은 대기다.

검증은 고정 위치의 압력 진동·고정 압력의 좌표 진동, 수동 계산한 .2→.35→.3125와 재생 픽셀 동일, 시간 표본 추가 불변, 누락 마우스 압력 불변, 설정 고정/취소 후 새 상태, 프리셋/문서의 비기본 보정 곡선 보존을 사용한다.
