Directional·Point·Spot에 모두 적용하며 편집 카메라/장면 카메라 변경에 따라 재평가하고 저장된 로컬 값은 바꾸지 않는다. 빛 색은 기존 선형RGB/광량이다. 환경광의 Current는 기존 내장 환경을 사용하며 Single-color는 환경 이미지 조명을 제외하고 ambient×선형RGB tint를 사용한다. Files/Embedded local material/Panorama는 `scene-environment`에서 먼저 읽어 내장한 로컬2:1 PNG/JPEG/HDR 스냅샷을 사용한다. Material은 내장 스냅샷의 로컬 소재 재사용이고 클라우드/상용 소재 호환을 뜻하지 않는다. 해당 이미지가 없으면 거절한다. 환경의 yaw/강도·배경 노출은 기존 환경 창에서 별도 조절하고 배경과 이미지 조명은 독립이다. 원근/평행 투영은 기존3D 카메라 창에서 선택한다.

물체별 Cast/Receive는 독립이다. 바닥으로 쓸 Plane/Box 모델에 Ground receiver role을 지정한다. 가상 바닥을 자동 생성하지 않는다. Off/Models/Ground/Both는 받는 대상의 역할을 고른다. 불투명/임계 통과 면만 단단한 그림자를 생성하고 반투명 색 그림자/연성 그림자는 제공하지 않는다. High1024/Medium512/Low256은 장면 경계 폭을 기준으로 광원 방향에 수직인1024/512/256 텍셀 격자에 광선 질의 위치를 맞춘다. 결정적 하드 섀도 격자이며 별도 GPU 그림자 맵/메모리 atlas를 만들지 않는다. 낮은 품질은 그림자 경계의 공간 해상도를 줄이고 최종 출력도 선택한 그림자 해상도를 따른다.

Fog는 카메라 방향 깊이, 카메라 원점까지 유클리드 거리, 세계Y 높이 From below/From above를 구분한다. 시작<끝·값 절댓값≤1000000·밀도0..64·RGB색0..1을 저장한다. 보간 범위를0..1로 자른 뒤1-exp(-density×range)로 선형광 색에 혼합한다. 높이 아래 방향은 끝 높이에서0, 시작 높이에서 최대다. 알파는 안개로 바꾸지 않는다. 밀도0은 원형이다. 윤곽선0..4픽셀/색은 별도이며 원근과 법선·가시 경계/깊이 불연속을 화면 이웃 광선으로 검출한다. 선 색은 안개색과 독립이고 각 모델의 레이어 합성을 따른다.

Source material/Opaque/Remove with threshold/Semi-transparent를 구분한다. 임계 이상은 포함하며 임계/반투명에서 alpha multiplier0..1을 제공한다. 반투명은 연속3D 모델 레이어의 모든 교차 면을 뒤→앞 깊이로 합성하며 닫힌 입체의 앞뒤 면을 모두 포함한다. 같은 물체의 같은 깊이 공유 삼각형은 중복 합성하지 않는다. 불투명 뒤의 결과도 전면의 실제 알파/레이어 속성으로 가려지므로 반투명 물체 사이에 있는 바닥/다른 입체를 반영한다.8비트와 부동/작업 프로파일 경로·PNG·다중 보기는 같은 교차 목록을 사용한다.2D 레이어/파일 대체/개별 물체2D 키 변환은 연속 그룹을 나누며 각각의3D 그룹을2D 쌓기 순서로 합성한다. 단일 레이어 원본 샘플은 해당 물체만 따로 합성한다. 레이어 불투명도는 교차 면에 적용하므로 닫힌 반투명 입체의 앞뒤 면을 모두 누적한다.

Billboard Off/All axes/Only horizontal은 표시용 변환이며 저장 메시·수동 물리 배치를 바꾸지 않는다. 모델 원점·축 길이·반사/전단을 유지한 회전으로 전체축은 카메라 평면, 수평축은 세계Y를 세워 카메라의 수평 위치를 향한다. 수직으로 겹친 카메라는 유효 수평 방향으로 대체한다. 모델 복제는 렌더 정책도 독립 복사하고 삭제는 사라진ID를 정리한다.
