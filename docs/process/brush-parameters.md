# 브러시 수치 정책

기능 054. 독자 값: 크기 0.1~4096px, 농도/경도 0~1, 지름 대비 간격 0.01~10. 경도는 타원 반경의 단단한 중심 비율이며 나머지에 선형 감쇠와 픽셀 경계 AA를 곱한다. 간격은 압력 크기를 반영한 지름 배수(연산 하한 1/1024px)다. 너무 긴 경로는 기존 획 자원 한도에서 전체 취소한다. 큰 간격은 의도적으로 점 사이 여백을 만든다.

한 획의 농도는 원본과 임시 결과의 혼합 비율이며 선택 마스크와 함께 한 번 적용한다. 색 알파·필압 농도와 독립적이다. 팁 누적은 임시 결과에서 계산하므로 전체 농도의 상한을 넘지 않는다. Down에서 세 값을 고정하며 미리보기는 문서/이력 밖이고 놓을 때 한 명령이다. 취소/0농도는 이력 0개다.

numeric::Scalar가 유한 값, 범위, 단위, 실제 변경 여부를 관리한다. 범위 변경은 Reject(기존 값·범위 유지)/Clamp(값·범위 동시 갱신)를 명시한다. 물리 단위는 활성 DPI에서 표시만 변환한다. 도구 속성 위젯의 직접 입력/슬라이더/증분은 같은 canonical 값과 범위를 쓴다. 문법·비유한·범위 밖 입력은 거절한다. 위젯 임시본은 마지막 정상값과 별도로 유지하고 창별 검증 상태로 적용·복사·저장·단위 전환을 막는다. Esc/창 Cancel/초기화/프리셋 교체는 해당 입력 임시본을 폐기한다. 값이 동등한 표시 동기화는 명령을 만들지 않는다.

설정 v2는 일곱 속성/크기 단위를 로컬 프리셋/작업공간에 보존한다. v1의 네 기존 값은 유지하고 새 값은 독자 기본값으로 이행한다. 기존 작업공간은 이미 저장한 도구별 농도를 보존한다. 문서 v9의 고정 Style은 새 세 값을 보존하며 1~9를 읽는다. v8 이전 메타데이터에 없는 필드는 농도/경도 1, 간격 .15로 읽는다. 도구 설정은 그림 실행 취소와 분리한다. 실제 펜 검증은 별도 대기한다.
