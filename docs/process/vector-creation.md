# 140 — 편집 가능한 벡터 직선·곡선 작성

Layers… 또는 Shape creation의 Draw vector line / Draw vector curve, 동일 사용자 명령 vector-line-tool / vector-curve-tool로 시작한다. 직선은 Polyline/Straight line, 곡선은 Bezier/Cubic Bezier와 By click/Create line을 선택한다. 현재 주색과 기존 폭을 사용하며 자유 제약·열린 경로·모서리 없음으로 준비한다. 시작만으로 문서나 레이어를 만들지 않는다.

클릭마다 제어점을 더하고 Enter로 확정한다. 두 점이 필요하며 미완성 클릭은 문서를 바꾸지 않는다. Backspace는 마지막 점을 제거하고 Escape/포커스·문서·프레임·보기·대상 변경은 기존 공통 작성 취소 경로를 사용한다. 선택한 벡터층에 경로를 추가하거나 새 벡터층과 경로를 한 Undo로 만든다. 숨김/잠금·부분 래스터 선택은 기존 벡터 작성 규칙에 따라 거절한다.

Shape creation에서 Straight line/Spline/Quadratic Bezier/Cubic Bezier, 클릭/드래그, 닫힌 경로·선/면·스냅·폭·색을 조절할 수 있다. 생성된 경로점과 원래 제어점·설정·생성 좌표계·현재 선/면 스타일을 자체문서에 보존한다. 문서 밖 제어점도 자르지 않고 출력 경계에서만 표시를 제한한다. 매우 짧지만 길이가 있는 경로는 유지하고 동일점만 있는 퇴화 도형은 무변경 거절한다. 자유 그리기 벡터의 한 점은 기존 점 도장 경로로 표현한다. 곡선의 수학적 정의와 샘플 수·기존 한도는 shape-creation.md를 따른다.

검증은 네 곡선×아주 짧은/문서 밖/닫힌 경로, 원래 제어점·스타일 저장 재열기, 기존 벡터층에 두 번째 경로 추가와 원래 경로 보존, 잠금/미완성 거절·자유 그리기 점·한 Undo/Redo를 포함한다. 실제 두 명령에서 마우스로 클릭 점을 쌓고 Enter로 확정하며 원래 제어점·네이티브 저장·한 Undo·Escape 취소를 검사한다. 기존 마우스/가상 펜×클릭/드래그×래스터/벡터 작성 검증도 유지한다.
