# 로컬 템플릿과 자원 묶음

명령 `template-bundle`. 레이어 구성·컷/페이지·애니메이션/타임라인을 서로 의존하는 편집 가능한 전체 페이지 스냅샷으로 저장한다. 기존 문서에 부분 삽입하지 않고 새 미저장 문서로 생성하므로 다른 문서 ID/층/셀과 충돌하지 않는다. 각 종류는 용도 분류이며 전체 편집 구조를 보존한다. 애니메이션 종류는 실제 타임라인이 있어야 출력한다.

새 로컬 폴더에 template.drawer, masks.json, manifest.json을 기록한다. SHA256/길이/자체문서 헤더 버전과 묶음 버전을 명시한다. 기존 네이티브 직렬화의 이미지·정밀 픽셀·셀·PCM·3D·글리프 캐시를 포함한다. 현재 로컬 마스크 정의 목록은 함께 보관하며 사용자가 선택한 경우 새 로컬 ID로 복사한다. 과거 획의 동결된 ID/해시/설정은 바꾸지 않는다. 폰트 파일 포함은283의 사용조건 정책에 남는다. 링크의 마지막 포함본을 유지하며 원본 재읽기는 기존 명시적 갱신만 사용한다.

가져오기는 전체 파일 검증 후 미리보기 상태에 두며 종류/이름/크기/DPI/층/프레임/마스크 수와 적용 범위를 표시한다. 확인하면 독립 문서를 연다. 기존 문서의 픽셀/경로/dirty/이력과 입력 파일은 보존한다. 마스크 복사는 기존 라이브러리 이력에만 기록하며 문서 이력과 분리한다. 미리보기 닫기/취소는 적용하지 않는다.

작업자는 취소 요청을 청크별로 검사한다. 내보내기는 전체 메모리/길이 검증 후 같은 부모의 독점 임시폴더에 파일 동기화→manifest 마지막 쓰기→새 목적지로 게시 순서다. 실패/취소는 자신이 만든 파일과 비어 있는 임시폴더만 정리하며 다른 임시파일은 지우지 않는다. 기존 목적지에는 쓰지 않는다. 가져오기는64MiB 자체문서·8MiB 마스크·64KiB manifest 및 작업공간 메모리 한도를 적용한다. 누락/변조·중복ID·경로탈출/절대경로·예상 외 파일·링크/재분석지점·비로컬 위치·버전 불일치를 거절한다.
