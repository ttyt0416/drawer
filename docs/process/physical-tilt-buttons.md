# 297. 실물 펜 기울기·지우개·버튼

상태: **실물 시험 대기**. 사용자의 펜 실물 검증 보류 지시를 유지한다. 이 문서와 빈 JSON 양식은 실행 결과가 아니며 완료 근거로 사용하지 않는다.

현재 배포 실행 파일의 해시와 Native 형식은 양식의 referenceBuild에 기록했다. 실제 시험 시 사용한 빌드·장치·드라이버·OS·모니터·도구 설정을 다시 확인해 기록한다. 물리 픽셀·논리 좌표·문서 픽셀과 원시 입력·앱 계산·화면 표시의 측정값을 구분한다.

원본을 유지하는 새 로컬 시험 문서와 별도 저장 경로를 사용하고, 데이터 수집 방법과 관측 가능한 항목부터 정한다. 수집하지 못한 값은 미측정으로 남긴다. 단위 시험이나 합성 이벤트의 수치를 실물 값으로 옮겨 적지 않는다.

1. **tilt-axes** — 기울기를 지원하는 장치에서 각 축의 방향과 중간/극단 각도를 기록하고 팁 방향과 비교한다.
2. **unsupported-tilt** — 기울기 미지원 또는 속성 누락 시 기본 기울기 동작과 사용 가능 여부 안내를 확인한다.
3. **inverted-eraser** — 지원 펜을 뒤집어 지우개 전환·들기·다시 누름을 확인하고 현재 획의 도구 고정 규칙과 비교한다.
4. **button-mapping** — 보고된 논리 버튼 번호별로 배정한 동작을 각각 실행하고 Pointer/Wintab의 번호 차이를 기록한다.
5. **held-exit** — 버튼을 누른 채 영역/창을 이탈했다가 해제·재진입하여 눌림 고착과 원치 않는 새 획이 없는지 확인한다.
6. **missing-attributes** — 지원하지 않는 지우개/버튼 속성을 임의 생성하지 않고 기본 동작과 안내가 유지되는지 확인한다.

각 속성의 장치 지원 여부와 보고된 논리 번호를 먼저 기록한다. 지원되지 않는 속성의 시험은 합격으로 채우지 않고 미지원 이유와 사용자 안내를 남긴다. 가상 속성 시험은 실제 드라이버 합격 자료가 아니다.

기록 양식: [physical-297-template.json](physical-297-template.json). 모든 사례는 not_run이고 수치·장치명·시각·결과는 비워 두었다.

완료 판정은 실제 시행 자료를 연결한 뒤 한다. 각 사례의 관측값·기대값·오차/실패와 해당 빌드·환경을 남기고, 미지원 속성은 지원 여부와 안내를 명시한다. 저장 전후 문서와 필요한 영상/이벤트 기록의 로컬 경로·해시를 보존한다. 필수 사례의 실제 결과가 없으면 체크리스트를 체크하지 않는다.
