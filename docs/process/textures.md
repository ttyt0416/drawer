# 브러시·종이 질감과 렌더된 외부 출력

Fine grain/Linen/Flecks는 독립 수식으로 작성한 기본 소재다. 안정된 source1/2/3, seed, 배율.01~1024, 강도0~1, ±360도, ±1e9 문서 좌표 위치를 저장한다. source0은 없음이다. 알 수 없는 source는 참조를 보존하며 무효과로 대체하고 안내한다. 사용자 이미지 등록은070 범위다. 기본 레시피는 실행 파일에 포함되어 파일 이동·오프라인 재열기에 외부 의존이 없다.

브러시 질감은 문서 좌표의 고정 패턴으로 획 농도를 변조한다. 겹친 도장에 반복 곱하지 않고 원본→임시 획 결과 혼합에 선택 마스크·전체 농도와 함께 한 번 적용한다. 확산도 질감 적용 전 후보에서 계산하고 마지막 혼합에 한 번 적용한다. 설정은 도구별 임시본·적용/취소·백업·초기화·작업공간/브러시 프리셋에 저장한다. 획 스타일은 시작 때 복사되어 진행 중 설정 변경과 독립적이다. 문서v12는 고정 스타일과 레시피를 보존한다. 구형1~11의 없는 종이/추가 질감은 무효과다.

종이는 RGB를 조절하고 알파와 원본 픽셀을 보존한다. 레이어별 종이와 폴더 종이를 분리한다. 활성 종이를 가진 폴더는 자식을 합성한 뒤8비트 RGBA에 질감을 한 번 적용하고 부모에 합성한다. 무효과 폴더는 원래 자식 순서대로 합성한다. 중첩은 안쪽부터 각 폴더별 한 번이다. 기본 수식의 밝기 곱셈이며 이후 체크리스트의 다중 질감 합성 모드는 이 범위에 포함하지 않는다.

Graph는256층/256폴더·깊이16, 중복·순환·누락 참조를 거절한다. 현재 최상위 전체 묶기와 중첩 묶기를 편집 임시본으로 제공한다. 문서의 scene 역변환 좌표에서 샘플링하므로 보기 배율/회전과 독립적이며 실제 그림 뒤집기/90도 회전과 정렬된다. 현재 층 전체 이동은 종이 원점도 함께 옮긴다. 선택 픽셀 이동은 층 전체 종이를 옮기지 않는다.

적용은 하나의 문서 명령, 취소/오래된 문서 편집 거절은 무변경이다. 층 베이크/폴더 병합은 현재 합성 결과와 캔버스 밖 전체 범위를 새 래스터에 보존하고 소비한 층·폴더 참조/고정 획 기록을 정리한다. 남은 참조 번호를 갱신한다. 잠금층·차원/메모리 한도는 시작 전에 거절한다. 병합 후 직선 끝점과 선택 층을 초기화한다. 실행 취소는 원본 픽셀·매개변수·참조를 복원한다.

PSD는 [Adobe 공개 형식 명세](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/)로부터 독립 구현했다. 버전1/8비트 RGB/원시 압축0, RGBA 레이어·Unicode 이름·합성 알파를 쓴다. 렌더된 최상위 층/폴더 대체 또는 전체 그림 대체를 명시 선택한다. 질감 레시피·폴더 효과·Drawer 이력이 포함되지 않는다고 안내하고 취소를 제공한다. 개체/애니메이션이 있으면 전체 현재 프레임만 허용한다. 저장 원본·변경 표시·보기·이력은 불변이다. 기존 파일 교체·보호 원본·쓰기 임시 파일 충돌을 검사하고 새 파일은 create-new 임시 파일과 원자적 게시로 쓴다.

PSD 재열기는 이 원시 RGBA8 RGB 하위 집합의 합성 미리보기만 가져오며300DPI를 사용한다. PSD 일반 레이어/압축 호환은 이후 상호운용 기능의 범위다. 큰/손상 헤더·섹션·압축·모드·길이는 명시 거절한다. 자체 문서가 편집 가능 원본이다. PNG는 현재 렌더를 그대로 출력한다.
