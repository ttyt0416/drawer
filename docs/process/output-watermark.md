# 출력 전용 로컬 워터마크

249: 원문서 레이어/픽셀/경로/이력과 분리된 출력 합성이다. PNG 이미지 또는 기존 로컬 텍스트 엔진을 사용하며 일반 레이어 합성28모드, 불투명도, 축별 배율/비율고정, 회전, 출력 픽셀 위치/앵커/여백과 반복 Grid/Staggered·Horizontal/Vertical/Both·간격을 제공한다. 회전한 단위의 로컬 좌표에서 반복하므로 단위와 패턴에 같은 회전이 적용된다. 변형 초기화는 배율1:1·회전0·위치0·기본앵커/여백만 복원한다.

출력 크기 변경 후 합성한다. 첫 출력의 표지 지정과 포함/제외는 명시적이며 본문 설정을 지우지 않는다. 노이즈는 워터마크 알파와 독립된 강도0..0.25·64비트seed를 가지며, 프레임/페이지 번호를 섞지 않는 출력 픽셀 좌표 정책이다. 따라서 같은 해상도/프리셋을 사용한 타임랩스 정지 프레임에도 같은 패턴이 적용된다. 노이즈는 기존 알파를 보존하고 완전 투명 픽셀에 색을 추가하지 않는다. 다른 해상도는 해당 출력 픽셀 좌표에서 다시 계산한다.

여러 문서의 출력 작업은 워터마크 파일/텍스트 렌더를 작업 시작 때 한 번 캡처하여 그 작업의 각 파일에 동일한 소재를 사용한다. Prepare preview가 합성한 실제 출력 바이트를 검토하며 JPEG도 실제 압축 해독을 사용한다. 작업 도중 실패/취소는 준비한 출력 픽셀을 부분 변경하지 않는다. 출판은 기존 출력 계획의 새 파일 전용 쓰기를 사용한다. 단일 출력은 still export의 연결 버튼 또는 같은 창의 현재 문서 모드를 이용한다. 애니메이션/타임랩스 출력 창의 Use saved output watermark preset을 선택하면 이 로컬 프리셋의 이미지 또는 글꼴 렌더를 캡처 시점에 고정한다. 이 배타 방식에서는 기존 간단 PNG/노이즈 입력값을 보존한 채 비활성화하며, 미리보기와 모든 인코더 프레임에 같은 변형·합성·반복·노이즈를 사용한다. 워터마크는 불투명 매트 처리 전에 적용하고 출력 ICC 좌표에 맞춘다. 출판 manifest에 캡처 프리셋의 SHA256을 기록한다.

프리셋은 settings/output-watermark.json(version1,24MiB)에 로컬로 저장한다. 이미지 path 또는 embed 픽셀 선택, 텍스트/글꼴, 모든 활성 상태와 마지막 수동 값을 유지한다. PNG≤8MiB/1M픽셀, 재분석지점·원격 경로 거부, 텍스트≤4096바이트/1M픽셀, 출력≤4M픽셀과 작업 메모리 제한을 적용한다. 경로 모드는 준비할 때 다시 읽고 embed 모드는 저장한 픽셀을 사용한다. Reload는 캡처만 교체한다. Save 명령 전에는 이전 프리셋 파일을 쓰지 않으며 손상 설정은 명시적으로 교체 확인을 요구한다. 독점 임시파일→sync→원자적 이름 변경, 외부 임시파일은 보존한다.

상위 사용/반복/노이즈/표지 스위치를 끄면 종속 입력은 비활성화되고 적용되지 않지만 값은 남는다. 텍스트/이미지는 배타 방식이다. 형식별 alpha/depth/compression 제한은 Options.applied()의 계산값이며 JPEG 전환이 이전 PNG/TIFF의 수동 값을 지우지 않는다. 회색조 채널 선택은251에서 추가한다.

검증:28합성모드·회전0/37/90·반복·비등방배율 결정성, 비활성 경로 누락 무시/활성 누락 거부, 알파0, 표지 제외, 변형 초기화, 노이즈 재시작 결정성/취소 원자성, 텍스트 렌더링, 실제 출력창 포인터 Prepare/Write/Close와 바이트 일치·프리셋 취소·원문서/이력 불변.
