# 로컬 데이터 관리 (254)

명령 local-data. 240의 소재 색인 재구축/논리 폴더/보존 복원과253의 실제 폴더 관리에 사용자 데이터 이동과 팁·질감 라이브러리 백업 복원을 연결했다. 라이브러리 백업은 자체 형식·ID·크기 검증 후 현재 bytes를 library.before-restore.json에 배타적으로 보존하고 원자적 교체한다. 같은 복구 이름이 있으면 덮어쓰지 않는다. 이미 그린 픽셀/포함된 획 정의는 자동 변경하지 않는다.

이동은 기존 저장·색인·파일 작업을 배출하고 타임랩스를 체크포인트/정지하며 작업 시간 저널을 저장하고 잠금을 놓는다. 일반 화면은 대기하고 명령/드롭을 최대128개 보관한다. 새 경로는 기존 부모를 가진 로컬 폴더여야 하며 원본과 동일/상하위 경로·링크/재분석 지점·네트워크 드라이브를 거절한다. 신규 폴더 또는 검증된 이전 위치만 대상으로 삼고 일반 기존 폴더를 덮어쓰지 않는다.

복사 전 원본 목록을 잡고 복사→파일 수/크기/SHA256 대조→관리 소재 경로 재연결/새 색인→원본/결과 재검증→루트 포인터 원자 교체 순서다. 최대32768개 항목/깊이32/16GiB이며64KiB 블록으로 취소를 확인한다. 소재 파일은 옮겨 없애지 않고 복사한다. 손상 색인은 사용자가 재구축을 명시했을 때만 원본 bytes를 남기고 새 색인을 만든다. 외부 소재 라이브러리 루트는 자동 탐색하지 않고 그대로 유지하며 명시적 재색인을 안내한다.

부트스트랩 위치의 부모에 .<이름>.drawer-location.json과 이동 저널을 둔다. 포인터가 검증 완료 커밋 기록이다. 커밋 전 중단은 기존 루트를 선택하고 소유권 표식/상대 목록을 확인한 새 복사만 정리한다. 원래 위치를 대상으로 복귀할 때는 남겨 둔 원래 bytes가 변경되지 않았음을 먼저 확인하고 원래 위치 자체도 별도 retained 폴더에 보존한다. 포인터 전환 뒤의 정상 설정 쓰기는 다음 시작 때 오래된 해시와 비교해 되돌리지 않는다. 전환 전 어느 오류에서도 기존 활성 루트를 유지하고 복구 실패에는 저널과 복사 경로를 남긴다.

열린 문서/원본 경로는 이동하지 않는다. 문서의 연결 파일과 보관 Undo/Redo 및 참고 이미지의 원본 중 이전 materials 안을 가리키는 경로만 바꾼다. 설정 파일의 이전 materials/fonts 안 절대 경로도 실제 원본 존재를 확인해 바꾼다. 연결 누락은 조용히 대체하지 않고 이동을 거절한다. 출력/모니터/액션/탐색기 메모리 설정도 재연결하며 새 작업 시간 저널을 새 루트에서 연다. 새 소재 색인은 다음 열기에 다시 읽는다. 문서 편집 Undo와 별개다.

이전 루트 정리는 선택한 경로/전체 내용을 확인한 별도 OS 휴지통 작업이다. 활성 루트의 조상이나 열린/보호된 문서 원본이 들어 있으면 거절하며 영구 삭제 대체는 없다. 그리기 문서의 저장 경로는 별도로 보호하므로 데이터 이동만으로 문서 원본을 옮기지 않는다.

검증: 원본 겹침·한글 경로·취소/공간 부족 주입·원본 해시 변경·복사 중/포인터 전 설치 중단 저널·커밋 뒤 정상 쓰기와 중단된 정리·손상 색인/명시적 재구축·누락 연결·정상 전환/재시작/역방향·이전 bytes·팁/질감 복원과 원본 보존, 실제 이동 버튼/보관 명령 재실행·열린 문서 경로/픽셀/Undo/소스 파일·연결 경로를 검사한다. 사용자 데이터/OS 휴지통을 자동 검사에서 건드리지 않는다.
\n기본 materials/fonts 이외에도 이전 데이터 안의 실제 소재 색인 루트를 새 데이터 위치로 연결한다. 외부 루트는 자동 접근하지 않는다. 탐색기는 활성 데이터와 시작 위치의 포인터/저널을 보호하며 이전 위치 정리는 열린 연결 파일과 참고 이미지 원본도 검사한다.\n
대기 중에도 키/버튼 놓기와 포커스 상태를 갱신하며 명령 단축키는 대기열로 받아 전환 후 실행한다. 원시 그림 입력은 적용하지 않는다. 이동 버튼 놓기 뒤 유휴 상태와 단축키 지연 실행을 입력 재생으로 검사한다.

사용자 문서가 데이터 안에 저장되어 있어도 열린 문서/원본·최근 문서와 보관된 문서 보기 경로는 옮기지 않는다. document/documents/recent/views 식별자와 최근/보기 설정 파일을 소재 경로 치환에서 제외한다. 데이터 내부 문서와 최근 경로 유지도 검사한다.
