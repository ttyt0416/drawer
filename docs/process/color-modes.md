# 086 — 주색·보조색·투명색과 시험 칠하기 독립 이력

## 색 선택과 명령

Color 패널에서 Primary/Secondary를 선택하고 Swap colors로 두 RGBA를 교환한다. 각 색의 숨은RGB/알파를 그대로 보존한다. 색 선택기로 바꾼 값은 현재 슬롯에 저장한다. Transparent shape eraser는 별도 선택 모드이며 현재 전경 RGBA를 변경하지 않는다. 색 선택/스포이트 확정/Primary/Secondary/Swap은 일반 색 선택으로 돌아온다.

새 기본 단축키는 X=색 교환,C=투명색 토글이다. 기존 사용자 단축키를 덮어쓰지 않으며 명령 목록에서 주색/보조색/교환/투명색을 키·마우스/펜 버튼·빠른 접근에 배정할 수 있다. 누름 반복은 색 교환/투명색을 다시 토글하거나 진행 중 획을 끝내지 않는다. 색 명령은 활성 획이 있을 때만 확정하므로 같은 프레임에서 키와 펜을 누를 때 아직 획으로 승격되지 않은 입력 접점을 초기화하지 않는다. 선택 중 스포이트는 색 명령으로 취소한다.

두 슬롯·활성 슬롯·투명색 선택·도구·시험 칠하기는 로컬 작업공간에 저장한다. 이전 설정의 누락 필드는 독자 기본값이고 현재 전경을 슬롯 전환/화면 표시 때 동기화한다. 선택/교환/토글은 그림 이력이 아니다.

## 원래 팁의 투명색 지우기

선택한 팁 종류/이미지/비트맵/섬유·형태/간격/산포/질감·도장/필압 반응을 유지하면서 지우개와 같은 알파 제거를 적용한다. RGB는 지워진 뒤에도 원래 값을 보존한다. 브러시 농도·선택 마스크·팁 밀도·압력/전체 불투명도는 지우기 강도다. 전경 RGBA의 알파는 강도에 곱하지 않는다. 알파0 전경으로도 C 모드에서는 지운다. 일반 색 선택의 알파0과 투명색 도구 선택은 별도 상태다.

복제 공급색·픽셀 덮어쓰기·특수 합성·닷지/번·안료/수채/확산·브러시 알파 잠금을 투명색 획에 적용하지 않는다. 원래 도구 설정을 덮지 않고 획 스냅샷에서만 지우기에 맞춰 해석한다. 래스터 잠금은 그대로 거부한다. 닫힌 경계 채색 제한은 지우기에 적용하지 않고 선택/레이어 저장 범위는 유지한다. 같은 도구의 팁 모양을 유지하므로 사각형 팁의 모서리도 지운다.

투명색 획의 프로필 플래그·원래 팁·설정과 결과 픽셀을 문서v32에 저장한다. 놓기까지 한 Undo/Redo다. Esc/포커스 상실은 미확정 획을 취소한다. 이전 문서/프리셋의 누락 플래그는 false다. 시험 영역/혼색판도 같은 지우기 플래그를 사용하고 기존 독립 Undo/Redo를 유지한다.

## 검증

7종 팁에 알파0 전경·수채/닷지/특수 합성/알파 잠금을 함께 두고 알파 제거/RGB 보존을 확인한다.5종 팁×Round/Square×기본/자체 비대칭 비트맵20조합에서 그리기 coverage와 지우기 coverage의 역관계를 비교한다(8비트 반올림 오차1 허용). 선택128×농도0.5와128알파의96 기준값·사각형 모서리·채색 경계 제한 제외·문서/메타데이터 왕복·한 Undo/Redo·구형 기본값을 검사한다.

생산 UI 이벤트에서 X 반복 무시·슬롯별 알파 보존·같은 프레임의 C/마우스 누르기와 동시 놓기·진행 중 C 반복의 무동작·합성 펜/C 동시 누르기/놓기와 접점 해제·사각형 팁의 실제 모서리·전경 알파0·복제 원점 미설정 우회·설정/시험 영역/도구 재시작을 검증한다. 기존 시험 영역의 실제 Undo/Redo 버튼도 재검증한다. 설치본도 같은 검증을 실행한다. 실제 펜 센서 검증은 대기다.
