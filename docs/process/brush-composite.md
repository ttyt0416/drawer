# 브러시 합성·필압 혼색과 폴더 통과

기능072. 자체 합성 규칙은 아래와 같다. 원본 프로그램의 수식/상수/코드를 복제한 호환 엔진이라는 주장은 없다. b는 기존 층 알파, s는 잉크 알파×팁 coverage×필압 농도×전체 농도×선택×질감의 최종 밀도다. 각 값은0~1이고 RGB는 비연관 색이다. 기존 Normal과 기존 지우개·번짐의 기본 동작은 유지한다.

|브러시 합성|독립 규칙|
|---|---|
|Normal|기존 source-over|
|Erase|기존 RGB 유지, 새 알파 b×(1−s)|
|Background|기존 픽셀이 위, 잉크가 아래. 새 알파 b+s×(1−b), 비연관 RGB는 이 가중치를 사용|
|Replace alpha|기존 RGB 유지. 기존 알파를 잉크 알파로 최종 coverage만큼 선형 보간. 투명 잉크도 알파를 줄임|
|Compare density|s>b일 때만 잉크 RGB와 알파s로 교체, 같거나 작으면 기존 픽셀 유지|
|Erase (compare)|s≥b이고s>0일 때 알파0, 그 밖에는 유지. RGB는 보존|
|Dissolve|좌표/시드의 고정 해시가s보다 작으면 불투명 잉크, 아니면 원본 유지|
|Black burn|기존 알파가 있으면 각 RGB 채널 max(0,1−(1−B)/S), S=0이면0. 결과 색을 source-over. 투명 바탕은 잉크색|
|White burn|기존 알파가 있으면 각 RGB 채널 min(1,B/(1−S)), S=1이면1. 결과 색을 source-over. 투명 바탕은 잉크색|

새 특수 합성은 한 획의 최대 coverage를 사용해 겹친 샘플에서도 최종 농도/선택/질감을 한 번 적용한다. 농도 비교와 확률 판정도 이 최종 밀도를 사용한다. Dissolve는 투명 바탕에서0/255 알파로 결정되며 시드가 같으면 이벤트 분할·미리보기·확정·다시 실행에 같은 좌표 판정을 사용한다. 알파 잠금은 기존 알파를 유지한다. 특수 합성에서는 기존 수채/시간 효과의 후처리 확산을 적용하지 않는다. 안료 혼색은 먼저 잉크색을 계산하는 데 사용한다. 복제 도장은 원본 RGBA 복사 규칙을 유지하고 기존 지우개는 알파 감소 역할을 유지한다.

Rendering quality는 별도 Normal/High 설정이다. High는 회전된 기하 마스크/경도 경계를 픽셀 안의 네 위치에서 평균하고 작업 예산에 네 계산을 추가한다. Normal은 기존 중심 계산을 유지한다. 픽셀 펜은 두 품질 모두 정수 격자/이진 마스크를 사용한다. 안료 Running color의 샘플 품질과 별도로 저장하고 지우개/복제의 기하 품질에도 적용한다.

도구 입력의 안료 설정에 합성 모드·Dissolve 시드·Pressure controls pigment pickup의5점 곡선을 제공한다. 기존 필압 보정/필터/응답을 거친0~1압력에서 곡선을 평가한 계수를 mixing에 곱하며 끄면1이다. 크기/농도/물 양과 분리한다. 기존 혼색 공간/Running color의 Normal·High 품질, 도구별 선 보정·필압 필터도 각각 저장한다. 색 없는 마우스 입력은 기존 가상 필압/누락 압력 규칙을 사용한다. 일곱 도구의 안료/보정은 각 슬롯으로 보존되고 프리셋/설정 임시본/백업/재시작·시험 영역·생산 입력 경로가 공유한다.

Layer and folder paper는 레이어/격리 폴더의 합성 모드·시드를 제공한다. 새/구형 폴더는 기본 격리이며 자식을 투명 바탕에서 합친 후 폴더 효과를 한 번 적용한다. Through는 자식을 외부 바탕에 직접 합성한다. 예를 들어 지우기 자식은 Through에서 아래층 알파를 줄이고 격리 폴더에서는 외부 아래층을 지우지 않는다. Through 선택은 현재 임시본의 폴더 자체 효과를 초기화하고, 자체 효과 조작을 비활성화한다. Cancel은 이전 문서를 보존하고 Apply는 한 이력으로 저장한다. 중첩 폴더에도 같은 규칙을 적용한다.

외부 바탕에 의존하는 특수 레이어/폴더 합성이 있는 문서는 독립 부분트리 굽기와 PSD Rendered layers를 거절한다. 계산할 수 없는 결과를 평탄화했다고 표시하지 않는다. 자체 문서를 보존하거나 PSD Rendered image를 선택하면 전체 합성 픽셀을 내보낸다. 기존 Normal 종이 효과/폴더 굽기는 유지한다. 문서v23은 픽셀·고정 브러시 설정/시드·폴더 모드/합성을 저장한다. 구형 누락은 Normal/시드0/필압 혼색 끔/격리 폴더다.

시험: 독립 수치/알파 규칙과 경계, 아홉 모드의 실제 래스터·알파0/128/255 조합·농도/선택/질감 한 번·투명 알파 대체·Dissolve 이진 결과/분포/재현/시드·알파 잠금/확산 배제, 필압 혼색 독립 변화/비활성 동일성, 중첩 Through/격리 픽셀과 Undo/Redo, 잘못된 곡선/구형 기본값, 자체 문서 재열기와 바탕 의존 굽기/내보내기 거절. 생산 입력에서도 전 모드 반복·한 이력·취소를 실행하고 프리셋/필압/품질/보정의 다른 도구 비전파와 재시작을 확인한다. 설치본도 같은 검증을 실행한다. 실제 펜 시험은 대기다.
