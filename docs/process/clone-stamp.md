# 로컬 원본 기반 복제 도장

기능069. 독립된 Clone stamp 활성 상태/원점은 input Settings에 저장한다. 기존7개 브러시를 복제 마스크로 사용하며 새 BrushTip 식별자를 만들지 않는다. UI는 Paint 아래 토글/다음 캔버스 누름으로 원점 선택, 입력 설정 임시본의 수치 편집/초기화/삭제를 제공한다. 좌표는 문서px이며 픽셀 선택에 floor를 사용한다. 원점 선택은 문서/이력/변경 표시를 바꾸지 않는다. 원점 없음은 누름 때 명시적으로 거절한다.

누름의 문서 좌표와 원점의 floor 차이를 고정된 정수 offset으로 만든다. 복제 원본과 대상은 누름 때 고른 같은 래스터 층이다. pending Stroke는 확정 전의 원본 레이어를 수정하지 않으며 source sampling은 candidate/미리보기를 읽지 않고 이 원본만 읽는다. 문서 id/revision/층 잠금·형식 검사를 유지하므로 중간 문서 변경은 임시 획을 거절한다. 별도의 전체 층 복사나 원본 파일 의존성을 만들지 않는다. 픽셀 결과와 고정 offset은 한 이력/문서v21에 보존하며 새 획은 저장된 원점을 다시 첫 위치로 사용한다.

원본의 Canvas/placed layer 범위 밖은[0,0,0,0]이다. 범위 안은 비연관 RGBA 원문을 읽어 완전 투명 픽셀의 숨은 RGB도 완전 복제 때 보존한다. 정상 복제는 coverage로 원본 RGBA와 대상 원래 RGBA를 혼합하고 겹친 coverage는 최대값으로 사용한다. 그 뒤 선택/전체 농도/질감을 한 번 적용한다. 대상 알파 잠금은 기존 알파를 유지하며 투명 원본 샘플은 기존 색도 보존한다.

복제는 선택한 마스크의 지우개/번짐 역할 대신 원본 픽셀을 사용한다. 색/안료 공급과 시간 기반 색상 특수 효과는 복제 RGBA를 바꾸지 않도록 정규화한다. 불량 수치 검사를 우회하지 않으며 크기/필압/순서/패턴/두 팁 coverage는 공유한다. 문서 선택은 대상을 제한하고 원본 샘플 영역을 제한하지 않는다. 연결선은 연결 시작점을 오프셋 기준으로 사용한다. Scratchpad도 자체의 불변 시작 픽셀과 같은 오프셋 계산을 사용한다.

입력 설정 적용/취소/백업/기본값/재시작과 가상 기록에 원점을 보존한다. 브러시 프리셋을 바꿔도 독립 복제 도구 상태는 유지한다. 옛 input/Style 누락 필드는 비활성이다. 캔버스와 source offset은 유한 범위를 검증하고 기존 픽셀/경로/메모리 한도와 미리보기 취소를 유지한다. 물리 펜 검증은 대기한다.
