# 애니메이션 타임라인과 편집 가능한 셀

`animation-timeline` 명령에서 현재 문서에 타임라인을 만들고 트랙/셀을 편집한다. 프레임 표시는1부터, 내부 프레임은0부터다. 트랙/셀/라벨 ID는 문서마다 독립적이다. 한 문서의 여러 시간 배치는 `timelines-playback`에서 관리한다. 시간 배치는 독립적으로 전환하며 그림 레이어·트랙 구조와 셀 원본은 문서 공통이다. 상세 계약은 [복수 타임라인과 재생](timelines-playback.md)을 참조한다.

## 셀 정의와 노출

전역 셀 정의와 트랙의 셀 슬롯/노출 시작점을 분리한다. 같은 ID를 두 트랙에서 참조하면 같은 네이티브 원본을 렌더링한다. 공유 복제는 ID를 유지하고 독립 복제는 새 ID와 독립적인 편집 내용을 갖는다. 셀 소스에는 래스터 정밀도/프로파일, 폴더, 마스크, 벡터, 텍스트, 효과 개체를 저장한다. 불변 네이티브 바이트만 공유할 수 있으며 편집은 스냅샷 교체로 처리한다.

빈 트랙/빈 셀, 반복 노출을 허용한다. 새 트랙/새 셀/붙여넣기는 현재 프레임에 자동 할당한다. 노출 시작점은 다음 시작점 또는 트랙 끝까지 유지된다. 노출 제거는 시작점만 지우므로 앞의 셀 노출이 연장될 수 있다. 셀 정의는 마지막 노출을 없애도 남는다. 명시적인 셀 삭제는 모든 트랙의 해당 슬롯/노출을 함께 제거하며 한 Undo로 복구한다. 삭제/이동/교체는 준비 결과와 영향 범위를 검토하고 확정한다.

## 내용 편집과 클립보드

셀의 `Open editable cel content`는 별도 편집 문서를 연다. 유지 노출을 포함한 사용 프레임의 합집합 수·실제 사용 트랙 수와 노출 시작점 수를 구별해 표시한다. 그 문서에서 기존의 그리기/레이어/마스크/벡터/텍스트 도구를 사용한 뒤 `Apply cel content to timeline`을 누른다. 공유 참조 전체가 한 부모 문서 Undo로 갱신된다. 내용 문서 안의 개별 Undo는 확정 전 초안에만 적용된다. `Return without applying`은 부모를 유지하고 독립 편집 문서는 열어 둔다. 부모 내용이 바뀌거나 닫히면 오래된 초안의 적용을 거절한다. 프레임 이동만 한 경우에는 적용할 수 있다.

로컬 편집 가능 클립보드는 정적 그림 전체를 보존한다. 시스템 클립보드는 Drawer의 벡터 패킷 또는 픽셀/정밀도 데이터를 읽어 새 셀이나 선택 셀 정의에 넣고 현재 프레임에 할당한다. 선택 정의를 교체하면 모든 공유 참조가 갱신된다. 직접적인 예전 래스터 버퍼 교체는 편집 가능한 원본을 유실시키므로 거절하며 셀 내용 편집 경로를 안내한다.

## 보기와 재생

처음/끝/이전/다음 프레임, 지정 프레임, 이전/다음 셀·키·라벨로 이동한다. 같은 전역 셀의 연속 시작점은 셀 이동에서 건너뛴다. 숨긴 트랙의 셀 이동과 없는 키/라벨 방향은 오류를 표시한다. 편집 트랙만 보기와 어니언 스킨은 문서 내용/원래 가시성/그림 Undo를 바꾸지 않는다. 현재 부모 캔버스와 별도 표시 창에 가이드 텍스처를 표시하고 내용 편집 보기에는 부모 좌표를 보정한 가이드를 표시한다. 보기 해제/창 닫기/다른 문서 전환에 오버레이를 제거한다.

재생은 경과 시간과 FPS 분자/분모로 위치를 계산한다. 끝에서 정지하거나 전체 범위를 반복한다. 한 프레임도 지원한다. 위치·재생·보기 설정은 세션의 문서별 보기이며 문서 시간 배치나 픽셀 이력에 포함하지 않는다. 라벨 정의는 네이티브 문서에 저장한다.

## 저장과 한도

네이티브96은 셀 정의의 길이 제한 원본 테이블을 기존 페이지 컨테이너 다음에 저장한다. 메타데이터의 크기/프로파일/해시와 슬롯/전역 ID/라벨 범위를 검증한다. 정적 셀 소스 안에 또 다른 타임라인/셀 은행은 넣지 않으며 페이지 원본을 포함한 중첩은4단계로 제한한다. 정의512개·연결10000개·라벨1024개, 기존 트랙32개·프레임10000개와 문서 메모리 한도를 적용한다. 초안 준비는 취소할 수 있고 확정 시 문서 ID/리비전/프레임을 다시 확인한다. 실패/취소는 원본을 바꾸지 않는다.

검증은 코어의 공유2트랙×10프레임, 독립 편집, 폴더/마스크/정밀도/개체 보존, 삭제/이동/붙여넣기와 Undo,96 저장 재열기·구버전 거절, 프레임/셀/키/라벨 이동, 가이드/재생 불변과 앱의 실제 입력 이벤트를 사용하는 확정/내용 편집/취소/오래된 초안 검사로 수행한다. 실물 펜 검증은 이후 단계다.
