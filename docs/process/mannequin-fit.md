# 227 — 자체 인체 외형과 자세 보조

완전 로컬 자체 Body/Head/Hand만 대상으로 한다. `model-controls`의 `Mannequin form / perspective / pose assistance`를 펼친다. 기존 관절 선택이 조정할 부위다. 축별0.5..2 배율은 부위 형상과 직접 자식 관절의 오프셋에 적용하며 자손의 기본 길이를 중복 곱하지 않는다. 얼굴·턱·손바닥·각 손가락 마디도 개별 조정한다. 기본 비율 초기화는 부위 배율·원근만 초기화하고 포즈·기존 체형·표정은 보존한다.

혼합 목표의 키·어깨·골반·부피·머리·얼굴·턱·손·손바닥·손가락을 직접 설정하고0..1로 혼합한다. Body는 전체, Head는 머리/얼굴/턱, Hands는 손/손바닥/손가락만 혼합한다. 단독 Head/Hand에서 존재하지 않는 영역은 거절한다. 목표는 독립 수치이며 다른 원본/상용 모델을 읽거나 다운로드하지 않는다. Apply는 결과 체형을 저장하고 반복 Apply는 현재 체형에서 새로 혼합한다.

만화 원근은 모델 로컬 viewer축±X/Y/Z와 강도0..2의 자체 변형이다. 축 방향 깊이는 보존하고 깊이/키에 따른 지수 배율로 수직면 좌표를 늘이거나 줄인다. 배율은1/4..4로 제한한다.0은 정확히 원형이다. 카메라를 움직여도 확정 형상은 변하지 않는다. 생성 메시를 직접 변형하고 본 부착에는 동일 변형의 위치/미분 행렬을 사용한다. 좌우 복사·포즈 열 골격 매핑은 유지된다. 사진/상용 프로그램의 결과 일치를 주장하지 않는다.

포즈 보조는 명시적 실행이다. 팔다리 충돌은 상완/하완·허벅지/종아리와 몸통의 축소 캡슐 근사로 검사하며 같은 사슬/인접 접합은 제외한다. 손가락·옷·소품·일반 가져온 메시의 충돌은 포함하지 않는다. 관절 잠금·한도 내에서 결정적인 좌표 탐색을 유한 횟수 수행하고 잔여 교차가 있으면 부분 적용 없이 거절한다. 충돌 해결이 불가능한 포즈는 잠금/체형을 직접 바꾸고 다시 실행한다. 직립화는 몸통/하체의 잠기지 않은 관절을 허용 범위의0도에 가깝게 펴고 모델의+Y축을 세계+Y로 정렬한다. 잠긴 관절은 보존하고 모델 축은 최소 회전으로 정렬하며 보행/균형/양발IK 시뮬레이션은 하지 않는다. 접지는 실제 발/발가락 꼭짓점 중 최저 세계Y를 입력 바닥 높이로 이동한다. 높이가 다른 양발을 동시에 바닥에 강제로 붙이지 않는다. 직립+접지는 한 준비/Apply/Undo이며 소품/자식도 함께 이동한다.

native118은 결과 체형·각 부위 배율·원근 방향/강도·관절 포즈/제약·본 부착을 내장한다.117 위장은 거절하고 기존117 문서의 기본값을 보존한다. 기존3D 예산·장면4MiB·숨김/잠금·파일 개체 제한과 포즈 열의 명시적 기본 장면 범위를 따른다. 미리보기는 취소 가능한 작업자에서 준비하고128픽셀로 렌더한다. 설정/문서/리비전/프레임 변경·Esc·포커스/창/문서 닫기는 작업자를 합류하고 결과를 버린다. Apply마다 한 Undo로 모든 형상·포즈·좌표·소품을 복원한다.
