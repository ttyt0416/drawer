# 같은 그림의 여러 보기와 별도 화면

기능 015는 문서 ID·픽셀·편집 이력을 공유하는 기존 문서 탭에 더해 하나의 별도 캔버스 창을 제공한다. 창은 현재 선택한 문서를 따라가며 도구·내비게이터 패널을 표시하지 않는다. 화면 렌더러는 같은 문서의 수정 번호로 캐시를 갱신하므로 픽셀 편집과 Undo가 두 보기에 반영된다. 다른 보기/별도 창을 닫아도 편집기의 마지막 문서와 이력을 유지한다. 열린 문서가 없으면 별도 창에 안내를 표시한다.

Windows 모니터 목록·물리 위치·해상도·화면 배율은 winit의 로컬 OS API로 읽는다. 1초마다 목록 변화를 확인한다. 선호 이름이 없거나 분리되면 기본 화면 또는 첫 유효 화면을 선택한다. 선호 이름은 보존하며 재연결 시 다시 선택한다. 전체화면 대상은 모니터 인덱스로 지정한다. 창 모드에서는 화면 경계 안의 물리 픽셀 위치/크기를 계산하고 해당 보기의 실제 UI 배율로 변환한다. 음수 화면 좌표를 허용한다. 독립 창을 닫으면 편집기를 표시하고 최소화를 해제한다. 모니터 정보가 전혀 없으면 별도 창 생성을 보류하며 편집기는 유지한다.

동기화 보기는 편집기의 기기 픽셀 배율·문서 중심·회전·반전을 전달한다. 논리 화면 이동 값을 그대로 복사하지 않고 문서 중심을 구해 수신 화면의 배율로 다시 계산한다. DPI와 화면 크기가 달라도 같은 문서 중심과 기기 픽셀 배율을 유지한다. 독립 보기는 문서별 중심/배율/각도를 메모리에 보존하고 별도 창의 마우스 보기 조작이 편집기 보기를 바꾸지 않는다. 문서 전환 뒤 돌아와도 각 보기 상태를 유지한다. 이 조작은 그림 변경 표시·문서 실행 취소·파일 내용을 바꾸지 않는다.

선호 모니터·동기화·전체화면·창 표시와 마지막 독립 보기 기본값은 버전 1의 로컬 `settings/display.json`에 원자적으로 보존한다. 직전본/손상본 보존, 설정 Undo/Redo·초기화·복원을 제공한다. 설정 기록이 실패해도 창 닫기는 즉시 반영하고 오류를 안내하며 이전 정상 설정 파일을 유지한다. 문서별 세션 보기 캐시는 문서 파일에 넣지 않는다. 다음 실행의 독립 보기에는 마지막 저장 기본값을 적용한다.

가상 구성 시험은 1920×1080/100%와 (-3840,-200)의 3840×2160/200% 화면, 100/150/200% 배율 조합, 분리/재연결, 전체화면 해제/전환, 최소 한 화면, 문서 전환과 닫기를 다룬다. 픽셀 편집/Undo 뒤 두 렌더러의 문서 수정 번호 갱신과 독립 보기 유지, 마우스 휠·설정 Undo/Redo·재시작·기록 실패 때 닫기를 확인한다. 설치 실행 시험은 실제 OS 모니터 목록과 숨긴 native 별도 창의 생성·렌더링·창 모드 해제를 확인한다. 실제 케이블 분리/재연결 조작은 하지 않았으며 이 경로는 가상 모니터 목록으로 검증했다.
