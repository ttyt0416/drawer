# 항목별 구현 기록

## 001 — 조사 자료와 구현 환경 분리

상태: 검증 완료.

- 구현 소스 저장소와 조사 보관 디렉터리를 분리했다.
- Rust 전달 도구가 명시된 파일 목록만 복사하며 경로 이탈·바이너리·추가 파일·변조를 검사한다.
- 전달 목록과 분리 정책을 Git으로 보존한다.
- 단위 시험 4개, 경고 없는 정적 검사, 실제 전달 생성·재검사가 통과했다.
- 묶음에는 새 Rust 소스와 구현 명세만 있다. 원본 바이너리·추출 리소스·디컴파일 산출물은 0개다.

빌드 캐시는 `target/latest` 하나를 갱신해 사용한다. 검증 뒤 `scripts/cleanup.ps1`으로 다른 캐시를 삭제한다. 임시 시험 파일은 시험 종료 때 제거한다.

## 002 — 구현 명세의 원본 내부 자료 제외

상태: 검증 완료.

명세 내용 검사와 검토 기록을 추가했다. 원본 식별자·주소·자료구조·경로를 포함한 입력을 거절하고 이전 정상 묶음을 보존하는 시험을 통과했다. 전체 시험 6개, 경고 없는 정적 검사, 실제 명세 검사가 통과했다.

## 003 — 독자 화면·아이콘·기본 팁

상태: 검증 완료.

Drawer 화면과 절차적으로 생성하는 아이콘·4개 기본 팁을 구현했다. 전체 시험 8개·정적 검사·Windows 앱 빌드 통과. 빈 작업 디렉터리에서 앱을 실행해 도구 목록과 내장 미리보기를 5프레임 그린 뒤 정상 종료했다. 원본 소재와 외부 이미지 파일을 사용하지 않는다.

## 004 — 구성요소 출처·라이선스·배포 고지

상태: 검증 완료.

Windows 의존성 라이브러리 114개와 내장 글꼴 4개를 잠금 파일/정확한 소스 리비전으로 기록했다. 고지문 누락 0개와 목록 재계산 일치를 확인했다. 전체 Rust 시험 8개와 정적 검사 통과. 릴리스 배포 및 소스 전달 묶음에 구성요소 목록·고지문·Cargo.lock을 함께 보존한다.

## 005 — Windows x64 실행·사용자 설치·제거

상태: 검증 완료.

사용자 설정/소재 폴더와 원자적 설정 저장을 구현했다. 전체 Rust 시험 9개·정적 검사·릴리스 빌드 통과. 표준 사용자와 제한된 네트워크의 실행 도구 환경에서 설치한 앱을 소스 없는 폴더/개발도구 없는 PATH로 시작했다. 설치·재설치·제거 통합 시험은 사용자 문서·소재·설정·추가 파일 네 개를 보존했다. PE x64 및 VC 런타임 DLL 의존성 0개를 확인했다. 실행에는 Windows의 그래픽 드라이버를 사용한다.

## 006 — 새 그림의 크기·DPI·배경·투명도

상태: 검증 완료.

새 그림 대화상자와 하나의 래스터층 문서 모델을 구현했다. 1×1/색 배경/투명 배경, 잘못된 숫자·비유한 DPI·범위·메모리 예산 초과 거절 시험 통과. 마우스 이벤트로 생성→다시 열기→잘못된 크기→취소를 실행했고 기존 그림을 보존했다. 전체 Rust 시험 14개·정적 검사·릴리스 빌드·설치 앱의 새 그림 렌더링 시험 통과. 생성은 미저장 그림으로 추가하며 기존 문서 데이터를 변경하지 않는다.

## 007 — 캔버스 보기 이동·배율·회전·좌우 반전

상태: 검증 완료.

휠 확대/축소, 가운데 버튼 또는 Space+드래그 이동, 회전 각도, 보기 반전과 초기화를 구현했다. 픽셀/장치 좌표 변환과 역변환을 공통으로 사용하며 포인터 위치를 고정해 확대한다. 문서별 보기와 로컬 보기 설정을 보존한다. 전체 시험 17개·정적 검사·릴리스/설치 시험 통과. 마우스 입력 후 비대칭 픽셀 데이터의 해시와 문서 변경 상태가 같았다. 배율은 1~6400%, 이동 안전 한도는 논리 좌표 ±10억이다.

## 008 — 여러 문서와 독립 편집 상태

상태: 검증 완료.

로컬 Drawer/PNG 열기, 탭 전환·닫기, 저장·실행 취소·다시 실행과 여러 보기를 구현했다. 문서별 도구와 이력을 유지하고 보기별 이동·배율·회전을 유지한다. 같은 이름의 서로 다른 경로, 중복 열기, 미저장 그림 여러 개, 마지막 보기 확인과 마우스 닫기 취소 시험 통과. 저장 실패 시 기존 파일과 열린 그림을 보존하며 여러 문서 종료 중 취소해도 앞서 버리기로 승인한 그림을 메모리에 유지한다.

전체 Rust 시험 26개·경고 없는 정적 검사·릴리스 빌드·설치/재설치/제거 시험 통과. 설치 앱은 문서 2개·보기 2개·닫기 취소를 확인하고 정상 종료했다. 추가한 파일 선택기의 고지문을 포함해 라이브러리 115개·내장 글꼴 4개의 라이선스 누락 0개를 확인했다. 저장 형식의 현재 보존 범위는 `native-format.md`에 기록한다.

## 009 — 재샘플링·DPI·캔버스 크기·잘라내기

상태: 검증 완료.

네 명령과 최근접/양선형 보간, 9개 앵커, 제거 영역 안내·확인, 배경 계산 취소와 명령별 Undo를 구현했다. 공통 문서 변환과 비래스터 crop 마스크를 보존하고 기본 페이지 객체/직교 카메라/세계 메시를 렌더링한다. 상세 보존 규칙과 현재 메모리 한도는 `image-sizing.md`에 있다. 저장 형식 2로 객체와 선택·가이드·카메라를 보존하며 형식 1도 읽는다.

10pt 텍스트·10px 선·60lpi 톤·10px 그림자·선택·가이드·카메라·3D 혼합 문서의 2배/비균등 배율, DPI만 변경, 축소/잘라내기, 물리 크기가 같은 300/600 DPI 출력 주기, 파일 재열기와 단일 Undo 시험 통과. 마우스 Apply/Cancel·미리보기 취소·계산 취소 후 새 명령의 독립성을 확인했다. 전체 Rust 시험 34개·정적 검사·릴리스/설치 시험 통과. 설치 앱에서 DPI 변경과 Undo를 확인했다. 라이브러리 121개·내장 글꼴 4개의 고지문 누락 0개를 확인했다. 후속 텍스트/벡터/톤/3D 편집 도구 항목은 완료로 표시하지 않는다.

## 010 — 보기 반전과 실제 그림 변환

상태: 검증 완료.

실제 그림의 좌우/상하 반전과 두 방향 90도 회전을 배경 계산·단일 Undo로 구현했다. 모든 래스터층과 페이지 객체를 함께 변환하고 보기 상태와 세계 기하를 유지한다. PNG 내보내기는 RGBA8 합성 픽셀을 원자적으로 저장하며 편집 문서의 연관 경로·변경 상태·이력·보기를 바꾸지 않는다. 현재 색상 프로필·DPI 메타데이터 출력은 후속 형식 항목에 남아 있다.

비대칭 4모서리를 실제 PNG로 출력해 보기 반전의 불변과 실제 변환 결과를 대조했다. 혼합 객체 외관·4회 회전 원본 복원·마우스 명령·내보내기 실패와 원본 파일 보존 시험 통과. 전체 Rust 시험 38개·정적 검사·릴리스/설치 시험 통과.

## 011 — 전체 그림 내비게이터

상태: 검증 완료.

전체 그림 미리보기와 현재 표시 영역, 클릭·드래그로 보기 이동을 구현했다. 화면 사각형을 문서 좌표로 역변환하고 그림 경계와 다각형 교차를 계산해 회전 시에도 실제 표시 영역을 그린다. 전체 그림이 보일 때는 그림 경계 전체를 표시하고 보기 밖이면 안내한다. 같은 프레임에 내비게이터 이동을 주 캔버스에 적용하고 기존 로컬 보기 설정에 보존한다.

1%·100%·6400%, 0°·37°·90°, Mirror와 1/1.5/2배 화면 배율에서 실제 화면 모서리와 좌표를 대조했다. 8각형 교차/교차 없음/전체 보기와 회전·반전 상태의 마우스 클릭·드래그 시험 통과. 문서 픽셀·객체·변경 표시·실행 취소 이력은 바뀌지 않았다. 전체 Rust 시험 41개·정적 검사·릴리스/설치 시험 통과.

## 012 — 로컬 참고 이미지 창과 색 추출

상태: 검증 완료.

PNG·이미지 클립보드 추가, 목록/이전/다음, 참고별 이동·배율·회전, 자동/클릭 스포이트, 투명도를 포함한 색 링, 연결 제거와 독립 새 문서를 구현했다. 목록·색·창 배치와 보기 설정을 원자적으로 저장하며 설정 Undo/Redo·직전본 복원·초기화와 복사본을 포함한 로컬 묶음 이동을 제공한다. 원본을 삭제/덮어쓰지 않는다. 상세 정책은 `references.md`에 있다.

재실행·누락/손상·원본이 없는 오프라인 복사본·휴대용 묶음·제거 복원·저장/가져오기 실패 시험 통과. 알파 0/128의 원본 RGB 보존, 회전 상태의 마우스/가상 접촉 링, 주 문서 불변과 독립 새 문서를 확인했다. 전체 Rust 시험 46개·정적 검사·릴리스/설치 실행 통과. 재설치·제거 뒤 참고 설정과 복사본을 포함한 사용자 파일 6개를 보존했다. 실제 사용자 클립보드는 건드리지 않고 공급자 시험과 OS API 빌드로 입력 경로를 검증했다. 실제 펜 하드웨어 시험은 후속 장치 항목에 남긴다.

## 013 — 눈금·격자·가이드·인쇄 크기 보기

상태: 검증 완료.

px/mm/inch 눈금, 격자 간격/원점과 가이드 추가/제거, 화면 표시 토글과 실측 보정에 따른 인쇄 크기 보기를 구현했다. 격자/가이드 기하를 자체 문서 형식 3에 저장하며 메타데이터만 따로 실행 취소해 래스터 버퍼를 복사하지 않는다. 형식 1/2도 읽는다. 화면 설정은 직전본 복원·기본값 초기화를 제공하며 문서 내용과 분리한다. 상세 규칙은 `canvas-aids.md`에 있다.

150/300/600 DPI와 100/150/200% 화면 배율에서 같은 물리 길이 계산, 회전·반전 눈금의 실제 문서 좌표, 조밀한 격자 표시의 계산 한도, 마우스 기하 편집/Undo, 저장·재열기와 픽셀 불변 시험 통과. 전체 Rust 시험 52개·정적 검사·릴리스/설치 실행 통과. 설치 앱의 격자/가이드 Undo와 인쇄 크기 보기를 확인했고 사용자 파일 8개를 재설치·제거 후 보존했다. 실제 화면 길이 정확도는 UI에 알린 대로 사용자의 실물 측정에 의존한다.

## 014 — 이미지 새 문서·최근 파일·다른 이름 저장

상태: 검증 완료.

클립보드 독립 새 그림, PNG/JPEG/TIFF의 읽기 전용 스냅샷·페이지/방향 선택·색상 프로필 변환·배경 디코딩 미리보기와 취소를 구현했다. 최근 파일 20개를 로컬에 원자적으로 저장하고 목록 Undo/Redo·초기화·직전본 복원을 제공한다. Save as는 성공한 경우에만 경로를 바꾸고 Export PNG는 경로·변경 표시·이력·선택·보기를 유지한다. 검증된 입력 변형·RGBA8/sRGB 정규화·지원하지 않는 변형과 예산은 `image-import.md`에 기록했다. 후속 입출력·색 관리 항목은 완료로 표시하지 않는다.

PNG 투명/숨겨진 RGB·Display P3 ICC 실제 변환·회색조 ICC, JPEG EXIF 적용/해제, TIFF 두 페이지/8·16비트 Gray/RGB/RGBA/Gray+alpha/연관 알파, 큰 치수와 예산·손상·누락·취소·원본 바이트 불변·자체 문서 재열기 시험 통과. 마우스 미리보기 취소/확정/방향 변경, 기존 문서 이력 불변, 반복 가져오기의 독립성, 최근 목록 재시작/손상본 보존, 파일 선택/덮어쓰기 취소와 저장 실패 시험을 통과했다. 전체 Rust 시험 64개·경고 없는 정적 검사·릴리스/설치 실행 통과. 설치 앱의 클립보드 공급자·다른 이름 저장/내보내기·최근 목록 재시작·실제 PNG 디코딩을 확인했고 사용자 파일 9개를 재설치·제거 후 보존했다. 실제 사용자 클립보드와 펜 하드웨어는 변경하지 않았다.

## 015 — 문서 공유 보기와 모니터 전용 창

상태: 검증 완료.

기존 독립 문서 보기 탭에 도구 패널 없는 native 캔버스 창을 추가했다. ## 021 — 파일 연결 안내·저장본 되돌리기·영상 셀 가져오기

## 023 — 모니터 DPI와 인터페이스 배율

외곽/십자/아이콘/시스템 커서와 작은 외곽의 최소 실제 화면 픽셀을 도구별로 저장한다. 아이콘 두 축에도 팁/보기 회전과 반전의 행렬을 적용한다. 원시 흰색·보정 청록색·주황색 열린 예측을 구분하며 두 표시에서는 원시 십자와 보정 외곽을 함께 표시한다. 시스템 커서는 원시 위치를 쓴다. 도구별 안정화 강도는 입력 설정으로 분리하고 실제 입력 필터는 표시 옵션을 받지 않는다. 예측은 표시만 하고 확정에 넣지 않는다.

캔버스 입력 추적과 독립 시험 칠하기가 같은 필터를 사용한다. 시험 칠하기는 실제 이동 이벤트 전체와 마지막 창밖 해제를 순서대로 처리하며 시작 때 도구/색/크기/강도를 고정한다. 표시 모드는 계산을 바꾸지 않고 입력 이탈/포커스/문서 변경에서 오래된 추적을 종료한다. 커서 끄기는 추적 계산을 끄지 않는다. 실제 문서 획 생성 전체는 038 이후에 남긴다.

일반 시험 124개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 세 모드의 같은 가상/실제 UI 입력에서 고속 꺾임과 창밖 해제 후 시험 영역 픽셀이 정확히 같음을 확인했다. 1px·팁29°/보기37°/반전·1/1.5/2배 DPI·최소4px의 중심/방향과 반전 행렬, 보정/예측 분리·표시 끔의 필터 불변·입력 종료·스타일/재시작·문서/이력 불변을 검증했다. 설치 앱의 모드/좌표 처리와 설정 재열기, 사용자 파일 18개 재설치/제거 보존을 확인했다. 실제 펜/기울기 장치 시험은 사용자 요청대로 대기한다.

## 031 — 좌표·길이·색 정보와 표시 설정

상태: 검증 완료.

정보 창에서 문서/px/mm/cm/in/pt 단위, RGB·HSV·HSL과 로컬 출력 ICC 기반 CMYK를 표시한다. 두 점의 좌표·차이·길이와 문서 좌표의 측정선을 제공하며 측정은 세션에만 유지한다. 프로파일은 4MiB 이내 CMYK 출력 변환표를 검증하고 원본을 수정하지 않는다. 선택하지 않거나 변환할 수 없으면 이유를 표시한다. 색 정보는 현재 합성 화면의 8비트 sRGB 값에서 계산한다. 테마와 좌우 도크 배치는 로컬 설정으로 저장하고 잘못된 설정은 기본값으로 복구한다.

일반 시험 128개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 회전/반전/배율/DPI별 3-4-5 선분·단위 환산·픽셀 경계·투명색, 서로 다른 ICC 출력표의 CMYK 값과 프로파일 없음/손상을 검증했다. 테마 변경 후 입력 포커스·선택·도구·문서/이력 불변과 재시작을 확인했다. 설치 앱의 정보 창·밝은 테마·로컬 설정 저장, 사용자 파일 18개 재설치/제거 보존을 확인했다. 실제 펜 하드웨어 검증은 대기한다.

## 032 — 수정키 임시 도구와 단축키 우선순위

상태: 검증 완료.

Ctrl/Shift/Alt별 임시 도구를 로컬 입력 설정에서 선택한다. 수정키는 짧게 눌러도 해제 시 원래 도구로 복귀하며 문자 키의 유지 시간 규칙과 분리한다. 겹쳐 누른 수정키는 press 순서로 복원한다. 공유 단축키를 설정 창에서 표시하고 키 조합·입력란·메뉴·대화상자·문서 전환·포커스 상실이 우선한다. 중단된 수정키는 해제 전 다시 활성화하지 않아 팝업 종료 뒤 고착을 방지한다. 기존 임시본 확정/취소·기본값·적용 전 백업을 공유한다.

일반 시험 130개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 10ms/300ms/10초 해제·겹침·기존 설정 호환/누락 도구 거부, 실제 UI 이벤트의 세 수정키·pointer 누름 중 해제·Ctrl+Z 우선·팝업 종료·앱 전환·재시작과 문서/이력 불변을 확인했다. 설치 앱의 수정키 배정 저장/재열기와 빠른 해제를 확인하고 사용자 파일 18개를 보존했다. 전체 검사에서 발견한 기존 탐색기 손상 설정의 시간표시 경합도 수정하여 작업공간의 오래된 값이 기본값 복구를 덮지 않게 했고, 파일 시간을 강제로 과거로 설정해 검증했다. 실제 문서 획 엔진은 038 이후, 실제 펜 장치 검증은 대기한다.

## 033 — 간단 화면과 전체 도구 화면

상태: 검증 완료.

상단 버튼과 배정 가능한 화면 전환 명령(새 설정 기본 F12)으로 간단/전체 화면을 바꾼다. 간단 화면은 네 도구 패널·탐색기를 숨기고 탭/도구/캔버스를 표시하며 All tools and commands 메뉴에서 기존 명령 전체를 제공한다. 전체 화면으로 돌아오면 기존 패널 표시/위치/도킹을 다시 사용한다. 화면 모드는 세션 상태로 문서·작업공간 설정을 다시 쓰지 않는다. 크기·이미지·붙여넣기·영상 미리보기의 모달 내부에도 같은 전환 버튼을 제공한다.

일반 시험 131개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 실제 UI 이벤트로 세 탭/두 문서의 픽셀·선택·이력·변경 표시·도구·보기와 패널 설정 보존, 캔버스 확장/탐색기 숨김, 숨긴 명령 메뉴·문자 도구 키 접근, F12 반복 방지, 진행 중 DPI 미리보기의 값 보존과 양방향 전환을 검증했다. 설치 앱의 미리보기 중 간단/전체 화면 및 분리 패널 복귀, 사용자 파일 18개 재설치/제거 보존을 확인했다.

## 034 — 상황 도움말과 입력란 독립 편집

상태: 검증 완료.

도움말 키를 입력란 포커스와 무관하게 받아 포커스 제어기→포인터 아래 제어기/캔버스→시작 안내 순서로 로컬 주제를 연다. 이름/숫자 입력란과 숫자 버튼·슬라이더의 값 편집기를 공통 제어기로 연결하고 일반 버튼/선택/체크 제어기에도 주제를 연결했다. 우클릭 메뉴와 키보드로 실행취소/재실행·잘라내기/복사/붙여넣기·선택 삭제·전체선택을 제공한다. 잘라내기 시 클립보드 쓰기를 먼저 확인하고 실패하면 선택과 문자를 보존한다.

입력 임시문자/이력은 그림과 분리하고 숫자는 Enter/포커스 이동에서 유한성·범위·정수 여부를 검사한다. Esc는 입력 시작값으로 복원하고 상위 대화상자의 Esc 처리를 소비한다. 숫자 버튼의 마우스 끌기와 키보드/클릭 문자 편집, 한글 조합 중 확정 억제도 연결했다. 최종 문서 속성 적용은 기존 미리보기 확정의 실행 취소 1개를 유지하며 도구/보기 값은 로컬 설정만 사용한다.

일반 시험 136개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 한국어 선택 잘라내기의 성공/쓰기 실패·복사/붙여넣기·선택 없음/삭제/전체선택·입력란 undo/redo, 문장/NaN/무한대/음수/범위 밖/소수 정수 입력 거부·포커스 확정·Esc·한글 Preedit/Commit을 검증했다. 실제 그림의 마지막 픽셀 변경 이력을 만든 뒤 입력 Ctrl+Z와 취소가 그림을 되돌리지 않는지 확인했다. 포커스가 호버보다 우선하는 도움말/누락 주제/포인터 없음과 설치 앱의 제어기 주제 등록, 사용자 파일 18개 재설치/제거 보존을 확인했다. 네트워크 호출이나 실제 사용자 클립보드 변경 없이 가상 공급자로 실패 경로를 시험했다.

## 035 — 도크 잠금·패널 표시와 캔버스 창 정렬

상태: 검증 완료.

좌우 도크의 실제 화면 픽셀 너비·높이와 크기/도킹 잠금, 분리 패널의 각 축 크기·위치 잠금, 쌓기/탭/팝업 표시를 로컬 작업공간에 저장한다. 도크 옆 경계와 아래 모서리로 조절하며 잠긴 축은 조절을 막는다. 분리 OS 창은 받는 DPI로 최소/최대 크기와 위치를 적용하며 화면 회수는 기존 모니터 복구 규칙을 사용한다. 제목줄/명령 메뉴줄을 숨겨도 Layout/화면 전환 버튼과 전체 명령 메뉴는 유지한다.

탭/계단/바둑판 정렬은 탭마다 독립된 캔버스 보기창을 만들고 원본 문서를 공유한다. 보기창의 이동/확대는 보기 상태만 바꾸며 닫기는 마지막 문서 저장 확인 규칙을 공유한다. 정렬 설정은 재시작에 보존하고 화면/배율이 달라지면 새 영역에 맞춰 다시 계산한다. 그림의 실행 취소와 배치는 분리한다. 도킹 영역에서 탐색기 공간을 확보하고 좁은 목록은 스크롤로 접근한다.

일반 시험 139개·정적 검사·라이선스 목록·릴리스/설치 실행 통과. 잠긴 도크 너비 드래그 차단·잠금 해제 높이 드래그/재잠금, 탭/팝업/제목줄/메뉴줄·문서 2개/보기 3개 정렬/닫기·최소80/최대4096 설정·취소/백업/재시작·문서/이력 불변을 검증했다. 0/1/2/3/7/256 보기와 작은 화면·0.5/1/1.5/2/4배 배율의 정렬 경계를 확인하고 기존 가상 모니터 제거/DPI·회수 검사를 통과했다. 설치 앱의 분리 창 잠금 명령·제목줄 전환·바둑판 보기 생성과 사용자 파일 18개 보존을 확인했다. 실제 모니터 케이블 제거·펜 하드웨어 시험은 수행하지 않았다.
