# 항목별 구현 기록

## 001 — 조사 자료와 구현 환경 분리

상태: 검증 완료.

- 구현 소스 저장소와 조사 보관 디렉터리를 분리했다.
- Rust 전달 도구가 명시된 파일 목록만 복사하며 경로 이탈·바이너리·추가 파일·변조를 검사한다.
- 전달 목록과 분리 정책을 Git으로 보존한다.
- 단위 시험 4개, 경고 없는 정적 검사, 실제 전달 생성·재검사가 통과했다.
- 묶음에는 새 Rust 소스와 구현 명세만 있다. 원본 바이너리·추출 리소스·디컴파일 산출물은 0개다.

빌드 캐시는 `target/latest` 하나를 갱신해 사용한다. 검증 뒤 `scripts/cleanup.ps1`으로 다른 캐시를 삭제한다. 임시 시험 파일은 시험 종료 때 제거한다.

## 002 — 구현 명세의 원본 내부 자료 제외

상태: 검증 완료.

명세 내용 검사와 검토 기록을 추가했다. 원본 식별자·주소·자료구조·경로를 포함한 입력을 거절하고 이전 정상 묶음을 보존하는 시험을 통과했다. 전체 시험 6개, 경고 없는 정적 검사, 실제 명세 검사가 통과했다.

## 003 — 독자 화면·아이콘·기본 팁

상태: 검증 완료.

Drawer 화면과 절차적으로 생성하는 아이콘·4개 기본 팁을 구현했다. 전체 시험 8개·정적 검사·Windows 앱 빌드 통과. 빈 작업 디렉터리에서 앱을 실행해 도구 목록과 내장 미리보기를 5프레임 그린 뒤 정상 종료했다. 원본 소재와 외부 이미지 파일을 사용하지 않는다.

## 004 — 구성요소 출처·라이선스·배포 고지

상태: 검증 완료.

Windows 의존성 라이브러리 114개와 내장 글꼴 4개를 잠금 파일/정확한 소스 리비전으로 기록했다. 고지문 누락 0개와 목록 재계산 일치를 확인했다. 전체 Rust 시험 8개와 정적 검사 통과. 릴리스 배포 및 소스 전달 묶음에 구성요소 목록·고지문·Cargo.lock을 함께 보존한다.

## 005 — Windows x64 실행·사용자 설치·제거

상태: 검증 완료.

사용자 설정/소재 폴더와 원자적 설정 저장을 구현했다. 전체 Rust 시험 9개·정적 검사·릴리스 빌드 통과. 표준 사용자와 제한된 네트워크의 실행 도구 환경에서 설치한 앱을 소스 없는 폴더/개발도구 없는 PATH로 시작했다. 설치·재설치·제거 통합 시험은 사용자 문서·소재·설정·추가 파일 네 개를 보존했다. PE x64 및 VC 런타임 DLL 의존성 0개를 확인했다. 실행에는 Windows의 그래픽 드라이버를 사용한다.

## 006 — 새 그림의 크기·DPI·배경·투명도

상태: 검증 완료.

새 그림 대화상자와 하나의 래스터층 문서 모델을 구현했다. 1×1/색 배경/투명 배경, 잘못된 숫자·비유한 DPI·범위·메모리 예산 초과 거절 시험 통과. 마우스 이벤트로 생성→다시 열기→잘못된 크기→취소를 실행했고 기존 그림을 보존했다. 전체 Rust 시험 14개·정적 검사·릴리스 빌드·설치 앱의 새 그림 렌더링 시험 통과. 생성은 미저장 그림으로 추가하며 기존 문서 데이터를 변경하지 않는다.

## 007 — 캔버스 보기 이동·배율·회전·좌우 반전

상태: 검증 완료.

휠 확대/축소, 가운데 버튼 또는 Space+드래그 이동, 회전 각도, 보기 반전과 초기화를 구현했다. 픽셀/장치 좌표 변환과 역변환을 공통으로 사용하며 포인터 위치를 고정해 확대한다. 문서별 보기와 로컬 보기 설정을 보존한다. 전체 시험 17개·정적 검사·릴리스/설치 시험 통과. 마우스 입력 후 비대칭 픽셀 데이터의 해시와 문서 변경 상태가 같았다. 배율은 1~6400%, 이동 안전 한도는 논리 좌표 ±10억이다.

## 008 — 여러 문서와 독립 편집 상태

상태: 검증 완료.

로컬 Drawer/PNG 열기, 탭 전환·닫기, 저장·실행 취소·다시 실행과 여러 보기를 구현했다. 문서별 도구와 이력을 유지하고 보기별 이동·배율·회전을 유지한다. 같은 이름의 서로 다른 경로, 중복 열기, 미저장 그림 여러 개, 마지막 보기 확인과 마우스 닫기 취소 시험 통과. 저장 실패 시 기존 파일과 열린 그림을 보존하며 여러 문서 종료 중 취소해도 앞서 버리기로 승인한 그림을 메모리에 유지한다.

전체 Rust 시험 26개·경고 없는 정적 검사·릴리스 빌드·설치/재설치/제거 시험 통과. 설치 앱은 문서 2개·보기 2개·닫기 취소를 확인하고 정상 종료했다. 추가한 파일 선택기의 고지문을 포함해 라이브러리 115개·내장 글꼴 4개의 라이선스 누락 0개를 확인했다. 저장 형식의 현재 보존 범위는 `native-format.md`에 기록한다.

## 009 — 재샘플링·DPI·캔버스 크기·잘라내기

상태: 검증 완료.

네 명령과 최근접/양선형 보간, 9개 앵커, 제거 영역 안내·확인, 배경 계산 취소와 명령별 Undo를 구현했다. 공통 문서 변환과 비래스터 crop 마스크를 보존하고 기본 페이지 객체/직교 카메라/세계 메시를 렌더링한다. 상세 보존 규칙과 현재 메모리 한도는 `image-sizing.md`에 있다. 저장 형식 2로 객체와 선택·가이드·카메라를 보존하며 형식 1도 읽는다.

10pt 텍스트·10px 선·60lpi 톤·10px 그림자·선택·가이드·카메라·3D 혼합 문서의 2배/비균등 배율, DPI만 변경, 축소/잘라내기, 물리 크기가 같은 300/600 DPI 출력 주기, 파일 재열기와 단일 Undo 시험 통과. 마우스 Apply/Cancel·미리보기 취소·계산 취소 후 새 명령의 독립성을 확인했다. 전체 Rust 시험 34개·정적 검사·릴리스/설치 시험 통과. 설치 앱에서 DPI 변경과 Undo를 확인했다. 라이브러리 121개·내장 글꼴 4개의 고지문 누락 0개를 확인했다. 후속 텍스트/벡터/톤/3D 편집 도구 항목은 완료로 표시하지 않는다.

## 010 — 보기 반전과 실제 그림 변환

상태: 검증 완료.

실제 그림의 좌우/상하 반전과 두 방향 90도 회전을 배경 계산·단일 Undo로 구현했다. 모든 래스터층과 페이지 객체를 함께 변환하고 보기 상태와 세계 기하를 유지한다. PNG 내보내기는 RGBA8 합성 픽셀을 원자적으로 저장하며 편집 문서의 연관 경로·변경 상태·이력·보기를 바꾸지 않는다. 현재 색상 프로필·DPI 메타데이터 출력은 후속 형식 항목에 남아 있다.

비대칭 4모서리를 실제 PNG로 출력해 보기 반전의 불변과 실제 변환 결과를 대조했다. 혼합 객체 외관·4회 회전 원본 복원·마우스 명령·내보내기 실패와 원본 파일 보존 시험 통과. 전체 Rust 시험 38개·정적 검사·릴리스/설치 시험 통과.

## 011 — 전체 그림 내비게이터

상태: 검증 완료.

전체 그림 미리보기와 현재 표시 영역, 클릭·드래그로 보기 이동을 구현했다. 화면 사각형을 문서 좌표로 역변환하고 그림 경계와 다각형 교차를 계산해 회전 시에도 실제 표시 영역을 그린다. 전체 그림이 보일 때는 그림 경계 전체를 표시하고 보기 밖이면 안내한다. 같은 프레임에 내비게이터 이동을 주 캔버스에 적용하고 기존 로컬 보기 설정에 보존한다.

1%·100%·6400%, 0°·37°·90°, Mirror와 1/1.5/2배 화면 배율에서 실제 화면 모서리와 좌표를 대조했다. 8각형 교차/교차 없음/전체 보기와 회전·반전 상태의 마우스 클릭·드래그 시험 통과. 문서 픽셀·객체·변경 표시·실행 취소 이력은 바뀌지 않았다. 전체 Rust 시험 41개·정적 검사·릴리스/설치 시험 통과.

## 012 — 로컬 참고 이미지 창과 색 추출

상태: 검증 완료.

PNG·이미지 클립보드 추가, 목록/이전/다음, 참고별 이동·배율·회전, 자동/클릭 스포이트, 투명도를 포함한 색 링, 연결 제거와 독립 새 문서를 구현했다. 목록·색·창 배치와 보기 설정을 원자적으로 저장하며 설정 Undo/Redo·직전본 복원·초기화와 복사본을 포함한 로컬 묶음 이동을 제공한다. 원본을 삭제/덮어쓰지 않는다. 상세 정책은 `references.md`에 있다.

재실행·누락/손상·원본이 없는 오프라인 복사본·휴대용 묶음·제거 복원·저장/가져오기 실패 시험 통과. 알파 0/128의 원본 RGB 보존, 회전 상태의 마우스/가상 접촉 링, 주 문서 불변과 독립 새 문서를 확인했다. 전체 Rust 시험 46개·정적 검사·릴리스/설치 실행 통과. 재설치·제거 뒤 참고 설정과 복사본을 포함한 사용자 파일 6개를 보존했다. 실제 사용자 클립보드는 건드리지 않고 공급자 시험과 OS API 빌드로 입력 경로를 검증했다. 실제 펜 하드웨어 시험은 후속 장치 항목에 남긴다.

## 013 — 눈금·격자·가이드·인쇄 크기 보기

상태: 검증 완료.

px/mm/inch 눈금, 격자 간격/원점과 가이드 추가/제거, 화면 표시 토글과 실측 보정에 따른 인쇄 크기 보기를 구현했다. 격자/가이드 기하를 자체 문서 형식 3에 저장하며 메타데이터만 따로 실행 취소해 래스터 버퍼를 복사하지 않는다. 형식 1/2도 읽는다. 화면 설정은 직전본 복원·기본값 초기화를 제공하며 문서 내용과 분리한다. 상세 규칙은 `canvas-aids.md`에 있다.

150/300/600 DPI와 100/150/200% 화면 배율에서 같은 물리 길이 계산, 회전·반전 눈금의 실제 문서 좌표, 조밀한 격자 표시의 계산 한도, 마우스 기하 편집/Undo, 저장·재열기와 픽셀 불변 시험 통과. 전체 Rust 시험 52개·정적 검사·릴리스/설치 실행 통과. 설치 앱의 격자/가이드 Undo와 인쇄 크기 보기를 확인했고 사용자 파일 8개를 재설치·제거 후 보존했다. 실제 화면 길이 정확도는 UI에 알린 대로 사용자의 실물 측정에 의존한다.

## 014 — 이미지 새 문서·최근 파일·다른 이름 저장

상태: 검증 완료.

클립보드 독립 새 그림, PNG/JPEG/TIFF의 읽기 전용 스냅샷·페이지/방향 선택·색상 프로필 변환·배경 디코딩 미리보기와 취소를 구현했다. 최근 파일 20개를 로컬에 원자적으로 저장하고 목록 Undo/Redo·초기화·직전본 복원을 제공한다. Save as는 성공한 경우에만 경로를 바꾸고 Export PNG는 경로·변경 표시·이력·선택·보기를 유지한다. 검증된 입력 변형·RGBA8/sRGB 정규화·지원하지 않는 변형과 예산은 `image-import.md`에 기록했다. 후속 입출력·색 관리 항목은 완료로 표시하지 않는다.

PNG 투명/숨겨진 RGB·Display P3 ICC 실제 변환·회색조 ICC, JPEG EXIF 적용/해제, TIFF 두 페이지/8·16비트 Gray/RGB/RGBA/Gray+alpha/연관 알파, 큰 치수와 예산·손상·누락·취소·원본 바이트 불변·자체 문서 재열기 시험 통과. 마우스 미리보기 취소/확정/방향 변경, 기존 문서 이력 불변, 반복 가져오기의 독립성, 최근 목록 재시작/손상본 보존, 파일 선택/덮어쓰기 취소와 저장 실패 시험을 통과했다. 전체 Rust 시험 64개·경고 없는 정적 검사·릴리스/설치 실행 통과. 설치 앱의 클립보드 공급자·다른 이름 저장/내보내기·최근 목록 재시작·실제 PNG 디코딩을 확인했고 사용자 파일 9개를 재설치·제거 후 보존했다. 실제 사용자 클립보드와 펜 하드웨어는 변경하지 않았다.

## 015 — 문서 공유 보기와 모니터 전용 창

상태: 검증 완료.

기존 독립 문서 보기 탭에 도구 패널 없는 native 캔버스 창을 추가했다. ## 021 — 파일 연결 안내·저장본 되돌리기·영상 셀 가져오기

## 023 — 모니터 DPI와 인터페이스 배율

## 040 — 크기·불투명도의 독립 필압 연결

네 도구 각각에서 필압→크기와 필압→불투명도를 독립 선택하고 로컬 설정과 JSON 프리셋으로 저장한다. 기본은 크기 켬/불투명도 끔이다. 마우스/필압 누락은 1이며 펜의 0~1 값을 정상화된 이벤트에서 실제 래스터 획으로 전달한다. 크기만 연결하면 농도를 유지하고 불투명도만 연결하면 팁 크기를 유지한다. 0압력은 연결된 축의 기여를 0으로 만들며 한 축도 연결하지 않았을 때에는 압력 변화로 픽셀을 추가하지 않는다. 곡선/최솟값/최댓값은 다음 항목이다.

이동 구간의 필압을 보간하고 정지 상태의 필압 변화도 처리한다. 불투명도 연결은 획 내 최대 팁 기여를 원본 픽셀에 적용하므로 겹침/왕복으로 지정 압력을 넘겨 진해지지 않으며 지우개는 같은 비율로 알파를 제거한다. 획 시작의 연결 설정을 유지하고 실제 크기 커서를 갱신한다. 추가 필압 버퍼의 메모리 상한을 반영하고 확정 이력의 남는 버퍼 용량을 줄였다. 적용/취소·적용 전 백업·재시작과 프리셋 덮어쓰기 명시 선택·손상/버전/64KiB 제한을 제공한다.

## 041 — 필압 입력 범위와 편집 가능한 단조 곡선

브러시별 입력 필압 최솟값/최댓값을 정하고 범위 아래/위는 0/1로 제한한 뒤 0·25·50·75·100%의 구간 선형 곡선을 적용한다. 양끝 출력은 0/1로 고정하고 중간 세 출력은 직접 입력/슬라이더로 편집하며 최종 원시 입력→출력 그래프를 표시한다. 평탄한 구간은 허용하고 감소하는 곡선·최소=최대·역전/범위 밖 설정은 이유를 표시하며 적용/프리셋 저장을 차단한다. 유효한 결과는 항상 0~1이고 원시 입력의 비유한 수는 거절한다.

연결된 크기/불투명도와 실제 커서에 같은 응답을 사용한다. 획 시작의 응답을 보존하므로 임시 설정 변경은 기존 획과 픽셀/이력을 다시 계산하지 않는다. 로컬 작업공간/프리셋에 응답을 저장하며 이전 연결 설정에 응답이 없으면 직선/전체범위를 보충한다. 적용/취소·적용 전 백업·손상 거부는 기존 설정 경로를 공유한다. 길어진 창은 스크롤하고 적용/취소는 위쪽에 배치했다.

## 042 — 선택한 펜 기울기·지우개·버튼 속성

상태: 검증 완료. 실제 펜 하드웨어 검증 대기.

정규화 입력에 선택적 기울기·펜 지우개·버튼 상태를 추가하고 Windows Ink의 실제 제공 속성을 전달한다. 기울기를 팁 각도에 연결하는 옵션은 화면 방향을 역 보기 변환하여 회전/반전/DPI에 맞춘다. 속성 없음/비유한 기울기는 기본 방향을 쓰고 유한한 축은 ±90°로 제한한다. 펜 지우개나 보고된 버튼을 누른 채 시작한 획은 선택 옵션에 따라 현재 브러시 모양/필압을 유지하며 지우개로 그린다. 그 여부와 옵션은 시작값으로 끝내고 문서의 선택 도구를 바꾸지 않는다. 일반 마우스/미분류 장치에는 펜 속성을 적용하지 않는다.

버튼 옵션은 기본 꺼짐이며 OS가 보고한 버튼 중 하나가 눌린 상태를 사용한다. 입력 제공자가 촉도 버튼으로 포함할 수 있으므로 개별 물리 버튼 번호를 가정하지 않는다. 버튼별 배정은 047에 남는다. 해제/범위 이탈/장치 제거 때 접촉과 버튼 상태를 해제한다. 진행 중 각도 변경은 미리보기와 픽셀에 반영하고 한 번의 실행 취소를 유지한다. 설정/이전 작업공간 호환과 적용/취소·백업을 공유한다.

## 043 — OS 출처 기반 펜 호환 마우스 중복 제거

상태: 검증 완료. 실제 펜/드라이버 중복 입력 검증 대기.

Drawer 루트 창의 Windows 마우스 메시지를 원래 UI에 그대로 전달하면서 현재 메시지의 OS 출처·좌표·단계를 별도 큐에 기록한다. 문서 그리기는 병합된 GUI 이벤트와 출처를 다시 추정해 짝짓지 않고 그 큐를 직접 소비한다. 네이티브 펜 제공자가 연결되어 있으면 OS의 펜 호환 표식이 있는 마우스 이벤트만 획에서 제거한다. 같은 위치·인접 시간의 실제 마우스 입력은 유지하고 펜 제공자가 없으면 호환 마우스도 기본 마우스 획으로 사용한다. 메뉴/일반 버튼은 기존 UI 이벤트를 계속 받는다. 접촉 이후에도 남는 시간 기반 차단 상태는 없다.

## 044 — 필압·기울기 없는 장치의 기본 브러시

## 046 — Windows Pointer·Wintab 선택과 실패 복귀

상태: 구현·가상/네이티브 초기화 검증 완료. 실제 펜 입력/드라이버 동작 검증 대기.

기본 펜 입력을 Windows Pointer로 교체하고 로컬 설정에서 Wintab/Mouse를 선택한다. 한 번에 한 펜 제공자만 보유하며 전환/Retry는 진행 획을 한 번 종료하고 이전 입력을 비운 뒤 기존 컨텍스트를 닫고 새 제공자를 연다. Wintab 미설치·초기화 실패는 Pointer→Mouse로 복귀하며 런타임 실패는 미확정 획을 버리고 Mouse로 복귀한다. 요청/실제 방식과 오류를 표시하며 재시도는 명시적이다. 설정 적용/취소·백업·재시작도 기존 작업공간 경로를 사용한다.

Pointer는 PT_PEN·장치/접촉·지원 압력/기울기/반전/버튼을 읽고 병합 이력을 오래된 순서로 재생한다. Wintab은 System32의 설치 DLL만 동적 참조하고 비활성 컨텍스트를 자체 창 포커스에서만 켠다. 시스템 커서 제어를 요청하지 않는다. 공개 ABI의 가변 패킷을 제한된 버퍼로 해석하며 각 메시지의 일련번호만 읽어 마우스와 원래 전달 순서를 유지한다. 가상 태블릿 UINT(-1)도 공식 규약대로 처리한다. 필압 축/방향 해상도·명시적 펜촉 버튼/반전 상태를 사용하고 전환/포커스/커서 변경 뒤 들어 올림을 요구한다. API·컨텍스트·창 수명과 재진입을 UI 스레드 Rc 경계에 묶었고 원시 포인터는 비공개 플랫폼 모듈 밖으로 내보내지 않는다.

교체로 사용되지 않는 RTS/octotablet 및 수정 vendor 소스를 제거하고 실제 배포 의존성 145개/내장 글꼴 4개의 고지를 재생성했다. 과거 출처는 Git 이력에 남는다. 상세 경계/공식 출처는 pointer-input.md와 windows-input-boundary.md에 기록했다.

## 047 — 펜 클릭 임계값·좌표·번호 버튼 매핑

상태: 구현·가상 픽셀/설정 검증 완료. 실제 펜 하드웨어 검증 대기.

네이티브/가상 입력이 같은 안전한 코어 정책을 거친다. 기본 클릭 임계값은 꺼져 기존 0압력을 보존하고 켜면 설정값 이상에서 Down, 아래에서 Up을 만든다. 필압 누락은 1이다. 절대 좌표와 0.05–10배 상대 좌표를 선택하며 상대 좌표는 첫 캔버스 중심·다음 접촉의 마지막 위치에서 이동 차이를 누적하고 창 경계로 제한한다. 시작 전/그리는 중 가상 커서도 같은 좌표를 표시한다. OS 커서·메뉴 클릭은 바꾸지 않는다. 잘못된 좌표/압력·분리/취소·중복 Down·포커스/설정 변경은 미확정 접촉을 끝내거나 버리며 최대32개 상태만 보유한다.

번호 있는 논리 버튼 비트를 선택 속성으로 추가했다. Pointer 배럴은 1번, Wintab은 식별된 펜촉 비트를 제외한 드라이버 논리 번호를 전달한다. 32개 슬롯에 기본 유지/현재 브러시/지우개/그리기 무시를 배정하며 무시→지우개→현재 브러시 순이다. 무시로 시작한 접촉은 들어 올릴 때까지 차단하고 선택된 팁은 획 동안 고정한다. 번호 없는 장치는 기존 동작을 유지한다. 임계값·좌표 모드·속도·버튼 설정은 Apply/Cancel·백업·재시작 경로에 포함한다. 원본 앱 코드나 드라이버 설정 변경은 없다.

## 048 — 태블릿 영역·화면 매핑·터치 오프셋

상태: 구현·가상 좌표/픽셀 검증 완료. 실제 장치 매핑/터치 드라이버 검증 대기.

장치의 전체 영역을 정규화한 선택 좌표를 추가했다. Pointer는 GetPointerDeviceRects와 원시 HIMETRIC 좌표를 사용하며 없으면 지원 없음으로 남긴다. Wintab은 원시 출력 원점/범위의 해상도와 부호를 유지하고 Y방향을 변환한 뒤 기본 화면 좌표도 부동소수점으로 계산한다. 클라이언트 커서 위치로 태블릿 좌표를 추정하지 않는다.

0–1 태블릿 사각형을 잘라 활성 캔버스 창 영역(정렬 보기 포함) 또는 선택 모니터로 매핑한다. 모니터 물리 위치/크기를 보존하며 사라지거나 배치가 달라지면 임의 대체하지 않고 재선택을 요구한다. 수신 창의 물리 원점과 실제 UI 배율로 음수 화면 좌표를 변환하며 상대 모드/속도는 매핑 후 적용한다. 창/보기/배율/환경 변경은 기존 유효 획을 한 번 끝내고 새 누름을 요구한다. 선택 영역 이탈·장치 좌표 누락은 미확정 획을 버리며 누른 채 재진입해도 새 획이 생기지 않는다. 터치 물리 픽셀 오프셋은 터치에만 적용하고 그리기를 켜지 않는다.

로컬 UI의 마우스 미리보기는 명시적 가상 UV로 같은 매퍼를 실행하고 사용자 그림은 바꾸지 않는다. 가상 입력 재생에 Tablet area sample을 추가했다. 설정은 적용/취소·백업·재시작에 포함하며 0면적·역전·NaN·초과 오프셋을 거절한다.

일반 시험 188개·경고 거부 정적 검사·145개 라이선스/4개 글꼴 고지·릴리스/설치 실행 통과. 서로 다른 수신 DPI·음수 모니터/창 원점·사각형 최소/최대/중앙·영역 밖/분리 모니터·누락 장치 좌표·0면적·터치/마우스/미확인 입력 분리·원시 태블릿 미세 좌표/부호를 확인했다. 실제 앱 가상 경로에서 매핑된 중앙 픽셀, 영역 이탈/재진입의 미확정 픽셀 취소, 장치 정보 누락 시 오입력 없음, 배율 변경 시 한 이력 종료와 누른 채 재시작 없음, 설정 UI 복원을 검증했다. 설치 앱에서도 같은 픽셀 시험과 두 네이티브 백엔드 초기화/복귀 및 사용자 파일 18개 보존을 확인했다. 실제 펜/터치로 검증한 결과는 아니다.

## 049 — 로컬 스캐너·카메라 취득

상태: 구현·프로토콜/픽셀/설치 검증 완료. 실제 장치 사진/스캔 전송은 미검증.

사용자 명령에서만 로컬 WIA 2.0 스캐너/카메라와 Windows 영상 카메라를 조회하고 선택 장치의 한 이미지를 취득한다. WIA GetImageDlg는 선택과 파일 전송을 묶어 실행하며 S_FALSE 취소의 부분 스캔도 모두 버린다. BSTR/CoTaskMem/반환 인터페이스·속성과 STA COM을 해제한다. 카메라는 선택한 VideoDeviceId·마이크 없는 Video 모드·자동 사진 스트림·메모리 PNG를 사용하고 첫 초기화는 메시지를 처리하는 보조 프로세스의 주 STA에서 실행한다. MediaCapture를 닫고 WinRT를 해제한다. 공급자별 장치 없음/분리/사용 중/접근 차단은 이유를 표시한다. 내려받기나 계정·클라우드 경로는 없다.

동일 Drawer 실행 파일의 명시적 보조 모드에 제한 JSON으로 요청한다. UI는 응답을 기다리는 동안 계속 작동하며 취소·30초 조회/5분 취득 시간 제한·원본 64MiB와 디코딩/문서 예산을 적용한다. Windows Job은 프로세스 커밋 512MiB와 마지막 핸들 닫기 종료를 설정해 앱 종료 때도 자기 보조 프로세스만 정리한다. 파일은 독점 생성한 로컬 작업 폴더의 실제 직계 파일만 읽고 외부 경로/링크/프로토콜 파일·초과 출력을 거절한다. 자식 종료를 기다린 뒤 임시 결과를 정리한다.

디코더의 동일 불변 원본 스냅샷과 픽셀을 미리보기에 보관한다. 새 문서는 독립 복사, 레이어는 배치 미리보기 뒤 한 번의 Undo/Redo로 확정한다. 미리보기 원본/픽셀을 메모리 예산에 포함하며 취득 전·실패·취소는 기존 그림을 유지한다. 원본은 선택한 새 사용자 파일에 바이트 그대로 저장하며 기존 파일을 덮어쓰지 않는다. 일반 WIA 출력을 위해 BMP RGB24 입력과 치수/메모리 제한을 추가했다. 동작/공식 API/실제 검증 범위는 acquisition.md에 기록했다.

일반 시험 193개·경고 거부 정적 검사·145개 라이선스/4개 글꼴 고지·릴리스/설치 실행 통과. 빈 장치 목록/명시적 조회·UI 미리보기 닫기/분리 오류·프로토콜 손상/초과·한글 장치 정보·외부/거대 이미지 거부·원본 보존/새 파일 저장·PNG/BMP 픽셀·독립 새 문서·레이어 미리보기 불변과 한 이력 Undo/Redo를 확인했다. 설치 앱의 장치에 접근하지 않는 진단 요청으로 실제 보조 프로세스 응답·시간 초과·실행 중 취소·Job 핸들 닫기 종료와 매회 임시 정리, 사용자 파일 18개 보존을 검증했다. Job 종료의 Windows 종료 코드만으로 성공을 오판하지 않고 2초 지연 작업의 1초 이내 종료 및 응답 파일 미생성으로 판정한다.

별도의 읽기 전용 실장치 조회에서는 영상 카메라 1개, WIA 장치 0개, 공급자 오류 0개를 확인했다. 실제 촬영/스캔은 수행하지 않았으므로 실제 센서 전송 성공으로 표시하지 않는다.

## 050 — 터치·두 손가락 제스처·손바닥 방지

상태: 구현·가상 입력/픽셀/자체 창 연결 검증 완료. 실제 터치/펜·드라이버 검증 대기.

자체 루트 창의 WM_TOUCH를 비공개 Windows 하위 클래스에서 읽어 winit이 빌린 터치 핸들을 닫기 전에 좌표·장치/접촉 ID·명시적 펜/손바닥 표식과 배치 ID를 복사한다. 원본 메시지는 한 번 그대로 전달하고 핸들을 직접 닫지 않는다. UI 스레드 Rc/Weak 수명, 제거 후 창 소유자 해제, 재진입·API 실패·32접촉/256배치/65536큐 한도를 적용한다. 명시적 펜 표식 터치를 손가락으로 처리하지 않으며 알 수 없는 입력을 필압으로 재분류하지 않는다.

같은 장치의 두 손가락 중점·간격·방향으로 보기만 이동/확대/회전한다. 완전한 네이티브 배치를 함께 처리해 중간 점프를 피하고 서로 다른 DPI·회전·반전에서도 중점 아래 문서 점을 유지한다. 겹친 접촉은 불안정한 확대/회전을 생략하고 세 손가락 이상·접촉 수/ID 변경에서 기준을 다시 잡는다. 실제 캔버스와 UI 층에서 시작한 접촉만 사용한다. 손가락 그리기는 기본 꺼짐이며 켜면 정상 미확정 획/한 이력 경로로 그린다. 두 번째 손가락·펜 접촉·손바닥 표식·설정/보기 변경·포커스 상실은 미확정 손가락 획을 취소하고 누른 채 재시작하지 않는다. 펜은 앱 클릭 임계값 아래라도 실제 접촉 중 터치를 차단한다. 원래 UI 클릭은 유지하며 문서용 호환 마우스 및 기존 마우스 보기 드래그와의 이중 적용을 막는다.

제스처를 포인터와 같은 순서의 캔버스 효과로 처리해 같은 묶음에서 먼저 끝난 획은 옛 보기에 기록하고 이후 제스처/획에는 새 보기를 쓴다. 보기 변경은 픽셀·변경 표시·편집 이력을 바꾸지 않는다. 터치/손가락/손바닥 설정은 기존 적용/취소·백업·재시작에 포함하고 늘어난 설정 창은 스크롤 및 상단 적용/취소로 조작한다. 상세 경계와 공개 API는 touch.md에 기록했다.

일반 시험 199개·경고 거부 정적 검사·145개 라이선스/4개 글꼴 고지·릴리스/설치 실행 통과. 완전 배치 변환·DPI/회전/반전·근접 두 점·2→3→2→1 접촉·장치 분리/호환 복사/UI 접촉 격리·손바닥/펜 우선·중복/잘못된 접촉·설정·포커스를 시험했다. 실제 앱 가상 경로의 보기 전용 변환/문서 불변·손가락 획 취소→펜 한 획·포커스 상실/복귀의 유지 접촉 무시와 새 접촉 그리기·Undo/Redo·같은 묶음의 완료 획→제스처 순서와 옛 픽셀 좌표 보존을 확인했다. 설치 앱은 자체 루트 터치 어댑터 연결과 같은 가상 경로, 사용자 파일 18개 보존을 통과했다. 물리 터치 발생이나 실제 손바닥 판별을 시험한 결과는 아니며 WM_TOUCH로 노출되지 않는 장치 동작을 추정하지 않는다.


## 051 — 직접 연결 다이얼·컨트롤러

상태: 구현·명령 재생·자체 창 네이티브 초기화 검증 완료. 실제 컨트롤러 조작/분리 시험 대기.

자체 루트 창에 Windows RadialController를 연결하고 OS 메뉴의 Drawer 항목을 추가했다. windows-radial이라는 OS 어댑터 식별자와 clockwise/counterclockwise/click 동작을 기존 로컬 명령 배정에 연결한다. OS가 물리 일련번호를 제공하지 않으므로 이를 개별 장치 번호로 주장하지 않는다. 기본 배정 추가는 브러시 크기 증감과 도구 순환이며 확대/축소·실행 취소 등 같은 앱 명령을 선택할 수 있다. 전용 컨트롤러의 키보드/추가 마우스 버튼 대체 경로를 유지하고 노출되지 않는 원시 제스처는 추정하지 않는다.

1~180도 민감도, 부분 회전/반대 방향, 제어권 상실/획득, 단조 증가 이벤트 중복 제거와 한 묶음 32명령 상한을 적용한다. 초과분을 나중에 재생하지 않는다. 포커스/설정/배정 변경 시 누적값을 지우며 입력란·IME·모달 창은 명령을 차단한다. 네이티브 큐는 256개로 제한하고 오류 시 비운 뒤 명시적 재연결을 요구한다. ButtonClicked만 구독해 누름/놓음과 이중 실행하지 않고 OS 길게 누르기 메뉴를 유지한다. 콜백은 제한된 값 큐와 Weak 창만 보유하며 UI 스레드 해제 시 죽은 큐 표시→구독 제거→자기 메뉴 항목 제거→COM 객체 해제→WinRT 초기화 균형→창 해제 순서다. 부분 초기화/재시도도 같은 정리를 한다.

설정 적용/취소·초기화·선택 가져오기·내보내기·이전 백업·재시작과 구형 프로필 기본값을 연결했다. 브러시/확대/도구 명령은 같은 키보드 경로와 동작하며 그림 픽셀·변경 표시·편집 이력을 바꾸지 않는다. 알 수 없는 이름/삭제된 배정은 실행되지 않는다. 상세 API와 경계는 controllers.md에 기록했다.

일반 시험 205개(앱 89, 코어 100, 플랫폼 10, 전달 도구 6), 경고 거부 검사, 145개 라이브러리/4개 글꼴 고지와 릴리스·설치 시험이 통과했다. 포커스 복귀가 OS 획득 상태를 지우던 문제를 시험에서 찾아 분리했다. 가상 입력으로 크기/확대/도구 적용, 중복·손실·폭주·설정 변경·모달·키보드 동등성·삭제/알 수 없는 배정·문서 불변을 확인했다. 설치본에서 Windows 어댑터 자체 창 연결 성공과 OS IsSupported=true를 확인했으며 실제 다이얼을 조작한 결과로 간주하지 않는다. 재설치/제거 후 사용자 파일 18개 보존도 통과했다.
