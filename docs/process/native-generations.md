# Native editable generations

Native124 streams a SHA256 body/footer check with the payload byte count, document revision and current frame. Versions1..123 remain readable; an unknown schema is refused. Read errors include the byte position. The native document contains current editable state and embedded sources, never a session Undo/Redo stack. Recovery uses the same current-state representation.

Project snapshot freezes all open documents at one synchronous boundary. Closed source pages are stamped before copying and checked again before publication. Each block is opened/validated and recorded with its page ID, byte length, full-file SHA256, native schema, revision and frame. The versioned generation manifest verifies every page on project load and verifies the selected page again on open. All pages must share a generation directory. Page/cel/material data remain in their containing native block, so no uncommitted external material/cel block is published separately.

Exclusive staging directories are renamed only after all blocks pass. The project manifest is replaced last and is the only publication boundary. Any error before that boundary removes only the owned generation and preserves the old manifest; errors from a completion observer after publication cannot undo a committed save. Previous directories are retained to protect saved references and in-session project history. Saving a project snapshot does not rewrite the live page path, dirty flag or Undo stack. Later edits are not added to the captured generation.

Generated verification covers editable nested vector/text pages, 3D/materials, animation/shared cel sources, current frame/revision, session history exclusion, unknown schema, truncation/hash mismatch, three-page failure injection before and after every block and before/after directory/manifest publication, restart, retained prior references, and later edits after capture. This is an in-process interruption model; power-loss durability depends on the filesystem/platform atomic replacement path.
