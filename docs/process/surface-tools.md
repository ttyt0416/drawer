# 229 — 프리미티브·표면/질감 편집과 출력

`model-controls`의 `Primitive / material maps and texture export`를 펼친다. 자체 프리미티브는 생성 종류/분할수를 native120에 저장한다. 구/원기둥/원뿔은3..64의 기존 절차적 분할, Box/Plane/Chair/Room은1..32의 원본 삼각형 격자 분할이다.0·범위 밖·65536정점/간선·131072면 초과를 거절한다. 모델 원점/누적 축/크기·색/재질은 유지하고 원래 형상 기준으로 위상을 재구축한다. 가져온 메시를 임의 프리미티브로 추정하지 않는다. rig/형태키는 먼저 분리하고 UV/질감/채색 정책을 지워야 재구축할 수 있다. 원형 분할/UV/재질은 한 Undo로 되돌린다.

모델별 Scene display/Wire/Faces/Both를 선택한다. Wire와 Both는 실제 저장된 간선의 짙은1픽셀 X-ray 선이며 숨은 간선도 포함한다. 면은 기존3D 렌더를 사용하고 전체 장면의 Wire 선택 중에도 모델별 Face/Both를 선택할 수 있다. 표시와 빌보드로 원본/물리 형상을 바꾸지 않는다. 카메라 전체축/수평축 빌보드·개체별 알파 제어는 기존 `scene-lighting`을 사용하고 여기서는 재질 슬롯별 Source/Opaque/Mask/Blend·임계0..1을 추가한다. 물체별 알파 강제 설정이 있으면 재질보다 우선한다. Source는 원래 재질 알파 규칙을 유지하므로 PNG 투명도를 사용하려면 슬롯 또는 개체를 Blend/Mask로 선택한다. 임계 이상은 포함한다.

UV가 없는 면은 명시적 `Generate overlapping box UV`로 좌표를 생성한다. 각 삼각형의 주축에 투영하고 로컬 모델 범위를0..1로 맞춘다. 면 차트는 겹치므로 공유 질감 무늬가 반복되며 UV atlas/원본 UV 보존 기능이 아니다. 새 UV는 기존 질감/채색의 매핑을 바꾸고 Undo로 복원한다.65536좌표를 초과하면 거절한다. 슬롯별 UV는 중심0.5 기준 배율(절댓값0.001..128, 음수 반전)→회전(±36000도)→이동(±10000), U/V Source/Repeat/Mirror/Clamp를 선택한다. 확정된 메시·UV 원본을 변경하지 않는 샘플러 설정이며 색·알파·노멀과 표면 채색 조회에서 공통 좌표를 사용한다.

로컬 PNG/JPEG를 선택해 diffuse/normal 각각 스냅샷을 읽고 수동 Reload한다. 입력8MiB·변1024·디코드16MiB 제한으로 RGBA8 PNG에 내장한다.16비트 입력도8비트로 변환하고 ICC/감마/EXIF를 적용하지 않는다. normal은 선형 RGB 데이터로 tangent+Y 기준이며 strength0..4·green 반전으로−Y 입력을 조절한다. 실제 면/변환 UV의 도함수로 tangent/bitangent를 계산하고 UV가 퇴화하면 기존 법선으로 돌아간다. 변환된 법선이0벡터인 경우도 기존 법선을 유지한다. Base color/알파 규칙·빌보드 변환·비균등 축에 연결하며 strength0은 원형이다.

원본 경로와 내장 픽셀은 분리한다. 외부 변경은 자동 반영하지 않고 누락/실패/잘못된 새 파일은 기존 스냅샷을 유지한다. 다른 기계에서 원본이 없어도 native 문서가 재열린다. 가져온 glTF 등에 원래 재읽기 경로가 없으면 로컬 이미지를 명시적으로 배정하며 자동 추측/네트워크 요청은 하지 않는다. 새 diffuse 배정은 그 모델의 painted RGB를 지우며 한 Undo로 복원한다. Reload는 내장 base만 바꾸고 후속 painted RGB가 있으면 그 RGB가 우선한다. normal은 별도이고 매핑 삭제/초기화는 명시적 동작이다.

`Export texture PNGs now`는 문서 전체에서 실제 면에 쓰인 diffuse/alpha·paint·normal 스냅샷을 고정해 PNG로 출력한다. 원본·문서·이력은 바꾸지 않는다. 대상은 새 로컬 폴더이며 기존 폴더를 병합/대체하지 않는다. Fail/Skip/Rename은 기존 폴더와 텍스처 이름 충돌에 적용하며 이름은 안전한 texture-접두사와 결정적 숫자 접미사를 사용한다. 같은 이름/대소문자 차이·기존 파일/폴더는 조용히 덮어쓰지 않는다. 최대1024파일/128MiB·사본 예산을 검사한다. 전부 비공개 준비/동기화한 뒤 취소를 검사하고 새 폴더를 독점 생성해 hard link로 게시한다. 취소는 게시 시작 전까지이며 짧은 게시 중에는 작업을 완료한다. 게시 실패는 동일한 소유 바이트만 정리하고 새/변경된 외부 파일을 보존한다. 비공개 파일은 소유 목록만 정리한다. 문서 변경/닫기·Esc/취소는 기존 작업자 합류/오래된 결과 보호를 따른다.

준비/128픽셀 미리보기/Apply/Cancel은 한 Undo이며 내보내기는 명시적 버튼으로 바로 실행하고 Apply를 요구하지 않는다. 슬롯/선택·설정/문서/리비전/프레임 변경은 편집 준비를 폐기한다. native120은 프리미티브 설정·질감 경로/내장 픽셀·UV/노멀/알파·표시를 보존하고119 위장을 거절한다. 복제는 독립 스냅샷을 가진다. SAI/CSP의 코드/모델/질감이나 클라우드 서비스를 사용하지 않는다.
