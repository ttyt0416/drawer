# 속도 크기·농도와 장치별 필압 보정

기능074. 기존 동역학 Speed size factor와 별도의 Speed opacity factor를 제공한다. 각각 입력 속도 범위·5점 곡선·최소/최대 출력·누락 입력 계수를 가진다. 속도는 문서 좌표의 두 실제 입력 사이 거리 / 증가한 시각 차이며 px/s다. 크기 곡선은 기존 필압/기울기 크기 계수와 곱하고, 농도 곡선은 필압 출력 농도와 곱한다. 한쪽을 꺼도 다른 쪽을 사용할 수 있다. 압력 없는 마우스도 위치/시각으로 두 곡선을 사용한다. 새 농도 축은 한 획의 coverage 최대값을 사용해 샘플 겹침에서 농도가 반복 증폭되지 않는다. 최종 전체 농도/선택/질감은 기존 경로에서 한 번 적용한다.

같거나 뒤로 간 시각·시각 누락은 속도를 나누지 않고 None으로 처리해 각 곡선의 missing 계수를 사용한다. 증가한 시각의 실제 정지 입력은 속도0이다. 속도는 최대1e18로 제한하고 곡선 입력은 설정 범위에 clamp한다. 프레임 시계만의 입력은 최근 실제 motion의 속성을 유지한다. 실제 정지 입력과 타이머를 구별한다. 가상 재생 파일 자체는 역행 시각을 읽기 검증에서 거절하며, 런타임 Replay가 직접 받는 역행 입력도 위의 누락 규칙으로 안전하게 처리한다. 설정의 비유한/뒤집힌 범위와 입력 NaN은 그리기/적용 전 검증에서 거절한다.

Brush pressure → Device pressure calibration은 최대8개의 장치 종류/장치 ID별 단조 필압 보정이다. 접촉 ID는 구별하지 않는다. 가장 최근 캔버스에서 그린 장치를 현재 슬롯에 등록하거나 aggregate mouse(ID0)를 등록한다. 이미 등록한 장치는 해당 슬롯으로 이동하고 같은 종류/ID 중복을 거절한다. 각 슬롯의 범위/3개 내부 곡선 점을 편집하거나 제거한다.0/1끝점은 고정한다. 장치 ID는 현재 입력 백엔드가 제공하므로 백엔드를 바꾸어 다른 ID가 보고되면 해당 장치를 다시 등록한다. 물리 마우스별 ID를 구별한다고 주장하지 않는다.

획 시작에 현재 도구와 이벤트 장치의 보정 Response를 유효 Style에 복사한다. 원래 입력의 필터링 후 장치 곡선→브러시 출력 곡선/최소 출력 순으로 처리한다. 추가 압력 크기 곡선은 장치 보정 후 압력을 사용한다. 필압 혼색은 기존 브러시 보정 출력에서 계산한다. 누락 압력1과 마우스 가상 압력은 기존 규칙을 유지하며 장치 보정을 한 번 합성한다. 접촉 중 설정/목록 변경은 이미 시작한 획을 바꾸지 않는다. 단축 연결선과 시험 칠하기도 장치 보정을 연결했다. 보정이 있는 획은 재구성/고정 메타데이터를 사용하고 선택된 Response를 문서v25에 저장한다.

브러시 프리셋/입력 임시본은 두 속도 곡선과 브러시 필압 응답을 저장한다. 장치 종류/ID별 목록은 로컬 작업공간과 필압 프리셋 JSON에 저장하고 적용/취소/적용 전 백업/재시작을 공유한다. 장치 Response는 획의 고정 스타일로 저장한다. 구형 누락은 속도 농도 끔·장치 보정 없음/항등 곡선이다. 장치 ID는 정수로 보존하며 접촉/서버/계정을 사용하지 않는다. 실제 펜 보정 체감/센서 검증은 별도 대기다.

시험은 느림/빠름의 실제 크기/농도 차이·압력 독립·누락/같은/역행 시각/실제 정지/프레임 시계와 재현·한 이력/취소, 장치 종류/ID/접촉 분리·보정 순서의 독립 기대값·시작 Response 고정·잘못된/중복 목록/저장 실패 시 이전 파일·구형 기본값, 문서 픽셀/곡선 재열기, 생산 입력 마우스/펜 속도 농도와 장치별 필압/다른 ID 비전파, 프리셋/설정 적용·취소/백업/재시작을 포함한다. 설치본도 같은 코어와 실제 앱 입력 경로를 실행한다.
