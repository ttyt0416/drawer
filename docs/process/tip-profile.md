# 최소 출력과 독자 팁 이미지

각7개 브러시의 minimum_size/minimum_opacity는0~1 출력 비율이다. Pressure response가 보정한p 뒤에 min+(1−min)×p를 적용한다. 필압 축이 꺼지면1이다. 기본min0은 기존 동작이고 min1은 압력0/1에서 같은 최대 출력이다. 전체 크기와 농도의 상한/선택 마스크/색 알파/질감은 기존 단계를 유지한다. 시작/끝의 기하 계수는 별도로 곱해 최소 굵기로 시작끝0을 되살리지 않는다.

최소 굵기는 도장 크기뿐 아니라 획 재표본화 간격·분사 반경·진행 중 커서 모양에도 적용한다. 최소 농도는 필압에 따른 도장 농도에 적용하며 마커/번짐의 누적 방식과 전체 획 농도 적용 횟수는 바꾸지 않는다.

Image::Native/Round/Square는 독립 코드로 생성한 로컬 마스크다. Native는 기존 팁, Round는 원/타원, Square는 직사각형 윤곽을 선택한다. 연필 입자/에어브러시 감쇠/혼색 등 도구 재질은 별도다. Hardness는054의 값을 그대로 사용한다. Pixel pen은 선택한 원/사각 윤곽에 이진 경계를 적용한다. 회전한 사각 팁의 범위와 선분 바깥 잘라내기는 사각 모서리까지 포함한다. 커서 윤곽도 같은 선택을 사용하며 보기 변환과 픽셀은 독립적이다. 시험 칠하기의 팁 이미지도 누르기 때 고정한다.

입력 임시본/적용/취소/이전 백업·초기화·재시작, 브러시 프리셋, 가상 기록, 자체 문서v14의 고정 스타일/결과에 보존한다. 구형1~13/기존 설정·프리셋에서 없는 프로필은 최소0/Native다. 프로필 숫자는 유한0~1만 허용한다. 사용자 비트맵 등록은070 범위다. 실제 펜 장치 검증은 대기다.
