# 실행 취소 기록 한도

Local resources에1–1000단계·1–64MiB·명시적 명령 묶음0–5000ms 설정을 저장한다.0ms는 합치기를 끈다. 같은 명령이 명시적으로 부여한 같은 그룹 번호의 연속 갱신만 시간 범위 안에서 합친다. 개별 획·레이어 작업·문서 전환·Undo/Redo·저장 기준 및 진행 중 저장 경계를 넘어 합치지 않는다.

단계/메모리 한도에서 오래된 Undo부터 제거하고 현재 그림·저장 기준·남은 연속 이력을 보존한다. Redo만으로 새 한도를 넘는 설정은 거절해 미래 분기를 자동 삭제하지 않는다. 작업 메모리 감소로 Redo 보존량조차 불가능하면 명시적으로 알리고 해결/명시적 비우기를 안내한다. 이력 창에 사용 바이트와 제거한 오래된 기록 수를 표시한다.

각 기록의 알려진 용량은 생성 시 계산해 보관한다. 같은 그룹의 상태 갱신과 관리 파일 경로 재지정은 용량을 다시 계산한다. 이력 사용량 검사 때마다 모든 보관 타일/상태를 다시 조사하지 않는다. 설정은 세션 기록 자체가 아니라 로컬 설정에만 저장한다. 이전 설정 파일은 기본 한도로 읽는다.

검증: 단계 한도·최초 남은 상태·메모리 상한·남은 연속 Undo·Redo 단독 초과 설정 거절·시간 경계·합치기 끄기·문서 전환 경계·독립 획·설정 재열기 및 앱 적용.
