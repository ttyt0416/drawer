# 추가 필터 계약 (171)

Detail and pixel effects 창은 Normal map, Color and line abstraction, JPEG block / ringing reduction, Polar coordinates, Smoothing과 Blur, Blur (strong), Sharpen more, Pinch, Curved surface, ZigZag, Ripple을 각각 목록화한다. 기존 Sharpen도 별도다. 같은 항목을 명령 팔레트/사용자 명령으로 호출한다. 가우시안 블러나 기존 Wave를 이 목록의 대체로 취급하지 않는다.

노멀맵은 작업 RGB의 명도 높이(0.2126R+0.7152G+0.0722B)의 중앙 차분과 기울기 강도0~32를 쓴다. [-dx, ±dy, 1]을 정규화해 RGB로 인코딩하며 Y up/down은 녹색 방향만 바꾼다. 균일 높이나 강도0은 [128,128,255]의 평면 노멀이다. 투명 이웃은 현재 높이를 사용하고 숨은 RGB를 읽지 않는다.

선·색 추상화는 각 채널의2~32단계 양자화와 네 이웃의 명도 기울기에 따른 윤곽 강도0~4를 제공한다. JPEG 보정은 문서0 기준8×8 격자의 경계를 이웃과 섞는 강도와 경계 가까이 작은 진동을 억제하는 별도 강도를 제공한다. 이는 독립적인 공간 보정식이며 원본 JPEG의 양자화 계수 복원이나 손실의 완전한 제거를 보장하지 않는다. 두 값0은 원본이다.

극좌표의 Rectangular to polar는 원본 직사각형의 가로를0~2π 각도, 세로를0~반경으로 해석해 출력 원판에 배치한다. 역방향은 원판을 직사각형으로 편다. 문서 좌표의 중심/반경을 사용하며 자동 중심은 저장된 레이어 영역의 중심이다. 각도의 이음매와 반경 밖 표본은 기존 투명 경계/보간 규칙을 따른다.

스무딩은 반경0~8, RGB 차이에 따른 윤곽 보존0~1, 혼합 강도0~1의 알파 가중 이웃 평균이다. 반경0 또는 강도0은 무변경이다. Blur는3×3, Blur (strong)는7×7 평균이며 Sharpen more는3×3 평균과의 잔차를3배 더한다. 이 색 필터들은 원래 정수 알파를 보존한다. 완전 투명 픽셀의 숨은 RGB도 그대로 남는다.

Pinch는 정규화 반경의 거듭제곱으로 샘플 반경을 바꾼다. Curved surface는 구의 반경 또는 원통의 X축을 asin 곡면으로 바꾸며 두 형상을 명시적으로 고른다. Ripple은 반경 방향 사인 변위, ZigZag는 접선 방향 삼각 파형 변위다. 중심/반경과 강도 또는 진폭/파장을 제공한다. 반경 밖은 항등이며 반경0/변위0은 무변경이다. 공간 변형은 원본 RGBA를 미리 곱한 알파로 쌍선형 보간하며 레이어 투명도 잠금도 존중한다. 문서 경계 밖은 투명이다. 선택은 출력 적용 범위이고 입력 이웃을 자르는 경계로 사용하지 않는다. 다른 경계/출력 모드 등의 추가 옵션은172의 범위다.

비동기 미리보기, 원본/프레임/설정 변경 결과 폐기, 취소/닫기, 미확정 저장 거절과 Apply 한 Undo는 기존 픽셀 필터 경로를 공유한다. 원본4M픽셀/32MiB, 계산64M과 문서/Undo/작업 메모리 한도를 계산 전에 확인한다. 반경에 따라 비용이 늘어나는 스무딩도 실제 이웃 수를 반영한다. 네이티브 v82는 변경된 픽셀과 마지막 실제 필터 설정을 보관한다. 이전 헤더 위장과 잘못된 값은 거절한다. 라이브 보정층으로 오인하지 않으며 다시 적용하면 현재 픽셀에서 계산한다.

Local user presets에서 이름(최대64자)과 필터/선택 제한을 로컬 workspace에 저장하고 불러오거나 이름으로 삭제한다. 최대32개, 같은 이름 저장은 교체이며 잘못된 값/중복/제어문자를 거절한다. 저장 실패는 기존 프리셋을 복원한다. other 범위의 workspace 가져오기/내보내기에도 포함하며 문서 Undo/dirty와 분리한다. 서버/다운로드/클라우드 소재는 없다.
