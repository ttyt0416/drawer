# 로컬 작업 자원 설정

Local resources에서 알려진 문서 작업 메모리64–256MiB, 새로 여는/만드는 캔버스 최대 치수1–32768, 복구 보관 예산16–4096MiB와 로컬 scratch 폴더를 설정한다. 프로세스 전체 메모리/운영체제 캐시의 상한을 주장하지 않는다. 임시 계산의 별도 입력 검사는 계속 적용된다.

경로는 로컬 드라이브·구성요소 재분석 검사를 통과해야 한다. 최소1MiB 여유 공간을 검사하고 독점 생성한 작은 파일을 기록·동기화·읽기 검증한 뒤 제거한다. 전체 문서 저장과 입력/파일 작업의 유휴 시점까지 적용을 보류한다. 적용 전 열린 문서가 새 한도에 맞는지 검사하고 새 복구 세션을 준비한 뒤 설정을 원자 저장한다. 실패는 기존 설정을 유지한다. 보류 취소와 초안 되돌리기를 제공한다.

작업 메모리는 다른 열린 문서의 사용량을 제외하여 나눈다. 기록 정리 이후의 실제 사용량으로 다음 문서 예산을 갱신한다. 현재의 정상 종료한 소유 세션은 정리한다. 미해결 과거 세션은 자동 삭제하지 않고 이전 경로를 설정에 보관하여 복구 선택/수동 재검색에서 계속 표시한다. 복구 저장은 실제 직렬화 비용과 보관 사용량을 계산하여 예산을 넘으면 기존 사본을 보존하고 명시적 오류를 표시한다.

검증: 설정 재열기·범위 초과·0 여유 공간·경로 분리·설정 임시 경로 충돌 시 정상본/외부 파일 보존·미해결 바이트 유지·작업 중 보류/저장 후 적용·새 치수 제한·실패한 경로 변경의 기존 설정 유지.
