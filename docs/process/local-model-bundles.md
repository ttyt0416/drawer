# 로컬 추론 모델 묶음

모델 입력은 같은 로컬 폴더의 manifest.json·weights.onnx·LICENSE.txt다.
명세 형식1, 작업 Body/Hand/HintColor/Upscale/Denoise, 이름/버전/고지 식별자/출처,
가중치와 고지의 소문자 SHA256, 입력1..512와 정규화/배율을 검증한다. 명세16KiB,
가중치64MiB, UTF-8 고지64KiB로 제한한다. 빈/unknown 등 미확인 고지와 손상
ONNX·외부 tensor·비표준 연산/함수·학습 정보/하위 그래프·과도한 tensor를 거절한다.
출처 URL은 표시 정보이며 다운로드하지 않는다.

Local models에서 명세를 선택하고 Inspect model and LICENSE.txt로 전체 고지와
메타데이터를 읽는다. 사용자가 로컬 복사/사용 권한을 확인해야 Install이 활성화된다.
복사 시 검증한 명세 해시가 여전히 같은지 검사한다. 이것은 구조/무결성 검사와
사용자의 권한 확인이며 앱이 법적 권리를 자동 판정한다는 뜻이 아니다.

사용자 저장소의 models/<명세 SHA256>에 세 파일만 전용 준비 폴더에서 기록·동기화·
검증하고 게시한다. 공간 부족/잘못된 고지/변경된 검토/손상된 기존 캐시/알 수 없는
파일은 등록을 바꾸거나 기존 모델을 덮지 않는다. 실패한 준비 폴더도 소유 기록과
예상 파일/해시가 맞는 경우만 정리한다. 완성된 캐시는 등록 쓰기 실패에도 보존한다.

settings/local-models.json 버전1은 작업별 최대5개 활성 등록과 상대 해시 식별자,
이름/버전/고지만 저장한다. 등록은 검증한 임시 파일과 원자 이름 변경으로 갱신하고
이전 바이트는 해시별 previous.json에 보존한다. 읽을 수 없는 등록은 초기화하지
않는다. 모델을 등록 해제해도 캐시 파일은 남는다. 절대 경로가 없고 models는
일반 소재 JSON 경로 재배치 대상 밖이므로 데이터 이동/전체 백업·복원 뒤에도
명세 바이트와 해시를 유지한다.

Run은 확인한 명세 해시를 포함한 요청만 받는다. 별도 CPU helper도 같은 검사
스냅샷의 명세/가중치를 사용해 해시를 대조한 뒤 실행한다. UI의 경로/작업 변경은
미리보기와 승인을 갱신하며 변경된 파일/알 수 없는 포맷은 다시 확인을 요구한다.
모델 검토/복사 비용은 측정한 가중치 두 배와8MiB를 작업 메모리 한도와 대조한다.
입력/결과 예산도 확인하며 helper는512MiB·120초·취소 시 종료/회수 규칙을 유지한다.
임시 입력은 지정한 로컬 scratch를 사용한다. 기본 편집/저장과 모델 등록은 별도다.
계정/다운로드/원격 서버/서버 폴백/사용 통계는 없다.

기존5개 실제 ONNX 어댑터·투명도/힌트·원본 보존/1회 Undo 시험에 캐시 설치·명세
고정·고지 확인 전 거절·미확인 고지/손상/중복/공간 부족·폴더 이동 후 등록 복원·
등록 해제 시 파일 보존·설정 RAM 한도·실제 UI 확인/설치 버튼을 추가했다.
test-local-model-bundles는 설치본이 실제 만든5개 등록/캐시의 명세/가중치/고지 해시,
크기·형식·상대 등록·임시 잔류0을 독립적으로 대조한다. 모델은 직접 작성한 결정적
시험 자료이며 외부 사전학습 가중치를 배포하거나 그 품질을 검증했다고 주장하지 않는다.
