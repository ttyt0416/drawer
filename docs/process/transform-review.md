# 165 — 변형 확정/취소·저장 확인·종횡비·미리보기 품질

확대/회전, 자유/원근/액화, 메시/퍼펫, 이미지/벡터 소스 변형은 원본 스냅샷의 별도 작업에서 계산한다. 변형 종류별 매개변수/대상/선택 방식과 미리보기 품질을 함께 고정하며 문서 ID/수정번호/프레임 또는 전체 옵션이 바뀐 결과는 버린다. 화면을 계속 그려 Cancel/닫기/Escape를 처리한다. 래스터 그룹/선택 픽셀/변형 출력/선택 마스크 재계산은128픽셀 간격의 중단 검사를 제공한다. 작은 소스 기하 준비는 전후에서 중단을 확인한다. 실패/취소는 원본 픽셀·선택·레이어/개체를 변경하지 않으며 이전 준비 결과를 재사용하지 않는다.

공통 미리보기 품질은 Fast48/Normal96/Fine192 축 한도의 표시용 표본 수다. 원본 문서보다 확대해 표본을 만들지 않는다. 품질은 최종 변형 기하/픽셀 계산과 분리하므로 최종 출력은 같으며 작업공간256MiB와 기존 커널/Undo/장면 한도를 유지한다. 선택 픽셀의 Hard edges/Smooth edges는 별도의 실제 재표본 정책이며 일반 그룹/소스는 기존 종류별 보존/래스터 변환 정책을 유지한다.

확대/회전과 소스 크기 변경의 Keep aspect ratio는 한 축 편집 시 기존 두 축 배율의 절댓값 비를 유지한다. 각 축의 반전 부호는 독립적으로 유지하며 허용 수치 범위를 넘으면 연결된 배율을 함께 제한한다. 잠금을 끄면 두 축을 따로 바꾼다. 자유/원근의 개별 꼭짓점은 이 비율 잠금과 구분된다. 원근 창의 Perspective depth는 정규화한 중심 기준 분모1+depth×(2y−1)로 두 좌표를 투영한다. 범위±0.9와 최종 사각형/지평선 검증을 적용한다. 깊이·비율·미리보기 품질은 각각 다른 제어다.

미확정 변형 중 저장/다른 이름 저장은 Apply prepared transform and save, Discard transform and save original, Keep editing — cancel save를 보여준다. 준비되지 않은 값·다른 문서/프레임/대상·변경된 옵션은 적용할 수 없다. 소스 변형의 기존 검토 확인도 유지한다. 파일 이름이 필요하면 선택을 먼저 마친 뒤 적용/취소한다. 파일 선택 취소와 Keep editing은 미리보기/원본/선택/Undo를 그대로 유지한다. 확정/저장은 전체 한 Undo, 취소/원본 저장은 문서 이력을 바꾸지 않는다. 저장 실패는 성공으로 표시하지 않으며 이미 확정한 변형은 문서의 변경 상태와 Undo로 남는다. 이후 원본의 일반적인 저장/재열기 계약을 공유한다.

동시에 다른 변형 초안을 시작하려면 기존 변형을 먼저 확정/취소한다. 계산을 취소한 작업이 남아 있으면 중복 작업을 시작하지 않고 중단 완료를 기다리도록 안내한다. 미리보기 매개변수/이미지는 임시이며 확정한 기하/픽셀/선택만 기존 자체 형식에 저장한다. 자체 형식 버전은 이 항목에서 추가하지 않는다.
