# 팁별 질감·반전과 수채 종료 경계

기능080. 주 브러시 시퀀스의8슬롯은 각각 팁 좌우/상하 반전과 선택적 질감 재정의를 저장한다. 여러 팁이 꺼지면 슬롯0이 현재 팁이다. 순서 이동/삭제는 팁ID와 슬롯 설정을 함께 이동한다. 보조 브러시에도 독립 반전/질감 재정의를 제공한다. 주 팁 반전은 보조 팁을 뒤집지 않는다. 등록 이미지·섬유·Pencil grain·장식의 팁 좌표를 반전하고 기존 회전/종횡비 좌표 변환을 유지한다.

각 질감은 기존 로컬/자체 패턴과 배율·각도·오프셋·강도, Document 또는 Tip 좌표, 질감 반전, 밝기[-1,1]/대비[-1,1], 독립 밀도 합성 모드를 저장한다. Tip 좌표는 정규화 팁의 ±1을 명목128픽셀 그리드의 ±64로 대응한다. Document는 문서 픽셀이다. 표시 확대/회전/미러는 문서 결과를 바꾸지 않는다. 밝기는 더하고 대비는0.5 중심의1+contrast 배율로 조정해0–1로 제한한다.

10모드의 두 값 a=원래 팁 밀도,b=조정된 질감에 대한 결과는 Normal=b, Multiply=ab, Subtract=max(0,a-b), Compare=max(a,b), Outline=a×질감의4이웃 최대 차이, Overlay/Color dodge/Color burn/Hard mix는 두 잉크에서 정의한 분리 스칼라 합성, Height=(a+b)/2다. 원래 밀도0 밖으로 확장하지 않고 원래/결과 사이를 질감 강도로 보간한다. Outline은4이웃을 추가로 읽고 작업량에 포함한다. 레이어의 합성/종이 질감과 다른 브러시 밀도 단계다.

슬롯/보조 팁에 재정의가 없으면 기존 brush texture의 최종 적용 경로를 정확히 유지한다. 활성 팁에 새 재정의가 하나라도 있으면 팁마다 질감을 적용한 뒤 두 잉크를 합친다. 이 모드의 상속 질감은 기존 brush texture의 Multiply이며, 선택적 재정의의 No texture는 그 팁의 상속 질감을 끈다. 사용하지 않는 슬롯/비활성 보조 팁의 설정은 현재 그리기를 바꾸지 않는다. 선택/전체 농도/클리핑은 기존 최종 단계에 남고 수채 확산에서 상속 질감을 다시 곱하지 않는다.

Watercolor edge 강도0–1은 Normal 수채에서만 쓰며 기본0이다. 정상 종료에서 기존 확산을 마친 뒤 바뀐 알파0 초과 픽셀의4이웃 중 획에 속하지 않는 곳과 접한 한 픽셀 테두리를 찾는다. 해당 RGB를 `1 - 0.5×강도×전체농도×선택coverage`로 한 번 낮추고 알파는 그대로 둔다. 이는 확정 중인 결과에 대한 경계 색 후처리다. 문서/배치 레이어 밖·선택0·완전투명/변경 없는 픽셀은 처리하지 않는다. 반복 종료 호출 방지, 취소, 할당/픽셀 작업량 한계를 검사한다.

옵션이 켜진 유효 수채 획은 포커스 상실에서도 정상 종료와 같은 결과로 확정한다. 다른 pending 획은 기존 포커스 취소를 유지하며 Esc/명시적 취소는 수채도 원본으로 돌아간다. 포커스 종료 시 입력 소유권/장치 접촉을 비워 뒤늦은 Move/Up이 재시작하지 않는다. 후처리는 같은 획의 한 Undo/Redo이며 재열기/Redo에서 재계산하지 않는다. 팝업 시험 영역은 기존 창/포커스 취소 규칙으로 원본 시험 픽셀을 보존한다.

버전29 문서의 고정 Style/확정 픽셀, 프리셋/사용자 도구/로컬 설정에 슬롯과 질감·수채 경계를 저장한다. 구형 누락은 빈 슬롯·보조 반전끔/재정의없음·경계0이다. 로컬 휴대 묶음은 현재/기본값의 슬롯/보조 질감 참조까지 포함해 검증/새ID 재매핑한다. 재실행에 소재가 없으면 누락을 표시하고 저장 픽셀은 유지한다.

검증: 비대칭 자체 마스크의 정확한 픽셀 반사·두 슬롯의 서로 다른 좌표/배율/각도와 개별 기준 결과·보조 팁 독립성·밝기/대비/좌표/양축 반전/배율/회전 각각의 변화·10모드 수치와 생산 입력·표시 확대/회전/미러에서 문서 결과 동일·후처리 전후 알파 불변/중앙 보존/반복 종료 불변·정상/포커스/Esc 경로·단일 Undo/Redo/문서 재열기·프리셋/재시작/소재·휴대 묶음 질감 참조·구형 기본값/잘못된 값·회전으로 생긴 작은 음수 반복 좌표의 경계를 확인한다. 반복 좌표가 부동소수 반올림으로 배열 크기와 같아질 때는 마지막 texel로 제한하며 자체 패턴 그리드도 같은 경계를 사용한다. 실제 펜 센서 검증은 대기다.

작업공간의 큰 입력 설정은 힙에서 소유하고 설정 복사는 독립 복제한다. JSON의 input 객체 형식은 그대로다. 팁별 설정이 늘어도 여러 임시 작업공간이 기본 스택에 큰 배열을 누적하지 않도록 했다.

완전 회전과90도 단위 회전은 정확한 정수 축 행렬을 사용해 미세한 삼각함수 오차가 옆 texel을 고르지 않도록 한다. 자체 패턴과 등록 이미지의0/±360/90/180/270도 결과를 정확한 좌표 회전 기준과 비교했다.
