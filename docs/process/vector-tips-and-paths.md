# 145 — 그린 후 팁 모양 변경과 벡터 경로 표시

Change vector tip은 선택한 벡터 획의 팁 스타일을 Round / Flat oval / Square / Diamond 중에서 바꾼다. 네 프리셋은 프로그램에 포함된 자체 기하 정의이므로 클라우드·외부 팁 파일 없이 문서를 재열 수 있다. 없는 프리셋 이름은 적용 전에 오류로 알리고 원본을 유지한다. 저장 문서에서 알 수 없는 스타일은 조용히 다른 팁으로 치환하지 않고 형식 오류로 거절한다.

기본 원형은 기존 원판의 연속 합, Flat oval은 세로 반경이1/3인 타원의 연속 합이다. Square와 Diamond는 네 반평면 조건을 만족하는 선분 매개변수 구간을 교차해 선형 가변 반경의 실제 휩쓴 영역을 계산한다. 채움·중심 경로·논리 제어점·독립 접선·장치 압력·편집 배수·기본 선폭·RGBA는 그대로 유지한다. 미리보기와 Apply는 기존 수치 편집기를 공유하며 적용은 한 Undo다. 문서v67에 선택한 팁을 저장하고 비원형 스타일을v66 이하 헤더로 위장하면 거절한다. 기존 문서는 Round로 읽는다.

벡터 출력과 화면·픽셀 조회는 같은 실제 팁 영역을 사용한다. 지우개는 Flat의 변환 타원, Square/Diamond의 변환 사각형 단면에 대한 거리를 사용해 접촉 범위를 정한다. 비균등/기울임 변환에서도 원형 단면으로 잘못 치환하지 않는다. 분할·단순화·밀기·지우기에서 프리셋을 유지하고 다른 팁끼리의 단순 연결은 거절한다. 스타일이 서로 다른 획의 연결 정책은150번이다.

Show/hide vector paths 명령으로 그리는 동안 경로 표시를 켜거나 끈다. Vector path display에서는 선택한 벡터층 또는 모든 벡터층, 열린 끝점만/모든 논리 제어점/점 없음 범위를 고른다. 닫힌 선에는 열린 끝점이 없으므로 끝점 모드에서 점을 표시하지 않는다. 숨김층은 제외하며 잠긴 층의 경로는 표시할 수 있다. 잠금층을 편집 가능하게 바꾸는 기능은 아니다. 편집 도구가 표시하는 조작 핸들은 별도 안내다.

경로와 점은 문서 변환·확대율·화면 배율을 거쳐 같은 화면 좌표로 옮긴다. 경로8192점/128획 한도 안에서 읽기만 하며, 밀집한 제어점은 화면4포인트 격자마다 하나씩 표시한다. 실제 제어점이나 선택 후보를 합치거나 이동하지 않는다. 오버레이는 입력을 가로채지 않는다. 표시 범위·점 종류·켜짐은 로컬 작업공간에 저장하고 문서·선택·Undo·내보내기 픽셀에는 포함하지 않는다.
