# 3D 배치·관절형 포즈·문서 카메라 (213)

`world3d` 창은 로컬 문서의 3D 개체와 카메라를 편집한다. 내장 참조 모델은 이 프로젝트에서 직접 정의한 세 직육면체의 바닥/두 관절 링크다. `Place local reference model`로 배치를 미리 보고 `Apply 3D preview`로 문서에 채택한다. 기존 3D 레이어도 편집하며 인체 체형/스키닝·외부 모델 형식·조명/표면 스타일은 해당 후속 항목에서 다룬다. 현재 표시와 PNG 출력은 공통 와이어프레임 렌더를 사용한다.

## 선택·조작기와 포즈

선택 목록의 클릭 순서를 보존해 첫 선택을 명시한다. 이동/회전·포즈/축척을 X/Y/Z 조작기로 드래그하거나 상대 수치를 입력해 미리 본다. 드래그를 놓으면 원본을 유지한 준비 상태로 남고 Apply 한 번이 한 Undo다. 다음 드래그 전에 현재 미리보기를 Apply하거나 Discard한다. Discard/Esc·포커스 상실·창/문서 닫기와 문서 ID/리비전 변경은 초안을 버린다. 원본이 바뀐 뒤 준비 결과를 덮어쓸 수 없다. 다른 확정 전 그림/텍스트/변형 편집이 있으면 먼저 마무리해야 한다.

Floor axes는 월드 X/Y/Z, Object axes는 누적 개체 변환의 길이를 정규화한 축이다. 비균등 축척과 회전으로 생긴 기울어진 기저를 유지하며 회전 각도로 다시 분해하지 않는다. 회전은 선택한 각 축 방향을 기준으로 수행하고 축척은 개체 기저에 맞춰 적용한다. 방향 반전을 포함한 음수 축척을 허용하고 절댓값0.0001..10000 범위,0·비유한 값·특이/불안정 행렬·누적 프레임 성분1e9 초과를 거절한다. 이동/회전 입력은 절댓값1e6 이내다.

피벗은 각 개체의 관절 피벗, 선택된 개체의 월드 경계 상자 중심, 첫 선택의 관절 피벗이다. 공통 피벗일 때도 개체 축은 각 선택 루트의 축이다. 회전 간격0은 스냅 해제, 양수는0..180도 범위에서 가장 가까운 간격으로 맞춘다. 축/피벗/모드/간격을 바꾸는 일은 모델·문서 이력·dirty를 바꾸지 않는다. 로컬 `settings/world3d.json`에 저장·재시작 복원한다.

부모 연결은 관절형 모델의 강체 부분을 묶는다. 하위 링크를 선택해 회전하면 그 관절과 자식의 포즈를 바꾼다. 부모를 움직이면 하위 개체 전체를 함께 이동한다. 부모·자식을 함께 선택했을 때 자식은 부모를 통해 한 번만 움직이며 별도 선택 루트로 다시 적용하지 않는다. 연결 설정/해제는 월드 위치·회전·축척을 유지하고 순환과16개를 넘는 부모 연결을 거절한다. 부모 삭제는 남은 자식을 현재 월드 포즈로 분리하며 Undo가 관계까지 복원한다. 잠김/위치 잠김/픽셀 잠김/숨김 개체를 포함한 편집을 거절한다.

## 카메라와 저장

문서 카메라는 위치·X/Y/Z 회전·페이지 사각형·원근 FOV/직교 픽셀 단위·near/far를 가진다. 카메라의 앞 방향은 로컬 -Z, 위는 +Y다. 원근 FOV는 세로1..179도다. near>0,far>near,far<=1e9이며 직교 배율은1e-6..1e6이다. 깊이 범위 밖 점/선은 표시하지 않고 경계를 통과하는 선은 교차점까지 자른 뒤 투영한다. 카메라 변경도 미리보기 후 한 Undo다. 문서 화면/합성/스포이트·래스터 변환/PNG는 같은 투영 선분을 사용한다. 기존 카메라 정의만 있는 문서는 이전 직교 표시를 유지한다. 새 카메라의 페이지 범위는 보존된 페이지 좌표계로 계산해 크기 변경/이동 뒤에도 문서 중앙에 배치한다. 2D 촬영 보기의 원본 편집 보호를 지키며 카메라 원본 수정은 base content 편집에서 수행한다.

native107은 개체의 월드 프레임/부모 ID와 렌즈를 저장한다. 메시 정점은 기존 월드 좌표 원본이며 편집 시 프레임·정점을 함께 갱신한다. 새 정보가 있는 파일을106 이하 버전으로 위장하면 거절한다. 모델 삭제/ID 변경 때 관계를 정리하고 문서/Undo·4MiB 장면 메타데이터 한도를 유지한다. 계산 전 문서 사본 예산3배와 정점+선524288개 작업 한도를 확인하고 준비·개체 처리 경계에서 취소 신호를 검사한다. 새 3D 메타데이터의 저장/재열기에도 같은 기하 한도를 적용해 투영 캐시를 제한한다. 외부 다운로드·자동 원본 변경은 없다.

## 검증

서로 다르게 회전한 세 개체의 첫 선택 순서·90도 스냅·개체/바닥 축, 개별/공통 피벗·비균등/음수 축척·기울어진 변환 역행렬·Undo/Redo, 부모/자식 중복 없는 이동과 잠긴 하위 개체·부모 삭제/복원·숨김/위치 잠금 층의 기존 삭제 정책·16/17단계·빈 입력/0축척·예산/취소/오래된 결과를 검사한다. 기존 레이어 이동의 카메라 평면/관절 이동과 복제 시 축/피벗/부모 ID 재연결도 검사한다. 크기 변경된 페이지의 새 카메라 중앙과2D 촬영 보기/원본 편집 보호도 검사한다. 원근/직교 좌표·회전 카메라·near/far 교차 선분의 실제 끝점, 실제 PNG 색/투명 픽셀·클리핑과 카메라 Undo,107 저장/재열기·구버전 위장 거절·로컬 기본값을 대조한다. 앱/설치본은 합성 포인터 참조 배치/검토 적용·축 드래그 동안 원본 불변/놓기/한 Undo·수치 미리보기 Esc·옵션/재시작·원본 수정/문서 닫기를 확인한다. 실물 펜 검증은 별도 대기다.
