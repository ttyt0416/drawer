# 로컬 애니메이션 출력

`animation-export`는 문서 수정 번호, 전체 상태, 공유 셀/소재/파일 개체의 불변 캐시, 프로파일, 선택 마스크, 포함 옵션, 로컬 워터마크 PNG의 바이트 해시·디코딩 픽셀과 노이즈 시드를 캡처한다. 출력 프레임/컴프 계산은 별도 Document에서 수행한다. 이후 그림·소재 갱신·워터마크 파일 변경·플레이헤드 이동은 캡처에 반영하지 않는다. 출력·취소는 문서 픽셀/현재 프레임/선택/보기/dirty/그림 이력을 바꾸지 않는다.

전체 캔버스, 선택 마스크 경계, 출력 프레임들의 합집합, 캔버스와 보존된 오버플로 내용의 합집합을 선택한다. 범위 전체의 정수 픽셀 경계와 원점을 한 번 고정하므로 모든 프레임 크기가 같다. 선택이 없거나 비었으면 선택 출력을 거절한다. 카메라 끄기는 최종 2D 촬영 변환만 해제하며 기존 부모 리그를 유지한다. 첫 프레임 미리보기에는 선택한 카메라·포함 조건을 실제로 적용한다.

밑그림, 만화 프레임선/인쇄 가이드, 라이브 드롭 섀도, 용지 배경 제거/투명, ICC 포함을 선택한다. 중첩된 편집 셀/페이지에도 같은 포함 정책을 적용한다. 이미 픽셀에 구운 그림자는 원본 픽셀이므로 제거하지 않는다. 불투명 출력과 H.264는 선택한 바탕색 위에 합성한다. ICC 생략 또는 GIF/동영상은 sRGB로 변환해 프로파일 없는 작업공간 숫자를 그대로 내보내지 않는다. 어니언/라이트테이블/카메라 경로 같은 화면 가이드는 포함하지 않는다.

PNG 연속 이미지에는 원래 프레임의 1부터 시작하는 `frame-000001.png` 번호와 v2 `animation.json`(원점·크기·수정 번호·유리수 FPS·범위·형식·반복·포함 옵션·시드·워터마크 해시)을 쓴다. APNG는 동일 메타데이터와 RGBA, Source/None 프레임, 기약분수 u16 지연을 사용한다. 표현할 수 없는 지연은 PNG 연속 출력을 안내한다. GIF는 프레임마다 최대256색, 알파128 미만 투명/그 외 불투명, ICC 없음이다. GIF10ms 및 WebP1ms 지연은 누적 경계 반올림의 차분으로 계산해 프레임별 반올림 오차 누적을 막는다. 0이나 형식 한도를 넘는 지연은 거절한다. 뷰어의 최소 지연 정책은 별도다. WebP는 RGBA VP8L 무손실 프레임과 ANIM/ANMF 컨테이너, 전체 프레임 덮어쓰기·폐기없음을 사용한다. 투명 RGB의 비시각적 정규화는 허용하되 알파와 가시 RGB를 검증한다. 이미지 애니메이션에는 오디오가 없으며 WAV 출력을 안내한다.

로컬 출력 프리셋 JSON을 저장/불러올 수 있다. 불러오기는 실행 권한이나 덮어쓰기 확인을 복원하지 않으며 인코더 검증을 다시 요구한다. 워터마크 위치는 출력 이미지 좌표이고 노이즈는 시드와 출력 x/y만 사용해 모든 프레임에서 고정된다.

동영상에는 설치된 로컬 FFmpeg/FFprobe7.1만 연결한다. 내려받거나 배포하지 않는다. 사용자가 선택한 경로 또는 PATH 발견 경로를 표시하고 명시 검증한다. `-encoders`에서 후보를 찾고 실제16×16 두 프레임·30000/1001fps·48kHz 스테레오 PCM을 인코딩/프로브/디코딩한다. FFV1/MKV/BGRA+PCM은 RGBA 일치, H.264/MP4/yuv420p+AAC는 불투명·색오차 한도와 스트림을 검사한다. 성공한 조합만 선택 목록에 넣는다. Chocolatey의 작은 실행 래퍼는 실제 설치 실행 파일로 해석하고 그 경로를 표시한다. 그 외 작은 래퍼는 실제 실행 파일을 선택하도록 거절한다. 검증 때 실제 실행 파일 해시를 고정하고 출력 전후 변경을 거절하며 취소 시 해당 인코더 프로세스를 종료한다. H.264는 짝수 크기가 필요하며 색/알파/AAC 손실을 확인한다. 출력 오디오는 캡처된 클립·볼륨·뮤트의48kHz 스테레오 믹스를 사용한다. 인코더가 없거나 검증에 실패하면 PNG 연속+WAV 대안을 표시한다.

출력 파일은 같은 부모의 개인 폴더에 준비해 다시 디코딩/크기/프레임/시간을 검사한 뒤 게시한다. 단일 애니메이션 파일은 전체 준비 후 원자적 교체하고 기존 파일은 명시 확인 및 시작/게시 직전 해시 일치가 필요하다. PNG 연속 출력은 새 폴더만 허용하고 검증된 프레임을 하나씩 배타적으로 게시한다. 취소/실패 전에 완성된 PNG는 보존하며 개인 미완성 파일만 정리한다. 사용자용 출력은 고유 이름의 영구 `drawer-output-*.json` 영수증에 설정·완료 파일·미완료 파일·오류/취소를 남긴다. 영수증은 임시 파일이 아니며 출력 폴더에 남는다. 파일 자체의 실패로 영수증 기록까지 불가능하면 화면에 오류를 표시한다. 외부 파일은 문서 Undo로 삭제하지 않는다.

범위10000프레임, 축32768픽셀(WebP16384), 문서/출력 메모리 예산, 중간 PNG 합계2GiB, 기존 교체 파일512MiB, 로컬 인코더 실행별120초·출력2GiB 제한을 적용한다. 원본 문서·캡처한 워터마크·연결 파일 개체/오디오 소스 경로로의 출력은 보호한다. 개인 준비 폴더에 모르는 파일이 들어와도 재귀 삭제하지 않는다.

컨테이너 근거: [WebP 공식 컨테이너 규격](https://developers.google.com/speed/webp/docs/riff_container), [GIF89a 규격](https://www.w3.org/Graphics/GIF/spec-gif89a.txt), [FFmpeg 공식 명령 문서](https://ffmpeg.org/ffmpeg-all.html). 라이브러리는 기존 잠금 버전 gif0.14.2·image-webp0.2.4·png0.18.1을 사용한다.
