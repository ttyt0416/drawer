# 로컬 애니메이션 파일 출력

`animation-export`는 문서의 선택한 시작/끝 포함 범위와 FPS를 고정한다. PNG 연속 이미지와 APNG를 지원한다. 파일 출력은 문서/현재 프레임/보기/그림 이력/dirty/연결 경로를 변경하지 않는다. 이후의 일반 셀·공유 원본·픽셀 편집과 플레이헤드 이동도 고정된 결과에 반영하지 않는다.

PNG 연속 파일은 원래 프레임의1부터 시작하는 번호를 `frame-000001.png`처럼 쓰고 자체 v1 `animation.json`에 수정 번호·크기·유리수 FPS·0부터 시작하는 포함 범위·형식·반복·RGBA 정밀도·파일 목록을 기록한다. 새 폴더만 허용한다. APNG는 같은 정보를 텍스트 청크에 넣고 전체 프레임 Source 합성/None dispose로 투명 픽셀을 대체한다. 무한 반복0 또는 완전 재생 횟수를 쓴다. FPS를 기약분수로 줄여 지연 분자/분모가 u16에 정확히 들어갈 때만 허용한다. 30000/1001은 지연1001/30000으로 보존한다. 해당하지 않는 경우 PNG 연속 출력을 안내하며 조용히 시간값을 양자화하지 않는다.

이미지 형식에는 오디오를 넣지 않는다. 두 경로는 기존 PNG 출력기와 동일한8비트 RGBA/프로파일 정책을 사용한다. 고정밀 원본은 출력에서만8비트로 양자화하므로 화면에 표시하고 확인을 요구한다. 부동소수점/ICC 색공간의 숫자와 ICC를 함께 보존한다. 캔버스 전체를 출력하며 화면 어니언/편집 트랙만 보기 등 임시 가이드는 포함하지 않는다. GIF/WebP/동영상과 별도 영역/카메라 옵션은 이 형식 패널에서 지원한다고 표시하지 않으며 기능204는 미완료 상태를 유지한다.

동일 부모의 새 소유 폴더에 모든 PNG와 APNG를 준비하고 취소 플래그를 프레임 전후 및 인코딩 사이에 확인한다. 최대10000프레임·기존 문서/출력 메모리 한도·중간 PNG 합계2GiB를 적용한다. 준비 폴더의 소유 파일만 삭제하고 낯선 파일은 재귀 삭제하지 않는다. PNG 폴더 전체 또는 APNG 파일 하나를 마지막에 원자적 이름 변경으로 게시한다. APNG 덮어쓰기는 명시 선택이 필요하며 시작/게시 직전 기존 파일의 해시를64KiB 버퍼로 계산/비교해 늦은 변경을 거절한다. 기존 경로가 디렉터리/링크거나 파일이512MiB를 넘으면 덮어쓰지 않는다. PNG 폴더가 렌더 중 나타나도 거절한다. 취소된 배치는 게시된 완료 파일0개이고 개인 준비 파일만 제거한다. 최종 게시 뒤의 취소는 완료 출력을 되돌리지 않는다.

검증은 투명/반투명/완전 불투명, ICC, 반복 셀/한 프레임·29.97fps, 디코딩된 PNG/APNG 픽셀/시간/반복 일치, 원본 편집 후 스냅샷 불변, 잘못된 범위/예산/정확히 표현 못하는 지연 거절, 취소/늦은 경로 충돌/기존 파일 보존·명시 덮어쓰기와 실제 포인터 캡처/확정/출력 경로를 사용한다. 기존 고정 전이 의존성 png0.18.1을 직접 사용하며 새 라이브러리 버전을 추가하지 않는다.
