# 128 — 래스터화·밝기 알파·현재 RGB

비파괴 편집 가능한 소스를 현재 해상도의 실제 RasterLayer로 교체한다. 벡터/텍스트·소재/도형/그라데이션/3D는 원래 개체 합성 위치를 보존하는 render_order 항목을 사용한다. 순서는 그라데이션·개체·벡터·3D 그룹을 유지한다. 해당 래스터는 기본 래스터 합성에서 제외하고 그 위치에서 한 번만 그린다. 벡터 묶음은 기존 고정 알파 합성을 사용하며 클리핑 기준과 같은 묶음을 함께 변환한다. 선택·검색 순서·썸네일·칠하기·복제·삭제·새 개체 추가·전체 합치기/Undo와 네이티브 저장을 연결했다. 일반 래스터/폴더 스택으로 명시 이동하면 별도 위치를 해제한다. 부분 합치기/클리핑은 먼저 일반 스택으로 옮기도록 안내하며 전체 합치기는 현재 합성을 보존한다.

래스터는 원래 불투명도와 혼합을 유지하고 표시 효과·표현색·종이질감·마스크만 픽셀에 굳힌다. 내재 소스 샘플러는 레이어 불투명도와 클리핑 관계를 중복 적용하지 않는다. 벡터 묶음과 기타 개체는 기준층의 불투명도를 일시100으로 샘플링한 뒤 그 속성을 새 래스터에 보존한다. 기준 혼합은 배경에 한 번 적용한다. 원래 데이터와 제어점은 Undo가 복원한다. 연결 소스는 마지막 캐시를 사용하고 링크를 소비하되 외부 파일을 삭제하지 않는다. 보정은 배경 없이는 독립 픽셀이 없으므로 병합을 안내한다. 애니메이션은 기존 현재 프레임 전체 합치기를 사용한다.

문서v56은 안정 래스터 키와 원래 소스 그룹/합성 순서를 저장한다. 그룹은 정렬되고 키가 중복될 수 없다. 존재하지 않는 래스터·원래 그룹의 잘못된 소스·폴더 안에 이중으로 배치한 대체 래스터·벡터 클리핑 묶음을 가르는 순서·대체 래스터의 미지원 새 클리핑은 거부한다. 그림을 변경한 뒤에도 새 개체가 같은 종류의 위쪽에 추가되고, 삭제/전체 합치기는 소비한 순서를 제거한다. PSD의 레이어 저장은 이 추가 순서를 지원한다고 주장하지 않고 렌더된 이미지 저장을 안내한다. PNG/PSD 렌더된 결과는 공통 렌더러를 사용한다.

Gray 밝기는 round((54R+183G+19B)/256), Mono는 밝기128 이상을255로 한다. 밝기 알파는 round(A*(255-Y)/255), 잉크RGB는0이다. 부분 선택은 알파를 선형 혼합하고 RGB는 반올림 전의 알파 가중 합으로 나누어 흰색을 회색으로 오염시키지 않는다. 현재 RGB 변경은 선택 강도로 RGB만 보간하고 원래 알파를 유지한다. 벡터는 선택한 경로의 선/채움 RGB만 바꾸며 각각의 알파·기하·정의/필압 윤곽은 유지한다. 투명 픽셀/스타일 RGB는0으로 정리한다. 그리기색의 알파는 이 명령의 대상 알파를 바꾸지 않는다.

검증은 겹친 반투명 배경·텍스트/도형·다중 벡터/혼합·3D의 전후 전체 픽셀 비교, 실제 글리프, 클리핑 알파128 고정, 마스크/표시 효과·불투명도 유지, 회색117/흑백과 알파128, 검정/중간/흰색·부분 선택의 독립 기대값, 현재 RGB 보간140/70/110/128·선택 밖/투명RGB0, 필압 윤곽과 선택하지 않은 경로 불변을 포함한다. 실제 UI Preview/Apply/Undo·변환층의 마우스 칠하기/Undo·래스터/벡터 RGB·밝기 알파·프레임 변경/Escape·재열기를 검사한다. 잘못된 순서는 기존 파일을 손상시키지 않는다.

한 번의 확정은 한 Undo이다. 대화상자는 문서/리비전/프레임과 작업공간 예산을 고정하고 변경 시 미리보기를 무효화한다. 변환 영역4Mi 픽셀·32768차원, 비교복잡도64Mi 작업과 문서/이력/JSON 한도, 렌더를 위한128MiB의 여유를 확인한다. 경계 계산용 캐시와 캡처 스냅샷/렌더러를 다음 단계 전에 해제한다. 표현색 변환은 의도된 색 변화이고 Color 래스터화는 전체 RGBA 차이1 이내를 요구한다.
