# 로컬 참고 이미지

참고 창은 PNG 파일과 운영체제의 이미지 클립보드를 지원한다. 참고의 픽셀은 읽기 전용이며 보기 확대·이동·회전, 목록 전환과 색 추출은 편집 문서의 픽셀·선택·변경 표시·실행 취소 이력을 바꾸지 않는다. 현재 PNG 읽기는 RGBA8 픽셀 기준이고 색상 프로필 해석은 후속 파일 형식 항목에서 구현한다.

참고를 추가하면 사용자 소재 폴더의 `references`에 PNG 복사본을 저장한다. 복사본과 원본이 모두 없거나 읽을 수 없으면 목록을 유지하면서 이유를 표시한다. Remove는 참고 연결을 제거하며 원본과 보존 복사본을 삭제하지 않는다. 복사본은 설정 복원·실행 취소에 필요하며 임시 파일이 아니다.

작업공간의 목록·순서·활성 참고·참고별 보기·색·자동 스포이트/링·창 위치와 크기는 버전형 JSON 설정에 저장한다. 저장 전에 직전 정상본을 보존한다. Undo/Redo settings, Restore previous와 Reset references를 제공한다. 손상 설정은 이유를 알리고 기본값으로 시작하며 다음 설정 저장 전에 손상본도 보존한다.

Save set은 설정과 PNG 픽셀을 함께 `.drawrefs`에 넣는다. 원본의 절대 경로를 넣지 않으며 다른 로컬 사용자 폴더에서 Load set으로 복원한다. 가져오기 실패 시 기존 목록과 픽셀을 유지하고 이번에 만든 복사본만 정리한다. 형식은 `DRAWREF1`, u32 JSON 바이트 수·JSON, 목록 순서대로 u64 PNG 바이트 수·PNG이며 정수는 little endian이다. 최대 참고 64개, 디코드 픽셀 합계 64 MiB, 설정 1 MiB, 묶음 128 MiB다.

스포이트는 변환 전 원본 픽셀의 RGBA를 읽는다. 알파가 0이어도 RGB를 보존하며 미리보기 링은 투명도를 표현한다. 자동 스포이트는 참고의 이미지 영역에만 적용한다. 마우스와 가상 접촉 입력은 같은 좌표 변환을 사용한다. 실제 펜 장치 시험은 사용자 요청에 따라 후속 장치 검증에 둔다.

Open as new drawing은 같은 픽셀과 크기의 독립 미저장 문서를 만든다. 원본/참고 경로에 연결하지 않으며 새 이력으로 시작한다. 클립보드 API 연결은 빌드했으며 이미지/빈 입력·실패 처리는 시험 입력으로 검증한다. 시험 중 사용자의 실제 클립보드를 읽거나 덮어쓰지 않는다.
