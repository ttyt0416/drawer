# 160 — 색수차·필름풍·연필풍

Chromatic aberration은 문서 픽셀 기준±32px의2축 이동과 강도0–1을 제공한다. 빨강은 이동의 반대 위치, 초록은 현재 위치, 파랑은 이동 위치에서 읽는다. 출력 알파는 채널별 알파의 최대이고 각 채널 RGB×알파를 출력 알파로 나눈다. 따라서 투명색을 가져오거나 검정 경계와 섞지 않는다. 강도로 원본과 premultiplied 혼합한다. 알파 잠금이 없으면 축별 이동량만큼 저장 경계를 늘려 캔버스 밖 결과를 보존한다. 잠금은 기존 경계/알파 안에서 색만 바꾸고 완전 투명 원자료를 유지한다.

Film은 강도0–1, 대비0–1, 페이드0–1, 색온도−1–1, 입자0–1, 정수64비트 시드를 받는다. 대비는 원래 값과3v²−2v³ 곡선을 섞고 페이드는 흑백 양 끝을 안쪽으로 이동한다. 색온도는 빨강/파랑을 반대로 조정하며 동일한 결정적 입자를 RGB에 더한다. 모든 색은0–1로 제한하고 원래 알파를 유지한다. 같은 시드/좌표는 같은 입자이고 입자0은 시드와 무관하다. 시드는 정수 문자열 입력을 공유하며 반올림하거나 잘못된 입력을 이전 값으로 적용하지 않는다.

Pencil은 강도0–1, 윤곽0–2, 명암0–1, 표본 반경1–16px을 받는다.3×3 Sobel을 지정 반경 간격으로 계산하고 가로/세로 기울기를 윤곽 강도로 제한한다. 윤곽 계산의 밝기는 알파를 흰 배경 위에 놓은 값으로 하여 숨은 투명색을 제외한다. 명암은 흰색과 원래 가중 명도를 섞으며 윤곽과 독립적이다. 결과는 문서 RGB 회색이고 원래 알파/경계를 유지한다.

세 효과 모두 실제8/16비트·프로필·선택 밖 원자료·고정 마스크를 유지한다. 선택 coverage로 섞으며 강도0·색수차 이동0·모든 필름 보정0·빈 선택·무변화는 dirty/Redo/마지막 기록을 유지한다. 원본4M픽셀/32MiB·출력4M/축32768·64M표본·열린 문서의 남은256MiB 예산을 확인한다. 색수차3표본·필름1표본·연필9표본으로 사전 계산하고128픽셀마다 중단을 확인한다.
