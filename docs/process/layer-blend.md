# 기본 레이어 혼합 모드

일반·곱하기·스크린·오버레이는 문서가 보관하는 8비트 encoded RGB 채널을 작업 색으로 사용한다. ICC 소프트 프루프/모니터 변환은 합성 뒤의 표시 처리이며 혼합식을 바꾸지 않는다. 선형광 혼합이나 타사 수식 호환을 주장하지 않는다.

Cb/Cs는0–1의 아래/위 채널이다. 일반 B=Cs, 곱하기 B=Cb×Cs, 스크린 B=Cb+Cs−Cb×Cs, 오버레이는 Cb≤0.5에서2CbCs, 그 밖에서1−2(1−Cb)(1−Cs)이다. As=위 알파×불투명도, Ab=아래 알파, 출력 알파 Ao=As+Ab(1−As), premultiplied 채널은 (1−As)AbCb+(1−Ab)AsCs+AsAbB이다. 저장 픽셀은 건드리지 않고 합성 내부 float 계산 후 출력 RGBA에서 반올림한다. 내부 premultiplied float32 경계로 독립 정수 기준과 최대1 채널 오차를 허용한다.

래스터·벡터·폴더·애니메이션 트랙 단위 속성이다. 셀은 트랙 혼합을 따르며 셀 불투명도는 트랙 불투명도와 곱한다. 일반 폴더는 격리 합성하고 통과 폴더에서 일반 이외 모드를 고르면 격리 폴더로 전환한다. 클리핑 위층은 같은 B식을 source-atop으로 적용해 기준 알파를 유지한다. 기존 종이의 특수 붓 합성 설정과 함께 지정하면 명시한 일반 이외 레이어 모드가 우선한다. 외부 배경에 의존하는 층의 독립 베이크는 거절한다.

문서v48은 모드 식별자를 저장하고 이전 문서의 누락 값은 일반이다. 알 수 없는 식별자는 거절한다. Layers… → Layer blend modes에서 대상을 고르고 네 모드 버튼과 Apply changed properties로 적용한다. 다른 속성/원본은 유지하고 Undo 한 번으로 속성과 폴더 모드를 복구한다.

CPU가 실제 층 혼합을 수행하고 화면 GPU에는 완성된 이미지 한 장을 전송한다. 별도 GPU 층 혼합 수식은 없다. 자동 검증은64개 반투명 조합·36개 검정/흰색/중간값과 고정 RGB 예상값, 폴더/불투명도/벡터/클리핑·이전 값·재열기와 실제 모드/적용 버튼을 검사한다. 각 모드에서 실제 UI가 GPU 텍스처로 제출하는 8×8 픽셀 전부를 CPU 합성과 비교한다. 이 비교는 하드웨어 프레임버퍼 읽기 검증과 구별한다. 기존 문서·JSON·초안·이력 한도를 공유한다.
