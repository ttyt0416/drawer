# 099 — 색상 범위 선택

Color range는 추출한 현재색 또는 편집한RGBA와RGB 허용치0~255로 선택한다. 스포이트로 색을 고른 뒤 창의 Use current drawing color를 누르거나 색상 편집기로 색을 정한다. Current는 현재 래스터의 원본 RGBA,Composite는 현재 프레임의 표시 합성을 읽는다. 잠긴층도 읽을 수 있지만 그림 픽셀은 쓰지 않는다. 비래스터를 선택한 Current는 거절하며 Composite는 사용할 수 있다. 화면용 색상 교정/모니터/증명 효과는 비교에 포함하지 않는다.

연결성과 별개로 전체 캔버스를 검사하므로 떨어진 같은 색을 포함한다. 알파가0보다 큰 픽셀은 RGB의 최대 채널 차이가 허용치 이하이면 강도255로 선택한다. 원본 알파와 지정색의 알파는 색차에 섞지 않는다. Include fully transparent pixels를 켜면 숨은RGB와 무관하게 알파0 픽셀도 선택하고 끄면 제외한다. 허용치0은 정확한RGB,255는 모든 보이는 픽셀이다. 새 영역은 캔버스에 자르고 Replace/Add/Subtract/Intersect의 기존 부분 강도 공식을 적용한다. 선택 없음의 Add는 빈 선택에서 시작하고 Subtract/Intersect는 전체 캔버스를 기준으로 한다.

창은 초안이며 Apply가 문서ID/리비전/프레임과 고정 참조층을 확인하고 한 Scene Undo로 적용한다. Cancel/닫기/Escape는 원본과 로컬 옵션을 유지한다. 성공한 색/허용치/투명 옵션/참조/연산을 로컬 작업공간에 저장하며 이전 설정의 누락 필드는 기본값으로 복원한다. 선택 결과는 기존 마스크/최근 선택/이름 있는 마스크 층과 문서v34에 저장한다.

작업은4Mi 캔버스 픽셀과4Mi 원래 페이지 격자·32768변/run·추정64Mi 합성 참조 작업·Scene4MiB·문서/Undo 예산을 검사한다. 실패는 이전 선택을 보존한다. 입력 강도는 문서 격자에서 계산하고 원래 페이지4×4 표본으로 저장하며 기존 이동/변환/캔버스 밖 선택 합성을 공유한다.

자체5픽셀 자료로 떨어진 동일색·허용치0/1/255·알파128의RGB 일치·투명 숨은RGB99/80/60의 포함 옵션·부분128 선택과의 추가/빼기/교차·숨긴층의 합성 제외·누락/잘못된 참조 거절·픽셀 불변·한 Undo/Redo·문서 재열기를 확인한다. 실제 egui Apply 버튼의 Current/Composite·분리된 열 선택·취소/오래된 문서 거절·로컬 설정 재열기를 설치본에서도 검사한다.
