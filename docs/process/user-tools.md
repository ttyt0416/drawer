# 로컬 사용자 도구·분류·기본값과 참조

기능075. 일곱 내장 브러시 엔진을 기본 입력방식으로 선택해 독립 사용자 도구를 만든다. 각 도구는 고정ID, 분류ID, 현재 자체 Preset, 등록 기본 Preset, 지원 공통 속성과 그 기본 목록을 가진다. 선택 가능한 공통 속성은 크기/비율/각도/선 보정/농도/경도/간격이다. 지원하지 않는 속성은 공장값으로 고정하고 조작을 숨기거나 거절한다. 도구 입력의 다른 안료/동역학/팁 설정은 자체 프리셋 규칙을 따른다. 색은 기존 공통 그리기 색을 유지한다.

새 도구는 선택한 기본 엔진의 현재 설정 또는 공장 설정에서 만든다. 도구/분류 이름변경·복제·순서 이동, 여러 도구 체크선택과 일괄 복제/이동/삭제를 제공한다. 복제는 새ID와 독립 설정/기본값을 가진다. 분류 이름은 전체에서, 도구 이름은 같은 분류에서 대소문자 중복을 거절한다. 다른 분류에는 같은 도구 이름을 둘 수 있다. 이름은1~64문자/공백 정리/제어문자 불가이며 파일 경로로 쓰지 않는다. 최대32분류/64도구, ID는 증가하며 삭제 뒤 재사용하지 않는다. 빈 분류와 모든 분류가 빈 상태도 저장한다. 분류삭제는 다른 분류로 도구 이동 또는 소속 도구 함께 삭제를 명시적으로 고르며 충돌/잘못된 대상은 전체 변경을 거절한다.

현재 사용자 도구의 수치/입력 편집은 그 도구의 현재 Preset에 반영한다. 같은 기본 엔진의 다른 사용자 도구는 영향을 받지 않는다. 활성화 전에 원래 내장 브러시의 수치/입력과 속성 표시/조작 방식을 보관하고 내장 도구로 돌아갈 때 복원한다. 한 번에 활성 사용자 도구 하나만 보관한다. 장기 기본값/내장 도구 복원 자료는 고정 배열을 힙에 보관해 설정 복사로 스택이 커지지 않게 했다. 시작한 획은 기존 고정 Style/소재 Arc를 사용한다. 사용자 도구를 삭제해도 이미 그린 픽셀·획 이력·등록 이미지·기존 저장 브러시 프리셋은 바꾸지 않는다.

Register selected values as default는 도구 값과 지원 속성 목록을 등록하고 Reset은 이를 복원한다. 기본 엔진별 사용자 기본값도 별도로 등록/복원할 수 있으며 등록한 값이 없으면 공장값이다. 파괴적 도구/기본값 편집은 기존 Brush presets 임시본에서 진행하고 Apply가 전체 검증·설정 백업·저장을 수행한다. Cancel은 도구/분류/참조/문서를 유지한다. 활성 도구 삭제 시 공장 Pen으로 전환한다. 초기화/삭제로 기존 brush preset Book을 지우지 않는다. 저장 실패는 이전 선택/설정을 복원하고 원래 파일/외부 임시 파일을 보존한다.

도구 명령은 local-tool:ID로 고정하고 화면에는 분류/이름을 표시한다. 명령 선택기/키보드/빠른 접근/원형 메뉴/장치 지정과 도구 순환에서 같은 인스턴스를 선택할 수 있다. 이름변경·분류 이동은 참조를 깨지 않는다. 삭제된 도구의 단축키/빠른 접근 등 참조는 보존하고 누락을 표시하며 실행을 거절한다. 일반 미지원 명령의 기존 처리와 별도로 이 참조는 복구할 수 있게 유지한다. Stage tool + reference settings backup은 적용 전 작업공간 전체를 읽어 도구와 명령 참조를 함께 임시 복원하며 Apply에서 모든 설정 범위로 적용한다. 문서 외관/이력과 분리한다.

로컬 그룹 JSON v1은 선택 도구 또는 현재 분류(빈 분류 포함)의 정의/분류/순서를 저장한다. 등록 기본값은 각 사용자 도구 정의에 포함하고 공통 내장 기본값·활성 상태·내장 복원 캐시·다른 명령 지정은 그룹으로 내보내지 않는다. 읽기는 일반 파일4MiB 이하, 버전/ID/분류 참조/이름/기본값/속성/프리셋을 전체 검증한다. 가져오기는 현재 목록의 복사본에서 모든 분류/도구 ID를 새로 매핑하고 분류 이름 충돌에는 별도 이름을 부여한다. 손상/중복ID/용량 초과는 기존 임시본까지 유지한다. 내보내기는 독점 임시 파일→기록/동기화→게시이며 기존 파일 교체를 선택하지 않으면 원본을 덮어쓰지 않는다. 이미지 소재는 같은 컴퓨터의 로컬ID 참조로 보존하며 이 그룹 JSON에 파일을 묶지 않는다. 다른PC용 소재 묶음은 기능077의 범위다. 누락 소재는 기존 팁/질감 대체와 경고를 사용한다.

도구 목록/기본값/순서/활성 상태/내장 복원 자료/참조 매핑은 로컬 작업공간 설정에 저장한다. 구형 작업공간의 누락은 비어 있는 My tools 분류와 활성 사용자 도구 없음이다. 그림 파일은 이미 그린 픽셀/고정 스타일을 저장하므로 도구 목록이 없어도 그려진 결과를 재열 수 있다. 원본 앱의 코드/자산/설치 데이터나 클라우드/계정은 사용하지 않는다.

검증: ID/독립 편집/같은 엔진 도구 전환/내장 표시와 값 복원, 기본값/지원 속성/일괄 작업/정렬·빈/동명 분류와 충돌 원자성·용량, 그룹 왕복/ID 재매핑/손상·중복ID/버전/크기·외부 임시 파일/교체 미승인 보존, 실제 관리 창 Cancel/Apply·지원하지 않는 조작 차단·키보드 선택·한 획 Undo/Redo·활성 도구 삭제와 누락 참조·사용 중 팁과 저장 프리셋 보존·도구+참조 설정 복원·재시작·저장 실패 이전 상태를 확인한다. 설치본도 같은 독립 도구/등록 팁/실제 그리기·그룹·복원 검증을 실행한다.
