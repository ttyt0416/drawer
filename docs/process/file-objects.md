# 127 — 로컬 파일 개체와 마지막 정상 캐시

안정 레이어 키에 로컬 경로와 불변 RGBA 캐시·변환을 연결한다. 기존 R/F/벡터/그라데이션/개체/3D/셀/트랙의 합성 위치에 같은 캐시를 주입한다. 원래 저장 내용은 남기고 링크 내용의 직접 수정을 막는다. 마스크·종이·불투명도·혼합·역할은 외부에서 적용한다. 변환용 원시 캡처에서는 이들을 중복 적용하지 않으며 전체 합성 전후를 비교한다. 현재 프레임의 외관을 편집 가능한 로컬 래스터 .drawer로 저장한다. 벡터·타임라인 등 원래 편집 데이터는 대상 그림과 Undo에 보존된다. Restore original embedded layer는 그 내장 원본을 복원한다.

Preview는 읽기 전용 상태를 만든다. 외부 저장을 요구하는 변환은 경로·문서/프레임/리비전·잠금·메모리·합성을 먼저 확인한다. Apply는 목적 파일의 미리보기 시점 크기/수정시각을 확인하고, 기존 파일의 명시 교체 선택을 요구한다. 원문서 자체 경로와 기존 링크 경로를 목적지로 쓰지 않는다. 원자적 네이티브 저장이 성공한 뒤에만 그림 상태를 확정한다. 오류와 취소는 원래 그림을 유지한다. Undo는 정상 생성한 외부 파일을 지우지 않는다. 폴더 열기는 검증한 로컬 폴더를 Explorer에 직접 인자로 전달하며 셸 문자열을 구성하지 않는다.

정상 그림 열기/렌더/내보내기는 원본 파일을 읽지 않는다. 캐시는 v55 JSON 메타데이터와 애니메이션 뒤의 정확한 길이 RGBA 페이로드로 저장한다. 메타데이터 단계에서 예상 캐시 메모리·한도를 검사하고 전체 수화 뒤 키/내용을 검사한다. 삭제·전체 합치기·베이크는 소비한 연결을 제거한다. 썸네일·렌더된 레이어 출력은 최신 캐시의 경계를 사용한다. PNG와 PSD의 렌더된 출력은 같은 캐시를 사용하며 PSD에 외부 링크를 보존한다고 주장하지 않는다. 사용자 잠금과 링크 내용의 읽기 전용 보호를 구분하고 연결된 폴더/트랙 일부만 소비하는 편집은 거절한다.

수동 갱신/다시 연결만 경로를 읽는다. 절대 로컬 드라이브 경로를 요구하며 URL/UNC/장치 경로를 거부한다. 네이티브 원문서의 참조 메타데이터를 최대8단계·64파일로 확인하며 각 문서를 내려가기 전에 해제한다. 순환/자기 참조·누락·읽기 오류는 기존 캐시를 바꾸지 않는다. 중첩 참조를 자동 갱신하지 않고 원문서에 저장된 정상 캐시를 사용한다. 링크256개·캐시당4Mi 픽셀과 메모리/작업 예산이 적용된다.

검증은 수동 전용 갱신·반투명·작은 이미지·삭제된 원본의 네이티브 재열기·경로 교체/변환 유지·이동·복제·원본 복원·URL/UNC/상대 경로·잘못된 파일·자기/중첩 참조·파일 충돌·쓰기 실패/임시파일·Undo와 외부 파일 존속을 포함한다. 래스터 표시 효과/불투명도가 두 번 적용되지 않고 새 캐시 경계가 출력에 반영되는지, 전체 합치기·베이크/Undo, 벡터/개체/폴더/그라데이션/3D/셀/트랙 변환과 타임라인 뒤 캐시 저장 순서를 확인한다. 실제 UI의 New/Refresh/Relink/Convert/Apply·원문서 별도 열기·교체 미확인 거절·프레임 변경·Escape를 검증한다. 실제 디스크 용량을 소진하거나 Explorer 창을 띄우지는 않고 저장 오류 경로와 원본 폴더 경로 해석을 검사한다.
