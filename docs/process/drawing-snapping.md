# 그리기 스냅 우선순위와 일시 해제

Snapping priority and temporary disable에서 활성 그리기 자, 페이지 가이드, 페이지 격자의 사용 여부·화면 캡처 거리·해제 수정키(Control/Shift/Alt)를 설정한다. 선형/원근 자의 제약을 먼저 적용하고, 없으면 거리 안의 가장 가까운 페이지 가이드, 다음으로 격자 교점을 고른다. 같은 거리의 가이드는 문서의 등록 순서를 사용한다. 대칭/방사형 자의 복제는 위치 제약과 별개이며 수정키로 스냅을 잠시 해제해도 복제는 계속한다. 자 전체 토글은 다음 획의 대칭 복제도 켜고 끈다.

캡처 거리는 논리 화면 픽셀이며 문서 거리=화면 거리×화면배율계수/보기확대율로 환산한다. 보기 회전/좌우 반전은 유클리드 거리 판정을 바꾸지 않는다. 가이드/격자는 문서의 페이지 변환을 반영한다. 선형/원근 자는 기존과 같이 거리 제한 없이 활성 제약을 따른다. 가이드와 격자의 위치/모양은 문서 Undo와 자체 문서 저장을 사용하고, 토글/거리/수정키는 로컬 작업공간에 보존한다.

누르는 동안만 수정키 상태를 입력별로 기록한다. 키 이벤트 하나가 누락되어도 다음 운영체제 수정키 상태를 읽어 복귀한다. 포커스 상실은 미확정 획을 버리고 원래 옵션을 보존한다. 일반 마우스/가상 필압/가상 펜, 연결선, 연속 분사·스프레이와 도형이 같은 우선순위를 쓴다. 브러시의 입자 오프셋은 가이드/격자로 이동한 기준점과 함께 옮긴다. 사용자에게 별도로 할당된 수정키 임시 도구는 기존 설정도 적용된다.

마우스 재계산은 원본 입력과 입력별 해제 상태를 먼저 해석한 후 평활/곡선/거리 보간을 한다. 보간 결과에 스냅을 중복 적용하지 않아 수정키 전환 시 경로가 꺾여 다시 붙는 오류를 막는다. 대칭 복제는 그 결과에 적용한다. 도형은 해석된 제어점을 저장하며 로컬 도형 격자는 상위 스냅이 없을 때만 사용한다. 문서v39의 작성 정의는 이미 해석한 제어점임을 보존해 재열기/정렬/재구성 때 다시 격자로 이동하지 않는다. 원래 격자 옵션도 함께 보존한다.

가이드4096개·격자/가이드64Mi 판정·기존 획/재계산 입력/메모리 한도를 검사한다. 초과/유효하지 않은 설정·보기·가이드는 미확정 작업을 거절하고 원본을 보존한다. 변경된 옵션/보기/문서/프레임의 입력은 기존 초안을 취소한다. 수정키 자체는 문서나 설정을 수정하지 않는다.

검증은 자/가이드/격자 경합, 가이드 동률, 격자 fallback, 확대율4종×화면배율2종×회전3종×거리 직전/직후, 페이지 변환, 획 중간 해제/복원·직접 입력/재계산 픽셀 일치, 이미 해석한 도형/문서/가이드·격자/설정 재열기·한 Undo·메모리 거절을 포함한다. 수정키 전환의 중복 제약과 기존 V 토글의 준비된 입력 취소 문제는 실패 재현 후 수정했다. 생산 입력은 일반 마우스/가상 필압/가상 펜의 획 중간 해제/키 놓침/포커스 복귀와 마우스·펜×클릭·드래그×래스터·벡터 도형8조합을 검증한다. 실제 펜 센서는 별도다.
