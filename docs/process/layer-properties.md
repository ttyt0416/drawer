# 117 — 표시·불투명도·잠금·구분색

Layers… → Properties / identification colors에서 래스터·벡터·폴더·애니메이션 트랙/셀을 고른다. 여러 대상을 선택해 표시/불투명도0–100%·전체 잠금·이미지 픽셀 잠금·위치 잠금·구분색 중 바꾼 필드만 한 번에 적용한다. 바꾸지 않은 각 대상의 값은 유지한다. 전체 선택/해제, 적용 전 초안, Apply/Cancel/Escape와 문서ID/수정본/프레임 고정을 제공한다. 적용은 한 상태 Undo이며 표시 위치 스위치는 작업공간 저장으로 분리한다.

전체 잠금은 콘텐츠·이름·구조·위치의 편집을 제한한다. 이미지 픽셀 잠금은 래스터/애니메이션 셀에 적용하며 픽셀을 바꾸지 않는 전체층 이동과 구별한다. 벡터 콘텐츠는 전체 잠금을 사용한다. 위치 잠금은 명시적 전체층/선 이동·정렬·선택 픽셀 이동을 제한하며 일반 래스터 그리기는 허용한다. 폴더 잠금은 자식에, 트랙 잠금은 셀에 상속한다. 잠금 해제와 표시·불투명도·구분색 같은 속성은 속성 편집기에서 바꿀 수 있다. 숨긴 대상은 먼저 표시해야 그림을 편집할 수 있다. 알파 선택처럼 읽기만 하는 기존 명령과 구별한다.

단일 픽셀/획·픽셀 묶음·문서 상태·벡터 Scene 확정의 공통 경계에서 다시 검사한다. 일반 획/도형과 정밀 이동/정렬/자 연동 이동도 시작 시 검사한다. 전역 페이지 좌표 변환은 잠긴 위치/전체 잠금이 있으면 거절한다. Undo/Redo는 기록된 상태를 직접 복원한다. 저장 영역이 커지는 일반 획과 전체층 위치 이동은 구별한다. 잠긴 대상이 있으면 묶음 편집을 일부만 적용하지 않는다.

래스터와 일반 폴더는 합성 전의 premultiplied 색/알파에 불투명도를 적용한다. 벡터는 한 층 안의 경로를 합친 다음 층 불투명도를 한 번 적용해 겹치는 선/면의 중복 감쇠를 막는다. 통과 폴더는 진입 배경B와 자식 처리 결과A를 premultiplied 색·알파 각각 (1-w)B+wA로 혼합한다. 트랙과 셀 불투명도는 곱한다. 기본100%의 기존 경로를 유지하며 화면/참조/PNG 렌더가 같은 합성을 사용한다. 베이크한 래스터는 이미 적용된 불투명도를100%로 되돌려 중복 적용하지 않는다.

구분색은 RGB 메타데이터이며 레이어/셀 픽셀을 바꾸지 않는다. 목록의 색 표식, 자식에 서로 다른 구분색이 있는 부모의 Mixed 표식, 선택 대상의 캔버스 경계, 타임라인의 셀/클립 표식을 제공한다. Lists / Mixed parent folders / Selected canvas bounds / Timeline cell / clip marks는 독립 보기 설정이다. 캔버스 경계는 숨긴 대상에 표시하지 않는다. 타임라인은 현재 프레임 근처 노출 표식을 보여주고 같은 셀을 참조한 여러 노출은 같은 셀의 구분색을 읽는다. 이 표식은 이미지 렌더/내보내기에 들어가지 않는다.

래스터의 안정 식별자와 벡터 기존ID, 현재 폴더/트랙/셀 키로 문서v46에 보존한다. 이전 문서는 누락 시100%/추가 잠금 없음/구분색 없음이며 기존 숨김/잠금 상태를 읽는다. 복제는 속성을 복사하고 삭제/폴더 합성은 사라진 소유자 기록을 정리한다. 래스터256·벡터32·폴더256·트랙32·셀10000, JSON4MiB와 기존 문서/작업공간/이력 예산 및32MiB 전체 상태 초안 한도를 검사한다.

독립 검증은0/50/100%·반투명 원색/배경·일반/통과 폴더·겹친 벡터의 층 단위 불투명도, 속성만 바꾸는 일괄 적용·기존 색/숨김 보존·빈/중복/범위 밖 입력, 픽셀/위치/전체/부모/트랙·셀 잠금, 구분색 전후 PNG 바이트 일치, 서로 다른 자식 색·숨김 셀·공유 셀의 여러 노출·문서/작업공간 재열기를 포함한다. 실제 Apply/취소/오래된 초안·그림 이력과 분리한 표시·캔버스 경계와 마우스/가상 펜의 잠금별 입력도 검사한다. 실제 펜 센서 검증은 별도다. 외부 서비스와 다운로드를 사용하지 않는다.
