# 137 — 일반 병합·알파 마스크 적용·개별 결합

| 동작 | 픽셀 | 결과 마스크 | 표시 효과 |
|---|---|---|---|
| 일반 Merge selected/down | 원본 마스크/효과가 포함된 합성 결과 | 굽고 제거 | 굽고 제거 |
| Apply mask to alpha | 해당 원본의 alpha×자체 마스크; RGB 유지(알파0 RGB0 정규화) | 해당 마스크만 제거 | 다른 설정/식별자는 유지하고 새 알파에서 다시 평가 |
| Individual combine | 마스크/효과를 무시한 아래·위 원본 픽셀의 Normal source-over | max(아래,위)를 독립 편집 마스크1개로 유지 | 원본 별도 레시피는 제거; 외관 보존 명령이 아님 |

개별 결합은 같은 부모의 연속된 두 일반 래스터, 자체 Normal 혼합/100% 불투명도를 요구한다. 아래층 없음·중복·잠금/상위 잠금은 상태 복사/변경 전에 거절한다. 보정층/다른 혼합/클리핑 연쇄/연결 파일 원본은 일반 병합 또는 먼저 명시적 래스터화/클리핑 해제를 안내한다. 숨김 포함은 명시 선택이다. 아래 배경을 추가로 소비하는 옵션은 개별 결합에서 사용할 수 없다.

픽셀 source-over는 136의 문서 RGB→sRGB 부동소수점 계산→문서 RGB/최종8·16bit 저장을 따른다. 마스크는 원본 각각의 좌표계/이동/반전/활성 상태에서 평가한 강도의 최댓값이다. 없음/비활성은 강도1이다. 이 경우의 무한한 외부 통과도 빈 coverage+반전 마스크로 보존한다. 두 유한 패턴은 저장 픽셀 경계로 잘라내지 않고 각 마스크의 전체 변환 영역을 문서 격자에 샘플링한다. 새 마스크는 문서 격자를 원래 페이지 공간에 연결한 독립/활성/이동 연동 마스크다. 0/중간/1 반대 패턴과 서로 다른 변환/반전/비활성 조합을 보존한다.

Apply mask to alpha는 해당 래스터의 원본 알파만 바꾸고 자체 마스크를 제거한다. 다른 층/마스크, 레이어 ID, 위치/범위, RGB, 불투명도/혼합, 종이/표현색/표시 효과를 유지한다. 보정/연결 파일/벡터/폴더에는 원본 알파 평면이 다르므로 일반 병합 또는 기존 전체 레시피를 굽는 Bake masked content를 명시적으로 고른다. 비활성 마스크는 먼저 활성화한다. 살아 있는 테두리/흑백 임계 등은 새 알파에서 다시 계산되므로 외관이 바뀔 수 있음을 안내한다.

Merge 창의 Individual combine은 항상 차이 경고와 전후 미리보기를 표시하고 검토 확인 전 Apply를 거절한다. 최대 표시 채널 차이는 반올림 오차와 구분하여 표시한다. 일반 병합은 문서 정밀도 기준1LSB 보존 비교와 기존 배경 의존성 검증을 유지한다. 마스크 창은 알파 적용과 전체 굽기를 별도 항목으로 제공한다. 두 창의 옵션/설명은 스크롤하며 실제 적용 버튼의 위치를 고정한다. 낡은 문서/프레임 확정·Escape/닫기/미리보기 취소는 무변경이다.

실제 적용 한 명령이 두 원본층·원래 마스크/속성·구조를 Undo/Redo한다. 개별 결과는 기존 자체형식v62의 래스터 정밀도 평면과 독립 Mask 필드로 저장하며 새 파일 태그는 필요하지 않다. 영역4Mi 표본/32768차원, 마스크±1e6/합계32768런, 기존 작업공간/Undo/메타데이터 한도를 적용한다.

독립 float64 source-over/정수 참조로 0/128/255/없음의 모든16쌍을 기존8/새8/16bit에서 비교한다. 각 경우 일반병합·알파적용·개별결합 기대값, 준비 중 원본/이력 불변, 저장 재열기와 한 Undo/Redo를 검사한다. 반대 패턴·서로 다른 좌표계/이동·반전·비활성/무한 외부, 다른 픽셀 알파·표시 레시피 보존, 비정상 혼합/불투명도/보정/잠금/없는 층 거절도 확인한다. 실제 창의 세 병합/전체 합치기와 새 개별 결합, 알파 적용/전체 굽기 버튼·검토 확인·오래된 프레임·Escape를 검증한다.
