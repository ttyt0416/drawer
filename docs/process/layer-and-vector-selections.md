# 레이어 알파와 벡터 편집 선택

Layer alpha / vector selections 창에서 래스터·벡터층·편집 그라데이션을 고르고 Replace/Add/Subtract/Intersect로 알파를 영역 선택 강도로 변환한다. 레이어 자체의 원시 내용 알파를 읽으며 숨김/잠금은 읽기를 막지 않는다. 벡터는 그 층의 경로들을 알파 합성하고 그라데이션은 색 지점과 저장 마스크를 계산한다. 외곽으로 배치된 래스터/벡터 내용도 기존 선택과 함께 보존한다. 픽셀·경로·색은 바꾸지 않는다.

기존 선택 a와 레이어 알파 b를0~255로 두고 Replace=b, Add=a+b−round(ab/255), Subtract=round(a(255−b)/255), Intersect=round(ab/255)로 합성한다. 선택 없음에서 Add는 빈 집합으로 시작하고 Subtract/Intersect는 캔버스 전체 허용 강도로 시작한다. 이미 같은 결과인 명령은 이력을 만들지 않는다. 기존 이동/캔버스 밖 선택을 포함한 원래 페이지 격자에서4×4 표본을 사용한다. 각 실제 선택 변경은 문서의 한 Undo/Redo와 자체 문서 저장을 공유한다.

Show/hide selection outline은 메인/여러 캔버스의 영역 경계 표시만 바꾼다. 내비게이터는 기존 개별 윤곽 설정도 함께 따른다. 선택 강도·칠 제한·픽셀·dirty/문서 이력은 바꾸지 않으며 미확정 획 중에도 전환할 수 있다. 로컬 작업공간에 보기 선호값을 보존한다. 내비게이터의 기존 반투명 선택 칠과 빠른 마스크 색 표시는 독립이다.

보완 명세의 Convert area to vector editing selection은 활성으로 지정한 벡터층에서 제어점 또는 교차 획 전체를 고른다. 제어점은 선택 강도>0인 좌표만 고른다. 베지어/도형은 생성 정의의 실제 제어점·핸들을 사용하고 일반 경로는 편집 정점을 사용한다. 획은 중심선 교차가 기본이며 Include stroke width를 켜면 둥근 선폭 범위와 영역의 실제 거리를 판정한다. 정사각형 팽창의 모서리 오검출을 쓰지 않는다. 두 끝점과 모든 제어점이 밖이어도 곡선이 영역을 지나면 획 전체를 고른다. 기하 판정은 잉크 색/알파를 수정하지 않는다.

벡터 편집 선택도 Replace/Add/Subtract/Intersect와 별도 Clear vector editing selection을 제공한다. 층 또는 종류를 바꾸면 그 모드의 빈 집합에서 시작한다. 빈 영역은 Replace에서 선택을 비우며 선택 자체가 없으면 안내하고 이전 편집 선택을 보존한다. 숨긴/잠긴 벡터층의 편집 선택 변경은 거절한다. 영역 경계는 왼쪽/위 포함·오른쪽/아래 제외이며 부분 강도도0초과면 제어점을 고른다. 페이지 변환과 선택 이동을 반영한다.

벡터 편집 선택은 층/경로 안정ID·제어점 번호·모드·선폭 옵션으로 v40 문서에 보존한다. 한 선택 명령은 한 Scene Undo다. 선택된 경로와 제어점은 캔버스에서 표시하며 영역 윤곽 숨김과 별개다. 삭제/교차점 분할 후에는 사라진 참조를 정리하고 Undo에서 원래 경로와 선택을 함께 복원한다. 구형 문서의 누락 상태는 비어 있는 편집 선택이다.

기존4Mi 선택 격자·32768 RLE·좌표/문서/설정 JSON·작업 메모리와64Mi 표본/교차 작업을 제한한다. 벡터 선택은8192점/128경로와 참조 유효성을 검사한다. 모든 계산은 읽기 전용 원본에서 준비하고 실패·오래된 창은 적용 전에 거절한다.

검증은0/128/255 알파의 네 독립 수치·무변경 이력 없음·숨김/잠금 원본·이동/회전/캔버스 밖·벡터와 그라데이션 알파·픽셀 불변/Undo/재열기, 두 끝점 밖 교차/선폭만 닿음/둥근 모서리/반열린 경계/부분 강도/빈 영역·없음/숨김·잠금·변환·베지어 핸들과 테셀레이션 구분/선택 취소/삭제 후 참조 정리를 포함한다. 실제 두 적용 버튼, 윤곽을 숨기고 선택 밖 칠 차단, 미확정 획 중 표시 전환의 무이력, 벡터 피드백과 오래된 상태/설정 재열기도 설치본에서 검증한다.
