# 149 — 작성 중 경로의 점 이력과 전환 결정

처음 점을 누를 때 임시 저널을 시작한다. 점 추가/Alt 드래그 편집은 접촉을 놓을 때 한 단계로 기록하고, 접촉 취소/포커스 상실은 진행 중 접촉만 되돌려 기존 점을 유지한다. 좌표와 펜 압력은 한 정점 값으로 보존한다. 점128개·이력128단계를 제한한다. Backspace/캔버스 우클릭/Ctrl+Z와 Ctrl+Y는 이 저널에만 작용하며0점까지 취소해도 문서 이력으로 넘어가지 않는다. 새 편집 뒤 redo는 버린다. 문자 입력/한글 조합과 모달 UI는 키를 소유한다.

Enter는2점 이상을 독립 곡선/연속선으로 한 Undo에 확정한다.1점은 불완전 경로이며 점표식을 만들지 않는다. Escape는 초안만 버린다. 펜 클릭의 압력 표본은 편집 배수와 분리해 기존 네이티브 형식에 저장하고 시작 당시 크기 압력 설정을 유지한다. 새 압력 자료를 넣은 뒤 기하·JSON·메모리/Undo 한도를 다시 검증한다.

도구/명령·키보드 도구 선택·문서/뷰/레이어 전환·새 문서/열기·문서 저장/다른 이름 저장·닫기/종료는 유효 초안을 먼저 확정/버리기/계속 작성으로 해결한다. 저장 파일과 그림은 결정 전 바뀌지 않는다. 확인창 Escape는 계속 작성이다. 확정 후에는 원래 요청을 다시 수행하고 기존 저장/닫기 확인도 유지한다. 새 벡터층 자동 선택이 사용자가 요청한 대상층을 덮어쓰지 않도록 처리한다. 미확정 경로는 문서 저장에 포함되지 않는다.

중단 마무리 함수는 클릭 초안을 지우지 않는다. 모달/문자 위의 마우스 입력과 캔버스 밖 누르기는 새 정점으로 전달하지 않는다. 화면 확대·DPI/투영 변화는 문서 좌표의 기존 점을 재투영한다. 문서의 다른 메타데이터 변경은 최신 문서 위에 경로를 추가해 보존하고, 다른 프레임/기하의 초안은 유지한 채 적용을 거절한다. 기존 그림의 취소와 세션의 점 취소는 구분한다.

실물 펜 검증은 별도 대기한다.
