# 083 — 색상환·RGB/HSV/HEX·표시 합성 스포이트·색 이력

완전 로컬이며 자체 HSV 변환과 메시 색상환을 사용한다. 한 내부 색은 unassociated 8비트 RGBA이고 알파0에서도 RGB를 보존한다.

## 색 선택

Color 패널에서 각도=색상각, 반지름=채도의 색상환을 사용한다. 환은 밝게 표시하고 별도 Value로 실제 명도를 조절한다. 환 선택은 현재 Value/알파를 유지한다. 클릭 또는 드래그 종료 때 한 색으로 확정하며 중간 위치마다 이력을 만들지 않는다.

RGB는 각0–255 정수와 알파, HSV는 H0–360도·S/V0–100%와 알파를 입력한다. 수치 입력은 공통 로컬 필드 편집기로 Enter/포커스 이동 시 검증/확정하고 잘못된 문자·비유한 수·범위 밖·정수칸 소수를 적용하지 않는다. 슬라이더/드래그는 범위 안에서 조절한다. HEX는 #RRGGBB 또는 #RRGGBBAA(앞 # 생략 가능),6자리는 현재 알파 유지,8자리는 알파 포함이다. 잘못된 HEX는 이유를 표시하고 이전 색을 유지한다.

입력 모델 전환은 표시만 바꾸며 RGBA를 왕복 변환해 다시 양자화하지 않는다. 회색의 마지막 유효 H는 선택기 메타데이터로만 보존하며 그림 픽셀에 넣지 않는다. RGB/스포이트로 얻은 유채색은 H를 갱신하고 회색은 보존한다. 마지막 모델·H·색·사용 이력은 로컬 작업공간에 저장한다.

## 스포이트와 사용 색

Sample color from canvas 또는 기존 Eyedropper를 선택한다. 현재층 RGB(그림 알파 유지),현재층 RGBA,표시 합성 RGBA와 평균 범위0–4px를 제공한다. 원시층은 선택/숨김/효과와 독립인 저장값이며 표시 합성은 래스터/종이 효과/페이지 개체/편집 벡터/표시된 월드의 실제 렌더러를 읽는다. 범위 평균에서 RGB는 알파 가중이며 RGB-only는 원시 RGB 산술 평균이다. 완전히 빈 픽셀은 현재 색을 유지한다.

Sampler and used colors에서 최근32 RGBA를 선택하고 색 선택만 Undo/Redo한다. 같은 RGBA는 중복하지 않고 최근 위치로 재사용한다. RGB가 같아도 알파가 다르면 별개다. 그림 문서/Undo/dirty와 분리한다. 원래 Previous color/Black 명령도 유지한다.

## 검증

RGB16단계 격자4096색×알파0/128/255를 HSV와 HEX로 왕복해 byte 일치를 확인한다. 원색/보색 축·H360·회색 H 유지·문턱/비유한/소수/잘못된HEX/유니코드·투명RGB·6자리 알파 보존을 확인한다.

실제 egui 이벤트로 알파0의 색상환 클릭,HEX 성공/실패,RGB256 거부와64 정상 입력,모델 전환 불변을 확인한다. RGBA 이력 중복/알파 구분·로컬 설정 재시작·저장 문서와 그림 이력/dirty 불변을 확인한다. 기존 스포이트 생산 입력 시험과 새 벡터/숨김/페이지 선의 표시 합성 픽셀을 비교한다. 설치본도 같은 검증을 실행한다. 실제 펜 센서는 별도 대기다.
