# 작업 자원 경고와 실패 보호

그림/이력 메모리가80% 이상이면 사용/한도 바이트와 정리 방법을 표시한다. Local resources를 열면 쓰기 권한·여유 공간·복구 사용량을 검사하며10초 간격 및 수동 재검사를 제공한다. 디스크가 거의 차거나 복구 보관량이90%에 도달하면 경고한다. 경로가 분리되거나 권한이 없으면 복구 사본 보존과 다른 로컬 경로로 저장할 방법을 안내한다. 그림을 무조건 버리거나 미해결 사본을 자동 삭제하지 않는다.

새 명령 자체의 완전한 Undo 기록조차 메모리/이력 한도에 맞지 않으면 픽셀·상태 변경 전에 필요/한도 바이트를 알리고 편집을 중지한다. 이미 정한 원자 저장·재열기 검증·이전 정상본 보존 절차를 유지한다. 권한/공간 변화로 쓰기가 실패하면 현재 그림은 dirty 상태로 남고 다시 저장할 수 있다.

검증: 메모리 소진 시8/16비트 픽셀 및 상태 편집의 무변경·메모리 복구 후 편집/Undo,0 디스크 여유·실제 Windows 파일 공유 잠금·scratch 폴더 분리 후 정상 원본/현재 상태/완성 복구본 유지와 재연결 후 저장 성공. 별도 test-resource-permissions.ps1는 소유 시험 폴더의 실제 Windows 쓰기 권한을 거부하고 배포 실행 파일의 probe 거절을 확인한 뒤 원래 권한을 복원한다. 실제 디스크 전체를 채우는 시험은 하지 않으며0 용량은 결정적 주입 시험이다.
