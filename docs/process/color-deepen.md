# 166 — 독립 색 심화·픽셀/보정층 적용·클리핑 경고

Layers의 Color deepen은 밝기−1~1, HSL 채도 증가0~1, 중간톤 대비0~1을 분리한다. 독립 설계는 먼저50% 회색을 중심으로 대비를 적용하고 밝기를 더한 뒤 HSL의 명도/색상을 보존하면서 채도를1+설정값으로 곱한다. 대비 기울기는1/(1−0.99×0.5×대비값)이다. 각 단계에서 색 범위/HSL 채도 한도를 적용한다. 이 기능은 원본 제품의 비공개 알고리즘과 일치시키려는 기능이 아니다. 회색의 채도0은 그대로0이며 별도 색을 주입하지 않는다.

Change raster pixels는 고른 래스터의 원자료를 바꾼다. 잠금/픽셀 잠금/연결 소스/보정층 등 기존 paintable 제한을 따른다. 프로필의 문서 RGB↔sRGB 변환과 부동 계산 후 기존8/16비트 저장·디더를 사용한다. 알파는 원래 정수 값을 정확히 복원하고 완전 투명 픽셀의 숨은 원자료, 선택 밖 바이트, 배치/마스크/효과는 보존한다. 래스터 위치는 기존 문서 픽셀 좌표를 유지하고 선택만 기존 Scene 변환/이동을 역으로 적용해 평가한다. 부드러운 선택 강도의 혼합도 보정층과 같은 sRGB 기준으로 계산하고 문서 RGB로 되돌리므로 ICC 문서의 두 방식이 일치한다. 보정층 마스크도 같은 좌표 계약을 사용하며 보기 조작과 구분한다.

New correction layer는 루트 래스터 합성 위에 편집 가능한 보정층을 만든다. 기존 소스 RGBA/배치/마스크를 보존하며 활성 선택 제한을 새 층의 고정 마스크로 복사한다. 선택 없음은 전체 허용이고 명시적인 빈 선택은 정확한 무변화다. 페이지 개체와 애니메이션 셀은 래스터 보정 범위와 구분해 창에 표시한다. 실제 계산은 Adjustment.local.Deepen에 저장한 같은 매개변수와 부동 렌더를 쓰므로 레거시 문서도 같은 색 공식을 사용한다. 픽셀 방식의 저장 반올림은 마지막 합성에서 계산하는 보정층과 최대 정수 단계 차이를 만들 수 있다.

내부 RGB 제한 또는 증가한 HSL 채도가 한도에 닿는 표본을 센다. 픽셀 방식은 선택한 소스의 전체 적격 픽셀, 보정층 방식은 최대64×64개의 래스터 배경 표본을 센다. 표시용 경고 이미지의 빨간색은 한도에 걸리는 표본이며 원본 또는 결과에 그리지 않는다. 원래 마스크/효과를 적용하기 전 소스 색과 선택 강도 보간 전 내부 보정의 제한임을 표시한다. 경고 표본과 전체 픽셀 개수를 혼동하지 않도록 source/preview 표기를 구분한다.

기존 로컬 색 보정의 별도 작업·진행률·입력/전후 미리보기·계산 취소·Escape·설정/문서/프레임 변경 결과 폐기·실패 계획 제거·미확정 저장 안내를 공유한다. 소스4M픽셀/32MiB와 작업공간256MiB, 기존 장면/Undo 한도를 검사한다.128픽셀마다 중단하고 실패/취소는 부분 결과를 확정하지 않는다. 세 값0과 명시적 빈 선택은 이전 최근값/dirty/Redo/이력을 유지한다. 두 방식의 확정은 각각 한 Undo다.

자체 형식v78의 Adjustment.local.Deepen은 보정층 매개변수를 보존한다. Scene.last_color_deepen은 마지막 직접 적용의 값·방식·선택 제한을 과거 기록으로 저장하며 픽셀 모드의 대상 ID는 실시간 참조가 아니다. 다음 창은 마지막 값/방식을 불러오되 현재 대상과 선택을 사용한다. 기존 Color correction layers에서 저장한 보정층을 열면 전용 세 값을 다시 편집할 수 있다. 구형 문서의 누락값은 None이며 v77 이하 위장 헤더의 새 기록/보정은 거절한다. 모든 계산은 로컬이며 모델·외부 통신·자산 다운로드가 없다.
