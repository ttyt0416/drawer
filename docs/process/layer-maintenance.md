# 138 — 보이는 층 복제와 빈/숨김층 정리

Layers… 메뉴의 Copy visible to new layer / Delete empty layers / Delete hidden layers와 동일 이름의 사용자 명령을 제공한다. 현재 문서ID·수정본·프레임을 고정한 초안에서 Prepare → 후보/영향·전후 이미지 검토 → 확인 체크 → Apply 순서로 실행한다. 옵션 변경은 준비·확인을 초기화하며 Escape/취소/낡은 문서나 프레임은 변경하지 않는다.

## 잠금

기존 Properties 편집기의 이미지 픽셀 잠금과 위치 잠금은 독립이다. 픽셀 잠금은 실제8/16bit 저장값 변경을 막지만 전체층 이동은 허용한다. 위치 잠금은 전체층 이동·좌표 변형을 막지만 일반 그리기는 허용한다. 전체 잠금, 폴더·트랙 상속과 공통 확정 경계 검사를 유지한다. 일괄 삭제는 전체/픽셀/위치/알파 보호를 모두 보존하며 잠긴 자식을 감싼 부모도 삭제하지 않는다.

## 보이는 결과를 새 층에 복제

현재 프레임의 문서 영역을 문서 RGB·8/16bit 정밀도로 한 번 양자화해 새 일반혼합100% 래스터에 담는다. 표시된 밑그림, 벡터·텍스트·소재·효과·애니메이션을 포함한다. 소프트프루프/체크무늬는 문서 픽셀이 아니므로 들어가지 않는다. 원본 픽셀·이름·잠금·참조·마스크·개체·타임라인을 유지한다. 새 층은 페이지 개체 뒤의 마지막 합성 위치에 두며 선택한다. 원본도 계속 표시되므로 반투명 영역의 농도가 증가할 수 있음을 전후 미리보기로 알린다. 잠긴 원본도 읽기만 하므로 복제할 수 있다. 문서 밖 픽셀과 다른 프레임은 복제하지 않는다.

## 빈 레이어

실제 저장 알파가 전부0인 래스터/애니메이션 셀, 경로가0개인 벡터, 문자열이 빈 텍스트만 후보가 된다. 16bit 알파1은 RGBA8 표시값이0이어도 빈 것이 아니다. 보정·참조·마스크·표시 효과·일반혼합 외 효과·종이 질감/종이 배경·연결 파일 캐시는 제외한다. 불투명도0, 화면 밖, 마스크 때문에 보이지 않는 원본을 빈 것으로 추정하지 않는다. 폴더/그라데이션/소재/3D/선택 레이어를 빈 층으로 추정하지 않는다.

## 숨긴 레이어와 참조 영향

부모에서 상속한 숨김까지 실제 표시 상태로 판정한다. 적격 래스터·벡터·텍스트/개체·소재·그라데이션·3D·폴더·애니메이션 트랙/셀을 목록에 보여준다. 저장된 선택 영역은 삭제하지 않는다. 보호/필수 구조로 제외한 후보도 이유와 함께 보여준다. 적어도 래스터1개와 남기는 각 트랙의 셀/노출1개는 유지한다. 부모 폴더/트랙은 모든 자식이 함께 삭제될 때만 제거한다. 폴더 슬롯은 기존 안정 식별자 정책에 따라 비활성화하며 다른 폴더 번호를 바꾸지 않는다.

각 저장 컴프에서 사라질 항목 수와 이름을 보여준다. 컴프 기록은 안정ID를 유지해 이후 적용 때 누락으로 보고하며 다른 층으로 재지정하지 않는다. 삭제되는 셀의 노출 표식을 제거하고 남는 셀 인덱스를 안정ID 기준으로 다시 연결한다. 제거된 표식 때문에 앞 노출의 유지 시간이 늘 수 있으므로 그 수와 영향을 확정 전에 알린다. 삭제하지 않은 픽셀은 변하지 않는다.

## 저장·취소와 한도

새 복제 픽셀/원래 구조/남은 타임라인은 기존 자체형식v62에 저장한다. 일괄 삭제·합성 복제는 각각 한 상태 Undo이며 전체 구조/픽셀·컴프/타임라인을 복원한다. 외부 원본 파일을 쓰지 않는다.4Mi 픽셀, 래스터256, 문서/작업공간/Undo 예산과 JSON4MiB를 검사한다. 저장된 연결 파일/레이어 그룹/종이 배경/표시 순서는 사라진 소유자만 정리한다.

## 검증

빈 래스터·숨긴 유효층·보정·참조·효과·종이·잠금·빈 벡터/텍스트·컴프와 노출 셀을 섞어 정확한 후보를 비교한다. 숨긴 부모·잠긴 자식·전체 트랙·마지막 래스터, 알파1/65535,8bit 호환/8bit 부동소수점/16bit 복제와 최상단 개체 합성, 저장 재열기, 전체 상태 Undo/Redo를 검사한다. 실제 명령/Preview/확인/Apply 버튼과 확인 우회 거절·프레임 변경·Escape 취소를 시험한다. 픽셀/위치 잠금의 실제 그리기와 이동 독립성은 기존 공통 검증을 함께 실행한다.
