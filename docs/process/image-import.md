# 이미지 입력·저장 경로 규칙

기능 014는 파일 내용을 읽기 전용으로 스냅샷에 읽고 선택한 페이지를 디코딩한다. 미리보기와 새 그림이 같은 RGBA8 픽셀을 사용한다. 같은 이미지를 반복 가져오면 다른 문서 ID·도구·이력으로 만든다. 편집 저장 경로와 원본 연결은 비워 두며 첫 저장은 `.drawer` 위치를 묻는다. 가져온 원본 경로는 실행 세션의 덮어쓰기 방지 목록에만 넣는다. 저장 후에도 앱에서 그 입력 파일을 내보내기로 덮어쓸 수 없다.

| 입력 | 현재 검증한 범위 | 변환 |
|---|---|---|
| PNG | 정지 RGBA8, 투명/반투명, RGB ICC | 알파와 숨겨진 RGB 보존, ICC는 sRGB로 변환 |
| JPEG | 8비트 RGB, EXIF 방향 | 방향 적용 여부를 선택하고 크기/배치를 미리보기와 일치시킴 |
| TIFF | 여러 페이지, Gray/RGB/RGBA 8/16비트, BlackIsZero Gray+alpha 8/16비트 | 페이지 선택, 16비트→8비트 반올림, 연관 알파→straight alpha, 방향 적용 |
| TIFF ICC | RGB/회색조 프로필 | sRGB 변환, 알파 값 유지 |
| 클립보드 | Windows 이미지 API에서 RGBA8로 읽을 수 있는 이미지 | 새 문서, 기존 문서 이력 불변 |

PNG/JPEG 디코더가 제공하는 다른 비트/색 변형은 여기서 검증 완료로 주장하지 않는다. TIFF의 CMYK/팔레트/부가 채널/부호 있는 샘플/실수 샘플, Gray+alpha WhiteIsZero와 APNG는 지원하지 않거나 디코더 오류로 거절한다. 더 넓은 파일 변형·고비트 편집/출력·색 관리 기능은 각 후속 체크 항목에서 검증한다. 손상된 ICC나 입력과 맞지 않는 프로필은 무시하지 않고 이유를 표시해 중단한다. 프로필이 없으면 sRGB로 가정하며 UI에 표시한다. 입력 DPI 메타데이터는 아직 적용하지 않으며 새 그림 DPI는 300이다.

축당 1~32768픽셀, 최대 256개 TIFF 페이지, 인코딩된 입력 64 MiB, ICC 1 MiB를 허용한다. 열린 그림과 이력을 포함한 문서 예산 256 MiB에서 원본 복사·디코더·변환·방향·새 문서 버퍼까지 사전 계산한다. 치수 한도 안이어도 메모리가 부족하면 디코딩 전에 거절한다. 계산은 배경에서 수행하며 취소는 결과를 폐기한다. 코덱 호출 자체는 반환 지점에서 취소를 확인한다. 페이지/방향 변경 때 기존 미리보기를 폐기하고 새 결과가 도착할 때까지 생성 버튼을 비활성화한다. 오류·취소는 빈 그림을 추가하지 않는다.

최근 목록은 버전 1의 `settings/recent.json`에 정규화된 로컬 절대 경로를 최근 순으로 20개 저장한다. 성공한 문서 열기·가져오기·저장만 기록하고 내보내기/취소/실패는 기록하지 않는다. 같은 경로는 맨 앞으로 이동한다. 누락 입력은 자동 삭제하지 않고 UI에 표시한다. 원자적 저장·직전본/손상본 보존·목록 Undo/Redo·초기화·직전본 복원을 제공한다. 그림 실행 취소와 별개이며 설정 기록 실패는 이미 성공한 그림 작업을 취소하지 않고 이유를 알린다.

Save는 현재 편집 경로에 저장하고 Save as는 성공할 때만 경로·제목·저장 체크포인트를 바꾼다. Export PNG는 문서 경로·변경 상태·이력·선택·보기를 유지한다. Windows 기본 저장 대화상자의 덮어쓰기 취소는 파일 선택 없음으로 처리한다. 디스크 기록은 임시 파일의 완료·동기화 후 교체하며 실패하면 기존 파일을 보존한다. 현재 PNG 출력은 합성 sRGB RGBA8이고 ICC/DPI 태그 출력은 후속 항목에서 구현한다.

시험은 생성한 독자 픽셀/EXIF/TIFF/ICC 자료를 사용한다. 원본 입력 바이트 불변, 방향 적용/해제, 페이지 선택, ICC 실제 색 변환, 저장 후 재열기, 큰 치수·메모리 거절·손상·취소, 최근 목록 재시작/복원, 경로·덮어쓰기 취소와 마우스 미리보기 동작을 대조한다. 실제 사용자 클립보드를 변경하지 않고 입력 공급자와 Windows API 빌드를 검증한다.

기능 017의 기존 문서 붙여넣기는 캔버스 독립 크기/원점을 가진 래스터를 새 레이어에 넣는다. 처음 중앙 배치에서 이동 가능한 미리보기를 제공하고 확정 하나를 하나의 문서 Undo로 기록한다. 원위치 메타데이터는 독자적인 Windows 등록 형식 `Drawer.LocalRaster.v1`로 전체 RGBA8와 정수 원점을 함께 전달한다. 표준 이미지 형식도 같이 제공해 외부 앱에 복사할 수 있으며 원위치 정보를 추가할 때 표준 이미지를 지우지 않는다. 클립보드가 바뀌면 메타데이터 추가를 중단한다. 읽기 전에 클립보드 데이터 크기를 확인하며 손상된 전용 패킷은 거절한다.

합성은 캔버스로 제한하지만 자체 형식 4는 캔버스 밖 전체 이미지와 위치를 보존한다. 반전/90도 회전/재샘플링/DPI 변경도 독립 래스터 기하를 유지한다. 캔버스 크기/잘라내기는 제거 픽셀을 알리고 확인 뒤 정규화한다. 붙여넣기 메모리/Undo 예산을 사전 계산하며 빈/비이미지/손상/범위 밖/예산 초과 입력은 원문서를 보존한다. 미리보기 중에는 다른 편집/저장을 막고 기존 문서 수정 번호가 바뀌면 확정을 거절한다. 실제 사용자 클립보드는 시험에서 변경하지 않으며 공급자·패킷 왕복·Windows API 빌드를 검증한다.
