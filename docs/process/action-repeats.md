# 액션 회차 반복 (255)

기존 Local auto actions의 실행기에서 Repeat rounds / wait / confirm을 연다. 반복1..1000·대기0..60000ms·회차/파일 사이 계속 확인은 로컬 action-repeat.json에 저장하고 손상 설정 교체는 명시적으로 선택한다. 단조 시계로 대기하며 화면이나 작업자에서 긴 sleep을 하지 않는다.

문서 회차는 새 비공개 실행 사본을 준비해 전체 성공 뒤 자동으로 한 번 커밋한다. 완료한 회차는 각각 Undo로 되돌린다. 변화 없는 회차는 빈 Undo를 만들지 않는다. 중지·오류에는 현재 사본을 버리고 완료 회차 수는 올리지 않는다. 재개는 다음 미완료 회차의 처음부터다. 대기 중 중지도 이전 완료 상태를 유지한다. 원래 문서 ID/리비전/프레임과 현재 작업 공간 예산을 다시 검사하며 문서 닫힘/변경에는 사본을 적용하지 않는다.

기존245의 단계별 중단·재개 실행기는 그대로 별도 제공한다. 새 반복 파일 모드는 파일별로 회차를 진행하고 대기/확인을 거친다. 취소/실패한 현재 회차는 시작 상태로 복원하고 이전 회차의 비공개 결과를 유지한다. 완료한 파일만 새 .drawer 출력으로 배타적으로 게시하고 입력 파일 해시와 충돌을 검사한다. 완료 출력과 커서는 로그 쓰기 오류에도 되돌려 중복 실행하지 않는다. 실패 파일 중지/건너뛰기·현재 파일 건너뛰기와 결과 로그를 제공한다. 파일별 반복 완료 전에는 부분 파일을 게시하지 않는다.

명령 작성기의 Document transform은 대상 래스터/벡터 슬롯과 문서 좌표 피벗·이동·배율·회전/보간을 기록한다. 확대/회전/반전/DPI를 변형 데이터로 기록하지 않으며 기존 검증된 아핀 처리기를 사용한다. View scroll은 현재 보기 중심을 이동할 문서 픽셀 차이이며 그리기 상태와 별도다. 재생은 현재 보기 배율을 사용해 같은 문서 이동량을 만들고 그림 Undo를 추가하지 않는다. 여러 단계의 보기 이동도 전체 회차가 성공한 뒤 적용한다. 기록은 기존 정책대로 액션 명령 작성기의 실행/기록을 사용한다.

로컬 데이터 이동은 진행 중 반복 작업을 배출하고 다음 회차 자동 시작을 보류한다. 화면을 닫으면 현재 회차 중지를 요청하며 이미 쓴 출력과 이전 회차는 보존한다.

검증: 옵션 경계/재시작·확인/대기·대기 중 중지·두 번째 회차의 부분 변경 뒤 실패·회차별 Undo·다른 보기/DPI의 같은 변형/보기 이동·순수 보기의 이력0·파일 회차 중 확인과 부분 출력0/새 출력/원본 보존, 실제 버튼으로 설정 저장·회차 실행/중지/계속/Undo·문서 닫힘을 확인한다.

통합 보완: 데이터 이동의 대기 경로에서 인쇄/출력/소재 창을 숨겼을 때도 완료 결과를 먼저 수집하도록 정리했다. 닫힌 래스터 창의 작업 소유권도 유지해 취소/유실시키지 않는다. 실제 가상 PDF 저장 작업을 창/입력 프레임 없이 배출하는 검증을 추가했다.
