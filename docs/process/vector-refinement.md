# 144 — 선 연결·단순화·부분 밀기·다시 그리기

Layers의 Refine vector strokes에서 현재 선택을 불러온 뒤 작업을 고르고 Prepare refinement preview로 전후 모습을 확인한다. 공통 Apply 버튼으로 한 Undo를 만든다. 기존 Point/Add/Delete/Corner/Smooth 도구로 제어점을 편집할 수 있고 Push vector span과 Redraw vector span은 캔버스에서 직접 드래그한다.

연결은 선택한 열린 두 획의 네 끝점 조합 중 문서 좌표에서 가장 가까운 쌍을 고른다. 지정한 최대 거리를 넘으면 적용하지 않는다. 같은 선폭·RGBA·장치 압력 활성 상태의 선만 연결하며 다른 속성의 선 연결 정책은150번에서 다룬다. 두 원래 윤곽 사이에 직선 구간을 넣는다. 방향이 바뀌면 압력 배열과 비균등 매개변수도 뒤집으며 두 선의 장치 압력·편집 배수와 원래 매듭 위치를 새 구간에 옮긴다. 채움 내부가 있는 객체는 연결하지 않는다.

단순화는 현재 저장된 윤곽의 정점에 Ramer–Douglas–Peucker를 적용한다. 오차는 문서 좌표에서 원래 정점과 대체 선분 사이 거리이며 허용 오차0이면 원래 데이터와 정의를 유지한다. 열린 끝점은 유지하고 닫힌 선은 시작점·중간점·마지막점을 남겨 두 개의 열린 호를 단순화한다. 자기 교차의 앞뒤 압력을 공간상 가까운 점으로 찾지 않고 원래 구간 매개변수로 추적한다.

밀기는 누른 위치를 중심으로 문서 픽셀 반경 안의 윤곽 점만 이동한다. 긴 직선도 중간을 밀 수 있도록 각 선분과 원형 반경의 접촉 구간에16등분 점과 최근접점을 넣고 원래 정점도 보존한다. 중심에서 바깥으로 이동량이 선형 감소하며 드래그 시작 문서에서 매번 계산하므로 미리보기 누적 오차가 없다. 열린 선의 Fix both ends는 양끝, Fix nearest end는 누른 위치에서 가까운 한 끝을 고정하고 Free both ends는 끝점을 자유롭게 둔다. 닫힌 선에는 열린 끝점 고정을 적용하지 않는다. 반경 밖 윤곽은 그대로이며 추가된 점의 필압은 원래 선분 매개변수를 따른다.

다시 그리기는 한 제어점에서 다른 제어점으로 드래그하거나 먼저 Shift로 경계 제어점 두 개를 선택한다. 선택 구간의 윤곽만 캡처한 선으로 바꾸며 역방향 드래그도 처리한다. 내부 경계는 선택 밖 구간과 연결된 상태로 고정하고 실제 열린 양끝에는 끝점 고정 선택을 적용한다. 구간 밖 윤곽 정점과 필압의 원래 위치 관계를 유지한다. 한 드래그는 최대128개의 입력 점을 받으며 한도를 넘으면 전체 임시 작업을 취소한다.

Polyline은 입력 점을 직선으로 연결하고 Spline·Quadratic Bezier·Cubic Bezier는 기존 자체 도형 생성 수식을 공유한다. 전체 곡선 종류 변환은 현재 논리 제어점, 다시 그리기는 캡처한 점을 입력으로 쓴다. 곡선 입력은128점까지이며 넘으면 먼저 단순화하도록 알린다. 윤곽을 바꾸는 처리는 저장된 선분으로 전환하며 원래 전역 곡선/독립 핸들 정의는 Undo로 복구할 수 있다. 보존된 외부 구간의 화면 윤곽은 바뀌지 않는다.

Thicken/Narrow는 기본 선폭을 가감하고 Scale up/down width는 배율을 적용한다. Fix width는 모든 선택 획의 기본 선폭을 지정한다. At least1pixel은 문서 변환의 최소 축 배율을 고려한 기본 선폭 하한이다. 필압으로 인한 가변 폭과0압력은 별도로 유지한다. Adjust opacity는 획의 알파만 바꾸며 채움색은 보존한다. Split은 열린 선의 내부 제어점에서 두 획으로 나누거나 닫힌 획의 선택점을 열린 이음매로 만든다. 채움 내부가 있는 객체는 먼저 선만 있는 객체로 준비한다.

미리보기는 원본 문서와 분리된다. 놓기/Apply가 한 Undo를 만들고 Escape·포커스 상실·입력 취소·문서/수정본/프레임/보기/대상/설정 변경은 임시 결과를 버린다. 일반/픽셀/위치 잠금과 연결 원본 보호를 따른다. 문서v66의 기존 윤곽·가변 압력 형식을 사용하며 기하4096점/획, 전체8192점/128획, 압력8192매듭, Scene JSON4MiB, 스냅샷/Undo 메모리 한도를 검사한다. 실패는 부분 적용하지 않는다. 실물 펜 검증은 별도 대기한다.
