# 200 — Onion skin counts, color and distance fade

`onion-skin` opens the existing timeline editor with its onion controls expanded. The guide is a canvas/view overlay, never a drawing layer. The controls provide preceding/following counts0..8, independent direction colors, starting opacity0..100%, fade per additional frame0..100 percentage points, Original/Half/Solid color and exclusion of repeated held cels.

The nearest neighbour uses the starting opacity. Distance d uses max(0, start - fade*(d-1)); zero-opacity frames are skipped. Solid uses the direction color, Original retains displayed source RGB, and Half averages original and guide sRGB channels equally, rounding half upward. Source alpha multiplies the resulting opacity. References are composed far to near. No frame wraps around a timeline endpoint. Zero counts produce no guides, and hidden source/parent properties continue to apply.

Repeated-cell exclusion starts with the current cel/pose and retains the nearest remaining occurrence for each track/source. Equal-distance repetitions prefer the preceding frame. Identity includes the editable shared cel source and its placement/evaluated transform, so a shared held cel does not accumulate opacity while a moving pose of the same source remains visible. The same rule applies to animated common layer/folder sources. Frame snapshots preserve base-content view when it is active; no source pixels, exposure times or keyframes are changed. Editing-track-only mode restricts the guide to that track.

Native99 stores a version-checked onion preference object inside the native JSON metadata. On open it is unpacked into Document session preferences and removed from Scene. Nondefault counts/colors/mode/fade/repeat exclusion are included when saving the drawing (defaults are omitted for compatibility); enabled/disabled and editing-track-only are session view choices. Preferences are intentionally excluded from drawing snapshots and Undo. Changing controls does not change document dirty state, revision, path, frame or drawing history. Saving the document captures the current preferences. Reopening starts with guide display off. Ordinary Undo/Redo preserves the latest view preferences.

The renderer/exporter does not consume the preferences. Installed verification decodes an actual PNG export and checks that prior/next guide pixels remain absent. Snapshot/output memory checks retain the existing budget, side limit1024, and64Mi source-sample cap; reducing counts or selecting one editing track resolves oversized requests. No libraries, assets or network services were added.

Verification covers three color modes with exact directional RGB/alpha, duplicate held exposures versus independent display, subtractive fade reaching zero, first/last and zero counts, hidden tracks/parents, parent mask/opacity, animated common-layer poses, preview state preservation, native99 reopen/98-header rejection, Undo isolation, actual PNG output and pointer events for display/repeat/color controls. The installed smoke receipt includes `onion_skin=true`.

The output regression run also exposed wall-clock timestamps in generated sRGB ICC headers. PNG export now normalizes only generated sRGB creation dates to2000-01-01; imported embedded profile bytes remain unchanged. A real cross-second PNG byte comparison and ICC parse check cover this correction.
