# 산포·연속 띠·독자 장식

기능067. 선택 모드는 기존 도장/경로 산포/연결 리본/반복 장식이다.7개 도구별 입력 임시본·적용/취소/백업/기본값 복원/재시작, 프리셋, 가상 입력, 문서v19의 고정 스타일에 보존한다. 이전 누락 필드는 기존 도장이다. 모든 소스는 자체 Rust 수식이며 외부/원본 소재를 사용하지 않는다.

산포는 문서 지름0~4096px, 입자1~64개, 타원 aspect.05~1을 제공한다. seed+경로 도장 번호+입자 번호로 좌표를 고정하고 sqrt 반경/균일 각도로 면적 표본을 만든다. 전체 타원은 기본 각도+동역학 scatter angle, 입자 팁은 기존 방향 규칙이다. 중심 지향에는 해당 군집 중심에서 각 입자로의 역벡터를 사용한다. 경로 잘라내기 범위를 산포 반경만큼 늘려 중심이 캔버스 밖이어도 안쪽 입자를 잃지 않는다.

리본은 유효 크기×aspect 폭의 연속 띠다. 반px 경로 표본마다 이전/현재 중심과 폭을 연결하고 둥근 캡/연결의 거리 마스크를 계산한다. 급회전 경로를 임의 직선으로 건너뛰지 않는다. 이전·현재 끝의 범위로 픽셀 경계를 구하고 폭은 선형 보간한다. 리본의 도장 사이 마스크는 최대값으로 합쳐 재방문 농도 누적을 방지하며 기존 선택/전체 농도/질감의 최종 적용을 공유한다. 일반 Spacing은 리본에서 무시한다. 동적 크기/시작끝은 폭에 반영된다.

장식은 별(5방향 반경 변조)/다이아몬드(L1)/잎(|x|+y²)의 독자 무차원 거리 마스크다. 모양 외곽은 기존 팁 크기·aspect·회전과 경도/AA/이진 팁 규칙에 결합한다. 반복 간격은 팁 폭 .25~16배이며 기존 최소 굵기·동적 크기 연동도 따른다. 팁 순서 마스크의 기본 재질/색은 유지하되 장식 모드의 외곽이 우선한다. 임포트된 이미지 리본 기능을 주장하지 않는다.

픽업/희석/알파 잠금·선택·전체 농도·질감·지우개·한 이력 게시를 기존 Stroke와 공유한다. 산포/장식은 독립적인 시드/번호를 써 크기 무작위와 순서를 섞지 않는다. 패턴 도장 최대262144회와 기존64Mi 픽셀 작업/메모리/경로 예산을 적용한다. 실패/취소는 미리보기 전체를 버린다. 시험 칠하기도 같은 엔진을 사용한다. 물리 펜 검증은 대기한다.
