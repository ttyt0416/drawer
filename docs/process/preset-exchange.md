# 로컬 사용자 브러시·색상표 교환 — 기능232

휴대용 브러시 묶음은 기존 tool_bundle v1의 manifest/tools/materials JSON 구조를 사용한다. 새 폴더로만 내보내고 도구의 preset/default에서 참조한 자체 팁/질감/섬유 자료를 포함한다. 전체12MiB·32자료·개별 자료2MiB 및 원래 도구/소재 한도를 검사한다. 버전/길이/해시·중복/누락/불필요 파일·상대 경로·링크/재분석 지점·wrong-kind/누락 참조를 모두 검증한 뒤 순수 복사본을 만든다. 소재와 도구/분류 ID는 새 번호로 매핑하고 분류 이름은 충돌을 피한다. 다른 분류의 같은 도구 이름은 독립 도구이며 기존 항목을 덮어쓰지 않는다.

기존 도구 편집기에 소재 준비 상태를 추가했다. 휴대용 가져오기/추가 가져오기/내보내기는 이 상태를 사용하며 실제 소재 파일이나 현재 슬롯에 반영하지 않는다. Apply만 등록하고 Cancel/Esc/창 닫기는 둘 다 버린다. 준비 중 기존 소재 목록이 바뀌면 적용을 거절한다. 소재 파일을 게시한 뒤 작업공간 저장이 실패하면 원래 소재로 되돌리고 빈 원래 목록은 파일 부재도 복원한다. 동시 외부 변경으로 복원할 수 없으면 오류를 명시하며 해당 외부 파일을 덮어쓰지 않는다. 이 절차는 정상 오류의 복원을 보장하며 여러 파일에 걸친 강제 종료/정전의 일괄 원자성을 주장하지 않는다.

참조 소재를 포함하지 않는 단일 브러시/그룹 JSON은 현재 또는 준비 중인 소재에서 모든 참조가 해결되어야 읽는다. 누락이면 휴대용 묶음 사용을 안내하고 부분 등록하지 않는다. 단일 프리셋의 이름 대체와 기존 출력 파일 대체는 원래의 별도 확인 흐름을 유지한다. ABR의 명시적 소재 등록은 별도 기능113의 작업이며 여기의 휴대용 묶음 준비와 구분한다.

색상표 교환은 자체 JSON version1, tables와 RGBA8 swatch/이름/레이아웃만 담는다. 일반 UI 환경 설정·자동 표본·색 이력 옵션은 옮기지 않는다.2MiB·16표·개별256색/전체2048색·양수/전역 유일 ID·이름/레이아웃을 검증한다. 독립 복사는 새 표/색 ID와 충돌하지 않는 표 이름을 사용한다. 이름 대체는 모호한 기존/입력 이름을 거절하고 목록 확인을 요구한다. 기존 표 ID를 유지하되 색 ID는 새로 만든다. 읽기/취소는 설정/파일에 적용하지 않고 준비 뒤 설정이 바뀌면 다시 읽도록 한다. Apply는 기존 작업공간 저장을 사용하고 색상표 편집 이력을 한 단계 기록하며 그림 픽셀/문서 Undo는 바꾸지 않는다.

색상표 출력은 전체/선택 표를 지원한다. 대체하지 않는 출력은 독점 새 파일로 게시하며 기존 파일/외부 임시 파일을 보존한다. 대체는 별도 확인하고 소유 임시 파일의 기록/동기화 후 바꾼다. 원본 브러시/색상표 파일은 읽기 작업으로 변경하지 않는다. 새 명령/외부 라이브러리/자체 문서 버전 변경은 없다.

시험: 같은 ID/표 이름의 복사·확인 없는 대체 거절/확인 대체·모호한 이름/용량/오래된 결과·잘못된 버전/중복 ID/색 범위/레이아웃/손상·기존 출력/외부 임시 파일 보존, 합성 마우스의 읽기/취소/적용/Undo/대체/재시작과 휴대용 묶음의 소재/슬롯 취소0개·일괄 적용·설정 저장 실패 복원·누락 팁 거절·문서 불변을 확인한다.

## 239 — 텍스트 색상표와 그라데이션 교환

GPL은 [GIMP 공개 명세](https://developer.gimp.org/core/standards/gpl/)를 기준으로 독립 구현했다. 이름/선택 열 수와 sRGB8 RGB·색 이름을 읽고 쓰며 알파가 있는 출력은 거절한다. 로컬 열 수 한계32를 넘는 GPL은 반응형 배치로 바꾸고 안내한다. UTF-8/BOM·CRLF·구형 이름 없는 GPL을 읽는다. 한 표 최대256색, 이름64자 및2MiB 한계를 검사한다.

자체 CSV의 헤더는 palette,r,g,b,a,name이며 한 표의 이름과 RGBA8·색 이름을 각 행에 둔다. 따옴표/쉼표/따옴표 이스케이프를 보존한다. 제어문자/다중행 이름·잘못된 열·인코딩·값은 전체 거절한다. JSON은 기존 ID/배치를 보존하며 GPL/CSV는 ID를 재발급하고 미리보기 후 기존 복사/이름 대체 정책으로 적용한다. 투명도는 CSV/JSON으로 교환한다.

자체 브러시는232의 버전형 도구 폴더와 검증된 별도ABR 경로를 유지한다. 그라데이션은 기존 자체JSON v1에 위치·RGBA·중간점·곡선·혼합 공간·반복을 보존한다. 같은 위치의 정지점은 순서를 보존한 하드 에지이며 정렬되지 않은 지점은 거절한다. 버전/인코딩/부분 실패·외부 임시 파일 오류는 기존 설정을 바꾸지 않는다. 파일은 로컬에서만 읽고 쓴다.
