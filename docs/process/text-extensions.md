# 앱 소유 글꼴·원형 텍스트·작품 전체 치환

앱은 사용 허가 확인을 받은 로컬 TTF/OTF/TTC/OTC 파일만 전용 fonts 폴더로 복사한다. 파일 내용 해시로 이름을 구별하고 소유 목록에 얼굴 식별자를 저장한다. 같은 파일 재등록은 중복을 만들지 않으며 동명 다른 글꼴은 별도 복사본이다. 삭제는 소유 목록·로컬 폴더·일반 파일·내용 해시와 표시 이름 확인을 모두 검사한다. 시스템 글꼴과 선택한 원본은 수정/삭제하지 않는다. 파일 한도32MiB,128개/1024얼굴, 컬렉션64얼굴이다. 다른 임시 파일/링크/변경된 소유 파일은 보존하고 거절한다. 작업 잠금과 쓰기 실패 복원으로 중간 소유 정보를 남기지 않는다. 사용 중 복사본을 제거해도 원문/글꼴 참조/서식은 문서에 남고 대체·누락 안내를 사용한다. 최근 적용 글꼴은 최대32개 로컬 설정이며 문서 Undo와 독립적이다.

원형 모드는 자체 세대2에서 명시적으로 전환한다. 반경0은 거절하며0.1~32768px, 시작각-360~360도, 바깥/안쪽 방향과 균등 간격을 저장한다. 글자군/합자 조형 단위를 접선에 배치하며 긴 내용의 원주 초과/겹침 가능성을 안내한다. 첫 명시적 줄만 그리며 나머지 Unicode·루비·밑줄/취소선·일반 줄바꿈/세로쓰기·기울이기 값을 삭제하지 않는다. 렌더링 복사본에서만 해당 속성을 끄고 원형을 해제하면 전체 원문과 서식으로 돌아간다. 일반 모드의 밑줄·취소선·기울이기도 실제 윤곽/색과 함께 렌더링한다. 전환 창은 전후 미리보기와 숨김 목록을 제공하고 확인 전에는 편집 초안도 바꾸지 않는다. 취소/Escape는 원본을 보존한다. 원형에서 자동 줄바꿈과 기울이기 조작은 비활성화한다. 네이티브v92는 모든 값과 모드를 보존하며 낮은 헤더 위장은 거절한다. 출력 전에는 숨긴 내용과 자체 원본 보존을 알리고 문서/수정번호/프레임별 검토를 요구한다.

작품은 로컬 .drawer-work 목록으로 정의한다. 이름과1~128개의 저장된 .drawer 페이지를 등록하며 닫힌 페이지도 전체 작품의 대상이다. 현재 페이지/전체 작품·리터럴 Unicode 검색·대소문자 구별을 선택하고 전체 바꿀 목록을 먼저 확인한다. 빈 검색어·글자군 중간 일치·길이/장면/윤곽/메모리 초과·중복 페이지는 거절한다. 각 일치를 역순으로 치환하며 기존 글꼴/범위/루비/원형 상태를 연결해 이동한다. 전체 문서의 변경과 Undo를 복사본에서 검증한 뒤 한 번에 반영한다. 실패/취소는 열린 문서와 원본 디스크 파일을 바꾸지 않는다. 닫힌 페이지는 Apply 때 변경된 문서로 열며 파일 저장은 사용자가 별도로 수행한다.

각 페이지의 문서ID/수정번호/프레임/이력 위치와 닫힌 원본의 내용 해시를 검사한다. 어느 소스가 바뀌어도 전체 적용을 거절한다. 여러 페이지 치환은 하나의 연결 Undo/Redo로 처리한다. 영향을 받은 어느 페이지에서도 전체 동작을 복원하고 후속 편집/닫힌 페이지가 있으면 부분 복원을 거절한다. 보기/현재 저장 경로/저장 기준점은 현재 문서를 기준으로 유지한다. 찾기 목록은10000개/표시 문자열4MiB, 전체 작업은 기존 문서 예산 안으로 제한한다. 클라우드·원제품 내부 포맷/코드/리소스는 사용하지 않는다. 실물 펜 검증은 대기한다.
