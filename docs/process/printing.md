# 인쇄 레이아웃과 하드웨어 검증 구분

`print-preview`는 활성 페이지의 읽기 전용 합성 스냅샷을 준비한다. 기존 PDF/EPUB/인쇄 창의 Print selected pages도 선택한 합성 페이지를 같은 검토 창으로 보낸다. A4/Letter/사용자 용지, 세로/가로, 네 여백, 용지맞춤/실치수 배율, 준비된 페이지 안의 범위를 검토한다. 사용자 용지/배율의 비활성 값은 유지한다. 내용은 여백 상자 가운데 배치하며 큰 배율은 그 상자에서 잘리고 경고/미리보기로 표시한다.

확인 뒤에만 Windows 프린터 대화상자를 연다. 같은 용지/방향과 드라이버 옵션을 선택하며 반환된DC의 물리용지·해상도·인쇄영역·원점을 검사한다. 용지는1mm 허용차로 대조하고 하드웨어 최소여백보다 작은 요청은 스풀 시작 전에 거절한다. mm 배치를 실제장치픽셀로 변환하고 인쇄가능원점오프셋을 뺀다. 각 페이지의 GDI클립은 검토한 여백상자다. 실패/취소는 소유한 작업만 AbortDoc하며 다른 프린터 작업은 건드리지 않는다. 이미 장치에 제출된 종이는 취소로 복원할 수 없다. 프린터 대화상자가 열린 동안 취소하려면 그 창의 Cancel도 사용한다.

배경은 흰색에 알파 합성하고32비트 top-down BGRA와 sRGB가 명시된 BITMAPV4HEADER를 사용한다. Windows ICM 켜기/끄기는 저장된 인쇄옵션이며 모니터ICC와 분리한다. [StretchDIBits](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-stretchdibits)·[SetICMMode](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-seticmmode)의 드라이버 색관리 경로를 사용한다. 기기/용지/잉크의 실제 색 정확도는 이 API 성공이나 소프트웨어 미리보기로 입증하지 않는다.

가상 PDF는 같은 배치/여백/클립/범위를96DPI의 흰 종이 래스터로 만들어 새 파일에만 기록한다. OS 스풀/실물 작업이 아니며 원본 레이어·픽셀·DPI·경로·dirty·그림 이력을 바꾸지 않는다. 인쇄옵션은 settings/printing.json으로 별도 저장한다. 저장 검증과 독점 임시파일 쓰기/동기화/교체를 사용하며 실패하면 이전 설정과 외부 임시파일을 보존한다. 손상 설정은 확인 없이 덮어쓰지 않는다.

한도는512준비페이지/소스128MiB·작업공간 메모리, 용지1..2000mm·여백0..500mm(남는 영역필수), 배율1..400%, 가상36..300DPI/종이당4M픽셀이다. 드라이버 좌표/해상도 한계를 추가 확인한다.

소프트웨어 검증은 물리mm·서로다른DPI의 실치수·세로/가로·맞춤·클립·범위·흰배경 알파·가상PDF·설정 재시작/실패·프린터없음·스풀실패/취소의 가짜싱크 및 실제앱입력이다. 자동검증은 실물 프린터에 종이를 보내지 않는다. 실제용지실치수·해상도·프로파일/종이/잉크 색검증은 별도 하드웨어 과제로 남는다.
