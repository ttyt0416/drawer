# 096 — 타원·다각형 선택과 선택 합성

Ellipse select는 두 모서리를 드래그해 타원을 만든다. Polygon select는 같은 입력 장치로 꼭짓점을 클릭하고 Enter로 닫는다. 펜의 접점 ID는 클릭마다 달라도 같은 장치의 다각형을 이어간다. Backspace는 마지막 꼭짓점을 지우며 최소 하나를 유지한다. Escape, 초점 상실, 보기/문서 리비전/프레임/도구/선택 연산 변경, 모달 열기는 초안을 취소한다. 추가 꼭짓점은 실제 캔버스 영역에서 누른 접점만 받으며 다른 UI 클릭을 꼭짓점으로 넣지 않는다. 선 미리보기는 기존 문서→보기 투영과 뷰포트 자르기를 공유한다. Enter 전에는 문서/픽셀/dirty/이력을 바꾸지 않는다.

Replace/Add/Subtract/Intersect는 타원·다각형뿐 아니라 사각형/올가미에서도 사용할 수 있고 기존 마술봉과 같은 로컬 설정 combine을 공유한다. 선택이 없을 때 Replace/Add는 빈 선택에서 시작하고 Subtract/Intersect는 전체 캔버스를 기준으로 한다. 명시적 빈 마스크는 실제 빈 선택이다. 입력 a,b는0~255 강도이며 Add=a+b-round(ab/255),Subtract=round(a(255-b)/255),Intersect=round(ab/255)다.128과128은192/64/64가 된다. 포함/일치 영역도 이 규칙을 적용하므로 반투명 선택을 자신과 교차하면 강도가 감소한다. 결과가 같으면 Undo/dirty를 추가하지 않는다.

도형은 문서 픽셀 좌표로 받고 원래 페이지 격자의4×4 표본으로 저장한다. 타원은 정규화된 거리 제곱≤1, 다각형은 even-odd 내부 판정으로 오목/역방향/교차 경로를 처리한다. 도형의 새 영역은 캔버스에 자르며 합성할 기존 선택은 이동·변환된 캔버스 밖도 보존한다. 저장 형식은 기존 Scene 선택 마스크이므로 포맷 버전은34 그대로다. 최근/이름 있는 선택·한 Scene Undo/Redo·문서 저장/열기를 공유한다. 래스터/셀 픽셀은 쓰지 않는다.

타원/사각형은 유한하며 폭·높이가0이 아니어야 하고 다각형은3~4096개 유한 꼭짓점과 비공선 영역을 요구한다. 원래 페이지 좌표±100만,32768변/런,4Mi 픽셀,64Mi 도형 판정 작업,Scene4MiB 및 기존 문서/이력 예산을 적용한다. 실패는 이전 선택을 유지한다. 기존 사각형/올가미 Replace의 큰 도형 행 스캔 경로는 유지한다.

자체 생성 자료로 경계128 합성의192/64/64·타원9/16 표본143·동일 타원143의206/63/80·분리/포함/일치·역방향/오목 다각형·0폭/공선/NaN 거절·원래 페이지90도 변환·이동된 밖 선택 보존·한 Undo/Redo/문서 재열기를 확인한다. 실제 egui 입력 경로에서 마우스/합성 펜·보기90도/확대1.5·타원 드래그·클릭별 접점 변경·다각형 Backspace/Enter·네 연산/무변경·여섯 취소 조건·픽셀 불변·로컬 설정 재열기를 검사한다. 물리 펜 센서는 별도다.
