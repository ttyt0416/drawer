# 085 — 중간색·유사색 격자

Color 패널의 Intermediate and similar colors에서 두 독립 격자를 연다. Use current as first/second color로 고정된 양 끝 RGBA를 정하고 Swap으로 교환한다. 중간색은 행 우선 순서에서 양 끝을 포함하는 균등 비율로 다시 표본화한다. 한 칸만 있으면 중간값이다. RGB는 알파 가중 보간하고 알파도 보간하며,완전히 투명한 두 끝에서는 숨은RGB를 선형 보간한다. 같은 두 RGBA는 모든 표본에서 byte 그대로 유지한다.

유사색은 현재색의 H/알파를 고정하고 가로축 S·세로축 V를 ±범위 안에서 균등 표본화한다. 허용 범위0–1에서 제한하며 한 행/열의 축은 중앙값이다. 무채색의 H는 색 선택기의 마지막 유효 메타데이터를 사용한다. 범위와 기준색은 격자 밀도와 독립이다.

각 격자에 행/열1–16,타일12–64px,격자선 표시를 따로 저장한다. 타일/선 변경은 색 계산에 참여하지 않는다. 밀도를 높이면 같은 정규화 좌표의 색이 유지된다. 창과 격자에는 스크롤이 있고 수치줄은 좁은 폭에서 줄바꿈한다. 마우스 선택과 Tab 후 Enter/Space 색 선택을 지원한다.

색 선택은 전경/색 이력만 바꾸고 문서 픽셀/Undo/dirty는 변경하지 않는다. 두 끝 RGBA·샘플 수·표시·S/V 범위·창 표시 상태는 로컬 작업공간에 보존한다. 구형 누락은 독자 기본값이다. 실제 펜 센서는 별도 대기다.

검증: 흑/백의128 중간값·동일 두 색의 투명RGB 포함 불변·투명 빨강/불투명 파랑의 파랑128알파·색역 경계·단일 칸 현재색·3×3/5×5 공통 중간값·5×5/9×9의 모든 공통 유사색 좌표·타일/격자선 변경 불변과 잘못된 범위를 검사한다. 실제 키보드 선택,120×140 작은 화면,표시/샘플 설정 재시작,문서 불변을 시험하며 설치본도 같은 검증을 실행한다.
