# 164 — 로컬 참고 색 분포·광원/그림자색 보정층

Layers의 Local reference colors는 로컬 PNG/JPEG/BMP/TIFF(페이지 선택 포함)를 기존 안전한 읽기·방향·ICC 변환 경로로 디코드한다. 참고는 sRGB RGBA8의 최대4M픽셀, 디코드 예산64MiB다. α 가중 RGB 평균/공분산을 온라인 누적하고 완전 투명 픽셀의 숨은 색은 제외한다. 문서의 기존 래스터 루트 합성을 sRGB로 변환해 통계를 구한다. 문서 표본은 셀 중심의 결정적인 균등 격자, 최대65536개이며 층/폴더 수를 고려해 추정4M개 노드 표본 예산으로 줄인다. 확대된 전체 해상도의 공간 배치나 개별 물체 의미를 맞추지는 않는다. 보정층 뒤에 합성하는 페이지 개체와 애니메이션 셀은 통계/보정 범위에서 제외되며 창에 이를 표시한다.

독립 수식은 RGB 평균/공분산의 whitening/coloring이다. 대칭3×3 공분산을 Jacobi 회전으로 분해하고 참고 제곱근×소스 역제곱근을 사용한다. 소스 고유값1e-8 이하는 역변환0으로 처리한다. 특이한 회색/단색에도 유한한 결과를 만들며 단색 참고는 그 평균으로 수렴한다. 완전 투명 참고/소스는 유효 표본이 없다고 거절한다. 변환 RGB를0–1로 제한한 뒤 원래 색과 강도0–1로 섞는다. 저장 값은 유한한 행렬/바이어스와 강도이며 불안정한 큰 수를 거절한다. 비공개 원본 알고리즘 일치는 목표가 아니다.

Local light / shadow colors는 밝은 영역과 어두운 영역의 색을 따로 고른다. sRGB 명도 L=0.2126R+0.7152G+0.0722B를 사용해 각 채널 tint=shadow×(1−L)+light×L, 결과=RGB×2×tint로 정한다. 색0.5는 중립이다. 범위를 제한하고 원본과 강도로 보간한다. 이는 사용자가 지정하는 명암색 보정이며 3D 형상/광원 위치를 추정하지 않는다. 모델·서버·자산 다운로드는 없다.

둘 다 루트 래스터 합성 위에 보정층을 생성한다. 기존 래스터의 RGBA8/16, 위치, 마스크와 문서 프로필을 보존한다. 자체 문서v77의 Adjustment.local에 통계 행렬/바이어스 또는 두 색과 강도를 저장하고 참고 이미지/경로를 문서에 저장하지 않는다. 재열기와 계산에 원본 참고 파일이 필요 없다. 기존 Color correction layers에서 보정층을 선택해 강도 또는 두 명암색을 다시 편집할 수 있다. 보정층 불투명도/마스크/숨김/폴더 합성 규칙을 공유하며 최종 알파는 바꾸지 않는다. 문서 RGB↔sRGB 부동 변환 안에서 계산하고 문서 RGB 반전은 기존 순서를 유지한다. 레거시8비트 문서도 이 보정이 있으면 부동 합성을 사용한다.

작업은 문서 스냅샷에서 별도 실행한다. 통계/공간 효과 생성/미리보기의 중단 검사와 입력·전후 미리보기, Cancel/Escape, 닫기, 원본 문서/수정/프레임/설정 변경 결과 폐기를 제공한다. 새로운 미리보기는 이전 계획을 먼저 버린다. 열린 문서·작업 사본과160MiB 처리 여유를 합쳐256MiB 예산을 사전 검사하고 결과/Undo/장면 한도를 다시 검사한다. 실패/취소/파일 읽기 오류는 원본에 부분 반영하지 않는다. 적용은 한 Undo다. 강도0과 중립 명암색은 새 층을 만들지 않고 dirty/Redo/이력을 유지한다. 미확정 초안은 정상 저장을 막고 먼저 적용 또는 취소하도록 안내한다.
