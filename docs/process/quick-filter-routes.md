# 빠른 필터·효과 프리셋과 출력 경로 (174)

`quick-filters`와 `pixel-filter-route`는 기존 일괄 필터 창의 비동기 작업·입력 스냅샷·미확정 저장·취소·한 Undo 경로를 공유한다. 여러 층 일괄 처리 기능은 그대로 유지한다.

## 입력과 출력

| 경로 | 입력 | 출력 |
|---|---|---|
| Quick preset | 현재 층 또는 현재 프레임의 전체 보이는 합성 | 원본을 보존한 새 래스터 |
| Pixel filter | 현재 층 | 현재 픽셀 적용 또는 새 결과 래스터 |
| Pixel filter + 전체 합성 | 현재 프레임의 전체 보이는 합성 | 새 결과 래스터 |

새 결과는 Normal/100%로 모든 페이지 소스 위에 놓인다. 원래 층·편집 개체·효과·마스크·애니메이션은 유지한다. 원본도 계속 보이므로 반투명 부분의 합성 농도가 높아질 수 있다. 전체 페이지의 전후 미리보기로 판단한다. 강도0도 새 결과 경로에서는 복사 층을 만들고, 기존 래스터의 현재 픽셀 경로에서는 불필요한 Undo/dirty를 만들지 않는다.

현재 래스터 입력은 저장된 원본 픽셀이다. 기존 라이브 효과는 그 원본에 남아 원본 변경에 따라 다시 계산한다. 표시된 효과·마스크·다른 층·텍스트·벡터·3D까지 포함하려면 전체 합성을 선택한다. 현재 비래스터 입력은 기존 명시적 래스터 변환기로 렌더한다. 연결된 벡터 클리핑 집합도 변환 입력에 포함될 수 있다. 새 결과 경로는 그 렌더 픽셀만 가져오며 원본 편집 정보는 보존한다.

현재 비래스터에 현재 픽셀 적용을 선택하면 원본 종류와 텍스트/벡터/재질/기하/라이브 편집 정보 손실을 표시한다. 미리보기를 먼저 준비하고 손실 확인을 선택해야 Apply가 활성화된다. 원본과 변환되는 연결 집합의 복원은 한 Undo다. 기존 래스터의 통상 픽셀 적용은 Apply와 Undo를 사용한다. 잠긴 입력에 대한 쓰기는 기존 편집 보호 규칙을 따른다. 합성/변환/필터의 지원 범위와 메모리 초과는 미리보기 전에 또는 계산 중 오류로 반환하며 부분 적용하지 않는다.

## 필터와 프리셋

Detail/pixel filters, motion/radial/spin/lens blur, Gaussian, surface effects의 기존 매개변수를 사용한다. 빠른 효과는 결과 픽셀로 만든다. 기존 효과 편집기의 라이브 효과 경로도 유지한다. 필터 변경 범위를 현재 선택으로 제한할 수 있다. 새 층은 입력의 처리 결과 전체이며 선택 밖은 입력 픽셀을 복사한다.

Line contrast / Soft blur / Warm glow 기본 프리셋과 최대32개의 로컬 사용자 프리셋을 제공한다. 이름은64자 이내·공백 이름/제어문자/중복 이름을 거절하고 같은 이름 저장은 교체한다. 프리셋은 작업·매개변수·Quick/Pixel 경로·현재/합성 입력·현재/새 출력·대상 종류만 기록한다. 문서/층/개체 ID를 담지 않는다. 다른 종류의 층에 불러오면 종류 불일치를 표시하고 호환 층을 선택하거나 명시적으로 종류를 맞춘다. `other` workspace 가져오기/내보내기에 포함하며 저장 실패는 이전 프리셋 목록을 복원한다.

## 라이브 효과와 삭제

기존 효과는 안정된 원본 층 ID 또는 페이지 합성 순서에 결합한 매개변수로 저장한다. 효과 알고리즘1을 문서에 명시한다. 원본이 바뀌면 렌더 캐시를 다시 생성하고, 새 래스터 결과는 그대로 유지한다. 첨부 효과는 소유자의 원본 픽셀만 읽고 보정층은 앞선 합성 결과만 읽으므로 임의의 역방향/순환 소스 그래프를 만들지 않는다. 지원하지 않는 소스 참조 필드와 알 수 없는 알고리즘은 거절한다.

래스터/벡터 소유자에 활성 효과/보정/마스크가 붙어 있으면 층 삭제를 즉시 적용하지 않는다. 삭제 영향과 전후 결과를 준비하고 확인한다. 효과와 함께 삭제하거나, 삭제 전 현재 프레임의 보이는 페이지 전체를 독립 래스터로 보존하는 선택을 제공한다. 보존 층은 해당 효과뿐 아니라 페이지의 모든 보이는 소스를 포함하며 다른 원본도 남으므로 투명 농도가 달라질 수 있다. 결과 미리보기 후 한 Undo로 확정한다. 삭제 취소는 원본을 유지하고 원본/프레임 변경은 이전 삭제 계획 적용을 막는다. 별도 보정층은 원래의 합성 순서를 계속 따른다.

## 저장과 검증

네이티브v85에 결과 층과 마지막 경로·입력/결과 식별 기록을 저장한다. 식별 기록은 적용 이력이며 래스터 결과가 원본을 다시 읽게 만드는 의존성은 아니다. 결과가 저장 픽셀을 갖고 라이브 효과가 원본/매개변수를 가지므로 렌더 캐시는 유일한 저장소가 아니다. 캐시 없는 재열기에서도 계산할 수 있다. 이전 헤더 위장과 잘못된 경로·대상·알고리즘은 거절한다.

검증은 현재/전체 합성 차이, 원본 보존, 새 층/현재 픽셀/비래스터 손실 확인, 강도0,16비트 알파1, 취소/미확정 저장/한 Undo, 로컬 프리셋 재시작·타문서 적용·ID 배제, 라이브 원본 수정과 고정 결과 불변, 삭제/래스터 보존/삭제 취소, 잘못된 참조/알고리즘, 네이티브/캐시 재생성을 포함한다. 물리 펜 검증은 대기한다.
