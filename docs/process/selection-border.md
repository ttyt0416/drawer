# 100 — 선택 테두리 그리기

Draw selection border는 현재 래스터에 안쪽/중앙/바깥쪽 정렬·0~128 문서 픽셀 폭·RGBA색으로 선택 경계를 그린다. 현재색이 초깃값이고 적용 창에서 바꿀 수 있다. Apply는 문서ID/리비전/프레임과 고정한 래스터를 확인하고 한 문서 상태 Undo로 확정한다. Cancel/닫기/Escape는 초안을 버린다. 래스터가 아닌 대상, 숨긴/잠긴/잘못된 대상, 선택 없음은 거절한다. 명시적 빈 마스크는 무변경이다.

경계는 선택 마스크의 강도0과0초과의 기하학적 경계이며 반투명 강도 사이의 내부 이음선을 그리지 않는다. 사각형 또는 RLE 마스크에서 바깥선과 구멍을 구하고 원래 페이지→문서 변환·선택 이동을 적용한다. 폭은 보기/페이지 확대와 별개인 현재 문서 픽셀이다. 각 픽셀의4×4 표본에서 경계 선분까지의 최소 거리로 판정한다. 중앙은폭/2,안쪽/바깥쪽은폭을 사용하고 안쪽은선택0초과,바깥쪽은선택0인 표본만 반영한다. 따라서 모서리는 유클리드 거리의 둥근 연결이 된다.

표본 강도를 현재색 알파와 한 번만 합성해 래스터에 그린다. 바깥쪽 선은 기존 선택에 다시 잘리지 않는다. 결과는 캔버스에 자르고 기존 캔버스 밖 래스터 픽셀을 그대로 보존한다. 문서 안에서 필요한 래스터 저장 영역은 기존 채우기와 같은 확장/합성/메모리 검사 경로를 쓴다. Scene 선택/이동/이름 있는 마스크/다른 개체는 복사 그대로 유지한다. 캔버스 밖으로 이어지는 선택은 실제 바깥 경계로 계산하므로 캔버스 가장자리에 가짜 닫는 선을 만들지 않는다.

작업 상한은4Mi 캔버스 픽셀·스캔당64Mi 표본×선분 검사(범위 탐색과 합성으로 최대두 번)·기존 Scene/래스터 저장/문서/Undo 예산이다. 실패는 원본을 유지한다. 넓은 폭과 복잡한 마스크가 이 상한을 넘으면 오류를 표시한다. 외부 서비스/새 의존성은 없다.

독립 수치로 직선부의1픽셀 Inside(밖0/안255),Center(밖128/안128),Outside(밖255/안0)와 중앙 빈 영역을 확인한다. 반투명128 선택의 구멍에는 지정색128이 적용되고 원래 선택은 그대로다. 음수 좌표로 이어진 경계의 캔버스 절단선 생성 방지·2배 페이지 변환+문서 이동/폭·0/1/2.5/128폭·NaN/음수/129 거절·빈 마스크·잠긴층·한 Undo/Redo·문서 재열기를 검증한다. 실제 egui Draw border 버튼의 세 정렬·보기90도/확대1.5·초안/선택 보존·Undo·Escape취소·오래된 문서 거절을 설치본에서도 검사한다.
