# 163 — 복수 레이어 필터의 원자적 미리보기·확정·취소

필터 전용 대상 목록에서 안정 ID로1–256개 래스터를 고른다. 목록에는 잠금/숨김/픽셀 잠금/연결 소스/보정층과 미지원 종류, 꽉 찬 효과 목록, 선폭/잉크 제거의 알파 잠금 제한을 계산 전에 표시한다. 선택된 부적격 대상이 하나라도 있으면 계산 전 전체를 거절한다. 레이어 선택은 그림 데이터를 변경하지 않는다. 목록은 보이는 행만 그려 큰 문서의 비지원 항목도 확인할 수 있다.

상세/픽셀/색수차/필름/연필/어안/파노라마/물결/소용돌이, 모션/방사/회전/렌즈 블러, 가우시안, 편집 가능한 그림자/발광/부풀리기/결정화를 제공한다. 기존 단일 필터와 세부값 위젯/커널을 공유한다. 공간 효과는 각 대상의 기존 목록 끝에 같은 매개변수의 효과를 추가한다. 선택 제한은 시작 스냅샷의 같은 영역을 사용하며 실시간 효과는 이를 각 항목에 복사한다. 일반 픽셀 필터는 선택 밖 원자료와8/16비트·프로필·각 층의 알파 잠금을 유지한다.

원본 문서와 분리한 작업 문서에 순차 계산하고 전체 성공한 하나의 DocumentState만 돌려준다. 중간 결과를 사용자 문서에 커밋하지 않는다. 뒤쪽 대상에서 처리량/경계/메모리 오류가 나거나 계산을 취소하면 앞쪽 결과도 버린다. 가우시안도 기존 API를 유지하면서128픽셀마다 중단할 수 있는 경로를 추가했다. 각 커널의 기존 범위/표본/메모리 제한과 전체 원본4M픽셀/256대상 제한을 적용한다. 작업공간256MiB 안에서 열린 문서·스냅샷·결과와160MiB의 보수적인 처리 여유를 사전 검사한다.

별도 계산 작업과 전체 진행률, 원본/전체 결과 미리보기를 제공한다. 원본 문서 ID/수정번호/프레임과 대상/설정이 바뀐 결과는 버린다. 옵션 변경은 이전 계획을 무효화하고 작업 중 Cancel/Escape/닫기는 즉시 초안을 버린다. 취소 작업을 중복 실행하지 않으며 원본 문서가 닫히면 남은 결과도 버린다. 저장은 전체 적용/취소를 먼저 안내한다.

Apply all은 전체 한 Undo이며 한 Undo가 모든 대상/선택/효과 목록/기록을 복원한다. 전체 항등 작업은 dirty/Redo/최근 기록을 유지한다. 문서v76의 last_batch_filter에 종류/값/당시의 안정 ID 목록을 저장한다. 과거 대상 ID는 실시간 참조가 아니며 삭제 후에도 과거 기록으로 남을 수 있다. 원본 픽셀/편집 가능한 효과 데이터는 각 층에 보존한다. 이전 헤더의 새 기록은 거절한다. 블러/공간 효과 최근 도구값은 전체 확정 성공 후에만 로컬에 저장하고 문서 Undo와 분리한다. 실패한 로컬 저장은 이전 설정을 유지하고 문서 적용 여부를 설명한다.
