# 레이어 컴프 (130)

컴프는 안정 레이어 ID와 자체 hidden/opacity/blend를 기록한다. 부모가 숨겨져도 자식의 자체 상태를 따로 기록한다. 폴더 through를 함께 기록하여 혼합 복원 후 통과/격리 모드를 정확히 되돌린다. 잠금·구분색·기하·픽셀·역할·마스크·순서는 건드리지 않는다. 표시 설정은 일반 속성 편집과 같이 내용 잠금과 별도로 전환 가능하다.

캡처/갱신/이름/삭제/전환은 문서 트랜잭션이다. ID는 삭제 후 재사용하지 않는다. 실제 현재 카탈로그 행에서만 적용 대상을 해결하므로 ID 모양만 유효한 삭제된 레이어는 건너뛰고 누락으로 보고한다. 나중에 추가한 층은 변경하지 않는다. 폴더 solo 중 캡처/적용을 거절하고, 새 종이질감/클리핑과 통과 상태가 충돌하면 전부 거절한다.

미리보기는 문서를 수정하지 않는다. 전후 축소 화면, 변경·누락·미기록 수, 누락 ID를 보여 주며 확정은 한 Undo다. 문서 ID/리비전/프레임을 고정하고 Escape/닫기로 취소한다. 문서당64컴프, 컴프당16384기록/총32768, 이름64문자, JSON4MiB 및 문서·작업공간 한도를 적용한다. 자체 문서v58 저장; 일반 교환에는 현재 합성을 사용한다.
