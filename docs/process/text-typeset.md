# 고급 조판과 텍스트 도구

조판 옵션은 명시적으로 현재 세대2를 켠 텍스트에만 적용한다. 이전 기본/확장/글자군 배치는 새 옵션 없이 보존한다. 자체 네이티브v91에 실제 옵션과 Unicode/글꼴/범위/루비/변형을 저장한다. 낮은 헤더 위장은 거절한다.

Kerning은 Manual/Metrics이며 수동 간격은 -0.5~4em, 글꼴 메트릭은 실제 Rustybuzz GPOS/kern을 사용한다. Feature는 Ligatures/ContextualAlternates다. 실제 글꼴의 지원 테이블이 없으면 이름과 미지원 안내를 표시하고 문자열은 유지한다. 합자 조작은 기존 표준 합자 체크와 같은 값으로 작동한다. 글꼴/수동/문자군별 범위 서식과 대체는 글자군 단위이며 원문을 자르지 않는다.

상자 폭/열 높이의 자동 줄바꿈은 글자군·합자·루비·세로중가로 단위를 보존한다. 균등 정렬은 마지막이 아닌 자동 줄에 남은 공간을 분배한다. 각 명시적 문단의 마지막 줄은 Left/Center/Right/Top/Bottom을 저장하고 진행축의 시작/중앙/끝에 맞춘다. 세로쓰기는 위에서 아래, 열은 오른쪽에서 왼쪽이다. 일본어 전각 괄호·쉼표·마침표 등의 진행 폭을 반각으로 압축하며 라틴 조형/커닝/합자를 분리하지 않는다. Unicode bidi 0.3.18의 문단 수준과 줄의 시각 순서를 사용하고 방향 제어 문자는 원문에 남긴다. 조형 방향과 문자 스크립트를 구별하며 확장 옵션 없는 기존 배치는 보존한다.

세로쓰기 속 가로쓰기는 최대64개 범위, 각1~16 Unicode scalar다. 글자군 경계/중복/본문 길이/명시적 줄바꿈과 루비 중첩을 검사한다. 가로 조형한 범위를 한 em 폭에 축소해 하나의 세로 셀에 배치하고 원래 색/테두리/글꼴 서식 범위를 유지한다. 일반 가로쓰기에서는 원래 범위만 보존한다. 입력과 IME의 확정·취소·필드 Undo에는 범위도 함께 처리한다.

배경 RGBA는 문자색/테두리와 독립적이다. 각 배치 단위의 사각형을 합쳐 텍스트 뒤에 그리며 배경 알파0은 투명하다. 기본 문자 알파가0이어도 배경은 출력/픽셀 경계에 반영한다. 배경은 자체 문서의 실제 속성이며 미리보기만의 장식이 아니다.

CreateAction은 CreateLayerAlways/AddToSelectedText/DetectPosition, DragAction은 CreateTextBox/SelectText다. 캔버스 클릭/드래그를 별도로 캡처하고 원본 문서/수정번호/프레임/보기/입력 출처를 검사한다. 그리기 원본을 바꾸지 않고 임시 텍스트 편집을 연다. 위치 판정과 드래그 선택은 표시 순서의 보이는 텍스트 개체를 고르며 SelectText는 개체 선택이다. 추가 동작은 선택된 텍스트의 커서 끝에서 입력을 이어간다. 드래그 상자는 문서 좌표의 시작점·폭으로 생성한다. Escape/취소/원본 변경/포커스 상실은 캡처를 버린다. Apply는 기존 문서 Undo 한 번이다.

ApplyTarget은 None/NewTextOnly/SelectedText다. 기본서식 저장은 그림을 직접 바꾸지 않으며 SelectedText는 선택 개체의 임시 서식 편집으로 확인한다. 기존 원문/루비/변형을 보존하고 IME 중 변경은 거절한다. 텍스트가 아닌 소스는 설정을 저장하기 전에 거절하며 종류별 색인을 혼용하지 않는다. 설정 저장 실패는 이전 설정을 복원한다. 새 텍스트 기본서식, 적용대상과 Quality Fast/High/Auto는 로컬 workspace other 범위로 저장한다. 품질은 임시 보기 필터만 조절하고 기존 보기 필터/실제 조형/문서/최종 출력은 바꾸지 않는다. 시스템 글꼴/원제품 리소스를 복사하지 않으며 클라우드 경로는 없다. 실물 펜 검증은 대기한다.
