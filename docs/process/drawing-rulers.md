# 095 — 직선·대칭·원근 그리기 보조

Drawing rulers에서32개까지 이름/ID가 있는 보조를 만들고 수정/삭제/활성화한다. 직선과 대칭축은 서로 다른2점, 방사는 중심1점과2~16개 팔, 원근은1/2/3개 소실점이다. 입력 좌표는 문서 픽셀이며 저장 좌표는 기존 Scene.transform의 원래 페이지 좌표다. 편집 창은 초안만 바꾸고 Apply가 하나의Scene Undo를 만든다. Cancel은 원본을 유지하며 오래된 문서 리비전의 적용은 거절한다. 문서v34에 보조/활성 ID를 보존하며 구형v33 이하의 누락 데이터는 빈 기본값이다.

활성 보조 한 개가 획을 보조한다. 직선은 무한 직선으로 투영한다. 원근은 누른 위치를 지나고 소실점으로 향하는 후보 중 첫 이동 방향과 가장 가까운 선을 고정한다. 이후 이동이 다른 후보에 가까워져도 같은 선을 유지한다. 중복 소실점은 같은 후보로 작동하고 시작점과 소실점이 겹친 영벡터는 건너뛴다. 모든 후보가 영벡터이면 해당 획을 유한 자유 좌표로 처리한다. 보조는 문서 좌표에서 계산하며 확대/회전/반전 보기와 별개다. 보조 표시에는 기존 문서→보기 투영·뷰포트 자르기를 사용한다. 기존 Guides 표시 설정으로 표시를 바꾼다.

축 대칭은 반사, 방사는 중심 주위 등각 회전으로 획을 복제한다. 각 팔이 독립된 안료/혼색·필터·질감·표본 상태와 선택/참조 판정을 갖는다. 기울기/방향·비대칭 팁/잎 장식·산포의 좌표와 복제 도장 정수 오프셋을 변환한다. 임의각 복제 도장 오프셋은 가장 가까운 정수 픽셀이다. 겹치는 픽셀은 기본 획,증가하는 팔 순서의 첫 변경만 반영해 대칭축의 반투명 획을 중복 합성하지 않는다. 미리보기와 최종 합치기가 같은 순서다. 모든 팔은 한 픽셀 명령/한 Undo로 확정한다. 수채 후처리는 각 팔에 적용한다. 메모리는 전체 획 예산을 분배하고 최종 단일 이력 합치기 공간을 예약한다.

V/ruler-snap은 현재 세션에서 이후 획의 스냅/복제를 켜고 끈다. 문서·보조 개체·그림 이력·로컬 저장 설정에는 쓰지 않으며 앱 재시작 시 켜진다. 누른 획이 있으면 기존 규칙으로 마친 뒤 이후 획부터 적용한다. 펜 Down과V가 같은 프레임에 들어와도 준비된 새 접점을 잃지 않으며 반복V는 두 번 토글하지 않는다. 마우스 가상압력/획끝 재구성과 일반 펜 경로가 같은 보조 엔진을 사용한다. 연결선의 다음 시작점도 실제 보정된 끝점으로 기억한다.

검증은 생성한 자체RGBA 자료만 사용한다. 직선의 문서 픽셀 투영·축/4방향 대칭 위치·축 위 알파128 단일 적용·미리보기/최종 RGBA 일치·선택 밖 쓰기 방지·한 Undo/Redo·보조 편집 Undo·문서 재열기·1/2/3점 및 중복/겹친 소실점·방향 고정·마우스 재구성을 확인한다.5개 방향원×일반/산포/비대칭 잎 장식의15조합을 단독 획+수학적 반사 기대값과 전체RGBA로 비교하며 알파0의 숨은RGB도 포함한다. 실제 egui Apply 버튼·마우스/합성 펜·보기90도/확대1.5·V와Down 동시/반복V·끄기 후 자유 획·스냅 토글의 문서/이력 불변·취소/재열기를 검증한다. 물리 펜 센서는 별도다.
