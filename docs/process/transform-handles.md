# 변형 핸들·각도 맞춤·유효 사각형 (169)

Scale and rotate의 도구 속성 스크롤 영역 위에 문서 좌표를 쓰는 핸들 패드가 있다. 상자 안 드래그는 이동, 흰 모서리는 비율 유지 확대/축소, 변 중앙의 사각 핸들은 한 축 확대/축소, 상자 바깥은 회전이다. Keep current aspect ratio를 끄면 모서리의 두 축을 독립 변경한다. 변 중앙은 비율 잠금과 관계없이 한 축만 바꾼다. 반대 모서리/변 중앙을 고정한 채 계산하고0축척·유효 범위 밖 기하는 거절한다. 음수 축척은 반전이다. Fit transform handles는 현재 기하를 패드에 맞추며 문서를 변경하지 않는다. 패드는 보기 줌/회전과 분리한 문서 좌표로 동작하며 캔버스 밖 대상도 표시한다. 선택 픽셀 모드는 선택 경계를 사용한다. 실제 문서 미리보기는 별도 작업으로 준비한다.

Angle snapping은 비율 잠금과 별개인 로컬 도구 설정이다. 기본 간격15도, 허용 범위1~90도다. 활성 시 회전 핸들과 직접 각도 편집을 가장 가까운 간격으로 맞춘다. 반 간격 동률은0에서 멀어지는 방향으로 반올림하고 회전 핸들은0~360도로 정규화한다. 두 옵션은 서로 값을 바꾸지 않는다. 로컬 workspace 설정에 저장하며 문서 이력/dirty에 넣지 않는다. named workspace의 other 설정에도 포함한다.

기본 창에서 Free mode/Perspective mode를 명시적으로 고르면 래스터의 별도 사각형 도구로 이동한다. 해당 창의 Basic mode로 돌아갈 수 있다. 미확정 초안의 모드 전환은 원본에서 다시 시작한다. 벡터/3D 등 래스터 이외 대상의 사각형 변형은 먼저 래스터 변환을 사용한다. 네 모서리는 기존0~1 편집 영역 좌표와 원근 깊이 투영을 사용한다.

오목·자기교차·뒤집힌 감김·면적0·원근 지평선을 넘는 사각형은 유효 기하로 채택하지 않는다. 잘못된 모서리 후보와 경고를 따로 보관하며 마지막 유효 기하/이미지/준비 결과를 유지한다. Apply/Enter/저장 중 Apply 선택도 잘못된 후보를 확정할 수 없다. 유효한 모서리로 고치거나 Reset corners 후 다시 미리보기한다.0축척 등 잘못된 기본 변형도 확정을 막고 마지막 유효 이미지를 유지한다. 픽셀 출력/작업/Undo 예산 초과는 미리보기 작업에서 거절한다.

핸들을 놓으면 비동기 미리보기를 준비하고, 준비된 유효 결과만 Enter 또는 Apply로 한 번 확정한다. 숫자 입력 등 egui가 키보드를 사용하면 Enter로 부모 변형을 강제 확정하지 않는다. Escape/창 닫기는 원래 픽셀·선택·개체/이력을 유지한다. 미확정 저장의 확정 후 저장/취소 후 원본 저장/계속 편집은165의 공통 절차를 따른다. 문서v80에 마지막 확정 변경의 각도/문서 행렬 또는 유효 사각형/원본 영역/원근 여부를 과거 기록으로 저장하며 실제 픽셀/좌표와 함께 한 Undo로 복원한다.

검증은 핸들 분류·네 모서리 반대 기준점·변 중앙 한 축·잠금 해제·이동/회전·음수/0축척·1×1/극소 상자·15도 경계±ε/음수/360·범위 밖 간격·잘못된 사각형·로컬 설정 저장·각도/행렬 재열기/이전 헤더 거절/한 Undo를 포함한다. 앱은 실제 마우스 드래그와 자동 미리보기·스냅/비율 독립·Enter/Escape·잘못된 모서리 드래그의 마지막 유효 이미지 유지/확정 거절·수정 후 채택과 재열기를 검사한다.
