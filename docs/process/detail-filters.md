# 158 — 샤픈·언샤프·색/명도 노이즈 제거

Sharpen은 네 이웃의 Laplacian과 강도0–5를 사용한다. 이웃 알파와 현재 알파의 작은 값으로 기여도를 제한해 투명색이 경계로 번지지 않게 한다. Unsharp는 반경0–32px, 양0–5, 임계0–1의 분리 가우시안으로 원본과 흐림의 차이를 더한다. 임계 이하 채널은 그대로 둔다. 표본은 원래 경계에 clamp하며 RGB×알파/알파를 계산한다. 출력 RGB는0–1로 clamp하고 원래 알파와 배치를 유지한다.

Reduce noise는 Y=(R+2G+B)/4, Co=(R−B)/2, Cg=(−R+2G−B)/4의 문서 RGB 성분에서8이웃의 알파 가중 중앙값을 사용한다. 명도와 색 노이즈 감소0–1을 독립 적용한다. 네 방향의 마주 보는 이웃 둘이 현재 성분과 허용차0–1 안에 있으면 그 성분을 보호하여 이어진 가로/세로/대각1픽셀 선을 남긴다. 허용차가 크면 더 많은 세부를 보존한다. 이 필터는 통계적 점 노이즈 억제이며 먼지 면적 판정과 별개다. 고립된 실제 점도 노이즈와 구별할 수 없으므로 전후 미리보기에서 강도를 선택한다.

실제8/16비트 표본과 문서 프로필을 유지하며 알파 잠금 여부와 무관하게 원래 알파·숨은 투명색·배치·선택 밖 원자료를 보존한다. 선택 coverage로 결과를 섞고 마스크는 고정한다. 균일색은 저장 경계에서도 정확한 무변화다. 강도/양/반경0·두 노이즈 강도0·빈 선택·저장 결과 무변화는 dirty/Redo/마지막 기록을 보존한다. 작은 부동소수점 계산 오차를 원자료에 덮어쓰지 않는다.

원본4M픽셀/스냅샷32MiB,64M이웃 표본과256MiB 작업공간을 검사한다. 분리 가우시안의 중간 행/결과/문서 사본과 모든 열린 문서의 남은 예산을 포함한다. 행/열/출력128픽셀마다 중단을 확인한다. 작업은 별도 계산에서 진행하고 Cancel/Escape/닫기는 즉시 초안을 버린다. 이전 작업이 끝나기 전에는 새 작업을 겹치지 않으며 공간 블러와 동시에 열지 않는다. 원본ID/수정번호/프레임/층/설정이 바뀐 결과와 실패한 이전 계획을 거절한다.

확정은 픽셀과 설정 기록을 한 Undo로 바꾼다. 앱 저장은 미확정 필터를 확정/취소하도록 안내하고 저장을 중단한다. 저수준 저장에는 원본만 들어간다. 문서v71의 선택적 Scene.last_detail_filter에 마지막 확정 매개변수를 보존하며 Restore last applied settings로 불러온다. 이는 구워진 결과의 기록이며 실시간 보정층이 아니다. 이전 문서의 누락은 기록 없음이고v70 이하 위장 헤더/잘못된 설정은 거절한다.

독립적인 Laplacian/2차원 가우시안, 균일색과 저장 가장자리, 점 노이즈와 색/명도 분리,1픽셀 선, 임계1, 과도 강도 clamp, 투명색/반투명/16비트 극저알파, 선택 밖/빈 선택/알파 잠금, 범위/처리량/메모리 거절과 계산 취소를 검증한다. 앱 입력 경로의3종 마우스 미리보기/확정, 미확정 저장 안내와 원본 보존, 영효과 dirty/Redo, 오래된 설정/프레임, 실패 계획 폐기, 큰 반경 비동기 취소와 네이티브 재열기/Undo를 검사한다. 실물 펜 검증은 별도 대기한다.
