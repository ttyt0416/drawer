# 도형 작성

Shape creation에서 Rectangle/Ellipse/Polygon/Polyline/Bezier, Straight line/Spline/Quadratic Bezier/Cubic Bezier, By click/By drag, Create fill/Create line/Create both line and fill을 선택하고 Draw shape on canvas를 누른다. By click은 각 클릭을 제어점으로 추가하며 Enter로 확정하고 Backspace로 마지막 점을 지운다. By drag는 사각형/타원에서 첫·마지막 모서리, 다른 도형에서 드래그 경로를 제어점으로 사용한다. Escape·포커스/문서/프레임/보기/설정/대상 변경·장치 취소는 초안만 버린다. 확정 전에는 윤곽만 표시한다.

Free는 원래 점을 사용한다. Specified ratio는 처음/마지막 점의 폭·높이를 지정 비율로 확장하며 중간 제어점도 같은 축 변환을 적용한다. Specify length는 처음→마지막 방향의 길이를 지정값으로 맞춘다. 사각형/타원의 중심 시작, 경로 닫힘, 모서리 trim, 제어점 격자 스냅을 제공한다. 스냅은 제약 계산 전에 문서 좌표의 지정 간격으로 반올림한다. 중심 시작은 사각형/타원에 적용한다. 사각형은 둥근 모서리를 반쪽 변 길이로 제한하고 직선 다각형/폴리라인은 각 접점에서 인접 변의 절반 이내로 잘라 2차 곡선으로 잇는다. Polygon과 Fill은 자동으로 닫힌다.

Spline은 독립적인 균일 Catmull–Rom 보간(구간당32표본)이다. 2차 베지어는 내부 제어점 평균을 단일 제어점으로, 3차는 첫/마지막 내부 제어점을 두 핸들로 사용한다. 내부 점이 없는 두 점은 선형 핸들을 생성한다. 2차/3차는 각각64/96구간으로 평가한다. 이 정의는 타제품의 수치 호환을 뜻하지 않는다. 열린 곡선은 처음/마지막 제어점을 보존하고 spline은 모든 제어점을 통과한다. 채움은 even-odd 규칙으로 자기 교차 영역을 처리한다.

래스터는4×4 면적 표본과 premultiplied RGBA 평균을 구한 뒤 원래 선택 강도를 한 번만 곱해 현재 래스터에 합성한다. 기존 바깥 픽셀/선택은 보존한다. 벡터는 선택된 벡터층에 추가하거나 새 벡터층을 만들고 다음 작성 대상으로 선택한다. 벡터 선/채움 색은 따로 저장·표시하며 원래 제어점·작성 옵션·생성 좌표계를 v38 문서에 함께 보존한다. 선 폭은 페이지의 원래 좌표 단위이며 기존 벡터와 같은 페이지 변환을 따른다. 부분 래스터 선택으로 편집 벡터를 만들 때는 선택 해제를 안내하고 무변경 거절한다. 잠금/숨김 대상은 수정하지 않는다.

각 확정은 벡터층 생성까지 한 문서 Undo이며 설정은 로컬 작업공간에 보존한다. 기존 벡터의 누락 fill/stroke/definition은 채움 없음·선 있음·작성 이력 없음으로 읽는다. 채움만 있는 벡터도 기존 선 참조 경로에서 인식한다. 교차점 지우기는 채움 있는 경로를 분할하지 않고 거절한다.

입력 제어점128개·생성 점4096개·벡터 전체8192점/128경로·래스터4Mi픽셀·64Mi 표본/선분 작업·Scene JSON4MiB와 기존 문서/Undo/작업공간 메모리 예산을 적용한다. 비유한 수치·0길이·무면적 fill·한도 초과는 원본을 바꾸지 않는다.

독립 검증은 네 곡선의 같은 제어점/끝점/중간점/접선, 다섯 도형×네 곡선×세 선/면 방식×두 출력 대상, 중심/둥근 모서리/스냅8조합의 저장/Undo, 고정 비율·길이·0길이·밖으로 드래그·자기 교차·부분 선택/구멍·잠금·페이지 좌표 변환·채움 참조/설정 재열기를 포함한다. 실제 생산 입력 경로는 마우스/가상 펜×클릭/드래그×래스터/벡터8조합에서 확정/한 Undo/Redo와 네 취소를 검증한다. 실제 펜 센서는 별도다.
