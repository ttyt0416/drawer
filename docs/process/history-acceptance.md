# Item 291: semantic history acceptance

`Document::audit_history_roundtrip()` is a read-only audit on detached document and history copies. It walks every retained Undo and Redo record. The five transaction formats are Pixel, Pixels (with optional scene), Multi (with optional scene), Scene and full DocumentState. It constructs the expected destination from the recorded payload, executes the real Undo/Redo path, compares complete typed states, returns to the original state and traverses again. This compares dimensions/DPI, color profiles/precision, layer pixels/storage/placement/lock/name, complete scene metadata and object IDs/geometries, selection, material/font snapshots and animation data. Layer-comp recall policy stays the defined local preference. Resource admission bounds the copy; ordinary edits do not run this diagnostic automatically.

Core regression tests exercise all five formats, nonempty Redo branches, saved/dirty boundaries, no-op/failure preservation, malformed retained after-state detection, new-edit branching and original document/history/path/revision invariance. Typed equality is used instead of unstable session identifiers or serialization order.

`scripts/test-checklist.ps1 -Item 291` runs the packaged acceptance entry point and 13 feature regression groups: layers, folders, groups, properties, selection, merge, masks, clipping/solo/quarter-turn, material, rich text, timeline timing, world placement/physics and movement. It includes hidden children surviving folder solo, exact restoration of saved visibility flags, deleted hidden clipping bases not retargeting, and 90-degree texture/line clipping invariance. The full workspace suite additionally runs feature-specific command/preview/apply/Undo/Redo and native regression tests; its result summary is retained separately with the source/test-log hashes.

Local receipts identify the executable and the explicit regression groups. Parameter domains are bounded by their feature tests. File writes and user preferences retain their documented F/S/V contracts; this audit does not convert them into drawing Undo.
