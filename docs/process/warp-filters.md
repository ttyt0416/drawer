# 162 — 어안·파노라마·물결·소용돌이

기존 비동기 픽셀 필터 경로에 독립 역변환4종을 연결한다. 출력 경계를 유지하고 역변환 위치의 실제8/16비트 premultiplied bilinear 표본을 읽는다. 소스 경계 밖은 투명하며 숨은 투명 RGB가 색에 섞이지 않는다. 선택은 입력 표본을 자르지 않고 최종 결과와 원본을 coverage 혼합한다. 선택 밖 원자료와 문서 프로필/정밀도는 보존하고 알파 잠금은 정확한 기존 알파를 유지한다.

어안은 중심에서 정규화한 반경r<1에 대해 원본 반경 배율1+강도×(r²−1)을 사용한다. 강도−1–1/반경0–32768px를 받으며 바깥 원은 그대로다. 파노라마는 가로 시야각0–179°의 원통 역변환으로 x를 tan(theta)/tan(반시야각), y를1/cos(theta)로 읽는다. 보이지 않는 뒤쪽은 투명하다.0°와1e−6° 미만은 수치적으로 안전한 항등이다. 물결은 가로/세로 진폭0–1024px, 각 주기0.25–32768px, 위상을 받아 반대 축 위치의 사인으로 표본 위치를 이동한다. 위상은360° 주기다. 소용돌이는 원 안에서 −각도×(1−r)²로 역회전한다. 각도−720–720°와 반경0–32768px를 받고 양의 출력은 시계 방향이다.

원형/파노라마 중심None은 소스 저장 경계의 중심을 자동 사용한다. 명시적 중심은 문서 픽셀±1M 범위이며 저장 후 유지한다. 중심은 고정점이다. 강도/시야각/진폭/각도0와 원형 반경0은 dirty/Redo/최근 기록을 유지한다. 잘못된 수치/주기0/시야각180°는 계산 전에 거절한다. 출력4M픽셀·원본32MiB·64M 추정 표본과 열린 문서/미리보기/Undo 메모리 한도를 공유하며 픽셀128개마다 중단을 확인한다.

문서/프레임/대상/설정이 바뀐 결과와 실패한 이전 계획은 적용하지 않는다. 전후 미리보기/계산 취소/Escape/닫기/미확정 저장 안내는 기존 필터 창을 사용한다. 적용은 한 Undo이며 문서v75의 last_detail_filter.operation.Pixels.Warp와 결과 픽셀을 저장한다. 이전 헤더의 새 기록을 거절하고 기존v74 문서와 효과는 유지한다. 외부 모델/클라우드/원제품 구현을 사용하지 않는다. 실물 펜 검증은 별도 대기한다.
