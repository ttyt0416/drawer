# 도구별 RGBA 쓰기·누적·알파 유지·수채 공급

기능076. Pixel pen의 Overwrite with brush RGBA는 Normal 합성에서 덮어쓰기를 선택한다. 색 변동을 거친 지정 RGB를 그대로 쓰고 새 알파는 지정 알파×팁 coverage×필압/속도 농도×전체 농도×선택×브러시 질감이다. 같은 픽셀 재통과/새 획에도 이전 알파와 누적하지 않는다. 강도0/선택 밖은 쓰지 않고,0보다 큰 강도의 투명 지정색은 숨은 RGB와 알파0을 쓴다. 기본값/구형 누락은 기존 source-over이며 체크로 전환한다. 일반 브러시는 기존 source-over 누적과 선택한 필압 농도의 획별 제한을 유지한다.

덮어쓰기는 안료 pickup/번짐/희석 결과 대신 지정 RGB를 쓰고 수채/시간 효과 후처리 확산도 생략한다. 색 변동·마스크/팁/압력/속도/좌표는 기존 고정 스타일을 공유한다. 명시적 특수 합성과 복제 도장은 자신의 규칙이 우선한다. 해당 안료 조작은 설명하고 숨기며 알파 잠금은 유지할 수 있다. 잠금에서는 투명 대상은 건드리지 않고 기존 알파를 보존한다.

Marker의 Keep the layer's original alpha는 공통 알파 잠금을 사용한다. 원래 알파0인 픽셀은 RGB까지 유지하고 반투명/불투명 픽셀은 전후 알파 배열을 정확히 고정한 채 색을 혼합한다. 모든 그리기는 캔버스/현재 레이어 저장 범위와 선택 coverage로 제한하며 캔버스 밖의 placed 레이어 픽셀도 보존한다.

새 Watercolor의 supply_threshold 기본값은0.2다. 필터·장치/브러시 보정 후 압력이 그보다 작을 때 주색 공급만0으로 만든다. 같은 값/큰 값에서는 설정한 공급을 유지한다. 기존 혼색/운반/혼합색 유지/농도 유지·희석·물 양은 별개다. 낮은 압력도 기존 색을 섞거나 옮기며 빈 영역에 주색을 공급하지 않는다. 마우스/누락 압력은1이므로 Colorless smudge (no foreground supply) 토글로 무공급 모드를 고른다. 구형 누락은0(종전 게이트 없음)을 유지한다.

도구 모드·임계값·알파 잠금/무색 토글은 자체 프리셋·입력 임시본/백업/재시작·사용자 도구에 보존한다. 문서v26은 고정 Style과 확정 픽셀을 저장한다. 설정 변경은 기존 획/그리기 이력을 다시 계산하지 않는다. 정상 종료의 바뀐 획 하나는 한 번의 Undo/Redo이며 동일 RGBA의 무변경 획은 빈 이력을 만들지 않는다. 취소/오류는 기존 pending 획 경로를 따른다.

시험은0/128/255바탕×선택0/128/255×1/2/10개의 획/반복 도장, 정확한 덮어쓰기 RGBA·일반 source-over 기준값/64→112→241 누적·마커 알파 배열 동일·투명 숨은 RGB 교체·캔버스/placed 범위, 임계0.1999/0.2/0.2001·무색/낮은 압력의 빈 영역·특수 합성 우선·잘못된 임계값/구형 기본값·문서 재열기/한 이력/재실행을 포함한다. 생산 입력에서 반복 덮어쓰기/일반 누적·마커 알파·투명색 교체·펜 임계 경계·압력 없는 마우스 토글, 프리셋/재시작/설정의 문서 불변을 확인한다. 실제 펜 센서 검증은 대기다.
