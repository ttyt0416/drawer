# 090 페이지 소유 사각형/올가미 선택

Rectangle select/Lasso select는 마우스 및 기존 펜 입력 경로에서 누르기→이동→놓기를 추적한다. 누르는 시점에 문서/리비전/보기/투영/입력원을 고정하고 다른 장치의 입력이 같은 선택을 확정하지 못하게 한다. 확정 전에는 선 미리보기만 그리며 원래 문서/픽셀/이력을 바꾸지 않는다. 놓으면 선택 Scene 명령 하나를 만든다. Esc, 초점 상실, 장치 취소, 모달, 보기/문서/도구/투영/리비전 변경은 미확정 상태를 폐기한다. 보기 밖에서 놓아도 캡처한 투영으로 처리하며 페이지 경계로 자른다. 선택 도구를 고르는 키와 펜 Down이 같은 프레임에 도착해도 준비된 펜 접점을 초기화하지 않고 키 반복은 선택을 재시작하지 않는다.

좌표는 문서의 보존된 페이지 원래 좌표에 속하고 기존 Scene 변환으로 현재 캔버스에 사상한다. 셀/프레임/보기 상태에는 들어가지 않는다. 4×4 coverage는 수평 scanline 교점과 run 이벤트로 계산하므로 큰 사각형의 내부 픽셀을 모두 순회하지 않는다. even-odd 규칙으로 자기 교차 올가미를 처리하고 캔버스 다각형과 교차한다. 정렬된 coverage runs는0을 생략하며 최대32768개,한 run 길이32768,보존 좌표±1,000,000을 사용한다. 올가미는3–4096점,행×점×4 작업은64Mi 이하이다. 무면적 올가미/영크기 사각형·비유한·범위·자원 오류는 이전 선택을 보존한다. 캔버스 밖의 유효 도형은 명시적 빈 선택이 될 수 있다.

Deselect는 제한 없음,명시적 빈 마스크는 아무 것도 선택하지 않음을 뜻한다. Invert는 페이지 범위에서 coverage255−현재 coverage를 계산하며 안티앨리어싱과 제한 없음/빈 선택을 구분한다. 정수 이동 마스크와 기존 사각형을 canonical runs로 변환한다. 분수 이동 마스크를 변환할 때는4Mi 픽셀 작업 상한이 있다. Reselect는 해당 페이지의 최근 선택을 복원한다.

페이지는 활성 선택,최근 선택,이름/ID가 있는 저장 선택을 소유한다. 로컬 캔버스 문서 한 개가 한 페이지를 소유하며 Duplicate page as separate document는 내용과 현재 셀을 복사한 독립 문서를 만든다. 페이지 식별자는 시간/프로세스/단조 카운터로 생성하고 저장 선택은 페이지 식별자+페이지 내 ID로 식별한다. 페이지 복사는 새 페이지 식별자를 사용하므로 같은 로컬 ID도 다른 페이지의 선택과 섞이지 않는다. 이름1–64자,저장16개이며 같은 이름의 명시적 저장은 ID를 유지한 교체다. 저장/불러오기/삭제/선택 생성/반전/해제/재선택은 문서 Scene Undo/Redo이고 래스터/셀 픽셀은 바꾸지 않는다. 확대/크기/90도 회전은 기존 페이지 변환을 사용하고 저장/최근 선택의 문서공간 이동 벡터도 함께 변환한다.

자체 형식v33에 페이지 식별자/최근/이름 있는 선택을 Scene.selections로 저장한다. 누락은 기본값으로 읽어 v32 이하를 보존한다. 선택 생성/저장/페이지 복사는 Scene의 기존4MiB JSON 한도를 적용 전에 검사한다. 실패하면 문서를 바꾸지 않는다. 픽셀 Ctrl+Z와 선택 명령의 시간 순서를 동일 이력에서 유지한다. 셀/프레임 전환과 참고 렌더는 선택 명령을 생성하지 않는다. 향후 다중 페이지 관리/라이트테이블 편집도 이 페이지 소유 상태와 fork_page 계약을 사용하며 단순 참고 상태로 픽셀 선택을 덮어쓰지 않는다.

검증은 독자 도형만 사용한다. 사각형 모서리96/반전159,원래 마스크의 두 번 반전·빈/전체/범위 밖·32768폭 run,자기 교차/잘림 올가미와 독립16서브샘플 oracle을 비교한다.2페이지×2셀의 렌더 차이/선택 유지/다른 페이지 불변·이름/ID/교체/용량 실패·Undo/Redo·문서v33 재열기와 구형v32 기본값을 확인한다. 실제 생산 입력에서 마우스 사각형과 합성 펜 올가미,확정 전 저장 데이터/픽셀 불변,Esc/초점/모달/보기 전환 취소,선택 키/펜 동시 해제와 반복,보기90도/확대1.5/보기 밖 놓기,페이지 복사 식별자를 검증한다. 이름 있는 선택 이동의 페이지90도 회전도 확인한다. 설치본이 같은 시험을 실행하며 실제 펜 센서와 향후 라이트테이블 UI 조작은 해당 통합 단계에서 별도로 검증한다.
