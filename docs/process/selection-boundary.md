# 097 — 선택 확대·축소·경계 흐림

Expand selection/Shrink selection/Feather selection은 반경0~64 문서 픽셀의 적용 창을 연다. 반경0은 기존 Scene을 그대로 반환하므로 선택 표현/이동/페이지 namespace/최근 선택/이력/dirty가 바뀌지 않는다. Apply는 해당 문서 ID·리비전·프레임을 확인하고 하나의 Scene Undo로 확정한다. Cancel/창 닫기/Escape는 초안을 버린다. 래스터/셀 픽셀에는 쓰지 않고 기존 선택 저장/이름 있는 선택/문서v34를 공유한다. 실제 창은 효과를 적용할 때만 계산하며 캔버스 실시간 미리보기는 제공하지 않는다.

독립 정책은 문서 픽셀 격자에서 정사각형 반경의 max 팽창/min 침식, 정규화된 가로/세로 상자 평균 흐림이다. 흐림은 각 패스에서 가장 가까운 정수 강도로 반올림한다. 원래 프로그램의 특정 곡선/가우시안 필터와 동일하다고 주장하지 않는다. 기존 선택은4×4 표본으로 문서 격자에 읽고 변환/이동을 반영한다. 처리 뒤 원래 페이지 격자로4×4 표본해 저장한다. 확대/흐림 결과는 캔버스 밖도 보존하며, 표본 범위 밖은 강도0이다. 선택이 없을 때는 캔버스 전체를 유한 선택으로 사용한다. 명시적 빈 마스크는 그대로 유지한다.

정사각형 커널은 가로/세로 두 패스로 처리하고 반경만큼 패딩한다. 모든 인덱스는 범위 검사 후 읽는다. 작업 격자4Mi 픽셀·변32768·좌표±100만·64Mi 커널 판정 작업·32768 RLE·Scene4MiB 및 기존 문서/Undo 상한을 넘으면 이전 선택을 유지하고 오류를 표시한다. 전역 라이브러리나 외부 서비스는 사용하지 않는다.

독립 기대값: 단일255 픽셀을 반경1 팽창하면3×3의255, 침식하면 빈 마스크, 상자 흐림하면3×3의28이다. 팽창한3×3의 반경1 침식은 중앙255다. 좌상단128 픽셀 팽창은 음수 좌표에서도128을 유지한다. 원래 페이지를2배 확대한 문서의 반경2가 원래 페이지1픽셀에 해당함을 확인한다. 반경0/65 거절·전체 선택의 경계·빈 마스크·픽셀 불변·한 Undo/Redo·문서 재열기를 검사한다. 실제 egui Apply 버튼의 세 연산/0반경 무변경·Escape취소·오래된 문서 거절을 설치본에서도 검사한다.
