# 눈금·격자·가이드와 인쇄 크기 보기

픽셀/mm/inch는 문서 DPI를 기준으로 환산한다. 회전·Mirror 상태의 눈금은 화면 가장자리를 문서 좌표로 역변환해 표시하며 90도 회전에서는 X/Y 축을 바꿔 표시한다. 눈금/격자/가이드 표시는 로컬 보기 설정이고 PNG 픽셀에 합성하지 않는다.

격자 간격·원점과 가이드의 좌표는 문서에 저장한다. 문서 변환을 적용한 원기하를 표시하며 새 좌표를 입력하면 현재 페이지 좌표에서 원좌표로 역변환한다. 적용/추가/전체 제거마다 문서 실행 취소 하나를 기록한다. 기하만 바뀌는 명령은 래스터 버퍼를 복사하지 않는다. 매우 조밀한 격자는 화면에서 선을 생략해 표시하며 저장 간격은 바꾸지 않는다.

인쇄 크기 보기는 사용자가 화면의 기준선을 실제로 재고 입력한 길이로 화면의 픽셀/인치를 계산한다. 보기 배율은 화면 픽셀/인치 ÷ 문서 DPI다. 화면 배율의 논리 좌표와 장치 픽셀을 구분한다. 허용 보정 범위는 20~1000 픽셀/인치이고 보기 배율 범위 밖이면 적용하지 않는다. 실제 화면 mm 정확도는 사용자의 측정에 의존하며 다른 모니터에서는 다시 보정해야 한다. 실물 자를 사용한 하드웨어 측정은 자동 시험으로 주장하지 않는다.

보기 설정은 버전형 로컬 파일에 저장하고 직전본 복원/기본값 초기화를 제공한다. 현재 자체 문서 형식 3은 격자를 포함한다. 형식 1/2도 읽으며 격자가 없는 형식 2는 기본 간격으로 연다. 형식 3을 지원하지 않는 구형 Drawer는 새 파일을 지원하지 않는 버전으로 거절한다.
