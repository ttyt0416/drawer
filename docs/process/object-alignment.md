# 개체 정렬과 균등 배치

Align/distribute objects 창에서 래스터층·페이지의 문자/선/톤/그림자·벡터 경로·편집 그라데이션을 체크한다. Left/Center/Right/Top/Middle/Bottom과 수평/수직의 Equal gaps 또는 Equal centers를 선택한다. 각 버튼은 선택한 여러 대상을 한 문서 Undo로 적용한다. 창을 닫으면 이미 적용한 변경은 유지하며, 적용 전 초안 선택만으로 문서가 바뀌지 않는다.

기준은 Selection bounds / Canvas / reference object다. Selection bounds는 래스터 선택이 있으면 변환·이동을 반영한 선택의 경계, 없으면 선택한 개체의 외곽 경계다. reference object는 기준으로만 읽고 선택 목록에도 있으면 이동 대상에서 뺀다. 잠긴/숨긴 개체도 명시적인 기준으로는 읽을 수 있다. 그 외 잠긴/숨긴 이동 대상이 하나라도 있거나 참조가 없으면 전체를 무변경 거절한다.

균등 배치는 이동할 개체가3개 이상일 때 기준 경계의 양 끝에 바깥 개체의 바깥 변을 맞추고 중간을 같은 간격으로 배치한다. Equal gaps는 개체 크기를 뺀 여백, Equal centers는 중심 간격을 동일하게 한다. 정렬 순서는 기존 중심 위치이며 같은 위치는 체크 목록 순서를 유지한다. 겹치지 않는 배치 공간이 부족하면 오류를 표시하고 원본을 보존한다. 0개 정렬과0/1/2개 균등 배치는 이력을 만들지 않는다. 1개도 캔버스/기준 개체에는 정렬할 수 있다.

래스터 경계는 픽셀 데이터의 배치 사각형이며 이동량을 가장 가까운 정수 픽셀로 반올림한다. 반 픽셀 중심은0.5픽셀 차이가 남을 수 있고 픽셀 내용은 다시 표본화하지 않는다. 페이지 객체/벡터는 문서 좌표 이동을 페이지의 원래 좌표로 역변환한다. 채움만 있는 벡터의 경계에는 쓰지 않는 선 폭을 포함하지 않는다. 벡터 작성 제어점은 유지하고 생성 좌표계를 함께 갱신해 도형 재구성의 위치를 보존한다. 그라데이션은 캡처한 RLE 경계를 쓰며 생성 좌표계를 바꿔 색과 마스크를 함께 이동한다. 선택 자체와 페이지 전체 변환은 바꾸지 않는다.

유효 대상8192개·문서/실행 취소/작업공간 메모리·좌표·4MiB Scene JSON 상한을 검사한다. 페이지/프레임/리비전이 바뀐 적용 창은 거절한다. 정렬·분배 후 문서 저장/재열기와 한 Undo/Redo를 공유한다.

검증은0/1/2/3개, 여섯 정렬과 네 배치 방식의 독립 경계/간격, 음수 위치, 기준 개체 고정, 잠긴 대상의 원자적 거절/잠긴 기준 읽기, 공간 부족/중복 대상 거절, 래스터 반올림/픽셀 불변, 부분 선택의 이동 경계, 회전/배율을 포함한 벡터/작성 정의와 그라데이션 색·마스크 동시 이동, 문자/선/그림자, 문서 재열기를 포함한다. 실제 창의 정렬 버튼·취소·오래된 상태 거절도 설치본에서 실행한다.
