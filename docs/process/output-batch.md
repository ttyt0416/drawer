# 출력 크기·해상도·파일 이름 계획

명령 `output-batch`. 활성 문서 또는 최대32개 열린 문서에서 독립 합성본을 준비한다. 출력 픽셀/DPI를 원본 유지 또는 명시값으로 선택하며 꺼진 수동 값은 보존한다. 크기 변경은 premultiplied-alpha bilinear이며 같은 크기는 재보간하지 않는다. 원본 크기/제목/DPI/경로/dirty/문서 이력은 바꾸지 않는다. 4M픽셀/파일·1..4800DPI·64MiB 인코딩된 묶음과 작업공간 메모리 한도를 적용한다.

PNG·JPEG·BMP·TGA·TIFF·WebP를 공통 정지 이미지 경로로 제공한다. PNG/TIFF는8/16비트 RGB/RGBA, PNG는None/Deflate, TIFF는None/LZW/Deflate/Packbits, TGA는RLE, JPEG는품질1..100, WebP는무손실이다. PNG pHYs(1inch=0.0254m)·JPEG 정수JFIF·TIFF 유리수DPI의 근사값을 안내하고 원본DPI에 역대입하지 않는다. BMP/TGA/WebP는현 어댑터의DPI메타데이터 미지원 안내를 표시한다. PNG16/ICC와 TIFF/JPEG의DPI 판독값을 검사한다. 이 단계의 JPEG 미리보기는 아티팩트를 시뮬레이션하지 않으며 실제 압축 미리보기는247에 남는다.

{title}(확장자 제외 원제목)·{index}(0001부터) 줄기와 선택 형식 확장자로 이름을 생성한다. 이름·픽셀·DPI·실제 인코딩 바이트 수·축소 합성 미리보기·변환 안내를 검토 후 새 파일만 출력한다. 대소문자 이름 충돌·금지문자·예약 장치명·알 수 없는 자리표시는 준비 전에 거절한다. [Microsoft 파일 이름 규칙](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file)에 따라 COM/LPT 위첨자¹²³와 확장자 붙은 장치명도 차단한다. 열린 문서와 가져온 보호 경로를 대체하지 않는다. 문서/프레임 변경·닫기는 재준비를 요구한다.

쓰기 때 경로를 다시 검사하고 독점 임시파일에 청크 기록/동기화 후 대체 없는hard-link 게시를 사용한다. 기존/읽기전용 대상·외부 임시파일·권한 오류는 파일별 실패로 남기고 나머지 새 출력은 계속한다. 실패/취소는 자신이 생성한 임시파일만 지운다. 준비/미리보기 취소는 파일을 쓰지 않는다. 출력 중 취소는 완료한 새 파일을 보존하고 나머지를 취소 목록으로 남긴다. 화면에서 파일별 성공/실패를 확인한다.
