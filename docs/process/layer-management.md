# 116 — 레이어 생성·삭제·복제·이름·순서

Layers 패널의 Layers… → Manage layers와 로컬 명령으로 래스터/벡터층을 생성·삭제·복제·이름 변경한다. 이름은1–64개의 출력 가능한 문자이며 양끝 공백을 제거하고 동명 층을 허용한다. 이름과 식별자는 별개다. 마지막 래스터층의 삭제는 비활성/무변경 거절한다. 잠근 층의 삭제·이름·위치 변경은 거절하고 읽기 복제는 기존 잠금 속성과 함께 복사한다.

래스터는 문서의 고유 정수 식별자를 사용한다. 이전 문서는 기존 인덱스의 결정적 식별자를 읽고 최초 관리 작업에서 명시적 목록으로 보존한다. 새 층/복제/폴더 합성은 새 식별자를 발급하고 삭제는 다른 층의 식별자를 보존한다. 벡터는 기존 층/경로 식별자를 사용하며 복제 경로도 새 식별자를 받는다. 문서v45와 누락 필드 기본값을 사용하고 식별자 중복/개수 불일치를 거절한다. 붙여넣기와 일반 상태 추가는 기존 식별자 목록을 확장한다.

래스터 순서는 종이/폴더 합성 그래프의 아래→위 순서다. 폴더 안 생성·인접 복제·다른 폴더/루트의 지정 슬롯 이동을 지원하며 패널도 같은 순서로 표시한다. 래스터 배열은 저장 위치이고 합성 순서와 구별한다. 빈 기존 폴더도 이동 대상으로 사용할 수 있다. 벡터층은 기존 벡터 스택에서 순서를 바꾼다. 벡터 폴더 합성은 별도 폴더 기능의 범위다.

삭제는 종이 속성/폴더 자식·참조/지우기 집합·기록된 획의 층 인덱스·정렬 기준·연결 자의 소유자를 명시적으로 갱신한다. 삭제한 소유자만의 자는 지우며 남은 소유자를 다른 층으로 바꾸지 않는다. 문서의 구조/픽셀/경로/식별자/속성은 한 상태 Undo로 복원한다. 활성 대상과 현재 작업공간의 채우기/샘플링 참조는 남아 있는 식별자를 따라 다시 해석한다. 작업공간 참조에서 삭제된 대상은 제거하거나 현재층으로 돌아간다. 그 작업공간 선택은 문서 이력에 포함되지 않는다.

새 래스터는1×1 투명 저장 영역으로 시작하고 기존 획 엔진이 필요할 때 영역을 확장한다. 복제한 픽셀/벡터 점/작성 정의/종이 속성은 독립 데이터다. 문서/작업공간/Undo 메모리, 래스터256층·벡터32층/128경로·기존 기하/JSON4MiB 상한을 함께 검사한다. 실패한 명령은 원본을 바꾸지 않는다.

연계 이미지 삽입은 Layers… → Import local image layer에서 현재 지원 디코더의 PNG/JPEG/TIFF 파일과 페이지/방향을 고른다. 기존 읽기/ICC→sRGB 변환 경로를 공유한다. 디코드 결과를 기존 배치 미리보기로 넘기며 기본적으로 픽셀 크기를 유지하고 문서 중심에 놓는다. 소스 DPI는 배율을 바꾸지 않는다. 캔버스 밖 픽셀도 저장한다. Fit image inside canvas는 별도의 알파 가중 bilinear 맞춤 선택이며 Original pixel size로 원본 크기를 복구한다. 소스 파일은 수정하지 않고 픽셀/변환 결과를 내장한다. 삽입 한 번은 한 Undo이고 배치 취소/읽기 실패/문서·프레임 변경은 문서와 선택을 보존한다. 이 항목은236의 연결 삽입 동작을 제공하며236의 나머지 포맷 입출력은 별도 항목이다.

검증은 마지막층·동명·잘못된 이름·256층 경계·폴더 안팎 생성/이동·새 ID/깊은 복제·삭제 참조 재지정·합성 순서의 빨강/파랑 픽셀·벡터 스택/잠금·일괄 Undo/Redo·저장 재열기를 포함한다. 실제 관리창 버튼, 로컬 이미지 작은/큰 크기·600DPI 목적지·투명 가장자리·맞춤/원래 크기·소스 제거 후 재열기·연속 삽입/취소·읽기 실패와 선택/도구 참조의 Undo 후 소유자도 검사한다. 실행은 완전 로컬이며 외부 서비스나 다운로드를 사용하지 않는다.

연계 캔버스 선택은 기존 수정키/후보 순환 경로와 합성 그래프 순서를 공유한다. 순서를 바꾼 래스터의 클릭 후보와 선 알파0/채움 알파가 있는 벡터의 실제 가시 영역도 검사한다. 좁은 패널의 목록 공간을 유지하기 위해 새 명령은 기존 Layers… 메뉴 안에 제공한다.123의 검색/일괄 선택 기능은 별도 항목이다.
