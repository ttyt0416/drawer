# 마스크 편집 (131/137)

기존 Mask의 enabled/linked/inverted/offset/coverage를 공통 폴더 마스크 검증 경로로 편집한다. 래스터/벡터/폴더만 대상이며 자체/부모 잠금·이미지/위치 잠금을 거절한다. 복사는 소스 읽기만 수행하고 독립 coverage를 만들며 덮어쓰기는 명시 선택이다. 레이어 이동은 기존 mask.linked를 따르고, 독립 마스크 이동은 문서 좌표의 변화량을 역변환한 원래 페이지 offset에 더한다.

선택 마스크는 이동 변환을 유지해 복제한다. 선택 사각형은 원래 픽셀 중심으로 샘플링한다. 선택 밖 숨김은 통과=선택강도, 안 숨김은 통과=255-선택강도다. 교차는 원래 픽셀 격자에서 강도 곱을 반올림하며 두 반전 마스크의 무한한 외부 통과도 보존한다. 좌표±1e6/차원32768/4Mi 샘플·32768런 제한. 비활성 기존 마스크 교차는 활성화 또는 대체를 요구한다. 선택 없음/명시적 빈 선택과 암묵적 덮어쓰기는 거절한다.

Apply mask to alpha는 래스터 자체 알파에 해당 마스크를 곱하고 마스크만 제거한다. RGB(알파0 RGB0 정규화 예외)/식별자/위치/불투명도/혼합과 다른 표시 레시피는 유지한다. 살아 있는 효과는 바뀐 알파에서 다시 평가될 수 있다. 벡터/폴더/연결 파일 또는 보정층은 일반 병합이나 명시적인 Bake masked content 대안을 안내한다.

Bake masked content는 기존 외관 비교 래스터 변환을 별도 동작으로 유지한다. 효과와 벡터/폴더 구조의 변환 및 클리핑 묶음 소비를 UI/도움말에서 알린다. 단일 폴더를 기존 병합 검증 경로에 허용했으며 비어 있는 폴더·혼합 역할·숨김 자식·잠금·불완전 클리핑·외부 배경 의존은 기존 거절 정책을 유지한다. 보정층 단독 굽기는 배경 병합 안내다. 세 명령의 구분과 정밀도 검증은 individual-combine.md에 기록했다.

화면 전후 미리보기/한 Undo, 문서ID/리비전/프레임 고정과 Escape 취소. 저장 형식은 기존 마스크 필드를 사용한다. 영역 보기는 작업공간 bool이며 기본 false/직렬화/설정 불러오기 other 범위로 복원한다. 선택층의 저장 마스크를 enabled와 별도로 최대256×256 빨강 투명 텍스처로 표시하며 문서 렌더러와 내보내기에는 전달하지 않는다. 뷰/회전은 화면 메시에서 처리하고 마스크 텍스처는 문서ID/리비전/대상으로 캐시한다.
