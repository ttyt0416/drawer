# 독자 화면·기본 소재 제작 기록

앱 이름은 Drawer다. 짙은 녹색 바탕의 대각선 펜 표식과 차분한 회색 작업 화면을 직접 구성했다. 제목 아래 도구 목록, 오른쪽 작업 영역, 선택 도구의 팁 미리보기로 시작한다.

기본 팁은 Pen·Pencil·Eraser·Wash다. 원형 경계 감쇠·결정적인 연필 입자·부드러운 세제곱 감쇠를 Rust 수식으로 새로 작성했다. 아이콘과 팁은 실행 파일에 포함된 코드로 생성해 원본 프로그램·소재 폴더·별도 이미지 파일을 읽지 않는다.

원본 디자인은 `drawer-core/src/assets.rs`와 `drawer-app/src/main.rs`에 보존한다. 이 저장소 작업 중 제작했으며 원본 프로그램에서 추출한 자산을 사용하지 않았다. UI 라이브러리의 기본 글꼴 등 외부 구성요소는 004의 고지 목록으로 관리한다.

기능 024의 현재 도구 커서 아이콘 4개도 독립 Rust 픽셀 도형으로 직접 제작했다. Pen 대각선·Pencil 가는 선·Eraser 직사각형·Wash 물방울을 서로 다른 색으로 표시한다. 원본 추출 이미지/파일이나 외부 생성 서비스를 사용하지 않는다.

한국어 도움말/UI 표시에는 Windows에 이미 설치된 `Fonts/malgun.ttf`를 읽어, 한글 글리프가 있는지 검사한 뒤 기본 내장 글꼴의 보조 글꼴로 사용할 수 있다. 시스템 글꼴 파일은 저장소/실행 파일/설치 묶음에 복사하지 않으며 앱은 글꼴을 내려받지 않는다. 사용할 수 없으면 기본 글꼴을 유지하고 도움말에서 상태를 표시한다. 내장 글꼴 고지와 수는 기존 네 글꼴 그대로다.
