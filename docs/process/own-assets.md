# 독자 화면·기본 소재 제작 기록

앱 이름은 Drawer다. 짙은 녹색 바탕의 대각선 펜 표식과 차분한 회색 작업 화면을 직접 구성했다. 제목 아래 도구 목록, 오른쪽 작업 영역, 선택 도구의 팁 미리보기로 시작한다.

기본 팁은 Pen·Pencil·Eraser·Airbrush·Marker·Smudge·Pixel pen이다. 원형 경계 감쇠·결정적인 연필 입자·부드러운 세제곱 감쇠를 Rust 수식으로 새로 작성했다. 아이콘과 팁은 실행 파일에 포함된 코드로 생성해 원본 프로그램·소재 폴더·별도 이미지 파일을 읽지 않는다.

원본 디자인은 `drawer-core/src/assets.rs`와 `drawer-app/src/main.rs`에 보존한다. 이 저장소 작업 중 제작했으며 원본 프로그램에서 추출한 자산을 사용하지 않았다. UI 라이브러리의 기본 글꼴 등 외부 구성요소는 004의 고지 목록으로 관리한다.

기능 024의 현재 도구 커서 아이콘 4개도 독립 Rust 픽셀 도형으로 직접 제작했다. Pen 대각선·Pencil 가는 선·Eraser 직사각형·Airbrush 분사점을 서로 다른 색으로 표시한다. 원본 추출 이미지/파일이나 외부 생성 서비스를 사용하지 않는다.

한국어 도움말/UI 표시에는 Windows에 이미 설치된 `Fonts/malgun.ttf`를 읽어, 한글 글리프가 있는지 검사한 뒤 기본 내장 글꼴의 보조 글꼴로 사용할 수 있다. 시스템 글꼴 파일은 저장소/실행 파일/설치 묶음에 복사하지 않으며 앱은 글꼴을 내려받지 않는다. 사용할 수 없으면 기본 글꼴을 유지하고 도움말에서 상태를 표시한다. 내장 글꼴 고지와 수는 기존 네 글꼴 그대로다.

기능 055에서 부드러운 팁의 기본 프리셋을 Airbrush로 정했다. 기존 내부/직렬화 식별자 Wash는 파일·배정 호환을 위해 유지한다. 이 식별자는 사용자 화면 이름과 분리했다. 새 기본값은 독자 수치이며 기존 저장 값을 강제 변경하지 않는다.

기능060의 Fine grain/Linen/Flecks 세 질감은 독립적인 해시/삼각함수 레시피로 직접 작성했다. 수식은 texture.rs에, 문서에는 안정된 참조 번호·시드·배율·강도·회전·위치를 저장한다. 외부 이미지·원본 프로그램 소재·다운로드를 사용하지 않는다. 사용자 이미지 소재 등록은 체크리스트070에서 별도로 다룬다.

기능061은 낮은 도장 농도의 원형 마커·현재 색 운반 팁·이진 직사각형 픽셀 팁과 세 커서 아이콘을 독립 Rust 수식/도형으로 추가했다. 기존 네 팁의 안정된 식별자는 유지하고 새 식별자 Marker/Smudge/PixelPen을 추가했다.

기능062의 선택 가능한 둥근/사각 팁 이미지는16~256 표본의 독립 기하 마스크로 생성한다. 참조는 Native/Round/Square로 저장하고 실행 파일의 수식으로 재구성해 외부 소재 파일 없이 이동한다.

기능065의 여러 팁은 기존 독자7개 마스크 참조를 조합한다. 팁 순서/순열과 Oklab 혼색은 새 Rust 코드이며 Oklab 공개 도메인 행렬의 수학 정의만 참고했다. 참고/검증 범위는 tip-sequence.md에 기록했다.

기능067의 별·다이아몬드·잎은 Rust 거리 마스크로 직접 제작했다. 산포 좌표와 연속 리본 기하도 독립 수식이며 원본 이미지/장식 소재를 사용하지 않았다.

기능068의 두 번째 둥근/사각/입자/부드러운 팁도 자체 Rust 기하·해시·감쇠 수식이다. HSV 변동과 coverage 조합 코드를 직접 작성했으며 외부 이미지/원본 소재를 사용하지 않았다.

기능070은 사용자가 지정한 이미지의 검증된 스냅샷을 로컬 밀도 마스크로 등록한다. 저장소/전달 묶음에는 사용자 이미지나 원본 앱 소재를 넣지 않는다. 시험용 PNG/JPEG/TIFF/BMP는 코드의 독립 패턴 배열에서 실행 중 생성한다.
