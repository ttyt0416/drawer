# 114 — 특수 자·투시점·레이어 연동

완전 로컬 문서에 평행 직선/곡선, 다중 곡선, 방사 직선/곡선, 동심원, 고정 가이드, 등분/황금비 눈금과 편집 가능한 원근/어안 자를 보존한다. 기존 대칭/방사 복제 자도 유지한다. Special rulers and layer scope에서 초안을 편집하고 적용한다. 자별 스냅 활성과 표시(All / Applied layers / Hidden), 적용 범위(All / Raster or vector layer / Raster folder), 프레임 범위, 연결 레이어를 각각 지정한다. 폴더 범위는 컷별 래스터 묶음을 구별한다. 표시 숨김과 스냅 해제는 독립이다.

평행 직선은 첫 입력점을 지나는 평행선, 가이드는 저장한 직선 위로 투영한다. 평행 곡선은 첫 점의 부호 있는 법선 간격을 보존하고 다중 곡선은 처음 가장 가까운 곡선을 고정한다. 방사 직선은 첫 점과 중심의 방향을 고정하며 방사 곡선은 중심 주위로 기준 곡선을 회전한다. 동심원은 첫 점의 반지름을 보존한다. 등분은1–512구간, 황금비는1–32단계의 대칭 분할이다. 눈금점 스냅은 화면 거리 설정을 문서 거리로 환산한다. 곡선 제어점2–32개와 다중 곡선1–8개를 허용한다.

투시점은1–16개이며 추가/삭제/고정/무한원 전환과 연결 가이드 추가/삭제를 제공한다. 고정점 이동은 무변경 거절하고 삭제 시 연결 가이드도 지운다. 눈높이 고정은 유한 투시점의 y를 지평선으로 제한한다. 무한원점은 방향을 저장해 평행 투영한다. 어안은 유한한 한두 극점과 입력점을 지나는 원호를 렌즈 원 내부로 제한하는 독립 기하 정의다. 한 극점은 렌즈 중심 대칭점을 사용한다. 일반 투시의 무한원은 어안에서 명시적으로 거절한다. 렌즈와 원의 교점을 직접 계산하고 가시 원호만 표본화해 거의 평평한 원호도 보존한다. 특정 제품의 수치/파일 호환을 주장하지 않는다.

Draw along saved ruler는 선택한 곡선/연결 가이드의 유한 경로를 선폭/RGBA로 래스터 또는 편집 가능한 벡터에 작성한다. 자 편집, 자 따라 그린 획, 연결 레이어 이동은 각각 한 Undo다. 닫힌 원/곡선 자는 기존 contour selection 명령에서도 선택할 수 있다. 미리보기는 문서를 바꾸지 않으며 문서ID/수정본/프레임이 달라진 초안은 적용하지 않는다. Escape와 문서 닫기는 초안을 버린다.

연결 자의 위치는 원래 좌표계의 오프셋으로 저장한다. 전체 레이어 이동 명령과 래스터 정밀 이동/정렬 시 문서 이동량을 역변환해 함께 이동한다. 그림으로 레이어 저장 영역이 커지는 것은 자 이동으로 해석하지 않는다. 벡터 전체 이동은 작성 정의도 갱신한다. 폴더 합성은 소유 레이어/범위 식별자를 새 래스터로 재지정한다. 페이지 변환과 보기는 별도로 적용한다. 두 번째 보기도 해당 문서/대상의 표시 범위를 사용한다.

새 문서는v43이며 이전 자 데이터의 누락된 범위/표시/연결 필드는 기본값으로 읽는다. 자32개·연결 가이드64개/투시 자·64Mi 투영 작업·유효 좌표/JSON4MiB와 기존 문서/작업공간/Undo 예산을 검사한다. 잘못된 수치나 초과 작업은 획을 확정하지 않는다. 마우스/가상 펜의 생산 입력과 실제 적용 버튼, 개별 Undo/Redo, 저장 재열기를 검사한다. 실제 펜 센서 검증은 별도다.
