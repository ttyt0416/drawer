# 인체·머리·손 마네킹과 관절 포즈 (215)

`human-rig` 명령은 인체(52관절), 머리(목·머리·턱 3관절), 손(손목과 다섯 손가락 각 3마디, 16관절)의 독자 절차 생성 모델을 연다. 외부 앱의 코드·모델·리그·소재를 포함하지 않으며 네트워크를 사용하지 않는다. 각 부분을 한 관절에 연결하는 rigid skin 방식의 그림용 마네킹이다. 표면의 부드러운 피부 변형이나 의학적 관절 정확도를 주장하지 않는다.

고정 상단의 New body/head/hand는 원본을 바꾸지 않는 미리보기를 만든다. 개체와 관절을 고르고 로컬 X/Y/Z 각도, 체형 슬라이더를 편집한다. 인체에는 키·어깨·골반·굵기·머리·손 비율, 머리에는 얼굴·턱 폭, 손에는 손바닥 폭·손가락 길이가 반영된다. 해당 부위가 없는 모델의 매개변수는 기하를 바꾸지 않는다. 관절마다 생성 코드에 정한 각도 범위를 UI와 저장 검증 양쪽에서 강제한다. 모든 손가락의 세 마디를 독립 조작할 수 있다. 부모 포즈가 자식에 전파된다.

Mirror pose는 인체의 좌·우 관절 값을 교환하고 좌우 반사에 맞게 Y/Z 회전 부호를 바꾼다. 손 모델은 왼손/오른손 형상도 반사한다. 두 번 반사하면 원래 포즈·방향으로 복구된다. Reset pose는 체형을 유지하며 모든 관절 각도만 0으로 돌린다. 미리보기에는 뼈와 선택 관절을 표시한다. Apply 한 번이 하나의 Undo이며 Discard/Esc/포커스 상실/창·문서 닫기/문서 리비전 변경은 준비 결과를 버린다. 다른 3D 미리보기와 동시에 적용할 수 없다.

기존 3D 창의 이동·회전·비균등/음수 축척, 로컬 모델 복제는 리그를 보존한다. 체형·포즈를 바꿔도 이 루트 행렬과 부모 관계를 유지한다. 독립 복제의 리그 매개변수는 공유하지 않는다. Detach rig도 미리보기 후 적용하며 현재 기하를 유지한다. 리그가 없는 OBJ·도형·분리 모델에서는 포즈를 지원하지 않는다고 안내한다. 숨김·각종 잠금·파일 개체 대체와 2D 촬영 원본 보호를 지킨다.

자체 문서 native109는 리그 버전·종류·체형·각도·손 좌우 방향과 생성된 정점/면을 함께 저장한다. 이전 문서는 빈 리그로 읽고, 이전 버전으로 위장한 리그 문서는 거절한다. 저장 검증은 생성 기하와 리그/루트 행렬의 일치도 검사한다. 문서당 마네킹 최대32개와 기존 모델/전체 기하 한도, 유한 수치·체형 범위·관절 수/버전·준비 및 결과 메모리 예산을 검사한다. 현재 화면·출력은 와이어프레임이며 조명/표면 렌더는 217번에서 다룬다. 물리 펜 검증은 유보한다.
