# 098 — 퀵 마스크와 선택 마스크 레이어

Quick mask/Shift+Q는 현재 세션의 빨간 선택 강도 표시와 마스크 칠 모드를 켠다. 기존 Q 빠른 팔레트 키는 유지한다. 빨간색은 선택된 강도이며0~255의 절반 알파로 표시한다. 그림 텍스처나 픽셀에 합성하지 않고 보기의 별도 오버레이로 그린다. 원래 페이지 좌표·선택 이동·문서→보기 투영·기존 뷰포트 자르기를 사용하므로 회전/반전/확대 보기에도 정렬된다. 명시적 빈 마스크는 빨간 영역이 없고, 무제한 선택은 전체 캔버스가 빨갛다. 표시 상태는 문서/작업공간에 저장하지 않는다.

켜진 동안 페인트 입력은 선택 브러시로 라우팅한다. J는 강도 추가,Shift+J는 지우기이며 기존 지름/경도/강도·펜 필압을 사용한다. 마우스/펜의 누르기 초안·놓기 한 Scene Undo·Escape/초점/보기/설정 변경 취소를 공유한다. 무제한 선택을 칠할 때는 전체255에서 시작하므로 추가는 무변경이고 지우기는 해당 부분만 낮춘다. 일반 선택 브러시의 처음 추가는 빈 선택에서 시작하는 기존 동작을 유지한다. Quick mask를 끄면 선택/그림/이력은 유지하고 이전 도구로 돌아간다. 누르는 중 토글은 기존 명령 규칙으로 획을 취소한 뒤 이후 입력부터 적용한다.

Selection mask layers 버튼은 Page selections의 이름 있는 마스크 층 목록을 연다. 기존 페이지 소유 선택 저장 객체가 마스크 레이어이며 색상 래스터 층을 만들지 않는다. 이름/고유ID와 원래 페이지의사각형/RLE강도/이동을 보관한다. 페이지당16개까지 이름으로 저장/교체하고 Load mask layer로 현재 선택을 복원하거나 Remove mask layer로 삭제한다. 각각 한 Scene Undo이며 프레임/셀과 별개로 페이지에 속하고 복제 페이지는 별도 namespace를 갖는다. 반투명 강도를 그대로 저장하며 기존 문서v34에 포함한다. 원본 그림 픽셀은 바뀌지 않는다.

검증은 자체 마스크와 생산 egui 경로를 쓴다. 마우스/합성 펜·90도/확대1.5에서 강도128 추가→64 지우기와 Undo·이름 있는 층 저장/clear/load·문서 재열기의 강도 일치·켜기/끄기의 픽셀/선택/이력 불변·이전 도구 복원을 확인한다. 오버레이 경로의 실제 알파64와4점 회전 투영을 검사하고 재시작 시 표시가 꺼지는지 확인한다. 무제한255의 추가 무변경과 지우기127/그 외255를 별도로 검증한다. 실제 펜 센서는 별도다.
