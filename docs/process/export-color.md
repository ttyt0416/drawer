# ICC 출력과 소프트프루프

`output-batch`의 픽셀 변환·ICC 포함을 별도 선택한다. 변환은 문서 작업RGB→선택RGB(빈 경로는sRGB)이며 변환을 끄면 작업RGB 숫자값을 유지한다. 포함만 할 때 빈 경로는문서RGB, 다른ICC 선택은숫자를그대로붙여해석을바꾸는할당이므로안내한다. PNG/JPEG/TIFF/WebP는선택ICC바이트를그대로포함하거나생략한다. BMP/TGA의포함옵션은미지원으로비활성화하고저장값을보존한다. RGB픽셀변환은태그여부와독립이다.

Perceptual·Saturation·Relative Colorimetric·Absolute Colorimetric을실제f64CMS변환에설정한다. 같은프로파일은항등변환이며자체표준sRGB의직렬화본도알려진동일공간으로인식한다. 포함된정밀값은16비트최종저장때만양자화한다. 작업RGB에서합성한복사본에출력변환을적용하고범위밖샘플수를안내하며파일에서만클립한다. 불투명배경도출력RGB로변환해합성한다. 원본문서픽셀/정밀도/프로파일/경로/dirty/이력과모니터보정은변경하지않는다.

출력프루프는양자화/클립된출력RGB를선택의도로sRGB에되돌려표시한다. 원본sRGB/출력프루프전환은준비된축소값사이의보기만바꾸고출력바이트나확인상태를바꾸지않는다. 모니터프로파일을파일에붙이지않으며실제프린터/종이의색검증과구별한다. 기존캔버스의RGB/Gray/CMYK소프트프루프는별도보기설정을계속사용한다. 아직CMYK출력채널어댑터가없으므로CMYK대상을안전하게거절하고RGB출력또는보기용프루프로안내한다.

ICC는로컬일반파일4MiB한도·경로/링크검사·RGB프로파일해석·변환방향검증후사용한다. 누락/손상/비RGB는준비를실패시키며기존파일/문서를유지한다. 변환과포함이모두꺼져서사용하지않는경로는읽지않고값을보존한다. 준비된프로파일과RGB는복사본이므로원본ICC를바꾸거나자동재읽기하지않는다.


절대 색도는 moxcms0.8.1의행렬경로가상대색도와같은결과를내는점을확인해별도PCS단계를추가했다. [ICC.1:2022의D.6](https://www.color.org/specifications/ICC.1-2022-05.pdf)에따라소스RGB→상대PCS XYZ→소스/목적지매체흰점비율→목적지RGB로처리한다. 내부선형좌표운반자는파일프로파일로내보내지않으며색도원색기저가XYZ단위행렬이다. 입력/출력방향의해석·TRC·행렬/LUT는같은CMS에위임한다. 유효한매체흰점이없는절대경로는오류로거절한다. 동일프로파일은여전히항등이다. 캔버스프루프절대의도도같은PCS처리를공유하고장치단계에서8비트양자화후역변환한다. 다른의도의기존8비트LUT는유지한다. 선형기저와알려진흰점비율의독립산술값으로절대색도를검사한다.

출력프루프는목적지색공간에서선택한8/16비트정밀도로먼저양자화한뒤표시변환한다. 8비트실제PNG채널판독에기반한회귀검사를추가했고, 수정전독립표본512개중357개에서표시채널차이를재현했다.
