# 독립 브러시 동역학

기능066. Style에 Copy/검증 가능한 Settings를 포함하고7개 도구의 입력 설정/프리셋/가상 재생/문서v18 고정 스타일에 보존한다. 옛 필드 누락은 기존 동작과 같은 기본값이다. UI는 기존 숫자 편집기를 공유하며 입력/출력 범위가 잘못되면 적용하지 않는다. 다섯 곡선 점은0~1의 임의 형태를 허용한다. 입력은 필압0~1, 기울기0~90도, 속도0~1e6px/s 범위에서 보정한다. 실제 속도는 더 클 수 있으나 곡선에서 범위 제한한다.

기존 필압 응답/최소 출력 후의 크기에 활성 pressure×tilt×speed 배율을 곱하고 seeded random 배율을 마지막에 곱한다. 절대px 크기 하한/상한으로 제한하고 그 뒤 시작끝 기하를 곱한다. 농도에는 새 크기 인자를 적용하지 않는다. 압력은 한 번 평활한 값, 기울기는 X/Y tilt의 tan 벡터 크기 atan, 방향은 기존 보기 투영의 문서 방향, 속도는 실제 문서 이벤트 거리/단조 증가 시각이다. 입력 누락/같은 시각/역행 시각은 각각 저장된 누락 출력 배율을 쓴다. 시각이 있는 영거리 이동은 속도0이며 시각 없는 이동과 구별한다.

Replay에 별도 입력 벡터를 두어 raw 필압/각도와 혼합하지 않는다. 방향 각도는 최단 회전, tilt는 선형 보간, 속도는 그 실제 구간의 속도를 유지한다. 프레임 시계는 기존 마지막 입력을 유지하고 실제 속도 기준 표본에서 제외한다. 원시 기록은 변경하지 않는다. 저장된 시드와 재표본화 경로로 미리보기/확정·취소 후 다시 그리기를 재현한다.

Fixed는 기본 각도에 설정 오프셋과 기존 전역 펜 기울기 옵션을 더한다. 명시적 Pen/Stroke는 자체 방향 또는 누락 기본값이다. 산포 타원은 기본 각도+scatter angle이며 입자 팁은 선택한 방향 규칙을 따르므로 전체 방향과 중심 지향을 분리한다. 동일한 직접 도장 API를 기존 시간 산포와 새 산포 기능에서 공유한다. 기본 커서는 마지막 실제 도장 크기/각도를 사용한다. Scratchpad도 한 획 상태와 마우스 속도를 유지한다. 연결선 명령은 펜 기울기를 전달하며 시각이 없는 선 속도는 기본값이다.

간격 연동은 양 끝 유효 크기를 고려하고 끄면 기본 크기의 고정 간격이다. 캔버스 선분 잘라내기는 크기 하한이 기본 팁보다 클 때도 모서리를 보존한다. 동역학이 활성화된 획의 도장 작업은262144회로 제한하고 기존 픽셀/경로/메모리 예산과 함께 거절 시 원본을 보존한다. 물리 펜/태블릿 검증은 합성 재생과 구별해 대기한다.
