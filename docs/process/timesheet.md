# 로컬 타임시트와 공유 셀 교환 (205)

`timesheet-exchange`는 Drawer timesheet v1의 JSON·CSV와 정적 PNG 묶음을 다룬다. SAI/CSP/XDTS 등 외부 전용 형식의 어댑터는 없으며 다른 형식/버전/헤더는 거절한다. 이 형식은 셀 원본·슬롯·노출을 서로 다른 ID로 기록한다. 같은 글로벌 셀을 여러 트랙/시점/좌표에서 재사용해도 PNG는 하나다. 별도 셀이 픽셀만 같은 경우에는 별도 원본을 유지한다.

출력 시 현재 문서의 불변 복사와 수정 번호·출력 옵션을 캡처한다. 새 로컬 폴더에 `timesheet.json`, `timesheet.csv`, 셀 PNG와 선택적 `common-background.png`를 준비하고 PNG 디코딩·해시·JSON/CSV 동등성을 확인한 뒤 폴더 전체를 게시한다. 기존 폴더는 합치거나 교체하지 않는다. 작업 중 그림/셀/현재 프레임 변경은 캡처에 반영되지 않는다. 취소/실패는 개인 준비 파일만 제거하며 문서/dirty/프레임/그림 Undo와 외부 파일을 유지한다.

셀명·연속번호·폴더명+셀명·폴더명+번호를 선택한다. 폴더는 타임라인 트랙 이름이며 파일명 접두어로 쓴다. Windows 예약명/제어문자/금지문자는 안전한 문자로 바꾸고 NFC 정규화·길이 제한을 적용한다. 대소문자/동명/잘린 이름 충돌은 원본 ID와 일련 접미어로 해소하며 실제 셀·트랙 이름은 메타데이터에서 그대로 보존한다. 경로는 묶음 폴더 안의 단일 PNG 파일명만 허용한다. CSV 행 자체를 정렬해도 명시적 트랙/슬롯 순번과 참조 ID로 원래 연결을 복원하며 노출은 프레임 순서로 정규화한다. 중복 ID/순번/동일 시점 노출·음수/범위 밖 프레임·잘못된 FPS·누락/변경 셀을 거절한다.

`Include unexposed slots and unassigned global cels`를 켜면 노출 없는 슬롯과 어느 트랙에도 배정하지 않은 글로벌 원본도 포함한다. 끄면 실제로 노출에 참조한 슬롯/원본만 쓴다. 빈 트랙은 이름/순서/끝/표시 설정과 함께 유지한다. 밑그림 포함과 전체 원본 캔버스/보존된 오버플로 영역을 선택하며 각 이미지의 원점을 메타데이터에 기록한다. 가져오기는 슬롯 좌표에 그 원점을 더해 페이지 위치를 유지한다. 숨긴 원본 내부 층은 렌더에서 제외하고 트랙/셀 표시·불투명도는 별도 설정으로 보존한다.

공통 배경 포함은 지정 용지층을 포함해 애니메이션 트랙을 모두 숨긴 나머지 층/개체를 현재 캡처 프레임에서 하나의 별도 PNG로 출력한다. 가져온 문서에서는 셀 뒤의 독립 배경층이다. 이 방식은 공유 셀을 다른 좌표에 배치해도 배경을 함께 움직이지 않고 같은 셀을 중복 출력하지 않는다. 배경의 키프레임은 캡처한 시점의 정적 합성으로 변환된다.

PNG는8비트 sRGB의 래스터 교환이다. 셀 내부 층·벡터/문자·마스크·키프레임·고정밀·오디오는 이 형식에 포함하지 않는다. 원본 네이티브 문서는 보존하고 화면에서 손실 범위를 확인한 뒤 출력한다. 가져오기도 검토/확인한 뒤 새 독립 문서로 추가한다. PNG 하나당 편집 가능한 래스터 글로벌 셀을 만들고 여러 슬롯이 같은 글로벌 원본을 참조한다. 초기 가져오기 전체를 한 번의 Undo/Redo로 제거/복원할 수 있으며 `.drawer`로 저장하면 픽셀과 공유 연결을 포함한다. 준비 후 확정 직전에 JSON/CSV와 모든 PNG의 해시를 다시 검사한다. 외부 원본은 수정하지 않는다.

출력 설정은 별도의 로컬 JSON 프리셋으로 저장/불러온다. 프리셋은 출력 실행·덮어쓰기 허용·검토 확인을 기록하지 않는다. 새 캡처와 확인을 다시 수행한다.

JSON의 format은 `Drawer timesheet`, version은1이다. 크기/DPI·유리수 FPS·전체 프레임 수·캡처 프레임·수정 번호·옵션, 이미지 원본 목록, 선택적 공통 배경과 트랙별 슬롯/노출/표시 설정을 기록한다. CSV는 `meta,image,common,track,cell,exposure` 행과 고정 헤더를 사용한다. `id,parent,order`로 소속과 순서를, `frame,source`로 노출과 셀 참조를 나타낸다. meta의 name은 형식명, version은 스키마 번호다. properties/options 열은 같은 JSON 설정 구조이며 이름의 쉼표·따옴표는 CSV 인용으로 보존한다. 프레임 번호는0부터 시작하고 트랙 끝은 미포함이다.

한도: JSON/CSV4MiB, 트랙32개, 독립 글로벌 원본512개, 슬롯10000개, 트랙별 노출10000개, 프레임10000개, PNG 입력64MiB 및 문서/작업 메모리 한도. 출력 셀 파일 합계2GiB 한도를 적용한다. 각 원본과 공통 배경은 축32768픽셀 이내이며 실제 출력 메모리 예산을 함께 확인한다.
