# 세션 이력 탐색

문서별 상태 토큰·명령 이름·현재 상태·Redo 분기를 목록에 표시한다. 보관 범위 안에서 여러 단계를 이동한다. 이동 후보에 전체 경로를 적용한 뒤 공개하므로 중간 실패가 현재 문서에 일부 이동만 남기지 않는다. 이 준비 비용이 작업 예산을 넘으면 단일 Undo/Redo를 안내한다. 새 편집 후 사라진 분기 및 오래되어 제거한 토큰은 거절한다.

이력 비우기는 별도 확인창을 거친다. 취소는 기록을 유지한다. 확인은 현재 그림·선택·경로·dirty·수정 번호를 유지하고 Undo/Redo만 해제한다. 토큰 발급 번호·저장 기준·비동기 저장 fence는 초기화하지 않는다. 이후 새 편집은 다시 Undo할 수 있다. 다른 문서 이력은 독립적이다. 저장 파일은 현재 상태만 포함한다.

검증: 다단계 왕복/현재 분기/저장 상태 복원/새 분기의 옛 토큰 거절/이력 비우기/미완료 저장/다른 문서/이후 새 편집, 실제 egui 클릭으로 확인 취소 및 승인, 저장/재열기의 이력 없음과 현재 상태 일치.
