# 159 — 모자이크·시드 노이즈·먼지·선폭

Mosaic는 문서 원점±1M과 셀1–256px의 격자에 원본 픽셀을 묶는다. 음수 좌표는 내림 나눗셈을 사용한다. 저장 경계의 부분 셀은 실제 표본 수로 평균하며 RGB×알파/알파와 평균 알파를 사용한다. 알파 잠금은 기존 알파를 유지하고 셀의 색만 적용한다. 투명 원자료와 균일색을 불필요하게 덮어쓰지 않는다.

Generate noise는 정수64비트 시드·문서 픽셀 좌표·채널의 독립 해시에서−1–1 균등값을 얻고 강도0–1을 더한다. 단색은 같은 값을 RGB에 사용하며 색 노이즈는 채널별 값이다. 결과는0–1로 제한하고 원래 알파와 숨은 투명색을 유지한다. 계산/영역 순서가 바뀌어도 같은 시드와 좌표는 같은 값이다. 시드와 옵션을 문서에 정수로 보존한다.

Remove specks는 어두운 점/밝은 점/투명 배경 고립 잉크를 선택한다. 임계0–1의 문서 RGB 가중 명도 또는 알파로 후보를 분류하고4방향 연결 면적0–4096px을 센다. 저장 경계에 닿거나 면적을 넘는 성분은 보호한다. 어두운/밝은 후보는 성분 경계의 알파 가중 색으로 바꾸고 원래 알파를 유지한다. 고립 잉크는 투명하게 지운다. 실제 점의 의도를 자동 추정하지 않으며 Before/After와 빨간 변경 후보 지도로 비교하고 선택/면적으로 제한한다. 후보 지도는 축당64칸에 모든 변경 위치를 모아 작은 점도 표시한다. 후보 지도 생성도 작업에서 계산하고128픽셀마다 취소를 확인한다.

Adjust line width−16–16px는 사각 이웃에서 양수는 최대 알파, 음수는 최소 알파를 고른다. 기존 잉크 RGB는 유지하고 빈 영역 확장은 가장 가까운 최대 알파 표본의 색을 받는다. 확장은 반경만큼 저장 경계를 늘려 캔버스 밖 잉크도 보존하며 축소는 원래 경계를 유지한다.1픽셀 선을 안전하게 완전히 지울 수 있다. 선폭과 고립 잉크 제거는 알파 잠금 해제를 요구한다.

실제8/16비트와 문서 프로필을 유지하고 원본에서만 계산한다. 선택 coverage로 섞고 선택 밖 원자료/마스크는 고정한다. 셀1·노이즈0·먼지 면적0·선폭0·빈 선택·실제 무변화는 dirty/Redo/이전 기록을 보존한다. 원본4M픽셀/32MiB, 출력4M픽셀/축32768,64M표본과 모든 열린 문서의 남은256MiB 예산을 확인한다. 셀 누적표·성분/큐/결과·출력과 스냅샷을 포함하며 무효 범위와 초과는 부분 확정 없이 거절한다.128픽셀/커널 표본마다 취소를 확인한다.

158번의 별도 계산·진행률·전후 미리보기·Apply 한 Undo·Escape/Cancel·오래된 문서/프레임/대상/설정 결과 거절·미확정 저장 안내를 공유한다. 후보 지도는 초안이며 문서/레이어에 넣지 않는다. 문서v72의 last_detail_filter.operation.Pixels에 마지막 셀/시드/먼지/선폭 설정과 선택 옵션을 저장한다. 실제 픽셀/배치는 기존 형식이며 다시 설정 불러오기를 제공한다. 새 변형의v71 이하 위장 헤더를 거절하며 기존v71 샤픈/언샤프/노이즈 제거는 계속 읽는다.

독립적인 셀 평균값·음수 격자/부분 셀·균일/투명 원자료·정수 시드 재현/변경·단색/색·먼지 면적/경계/명암/고립 잉크·선폭 알파/색/확장/완전 축소·선택/알파 잠금·16비트 극저알파·범위/예산/취소·네이티브/한 Undo/Redo를 검사한다. 앱에서4종 명령과 실제 마우스 미리보기/확정, 빨간 후보 위치/개수,64비트 큰 시드의 실제 키 입력/왕복, 저장 안내, 영효과 dirty/Redo·잘못된 계획 폐기·Escape·오래된 프레임을 검증한다. 실물 펜 검증은 별도 대기한다.

시드는 문자열에서 정수64비트로 직접 해석한다. 잘못된 입력 중에는 이전 정상 시드로 미리보기/확정하지 않는다. 최대값 바로 아래의 시드를 실제 키 입력으로 검증해 부동소수점 반올림을 피한다.
