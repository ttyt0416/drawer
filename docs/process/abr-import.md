# 로컬 ABR 검사와 제한된 팁 변환

기능071. ABR 원본은 읽기 전용으로16MiB 이하의 스냅샷을 만든다. 먼저 버전과 레코드 경계를 검사하고 변환 가능/미지원 이유를 항목별 표시한다. 검증된 범위는 독립 생성 시험 자료의 v1/v2 sampled(type2), 8비트 비압축 밀도, 각 변1~512px다. 외부 공급자의 실제 ABR 호환 검증은 완료했다고 주장하지 않는다. 이 범위 밖의 버전·계산형/알 수 없는 레코드·압축·깊이·추가 속성은 변환하지 않는다. 새 변형은 시험 자료를 검증하기 전 지원 목록에 추가하지 않는다.

메모리 내 레코드 수256개, 디코딩된 마스크 합계2MiB, 이름256 UTF-16 단위로 제한한다. 알려진 버전의 전체 테이블 경계·파일 끝·부호 있는 치수 차·원시 데이터 길이를 검증한다. 프레임 잘림/과대 길이/예상 밖 파일 꼬리는 보고서 전체를 거절하고, 경계가 정상인 미지원/손상 sampled 항목은 이유와 함께 제외한다. 미지원 버전은 헤더 번호만 표시하며 레코드로 추측해 읽지 않는다. 확장자만으로 파일의 진위를 확정하지 않는다.

기본 팁 밀도는 그대로 사용한다. 직사각형 마스크에는 투명 정사각형 여백을 더해 자체 팁 엔진에서 비율을 유지한다. 홀수 여백은 오른쪽/아래에 한 픽셀 더 배치한다. 프리셋 크기는 긴 변, 나머지 그리기 설정은 Drawer Pen 기본값이다. 원본 간격·안티앨리어싱·필압/색/산포/그 밖의 동역학은 변환하지 않으며 보고서에 이 사실을 명시한다. 원본과 같은 브러시 엔진 결과라는 주장은 하지 않는다.

Brush presets → Import ABR tips에서 검사 후 항목과 고유 이름을 선택한다. Convert selected tip은 기존 라이브러리와 프리셋 모음의 복사본을 먼저 검증하고 소재를 로컬에 게시한 뒤 프리셋 임시본에 추가한다. 중복 이름은 덮어쓰지 않는다. 이후 Apply brush presets가 S를 저장하고 Cancel은 프리셋 임시본을 버린다. 이미 등록한 소재 F는 Cancel 뒤에도 Local image materials에서 사용할 수 있다. 등록은 문서/변경 표시/Undo와 분리된다. 저장 실패·손상된 기존 목록·외부 목록 변경은 임시 프리셋과 기존 소재를 유지한다. 자체 JSON 프리셋 내보내기와 재시작도 기존 프리셋 경로를 사용한다. 향후 그리기는 로컬 materials/library.json의 등록 마스크가 필요하며 원본 ABR을 다시 읽지 않는다.

자료 근거는 공개 구현에 드러난 파일 필드의 의미/배열 순서로 제한했다. [GNOME 공식 공개 ABR 로더](https://github.com/GNOME/gimp/blob/master/app/core/gimpbrush-load.c)의 v1/v2 레코드 구분, endian, 이름/밀도 필드를 확인했다. 구현 코드·제어 흐름·자산은 가져오지 않았고 경계 검사/보고서/변환/시험 파일 생성은 이 저장소에서 독립 작성했다. Adobe/SAI/CSP의 설치 데이터·디컴파일 결과는 빌드/전달 입력에 없다.

시험은 두 버전의 독립 바이트 자료, 계산형/알 수 없는 레코드 혼재, 모든 바이트 길이 잘림, 버전/수량/길이/UTF-16/깊이/압축/치수/빈 마스크/꼬리/메모리 예산, 중복/잘못된 이름·실패 시 보존, 직사각 여백, 원본 바이트 불변, 자체 프리셋/목록 재읽기, 실제 Apply/Cancel와 재시작, 생산 입력의 변환 팁 사용/재현/한 이력/취소를 포함한다. 설치본도 독립 시험 파일을 만들고 동일한 검사·변환·로컬 저장·재시작·그리기를 실행한다. 실제 펜 검증은 별도 대기다.
