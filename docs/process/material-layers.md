# 126 — 로컬 비파괴 소재층

단색 RGBA, 기존 공개 그라데이션 계산, 불변 Arc RGBA 이미지와 별도의 영역/반복/역변환을 사용한다. 소재 로컬 좌표에서 픽셀 중심을 샘플링한다. 이미지는 최근접 원래 픽셀을 사용하고 X/Y별 바닥 좌표를 크기로 나눈 나머지로 반복한다. 반복을 끄면 작은 이미지 밖은 투명하다. 영역 밖은 항상 투명하며 페이지 크기/화면 회전은 원본 이미지를 재샘플링하지 않는다.

선택/속성/역할/이동/검색에는 기존 안정 개체 ID를 사용한다. 생성 기본값은 새 소재에만 적용한다. 편집은 잠금과 문서/프레임/리비전 및 작업공간 제한을 확인하고 Preview 후 한 번의 상태 확정으로 저장한다. 취소는 원본을 건드리지 않는다. 기존 자유형 그라데이션은 별도의 영역 도구에 남아 있다.

문서 v54는 JSON에 이미지 크기와 매개변수를 저장하고 애니메이션 뒤에 해당 이미지 순서의 u64 바이트 길이와 RGBA를 스트리밍한다. 이미지가 없으면 추가 바이트는 없다. JSON 단계에서 크기·한도와 예상 이미지 메모리를 먼저 검증하고 길이가 정확히 맞아야 픽셀을 읽는다. 수화 뒤 전체 검증과 파일 끝 검사를 수행한다. 저장은 기존 원자적 임시파일/치환 경로를 사용한다. 과거 버전은 불완전 이미지 개체를 허용하지 않는다. 이미지 원본 파일을 문서에 연결하지 않으므로 없어져도 재열기가 가능하다.

독립 기준 픽셀, 반투명 단색, 그라데이션 중간값, 2×1 투명 이미지, 작은 이미지 밖 투명, X/Y 반복, 90도 회전/2배/이동, 화면 독립, 원본 RGBA 보존, 검색 종류, Undo/Redo, 원본 이미지 삭제 후 재열기, 잘린/잘못된 길이·작은 예산·비가역 변환 거절 및 실제 앱 버튼/미리보기/편집/프레임 변경/Escape를 검사한다. 이미지당4Mi 픽셀, 문서/이력/JSON/작업공간 예산을 초과하면 확정 전에 거절한다.
