# 위치 안정화와 획 시작·끝

기능057. 안정화0~.95와 별도의 시작/끝 거리0~1e6px를 도구별 로컬 입력 설정으로 보존한다. 0은 해당 끝 끔. 선형 거리 계수의 곱으로 팁 크기를 줄이며 실제 입력 압력→필압 응답/크기·농도 대상 계산과 독립이다. 전체 길이0인 점 클릭은 계수1로 유지한다. 프리셋/작업공간 적용·취소·백업·초기화는 기존 설정 트랜잭션을 따른다.

기존 불변 원본 재계산기에 실제 입력 필압과 문서좌표 기울기 각도를 별도로 기록한다. 네이티브/중립 압력 경로는 마우스 가상 필압 활성 설정과 혼합하지 않는다. 마우스 가상 필압을 쓰면 그 결과와 별도 기하 계수를 함께 적용한다. 분사도 중심 반경/팁 크기에 기하 계수를 적용한다. 거리 절점과 .5px 세부 경로를 넣어 짧은 양 끝이 모두0인 두 이벤트의 중간을 잃지 않는다. 각도는 최단 회전으로 보간하며 필압 원자료는 그대로 보존한다.

미리보기는 실제 이벤트마다 한 번 안정화한 경로를 원본에서 재계산한다. 정상 종료에서 최종 입력점은 실제 수신 좌표로 마무리해 높은 안정화의 끝점 지연을 닫는다. 중간에 받지 않은 좌표나 예측점으로 연장하지 않는다. 취소/포커스 상실에는 이 마무리를 호출하지 않고 임시 획 전체를 버린다. 원시/보정/예측 Trace와 시작 시 안정화 값을 다시 표시 경로에 연결해 커서가 보정점을 원시점으로 잘못 표시하지 않게 한다.

팁 반복 중 기하 크기는 선형 보간하며 줄어든 크기를 간격 계산에도 반영한다. 기존 시간·경로·메모리·픽셀 작업량 한도와 계산 중 취소를 유지한다. 설정/스타일은 Down에서 고정한다. 픽셀과 고정 설정 메타데이터를 한 이력으로 Undo/Redo하며 저장 버전10은 끝 처리와 실제 입력 압력 경로 표식을 보존한다. 구형1~9의 누락 필드는 끝처리0/기존 가상 경로로 읽으며 기존 저장 픽셀은 바꾸지 않는다. 전체 원시 이벤트는 로컬 가상 재생 JSON에 보존한다.

실제 펜 장치 검증은 대기한다. 가상 입력/자체 설치 프로세스의 검증을 물리 장치 검증으로 간주하지 않는다.
