# 102 — 올가미·둘러싸기 채우기·작은 미채색 영역 보정

Lasso and enclosed-area fill에서Lasso fill/Enclose and fill을 고르고 캔버스에 경로를 드래그해 놓는다. 경로는 마지막점과첫점을 닫는다. 누른 동안 기존 문서→보기 투영으로 윤곽을 표시하고 놓기 전에 그림/선택/dirty/이력을 바꾸지 않는다. 실제 색칠 미리보기는 제공하지 않는다. 최소3개 비공선 점을 요구하며4×4 행 스캔RLE로 안티앨리어싱된 올가미를 구한다. 기존 페이지 좌표/문서 변환·선택 이동을 사용한다.

Lasso fill은 닫은 도형 전체를 현재색 또는 투명색으로 채운다. 원래 선택 강도와 올가미 경계 강도를 곱해 한 번만 적용한다. 선택/참조 개체를 바꾸지 않고 캔버스 밖 결과는 자른다. Paint coverage의 기존 래스터 확장·합성·알파보호·메모리 검사와 한 문서 Undo를 공유한다.

Enclose and fill은 현재 Fill options의 참조 집합/제외와 Alpha tolerance를 사용해 미채색(참조알파≤허용치)인4방향 연결 성분을 조사한다. 연결 성분이 캔버스 끝에 닿거나 올가미/원래 선택의 밖으로 이어지면 채우지 않는다. 참조에서 실제로 닫혔고 도형과 선택 안에 전체가 포함되는 성분만 채운다. 올가미가 외부 배경을 인위적으로 막는 벽이 되지 않으며1픽셀의 열린 틈도 바깥 연결로 유지한다. 색차/클릭 시드/틈 닫기/영역 확장은 이 도구에서 사용하지 않는다. 원래 틈을 자동으로 봉합하려면 별도의 Fill 도구101 옵션을 사용한다.

Patch small unpainted areas는 현재 선택(없으면 캔버스) 안에서 동일한 닫힌 미채색 성분 중 Maximum small-area pixels 이하인 성분만 채운다. 범위는1~4194304 정수 픽셀이며 경계값은 포함한다. 연결 성분 면적은 선택 강도로 가중하지 않는 픽셀 수다. 바깥 배경/열린 틈/최대면적 초과 성분은 유지한다. 값은 로컬 작업공간에 저장하고 구형 설정의 누락은64로 복원한다.

입력원·문서ID/리비전/프레임·보기·대상층·참조/영역 옵션·색/투명/알파보호를 획 시작 때 고정한다. Escape/초점 상실/보기/도구/설정/대상 변경/모달은 초안을 취소하고 실제 놓기를 기다린다. 놓기 한 번은 한 문서 명령으로 확정하며 선택 Scene을 그대로 보존한다. 잠긴/숨긴/비래스터 대상과 잘못된 도형·최대 면적은 거절한다. 실패는 부분 적용하지 않는다. 원본과 결과의 문서/작업공간 메모리·4Mi 픽셀·도형 행 스캔64Mi 작업·참조 합성64Mi 추정작업·RLE/Scene/Undo 상한을 검사한다. 외부 서비스/새 의존성은 없다.

자체7×7 닫힌 선에서 내부9픽셀만 채우고 바깥배경을 보존한다. 최대9는 포함/8은 제외,열린1픽셀 틈은 내부/외부 모두 유지한다. 올가미0.5좌표 경계는 알파128색의모서리32/중앙128이며 밖은0이다. 퇴화 경로/면적0/잠긴 대상·원본/선택 불변·한 Undo/Redo·문서 재열기를 확인한다. 생산 마우스/합성 펜의두도구·90도/확대8·누르기 초안/놓기 확정·여섯 취소·실제 작은영역 명령의면적8/9·로컬 설정 재열기를 설치본에서도 검사한다. 실제 펜 센서는 별도다.
