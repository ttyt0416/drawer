# 색상 변동과 두 번째 팁

기능068. RGBA 주색을 HSV로 변환하고 hue/saturation/value에 독립적인 시드 채널의 ±변동을 더한다. hue는 원형, S/V는0~1로 제한하고 원래 알파는 보존한다. 세 변동0은 변환 자체를 건너뛰어 원래 바이트를 보장한다. scope는 한 획의 같은 색 또는 도장 번호별 색이다. 시드는 동역학 크기/팁 순서/산포와 별도 상태이며 새 획마다 재현한다. 변동된 주색은 기존 안료 공급/혼색에 연결한다. 무색 운반은 주색을 만들지 않는다.

두 번째 마스크는 자체 Round/Square/Grain/Soft 수식이다. 기본 팁 로컬 좌표에서 상대 크기.1~1·회전±180°·각 축±반경1을 적용한다. Grain은 문서 좌표와 별도 채널 해시로 고정한다. coverage a/b의 Multiply=a×b, Add=min(1,a+b), Subtract=max(0,a−b), Minimum=min(a,b), Maximum=max(a,b), Difference=|a−b|를 계산한 뒤 기본 a와 opacity로 선형 혼합한다. 두 번째 opacity0/끔은 마스크 계산을 건너뛰므로 완전 투명한 두 번째 팁은 효과가 없다. Add/Maximum/Difference는 기본 coverage0 영역도 사용할 수 있으며 보수적인 픽셀/경로 경계를 확장했다. 주색 자체가 완전 투명하면 기본 잉크는 생기지 않는다. 기존 무색 번짐처럼 원래 안료를 사용하는 동작은 별도다.

합성 마스크는 기존 필압 농도/알파 잠금/선택/전체 농도/질감과 한 이력 게시를 공유한다. 도장 작업262144회·픽셀 작업/메모리/경로 예산과 계산 중 취소를 유지한다. 원본 앱의 HSV/합성 수치 호환을 주장하지 않으며 원본 소재/코드를 사용하지 않는다. 입력 설정 적용/취소/백업/기본값/재시작·로컬 프리셋·가상 입력·문서v20의 고정 스타일/결과에 보존한다. 옛 필드 누락은 변동0/두 번째 팁 끔이다. 시험 칠하기도 같은 엔진이다.
