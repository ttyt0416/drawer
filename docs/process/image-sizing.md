# 문서 크기·해상도 변경

`Resample…`은 래스터 픽셀을 최근접 또는 premultiplied-alpha 양선형 보간으로 재생성한다. 가로·세로 배율은 별도로 적용한다. `DPI…`는 DPI만 변경한다. `Canvas size…`는 9개 앵커 중 하나를 기준으로 래스터를 이동하고 여백을 투명하게 채우거나 경계 밖을 제거한다. `Crop…`은 현재 그림 안의 정수 픽셀 직사각형을 새 출력 경계로 삼는다.

텍스트·벡터 선·톤·그림자·선택·가이드·카메라는 원래 좌표와 속성을 유지하며 공통 문서 변환으로 위치와 외관을 바꾼다. 3D 세계 정점은 변경하지 않는다. 비래스터 잘라내기는 원좌표계의 다각형 마스크를 추가한다. 다시 캔버스를 키워도 잘린 비래스터 내용이 나타나지 않지만 기하는 편집 가능한 상태로 남는다.

본문 모델의 기본 텍스트 윤곽·선·톤·그림자와 직교 카메라/와이어 메시 렌더러로 혼합 문서를 검증한다. 이 모델은 후속 편집 도구의 기반이며, 텍스트 배치·벡터 편집·톤 설정·선택 도구·3D 편집기 전체를 완료했다는 뜻은 아니다. 그 항목들은 별도로 검증한다.

크기 변경 창은 원본 상태에서 경계·제거할 픽셀 영역/레이어·잘릴 객체 번호와 물리 크기/객체 단위를 표시한다. 제거가 있으면 추가 확인이 필요하다. 계산은 별도 스레드에서 진행하고 Cancel/Escape로 중단한다. 문서 식별자와 변경 번호가 같을 때만 결과를 적용한다. 미리보기 도중 저장·다른 편집은 창을 확정하거나 취소한 뒤 할 수 있다.

확정 하나는 실행 취소 하나다. 원래 픽셀·좌표 변환·잘림 마스크·DPI·선택·가이드·카메라를 복원한다. 크기 변경의 원본과 결과를 함께 보존할 수 없으면 계산 전에 거절한다. 현재 기본 한도는 열린 문서/작업 예산 256 MiB와 이력 64 MiB·100단계다. 성능 목표의 대용량 희소 문서는 후속 저장/이력 기능에서 구현한다.

300/600 DPI 출력은 문서의 물리 크기와 톤 기준 픽셀 주기에서 출력 좌표를 환산한다. DPI만 2배로 바꾸면 같은 문서 픽셀 외관은 유지되고 표시 pt/mm는 절반, 표시 lpi는 2배가 된다. 비균등 이미지 배율은 수평/수직 단위를 따로 표시한다.
