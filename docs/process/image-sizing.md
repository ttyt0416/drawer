# 문서 크기·해상도 변경

`Resample…`은 래스터 픽셀을 최근접 또는 premultiplied-alpha 양선형 보간으로 재생성한다. 가로·세로 배율은 별도로 적용한다. `DPI…`는 DPI만 변경한다. `Canvas size…`는 9개 앵커 중 하나를 기준으로 래스터를 이동하고 여백을 투명하게 채우거나 경계 밖을 제거한다. `Crop…`은 현재 그림 안의 정수 픽셀 직사각형을 새 출력 경계로 삼는다.

텍스트·벡터 선·톤·그림자·선택·가이드·카메라는 원래 좌표와 속성을 유지하며 공통 문서 변환으로 위치와 외관을 바꾼다. 3D 세계 정점은 변경하지 않는다. 비래스터 잘라내기는 원좌표계의 다각형 마스크를 추가한다. 다시 캔버스를 키워도 잘린 비래스터 내용이 나타나지 않지만 기하는 편집 가능한 상태로 남는다.

본문 모델의 기본 텍스트 윤곽·선·톤·그림자와 직교 카메라/와이어 메시 렌더러로 혼합 문서를 검증한다. 이 모델은 후속 편집 도구의 기반이며, 텍스트 배치·벡터 편집·톤 설정·선택 도구·3D 편집기 전체를 완료했다는 뜻은 아니다. 그 항목들은 별도로 검증한다.

크기 변경 창은 원본 상태에서 경계·제거할 픽셀 영역/레이어·잘릴 객체 번호와 물리 크기/객체 단위를 표시한다. 제거가 있으면 추가 확인이 필요하다. 계산은 별도 스레드에서 진행하고 Cancel/Escape로 중단한다. 문서 식별자와 변경 번호가 같을 때만 결과를 적용한다. 미리보기 도중 저장·다른 편집은 창을 확정하거나 취소한 뒤 할 수 있다.

확정 하나는 실행 취소 하나다. 원래 픽셀·좌표 변환·잘림 마스크·DPI·선택·가이드·카메라를 복원한다. 크기 변경의 원본과 결과를 함께 보존할 수 없으면 계산 전에 거절한다. 현재 기본 한도는 열린 문서/작업 예산 256 MiB와 이력 64 MiB·100단계다. 성능 목표의 대용량 희소 문서는 후속 저장/이력 기능에서 구현한다.

300/600 DPI 출력은 문서의 물리 크기와 톤 기준 픽셀 주기에서 출력 좌표를 환산한다. DPI만 2배로 바꾸면 같은 문서 픽셀 외관은 유지되고 표시 pt/mm는 절반, 표시 lpi는 2배가 된다. 비균등 이미지 배율은 수평/수직 단위를 따로 표시한다.

그림 자체의 좌우/상하 반전과 시계/반시계 방향 90도 회전은 보간 없이 모든 래스터층을 재배치하고 같은 문서 변환을 객체에 합성한다. 회전 때 가로·세로를 교환한다. 보기 각도·배율·Mirror는 유지하며 실행 취소 한 번으로 원본을 복원한다. PNG 출력은 보기 변환을 적용하지 않는다.

기능 016은 새 그림/크기 변경에 px/mm/inch 단위·비율 잠금과 로컬 크기 프리셋을 추가한다. 물리 치수는 입력 DPI로 정수 픽셀에 반올림하며 실제 픽셀·mm 결과를 표시한다. DPI의 픽셀 유지 모드는 크기 입력을 비활성화하고 실제 픽셀을 변경하지 않는다. 재샘플링 모드는 DPI 변경 때 물리 크기를 유지하도록 픽셀 수를 계산한다. 캔버스 크기 프리셋은 픽셀 치수를 적용하며 문서 DPI는 바꾸지 않는다고 UI에 표시한다.

각 변 증감은 기존 가로+왼쪽+오른쪽, 세로+위+아래를 출력 크기로 삼고 왼쪽/위 증감만큼 원본을 이동한다. 양수는 투명 여백, 음수는 제거다. 합이 0/음수/축 범위 밖이거나 증감이 안전 한도를 넘으면 거절한다. 9점 기준 크기 변경과 별도 방식으로 제공하며 제거 확인·배경 계산 취소·단일 Undo를 동일하게 적용한다.

프리셋은 이름·픽셀 크기·DPI·표시 단위를 버전 1의 `settings/canvas-presets.json`에 저장한다. 중복 이름은 확인 없이 덮지 않는다. 선택 적용·현재 크기 저장·삭제·프리셋 Undo/Redo·초기화·직전본 복원과 로컬 묶음 입출력을 제공한다. 설정 변경/가져오기 전에 정상 직전본 또는 손상본을 보존하고 원자적으로 저장한다. 불량/쓰기 실패는 기존 목록과 그림을 보존한다. 기본 프리셋은 독자적으로 지정한 1200×900, A4 300 DPI, 정사각형 2048이다.

기능 018은 최근접·양선형·Catmull–Rom 쌍삼차·픽셀 영역 평균·4×4 양선형 오버샘플링을 별개 방식으로 제공한다. 모든 가중 합성은 premultiplied alpha로 계산한다. 영역 평균은 역변환한 출력 픽셀의 사각형과 원본 픽셀 셀의 교차 면적을 적분하며, 오버샘플링은 그 영역의 16개 지점에서 양선형 값을 평균한다. 평균색과 오버샘플링은 서로 다른 함수/설정 값이며 시험 패턴에서 다른 결과를 확인한다.

Image quality의 보기/해상도/래스터 개체/애니메이션 샘플링 설정은 별도 입력으로 보존한다. 보기와 해상도 명령에는 현재 UI가 연결되어 있다. 개체/애니메이션은 명시적 Scope를 받는 공통 래스터 샘플링 API로 분리하며 해당 전체 편집기 항목은 아직 완료하지 않는다. 모든 보기 창은 실제 보이는 원본 픽셀에서 화면 텍스처를 계산하며 회전·반전·DPI의 출력 픽셀 영역을 사용한다. 현재 화면 텍스처는 축당 2048 기기 픽셀 이하로 제한하며 더 큰 화면은 동일 영역을 축소 계산한다. 이 보기 버퍼는 파일에 저장하지 않는다.

보간 설정은 버전 1의 로컬 interpolation.json에 저장하고 별도 설정 Undo/Redo·초기화·직전본 복원을 제공한다. 보기 설정 변경 전후 문서 픽셀/선택/변경 표시/문서 이력과 실제 PNG 출력 바이트의 불변을 시험한다. 체커보드 확대/축소, 1픽셀 알파 경계, 0/37/90도 영역과 설정의 대상 분리를 검증한다.
