# 로컬 이미지 소재

기능070. 지원 입력은 기존 검증된 ImageSource 경로의 PNG/JPEG/단일 페이지 TIFF다. 파일 스냅샷/크기 확인 뒤1~512px만 decode하고 방향/ICC를 sRGB RGBA8로 정규화한다. encoded 입력 최대16MiB·작업32MiB와 기존 프로필/페이지/디코더 한도를 공유한다. 압축이 작아도 큰 치수는 decode 전에 거절한다. 완전 투명 입력은 종류와 무관하게 거절한다. 투명도가 있는 팁은 알파, 완전 불투명 팁은 정수 농담(54R+183G+19B+128)/256의 반전을 사용하며 빈 밀도는 거절한다. 질감은 농담을 알파로 흰색과 합성한다. 원본 파일을 변경하지 않는다.

Library v1은 ID1024 이상/이름/종류/치수/L8 마스크를 로컬 JSON에 저장한다. 최대32개·마스크 합계2MiB·파일8MiB다. deserialize의 목록/픽셀 방문자는 allocation 개수를 제한하며 이름/ID/치수/길이/버전/중복을 검사한다. ID는 삭제 후 재사용하지 않는다. 새 임시 파일을 exclusive 생성하고 기록/동기화 후 게시하며 외부 임시 파일은 보존한다. 앱은 손상되거나 외부에서 바뀐 목록을 덮어쓰지 않는다. 실패는 이전 디스크/메모리 목록을 유지한다.

등록은 F이며 문서와 입력 임시본의 적용 트랜잭션과 별개다. Use 버튼/팁 목록/Brush texture는 S 임시본에 참조 ID를 고른다. 프리셋/문서v22의 기존 순서/질감 참조와 결과 픽셀에 보존한다. 이미지 원문 대신 마스크를 저장해 원본 이미지를 지워도 목록 재시작/새 획에 사용할 수 있다. 소재 참조 자체는 전역 로컬 목록에 의존하며 문서는 그려진 픽셀을 자체 저장한다. 종이 효과의 사용자 이미지 적용은 이 브러시 소재 선택에 포함하지 않는다.

Stroke/Replay/시험 영역/가상 재생 worker는 누름/시작의 Arc<Library>를 고정해 삭제/재등록이 진행 획을 바꾸지 않는다. Native 팁은 사각 범위와 이중 선형 마스크 샘플, 명시적 Round/Square 외곽은 유지한다. 현재 색·부모 도구 동작·경도/필압/순서/패턴·두 팁과 결합하며 전역 농도/선택/질감은 한 번 적용한다. 질감은 문서 좌표의 크기/회전/위치와 반복 샘플을 사용하고 최종 수채 확산에도 한 번 반영한다. 추가 이미지 샘플은 픽셀 작업 예산에 포함한다. 누락 참조는 경고와 기존 대체를 사용한다.

시험 이미지는 독립적인 작은 PNG/JPEG/TIFF/BMP 및 수식 배열로 생성한다. 원본 프로그램 이미지/코드/리소스는 사용하지 않는다. 새 외부 라이브러리를 추가하지 않는다. 물리 펜 시험은 대기한다.
