# 빠른 획의 팁 간격

기능 056. 문서 좌표에서 실제 입력점 사이를 거리 간격으로 보간하며 프레임 수나 화면 확대에 의존하지 않는다. 회전된 납작한 타원도 연결되도록 간격 기준 지름은 보수적인 짧은 축이다. 크기×비율×최소 구간 필압크기×간격, 연산 하한1/1024px. 큰 간격을 사용자가 지정하면 그 간격에 따른 점 여백은 유지한다. 압력에 따라 간격이 줄면 이전 잔여 거리를 새 간격으로 정규화해 뒤로 되돌아간 팁을 생성하지 않는다. 실제 끝점은 종료 때 한 번 마무리하고 같은 위치 반복은 가짜 이동을 만들지 않는다. 알려지지 않은 실제 곡선을 추측하지 않고 수신한 꺾은 경로를 연결한다.

캔버스 밖 두 점의 긴 선분도 확장 캔버스 사각형과 교차한 부분만 계산한다. 한 선분100만 팁과 획 전체64Mi 후보 픽셀 연산, 기존 변경 픽셀/메모리 한도를 적용한다. 실패는 문서에 부분 확정하지 않고 호출자가 임시 획 전체를 폐기한다. 마우스 재계산의 사전 작업량 추정도 같은 간격 공식을 쓴다.

가상 재생 JSON은 크기/비율/각도에 더해 도구별 농도/경도/간격을 보존·검증한다. 누락된 옛 필드는 각각1/1/.15로 읽는다. 같은 시간 묶음·동일 이벤트 반복·압력 유무·마우스/펜 경로에서 픽셀과 Undo/Redo를 검증한다. 이 재생은 물리 장치나 드라이버 성능의 검증이 아니다.
