# 로컬 파일 동작·영상 가져오기

기능 021은 자체 문서 저장본 되돌리기, 사용자 요청의 OS 기본 앱 설정 안내, 로컬 영상을 새 애니메이션 또는 기존 타임라인으로 가져오는 동작이다. 파일 연결은 Windows가 결정하며 앱은 레지스트리 연결을 자동 변경하지 않는다. 실행 인자로 전달된 로컬 .drawer/PNG 경로를 연다. 되돌리기는 버릴 변경을 확인하고 파일을 끝까지 읽은 뒤 같은 문서 ID/도구/보기로 교체한다. 취소·누락·손상·자원 부족은 현재 문서를 유지한다.

코덱은 선택적 로컬 외부 프로세스다. 설치된 FFmpeg/FFprobe 7.1을 PATH에서 찾거나 사용자가 로컬 실행 파일을 고른다. 자동 다운로드·원격 입력·코덱 배포는 없다. 검증한 입력은 MP4/MOV의 H.264 yuv420p, MKV의 FFV1 BGRA, AVI의 rawvideo BGRA, WebM의 VP9 yuv420p다. 8비트 SDR 전달 특성(미지정/BT.709/SMPTE170M/sRGB)만 허용한다. 다른 코덱/픽셀 변형/HDR은 이유를 표시하며 원본을 수정하지 않는다. 오디오 선택은 AAC/16비트 signed PCM을 48 kHz signed PCM으로 변환하며 1~8개 채널 수를 유지한다. 오디오 없는 영상은 영상만 가져온다. FFV1/AVI의 RGB, 알파와 숨겨진 RGB는 RGBA8 셀 데이터에 보존한다.

원영상은 최대 64 MiB의 고정 바이트 스냅샷으로 읽고 임시 복사본만 디코더에 전달한다. 입력 프로토콜은 file/pipe, 컨테이너는 mov/matroska/webm/avi로 제한한다. 원본 파일 경로에 쓰지 않는다. 소스/샘플 프레임은 각각 10,000개 이하, 영상 시간은 1시간 이하, 한 원본 프레임의 RGBA 크기는 64 MiB 이하이며 더 작은 실제 문서/작업공간/Undo 예산도 통과해야 한다. 처리 중 Cancel/Escape는 자식 프로세스를 중단하고 임시 복사본을 제거한다. 오류 출력/결과 크기와 실행 시간(120초)을 제한하고 실패한 결과는 확정하지 않는다.

시간 범위 양끝은 포함한다. t=start+n/fps에서 그 시각 이하의 마지막 원본 프레임을 선택하여 VFR을 실제 타임스탬프로 처리한다. 첫/마지막 프레임·0 길이 범위를 처리한다. 출력 크기는 기능 018의 다섯 보간 방식으로 샘플링한다. 셀과 시간 대응표를 미리 보고 명시적으로 확정한다. 새 문서는 독립 경로 없는 미저장 애니메이션이다. 삽입은 문서 FPS에 맞춘 전체 대응표를 보여 주고 새 트랙/노출표/선택 오디오를 한 Undo로 추가한다. 기존 트랙·DPI·파일 경로는 유지하며 범위 초과/수정 번호 불일치/디코드 실패/취소는 원래 타임라인을 보존한다.

자체 형식 6은 FPS 유리수·셀별 RGBA/크기/원점·트랙·노출·오디오 PCM/채널/시작을 보존하고 형식 1~5를 읽는다. 셀 버퍼는 불변 공유로 복사되며 문서 예산에는 보수적으로 각각 계산한다. 현재 프레임 이동은 보기 동작으로 픽셀/변경 표시/문서 이력에 넣지 않는다. 표시 캐시는 프레임도 구분한다. 기존 크기/DPI/반전/회전 명령은 모든 셀에 적용하고 시간과 오디오는 유지한다. 전체 타임라인 편집기·재생기 항목은 별도로 검증하며 이 항목을 이유로 후속 항목을 완료 처리하지 않는다.

일반 오프라인 시험 88개와 별도로 `cargo test -p drawer-core --offline --locked --target-dir target/latest real_decoder_vfr -- --ignored`를 실행해 실제 설치 코덱 시험 1개를 통과했다. 코덱 시험은 개발 컴퓨터의 로컬 FFmpeg가 필요하므로 일반 시험에서는 선택적으로 실행한다. 실제 fixture는 VFR 0/0.15/0.6초, 1프레임 AVI, MP4/MOV/WebM, FFV1의 반투명/투명 RGB, 서로 다른 좌우 음성·PCM/AAC와 범위/끝·예산·중단을 검증한다. 파일/시험 영상/디코더 임시 복사본은 시험 종료 때 제거한다. 마우스로 취소/새 문서/삽입을 확인하고 누락 코덱 공급자·쓰기/되돌리기 오류·원본 불변·자체 문서 재열기·한 번 Undo를 검증한다. 설치 앱에서도 코덱 없음 상태 공급자, 되돌리기와 애니메이션 재열기를 검증한다.
