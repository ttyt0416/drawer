# 화면 기준 크기·최소 픽셀·간격 농도·연속 분사

기능078. Tool input → Scatter, ribbon and repeating decorations의 각 도구에 동작 옵션을 둔다. 기본값은 모두끔, 분사율20회/초다. 구형 pattern 설정에 behavior가 없으면 이 기본값을 사용한다. 프리셋/사용자 슬롯/전체 설정/백업과 문서v27의 고정 Style에 함께 저장한다. 바뀐 획은 확정 픽셀과 한 그림 이력을 보존한다. 설정 변경은 이미 그린 그림이나 진행 중인 획을 재설정하지 않는다.

Keep size in physical screen pixels는 획 시작 표시 배율로 입력 크기를 나눈 문서 지름을 고정한다. View.zoom은 물리 표시픽셀/문서픽셀이므로 화면 배율 보정에 별도 논리 DPI 계수를 곱하지 않는다. 배율0.5/2에서 화면16px는 문서32/8px, 문서16px 모드는 그대로16px다. 회전/미러는 기존 좌표 변환을 공유하고 hover 커서도 같은 환산을 쓴다. 엔진의 문서4096px 한계는 유지한다. 기존 동역학의 절대 최소/최대 크기 제한은 문서 단위다.

Minimum diameter: one document pixel은 독립 옵션이다. 압력·속도·크기 변동 후 지름과0보다 큰 끝점 기하 배율의 결과를 최소1로 한다. 명시적으로0인 끝점 기하는 계속 무잉크이며 알파/농도0은 그대로0이다. 끄면 기존0보다 큰 소수 지름을 유지한다. 최소값은 큰 축의 지름이며 종횡비를 바꾸지 않는다.

Compensate density for path spacing은 기준 간격0.15에서 원래 coverage를 유지한다. 누적 가능한 각 도장의 실제 알파 a에 대해 `a' = 1-(1-a)^(spacing/0.15)`를 사용한다. 동일한 균일 coverage/거리에서는 도장 수가 달라도 광학 투과율이 같고 RGBA8 반올림 오차만 남는다. 실제 팁 경계·간격이 넓어 생긴 빈 공간·색/압력 변화는 다르게 표본화될 수 있다. 픽셀/복제/특수 합성/리본/속도 농도의 기존 최대 coverage 규칙은 유지한다. 선택·전체 농도·질감은 기존처럼 마지막에 한 번 적용한다.

Continuous emission while held는 마우스/펜 모두 누르는 순간1개, 이후 고정 정수 마이크로초 간격(1–200회/초)마다 도장을 생성한다. 실제 위치가 같아도 시간만으로 누적한다. 크기/필압/색/팁 시퀀스/소재/산포·끝점 설정을 동일한 재구성 경로로 적용한다. 네이티브 필압은 필터 후 보간하고 장치/브러시 곡선을 한 번 적용한다. 시계 표본은 마지막 실제 속성/속도를 유지한다. 실제 샘플과 프레임 시계를 분리하며 release의 실제 시각보다 늦은 임시 시계는 제거한다. 버튼을 놓으면 즉시 정지하고 하나의 Undo/Redo로 다룬다. Esc/명시적 취소는 pending 세션 전체를 취소한다. 포커스 상실도 기본적으로 취소하며, 기능080의 수채 경계가 켜진 유효 수채 세션은 후처리를 포함해 종료한다. 연결선은 held 세션이 아니므로 시간 분사를 거절한다.

이 모드는 시간당 농도를 정의하므로 경로 간격 농도 보정은 생략한다. 기존 Mouse spray를 동시에 선택하면 기존 작은 입자·반경·입자 수·주기를 우선한다. 일반 연속 분사는 현재 팁 전체 크기를 쓰고 Scatter라면 각 시각에 설정한 입자 수를 낸다. 누락/같은/역행 시각은 음수 시간이나0나눗셈을 만들지 않는다. 최대262144도장·기존64Mi 픽셀 작업량/재구성 입력 한계를 넘으면 확정하지 않고 취소한다.

Keep scatter offsets fixed per tip and particle는 시드+팁 소재ID+입자 번호로 위치를 결정하고 경로 도장 번호를 무시한다. 같은 획 안에서 같은 팁·입자 오프셋을 유지하고 시드 재현으로 같은 결과를 낸다. 끄면 기존 경로 도장별 산포다. 방향은 기존 산포 방향 설정을 공유한다.

팝업 시험 영역도 고정3논리픽셀 표시 배율에서 화면 크기를 환산하고 기존 문서64px 지름 한계를 유지한다. 동일 재구성 엔진에 held 시계를 공급하며 놓기/취소 뒤 분사하지 않는다. 창을 닫거나 포커스를 잃으면 원본 시험 픽셀로 돌아간다.
