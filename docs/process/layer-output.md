# 레이어·컴프 출력과 생성 표시 정책

250: 기존 Layer comps에서 이름·표시/불투명도/합성 모드 저장·갱신·전환·삭제·비교를 유지하고 현재 컴프 ID를 기록한다. New-layer policy / batch output을 펼치면 새 레이어의 All 또는 Current 정책과 컴프/레이어별 출력 창을 연다. 앱 기본은 settings/layer-comp-policy.json의 로컬 설정이고 문서의 선택 정책·현재 컴프는 Native123에 저장한다. 정책 선택만은 그림 Undo와 분리되며 기존 그림 Undo/Redo가 현재 선택한 생성 정책을 되돌리지 않는다. 읽지 못한 기본 파일은 교체 확인 전 보존한다.

새 래스터/벡터·폴더·페이지 개체·트랙/셀의 안정 ID를 공통 commit_state/edit_scene 경로에서 검사한다. 기존 컴프마다 새 항목을 추가하며 All은 모두 표시, Current는 현재 컴프만 표시하고 다른 컴프는 명시적으로 숨긴다. 삭제된 컴프/층은 표시할 수 없으며 재사용 폴더 키에는 새 생성 상태를 기록한다. 현재 컴프를 지정하지 않은 옛 문서에서 Current 정책으로 생성하려면 먼저 컴프를 적용한다. 새 층/컴프 항목은 같은 생성 Undo 단위이다. 컴프 없는 문서에서는 항목을 만들지 않는다. 생성 이외의 편집에서는 ID 집합만 검사해 추가 문서 복사 없이 끝낸다.

Output size/resolution/name 창에서 Full composite / Each layer / Each saved comp, 숨긴 층 포함, {title}/{index}/{layer}/{comp} 이름 규칙을 선택한다. 최대32문서·128출력·합계64MiB이며 실제 인코딩 바이트/이름/크기/손실/누락층을 검토하고 새 파일만 출판한다. 금지 이름·대소문자 충돌·같은 이름 규칙은 쓰기 전에 거절하고 기존 파일은 건너뛰어 결과에 표시한다. 완료 파일은 취소 후 유지하며 미완료 파일은 취소 결과를 남긴다.

컴프 적용과 레이어 격리는 출력 복사본에만 수행하므로 성공/실패/취소 뒤 복원할 라이브 상태가 없다. 원래 픽셀·표시·문서 경로·리비전·Undo를 바꾸지 않는다. 컴프의 삭제된 ID는 출력 상세에 나열하고 살아 있는 항목만 적용한다. 개별 레이어는 원래 크기의 독립 소스/폴더 하위 트리를 출력하며 필요한 조상 폴더를 열고 외부 배경을 제외한다. 제외된 베이스에 대한 클리핑만 복사본에서 해제한다. 따라서 전체 그림의 하위 배경에 의존하는 합성 모드는 다르게 보일 수 있다는 안내를 출력 계획에 표시한다. 전체 시각적 합성 상태가 필요하면 컴프 출력을 사용한다.

검증: 새층·복제·폴더·실제 래스터 붙여넣기에서 All/Current 항목과 한 번 Undo/Redo, 로컬 기본 재시작, Native123 재열기/122로 위장 거부, 숨긴 층 포함·컴프별 다른 PNG·검토 바이트·중복/금지 이름·기존 파일 보존·취소/누락층·라이브 표시/이력 불변, 실제 포인터 Prepare/Write/Close 경로를 포함한다.
